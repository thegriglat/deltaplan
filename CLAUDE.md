# Deltaplan — для Claude

Симулятор дельтаплана на Godot 4.7.2 (Win/Linux/macOS), некоммерческий open source. Процесс работы с агентами, роли, контракты, правила, типы агентов, наблюдение — **`.claude/workflow.md`** (прочитать перед любой многошаговой работой).

Коротко:
- Роли: пользователь — решения; главная сессия — глобальный координатор (планы, координаторы модулей, отчёт каждые 30 мин, слияния по одобрению); координатор модуля (`dp-coordinator`) — план, **контракты до исполнителей**, копия на задачу, приёмка, шлюзы; исполнители — одна задача в своей копии.
- Физика прежде «нравится»; не шлифовать; совместимость не нужна; Godot — только `XDG_DATA_HOME=$(mktemp -d)`; переписанный редактором `project.godot` не коммитить.
- Долгие запуски — фоном или `tools/job.sh start/wait`; не `pgrep -f`/`pkill -f`.
- Коммиты — только свои файлы (`git commit -- <пути>`), по-русски, со строкой Claude-Session; не пушить без команды пользователя.
- Публичные тексты: родители — только «родители автора — пилоты»; иначе «пилот».
