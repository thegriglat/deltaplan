# Deltaplan — для Claude

Симулятор дельтаплана на Godot 4.7.2 (Win/Linux/macOS), open source. Процесс работы с агентами, роли, контракты, правила, особенности проекта — **`.claude/workflow.md`** (прочитать перед любой многошаговой работой; раздел «Deltaplan» — специфика проекта).

Коротко про проект:
- Физика прежде «нравится»; не шлифовать; совместимость не нужна.
- Godot — постоянный профиль своей копии `XDG_DATA_HOME=~/.cache/dp-xdg/$(basename "$PWD")`, пачки тестов — временный; переписанный редактором `project.godot` не коммитить.
- Долгие запуски — фоном или `.dpcli/dpcli job start/wait`; не `pgrep -f`/`pkill -f`.
- Коммиты — только свои файлы (`git commit -- <пути>`), по-русски; не пушить без команды пользователя.
- Публичные тексты: родители — только «родители автора — пилоты»; иначе «пилот»; пасхалки на сайте не упоминать.
- Документация: вход `docs/INDEX.md`; «что мы знаем про X» — `.dpcli/dpcli docs findings X` / `.dpcli/dpcli docs find X`; frontmatter обязателен, `.dpcli/dpcli docs check` перед коммитом docs.

## Процесс работы с агентами (dpcli)

Перед многошаговой работой — прочитать **`.claude/workflow.md`**. Журнал, задачи, ветки, документы — только `.dpcli/dpcli` (`.dpcli/dpcli -h`).

- Роли: пользователь — решения; главная сессия — планы, координаторы модулей, отчёт раз в 30 мин, слияния в `main` по одобрению; `dp-coordinator` — контракты, карточки, приёмка, шлюзы; исполнитель — одна задача в своей копии.
- Сообщения — по протоколу (.claude/workflow.md, «Протокол сообщений»): ID и команды, без пересказа журнала.
- Детерминированное — командами `.dpcli/dpcli`; журнал `docs/plan/<м>/` только дописывается.
- Корректность прежде «нравится»; не выдумывать; не шлифовать.
- Документы — вход `docs/INDEX.md`; искать `.dpcli/dpcli docs find`, читать по разделам `.dpcli/dpcli docs section <путь> [раздел]`, не целиком.
- Коммиты — только свои файлы (`git commit -- <пути>`); не пушить без команды пользователя.
- Агенты — `.dpcli/agents/`, процесс — `.dpcli/templates/workflow.md`; `.claude/` обновляет `.dpcli/dpcli init`.
