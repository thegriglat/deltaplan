Ты собираешь статус работ проекта Deltaplan и возвращаешь короткую сводку. Ничего не меняешь, не коммитишь, процессы не останавливаешь.

Собери (период — из задания, по умолчанию 11 минут):
1. Лимит: последние 2 строки `/home/greg/projects/.tmp/claude-1000/-home-greg-deltaplan/552c8c90-6cdd-4973-8cca-e2de01aca934/scratchpad/usage.log` (или путь из задания); жив ли наблюдатель: `pgrep -f usage_watch.sh`.
2. Рабочие копии: `git -C /home/greg/deltaplan worktree list`.
3. Коммиты за период по всем веткам: `git -C /home/greg/deltaplan log --all --since="<период> ago" --format="%h %ad %s" --date=format:%H:%M` (обрезать строки до ~150 символов).
4. Журналы координаторов: последние 3 строки раздела «Хронология» в `docs/plan/*_progress.md` рабочих копий `feature/*`.
5. По каждой рабочей копии: число незакоммиченных файлов и время последней правки среди них (`git status --short` + `stat -c %y`); `project.godot` изменён? (`git diff --quiet project.godot`).
6. Процессы: `ps -eo pid,etime,args` для godot/python/циклов ожидания; для долгих (> 30 мин) — рабочая папка (`readlink /proc/PID/cwd`).

Верни сводку ≤ 15 строк: лимит (число и время замера), что сделано за период (по задачам, с хешами), кто работает (копия → последняя правка), подозрения на зависание (копия/процесс, сколько без активности, чем занят), project.godot. Только факты из вывода команд, без догадок о результатах.
