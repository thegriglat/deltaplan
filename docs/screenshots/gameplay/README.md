# Геймплей свободного полёта — кадры по камерам (карточка game/03)

Снято `tools/shots/gameplay.sh` (Онгудай, старт по умолчанию, `--autopilot`, 20 с симуляции, 1920×1080,
каждый запуск под `timeout 120`). Клавиша C переключает камеры в этом же порядке.

| Кадр | Камера | Чек-лист | Итог |
|---|---|---|---|
| [cockpit.jpg](cockpit.jpg) | cockpit (кабина, взгляд вперёд) | прибора в углу **нет** (FR-21: в кабине прибор — на трапеции, под кадром); впереди простор — горизонт, склоны, облака | ✔ |
| [chase.jpg](chase.jpg) | chase (сзади) | крыло и пилот лёжа по центру; камера над рельефом, не в склоне; прибор в углу справа внизу, страница 1 «ПОЛЁТ», показания живые (варио −0,1, 37–38 м над землёй, время 0:00:17) | ✔ |
| [free.jpg](free.jpg) | free (свободная) | камера осталась у старта (включена стоя, сзади-сбоку, над травой ≥ `free.min_agl_m`), смотрит на планер — он улетел по курсу автопилота; прибор в углу виден; крыло летит без рук, WASD двигают камеру | ✔ |

Проверки того же в коде — `tests/game/test_gameplay.gd` (смена 3 камер, прибор в углу по камере, chase над рельефом,
free не двигает крыло).
