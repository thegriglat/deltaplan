## Найденные чужие дефекты (не мои владения — не чинил)

1. **`scripts/flight/landing_flare.gd:88`** и **`scripts/game/game.gd:411,443`.**
   `LandingFlare.touchdown()` кладёт в результат посадки свой ключ `result["flight_time_s"] =
   m.time_s` (время `FlightModel` с последнего `reset_on_ground/reset_in_air`, а не время всего
   полёта). В `Game._on_landed`/`_on_collision` это же имя есть в `FlightStats.summary()`
   (реальное суммарное время полёта), но `info.merge(stats.summary(...))` вызывается без
   `overwrite=true` — Dictionary.merge по умолчанию не перезаписывает существующий ключ.
   В результате на экране итога после ЛЮБОГО повторного взлёта/переброски в воздухе в рамках
   одной попытки (без `restart()`) «Время полёта» показывает время только с последнего
   `reset_in_air`, а не всей попытки — то же самое отражается и в кадрах `*_result.jpg` здесь
   (например, ongudai: «Время полёта: 0:05» при пройденных 60+ с и 5.72 км). Симптом
   воспроизводится и без моих скриптов: любой код, который делает `glider.reset_in_air(...)`
   посреди полёта перед посадкой (например, в тестах группы game или на будущих заданиях с
   несколькими стартами), получит заниженное «Время полёта» на итоговом экране. Владелец —
   группа `game/` (`scripts/game/game.gd`) совместно с `scripts/flight/` (не в моих владениях).
