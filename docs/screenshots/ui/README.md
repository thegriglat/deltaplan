## Найденные и исправленные по ходу баги (в своих файлах)
- `scripts/ui/settings_panel.gd`: пресеты `configs/audio.json → vario_audio.presets` хранят имя в
  ключе `title`, код читал `name` — в списке был виден сырой ключ (`classic_90s`) вместо
  «Классический, 1990-е». Исправлено.

## Баг вне своих файлов (не чинил — не мои владения)
- `scripts/flight/landing_flare.gd:88` кладёт своё `flight_time_s` (модельное `m.time_s`) в
  результат посадки **до** `info.merge(stats.summary(...))` в `scripts/game/game.gd:411,443`.
  `Dictionary.merge` без `overwrite=true` оставляет чужое (заниженное после `reset_in_air`
  посреди полёта) время. Т. к. `FlightStats` — теперь источник истины для итога, фикс:
  `info.merge(stats.summary(...), true)` в обеих строках `game.gd` (411, 443). Контракт
  зафиксирован тестом `tests/game/test_flight_stats.gd::test_summary_must_overwrite_stray_flight_time_from_landing_flare`.
