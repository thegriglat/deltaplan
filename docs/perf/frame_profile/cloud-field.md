# Цена GPU облаков: поле облачности против main (CLF-7)

Справочный замер по решению пользователя (17.10.2026): порога нет, шейдеры и настройки по результату не правились.

## Как мерили
- Стенд: RTX 4070 SUPER, 1920×1080, без VSync, пресеты medium и high, `tools/bench/frame_profile.sh` под замком GPU, `SKIP_FLY=1`.
- Сильный день: `--hour=12 --temp=30 --wind=3`, мир переведён на +5400 с (13:30) новым флагом бенча `--world-t=5400`; бенч ждёт, пока поле облачности догонит время (на ветке поле: покрытие ср. 0,167, основание 3375 м MSL). Старт в воздухе (`--air-start`: 1000 м от старта, 300 м над рельефом) — иначе автопилот на ветке разбивался на взлёте во время пересчёта поля.
- Отметки: 2, 30, 60 с полёта, камера chase; на каждой base и base2 (6 замеров на ячейку), в таблице медиана. Проход облаков — «Process Post Transparent Compositor Effects». Опыт noclouds — кадр с скрытыми слоями облаков.
- main — отдельная копия `main` (23f835e7) со скопированным `frame_profile.gd`; ветка — cloud-field/CLF-7 (feature/cloud-field + бенч).

## Границы и оговорки
- Сравниваются разные модели облаков: на main — боксы кучевых, на ветке — слой поля (один отрезок луча, пропуск пустых блоков). Покрытие поля на main не измерено (поля нет); картинки в кадре различаются, равного числа облаков в обзоре нет.
- Одна локация, один час, одно семя, шесть замеров на ячейку; разброс медиан не оценивался. Алматы не мерили.
- Ранний замер CLF-5 (0,49 мс, покрытие 0,02) заменяется этим; его же оценка «+1,2…1,7 мс к кадру слоя против без слоя» (в кадрах Онгудая) относится к другому сравнению (слой вкл/выкл), здесь noclouds даёт +0,5 мс (medium) и +0,9 мс (high) на ветке.
- Камера chase за пилотом смотрит вперёд-вниз с 300 м над рельефом; доля неба с облаками в кадре могла быть невелика.
