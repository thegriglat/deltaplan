# Настройки рендера: project.godot, пресеты, ресурсы

Часть профиля кадра PF-1; вход и сводка — [frame_profile.md](../frame_profile.md).

## Настройки рендера (project.godot, пресеты, ресурсы)

- `project.godot → rendering`: Forward+, атлас направленных теней 4096, мягкие тени quality 3
  (high), MSAA 2× (окно — по пресету), debanding вкл., `import_etc2_astc=true` (мобильные форматы
  при импорте — лишняя работа на десктопе). SSAO выкл. во всех пресетах (`world.json → effects`),
  SSIL, SDFGI, SSR, объёмный туман и туман Godot — не включаются (проверено на живом Environment).
  Окклюзии нет (рельеф строится на лету — запекать нечего).
- Пресеты (`configs/game.json → graphics_presets`): различаются травой (0/100/150 %), облаками
  (quality low/medium/high, max_clouds 90/160/220), радиусом деревьев 250/400/500 м и тенями
  деревьев (low без), дальностью теней 1200/2000/3000 м, окном (low: 0,75 FSR, без MSAA). Самый
  дорогой параметр — `clouds.quality` (буфер облаков 0,33/0,5/0,75 и max_iterations 64/128/200), а
  low дешевле medium по облакам в 5–9 раз по GPU.
- Тени солнца: 4 каскада, деления 0,05/0,2/0,5, `shadow_blur` 1,5; проход теней 0,2–0,8 мс, вся
  цена теней с выборкой — 0,74 мс (medium без облаков); 4096 → 1024 даёт лишь 0,27 мс.
- LOD и видимость: деревья — свои LOD (MultiMesh на вариант и LOD, `lod_distances_m` 60/180,
  импостеры до 3,5 км), кусты/камни — MultiMesh с LOD, объекты OSM и лагерь —
  `visibility_range`. Вызовов отрисовки 300–900 — нормально. Трава — один MultiMesh на ~105 тыс.
  пучков × 6 травинок × 3 сегмента (радиус 34 м, шаг 0,21 м), редение вдали — в шейдере (вершины
  всё равно обрабатываются).
- Импорт текстур: все 3D-текстуры, кроме двух (`grass_ambientcg_grass004.jpg`,
  `rock_ambientcg_rock030.jpg`), без VRAM-сжатия; **без мипмапов** — `scree_ambientcg_gravel022.jpg`,
  `rock_ambientcg_rock030_normal.jpg` (рельеф читает их `textureGrad` с анизотропией — на дальнем
  рельефе мерцание и промахи кэша), все 96 карт паруса (`assets/shaders/sail/*`, 1024², RGB без
  потерь → 4 МБ VRAM каждая, на бот-крыльях вдали — мерцание).
- Варианты шейдеров: `shader_baker/enabled=true` во всех пресетах экспорта — хорошо; compute-облака
  собираются из исходника при каждом запуске (кеш SPIR-V убран, b26234d), 159 мс на первом кадре.
- Прозрачность: деревья и импостеры — alpha scissor (непрозрачный конвейер с discard, есть в
  depth prepass), дымка и провода — blend без записи глубины; проход прозрачных 0,1 мс.

### Шейдер рельефа (`scripts/terrain/terrain.gdshader`, 58 КБ)

Цена рельефа — 1,6 мс на medium (28 % кадра без облаков; depth prepass + opaque). Чтений текстур
на пиксель вблизи — до ~20, все за ветвлениями по дистанции/весу: трава 2 + крупный слой 2 + нормали
2 (`textureGrad`, два сдвига против повторения), скала — триплан 2–3 + нормали 2, осыпь 1–2,
макрошум 2–3 (`textureLod`), рельеф/тени рельефа 2, маска леса 2, тень облаков 1, поле ветра 1,
снег 1, лес 1. Свой `light()` (на каждый источник). Тяжёлых циклов по шуму нет; ветвей много
(регистры → заполнение на RDNA1 ниже). Отдельный выигрыш: включить мипмапы двум текстурам
(выше); переписывать шейдер ради 1,6 мс не стоит — облака и трава важнее.

### Почему assets/shaders весит 23 МБ

Это не шейдеры: `assets/shaders/sail/` — 48 крыльев × 2 карты паруса 1024×1024 (`tools/blender/
sail_maps.py`): `_normal.png` (25 штук по 0,8–1 МБ — мелкий рисунок ткани не жмётся PNG, остальные
по ~50 КБ) и `_trans.png` (~25 КБ). Импорт — без потерь, без мипмапов. В кадре — карты своего
крыла и крыльев ботов. VRAM-сжатие (BC5/RGTC для нормалей, BC4 для просвечивания) и мипмапы:
4 МБ → 1–1,3 МБ VRAM на карту, меньше пакет экспорта; GPU-выигрыш мал.
