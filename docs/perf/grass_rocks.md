# Цена травы и камней: замеры grass-rocks

Протокол — контракт G3 (`docs/contracts/grass-rocks.md`): GPU окна, мс, без облаков (`--keep=nocloudfx`),
ongudai, отметки старт@2 (кабина), лес@30, облака@60 (сзади); трава = base − nograss, камни и кусты = base − noscatter.
Разделы — по задачам (`## <ID>`), база — `## GR-2`.

## GR-2. База: цена травы и камней до правок

Замер по G3 на `feature/grass-rocks` (b1d71a11), RTX 4070 SUPER, 1920x1080 (окно 1918x1036), ongudai, без облаков
(`--keep=nocloudfx`), GPU окна в мс. Трава = base − nograss, камни и кусты = base − noscatter, шум = |base2 − base|.
Отметки: 2 с — кабина (старт), 30 с и 60 с — вид сзади. Пресеты medium и high (тени 2000 и 3000 м, остальное по `_env` в jsonl).

Команда (под замком GPU, в копии GR-2):
`dpcli job --lock gpu start GR-2-perf 3600 env SKIP_FLY=1 TAG_SUFFIX=_noclouds tools/bench/frame_profile.sh build/perf/GR-2 "medium high" ongudai --sample=2 --keep=nocloudfx --exps=base,nograss,noscatter,base2`.
Повтор (шум на отметке > 0,1 мс): то же в `build/perf/GR-2b` (профили Godot скопированы из GR-2, кэш тайлов тёплый).
Таблицы отчётов — `python3 tools/bench/frame_profile_report.py build/perf/<прогон>` (в архиве `report.md`).

Ход замера, как есть:
- Прогон 1: high@2 упал при холодной загрузке (SIGABRT, exit 134 при первом запуске high; загрузка места ~93 с); повтор только этой отметки
  в том же каталоге GR-2 (тёплый кэш) прошёл. Промежуточная попытка в пустом профиле (GR-2-hi2) — «не долетели до FLYING» (холодная загрузка ~100 с съела лимит 6000 кадров),
  в данные не вошла.
- Прогон 2 (GR-2b) — полный, без сбоев.

### Выводы и границы

- Автопилот долетел до всех трёх отметок на обоих пресетах, обоих прогонах.
- Цена травы стабильна между прогонами: ≈ 0,75–0,85 мс (medium) и ≈ 1,15–1,2 мс (high) на отметках 2 и 30; на отметке 60 равна нулю
  (в кадре нет травы: примитивов base = nograss) — среднее по трём отметкам занижено, цена травы «где она есть» — 0,8–1,2 мс, 15–20 % кадра без облаков.
  Трава — ≈ 1,1–2,2 млн примитивов из 3,8–4,9 млн.
- Камни и кусты: 0,0–0,2 мс (среднее −0,01…0,13), на уровне шума измерения (~0,1 мс); как отдельную статью оценить нельзя, ожидаемый выигрыш от их правок мал.
  Примитивы для noscatter контрактом не требуются; в jsonl есть.
- Шум: > 0,1 мс на отметке 2 с в обоих прогонах — high@2 в прогоне 1 (0,12), medium@2 (0,11; 0,30). В прогоне 2 medium@2 шум 0,30 мс: на 2 с число
  облачных экземпляров (60 против 72) и сцена ещё не устоялись. Отметка medium@2 по G3 негодна (шум не вошёл в 0,1 мс ни в одном прогоне), её значения
  травы (0,73–0,77) и камней (−0,23…−0,10) — ориентир; остальные пять отметок годны (в прогоне 2 — все, кроме medium@2).
  Для сравнения «до/после» брать отметки 30 и 2 (high) как основные.
- Допущения: GPU окна — метки движка (`--gpu-profile`), без облаков; пауза на отметке, облака выключены, трава/камни убираются переключением рендера
  (nograss/noscatter), т.е. цена включает только GPU-часть, CPU не входит. Одна машина, один раз в день, дрейф тактов GPU не учтён.
- Данные: `docs/perf/data/grass_rocks_GR-2.tar.gz` (jsonl обоих прогонов и report.md; без xdg_* и логов).

## GR-4

Камни: выпуклые многогранники вместо икосфер + трипланарная нормаль в `rock_scatter.gdshader`. Протокол G3, RTX 4070 SUPER,
без облаков, ongudai. Данные — `docs/perf/data/grass_rocks_GR-4.tar.gz` (run1, run2: jsonl + report.md).
Два прогона, потому что часть отметок в каждом не долетела до FLYING (сбой запуска, не камней): run1 — нет medium@2, run2 — нет high@2 и high@30.

Среднее «камни и кусты»: high −0,07 (run1) / −0,15 (run2, одна отметка); medium −0,17 (run1, 2 отметки) / −0,05 (run2).
Сравнение: база GR-2 в ветке ещё не появилась — сравнивать с `docs/perf/frame_profile/measurements.md`: камни и кусты 0,37 / 0,29 мс
(high / medium, там же −0,23 среднее). После: в среднем ≈ 0,05–0,17 мс, то есть цена не выросла и, вероятно, упала на 0,1–0,2 мс
(прогоны шумят на 0,1 мс; три выборки трипланарной нормали вместо одной цены не добавили — кусты и камни на этих кадрах
в основном не в кадре). Вывод: регрессии нет, выигрыш на пределе шума.
