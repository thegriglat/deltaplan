# Цена травы и камней: замеры grass-rocks

Протокол — контракт G3 (`docs/contracts/grass-rocks.md`): GPU окна, мс, без облаков (`--keep=nocloudfx`),
ongudai, отметки старт@2 (кабина), лес@30, облака@60 (сзади); трава = base − nograss, камни и кусты = base − noscatter.
Разделы — по задачам (`## <ID>`), база — `## GR-2`.

## GR-4

Камни: выпуклые многогранники вместо икосфер + трипланарная нормаль в `rock_scatter.gdshader`. Протокол G3, RTX 4070 SUPER,
без облаков, ongudai. Данные — `docs/perf/data/grass_rocks_GR-4.tar.gz` (run1, run2: jsonl + report.md).
Два прогона, потому что часть отметок в каждом не долетела до FLYING (сбой запуска, не камней): run1 — нет medium@2, run2 — нет high@2 и high@30.
Δ GPU окна, мс (отрицательное = цена):

| пресет | отметка | прогон | трава | камни+кусты | шум | примитивов, тыс. (base) |
|---|---|---|---|---|---|---|
| high | cockpit@2 | run1 | −1,09 | −0,00 | 0,15 (> 0,1) | 4831 |
| high | chase@30 | run1 | −1,24 | −0,09 | 0,04 | 4915 |
| high | chase@60 | run1 / run2 | +0,03 / 0,00 | −0,13 / −0,15 | 0,04 / 0,02 | 2811 / 2809 |
| medium | cockpit@2 | run2 | −0,79 | +0,02 | 0,00 | 3696 |
| medium | chase@30 | run1 / run2 | −0,99 / −0,82 | −0,19 / −0,03 | 0,06 / 0,04 | 3837 |
| medium | chase@60 | run1 / run2 | +0,07 / −0,04 | −0,15 / −0,15 | 0,10 / 0,04 | 2340 / 2338 |

Среднее «камни и кусты»: high −0,07 (run1) / −0,15 (run2, одна отметка); medium −0,17 (run1, 2 отметки) / −0,05 (run2).
Сравнение: база GR-2 в ветке ещё не появилась — сравнивать с `docs/perf/frame_profile/measurements.md`: камни и кусты 0,37 / 0,29 мс
(high / medium, там же −0,23 среднее). После: в среднем ≈ 0,05–0,17 мс, то есть цена не выросла и, вероятно, упала на 0,1–0,2 мс
(прогоны шумят на 0,1 мс; три выборки трипланарной нормали вместо одной цены не добавили — кусты и камни на этих кадрах
в основном не в кадре). Вывод: регрессии нет, выигрыш на пределе шума.
