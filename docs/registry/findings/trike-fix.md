# Выводы: trike-fix

- Причина «тележка вправо при крыле вперёд», «сквозь крыло», «трапеция впереди подкоса» — вид, не физика: `cart_basis` ограничен 20 °/с, в виражах отставание 55–72°, в накачке по крену 143°; рыскания тележки к крылу в физике нет (`yaw_rel` 0); после правки отставание вида ≤ 0,06° во всех 11 сценариях — [coupling.md](/docs/research/trike-fix/coupling.md#1-вывод), [after.md](/tools/research/trike-fix/after.md).
- Реальный узел подвеса — шарнир тангажа и крена (Gratton, Brunel; AAIB G-CEVW), рыскание общее с крылом; пределы крена тележки к крылу и трение узла в источниках не найдены — [coupling.md](/docs/research/trike-fix/coupling.md#2-реальный-узел-подвеса-по-источникам).
- Бывший режим `weight_shift` кинематический (ход задаёт скорость крена, без массы тележки и предела рук); не возвращён, решение пользователя Q1 — [control.md](/docs/research/trike-fix/control.md#5-бывший-упрощённый-режим-weight_shift-удалён-в-574dfab6a).
- По крену дельталёт не туже, а резче дельтаплана: 30°→30° за 2,0–2,1 с при любом газе (`sport` 2,7 с; по Gratton у трайков 2,5–5 с); туго по тангажу «на себя» — 6 °/с на газу 0–0,5 и 15 на полном против 32 у `sport` из-за хода штанги 0,111 м, не предела рук — [control.md](/docs/research/trike-fix/control.md#2-результаты).
- Ошибка знака z в `CART_CM_MODEL` (ЦМ тележки за подвеской по `cart.py`) повернула вид тележки на 8,75°; с поправкой `bar_deg` при вводе 0 = −4,65° (TT-8 −4,68°), касание подкоса при ≈ 55 км/ч (прежняя мин. скорость на газу 0) — [strut.md](/docs/research/trike-fix/strut.md#3-причина-знак-z-у-цм-тележки).
- Положение штанги у подкоса на триме и на упоре у реальных трайков числами не найдено; «касание на прежней мин. скорости» — решение пользователя Q3, не данные — [strut.md](/docs/research/trike-fix/strut.md#1-что-у-реальных-трайков-источники-без-выдумок).
- Упор подкоса в физике: −10,87° угла мачты, жёсткость 200 000 Н·м/рад и демпфирование 5000 Н·м·с/рад — оценки; `bar_deg` ≤ 5,04°; полный «от себя» на газу 0 — 55,1 км/ч; фугоида k = 0,41 (порог 0,65) — [trike-pilot.md](/docs/guide/flight/trike-pilot.md#скорости-и-качание).
- Ход «на себя» игрока 0,178 м (Q4 б): штанга касается груди (−10,29°, предел TT-К6 −8,39° превышен сознательно); тангаж «на себя» 7,5 / 8,0 / 12,3 °/с на газу 0 / 0,5 / 1 — [trike-pilot.md](/docs/guide/flight/trike-pilot.md#скорости-и-качание).
- Спираль на полном газу в модели возвращается к горизонту (−4° через 10 с из 20°), у реальных трайков на большой мощности неустойчива — граница модели — [control.md](/docs/research/trike-fix/control.md#3-реальность).
- Трава от винта — «несложно»: струя идеального диска 36,6 м/с при 2070 Н, ядро 7,6 м, затухание и ширина — оценка по литературе; цена в шуме (−0,03 мс при ±0,1); на крыло струя не действует — [grass-wash.md](/docs/research/trike-fix/grass-wash.md), [trike-pilot.md](/docs/guide/flight/trike-pilot.md#камера-и-вид).
