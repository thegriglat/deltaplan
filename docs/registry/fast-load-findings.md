# Выводы: быстрая загрузка места

- **Попадание кеша поля**: до полёта Онгудай 29,2 → 12,5 с (−57 %), точка 40,2 → 18,0 с (−55 %); наибольшее замирание экрана 5934 → 1031 и 11660 → 1472 мс; этап wind (15 с) исчезает — [final.md](/tools/research/load_profile/final.md)
- **Промах**: Онгудай 29,2 → 29,9 с (в шуме), точка 40,2 → 27,4 с; расчёт поля ~15 с остаётся — [final.md](/tools/research/load_profile/final.md)
- **Размер записи**: 6,5 МБ в float16 давал разные источники термиков (3074 против 3072), без потерь (float32) ≈ 17 МБ на Онгудай, термики бит-в-бит — [FL-К1](/docs/contracts/fast-load.md)
- **Малый пул потоков**: Онгудай при попадании 12,5 с (20 потоков) → 18,1 (4) → 24,2 (2), замирание 1,0 → 2,8 → 6,0 с; зависаний нет после `PoolFor` — [final.md#Пул потоков](/tools/research/load_profile/final.md)
- **Полосы `AirThermals.build`**: авто против 1 полосы на попадании в шуме (12,5 против 12,2 с); дальше 4 потоков не масштабируется (spin-lock `ObjectDB`) — [final.md](/tools/research/load_profile/final.md)
- **Ошибка вырубки**: маска считала 293 275 домов против 18 149 расставленных; площадь на точке 140,2 → 106,2 км² — [guide](/docs/guide/fast-load.md)
- **Деревья и пирамида высот**: этап trees Онгудая 3,4 → 1,3 с (одна сборка сцены на породу); кеш текстуры высот не нужен (10–30 мс) — [guide](/docs/guide/fast-load.md)
- **Вложенные группы пула**: `wait_for_group_task_completion` из рабочего потока в Godot 4.7 вешает загрузку при пуле 2 (и на `main`); решение — `PoolFor.run` — [guide](/docs/guide/fast-load.md)
