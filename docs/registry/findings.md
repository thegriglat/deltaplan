## air-phase

- **Порог U/N — граница итераций Пикара, не фаза**: без нагрева решение не сходится при N > N_c(U), N_c = 0,0087 / 0,0113 / 0,0142 1/с при U_sat 3 / 4,5 / 6 м/с (∝ U^0,70, U/N_c = 344–422 м); ω = 0,5 поднимает N_c в 1,4 раза (исправляет 15 из 17, не портит ничего). Такие случаи помечать «не сошлось при ω = 1», не «нестационарно» — [air_phase_results.md](/docs/research/air_phase_results.md#3-ap-13-порог-un--свойство-итераций-пикара-ap_v3)
- **Штиль Fr ≲ 0,25**: Пикар стационарного решения не находит — при Fr 0,3–0,5 ω = 0,5 исправляет 36 из 93 несошедшихся; при Fr ≤ 0,25 (U10 ≤ 0,5 м/с) не помогают ω = 0,5, ω = 0,3, K_min, относительный критерий, блуждание 0,39–0,63 U_sat; при Fr 0,1–0,2 не сошёлся ни один из 81. Поле фазы H — статистика (воспроизводимо до ~0,1 U), подветренную зону из него не брать — [air_phase_results.md](/docs/research/air_phase_results.md#4-ap-9-штилевая-граница-несходимости-relax)
- **Границы фаз резкие, гистерезиса нет**: на идеальном рельефе (81 линия) застой, обход, обратное течение, ротор, густота источников термиков — w 0,01–0,04 декады при Fr ≈ 0,85–1,1; торможение, снос, ΔU, подветренная зона, потолок термиков — 0,1–0,25 (Fr_c ≈ 1,5 ⇔ −z_i/L ≈ 35); гистерезис — 4 пары из 501, все объяснены; тёплый старт даёт то же решение в 97 % пар при Fr ≥ 0,8 — [air_phase_results.md](/docs/research/air_phase_results.md#5-ap-8-границы-фаз-резкость-гистерезис-второй-старт-grid-и-sweep-пересчёт-ap-14)
- **Срыв за бровкой** (для `lee`): угол линии тени 9,9° (хребет 7,3°, занижен: слой смешения растёт в 2–4 раза медленнее турбулентного, S = 0,030 против 0,06–0,11), rotor_reverse 0,65, rotor_height_fraction 0,59, shear_layer 408 м, danger_sink_per_wind 0,04 (в игре 0,7); порог обратного течения по крутизне 0,20–0,30, порога по Fr нет. Огибающая 12° лечит несходимость на крутых местах (75 % nonconv_m), поле над склоном не улучшает — [air_phase_results.md](/docs/research/air_phase_results.md#6-ap-10-срыв-за-бровкой-и-огибающая-separation-envelope)

## surface-heat

Ясно, ψ = 63°: луг 209, лес 289, скала 305, застройка 317, снег 22 Вт/м² (у луга было 275). Один H для решателя и термиков — [surface-heat.md](/docs/archive/plan/surface-heat.md#1-физика-и-границы-модели-зафиксировано-координатором), [game-radiation.md](/docs/research/surface_params/game-radiation.md#9-использование-в-игре-surface-heat)

Следствие литературы, не ошибка; пересматривать по облёту — [surface-heat.md](/docs/archive/plan/surface-heat.md#1-физика-и-границы-модели-зафиксировано-координатором)
- **Озёра днём не греют**: H воды = ρc_p·C_H·U·(T_воды − T_воздуха), C_H = 1,4·10⁻³, U ≥ 1 м/с, T_воды = max(0, T̄ воздуха за 30 сут); над Аушкулем p10 = −31,5 Вт/м²; T_воды ≤ 0 — лёд. Горные реки получают ту же T_воды — граница — [game-moisture-water.md](/docs/research/surface_params/game-moisture-water.md#95-вода)
- **До/после на трёх местах** (15 июля, ясно, 3 м/с; 9/12/15 ч): средний H в полдень −10…−16 %, в 9 ч −27…−30 %; число источников ±0–8 %, w0 −1…−13 %, потолок −1…−10 %, подъём на склоне ±6 %; сдвига больше чем вдвое нигде нет — [air-model.md](/docs/guide/air-model.md#до-и-после-замер-toolsresearchsurface_heat-15-июля-ясно-t_max-26-c-ветер-меню-3-мс-поле-400-м-круг-10-км)
- **z0 по клетке без перестройки схемы**: лог-среднее по долям классов (Алтай 0,216 м, Онгудай 0,201 м против 0,1); U на 30 м над лесом ×0,95, над лугом ×1,03–1,05. Смещение нуля d над лесом и масштаб 3 по столбцу не делали — [surface-heat.md](/docs/archive/plan/surface-heat.md#3-z0-по-покрову--решение-координатора)
- **Вне модели нагрева**: влажность почвы только по рельефу (дождей нет), α не зависит от угла Солнца, L\* константа, облачные ярусы не различаются, адвекция, суточный ход T_воды, глубина озера, холодные реки, лёд — [air-model.md](/docs/guide/air-model.md#чего-не-умеет)
