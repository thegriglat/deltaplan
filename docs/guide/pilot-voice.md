# Голос пилота

Пилот иногда говорит короткие реплики: радуется термику, ругается на провал, ойкает на сваливании, замечает пасхалки. Контракты — `docs/contracts/pilot-voice.md` (PV-К1…К4), тексты и пороги — `configs/pilot_voice.json`. Здесь — как это устроено и где граница.

## Принцип

Пилот говорит то, что почувствовал бы сам, **по данным, которые есть у игрока**: отфильтрованный вариометр (то, что пищит и показывает прибор), воздушная скорость, перегрузка, крен, высота над землёй, касание, облако вокруг, события задачи. Скрытые данные поля ветра (где термик, его сила впереди) входами **не** являются.

## Устройство

- `PilotVoiceLogic` (`scripts/audio/pilot_voice_logic.gd`, `RefCounted`, без нод) — решает, какую реплику сказать: `update(dt, s)` возвращает id реплики (`sink_2`) или пустую строку; `event(name, data)` — события (`took_off`, `landed`, `turnpoint`, `goal`, `egg_seen`).
- `PilotVoice` (`scripts/audio/pilot_voice.gd`, `Node`) — плеер на шине `Voice`, выбор голоса и языка, загрузка файла, `watch_eggs` для пасхалок.
- `Game` (`scripts/game/game.gd`, поиск `pilot_voice`) — подаёт телеметрию, вариометр прибора и облако, события взлёта, посадки и задачи; сбрасывает логику при новом полёте.
- Пороги берутся только из `params` в конфиге, не из кода.

## Ситуации

Приоритет: 3 — срочное, 2 — событие, 1 — фон. Условия и числа — PV-К1; реплики — `configs/pilot_voice.json`.

| id | Когда | Пр. |
|---|---|---|
| `takeoff` | отрыв (через 1 с, раз за полёт) | 2 |
| `thermal_found` | вариометр держится ≥ 1,0 м/с 3 с после 20 с тишины | 1 |
| `thermal_strong` | вариометр ≥ 3,0 м/с 4 с | 1 |
| `thermal_lost` | после 30 с подъёма — снижение ≤ −1,0 м/с 5 с | 1 |
| `sink` | ≤ −3,0 м/с 3 с, не сваливание, не пикирование (V ≤ 15 м/с) | 1 |
| `turbulence` | не меньше 3 выбросов перегрузки за 8 с, высота > 10 м | 1 |
| `stall` | сваливание 0,5 с, высота > 5 м | 3 |
| `fast` | V ≥ 22 м/с (≈ 80 км/ч) 3 с | 1 |
| `low` | высота < 80 м при снижении; повтор после набора ≥ 200 м | 1 |
| `high` | набор высоты от точки отрыва кратен 300 м, впервые за полёт | 1 |
| `view` | высота ≥ 150 м, спокойный вариометр (|v| < 1) 60 с без реплик | 1 |
| `cloud` | облако вокруг ≥ 0,6 за 1 с | 2 |
| `turnpoint`, `goal` | точка маршрута взята, гол | 2 |
| `landing_soft`, `landing_hard`, `crash` | касание по оценке посадки (через 0,6–0,8 с, раз за полёт); `hard` и `crash` — срочные | 2 / 3 |

Реплика звучит не всегда: у каждой ситуации есть вероятность `chance` (0,3…1,0) и своя пауза `cooldown_s`. Не выпал шанс — ситуация всё равно уходит на паузу, как если бы пилот сказал.

## Очередь

- Одна реплика за раз. После конца реплики следующая — не раньше `gap_s`: 20 с для фона, 5 с для событий, 2 с для срочных.
- Срочная (3) прерывает звучащую фоновую (1).
- Ситуации по данным полёта (условие держится) в занятый момент не ставятся в очередь и **не тратят** паузу: проверяются на каждом шаге и скажутся, когда станет можно, если условие ещё держится.
- События (отрыв, посадка, точка, гол, пасхалка) ждут в очереди не дольше `max_wait_s` 8 с; не дождались — отбрасываются, паузу не тратят.
- Фон молчит первые 8 с после отрыва (`quiet_after_takeoff_s`).
- Вариант реплики случайный и не повторяет последний сказанный.

## Пасхалки

Пилот замечает пасхалку (событие `egg_seen`), когда её видимая точка (`EasterEgg.voice_anchor`, у машин, стад, шаров, гусей и кругов на поле переопределена) непрерывно 1,5 с лежит в конусе взгляда камеры 30° (полуугол), ближе `max_dist_m` и не закрыта рельефом (16 точек отрезка камера → точка против `Terrain.height_at`). Проверка не чаще 4 Гц. Ситуация `egg_<id>`: приоритет 1, раз за полёт на каждую, пауза 300 с. Есть реплики на Ан-2, лайнер, глорию, шар и фестиваль шаров, УАЗик, людей у лагеря, стадо, чужую группу, орла, круги на поле, рулоны сена и гусей; дальности и шансы — в PV-К1. Без реплик: `probe`, `bar_charm`, `start_dog`.

## Где молчит

Голос «выкл»; скорость времени не ×1; пауза; сетевая игра (v1 — только одиночная); буксир; режим «Осмотреться»; дельталёт (v1 — только дельтаплан); фон меню. Если файла реплики нет, реплика молча пропускается без ошибки в логе.

## Файлы голосов

- Путь: `assets/sounds/voice/<male|female>/<ru|en>/<id>_<k>.ogg`, `k` — номер реплики в `lines` (с 1). Язык — по локали игры: начинается с `ru` — русский, иначе английский.
- Формат: Ogg Vorbis, моно, 44 100 Гц, около −20 LUFS, пик ≤ −3 dBFS, тишина по краям ≤ 80 мс.
- Голос **синтетический**: модель Qwen3-TTS-12Hz-1.7B-VoiceDesign (Apache-2.0), голос задан текстовым описанием, не копия реального человека. Выбор модели — `docs/research/pilot-voice-tts.md`.
- Перегенерация — `tools/sounds/voice/README.md`: локальное окружение (`~/data/pilot-voice`, torch для CUDA 12.4, `ffmpeg` с libvorbis), `gen_voice.py` читает тексты и тон из `configs/pilot_voice.json`, подгоняет громкость замером ffmpeg. Запись о лицензии — `assets/sounds/LICENSES.md`, `ASSETS.md`.

## Шина и настройка

- Шина `Voice` (Master ← Voice) — в `scenes/audio/bus_layout.tres`; громкость конфига — `volume_db` (по умолчанию 0).
- Настройки → «Звук» → «Голос пилота»: мужской / женский / выкл (`pilot_voice.json → voice`, по умолчанию мужской). Применяется сразу; пишется патчем `UserSettings.save_patch("pilot_voice", {"voice": …})`. Неизвестное значение трактуется как «выкл».

## Чего не умеет (честно)

- Тон реплик (`tone` в конфиге) подсказка синтезатору; он не гарантирует окраску, стоны и кряхтение (`landing_hard`, `crash`) читаются словами.
- Часть реплик не проверена на слух.
- Пилот не знает про ветер и термик, которых прибор не показал (вход — отфильтрованный вариометр).
- Реплики редкие и случайные: повторить сцену с теми же репликами нельзя.
- Сетевая игра, дельталёт и буксир — без голоса.
