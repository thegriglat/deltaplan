# Таблица поляры

`godot --headless --path . res://tests/flight/polar_table.tscn` — прогон модели в спокойном воздухе
(плотность уровня моря) при разных положениях трапеции, для мин./эталонной/макс. массы пилота; печатает все 48 крыльев,
здесь — три опорных (1.5.15). «срыв» — трапеция за сваливанием, крыло парашютирует (значения усреднены по циклам срыва).
Положение трапеции: +1 — «от себя» до упора (ниже сваливания), 0 — трим, −1 — «на себя» до упора.
