# Меню, настройки, «Об игре»

Часть описания сборки игры (вход — [game.md](../game.md)). Код: `scripts/ui/*.gd`, `scenes/ui/*.tscn`, `scripts/game/user_settings.gd`, `graphics_presets.gd`, `favorites.gd`, `recent_places.gd`; тексты — `locale/ui.csv`.

## Главное меню

`StartMenu` (`scripts/ui/start_menu.gd`): логотип (`configs/ui.json → menu_logo`), цитата, версия, строка про отправленный отчёт о вылете (`docs/guide/crash-report.md`), колонка кнопок в центре (прокручивается колесом, если не влезает в экран): «Лететь», «Осмотр карты» (`launch.md`), под ней — строка текущего выбора (`StartMenu.summary_text`), «Полёт…», «Сетевая игра», «Управление», «Настройки», «Об игре», «Выход», переключатель языка. Слева — список «Избранное». Фон меню и экрана загрузки — кадры игры `assets/ui/backdrops/*.webp` (список — `ui.json → backdrops`, смена — `BackdropSlideshow`).

Вход в полёт — один: «Лететь». «Полёт…» (`FlightSetupScreen`) — только выбор: «Готово» сохраняет его в `user://last_flight.json` и возвращает в меню, «Назад» — без изменений. Экран — две вкладки:

- **Место**: прогноз (температура днём, ветер на старте, откуда ветер — встречный старту или румб, облачность), время старта (из `world.json → time.start_hours`) и дата, ряд выбора места `PlacePickRow` (общий с экраном сети): «Выбрать на карте» (`MapPicker`, «Выбрать эту точку»), «Популярные места…», подпись выбора и «Старт уточнён на рельефе · курс N°» (точный старт, `launch.md`); внизу — «Недавние места» (`RecentPlaces`, `user://recent_places.json`: переименовать, закрепить, удалить).
- **Аппарат**: класс крыла → модель (`WingCatalog`), сведения о крыле (площадь, качество, предел ветра), масса пилота (50–120 кг), параметры аппарата (`resolved_apparatus`; для режима «Маятник» часть параметров только для него).

«Популярные места…» — окно `PopularPlacesWindow` (`scripts/ui/popular_places_window.gd`, данные — `PopularPlaces`, контракт PP-К1, `docs/contracts/popular-places.md`): страны → места страны с высотой и ветром старта, поиск по названию; выбор места = точка старта по координатам, как с карты; название идёт в «Недавние места». Каталог — `configs/ui.json → popular_places_path` = `data/places/hg_takeoffs.json` (696 стартов дельтаплана из OpenStreetMap в 24 странах); файла нет — кнопка скрыта. Десять мест каталога — встроенные места игры (Алтай, Онгудай, Аскарово, Аушкуль; `tools/places/add_builtin_places.py`) с полями `location`/`site`: выбор такого места грузит встроенное место и его точный старт (разбег по `heading_deg`), а не поиск склона у точки.

«В избранное» (внизу «Полёт…», QL-12) — текущие условия (`FlightSettings.to_dict()`) в `user://favorites.json` (`Favorites`): не больше 8 (`MAX_ITEMS`), девятое вытесняет самое старое, одинаковые не дублируются. В главном меню слева — список «Избранное» с автоназванием («Онгудай, 13:00, 3 м/с СЗ, Sport»): щелчок — сразу `fly_requested` с этими условиями, × — удалить. Тест — `tests/ui/test_favorites.gd`.

«Сетевая игра» — `NetScreen` (`network.md`).

## Настройки пилота

Экран «Настройки» (из меню и паузы, `SettingsPanel`) — пять вкладок:

- **Игра**: язык, имя пилота (пусто — ник Steam, затем по языку), модель ветра («расчёт по рельефу» / «эвристика»: `atmosphere.json → air_model.enabled`), скорость времени (×1, ×10, ×60, стоп; в зоне скрыта), число других пилотов в небе 0…20 (`bots.count`, со следующего полёта), имена над ботами, подписи вершин, индикатор смещения пилота, часы (внизу справа и на запястье), компас на запястье.
- **Графика**: пресет (low/medium/high), масштаб рендера (FSR), густота травы, дымка к солнцу, поле зрения (45–100°), камера в кабине (`eye_mode`), каска, окно и кадры (ниже).
- **Управление**: чувствительность мыши, инверсия тангажа (по умолчанию выкл), режим крена (простой / смещение веса / маятник), направление крена (трапеция / тело), раздел «Трапеция / джойстик» (`ControlBarSettings`: устройство, оси, инверсии, мёртвая зона, экспонента, калибровка).
- **Звук**: громкость вариометра (дБ) и пресет звука.
- **Платформа движения**: вывод в симулятор движения (`MotionRig`, `docs/guide/motion-rig.md`).

Настройки пишутся патчем в `user://configs/<конфиг>.json` (`UserSettings.save_patch`), в файле только изменённые ключи. `Config` складывает конфиги слоями, каждый следующий поверх предыдущего: `res://configs` → `configs/` рядом с исполняемым файлом (только в сборке) → `user://configs` (в Steam Cloud) → `user://local/configs` (машинные настройки, в облако не идут). Машинные ключи перечислены в `UserSettings.LOCAL_KEYS` (графика, окно, облака и воздух, деревья, солнце, эффекты, трава, платформа движения, калибровка геймпада) и дублируются в `steam/partner/auto_cloud.json`.

**Окно и кадры (QL-13).** В настройках графики: VSync (по умолчанию вкл), предел кадров 30/60/120/144/без предела (по умолчанию 144), режим окна (оконный/полноэкранный), разрешение окна (список — что помещается в монитор; «Как есть» — не менять), «Масштаб рендера» (FSR) — рядом. Хранится в `game.json → display` как машинная настройка. Применяет `GraphicsPresets.apply_display`: `Engine.max_fps`, VSync, режим и размер окна; при запуске (из `apply_viewport`) и сразу при сохранении настроек. Аргументы Godot `--resolution`/`--fullscreen`/`--windowed` (и `-f`, `-w`) перекрывают режим и размер на этот запуск (VSync и предел кадров применяются всегда). Без VSync и без предела GPU грузится на 100 % — предел кадров для этого и нужен.

### Как добавить настройку

1. Параметр уже есть в каком-то `configs/<имя>.json` (NFR-7).
2. В `scripts/ui/settings_panel.gd`: элемент в `_ready()`/`_build…` (`UiKit.slider_row` / `UiKit.row`) на нужной вкладке, чтение в `load_values()`, запись в `save()` через `UserSettings.save_patch("<имя>", {…}, config_dir)`.
3. Если значение закешировано в ноде — применить в `Game.apply_user_settings()`.
4. Машинная настройка (зависит от железа) — добавить ключ в `UserSettings.LOCAL_KEYS` и в `steam/partner/auto_cloud.json` (тест S7 сверяет списки).
5. Строку подписи — в `locale/ui.csv` (ключ snake_case, колонки ru и en).

### Как добавить экран

1. `scripts/ui/<экран>.gd` (`extends Control`, `class_name`), вёрстка в `_ready()` через `UiKit`, наружу — только сигналы (`closed`, `…_requested`).
2. `scenes/ui/<экран>.tscn` — корень Control на весь экран, `theme = theme.tres`, скрипт.
3. Инстанс в `scenes/main.tscn` под `UI`, подключение сигналов в `main.gd → _connect_ui()`, показ через `_open_overlay(экран, откуда)` (Esc вернёт назад).
4. Тексты — через `tr()`, ключи и переводы — `locale/ui.csv`.

## «Об игре» (FR-27a)

Текст собирается при открытии: таблицы из `ASSETS.md` (`AssetsCredits.parse_tables`: заголовки `##` и таблицы `| … |`, колонки «Что», «Источник», «Лицензия») + тексты лицензий (`configs/ui.json → license_files`). Эти файлы кладутся в сборку: `export_presets.cfg → include_filter`.

## Фоны меню

Фоны главного меню и экрана загрузки снимает `tools/shots/menu_art.py` пачкой по сюжетам `tools/shots/menu_art.json` (черновики 1920×1080; выбранные — `--size=3840x2160 --only=NN,…`, потом 2560×1440 WebP). Один кадр: `tools/shots/menu_background.sh [--size=3840x2160|2560x1440] [--out=файл.jpg]`; параметры кадра — `tools/shots/menu_background.json` (флаги игры, часы неба, момент симуляции, камера от планера, пресет `high` без FSR, прогрев). Окно — виртуальный дисплей xvfb нужного размера (Vulkan на видеокарте), профиль временный; ~1 мин. После замены файлов перезапустить импорт (`godot --headless --import`).
