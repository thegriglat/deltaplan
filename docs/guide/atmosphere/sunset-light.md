# Яркость заката и экспозиция (HH4 v3)

Ручных таблиц `time.light.sun_energy` и `sky_energy` нет. Всё считается по высоте солнца `el` (истинной, SunClock):

| Что | Формула | Где |
|---|---|---|
| Свет рельефа | `light_energy = sun.energy · T_G(el, долина) / T_G(35°, долина)`; цвет — отношения каналов `sun_tint`, нормированные на G; T = 0 — 0 | `SkyEnvironment._apply_sun`, `SunTransmission.light_ratio` |
| Небо, окружение, дымка, облака | одна `sky_k(el)` — рассеянная освещённость безоблачного неба относительно 35° (таблица узлов `clouds.sun_transmission.sky_k`) | `SunTransmission.sky_k` |
| Цвет | `horizon_tint` — только горизонт, низ окружения, дымка; зенит и `ambient_top` облаков синие, не подкрашены | `SkyEnvironment`, `CloudLayer._update_light` |
| Экспозиция | `E = clamp((L(35°)/L(el))^a, 1, E_max)`, `L = light_energy·max(sin el, 0)·ρ + sky_k`; множитель к `tonemap_exposure`, сглаживается (`tau_s`) | `rendering.sunset_exposure` |

Параметры экспозиции: ρ = 0,2 (отражательная способность рельефа), a = 0,8 (доля компенсации), E_max = 10 (3,3 ступени).
Закат физически темнее дня на 3 ступени (L(2°) = 0,14); экспозиция возвращает 2,3 из них, сцена остаётся темнее дня, но не чёрная.
Диск, корона, ореол неба и ореол дымки к солнцу заданы яркостью на кадре (уже сжаты `sun_disk.energy_exponent` до отображаемого
диапазона) и делятся на E — экспозиция заката их не раздувает; засвет глаза (`SunGlare`) от E не зависит.

Таблица `sky_k` и вывод — [tools/research/haze_humidity/sky_light/README.md](../../../tools/research/haze_humidity/sky_light/README.md).

## Границы модели
- `sky_k` — однократное рассеяние в той же атмосфере (Рэлей + мутный слой 60 км, 2 км); многократное, озон, отражение земли не учтены. Сверка с ESRA: ±3 % при ≥ 6°, ESRA выше на 9–49 % при 0–4°. Таблица не зависит от дымки дня (ослабление ×2 — `sky_k(2°)` в 1,8 раза меньше).
- Сумерки (солнце ниже 0°) не моделируются: `sky_k` ниже 0° равна значению при 0°, свет рельефа там 0.
- `a`, `E_max`, ρ — оценки по опыту (фото закатов: разница экспозиции дня и заката 3–5 ступеней, зрение адаптируется частично), не измерение; полная адаптация сделала бы закат днём.
- Яркость неба на экране после E: у 2° небо ≈ 0,76 дневного, рельеф ≈ 0,2 — небо относительно рельефа ярче, чем днём (экспозиция выбрана по сцене с весом неба 1).
- Засвет глаза: ядро `C/θ²` (Хоулдей–Стайлс, `sun_glare.veil_c_deg2`); C = 1,08 — по фото телефона (пятно ≈ 3 диаметра); по глазу (белая поверхность на солнце) C ≈ 49. Экспозиция в засвет не входит (иначе ореол вырос бы в 2–3 раза).
- Диск не перекрашивается после тонмаппинга: он светлее окружения по каждому каналу (источник), но тусклее красного `sun_tint` — цвет солнца в диске ближе к жёлто-белому, красный цвет несёт ореол.
