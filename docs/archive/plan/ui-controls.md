# План модуля «ui-controls» — раскладка тангажа «как у дельтапланериста»

Внутренний документ. Журнал — `docs/archive/plan/ui-controls-progress.md`, контракты — `docs/contracts/ui-controls.md`. Ветка `feature/ui-controls`, копия `~/deltaplan-ui-controls` (от `main` 938d1ea).

## Цель
По умолчанию в полёте вперёд/вверх = трапеция **от себя** (нос вверх, торможение): W, ↑, мышь от себя (в режиме `bar`), стик вперёд. Назад/вниз = **на себя** (нос вниз, разгон). Это раскладка дельтапланериста, не самолёта.

## Решения пользователя (не обсуждаются)
- 01.10 — по умолчанию в полёте **W = трапеция от себя**, **S = на себя**; то же для ↑/↓ и для стика/мыши по умолчанию («вперёд/вверх = от себя», мышь вперёд = от себя), без инверсии «как в самолёте» по умолчанию. Настройка инверсии остаётся, но по умолчанию — дельтапланерная.

## Что было на v1.0.0 (938d1ea)
- `configs/controls.json → keys`: `pitch_pull_in` = [W, Up] (на себя), `pitch_push_out` = [S, Down] (от себя). `InputController._update_air`: `pitch_dir = −(pull_in − push_out)·inv` → W даёт `ControlInput.pitch` −1.
- Мышь (`bar`): `pitch = −offset.y` — мышь от себя (курсор вверх) = от себя. **Уже дельтапланерно.**
- Стик (`_apply_gamepad`): `pitch = gy·inv`, ось 1 вперёд < 0 → стик вперёд = на себя. **Как в самолёте — менять.**
- На земле: W/S — шаг (`walk_forward`/`walk_back`), ↑/↓ — нос вверх/вниз (`nose_up`/`nose_down`). Не меняется.
- `configs/ui.json → controls_help`: раздел «На земле» показывает клавиши шага через действия `pitch_pull_in`/`pitch_push_out` — после перестановки показал бы S/↓ для «идти». Привязать к `walk_forward`/`walk_back`.
- Подсказка инверсии `settings_invert_pitch_hint` («W — от себя, S — на себя») описывала инверсию; теперь инверсия = «как в самолёте».

## Разбор кода (ветка модуля от main ce5ea58)
- Мышь в режиме `bar` (`controls.json → mouse.mode`, **по умолчанию**; пункт настроек «Мышь: Обзор / Трапеция») ведёт трапецию по **обеим осям** (тангаж и крен), пока мышь захвачена (`InputController.mouse_captured`, клавиша M; захват при старте — `mouse.capture_on_start`). Клавиши при этом суммируются с мышью (`_update_bar`: `_key_pitch + m_pitch`) — WASD и стрелки дублируют мышь.
