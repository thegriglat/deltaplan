# 04. Проверка конфигов: `_doc` и единицы измерения (NFR-7)

**Цель:** каждое числовое значение во всех `configs/*.json` документировано (`_doc`-поле или комментарий-ключ рядом) с единицей измерения.

**Контекст:** REQUIREMENTS.md (NFR-7), configs/*.json (13 файлов), docs/guide/architecture.md.
**Папки-владения:** только чтение и точечная правка `_doc`-ключей внутри `configs/*.json` (без смены самих значений/структуры — это владение других групп). Найденные пропуски по числам без `_doc` — либо сама правка (если тривиально: добавить строку), либо список владельцам групп.

## Шаги
1. Скрипт (`tools/bench/` или временный, в отчёте) проходит по всем `configs/*.json`, ищет числовые листья без соседнего `_doc`/units-поля.
2. Составить список пропусков по файлам с указанием группы-владельца (см. таблицу README «Владения»).
3. Добавить `_doc` с единицей измерения там, где это не требует знания физики (переименования, очевидные единицы — м, с, м/с, °); неочевидные — список владельцу.
4. Свериться, что описание в docs/ соответствующего модуля упоминает единицы для ключевых параметров.

## Критерий приёмки
- Скрипт проверки печатает 0 числовых значений без `_doc`/единиц в файлах, тронутых этой карточкой, или список с владельцами передан (приложен к отчёту).
- Ни одно значение параметров не изменено — только добавлены документирующие поля.
- `tools/check.sh --no-build` зелёный после правок (валидный JSON).

**Зависимости:** независима, можно вести сейчас. **Модель:** sonnet. **Размер:** S.
