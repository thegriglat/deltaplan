# Группа 5 «Растительность» — карточки

Файлы растительности пока остаются в `scripts/terrain/` (перенос в `scripts/vegetation/` не нужен для основы — владение по списку файлов).
Настройки — `configs/vegetation.json` (создаёт V01), документ — `docs/guide/vegetation.md` (создаёт V01). Замеры — стенд T01 группы рельефа.

| # | Карточка | Модель | Размер | Волна |
|---|---|---|---|---|
| V01 | [Свой конфиг и травинки вблизи](01-nastrojki-travinki.md) | sonnet | M | 0 (‖ T01) |
| V02 | [Деревья по кромке 10 м, тон с высоты](02-derevya-po-maske-dalnij-ton.md) | opus | M | 2 (‖ T03, T04), после T02 |

- Волны порывов по траве (рекомендация 2) — в `terrain/05` (это `TerrainWind`, владелец — группа 4); трава получает их через include.
- Не вошло (при необходимости — следующей карточкой после V02): вариации деревьев (2–3 сида, импостеры 8 ракурсов, `tools/blender/build_trees.py`).
- Подключение в игре (`set_landing_sites` из `WorldObjects.get_landing_sites`, `set_pilot`) — группа «Сцена игры».
