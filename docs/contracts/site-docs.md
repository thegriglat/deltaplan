# Контракты модуля site-docs

## SD-К1. Страница сайта под main (v1)

Владелец — координатор; исполнители — задачи SD-2…SD-10; потребитель — сборка сайта (Hugo, `site/hugo.toml`).

**Файлы.** Страница — пара `<база>.ru.md` + `<база>.en.md` (или `<база>/index.ru.md` + `index.en.md` у бандла
с картинками). Frontmatter — ключи как у соседних страниц раздела (`title`, `weight`, `description`; одинаковый набор
в паре, SI-К2). `description` — что на странице сейчас, без упоминаний удалённого.

**Пара ru/en.** Одинаковые разделы (заголовки `##` — то же число и порядок), те же числа, таблицы, картинки, ссылки;
en — перевод ru, не пересказ. Ссылки — внутренние пути сайта (`/mechanics/…/`, `/docs/guide/…`), только на существующие
страницы; новые страницы других задач — не ссылаться (ссылки дорисует SD-10).

**Факты.** Каждое утверждение о поведении игры — по коду (`scripts/`, `rust/`) и `configs/` ветки, отведённой от main;
числа — из конфигов/кода/замеров в `docs/research`, с тем же округлением. `docs/guide` — подсказка, где искать;
расходится с кодом — верен код, расхождение — в `uncertain` отчёта. Не нашлось в коде — не писать.

**Запрещено (решение 2026-11-02).** Ни в каком виде («было», «убрали», «раньше», «рассматривали и вернулись»):
нейросеть ветра (ONNX, air-synth), расчёт ветра/Пикара на видеокарте (GPU-ветер; GPU для отрисовки — можно), режимы
крена игрока «Смещение веса»/weight_shift и «Простое»/rate, настройки, которых нет в меню main. Прямые команды крена
у ботов (`FlightModel`) — есть в main, писать можно.

**Дельталёт.** Пункты, которые меняет модуль `trike-fix` (вид тележки и её поворот в вираже, упор переднего подкоса и
ход штанги «на себя», трава от винта, тяжесть управления на газу), — в текст не включать ни в старом, ни в ожидаемом
виде; перечислить в отчёте (`uncertain`: «trike-fix: <пункт> — не описан»).

**Публичные тексты.** Родители — только «родители автора — пилоты», иначе «пилот»; без продающего тона, раздел «Границы
модели» — честно, где симулятор врёт; пасхалки упоминать можно.

**Не трогать.** `site/content/releases/**`, `site/content/wings/**` (кроме SD-9), `site/hugo.toml`, `site/layouts/**`,
`docs/**` (кроме SD-1), код игры, `configs/`.

**Контрактный тест** (проверки карточек; `<базы>` — базы страниц задачи через запятую, `<файлы>` — её md):
1. `python3 tools/site/check_i18n.py --pages=<базы>` → exit 0 (пары, сборка hugo без WARN/ERROR, живые ссылки, en без кириллицы).
2. Запрещённые слова: `! grep -niE 'onnx|air[-_]synth|нейросет|нейронн|neural|weight[_ -]?shift|смещени[а-я]* веса|Пикар[а-я]* на (GPU|видеокарт)|ветер[а-я]* на (GPU|видеокарт)|расч[её]т[а-я]* на GPU|GPU-ветер|Picard[a-z ]* on (the )?GPU|wind on (the )?GPU|GPU wind' <файлы>` → exit 0.
3. Пары: у каждой пары число строк `^## ` в ru и en равно → exit 0.
