## SWD3 v4 — вихревые нити 3D (пакет `filaments3d`)
v4 (2026-11-08, решение пользователя: ограничитель — только если дёшев): обязательны `t_birth`, огрубление по возрасту
(а) и потолок `n_max` (в); слияние (б) и `method="tree"` — необязательны: не сделано — `NotImplementedError` при
включении, их тесты пропускаются (`pytest.skip` с причиной); имена параметров — как v3.
v3 (2026-11-08, Q1 — вариант C): ограничитель роста и быстрое суммирование; всё v2 без изменений поведения при
значениях по умолчанию.
- v3. `Filaments.t_birth` (K) — время схода отрезка, с (наследуется при дроблении/слиянии/перезамыкании — минимум);
  `shed(..., t=0.0)` — новый необязательный последний параметр.
- v3. `coarsen(f, t, params)` → `Filaments`: огрубление старых нитей — (а) по возрасту: l_max отрезка =
  max(`l_max`, `l_age`·(t − t_birth)) (`l_age`, м/с; None — выкл.), дробление/слияние с сохранением замкнутости;
  (б) слияние соседних почти параллельных отрезков одного направления (cos > `amal_cos`, 0,9) с расстоянием между
  серединами < `r_amal` (по умолчанию 2·core): один отрезок, Γ = сумма, положение — среднее по |Γ|, core =
  max(core₁, core₂, расстояние/2) — с перестройкой связей так, что Kirchhoff сохраняется (правило — README со
  ссылкой; пары, где сохранить нельзя, пропускаются со счётчиком); (в) `n_max` — потолок узлов: при превышении
  (а) и (б) повторяются для самых старых нитей с удвоенными `l_age`, `r_amal`, пока узлов ≤ `n_max` или нечего
  сливать (счётчик). `params` — `l_age`, `r_amal`, `amal_cos`, `n_max` (None — выкл.). Счётчики — `f.stats`.
- v3. `induced(f, x, y, z, backend="auto", method="direct", theta=0.5)` и `self_velocity(f, method="direct",
  theta=0.5)`: `method="tree"` — дерево (Барнс — Хат, мультиполь ≥ дипольного по отрезкам) с параметром раскрытия
  `theta`; "direct" — v2.
- Инварианты v3 (тесты): после `coarsen` imbalance ≤ 1e-12; импульс I ± 2 %; скорость на расстоянии ≥ 5·r_amal от
  огрублённых нитей ± 5 % к до-огрубления; модельный сход (линия 110 точек, U = 10 м/с, нить на каждом шаге dt = 3 с,
  500 шагов, снос со скоростью U, удаление за x > 6 км) с `l_age`/`r_amal`/`n_max` по умолчанию README — узлов
  ≤ 3·10⁴ и рост за последние 100 шагов < 10 %; `tree` против `direct` — отн. ошибка ≤ 1e-3 (θ = 0,5) на 2·10⁴
  узлов, ускорение ≥ 10× на 10⁵ узлов (GPU или CPU — в README).
v2 (2026-11-08, отчёт SWD-3): скорость кольца Розенхеда — Мура — ln(8R/δ) − 1 (подтверждено сходимостью по n);
`shed`: `u_s` — векторы (M, 3); при разной Γ соседних отрезков — «ножки» длиной core по −n к якорным узлам.
Владелец — SWD-3; потребители — SWD-4, SWD-6. Без рельефа: стенку даёт вызывающий (скорость `flow` и `ground`).
Пакет `tools/research/sw_charges_3d/filaments3d/` (NumPy; CuPy — `backend`).
- `Filaments` — узлы `x` (M, 3) м, отрезки `seg` (K, 2) int (от a к b), `gamma` (K) м²/с (завихренность — вдоль a→b,
  правило правой руки), `core` (K) м, `anchored` (M) bool — узел на земле, `fid` (K) — номер нити. Пустой набор допустим.
- Замкнутость (∇·ω = 0): в каждом неякорном узле Σ Γ входящих = Σ Γ исходящих; линия — петля или кончается якорными
  узлами на земле. `imbalance(f)` → max |дисбаланс| по неякорным узлам (м²/с).
- `induced(f, x, y, z, backend="auto")` → `(u, v, w)` — Био — Савар с регуляризацией Розенхеда — Мура (δ = core
  отрезка); `self_velocity(f)` → (M, 3) — в узлах, той же регуляризацией.
- `ring(R, gamma, core, n, center=(0, 0, 0), normal=(0, 0, 1))`, `line(points, gamma, core, anchored_ends=True)` —
  конструкторы.
- `shed(f, line_pts, u_s, dt, core, normals)` → новый `Filaments`: нить по `line_pts` (M, 3), `u_s` (M, 3) — скорость слоя
  в точках, Γ отрезка = ½·|ū_s|²·dt (ū_s — среднее в концах); разная Γ соседних отрезков — из общего узла ножка длиной core
  по −n в якорный узел (Kirchhoff), завихренность — по n × û_t (n — нормаль земли `normals` (M, 3), û_t —
  направление скорости слоя), концы — якорные узлы на земле (нить замкнута стенкой).
- `step(f, flow, dt, ground, params)` → `Filaments`: `flow(x, y, z)` — скорость без самоиндукции нитей (фон + панели
  от вызывающего); узлы движутся со скоростью flow + `induced` (RK2), растяжение — от движения узлов (Γ отрезка
  постоянна); якорные узлы — проекция на `ground(x, y)` с касательной скоростью; затем по `params`: дробление
  отрезков длиннее `l_max` (по умолчанию 2·core) и слияние короче `l_min` (0,5·core) с сохранением замкнутости;
  перезамыкание встречных отрезков ближе `r_rec` (по умолчанию core, косинус направлений < −0,5) — обмен связями
  (Γ и замкнутость сохраняются, правило — в README со ссылкой); рост ядра core² += 4·`nu_t`·dt; затухание
  Γ·exp(−dt/`tau_s`) (`tau_s=None` — нет); неякорный узел под землёй — поднимается на ground + core/2 (счёт в
  `f.stats`), нить удаляется целиком, если под землёй > 50 % её узлов, если |Γ| < `gamma_min` или она вся за `bounds`.
  `params` — dict с ключами `l_max`, `l_min`, `r_rec`, `nu_t`, `tau_s`, `gamma_min`, `bounds` (xmin, xmax, ymin,
  ymax, zmax); нет ключа — значение по умолчанию.
- Инварианты (тесты пакета): кольцо R, Γ, δ ≪ R — скорость Γ/(4πR)·(ln(8R/δ) − 1) ± 3 % (Розенхед — Мур, предел
  по n; v1 ошибочно −½) и форма сохраняется 100 шагов; `imbalance` ≤ 1e-12 после `step`, дробления, слияния, перезамыкания;
  импульс I = ½·Σ Γ·(x_mid × Δl) — сохранение без затухания ± 1 % за 100 шагов кольца;
  перезамыкание двух встречных колец — две петли превращаются в одну (или наоборот), замкнутость сохранена;
  прямая бесконечная (длинная) нить у плоской стенки с изображением через `flow` — скорость Γ/(4πh) ± 2 %.
