## SWD6 v6 — установившийся вихревой слой (пакет `sheet3d`)
v6 (2026-11-08, ответ Q3, вариант B): замыкание постоянным давлением в зоне (свободная линия тока, Roshko 1955) —
`build_sheet(..., params={"closure": "roshko", "cpb": <C_pb>})`: давление в зоне постоянно, C_pb — одно значение из
литературы для отрывных зон за хребтами/уступами (ссылка и значение — README; без подгонки по месту); на внешней
стороне слоя скорость u_b = U_ref·√(1 − C_pb), внутри — покой ⇒ γ = u_b вдоль всего слоя; форма слоя — линия тока
(нормальная скорость на слое = 0) итерациями от точки отрыва Хеда; замыкание зоны — слой доходит до земли
(присоединение) или, если не доходит за `L_max`, — замыкание Рябушинского (зеркальная пластина/изображение — README)
с пометкой `closure_kind`. `Sheet.reattach` — точка присоединения; `info` — `L_b`, `closure_kind`, `cpb`.
Инварианты v6 (тесты): Agnesi H/L 0,5 + `bg_uniform` — итерации сходятся, есть присоединение, обратный u∥ на 10 м за
гребнем, L_b/H — числом; ровная земля/гаусс 0,1 — без слоя (как v1); `closure="free"` — поведение v5 (регрессия).
v5 (2026-11-08, решение пользователя о варианте B): `fold_sheet` / `velocity_fold` сняты — нить ротора делается
геометрическим замыканием (SWD7, пакет `rotor3d`); слой (A) — без изменений v4.
v4 (2026-11-08, ответ Q2: A, затем B): делается слой из рядов (`build_sheet`, `velocity_sheet` — v1 ниже) с точкой
отрыва Хеда (`separation3d`, restart, lee_only), γ = |u_s| там, форма — по линиям тока до присоединения, без Kutta;
ряды — замкнутые петли с возвратом под землёй (отражение панелями открытой подковы даёт ~20 % ошибки — SWD-9);
затем при удаче — свёртка в одну нить: `fold_sheet(sheet)` → Filaments: Γ = Σ Γ рядов (по линии), положение —
центр завихренности слоя, ось — вдоль линии отрыва; `velocity_fold(...)` = `velocity_jh(..., extra=induced(свёртка),
couple=True)`; сравнение свёртки со слоем — u∥ на 10 м за гребнем и L зоны ± 15 % (числами в отчёте, не порог).
Точка отрыва снаружи (угол/уклон) — не делать (Q2: C — нет).
v3 (2026-11-08, отчёт и ревью SWD-9): замыкание «равновесие Фёппля + нулевая касательная скорость в точке отрыва на
гребне» корня не имеет (2D аналитически: вдоль кривой Фёппля скорость в вершине > 0, ноль — только при уходе вихря
на бесконечность; 3D подтверждает); на Agnesi H/L 0,5 корня с s > 0 нет и для точки Хеда. Это результат, не дефект:
`converged=False`, нить не ставится. `params["sep_point"]` — заданная точка отрыва (x, y) или угол на полуцилиндре
(для 2D-теста, θ = 60° от оси по ветру: s, h, Γ в −3…−5 % от 2D); инварианты v2 про Agnesi и отрыв в вершине
заменены этим отрицательным результатом. Выбор другого замыкания — шлюз Q2.
v2 (2026-11-08, решение пользователя: первым — простейший вариант): одна установившаяся нить ротора (Фёппль) —
`foppl_vortex`, `velocity_foppl` (ниже, задача SWD-8); слой из рядов (`build_sheet`, `velocity_sheet`, v1) — следующий
шаг, только если нити Фёппля мало (отдельное решение).
- v2. `foppl_vortex(panels, bg, z0, infl=None, params=None)` → `(fil, sigma, info)`: по каждому гребню (`hill_length`
  на линиях тока поперёк области; гребни соседних линий, совпадающие в пределах 2·ds_min, — один хребет) — одна прямая
  нить вдоль оси хребта (МНК по точкам гребня) за гребнем, длина — протяжённость гребня по линиям тока, концы —
  ножки в землю подковой (якоря; ∇·ω = 0); отражение в земле — панелями (σ с extra = нить). Неизвестные на хребет —
  положение (s за гребнем вдоль ветра, h над землёй) в середине нити и Γ; уравнения: скорость в середине нити
  (bg + панели + ножки и прочие нити, без самоиндукции прямого участка) в плоскости поперёк оси = 0 (2 уравнения,
  равновесие Фёппля) и условие отрыва на гребне — касательная скорость у земли в точке гребня на середине нити = 0
  (аналог условия Кутты; точка отрыва — гребень по решению пользователя; `params["sep"]="separation3d"` — точка
  отрыва Хеда, вторично). Решение — Ньютон/`scipy.optimize.root` с начальным h = H/2, s = H, Γ = U_ref·H;
  `params`: `core` (ds_min/2), `sep` ("crest"), `tol` (1e-3 отн.). `fil` — Filaments (SWD3); `info` — по хребтам
  {`x_c`, `y_c`, `axis`, `L_axis`, `s`, `h`, `Gamma`, `converged`, `residual`, `iters`} и `t_s`. Нет решения —
  `converged=False`, нить не ставится (счётчик), без подгонки.
- v2. `velocity_foppl(panels, sigma, bg, fil, x, y, z, z0, U_ref=None, infl=None)` → (u, v, w) =
  `velocity_jh(..., extra=induced(fil), couple=True)`.
- Инварианты v2 (тесты): ровная земля и гаусс H/L 0,1 без хребта — нитей нет, поле = `velocity_jh` побитно;
  imbalance ≤ 1e-12; 2D-предел — круговой цилиндр (полуцилиндр на стенке, длинный, R) с отрывом в вершине: положение
  и Γ середины нити — в ± 10 % от 2D-решения равновесия вихря за полуцилиндром на стенке с тем же условием (посчитать
  в тесте panels2d или аналитикой Фёппля с изображением; README); длинный хребет Agnesi H/L 0,5: решение сходится,
  обратный u∥ на 10 м за гребнем, s/H, h/H, Γ/(U·H) — в отчёте; цена ≤ 20 решений панелей того же N.
Владелец — SWD-8; потребители — SWD-5d. Решение пользователя 2026-11-08: вариант без эволюции во времени — лист
вихрей вдоль линии отрыва и границы зоны рециркуляции, сила — из критерия отрыва, цена порядка панелей.
Схема — модель свободной линии тока / слоя смешения (Kirchhoff — Helmholtz; замыкание зоны — по типу Riabouchinsky /
Roshko): слой дискретизирован поперечными (вдоль линии отрыва) нитями `filaments3d` с шагом Δs вниз по слою,
Γ ряда = γ·Δs, γ = |u_s| в точке отрыва (скачок скорости через слой; согласовано со сходом SWD3: dΓ/dt = ½u_s² при
переносе слоя со скоростью u_s/2); концы рядов — якоря на земле (замкнутость, ∇·ω = 0).
Пакет `tools/research/sw_charges_3d/sheet3d/` (NumPy/CuPy; панели — SWD2, нити — SWD3, только вызывать).
- `Sheet` — {`filaments` (SWD3), `rows` (список: номер линии отрыва, s вдоль слоя, Γ ряда), `reattach` (список
  {x, y, z} | null по линиям), `iters`, `residual` (макс. сдвиг узлов последней итерации, м), `stats`}.
- `build_sheet(panels, bg, z0, infl=None, params=None)` → `(sheet, sigma, info)`: (1) σ для bg и
  `separation3d(restart=True, lee_only=True)` (SWD2 v4); (2) по каждой polyline `lines` — слой: ряды через Δs
  (`ds_sheet`, по умолчанию 2·ds_min) вдоль направления внешней скорости в точке отрыва на высоте `h0` (по умолчанию
  ds_min/2), ядро `core` (по умолчанию ds_min/2); (3) итерации до `n_iter` (10): σ ← solve(bg, extra = induced слоя),
  узлы слоя ← линии тока полной скорости (bg + панели + слой без самоиндукции ряда) от точки отрыва, шаг Δs;
  ряд, ушедший к земле ближе `core`, — присоединение: слой заканчивается (замыкание зоны); длина не больше `L_max`
  (10·H гребня по `hill_length`); релаксация `relax` (0,5); стоп — `residual` < 0,05·Δs. `info` — {`t_s`, `iters`,
  `residual`, `N`, `n_nodes`}. `params` — dict ключей выше и `gamma_decay` (None — γ постоянна вдоль слоя; число —
  γ(s) = γ0·exp(−s/`gamma_decay`), спадание при росте слоя смешения — в README со ссылкой).
- `velocity_sheet(panels, sigma, bg, sheet, x, y, z, z0, U_ref=None, infl=None)` → (u, v, w) =
  `velocity_jh(..., extra=induced слоя, couple=True)`.
- Инварианты (тесты): ровная земля / гаусс H/L 0,1 — отрыва нет, слоя нет, поле = `velocity_jh` без extra побитно;
  imbalance ≤ 1e-12; длинный хребет Agnesi H/L 0,5 + `bg_profile` — слой за гребнем, итерации сходятся (residual
  < 0,05·Δs не больше чем за `n_iter`), обратный u∥ у земли (10 м) за гребнем есть, длина зоны L_b/H — в README и
  отчёте (ориентир 2D-хребтов: L_b/H ~ 5–10 — литература в README); цена `build_sheet` ≤ 10 решений панелей того же
  N (замер в отчёте); двойной хребет (два Agnesi через 3L) — слой за первым и за вторым гребнем.
