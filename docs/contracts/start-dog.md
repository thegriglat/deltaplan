# Контракты модуля start-dog

Пасхалка `start_dog` живёт в каркасе пасхалок (К1–К7, `docs/contracts/easter-eggs/framework.md`) и в зоне старта
SC-K1 (`docs/contracts/start-camp.md`). Всё, что ниже не сказано, — как там: только картинка и звук, без тел и
столкновений, случайное — только из `rng`, тест К7 зелёный.

## DOG-K1 v2 — что пасхалка видит: бегущие, старт лагеря, препятствия
Владелец — DOG-2. Потребитель — `start_dog.gd`. Только чтение, ни одна пасхалка в это не пишет.

- `EggContext.runners: Array[Dictionary]` — пилоты на земле и в воздухе, планировщик заполняет каждый `update()`:
  игрок первым (`id = 0`, `game.glider.get_telemetry()`), затем боты (`id ≥ 1`, `game.bots.agents`, их телеметрия).
  Поля: `id: int`, `pos: Vector3` (крыло, мир, м — `Telemetry.position`), `vel: Vector3` (путевая, м/с —
  `Telemetry.velocity`), `phase: String` (`Telemetry.phase`: `standing|walking|running|flying|landed|failed`),
  `heading_deg: float` (0 — север, по часовой). Нет игры (тест) — `[]`, тест подставляет свой список.
- `WorldObjects.camp_start: Dictionary` — старт, у которого стоит лагерь: `{position: Vector3, heading_deg: float}`,
  пишет `place_camp(start, heading_deg, …)`; лагеря нет — `{}`.
- `EggPlace.camp_start() -> Dictionary` — копия `WorldObjects.camp_start` (`{}` — нет).
- `EggPlace.obstacles_near(c: Vector2, r: float, kinds: PackedStringArray) -> Array[Vector3]` — прокси на
  `WorldObjects.obstacles.points_near` (только чтение; элемент — `Vector3(x, z, радиус)`: `.x, .y` — центр по мировым X, Z, `.z` — радиус, как в `ObstacleIndex`; уточнено в v2 по коду); нет
  объектов — `[]`. Виды, нужные собаке: `tent`, `gear`, камни/кусты — какие есть в индексе.
- Оси старта — SC-K1: `h = deg_to_rad(heading_deg)`, `fwd = Vector2(sin h, −cos h)`, `right = Vector2(cos h, sin h)`;
  `along = (p − s)·fwd`, `lat = (p − s)·right` (по `x, z`).

## DOG-K2 v1 — модель собаки
Владелец — DOG-1 (или DOG-1b). Потребитель — DOG-2.

- Файл `assets/easter_eggs/start_dog/dog.glb` (+ текстуры рядом). Одна собака средней дворовой породы: высота в
  холке 0,50–0,65 м, длина корпуса 0,8–1,0 м. Метры, Y вверх, морда смотрит в **−Z** (как вперёд в Godot), начало —
  на земле посередине между лапами.
- Сцена glb: `Skeleton3D` + скиновые меши + `AnimationPlayer`. Анимации (имена точно такие, циклы — без
  движения корня по XZ, на месте):
  - обязательные: `gallop` (галоп), `trot` (трусца), `idle` (стоит), `bark` (стоит и лает — цикл с 1–2 «гавками»),
    `lie` (лежит, дышит);
  - желательные: `walk` (шаг), `sniff` (нюхает землю), `sit` (сидит). Нет — поведение заменяет (`sniff` → `idle`
    с опущенной головой или `walk` медленно; `sit` → `lie`).
  - чего нет в готовом паке (часто `bark`, `lie`, `sit`) — дописать ключами в Blender **на скелете самой модели**
    (геометрию не менять, свою модель не делать — решение пользователя 2026-10-17).
- Скорость без проскальзывания: для каждой ходовой анимации (`gallop`, `trot`, `walk`) — `speed_ms` — путевая скорость,
  при которой лапы в опоре не скользят при скорости воспроизведения 1,0 (измерено по смещению стопы в опоре за цикл),
  и `cycle_s`. Числа пишутся в `configs/easter_eggs.json → eggs.start_dog.anims.<имя>.speed_ms` / `cycle_s` (с `_doc`).
- Если в анимации `bark` открывается пасть — кость/ключ пасти есть в модели; тайминг «гавков» в цикле —
  `anims.bark.bark_at_s: [с, …]` (под них звук).
- Бюджет: LOD0 ≤ 5000 треугольников; дальний уровень — автоматические LOD импорта Godot (`meshes/generate_lods`);
  ≤ 2 материала; текстуры ≤ 512×512 (собака на экране мала), в `.import` — VRAM-сжатие и мипмапы.
- Лицензия допускает коммерческое использование (CC0 / CC-BY / MIT своей генерации); строка в `ASSETS.md`
  (источник, автор, лицензия, URL, что меняли).

## DOG-K3 v1 — лай
Владелец — DOG-1. Потребитель — DOG-2.

- `assets/easter_eggs/start_dog/bark_<n>.ogg`, n = 1…2–4: одиночные «гав» (0,15–0,5 с), моно, 44,1 или 48 кГц,
  пик −3 dBFS, без тишины по краям > 30 мс. Лицензия — как у модели (CC0 предпочтительно), строка в `ASSETS.md`.
- Играет `AudioStreamPlayer3D` пасхалки на шине `Ambient` (`audio.json → buses.ambient`); вариант гавка — из `rng`
  собаки (или по счётчику гавков), не из глобального генератора.

## DOG-K4 v1 — пасхалка `start_dog`: появление, поведение, конфиг
Владелец — DOG-2.

**Файлы.** `scripts/world_objects/easter_eggs/start_dog.gd` (`extends EasterEgg`), блок
`configs/easter_eggs.json → eggs.start_dog` (каждое поле с `_doc`), ассеты — DOG-K2, DOG-K3.

**Появление.** `mode: per_flight`, `chance: 1.0`, `lifetime_s: 0`, `window_s` ≈ [0, 1]. `can_appear`: лагерь есть
(`place.camp()` не пуст и `place.camp_start()` не пуст) **и** доля мест-дней: `rng` с сидом
`"start_dog|%d|%d|%d|%d" % [roundi(s.x), roundi(s.z), month, day]` (`s` — `camp_start.position`) → `randf() <
presence_share` (≈ 0,6). То есть детерминированно по месту и дню, не по погоде и не по игроку. Ночью
(`sun_elev_deg < min_sun_deg`) — нет.

**Дом.** Центр лагеря и пятачок вещей (SC-K1); собака бродит в круге `home_radius_m` вокруг центра лагеря, не заходит
в коридор разбега, пока никто не бежит.

**Состояния** (`info().state`):
- `rest` — лежит/сидит (`lie`/`sit`), `wander` — ходит/трусит между точками у палаток и вещей, `sniff` — стоит и нюхает;
  длительности и точки — из `rng` собаки; в покое состояние — функция времени мира и параметров (одно и то же при любом
  шаге кадра), пока не было погони. Без бегущих собака ≈ треть времени в движении (шаг, трусца, пробежки галопом
  по лагерю и к бровке сбоку от коридора) — пожелание пользователя 2026-10-17: при пролёте над лагерем видно, что живая.
- `chase` — бегущий (`phase == "running"`) ближе `notice_m` к собаке: через `react_s` (0,3–0,8 с) срывается галопом;
  цель — точка сбоку от бегущего (`side_m`, сторона — та, где собака) и чуть впереди/позади (`lead_m`); скорость
  ≤ `gallop_max_ms` (≈ 9 м/с), разгон/торможение ≤ `accel_ms2`; лает с интервалом `bark_interval_s`.
  Стоящий или идущий пилот погоню не вызывает (сколько бы ни стоял).
- `edge` — бегущий оторвался (`flying`) или собака у бровки: собака тормозит **до бровки** — не дальше точки, где
  земля впереди уходит вниз круче `brow_slope_deg` или ниже прямой на `brow_drop_m` (проба рельефа на
  `brow_probe_m` вперёд), и не дальше `max_along_m` от линии старта; стоит и лает вслед (`bark`) `edge_bark_s`.
- `return` — трусцой (`trot`) обратно домой, дальше — покой. Разбег сорван (`failed`, `standing` после `running`) —
  короткий лай на месте и `return`.

**Движение.** Высота — `height_at` под собакой (|y − земля| ≤ 0,05 м), тангаж — по разнице высот передних и задних
лап, курс — плавно (≤ `turn_rate_deg_s`). Палатки, вещи, камни — обход по `place.obstacles_near` (только чтение).
Аллюр по скорости с гистерезисом (`walk` < `trot_from_ms` ≤ `trot` < `gallop_from_ms` ≤ `gallop`); скорость
воспроизведения = скорость / `anims.<аллюр>.speed_ms`, ограничена `anim_scale` [мин, макс] — проскальзывание
|scale·speed_ms − v| / v ≤ 10 % при v > 0,5 м/с (если скорость за пределами — меняется аллюр, а не скольжение).

**Звук.** DOG-K3; громкость и затухание — `bark_unit_m`, `bark_max_m`, `bark_volume_db`; на разбеге из кабины слышно.

**Дёшево.** Дальше `visible_m` (≈ 300 м) от камеры — скрыта, `AnimationPlayer` стоит; тень — ближе `shadow_m`.
Узлов под пасхалкой нет, если собаки нет.

**Для тестов.** `info() -> Dictionary`: `state`, `pos: Vector3`, `speed: float`, `anim: String`, `anim_scale: float`,
`barks: int`, `target_id: int` (−1 — никто). Статическая `static func present(start: Vector3, month: int, day: int,
cfg: Dictionary) -> bool` — бросок доли мест-дней.

**Инварианты.** К3/К7 каркаса; собака не выходит за бровку и вперёд дальше `max_along_m`; не реагирует на стоящих;
сеть: появление одинаково у всех (место, день), погоня — местная картинка (по своим `runners`).
