# Контракты пасхалок: К13–К16: модели и звук

Стыки К13–К16. Вход (правила изменения, общие соглашения, список стыков и частей) — [easter-eggs.md](../easter-eggs.md).

## К13. Модель гуся (v8, владелец EE-7; потребитель EE-6 «Клин гусей»)

- Файл `assets/easter_eggs/geese/goose.glb`, генерирует `tools/blender/build_goose.py` (headless
  Blender, как `tools/blender/bird.py`; команда — в шапке скрипта); своя модель, CC0, строка в `ASSETS.md`.
- Оси Godot: **вперёд −Z** (как `assets/models/bird.glb`), Y вверх, X вправо; метры, масштаб 1,
  трансформы применены; **начало координат — центр тела у корня крыльев**.
- Размеры: размах 1,6 м (x от −0,8 до 0,8 ± 5 %), длина клюв–хвост ~0,9 м (по z), крылья раскрыты
  горизонтально (середина взмаха), плоскость крыльев на y ≈ 0.
- **Взмах делает шейдер потребителя** по `abs(VERTEX.x)`: тело — в пределах |x| ≤ 0,12 м, вершины крыла —
  только за |x| > 0,12 м; у каждого крыла ≥ 3 ряда вершин по размаху (корень, локоть, кончик), чтобы крыло
  гнулось.
- Один меш (первый `MeshInstance3D` в сцене), ≤ 150 треугольников, один материал; цвет — цвета вершин
  (серо-бурое тело, тёмные шея и голова, светлее брюхо), без текстур.

Контрактный тест (EE-7) `tests/contracts/test_goose_model_contracts.gd`: glb грузится, AABB по x
1,6 м ± 5 %, по z 0,75–1,05 м, вершины с |x| ≤ 0,12 есть у тела, у крыльев ≥ 3 различных |x| > 0,12,
треугольников ≤ 150. До слияния модели потребитель работает на `assets/models/bird.glb` (подмена — одна строка).

## К14. Звук гусиной стаи (v8, владелец EE-7; потребитель EE-6)

- Файл `assets/sounds/geese/geese_flock_loop.ogg`: гогот летящей стаи, моно, 44,1 или 48 кГц,
  8–20 с, зациклен без щелчка (`loop` в .import), нормализован к пику ≈ −1 dBFS.
- Источник — запись CC0 (предпочтительно) или CC-BY (атрибуция), как остальные звуки: строка в
  `ASSETS.md` (таблица «Звуки») и в `assets/sounds/LICENSES.md`; NC — нельзя.
- Потребитель: `AudioStreamPlayer3D` на шине `Ambient`, громкость по расстоянию (1/r, `unit_size`,
  `max_distance` — в конфиге пасхалки с `_doc`), слышен раньше, чем стая различима (≥ ~1,5 км).

Контрактный тест (EE-7) `tests/contracts/test_geese_sound_contracts.gd`: файл грузится как
`AudioStreamOggVorbis`, длина 8–20 с, `loop == true`.

## К15. Модель брелока-чайки (v10, владелец EE-9; потребитель EE-10)

- Файл `assets/easter_eggs/bar_charm/gull_charm.glb`, генерирует `tools/blender/build_gull_charm.py`
  (headless Blender, как `tools/blender/bird.py`; команда — в шапке); своя модель, CC0, строка в `ASSETS.md`.
- Фигурка чайки с расправленными крыльями (силуэт «Джонатана»: длинные узкие крылья, лёгкий излом),
  размах 6 см (x от −0,03 до 0,03 м ± 10 %), длина клюв–хвост ~4 см; светлая (белое/светло-серое тело,
  чуть темнее концы крыльев, жёлтый клюв) — цвета вершин, без текстур.
- Оси Godot: **вперёд (клюв) −Z**, Y вверх, X вправо; метры, масштаб 1, трансформы применены.
- **Начало координат — точка подвеса — центр спины** (решение пользователя): маленькое колечко на спине над центром масс; фигурка висит горизонтально, «парит» (крылья в стороны, клюв вперёд), не головой вниз; вся
  фигурка ниже начала (max y ≈ 0, ± 3 мм), центр масс — на оси −Y под колечком (висит ровно).
- Один меш (первый `MeshInstance3D`), ≤ 300 треугольников, один материал.
- Шнурок в модель **не входит** — его рисует потребитель (тонкий цилиндр/лента от штанги до начала координат).

Контрактный тест (EE-9) `tests/contracts/test_gull_charm_model_contracts.gd`: glb грузится, размах по x
6 см ± 10 %, max y ≈ 0 (± 3 мм), центр AABB по x и z в пределах 5 мм от оси подвеса, треугольников ≤ 300.
До слияния модели потребитель работает на `assets/easter_eggs/geese/goose.glb` в масштабе 0,04.

## К16. Брелок на трапеции — `bar_charm` (v10, владелец EE-10)

- Всегда на месте (не редкая пасхалка, без настроек игрока): пасхалка `bar_charm` по К3
  (`per_flight`, `chance` 1, `lifetime_s` 0 — до `reset()`); в меню и на загрузке — нет (К1).
- **Только чтение** чужого: глобальный трансформ маркера `BaseBar` / точки хвата (`glider_visual.bar_grip(±1)`,
  `get_marker`) крыла игрока. В узлы крыла/пилота/камеры **ничего не добавлять** (К3) — брелок —
  свой узел под `EasterEggs`, каждый кадр ставит себя по маркеру; порядок кадра — после визуала крыла
  и камеры (`process_priority` выше, чем у `CameraRig`), без отставания на кадр.
- Точка подвеса — **правый угол трапеции** (с точки зрения пилота, +X визуала): у стыка базовой штанги с
  правой боковой стойкой (решение пользователя); шнурок 8–10 см (конфиг, `_doc`).
- Ориентация: чайка «парит» горизонтально под шнурком — крылья в стороны, клюв вперёд по курсу крыла;
  наклон фигурки — по направлению нити (ось −Y модели вдоль нити), рысканье — по курсу крыла (кручение
  шнурка не моделируется).
- Качание — физический затухающий маятник (точечная масса на нерастяжимой нити) от ускорения точки
  подвеса в мире и силы тяжести: крен, перегрузка, болтанка дают отклонение сами; затухание — конфиг;
  подшаги при большом `dt`; CPU, без аллокаций. Не скриптованная анимация.
- Цена: ≤ 0,02 мс CPU/кадр; один меш + шнурок, тени — как у мелких деталей трапеции.

Тест (EE-10) `tests/world_objects/test_egg_bar_charm.gd`: при ускорении точки подвеса вперёд брелок
отклоняется назад (и в бок — в обратную сторону), при постоянной перегрузке n висит вдоль `g − a`,
после рывка амплитуда затухает (огибающая убывает), длина нити постоянна; К7 зелёный.
