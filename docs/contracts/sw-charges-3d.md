# Контракты модуля sw-charges-3d

Владелец всех стыков — координатор модуля; меняет только он (версия +1, потребителям — `task note`).
Интерпретатор — `tools/research/sw_charges_3d/py` (venv numpy, scipy, matplotlib, h5py, cupy, pytest; PYTHONPATH —
`tools/research/sw_charges_3d` и `tools/research/sw_charges`, оттуда `panels2d` — только чтение).
Контрактный тест: `tools/research/sw_charges_3d/py tools/research/sw_charges_3d/contract/check_contract.py --selftest`;
`check_contract.py files <файлы|каталоги>` — файлы SWD1, SWD5 по полю `format`; `check_contract.py api <пакет>` —
публичные имена и сигнатуры SWD2–SWD4 (`panels3d`, `filaments3d`, `sim3d`). Поведение SWD2–SWD4 — тесты пакетов.

Общее:
- Оси: x — на восток, y — на север, z — вверх (м, над уровнем моря); система случая — та же, что у модулей
  `tools/research/cases/askervein.py`, `perdigao.py` (начало — их). Скорость (u, v, w), м/с.
- Ветер: `wind_to` — единичный горизонтальный вектор, куда дует (ex, ey); `wind_from_deg` — метеорологическое
  направление (откуда, ° от севера по часовой). u∥ = (u, v)·wind_to.
- Случаи: `ASK_TU03B` (Askervein, подслучай b1 `tu03b`), `PERD_NE`, `PERD_SW` (Perdigão, b1 `ne`, `sw`); синтетика —
  только в тестах пакетов.
- Типы точек: `upstream`, `windward`, `crest`, `lee`, `valley`.
- Неприменимое — `null`. Запись файлов — во временный файл и переименование.

## SWD4 v4 — связка панелей и нитей (пакет `sim3d`)
v4 (2026-11-08, Q1): `params["coarsen"]` (dict для `filaments3d.coarsen`, None — выкл.) — вызывается после
`filaments3d.step` каждый шаг с t; `params["bs_method"]` ("direct" | "tree", `theta`) — для induced и самоиндукции;
`shed` с t; в `stats` — счётчики огрубления. Инвариант: на хребте Agnesi H/L 0,5 с ограничителем 500 шагов —
рост узлов за последние 100 шагов < 10 %, imbalance ≤ 1e-12.
v3 (2026-11-08, отчёт SWD-4): изображение — замкнутое кольцо у земли против зеркального кольца ± 3 % (у прямой нити
с ножками конечная длина даёт −2h/L — не инвариант); `couple` — эффект нитей на u∥ у земли за гребнем записывается
(замер: 4,5 % на 10 м, > 10 % на 5 м — изображение гасит нить), тест — > 10 % на 5 м и > 3 % на 10 м.
Владелец — SWD-4; потребители — SWD-5, SWD-6. v2 (2026-11-08, итог 2D №9, №11; ревью SWD-3 — устойчивость по dt).
Пакет `tools/research/sw_charges_3d/sim3d/`.
- `Setup(terrain, panels, bg, z0, params)` — `params`: `fil` (dict для `filaments3d.step`), `core` (ядро новых нитей,
  по умолчанию `panels.ds_min`/2), `cfl` (0,25), `couple` (True — `velocity_jh(couple=True)`), `restart` (True),
  `U_ref`; `infl` собирается один раз в `Setup`.
- `run(setup, t_end, dt, t_avg=None, probes=None, sep_every=1, record_every=None)` → {`t`, `filaments` (последнее
  состояние), `stats` (по шагам: t, N нитей, узлов, отрезков, Σ|Γ|, imbalance, max|u| в узлах, подшагов, время шага,
  невязка solve, число точек отрыва и присоединений, счётчики `f.stats`), `probes_mean` / `probes_std` — средние и СКО
  (u, v, w) в `probes` (P, 3) за t ≥ `t_avg` для вариантов "potential" (без нитей), "potential_jh", "vortex_jh"
  (`velocity_jh` с `couple`), `snapshots` (каждые `record_every` шагов — нити)}.
- Шаг: `solve` (extra = `filaments3d.induced`, `infl`) → `separation3d` (restart, streamlines_from="bg") каждые
  `sep_every` шагов → `shed` по `lines` (u_s — вектор `ut` полной скорости в точках линии) → `filaments3d.step` с
  flow = bg + панели (σ этого шага), ground = `panels.height`; подшаги нитей: dt_f ≤ `cfl`·min(core)/max|u в узлах|
  (число подшагов — в `stats`); σ на подшагах — от начала шага.
- `velocity_mean(result, x, y, z, variant)` → (u, v, w) — среднее за t ≥ t_avg по `snapshots` (или из `probes_mean`).
- Инварианты (тесты): ровная земля без отрыва — нитей нет, поле = фон; длинная нить у ровной земли (концы-ножки) —
  скорость изображения Γ/(4πh) ± 3 % через панели; хребет Agnesi H/L 0,5 — нити рождаются только за гребнем,
  `imbalance` ≤ 1e-12, нет NaN 200 шагов, число отрезков ограничено (рост < ×10 за последние 100 шагов);
  `couple=True` — ротор меняет ΔS у земли за гребнем (u∥ на 10 м за гребнем отличается от `couple=False` > 10 %);
  двойной хребет (два Agnesi H/L 0,5 через 3L) — с `restart` отрыв за обоими гребнями, без — только за первым;
  время шага на N ≈ 5000 панелей и 2000 узлов — в отчёте.

## SWD7 v2 — нить ротора с геометрическим замыканием (пакет `rotor3d`)
v2 (2026-11-08, ответ Q3, вариант A): одно условие — `params["closure"]="reattach"` (по умолчанию): ноль касательной
скорости у поверхности только в точке присоединения x_r; отрыв — по критерию (порог), не условием на гребне; R — одно
правило геометрии на все места: R = (x_r − x_c)/4 по нормали к склону от x_m = (x_c + x_r)/2 (`params["R_rule"]`,
по умолчанию 0,25 доли (x_r − x_c)); неизвестная — только Γ (скаляр, `brentq`/`root`); порог по умолчанию —
`gate="slope"`, `slope_min` 0,27. `closure="two_point"` — поведение v1 (регрессия). Инварианты v2 (тесты): Agnesi H/L
0,5 — корень есть, |u_t(x_r)| ≤ 1e-3·U, обратный u∥ на 10 м между x_c и x_r, |u_min|/U — числом (физично: ≤ ~0,5·U;
больше — в отчёт как провал, не подгонять); C4 — нити нет (уклон < 0,27); C2 — нить есть, L зоны обратного u∥ на 15 м
против Пикара ~800 м — числом; цена ≤ 5 решений по кешу LU.
Владелец — SWD-11; потребители — SWD-5d. Решение пользователя 2026-11-08 (вариант B): вихрь в потенциальном потоке
сам не держится (Фёппль; держат вязкость и турбулентность, которых в панелях нет) — положение задаётся правилом
геометрии, одним на все места, без подгонки по месту.
Пакет `tools/research/sw_charges_3d/rotor3d/` (панели — SWD2 v5, нити — SWD3, только вызывать).
- `rotor_vortex(panels, bg, z0, infl=None, params=None)` → `(fil, sigma, info)`. По каждому хребту (гребни
  `hill_length` на линиях тока поперёк области, совпадающие в пределах 2·ds_min, — один хребет; ось — МНК по точкам
  гребня): на линии тока через середину хребта — гребень x_c; точка присоединения x_r = ближайшая по ветру из
  (подножие подветренного склона — первый минимум сглаженного профиля за гребнем, σ как у `hill_length`; середина
  долины — половина пути до следующего гребня); середина x_m = (x_c + x_r)/2 на поверхности; нить — прямая вдоль оси
  хребта через точку x_m + R·n (n — нормаль к сглаженному склону в x_m), длина — протяжённость гребня; концы —
  подкова в землю, замкнутая под землёй (как `sheet3d`, отражение ±0,2 %). Неизвестные R > 0 и Γ; уравнения —
  касательная скорость у поверхности (bg + панели + нить) по ветру = 0 в x_c и в x_r (середина нити) —
  `scipy.optimize.root`; σ — с extra = нить (кеш `infl`). Порог постановки (`params["gate"]`): "head" (по умолчанию)
  — у хребта есть отрыв Хеда (`separation3d(restart=True, lee_only=True)`) на подветренной стороне; "slope" —
  макс. подветренный уклон сглаженного профиля > `slope_min` (0,27); ниже порога — нити нет. `info` — по хребтам
  {`x_c`, `x_r`, `x_m`, `rule_r` ("foot" | "valley_mid"), `R`, `Gamma`, `gate`, `placed`, `converged`, `residual`},
  `t_s`. Нет корня — `converged=False`, нить не ставится (без подгонки).
- `velocity_rotor(panels, sigma, bg, fil, x, y, z, z0, U_ref=None, infl=None)` → (u, v, w) =
  `velocity_jh(..., extra=induced(fil), couple=True)`.
- Инварианты (тесты): ровная земля и гаусс H/L 0,1 — нити нет, поле = `velocity_jh` побитно; imbalance ≤ 1e-12;
  длинный хребет Agnesi H/L 0,5 + `bg_profile` — нить стоит, корень есть, касательная скорость в x_c и x_r ≤ 1e-3·U,
  обратный u∥ на 10 м между x_c и x_r; разрез C4 (cascade-2d, вытянутый вдоль оси в длинный хребет) — нити нет
  (у Пикара ротора нет; контроль ложного ротора), разрез C2 — нить есть (у Пикара ротор L ≈ 800 м; L — числом);
  цена ≤ 5 решений панелей того же N (по кешу LU) — замер.

## SWD9 v2 — ротор как цепочка «сток + вихрь» (пакет `chain3d`)
v2 (2026-11-08, дополнение пользователя к C'): (1) концы прибиты к рельефу (Гельмгольц): ротор — непрерывный участок
хребта, где подветренный уклон (сглаженный, по линиям тока поперёк области) выше порога; концы — где участок
кончается (седловина, конец хребта, распадок): там ножки в землю; на хребте может быть несколько роторов; звенья —
внутри участка. (2) Устойчивость — число закрутки S (отношение закрутки к осевому оттоку стока; определение —
по литературе о распаде вихря, напр. Leibovich 1978, Escudier 1988; вихрь Бюргерса — сток растягивает вихрь): для
каждого ротора `state` = "есть" (S ниже нижней границы литературного диапазона порога распада S_c), "дышит" (внутри
диапазона), "нет" (выше верхней) — диапазон и ссылка в README, без подгонки; при "нет" поле ротора не добавляется
(срыв вихрей — масштаб 3). Q = 0 — предельный случай распада (S → ∞). (3) Выход для игры — `info["rotors"]` —
{`axis_from`, `axis_to`, `length_m`, `S`, `S_c_range`, `state`}; проверка — по присутствию (есть/нет/дышит), не по
числам. Инварианты v2 (тесты): хребет конечной длины с понижением по краям — концы ротора у края участка уклона
(± 2·ds_min); седловина посередине длинного хребта — два ротора; Q = 0 — state "нет"; Agnesi H/L 0,5 и C2, C4 —
state по правилу (числами S в отчёте).
Владелец — SWD-15; потребители — сравнение (вариант "chain_jh"). Решение пользователя 2026-11-08 (Q3, C'): звенья
вдоль хребта, каждое — вихрь (Γ) + линейный сток (Q): комплексная сила (Q − iΓ)·log z, течение спиральное;
притяжение к склону — от отражения стока в земле (Бьеркнес); масса не теряется. Без подгонки по месту.
Пакет `tools/research/sw_charges_3d/chain3d/` (панели SWD2 v5, нити SWD3 — только вызывать).
- `chain_rotor(panels, bg, z0, infl=None, params=None)` → `(chain, sigma, info)`. Хребты, x_c, x_r — как SWD7 (правило
  присоединения, ось МНК); порог — уклон > `slope_min` 0,27. Звенья: K = ceil(длина хребта / `l_link`), `l_link` по
  умолчанию 2·H хребта (суброторы — Doyle & Durran 2007; README); звено k — прямой отрезок вдоль оси с вихрем Γ_k и
  равномерным линейным стоком q_k (м²/с, расход на единицу длины, < 0 — сток).
  Γ_k — из потока завихренности со склона (Lighthill 1963; Morton 1984): Γ_k = (Δp_k/ρ)·τ_k, Δp_k/ρ = ½(u_t(x_c)² −
  u_t(x_r)²) по панелям на линии тока звена (рост давления вдоль подветренного склона), τ_k = (x_r − x_c)/U_ref.
  q_k = −E·ΔU_k·(x_r − x_c), ΔU_k = u_t(x_c) (скачок через слой сдвига), E — вовлечение слоя смешения из литературы
  (одно значение; напр. Brown & Roshko 1974 — README; без подгонки). Баланс массы: линейный источник вдоль линии
  присоединения x_r звена с расходом −q_k (`params["mass"]="reattach"`, по умолчанию) — сумма расходов = 0.
  Вихри звеньев с разной Γ — ножки в землю на стыках, концы цепочки — подкова, замкнутая под землёй (как sheet3d,
  ∇·ω = 0); стоки/источники — через `extra` панелей (σ — с ними) и их отражение панелями.
  Положение звена (s вдоль ветра от гребня, n по нормали к склону) — из равновесия: скорость в середине звена
  (bg + панели + прочие звенья, стоки, источники, без самоиндукции звена) = 0 в плоскости поперёк оси — 2 уравнения
  на 2 неизвестных на звено; совместно по звеньям (`scipy.optimize.root`), начальное s = (x_r − x_c)/2, n = H/2.
  `chain` — {`fil` (Filaments), `sinks` (список {отрезок, q}), `sources` (список {отрезок, q})}; `info` — по звеньям
  {`s`, `n`, `Gamma`, `q`, `converged`, `residual`}, `mass_balance` (Σ расходов), `t_s`, `n_solves`.
- `velocity_chain(panels, sigma, bg, chain, x, y, z, z0, U_ref=None, infl=None)` → (u, v, w) =
  `velocity_jh(..., extra=поле цепочки, couple=True)`.
- Инварианты (тесты): ровная земля/гаусс 0,1 — цепочки нет, поле = `velocity_jh` побитно; |Σ расходов| ≤ 1e-9·|q|;
  imbalance вихрей ≤ 1e-12; отражение линейного стока у плоской стенки панелями — против изображения ± 1 %; 2D-предел
  (длинный хребет, одно звено): точечный (Q − iΓ) у стенки — равновесие против аналитики с изображением ± 5 %;
  Agnesi H/L 0,5 — равновесие есть, обратный u∥ на 10 м между x_c и x_r, |u_min|/U и L — числами; C4 — нет (уклон),
  C2 — есть, L против ~800 м Пикара — числом; цена ≤ 10 решений панелей по кешу LU.
