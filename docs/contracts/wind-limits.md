# Контракты модуля wind-limits

План — `docs/plan/wind-limits.md`. Менять — только через координатора (версия +1, что изменилось, уведомить потребителей). Используются без изменений: К1 v2, К2 v1, К3 v1, К6 v1 (`docs/contracts/wing-physics-check.md`); С1–С3 (`docs/contracts/control-fix.md`). Правка формулы ветра меню (К3) — только задачей WL-3 через координатора (К3 → v2).

## WL-К1. Класс крыла и предельный ветер класса (v1)
Владелец: WL-2. Потребители: `WingCatalog` (`scripts/game/wing_catalog.gd`), меню (`scripts/ui/flight_setup_screen.gd`), WL-1/WL-4 (сводная таблица), тесты.
- `configs/wing_classes.json`: `{"classes": {"1": {...}, "2": {...}, "3": {...}, "4": {...}}, "_doc": "…"}`; у класса — `name_key` (ключ перевода), `wind_limit_ms: [lo, hi]` (м/с, ветер меню = U на 10 м над стартом, К3), `_doc` — источник (отзыв пилота 05.10.2026 + паспорта/клубные данные, если есть). v1: 1 учебный [7, 10]; 2 мачтовый с жёсткой поперечной [10, 12]; 3 мачтовый с плавающей поперечной [12, 15]; 4 безмачтовый [20, 25].
- `configs/wings/<id>.json`: `wind_class: int ∈ {1, 2, 3, 4}` (обязателен у каждого крыла), `wind_class_doc: String` — довод (паспорт: мачта, поперечная жёсткая/плавающая, источник); `double_surface_pct: float|null` — доля двойной обшивки, % (из паспорта; нет данных — `null`, крыло в списке вопросов пилотам). Деления «одно-/двухобшивочный» нет нигде (ни поля, ни ключа перевода, ни колонки). Поля `wind_max_ms`, `wind_max_ms_doc` удаляются.
- `WingCatalog.wind_class(cfg) -> int`, `WingCatalog.wind_limit(cfg) -> Vector2` (lo, hi; м/с); `wind_max` удаляется, сортировка группы — по best_glide, при равенстве — по hi.
- Инварианты: lo < hi; hi класса не убывает с номером класса; предел — подсказка в меню, в физике не участвует (ни одного порога «ветер > X»).
- Контрактный тест: `tests/contracts/test_wind_limits_contracts.gd` (у всех крыльев класс 1–4, таблица классов полна, lo < hi, нет `wind_max_ms`).

## WL-К2. Таблицы ветра сноса и удержания на старте (v1)
Владелец: WL-1 (инструмент и «до»); WL-4 — «после» тем же инструментом. Потребители: координатор, WL-3, WL-4, отчёт пользователю.
Каталог `tools/research/wind_limits/out/<метка>/` (`before`, `after`, …), UTF-8, разделитель `,`, точка — десятичный знак. Ветер — ветер меню (м/с, К3). Повторный запуск пропускает готовые ключи.
- `runs.csv` — сырые полёты, колонки К6 v1 строго (`series=penetration`), `mode` ∈ `analytic|nn|field`, `pitch` — команда трапеции (0 трим, −1 «на себя»).
- `limits.csv` — по строке на (mode, wing, start, agl0_m, pitch):
  `mode,wing,wind_class,location,start,agl0_m,pitch,wind_blow_ms,gs_w6_ms,gs_lo_ms,gs_hi_ms,winds,note`
  - `pitch` ∈ `trim|full_pull`; `wind_blow_ms` — ветер меню, при котором `gs_into_wind_ms` (К6) переходит через 0 (линейно между соседними ветрами сетки, первый переход снизу); пусто, если вперёд при всех ветрах сетки (`note` `>W`) или назад при всех (`<W`);
  - `gs_w6_ms`, `gs_lo_ms`, `gs_hi_ms` — путевая против ветра при 6 м/с и на границах класса (WL-К1; линейно по сетке), м/с; `winds` — сетка через `;`.
- `ground_hold.csv` — по строке на (mode, wing, start, wind_set_ms):
  `mode,wing,wind_class,location,start,wind_set_ms,held,lifted_s,max_abs_roll_deg,min_pitch_deg,max_pitch_deg,note`
  - пилот стоит на старте носом в ветер, управление — как у пилота-игрока в `tools/flight/cf3_ground_control.gd` (держит нос у нейтрального угла разбега, крен — рукой, С1 v2), 20 с, болтанка включена (сид конфига); `held` = 1, если ноги не отрывались дольше 0,5 с (`lifted_s` — суммарно) и |крен| ≤ 25°; углы — крыла относительно горизонта, градусы.
- `class_table.md` (и `class_table.csv`) — по строке на (класс, mode): число крыльев, диапазон пилота, мин/медиана/макс `wind_blow_ms` на триме и «на себя» (100 и 300 м), мин/медиана `wind_hold_ms` (наибольший ветер сетки, до которого включительно все `held` = 1), доля крыльев, идущих вперёд при 6 м/с на триме. С двумя метками (`--before --after`) — колонки «до/после».
- Проверка формы: `python3 tools/research/wind_limits/check_contract.py <каталог>` (колонки, типы, допустимые значения) — пишет владелец WL-1.
