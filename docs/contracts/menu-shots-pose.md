# Контракты menu-shots-pose

Контрактный тест — `python3 tools/shots/menu_pose_check.py --selftest` (пишет MSP-1). Правка интерфейса — только через
координатора: версия +1, этот файл и тест — в том же шаге.

## MSP-К1 v1
Поза планера на кадре `tools/shots/menu_background.gd` (через `menu_background.sh` и `menu_art.py`).
- Владелец: MSP-1. Потребители: `tools/shots/menu_art.py` (пишет конфиг кадра), `tools/shots/menu_pose_check.py` (читает логи).
- Конфиг кадра (JSON, который читает `menu_background.gd`): поле `pose` — объект; нет поля — `{"mode": "fixed"}`.
  - `mode`: `"fixed"` (по умолчанию) — после `sim_time_s` и паузы планеру ставится установившаяся поза: крен `bank_deg`
    (по умолчанию 0), тангаж — балансировочный тангаж планирования этого крыла (из физики планера, не подбором на глаз),
    курс — текущий; пилот и подвеска — в равновесии для этой позы; физика и ветер до снимка позу не меняют.
    `"physics"` — как было: поза, какую дала симуляция к `sim_time_s`.
  - `bank_deg`: float, градусы, + — правое крыло вниз; допускается |bank_deg| ≤ 30.
  - `menu_art.json` может задать `pose` на весь набор (верхний уровень) и переопределить в варианте; `menu_art.py`
    переносит его в конфиг кадра.
- Лог кадра: перед снимком — ровно одна строка
  `menu_background: поза режим=<fixed|physics> крен=<°> тангаж=<°> курс=<°> баланс=<°> p=<°/с> q=<°/с> r=<°/с>`
  (числа `%.1f`; крен/тангаж — по фактической трансформации узла, который рисуется на кадре; `баланс` — балансировочный
  тангаж, по которому ставилась поза, в `physics` — тот же расчёт для сравнения; p/q/r — угловые скорости в момент снимка,
  в `fixed` — 0).
- Проверка `tools/shots/menu_pose_check.py <каталог_с_logs>`: по каждому `logs/NN.log` — строка позы есть;
  в режиме `fixed` |крен − bank_deg| ≤ 1°, |тангаж − баланс| ≤ 1°, −5° ≤ тангаж ≤ 20°; вывод — таблица и итог
  `pose ok N/M`; код 0, только если N = M. `--selftest` — разбор строк-образцов (годная, крен вне пределов, строки нет), код 0.
- Единицы: градусы, °/с. Оси: крен — вокруг продольной оси крыла, тангаж — нос вверх +.
