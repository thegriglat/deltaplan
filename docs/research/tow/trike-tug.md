# Буксировщик-дельталёт: параметры и набор связки

Задача TT-1 (модуль `tow-trike`). Выход: `configs/tow_tug.json` (блоки TT-К1), числа крыла `tools/research/tow-trike/wing_trike_ixess15.json`
для TT-2, скрипты — `tools/research/tow-trike/` (воспроизведение — README там). Метка «оценка» = без источника, «вывод» = расчёт по числам из источников.

  Junkers Profly Trike 186 (крыло 12,8 м²), PowerTrike II / Sunward ST 198 кг; Cosmos Phase II 136 (503), Aeros-2 229,5 (912).
- Tanarg/iXess 15 (912ULS): BMAA HADS HM16 — <https://www.bmaa.org/files/hads_hm16_tanarg.pdf> (через `tools/research/trike-model/wings.json`): пустой 250 (с крылом 53), MTOW 450, Vso 59,3, глиссада 6,6, набор 5,49 м/с (Annex F), best climb 83,3, винт Ø 1,7.

- Буксировка: `docs/research/tow/kinds.md`, `kinds-bhpa.md` (BHPA §2.7.6 E: 64 км/ч при 2,54 м/с, 152 м, ≤3,05 м/с, крен ≤10°, натяжение 21–35 даН).

## Расчёт тяги
Мощность двигателя — кусочно-линейная по оборотам (48 кВт @ 6500, 47 @ 6000, 41 @ 5500, 36 @ 5000, дальше вниз; точки до 6000 кроме 47 кВт — оценка по почти плоскому моменту 69–72 Нм).
Винт фиксированного шага: `Ct = Ct0 (1 − J/J0)`, `Cp = Cp0 (1 − 0,35 J/J0)`. Калибровка: `Cp0` — статические обороты 5600 об/мин двигателя (типично для 582 с таким винтом, допущение);
`Ct0` — статическая тяга по идеальному диску с FM 0,60: `T = (2ρA)^(1/3) (FM·P)^(2/3)`; `J0` — по пику КПД 0,72 (получается Ct0 = 0,171, Cp0 = 0,094, J0 = 1,29). Обороты при скорости V — равновесие мощности двигателя и винта, потолок 6800.
Результат (`thrust_table.csv`): статика 1587 Н (FM 0,5–0,7 → ≈ 1450–1700 Н); 1352 Н и 1720 об/мин винта на 60 км/ч (КПД 0,48); 1076 Н на 30 м/с. Холостые: 202 Н в статике, на 60 км/ч ≈ 50 Н, выше 22 м/с — 0 (обрезано контрактом `idle_n ≥ 0`; реальная авторотация даёт сопротивление).

**Проверка метода:** тот же расчёт для Tanarg/912ULS (D 1,7, редуктор 2,43, 61,7 кВт@4600 в статике), 450 кг, 83,3 км/ч даёт набор **4,71 м/с против 5,49** по HADS (−14 %): метод занижает. Для 582 паспортных данных по набору нет.

## Крыло iXess 15 для TT-2
Поляра — парабола `CD = CD0 + k·CL²`, `k = 1/(π·0,75·6,66)`; `CD0 = 0,0352` из «качества связки 6,6 на 74,1 км/ч при 450 кг» минус сопротивление тележки (CdA 0,82); `CL_max = 1,77` из Vso 59,3.
Получается: качество самого крыла 10,5 на 79 км/ч, при массе 315,5 кг Vs = 49,7 км/ч, мин. снижение 1,77 м/с, снижение на 80 км/ч 2,11 м/с. Все цифры и `src` — `wing_trike_ixess15.json`. Поляра крыла **без** тележки (тележка — `cda_m2`). Хорды, число латт, дигедрал, крутка, кингпост — оценки (в HADS их нет); трим 73 км/ч — прокси (best climb 83,3 × √(m/450)).

## Баланс мощности: связка с sport
Установившийся набор: `T − D_tug − D_glider = (m_tug + m_gl)·g·sinγ`, `ROC = V sinγ`; натяжение троса `D_gl + W_gl sinγ`; дельтаплан sport — поляра `configs/wings/sport.json` по массе 134,4 кг (пилот 100 + крыло 34,4); трос вдоль траектории.
Основной результат на 60 км/ч: `climb_ms=3,02 speed_kmh=60 thrust_n=1352 drag_n=461 tension_n=331` (натяжение 33 даН — в диапазоне 21–35 даН из `kinds.md`).

| Случай | V, км/ч | Набор, м/с |
|---|---|---|
| 582 + sport 100 кг | 55 / 60 / 65 / 70 | 2,83 / 3,02 / 3,13 / 3,13 |
| 582 + sport, пилот 80 кг | 60 | 3,20 |
| 582 + sport, бак 15 кг | 60 | 3,21 |
| 912ULS (тележка 197 кг) + sport | 60 | 3,78 |
| 582 без дельтаплана | 60 / 75 | 4,87 / 5,18 |

Порог BHPA 2,54 м/с при 64 км/ч выполняется с запасом ≈ 0,5 м/с (≈ 20 %). С поправкой на занижение метода запас больше, но неопределённость тяги (FM, статические обороты), масс (±25 кг ≈ ±0,3 м/с) и CdA (±30 % ≈ ±0,3 м/с) сопоставима с запасом.
Без дельтаплана 4,9 м/с — того же порядка, что паспортные 5 м/с у трайков с 80–100 л.с. при полной нагрузке (Aeros-2 912: 5 м/с; PowerTrike II BMW: 5 м/с); для лёгкой 582-тележки правдоподобно.

## Допущения и границы применимости
- Уровень моря, ρ = 1,225, штиль, трос вдоль траектории без провисания и угла; дельтаплан в тросе на той же траектории и скорости.
- Тяга и КПД — калибровка винта по трём допущениям (статика 5600 об/мин, FM 0,60, пик КПД 0,72); измерений для винта 1,8 м/582 нет. Разброс тяги на 60 км/ч ±15 %.
- Поляра iXess — из двух паспортных точек (глиссада 6,6 и Vso) и допущения e = 0,75; в связи с 14 % занижения набора на 912 это не разделяется между винтом и полярой.
- Массы тележки, ЦМ, CdA, сила на штанге, тангаж на земле — оценки.

## Чего модель не умеет
Просадки тяги на разбеге из-за оборотов и рулёжки; влияние высоты и температуры на мощность 2-тактника (не учтено — на 150 м ≈ −2 %); авторотацию винта на холостых (тяга обрезана нулём); реакцию тележки на рывок троса и на колебания натяжения; изменение массы по мере выработки топлива; нагрузку на штангу от тяги троса; перекос тяги от крена (ось тяги — фиксированная).
