# Площадка буксировки для места игры (Q2)

Задача TW-13. пользователя (Q2, 2026-10-22): Волжский не обязателен, место может быть не в России; сначала
смотреть места, уже предзаполненные в игре. Числа — только с `[n]` из «Источников»; `расчёт` — наш пересчёт.

## Выбор

**Wilotree Park (Quest Air), Грувленд, Флорида, США** (OSM-аэродром «Sheets Airport», FAA FA42, `ele=33`) [12].

Почему: (1) аэробуксировка дельтапланов подтверждена несколькими независимыми отчётами соревнований (Quest Air Open,
Национальный чемпионат США по буксировке на равнине, 2015–2022) [10][11]; (2) равнинная площадка, как раз сценарий
`aerotow`; (3) в OSM две пересекающиеся травяные полосы, и их `length`/`width` совпадают с цифрами из отчёта о
соревновании (E/W 1780 фут ≈ 543 м × 155 фут ≈ 47 м; N/S 2000 фут ≈ 610 м × 115 фут ≈ 35 м) [10][12] — данные
OSM независимо подтверждены; (4) Quest Air — одна из самых известных площадок буксировки дельтапланов в США
(не оценка, а вывод по числу национальных соревнований в [10][11]). Wallaby Ranch популярнее у туристов, но в OSM
полосы нет.

Какую полосу брать: N/S 18/36 (way 304948919) — длиннее и разгонный вектор свободнее; E/W 09/27 (way 304948918) —
запасная при боковом ветре («взлёт и посадка обычно в одном месте по ветру» [10]). Какой именно полосой пользуются в
соревнованиях, источник не говорит.

Что не подтверждено: регулярность буксировки сегодня (источники 2015–2022); аэродром окружён деревьями [10] —
препятствия по краям; площадь для посадки шире полосы («дополнительные площадки, особенно к северу» [10]).

## Полоса

Источник геометрии — OSM, way 304948919 (`aeroway=runway`, `ref=18/36`, `surface=grass`, `length=610`, `width=35`),
ODbL [12]. Концы — первая и последняя точки линии; длина и курс по ним — расчёт (сфера R = 6371 км).

| параметр | значение |
|---|---|
| lat_start | 28.5311456 |
| lon_start | -81.8464567 |
| lat_end | 28.5388934 |
| lon_end | -81.8469503 |
| heading_deg | 356.8 |
| length_m | 610 |
| width_m | 35 |
| surface | grass (трава, по OSM и отчёту [10]) |
| elevation_m | 33 |

Начало — южный конец; курс 356,8° — истинный, по геометрии (на север, т. е. взлёт на 36; номер полосы 18/36 — по магнитному, склонение в районе ≈ −5° дало бы ≈ 355°, это расчёт и по источнику не проверено).
Длина: тег OSM и отчёт [10] — 610 м (2000 фут); расчёт по концам линии — 862 м (линия длиннее объявленной полосы, вероятно
включает концевые зоны). В игру: `runway_length_m = 610` (заявленная, для проверок `TowSite`), геометрию использовать для
размещения. Высота: тег аэродрома `ele=33` (Sheets Airport) [12]; SRTM по open-elevation на концах полосы 40 и 36 м [16] — расхождение ≈ 3–7 м, берём тег.

Запасная E/W 09/27, way 304948918: 28.533125 N −81.8496539 → 28.5329554 N −81.8436672: `length=543`, `width=47`, `grass`; в
таблицу не вынесена.

Для `configs/locations` (TW-К6): `tow.kinds = ["aerotow", "winch_static"]`, `runway_length_m = 610`,
`runway_width_m = 35`, `heading_deg = 356.8`; запись предлагается как `builtin/wilotree/runway` в `hg_takeoffs.json`.
Лебёдка здесь источниками не подтверждена — `winch_static` как режим игры, а не факт о площадке.

## Чего не знаем

- Каким покрытием/состоянием обладает полоса сейчас; ширина 35 м и `grass` — OSM-теги, сверенные с отчётом [10], не замером.
- Какая из двух полос используется (зависит от ветра); почему геометрия длиннее заявленных 610 м.
- Высота: 33 м (OSM) против 36–40 м (SRTM); перепад вдоль полосы неизвестен.
- Препятствия: деревья вокруг поля [10]; воздушное пространство (ближе к Орландо), прочие операторы на поле.
- Лебёдка на Wilotree — нет источника.
- Крутиха: нет геометрии полосы; лебёдка — одно поле, только запад [3].
- Логиново: буксировка дельтапланов не подтверждена; Wallaby Ranch — размеры не найдены.
- Для Gooden Airpark: Wikipedia даёт полосу 12-30, OSM — 10/28 (ориентация та же ≈ 120°, номер расходится), высота 20 м против `ele=18`.
- Поиск вёлся веб-поиском с неполной выдачей; Европа/Австралия не проверены; ofsla.ru регламент отдал 404, не прочитан.
- OSM Overpass запрашивался 2026-10-22; правки OSM после этого не учтены.
