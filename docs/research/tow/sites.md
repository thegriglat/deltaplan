# Площадка буксировки для места игры (Q2)

Задача TW-13. Решение пользователя (Q2, 2026-10-22): Волжский не обязателен, место может быть не в России; сначала
смотреть места, уже предзаполненные в игре. Числа — только с `[n]` из «Источников»; `расчёт` — наш пересчёт.

## Кандидаты

Проверено каталогом игры `data/places/hg_takeoffs.json` (700 стартов, OSM) и `configs/locations/*.json`: все записи —
склоны и горы (Алтай, Аскарово, Аушкуль, Юца, Онгудай, Ушконыр и т. д.), ни одной равнинной площадки с полосой и
признаком буксировки нет. Ближайшая равнинная запись — `Lake George` (AU, склон-эскарп), для буксировки не подходит
(в источниках [8] про буксировку ничего нет). Поэтому берём внешние площадки по источникам.

| площадка | где | буксировка по источникам | полоса известна | вывод |
|---|---|---|---|---|
| Дельтадром Крутиха, поле у п. Белоярский | Свердловская обл., 56,785395 N 61,499352 E, 238 м [1][2] | да: Чемпионат России 2023, старт «аэробуксировка»; в Kruticha Open 2021 — лебёдка (одно поле, только западный сектор ветра) и аэробуксировка [1][2][3] | нет: только точка взлёта и «поле левее трассы Екатеринбург–Тюмень» [2][3] | основной район, но геометрии нет |

## Выбор

**Аэродром ДОСААФ «Логиново»**, Свердловская область (Аэроклуб ДОСААФ, Екатеринбург).

Почему: (1) единственная из найденных площадок, где в открытых данных есть полоса с координатами, длиной, шириной,
покрытием и высотой; (2) официально названа запасной площадкой Чемпионата России по дельтапланеризму 2023 (взлёт —
поле у Белоярского в 25 км) [2]; (3) в регионе дельтапланы буксируют по-настоящему — Крутиха [1][3]; (4) равнина,
длинная прямая полоса подходит `aerotow` и `winch_static` (по `kinds.md`: полоса ≥ 10 длин разбега, лебёдка на дальнем
конце).

Что не подтверждено: что именно на Логиново буксируют дельтапланы регулярно — прямого источника нет (в источниках
[5] — планеры и авиашоу). Для игры это допущение: место названо настоящим именем, но в тексте/описании не утверждать
«здесь проходят сборы дельтапланеристов». Запасной вариант — Крутиха (поле у Белоярского) с полосой, которую придётся
задать самим (точка взлёта 56,785395 N 61,499352 E, 238 м [2]).

## Полоса

Источник геометрии — OSM, way 292686512 (`aeroway=runway`, `ref=9/27`, `surface=ground`, `length=800`, `width=40`,
`ele=250`), ODbL [4]. Концы полосы — первая и последняя точки линии (линия из 4 точек); длина и курс — расчёт по ним
(сфера R = 6371 км).

| параметр | значение |
|---|---|
| lat_start | 56.6532565 |
| lon_start | 61.3662393 |
| lat_end | 56.6546677 |
| lon_end | 61.3526566 |
| heading_deg | 280.7 |
| length_m | 845 |
| width_m | 40 |
| surface | ground (грунт, по OSM; трава/грунт — не уточнено) |
| elevation_m | 250 |

Начало — восточный конец; курс 280,7° идёт с востока на запад, т. е. взлёт на 27 (ref 9/27). Длина: расчёт по концам 845 м, OSM-тег `length` 800 м (разница ≈ 6 %: тег округлён или
мерялся иначе) — в игру брать 800 м как заявленную, 845 м как геометрическую; выбрать геометрическую для размещения,
заявленную для проверок `TowSite`. Высота: тег полосы 250 м, тег аэродрома 248 м [4]; перепад вдоль полосы по OSM
неизвестен — смотреть по рельефу игры.

Для `configs/locations` (TW-К6): `tow.kinds = ["aerotow", "winch_static"]`, `runway_length_m = 845`,
`runway_width_m = 40`, `heading_deg = 280.7`, запись `builtin/loginovo/runway` в `hg_takeoffs.json`. Рельеф
вокруг — равнина с лесом по краям (по контуру OSM аэродрома ≈ 3,2 × 1,5 км), проверять `TowSite.check`.

## Чего не знаем

- Регулярная буксировка дельтапланов на Логиново: нет источника; только соседние события [2].
- Реальная ширина и состояние покрытия: 40 м и `ground` — OSM-теги, не замеры; нет ссылки на документ аэродрома.
- Различие 800 м (тег) и 845 м (геометрия); порог посадочный/смещённый.
- Препятствия и уклон вдоль полосы; воздушное пространство (аэродром с парашютистами, возможен конфликт).
- У Крутихи нет геометрии полосы; лебёдка там — одно поле, только запад [3].
- Новосибирский клуб — аэродром не назван; Wallaby Ranch — размеры полосы не найдены.
- Поиск вёлся веб-поиском с неполной выдачей, а не обходом форумов; ofsla.ru регламент (reglament-chr-2023-dp.pdf)
  отдал 404, не прочитан.
