# air-phase, часть 2: почти аналитика по фазам, эксперты, эталоны, сборка на GPU

Продолжение `docs/research/air_phase.md` (фазы A–H, оси, измерения). Литература и надёжность чисел — `docs/research/air_phase_refs.md`; здесь ссылки вида [Sm80]. Числа «по памяти» помечены.

## 12. Почти аналитика по фазам

Тезис автора: ядра фаз описываются почти аналитически; сложность — на границах (C, переходы, взаимодействие гребней). Разбор по фазам: формула, точность, где ломается (оценки цены по решению автора не приводятся).

### A — линейная теория (нейтрально: Джексон–Хант; устойчиво: Смит)
- **Формула.** Возмущение — свёртка рельефа с передаточной функцией: û(k, l, z) = T(k, l, z)·ĥ(k, l), по БПФ. Нейтральный пограничный слой [JH75]: два слоя — внутренний толщиной ℓ из ℓ·ln(ℓ/z₀) = 2κ²·a (a — полуширина холма; при a = 1 км, z₀ = 0,1 м ℓ ≈ 30–40 м) и внешний (потенциальное обтекание); разгон на гребне ΔS ≈ 2h/a (2D), 1,6h/a (3D), 0,8h/a (уступ) [Fin20]. Устойчивая гидростатическая атмосфера [Sm80]: ŵ(k, l, z) = i·U·k·ĥ·exp(i·m·z), m = N·√(k² + l²)/(U·|k|)·sign(k) — волны уходят вверх, давление на поверхности даёт волновое сопротивление; условие линейности — Nh/U ≪ 1 (на деле ≲ 0,5), гидростатичность — N·a/U ≫ 1. Торможение массивом в целом (главная ошибка профиля притока в P3: −2,3 м/с на 60 м, `air_physics_primer.md` §3.4) линейная теория не даёт — нужна поправка: эффективная шероховатость/сопротивление массива (orographic drag) как сток импульса, либо снижение U_b по высоте массива.
- **Точность.** Приемлема при h/a < 0,2 [Fin20]; на Askervein наветренный склон и гребень — в пределах 10–20 %, подветренный — большие ошибки [Fin20, по памяти для чисел]; ошибка ~1,5 % скорости на 1 % ΔRIX (доля местности круче 0,3) [Mor06].
- **Ломается.** h/a > 0,2–0,3 (срыв → B), Fr < 1 (блокирование → D), вблизи Fr ~ 1 (нелинейные волны → C), сильный нагрев (слой перемешивания нейтрален, но анабатика и конвергенция над склонами — E/F).

### B — линейная теория по огибающей + эмпирика пузыря
- **Формула.** Эффективный рельеф h_eff = max(h, огибающая): с подветренной стороны «досыпать» воздух до уклона s_crit ≈ 0,3 (как тепловая эрозия в генераторе, направленная по ветру); длина пузыря ≈ 2,8h (Perdigão, по `air_physics_primer.md` §3.3), обратный ветер в пузыре ≈ 0,2·U₁₀₀ ± 0,08; выше крышки — A по h_eff; слой сдвига на крышке — пульсации σ_u ≈ 0,18ΔU (масштаб 3). Максимум разгона ограничить 1,25 [Fin20].
- **Точность.** RANS сам даёт в подветре 26–92 % ошибки [Wag19] — эвристика с подогнанной огибающей не хуже; калибровка — Пикар на окне 50–100 м с 2-м порядком (§9 основного документа, п. 5).
- **Ломается.** Нестационарный отрыв (пульсации — масштаб 3), затекание в пузырь с концов гребня, роторы под волной (это C), устойчивая стратификация (подавляет отрыв [Ros04]) и нагрев (усиливает?) — порог s_crit зависит от Ri и z₀ [Woo95].

### C — уравнение Лонга, двухслойная гидравлика
- **Формула.** Лонг (1953/55): при постоянных U, N стационарное 2D-решение точное и линейное по функции тока смещения δ: ∇²δ + (N²/U²)·δ = 0 с граничным условием на рельефе (не на z = 0) — решается спектрально по x с итерацией по граничному условию; опрокидывание при Nh/U ≈ 0,85 (полукруг, Miles & Huppert 1969 — по памяти; 0,67–1,1 по форме [M]). Нисходящая буря и прыжок — гидравлика слоя под инверсией [Dur86, Smi85]: Fr_i = U/√(g′H₀); слой переходит в сверхкритический над гребнем, когда высота горы достигает критической h_c/H₀ = 1 + Fr_i²/2 − (3/2)·Fr_i^{2/3} (однослойная мелкая вода, Long 1954 / Houghton & Kasahara 1968 — формула по памяти, проверить); за гребнем — ускорение по склону и прыжок у подножия [Vos04: роторы при чуть больших Fr_i, прыжки при малых и высоких h/z_i].
- **Точность.** Качественная; Vosper 2004 показывает, что линейная теория даёт порог и длину волн на инверсии хорошо, а амплитуду и роторы — нет.
- **Ломается.** Мультистабильность и гистерезис (две ветви: «волна» и «прыжок»); 3D-рельеф; нестационарность. Вывод: в C аналитика даёт **ветви**, выбор ветви — по истории (утро → день) или по Пикару. **Старты Пикара из A-поля и из D-поля около Fr ~ 1 — прямой тест гистерезиса** (§9 основного документа).

### D — разделяющая линия тока + послойный обход + A сверху
- **Формула.** H_c = h_max·(1 − Fr) [She56, Sny85]. Ниже H_c: воздух не поднимается — на каждом уровне z < H_c двумерное обтекание «стенок» (клетки с h > z): Лаплас для функции тока ψ с ∂ψ/∂n = 0 на стенках и ψ = U·y на границе, u_h = ∇⊥ψ (несжимаемо в слое по построению, w = 0). Выше H_c: A по рельефу, срезанному на H_c (h′ = max(h − H_c, 0)), плюс сшивка на H_c. Подветренные вихри (Fr ≲ 0,4) — статистика: положение/срыв случайны, среднее — слабый возвратный ток. Проход через седловины — автоматически (Лаплас усиливает поток в сужениях, ×1,4–1,6 в поле).
- **Точность.** H_c — хорошая оценка для симметричных холмов при малом сдвиге; нижняя граница при сильном сдвиге/асимметрии [Sny85]. Послойное обтекание (Drazin 1961 — предел Fr → 0) верно при Fr ≲ 0,3; при 0,3–0,5 слой частично переваливает.
- **Ломается.** Fr 0,4–1 (переход в C); h/z_i: при h < z_i N внутри слоя ≈ 0 и «истинный» Fr велик — D не наступает, пока рельеф не пробивает слой; наклонная инверсия; нагрев (анабатика выносит воздух из застойных зон). Проверка — Пикар там, где сошёлся (Fr 0,3–0,5: 85–90 %), застой и поворот §6.1 основного документа.

### E/F — подобие слоя перемешивания + анабатика Прандтля
- **Формулы.** w* = ((g/θ₀)·H/(ρc_p)·z_i)^{1/3}; σ_w²/w*² = 1,8·(z/z_i)^{2/3}·(1 − 0,8·z/z_i)² [LWP80 — проверить]; доля площади подъёмов ≈ 0,4–0,45 [LS80]; шаг термиков ~1–1,5 z_i [M]; валы 2–4 z_i (отношение сторон ~3) вдоль ветра при −z_i/L ≲ 25, U ≳ 5 [M]; переход валы → ячейки плавный до −z_i/L ≈ 15–20 [Sal17]. Анабатика — модель Прандтля с нагревом (знак C > 0): u(n) = C·(g/(θ₀N))·(K_h/K_m)^{1/2}·e^{−n/ℓ}·sin(n/ℓ), ℓ = (4K_mK_h/(N² sin²α))^{1/4} (выведено заново из уравнений Прандтля, см. G и refs [Arb22]); днём N внутри слоя ≈ 0 → модель Прандтля вырождается, работает подобие Schumann 1990 (масштаб слоя задан потоком тепла и стратификацией, формулы не извлечены) — на практике анабатика 1–5 м/с, толщина 20–200 м [ZW13]. Среднее поле (куда идут массы) — из баланса: подъём над прогретыми склонами Φ_up ∝ ∑H·площадь, компенсация опусканием над долинами и под инверсией; это то, что сейчас даёт K-решатель с нагревом (h − m), и его можно заменить явным балансом масс.
- **Точность.** Подобие — ±20–30 % по σ_w, доле, шагу (разброс по литературе); положение термиков — только статистика.
- **Ломается.** Привязка к рельефу (где рождаются термики) — не из подобия, а из нагрева склонов и конвергенции; это уже план масштаба 2 (AM-07, Аллен). Валы над горами редко чистые.

### G — сток Прандтля + заполнение долин
- **Формулы.** Уравнения Прандтля (баланс плавучести и трения вдоль склона, адвекции фона и диффузии тепла): 0 = g(Δθ/θ₀)·sin α + K_m·u″, 0 = −Γ·u·sin α + K_h·Δθ″, N² = gΓ/θ₀, Δθ(0) = C (дефицит у земли), u(0) = 0. Решение: u(n) = −C·(g/(θ₀N))·(K_h/K_m)^{1/2}·e^{−n/ℓ}·sin(n/ℓ), Δθ(n) = C·e^{−n/ℓ}·cos(n/ℓ), ℓ = (4K_mK_h/(N² sin²α))^{1/4} (проверено по выводу: u″″ = −N² sin²α/(K_mK_h)·u, корни (−1 ± i)/ℓ; совпадает с [Arb22], eq. 6, при постоянных K); максимум на n = πℓ/4, u_max = e^{−π/4}·sin(π/4)·C·g/(θ₀N)·(K_h/K_m)^{1/2} ≈ 0,32·C·g/(θ₀N)·Pr^{−1/2}. Пример: K_m = K_h = 1 м²/с, N = 0,02 1/с, α = 10° → ℓ ≈ 24 м, струя на ≈ 19 м, u_max ≈ 0,55 м/с на 1 К дефицита (C = 5 К → 2,7 м/с) — согласуется с наблюдениями 1–4 м/с, 3–100 м [ZW13]; толщина дефицита ≈ 5 % перепада от вершины [Horst & Doran 1986 по ZW13]. Озёра холода: холод стекает по тальвегам (дренаж Fastscape уже даёт дерево стока) и накапливается — мелкая вода с g′: объём = ∫ выхолаживание·время, уровень по гипсометрии котловины, перелив через седловину; порог отделения от ветра — критическая глубина долины [VB08, формула не извлечена], порог ветра 5–7 м/с [VdW12].
- **Точность.** Качественно подтверждено наблюдениями; количественно — ±50 %.
- **Ломается.** Ветер > 3–5 м/с (сток сдувается, перемежаемость), сложные котловины, толщина тоньше Δz (в поле ветра игры — только как слой у земли, не как клетка).

### H — статистика порывов
Поля нет; направление — меандрирование (< 1–2 м/с, [Anf05]); для игры — слабое поле F-циркуляции + случайные порывы масштаба 3.

**Вывод для проверки:** аналитика покрывает ядра A, D, E/F, G; на границах (B↔A по s, C, переходы D↔C↔A, несколько гребней в тени друг друга) нужна либо поправка (сеть или Пикар), либо правило рычага. Схема «аналитический эксперт + поправка» (сеть/решатель учит только разность) — H11 для опыта на идеальном рельефе: сколько дисперсии поля Пикара снимает аналитика фазы (ожидание по P3: линейная база снимала 7–10 % разгона, но не торможение массивом — поправка должна включать сопротивление). Побочно: **старт Пикара с аналитического поля фазы** — экономия итераций (тёплый старт уже даёт 40–70 %, `air_model.md`).

## 13. Смесь экспертов (одна сеть с подсетями под фазы)

- **Распределитель.** Жёсткий выбор — скачки на границах, для игры плохо. Мягкий глобальный (правило рычага по Fr области) — не ловит «шлиф». **Локальный по клеткам** — предпочтителен: вес фазы на клетку из местных Fr, −z_i/L, s, h/z_i (формулой — прозрачно, или обученный по разметке параметрами порядка, или смешанный: формула + обученная ширина перехода).
- **Архитектура.** Общий кодировщик рельефа (U-Net-энкодер) и свои выходные блоки по фазам; выход = ∑ w_φ(x, y)·u_φ(x, y, z). Общий кодировщик — общие признаки рельефа, головы — законы фаз.
- **Где поможет:** A, B, D — разные законы (разгон, пузырь, обход), одной свёрточной сети приходится учить переключение сама; **FiLM-условия в P2 уже дают мягкое переключение** [Per18], а ошибка упирается в 0,69 м/с — довод, что дело не только в ёмкости/переключении, а в постановке (цель, нелокальность, торможение массивом).
- **Где не поможет:** F и H — эталон одна случайная реализация (решатель даёт сглаженное среднее, LES — одну реализацию): нужен **вероятностный выход** (среднее + разброс), а не поле; несошедшиеся случаи — шумный эталон. **Проверено:** в SY-11 (`train/s7_data.py::select`, `ok_only`) из обучения и оценки исключаются только разошедшиеся (status 2, их 0); несошедшиеся (status 1, 11 % m / 9,5 % h) идут в обучение с целью «среднее поздних» (разброс 0,33 м/с медиана, до 2,5). Знание фазы позволяет их исключить или снизить вес — дешёвый опыт (одно переобучение), ожидаемый выигрыш небольшой на медиане (их 10 %), но заметный на хвосте p90.
- **Эксперты не обязаны быть сетями:** аналитика §12 + сеть-поправка; тогда сеть учит малую разность, данных нужно меньше (эксперту чистой фазы — меньше данных, чем универсальной сети, ср. кривую P3: −7 % на удвоение мест).

## 14. Свой эталон для каждого эксперта

Уточнение к «на околочистой конвекции решатель бесполезен»: численно он там сходится (с нагревом даже чаще: 9,5 % против 11,1 %), но по построению даёт сглаженное среднее с K-перемешиванием — термиков и их организации в полях нет (§6.1: конвективная добавка в w — 0,06–0,15 м/с СКО; асимметрия w не растёт с нагревом).

| фаза | эталон | замечания |
|---|---|---|
| A, B, D | Пикар (сходится: A < 1 %, D при Fr 0,3–0,5 — 85–90 %) | B — на окне 50–100 м с 2-м порядком; D — только сошедшиеся, с проверкой разброса |
| C | мелкая сетка, несколько стартов (A- и D-поле), флаг «ненадёжно» при расхождении ветвей | эталон — не одно поле, а пара ветвей + вероятность |
| E/F | LES (PALM, MicroHH, FastEddy — GPU), **статистика по нескольким реализациям**: среднее + σ_w(z), доля подъёмов, шаг, привязка к склонам | выход эксперта — среднее + статистика термиков (стык с масштабом 2 air_model) |
| G | LES с охлаждением или аналитика Прандтля + полевые измерения стоков [ZW13]: 1–4 м/с, 3–100 м | в поле игры — слой у земли |
| H | подобие (порывы, меандрирование) | эталона-поля нет |

**Сколько LES нужно.** Массовый набор не нужен и не нужна вся область 40 км: статистике слоя перемешивания хватает области 5–10 км при z_i 1–2 км и разрешения 20–50 м (стандарт LES CBL — область ~5 z_i), осреднения 1–2 ч; ошибка дисперсии ~√(2τ/T) [LMK94 — формула по памяти, библиография проверена] при интегральном масштабе τ ~ z_i/w* ≈ 10 мин и T = 2 ч даёт ~0,4 на одну точку, горизонтальное осреднение по области (L/ℓ)² снижает её на порядок — хватает нескольких реализаций на условие. Десятков случаев (сетка −z_i/L × h/z_i × крутизна × ориентация склона к солнцу) достаточно для статистики подобия над рельефом. Коды: PALM [Mar20] (GPU-порт [Kno18]), MicroHH [vH17] (CUDA), FastEddy [SM20] (резидентный на GPU).

**Ещё.** Учить на **кусках**, размеченных по локальному параметру порядка (окно 16–32 клетки с контекстом), а не на целых случаях — эксперту чистой фазы меньше данных, фазы в одном случае перемешаны. Переходные зоны — правило рычага или дообучение на переходных случаях (эталон — LES/мелкий Пикар). Разные выходы экспертов (поле; среднее + разброс; слой у земли) → игра принимает **не один массив ветра**, а набор слоёв: среднее поле, статистические параметры масштаба 2, приземный слой G — это уже совместимо с планом трёх масштабов. Распределитель учится отдельно (по разметке) или задаётся формулой.

## 15. Целевая архитектура: сборка поля по фазам в шейдерах GPU (без сети)

Если фазы выделены и для каждой есть механизм, поле ветра собирается честно в compute-шейдерах Godot (RenderingDevice; каркас `AirGpu`, `docs/guide/air-model-gpu.md`): в каждой клетке — свой механизм по её фазе. Сеть не обязательна.

### 15.1. Классификатор фаз по клеткам
Полностью параллелен (одно ядро 96×96 или 192×192): входы — рельеф h, максимум в окне (разделяемая память / mip-пирамида) → h_loc; U, N(z), z_i, Δθ инверсии → местные Fr, Fr_i, h/z_i; нагрев клетки H(x, y) (солнце по уклону и азимуту — уже есть, `surface_heating.gd`) → местный −z_i/L и знак; уклон по ветру → s. Выход — веса фаз w_φ ∈ [0, 1] на клетку (сигмоиды с шириной из опытов §9), сглаженные ядром 3–5 клеток (чтобы не было «шахматки»). 

### 15.2. Механизмы на GPU
| фаза | механизм | реализуемость |
|---|---|---|
| A | БПФ рельефа × передаточная функция (JH75/Sm80) по 13 уровням | БПФ в compute — своё ядро (radix-2/4 на 128², разделяемая память; БПФ в проекте нет — писать) или **DCT матричным умножением** (96×96×96 MAC на срез, ~10⁶ — тривиально, непериодичность решается сама, как P3) |
| B | огибающая по ветру (марш — последовательный по ветру, параллельный поперёк) + A по h_eff | марш — запуски ядра по срезам или одно ядро с барьерами |
| D | H_c; 2D Лаплас ψ на слой (13–32 слоёв) — Якоби/красно-чёрный Гаусс–Зейдель или **существующий V-цикл** (`AirMultigrid`, 7-точечный шаблон, маска — подходит и для 2D-слоёв как «3D с одним уровнем») | есть |
| E/F | источники по клеткам (нагрев, конвергенция) и статистика подобия (σ_w(z), доля, шаг) — поклеточно; среднее поле — баланс масс: подъём над склонами, компенсация (один Пуассон для потенциала или тот же V-цикл) | есть |
| G | сток по дереву (D8-подобный — последовательный): либо CPU на 96×96 (один раз на пересчёт), либо итеративное распространение на GPU (Якоби «накопление холода») | есть |
| C | существующий GPU-Пикар («Расчёт на GPU», `air_picard.glsl`): в C — и как рабочий механизм (на окне вокруг зоны C), и как эталон; флаг «ненадёжно» по итерациям/разбросу; два старта (A- и D-поле) — выбор ветви | есть |

### 15.3. Сшивка
Смешивание скоростей по весам u = ∑ w_φ·u_φ нарушает ∇·u = 0 на границах зон. Стандартное лечение — **один шаг проекции**: ∇²φ = ∇·u, u ← u − ∇φ (как в массосогласованных моделях [Ros88]). В проекте он уже есть: `AirMultigrid` / `air_mg.glsl` — V-цикл давления с маской (7-точечный шаблон, сходимость ~×20 за цикл, 3–5 циклов на шов); тот же `finalize` (10 V-циклов без изменения p) даёт ∇·u до округления. Проекция сохраняет вихревую часть смеси и правит только дивергентную — ровно то, что нужно на швах.

### 15.4. Время: фазы за день и гистерезис
Фазы меняются (утро G/D → день E/F → вечер G): пересчёт каждые 15 игровых минут (как сейчас) — классификатор + механизмы заново, веса фаз **сглаживаются во времени** (экспоненциальное окно ~15–30 мин) — плавная подмена; **гистерезис** — для бистабильных границ (C: ветви «волна/прыжок»; D↔A при проходе Fr через 0,4–0,6) вес ветви наследуется от предыдущего часа и переключается только при выходе параметра за полосу ±w (ширина из опытов §9). Утренний пробой инверсии: h/z_i растёт → D-слой тает снизу вверх — естественно в этой схеме (H_c от z_i).

### 15.5. Прозрачность и детерминизм
- **Прозрачность:** отладочный слой «карта фаз» (как F3-стрелки) — каждая клетка объяснима («здесь обход под инверсией», «здесь срыв»); соответствует «физика прежде всего»; калибровка AM-09 — по фазам, не одним множителем.
- **Детерминизм для сети:** поле масштаба 1 у каждого клиента своё и в ключ мира не входит (решение air_model) — так и остаётся; побитовое совпадение между разными GPU не гарантируется (float32, порядок редукций), но классификатор фаз и аналитика A/D/G — детерминированные арифметически простые ядра, расхождение между картами — на уровне ошибок округления (≪ ошибки модели); термики (масштаб 2) синхронизируются ведущим как сейчас. На CPU (запасной путь) те же формулы A/D/G считаются и без GPU — запасной путь становится **честнее нынешней аналитики**.

### 15.6. Сопоставление и рекомендация
| | сборка по фазам на GPU | смесь экспертов-сетей | один Пикар (сейчас) |
|---|---|---|---|
| физика/объяснимость | каждая клетка объяснима | чёрный ящик с масками | уравнения, но одно замыкание на всё |
| где честно | A, D, E/F (среднее+статистика), G | A, B, D при хороших эталонах | A, C, умеренное D |
| где нет | C (нужен Пикар/ветви), B (эмпирика) | F, H (вероятностный выход), C (двузначная цель) | F (нет термиков), H, D при Fr < 0,3, слабый ветер |
| данные для создания | опыты на идеальном рельефе (пороги, ширины) + литература | корпус SY-12 + LES для F + разметка | корпус уже есть |
| запасной путь без GPU | те же формулы на CPU | сеть на CPU | аналитика |
| риск | пороги по литературе неточны, швы | эталон шумный в 10 % случаев, ёмкость не главное (P2) | несходимость 10 %, слабый ветер |

**Рекомендация.** Целевая архитектура — сборка по фазам на GPU: она прямо следует из принципа «физика прежде всего», переиспользует готовые блоки (классификатор — тривиален; V-цикл для D-слоёв и для проекции швов — есть; Пикар для C — есть) и не требует корпуса. Сеть — не замена, а **поправка** к аналитике фазы (A/B/D), и только если опыт §9/H11 покажет, что аналитика + сопротивление массива оставляют > 0,3–0,5 м/с ошибки против Пикара. Смесь экспертов-сетей — запасной путь с теми же распределителем и эталонами. Первые шаги: (1) опыты §9 на идеальном рельефе (пороги, ширины, гистерезис — GPU); (2) прототип классификатора + A (DCT) + D (Лаплас по слоям) + проекция на Python/numpy против Пикара на корпусе SY-12 там, где Пикар сошёлся (CPU, по готовым данным) — это даёт H11 без GPU; (3) переобучение SY-11 без несошедшихся как дешёвая проверка «шумного эталона».
