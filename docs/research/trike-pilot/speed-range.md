# Диапазон скоростей дельталёта штангой (TP-17)

Вопрос (Q6, 2026-10-23): почему полная выборка штанги даёт ≈ 65 км/ч вместо `full_pull_speed_kmh` = 130 (`configs/wings/trike_ixess15.json`). Код игры, конфиги, тесты не менялись; правка — TP-18 по решению пользователя. Данные и команды — `tools/research/trike-pilot/`.

## Коротко
1. **65 км/ч — не скорость «выборки», а режим «полный газ на упоре»**: тяга задирает нос (θ ≈ +15…20°), скорость качается (4…190 км/ч), в среднем 69–76. На нуле газа на том же упоре — 81,5 км/ч.
2. **Ход штанги по TT-8 слишком мал для модели**: 0,1107 м от нуля ввода (3,7°) = +10 км/ч; модель набирает ≈ 1 км/ч на 1 см. Для 100 км/ч нужно 0,30–0,35 м, для 113–117 — 0,40–0,50 м (12–17°).
3. **У модели есть потолок ≈ 113–117 км/ч** (1,6–1,65·V_трим): при ходе ≥ 0,5 м равновесия нет, крыло кувыркается (при σ = 0 потолок 126 км/ч). 130 км/ч одним ходом штанги не получить.
4. **130 км/ч — не горизонтальная скорость этой тележки**: тяга Rotax 582 по таблице TT-К1 держит горизонт не выше **120,6 км/ч** (на 130 нужно 1134 Н, есть 942). Паспортные 130 ≈ Va 133 км/ч (HADS), она достижима со снижением.
5. По источникам правку чисел не вывести: углы хода штанги у реального дельталёта в открытых источниках не нашёл, Kn крыла — оценка. Развилка — пользователю (раздел «Варианты»).

## 1. Кривая сейчас
Модель: `PendulumModel`, крыло trike_ixess15, тележка 272,25 кг (TP-6), hang 1,71 м, CdA 0,82, тяга TT-К1 (`speed_sweep*.gd`, средние за 30 с после 45 с, ввод нарастает 20 с). Ход `pull` — на себя от нуля ввода, м; ввод 0 = планирование 71 км/ч (трим с тележкой).

|---|---|---|---|

| 0 | 71,0 (2,64) | 65,2 (набор 1,4) | 98,6 (кач. 51–148) |

- Наклон ≈ 1,0–1,05 км/ч на см во всех режимах.
- При полном газе и малом ходе штанга не держит: нос поднимается до 15–20°, фугоида с размахом 50–150 км/ч не затухает за 75 с. Это то, что TP-6 записал как «≈ 18 м/с на упоре» — среднее по колебанию.
- Нулевой ввод (трим с тележкой) 71 км/ч при g = 0, 65 км/ч при g = 0,5: тяга сдвигает равновесие вниз по скорости.

## 2. Что говорят источники
- BMAA HADS HM16 issue 7 (Tanarg / iXess 15): Vso 32 kt (59 км/ч), **Va 72 kt (133 км/ч)**, Vne 89 kt (165), VDF 99 kt (183). Параметр `full_pull_speed_kmh` = 130 ≈ Va 133 ≈ 0,8·Vne (131,8): как скорость при полном отклонении штанги число разумно, но это **скорость, разрешённая для полного хода управления, а не измеренная скорость полной выборки на 582**.
- Wikipedia (Tanarg, 912ULS 100 л.с.): max 157, cruise 135, stall 55 км/ч. **Skypper на 582: max 125 км/ч**. 582 (48 кВт) в горизонте слабее: наш расчёт 120,6 км/ч (`level_speed.json`, поляра TT-1 + CdA 0,82 м² + таблица тяги, диапазон ±10 %).
- Руководства (FAA-H-8083-5, HADS) числа хода штанги и угла крыла к тележке не дают; **углов хода штанги у реального трайка в открытых источниках не нашёл**. Качественно (FAA-H-8083-5, WSC): штанга на себя — нос вниз, скорость растёт; газ даёт набор/снижение, нос поднимается с газом.

## 4. Варианты (решение пользователя)
Подгонкой это не закрыть: источников на ход штанги и Cm(α) трайкового крыла нет. Тяга и поляра ограничивают горизонтальную скорость 120 км/ч в любом случае.
- **A. Оставить геометрию TT-8, поправить число.** `full_pull_speed_kmh` = модельное: ≈ 82 км/ч без газа (на упоре), 130 оставить только как Va для крыла (описание/предел). Буксировщик не задет. Честно, но игрок на «выборке» не разгонится.
- **B. Расширить ход «на себя» для игрока (≈ 0,45 м, как «добор» VM-К3, `shift_x_pull_full`).** Ожидаемая кривая g = 0,5: 0,3 м → 94, 0,4 → 105, 0,5 → 117 км/ч (горизонт 100–110 при g ≈ 0,7–1). Тело в трапеции TT-8 в этом диапазоне не помещается (бросается в глаза в виде руки): визуал TP-8 покажет это. Автопилот буксировщика: `bar_min_m` −0,1107, ход u в метрах — его скорость 55–65 км/ч лежит по ту сторону нуля (pitch +0,5…+0,7 от себя), не задет.
- **C. B + мягче Cm(α) (σ ≈ 0,25 для trike_ixess15):** 0,3 м → 102 км/ч, 0,4 м → 119 км/ч; потолок ~120 км/ч совпадает с потолком тяги. σ в `configs/pendulum.json` общий на парк; отдельное значение — оценка без источника.
- **D. Принять 120 км/ч как горизонтальный потолок 582** и 130 — только в снижении (Va): не искать сквозного числа.

Рекомендация: **D + A как основа** (честные 120/82 при геометрии TT-8), B/C — если пользователь хочет, чтобы выборка действительно разгоняла до 110–120 ценой телесной геометрии. Прежде чем менять числа, у пользователя (пилота-эксперта) стоит спросить реальный ход штанги на Air Creation (угол вверх по стойке от трима до груди) и скорость трима iXess 15 на 582: оба — не в открытых источниках.

## 5. Допущения и границы
- Замер: установившееся среднее; при полном газе и ходе < 0,3 м равновесия нет (размах vmin–vmax в `speed_curves.json`), цифра — условная.
- Пилот держит штангу без ограничения силы (5000 Н); при 500 Н потолок может быть ниже — не прогонялось.
- Потолок 117 км/ч — свойство модели Cm(α), не измеренное; σ 0,25/0 — чувствительность, не калибровка.
- Горизонт на 582: тяга по TT-К1 (Ct0 с FM 0,6, ±15 %), CdA тележки 0,82 (±30 %), поляра ±15 %; на 130 км/ч значение тяги — экстраполяция таблицы (последняя точка 35 м/с = 126 км/ч).
- Масса 272,25 кг (TP-6); для 262,5 кг (буксировщик) потолок тот же 120,6.
- Не проверено: поведение с `pull_full`, с кабиной/видом TP-8, ветер, плотность по высоте.
