# Колёса дельталёта: руление, тормоз, посадка (TP-К7)

Результат - блок `wheels` в `configs/trike_pilot.json` (TP-К1 v3), модель - `PendulumModel.reset_on_wheels` с необязательными ключами
`wheelbase_m`, `steer_max_deg`, `lat_mu`, `brake_mu`, `land_on_wheels`. Без ключей модель - TT-К3 бит в бит (проверено: числа
через 14 с разбега и отрыва совпадают с коммитом до правки).

## Руление

Кинематика велосипеда: `dpsi/dt = v*tan(turn*steer_max)/wheelbase`, `turn` в [-1; 1], +1 - вправо (курс по часовой).
Предел шин: `|v*dpsi/dt| <= lat_mu*g`. Курс крыла = курс связки. На месте (v = 0) не поворачивает, заднего хода нет.

- `wheelbase_m` = 1,8 - `tools/blender/trike_params.json` (схема пилота, прототип Airborne XT912 - 1,89).
- `steer_max_deg` = 35 - оценка (25-45), источника по трайкам нет. Минимальный радиус `wheelbase/tan(35)` = 2,6 м.
- `lat_mu` = 0,4 - оценка (0,3-0,5), порядок трения шины по твёрдому дёрну (Raymer, Aircraft Design, таблица коэффициентов
  трения полосы: по памяти, не перепроверено). Радиус на 15 м/с не менее `v^2/(lat_mu*g)` = 57 м.
- Следствие: при 35 градусах предел шин начинает работать с `v = sqrt(lat_mu*g*wheelbase/tan(steer))` = 3,2 м/с; быстрее руль
  поворачивает колесо на 35 градусов, а машина идёт по пределу сцепления (скользит носовое колесо). Для контрактной проверки
  "v = 5 м/с - формула +-5 %" использована формула вместе с пределом; чистая формула проверена на 2,5 м/с.

## Тормоз

Замедление `brake_mu*N/m` в добавок к качению (`rolling_crr*N/m`), до нуля, не назад. `brake_mu` = 0,3 - оценка (0,2-0,4),
твёрдый дёрн/грунт (Raymer, по памяти). Остановка с 10 м/с без тяги: `v^2/(2*(brake_mu+crr)*g)` = 13,8 м; в модели 14,7 м
(+6 %: аэродинамика уменьшает прижим N, тормозит только аэродинамическое сопротивление).

## Посадка на колёса

Касание низом колёс (`land_on_wheels`) возвращает режим колёс (`phase()` = "wheels"), `landed(result)` с `on_wheels: true`,
`grade` "soft", `touchdown` "wheels"; аварии нет при любой вертикальной скорости (вертикальная скорость остаётся в результате:
`vertical_speed_ms`).

Границы модели:
- Вертикальная и боковая скорость гасятся мгновенно (скорость связки - проекция на курс), крыло и тележка скачком
  принимают положение на колёсах (крен 0, подвеска по нормали); тангаж крыла `_wh_pitch` берётся из тангажа в момент касания.
- Касание крылом (нос, консоль) раньше колёс обрабатывается как раньше: авария.
- На трим-скорости крыло с килем 10 градусов несёт вес, поэтому колёса не держат тележку без добора "на себя" (pitch -1)
  и тормоза: возможен повторный отрыв.
