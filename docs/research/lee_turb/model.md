# Модель слоя смешения за гребнем (LT-5)

Задача LT-5 (lee-turb): спецификация и Python-прототип для пути с полем. Входы: числа LTL
(`tools/research/lee_turb/lit/lit_numbers.csv`, выводы — `docs/research/lee_turb.md`), нынешняя модель и её
разрезы — `docs/research/lee_turb/baseline.md` (LT-2). Константы — `spec.json` (формат `ltm-spec` v1; каждая:
`ltl` — id строк LTL, `derived` — формула из A/C-строк, или `assumption` — явное допущение). Онгудай — только
проверка, константы под него не подбирались. Измерений за гребнем (LTO, LT-3) на этой ветке ещё нет — **сверки
с натурой здесь нет**; сравнение «прежняя / новая» — по разрезам LT-2 (LTS v1, ~/data/lee_turb/lts_baseline, вне git).

## 1. Что не так сейчас (из LT-2, коротко)
На пути с полем (доля поля 1) ΔU слоя смешения = 0, рывки и масштаб слоя выключены; болтанку за гребнем даёт
механическая ветвь l·|∂U/∂z| с максимумом у гребня (x/H 0,5–1) и спадом к x/H 4–6 до 0,5–0,56 притока. Поле на
50 м даёт пузырь в 4–5 раз короче литературного, на 100/400 м — не даёт.

## 2. Модель

Оси: x — от гребня по ветру, y — высота MSL, H — превышение гребня над подветренным подножием, λ = (U1−U2)/(U1+U2).

**(1) Где слой есть.** Признак из поля (lee_f) не годится: на клетках 100/400 м lee_f = 0 при очевидном следе
(LT-2: U10 за гребнем 4–5 м/с против 8 в притоке). Критерий — геометрический, из рельефа: уклон линии гребень —
точка присоединения `s_lee = (h_гребня − h(x_r))/x_r`; `f_sep = smoothstep(0,128; 0,22; s_lee)`. Пороги — tan 7,3° и
tan 12,4° (угол появления зоны решателя для хребта и холма, `configs/atmosphere.json: lee.shadow_angle_deg_doc`, AP-10).
**Это допущение, не LTL**: критерия отрыва для гладкого холма в LTL нет. На пологом склоне (уклон < 0,13) слоя нет
(проверено в selftest). Все 6 гребней Онгудая имеют s_lee = 0,20–0,29 → f_sep 0,92–1,0: проверка «пологий склон»
на реальном рельефе не проведена, только синтетически.

**(2) Гребень и H.** От точки идём против ветра (16 опросов высоты земли по 50 м до 800 м, 24 по 100 м до 3200 м),
гребень — последний максимум до падения земли ниже `max(30 м, 0,25·(h_max − h_точки))` (бугры на подветренном
склоне — не гребень). H = h_гребня − min(h) на 1500 м по ветру от гребня (как Menke 2019 и LT-2). Одно H на
гребень (кэш по гребню), не «текущий перепад». За подножием, на наветренном склоне следующей возвышенности, гребня
против ветра нет — слоя нет (так слой обрывается: у a50_west при x/H > 4,3).

**(3) Длина пузыря.** x_r = L поля (первая область u < 0 на 15 м над землёй за гребнем + расстояние до присоединения),
если L/dx ≥ 8; ниже 4 клеток — `x_r = 3,5·H` (`ridge_xr_over_h`, Perdigão 697 м / H ≈ 200 м; разброс 2–5; гайд
берёт 2,8 — этой строки нет в LTL); между — линейное смешение. В Онгудае пузырь в поле не разрешён ни на одном из 18
разрезов (≤ 3,5 клеток), поэтому везде x_r = 3,5H. Чувствительность к x_r = 2,8H / 5H — таблица T4.

**(4) Линия слоя.** `y_c(x) = max( h_гребня − (h_гребня − h(x_r))·x/x_r , h(x) + 0,3H·min(x/x_r, 1) )`: прямая
от гребня к точке присоединения на земле; пол 0,3H над землёй — y/H пика σ_u на уступе при x/H = 6 (`ds_y_tke_max`,
для x/x_r = 0,64 — 0,4; прямая даёт 0,36). Угол линии — 16–20° (Perdigão 19,7° в guide).
Поле: в LT-2 центр слоя поля держится у уровня гребня (+9, −1, −43 м на x/H 1, 2, 4), прямая же даёт −10, −50, −140:
**расхождение**, поле на 50 м слой недооценивает (см. §5).

**(5) Толщина.** `δ_ω(x) = 0,30H + 0,17·λ·(min(x, x_b) + 0,57·max(x − x_b, 0))`, x_b = 0,64·x_r. 0,17 — среднее
BR74 (0,181), Delville (0,168), MW85 (0,16); 0,30H и 0,57 — из профилей уступа (δ_ω/H = 0,48 / 1,02 / 1,23 при
x/H = 1 / 4 / 6; наклоны 0,181 и 0,104). Начальная δ0 = 0,30H — линейное продолжение к x = 0; для гладкого гребня
она не проверена (холм δ_ω в LTL нет). Рост за x_r — допущение (то же замедление).

**(6) U1, U2.** U1 = u_par поля на уровне гребня в той же колонке (U_H поля). U2 — в следе: если пузырь разрешён,
поле на 0,1H над землёй (`ds_uback` измерен на y/H = 0,1), с нижним пределом −0,17·U1; иначе U2 = −0,10·U1 (середина
−0,171 … −0,035 уступа). ΔU = U1 − U2, λ ≤ 1. **Поле в Онгудае пузыря не разрешает** (≤ 3,5 клеток), поэтому U2 = −0,10·U1 — решение модели. Само поле на 0,1H над
землёй показывает след, но слабее: при x/H 2–4 u = 0…4 м/с при U1 = 6–10 м/с в окнах 50/100 м (ΔU поля 5–9 м/с) и
4–6 м/с в клетках 400 м (ΔU 3–5 м/с); модель берёт ΔU = 1,1·U1 (≈ 7–11 м/с): +20–30 % к полю на 50/100 м и ×2 на 400 м.
Чувствительность — T4 («U2 по полю»: максимумы σ_w −0…−12 %, слой в c400 слабеет).

**(7) Профиль σ.** `σ_i = f_sep·a_i·ΔU·g_x(x)·exp(−η²/2)`, η = (y − y_c)/(0,49·δ_ω); a_u,v,w = 0,166 / 0,130 / 0,153
(Delville, пики; разброс по x 0,154–0,166 / 0,096–0,130 / 0,121–0,153). 0,49 = 0,5/√(−2 ln 0,596) по `del_su_prof_half`.
Число 0,14 из guide — расхождение: измерено σ_w/ΔU = 0,153 (A), σ_v = 0,130. σ_u у слоя на уступе 0,181·U_ref даёт
a_u·ΔU при U2 = −0,1·U1 (0,166·1,1 = 0,183).
`g_x = (1 − exp(−x/(0,15·x_r)))·exp(−max(x − 0,64·x_r, 0)/(2,0·x_r))`: нарастание (σ_u уступа x/H = 1 к x/H = 4:
0,118 / 0,181 → ξ = 0,15·x_r), максимум около 0,64·x_r (`ds_x_tke_max`, холм 0,25–0,56) и затухание (МНК по
x/H = 6, 10: 2,0·x_r; холм затухает медленнее, 4–9·x_r).

**(8) Длина перемешивания и сложение.** В слое −u′v′ = l²(∂U/∂z)², пик ∂U/∂z = ΔU/δ_ω, −u′v′ = 0,0118·ΔU² ⇒
l ≤ 0,109·δ_ω. Механика σ ∝ u* ∝ l: `l_эфф = l(1−w) + min(l, 0,109δ_ω)·w`, w = f_sep·(1 − e^{−x/(0,15x_r)})·exp(−η²/2);
σ_мех,нов = σ_мех·l_эфф/l (в прототипе l = 1/(1/κz + 1/40 м), в игре l есть). Слой и механика: **максимум**
(`σ = max`): l-ограниченная механика — то же производство от сдвига, сумма квадратов удвоила бы его. Корень из суммы
квадратов дал бы +4…+25 % (T4). Конвективная ветвь не трогается.
Ограничение l работает только там, где 0,109δ_ω < l: у стенки (l ≈ z ≤ 25 м при δ_ω ≥ 100 м) оно не бьёт —
**стенка остаётся главным источником у гребня** (§4).

**(9) Масштаб.** L_u = L_w = 0,48·δ_ω: шаг вихрей 3,3δ_ω (BR74, A) делится на 6,87 — отношение длины волны пика
k·S к L у спектра фон Кармана в guide. Метка C: L_u и L_w слоя в открытых источниках не найдены, одинаковость — допущение.

**(10) Перенос.** U_c = (U1 + U2)/2 — допущение BR74, измеренной нет.

**(11) Рывки вниз.** Часть σ_w слоя, нулевое среднее: амплитуда 3σ_w,слоя (пик 3σ; в коде сейчас 0,42ΔU =
3·0,14ΔU), её доля вычитается из гауссовой части, как сейчас. Растёт вместе с g_x и профилем.

**(12) Цена на точку для `dp-air`.** Поиск гребня: 40 опросов высоты земли; подножие (31) и h(x_r) (1) — один раз на
гребень (кэш по гребню и направлению ветра, обновление при смене ветра); поле — 2 опроса столбца (U1, U2) +
опрос u на 15 м над землёй вдоль луча при проверке пузыря (один раз на гребень: до ~40 опросов столбца). Прежний
`relief_at` — 6 опросов земли; поиск гребня дороже в ~7 раз без кэша — кэшировать по ячейке (x, z, направление) надо.

## 5. Сравнение формы с уступом и холмом (T5)

Нормированные оси (x/H, x/x_r), λ-модель при U2 = −0,1·U1, f_sep = 1. Для уступа форма **подогнана** по тем же строкам
(`ds_*`: δ0, ξ, 0,57, L = 2,0 — вычислены из этих чисел, это не независимая проверка): amplitudes 0,118 / 0,181 / 0,144 /
0,116 против 0,120 / 0,180 / 0,156 / 0,114 — отклонение на x/H = 6 (+8 %). Холм (Rapp–Manhart, Re 10 600) — независимая
проверка формы: модель **вдвое слабее по амплитуде** (0,10–0,18 против 0,32–0,20 u_b) и затухает быстрее (0,18 → 0,09
против 0,30 → 0,20 за x/h 2 → 8). Причины: у холма σ нормирована на u_b, не на ΔU (канал 3,036h, кривизна линий тока,
периодичность); ΔU, измеренный на холме, в LTL нет. Модель, проверенная на плоском слое и уступе, **не воспроизводит**
холм без отдельного множителя — подгонять не стал (шлюз: нужен ли множитель по форме гребня; см. `uncertain`).

## 6. Чего модель не умеет / чувствительность

- **Нестационарность и рывки по месту**: σ даёт стационарный профиль; рывки — по существующему шуму, привязка только по амплитуде.
- **Поле не даёт слоя**: ΔU, U2 и линия слоя берутся не из поля, а из моделей (U2 = −0,1·U1, прямая к x_r). Поле на 50 м
  имеет центр слоя у уровня гребня (+9 → −43 м на x/H 1 → 4), прямая даёт −10 → −140: если поле право, y_c завышена
  вниз на ~100 м у x/H 4. Проверка — LT-3/LT-4.
- **Критерий присутствия** (s_lee) — допущение из конфига, не из LTL; Perdigão: зона в 52 % периодов — модель
  ветер-независима (кроме U1), устойчивость (Ri) не учитывает.
- **U2/ΔU**: модель, не поле (см. (6)); при U2 из поля слой слабее на 400 м (T4).
- **x_r = 3,5H** — единственное число для всех гребней; разброс 2–5 (T4: для a50/b100 максимум не меняется,
  для c400_a при 5H уходит к x/H 8,4 на 140 м — зона слоя вне окна метрики; для c400_b 5,1).
- **Гладкий холм**: δ0, замедление роста, затухание — по уступу.
- **Закрытые источники** (Bell–Mehta, Pope §5.4, Castro–Haque): цифры только из открытых данных LTL.
- **Две вертикальные оси**: профиль берёт вертикальное расстояние до линии слоя, не нормаль (наклон линии 16–20°, ошибка cos ≈ 4–6 %).
- **σ_u, σ_v**: считаны формулой, но T-таблицы приводят только σ_w; σ_u без пересчёта l_ограничения (та же формула).
