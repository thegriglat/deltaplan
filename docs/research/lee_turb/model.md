# Модель слоя смешения за гребнем (LT-5, LT-6, LT-7)

Задача LT-5 (lee-turb): спецификация и Python-прототип для пути с полем. Входы: числа LTL
(`tools/research/lee_turb/lit/lit_numbers.csv`, выводы — `docs/research/lee_turb.md`), нынешняя модель и её
разрезы — `docs/research/lee_turb/baseline.md` (LT-2). Константы — `spec.json` (формат `ltm-spec` v1; каждая:
`ltl` — id строк LTL, `derived` — формула из A/C-строк, или `assumption` — явное допущение). Онгудай — только
проверка, константы под него не подбирались. Сверка с натурой (мачты Perdigão, Askervein) — в
`docs/research/lee_turb/model_obs.md` (LT-6); здесь — формулы и сравнение «прежняя / новая» по разрезам LT-2
(LTS v1, ~/data/lee_turb/lts_baseline, вне git). **Правки LT-6**: (1) s_lee, (2) H и число опросов, (3) x_r и поиск u<0, (7) ξ, (8) вариант B; **правки LT-7 (решение пользователя Q1)**: (4) линия слоя — центр слоя поля или глубина пузыря,
(8) B только под линией, (12) стоимость z½, §4 пересчитан (старые таблицы LT-5 удалены).

## 1. Что не так сейчас (из LT-2, коротко)
На пути с полем (доля поля 1) ΔU слоя смешения = 0, рывки и масштаб слоя выключены; болтанку за гребнем даёт
механическая ветвь l·|∂U/∂z| с максимумом у гребня (x/H 0,5–1) и спадом к x/H 4–6 до 0,5–0,56 притока. Поле на
50 м даёт пузырь в 4–5 раз короче литературного, на 100/400 м — не даёт.

## 2. Модель

Оси: x — от гребня по ветру, y — высота MSL, H — превышение гребня над подветренным подножием, λ = (U1−U2)/(U1+U2).

**(1) Где слой есть.** Признак из поля (lee_f) не годится: на клетках 100/400 м lee_f = 0 при очевидном следе
(LT-2: U10 за гребнем 4–5 м/с против 8 в притоке). Критерий — геометрический, из рельефа: уклон линии гребень —
подножие `s_lee = H/x_foot` — средний уклон гребень → подножие (минимум рельефа на 1500 м по ветру), **только по рельефу,
не через x_r** (LT-6; прежнее `(h_гребня − h(x_r))/x_r` при неразрешённом пузыре ≤ H/x_r по построению); `f_sep = smoothstep(0,128; 0,22; s_lee)`. Пороги — tan 7,3° и
tan 12,4° (угол появления зоны решателя для хребта и холма, `configs/atmosphere.json: lee.shadow_angle_deg_doc`, AP-10).
**Это допущение, не LTL**: критерия отрыва для гладкого холма в LTL нет. На пологом склоне (уклон < 0,13) слоя нет
(проверено в selftest). Гребни Онгудая: s_lee = 0,20–0,29 → f_sep 0,90–1,0, кроме a50_focus (s_lee 0,16, f_sep 0,33: подножие далеко, средний
уклон мал; раньше через x_r было 0,97). Реальный пологий случай — Askervein: s_lee 0,15 → f_sep 0,15, слой почти не включается
(model_obs.md).

**(2) Гребень и H.** От точки идём против ветра (17 опросов по 50 м до 800 м включительно, 24 по 100 м до 3200 м),
гребень — последний максимум до падения земли ниже `max(30 м, 0,25·(h_max − h_точки))` (бугры на подветренном
склоне — не гребень). H = h_гребня − min(h) на 1500 м по ветру от гребня, x_foot — расстояние до этого минимума (одно определение для модели
и данных; LT-2 использовал то же). Для Perdigão по DSM вдоль оси мачт: NE 149,5 м, SW 178,4 м (по мачтам 147,6 / 167,7), Askervein 112,5 м (116 по карте).
Опросов высоты: **41** на точку (17 по 50 м, 0…800 включительно, + 24 по 100 м, 900…3200); подножие (31) и h(x_r) (1) — один раз на гребень. Одно H на
гребень (кэш по гребню), не «текущий перепад». За подножием, на наветренном склоне следующей возвышенности, гребня
против ветра нет — слоя нет (так слой обрывается: у a50_west при x/H > 4,3).

**(3) Длина пузыря.** x_r = L поля (первая область u < 0 **на нижнем уровне поля, 25 м над землёй** — не ниже первой клетки, LT-6; в LT-5 было 15 м,
т. е. ниже поля) за гребнем + расстояние до присоединения, если L/dx ≥ 8; ниже 4 клеток — `x_r = 4,25·H`
(`ridge_xr_over_h` = 697 м / ⟨H⟩ = 697 / 164 м, ⟨H⟩ — среднее H модели по NE и SW Perdigão; по H мачт 4,42; NE 4,66, SW 3,91);
между — линейное смешение. **Одно H**: 3,5 из LT-5 — это 697/200 м (200 м — «от дна долины до вершины» у Menke 2019 разд. 2.1),
2,8 из guide и configs (`field_bubble_length_per_relief_doc`) — 697 м / «h ≈ 250 м»: в тексте Menke 250 м — высота следа над
NE-гребнем (разд. 4.3.1), а высота гребня числом дана только в табл. 2 (картинка); значение 250 м как H подтверждения не нашло.
В игре H считается по (2), поэтому единственное согласованное значение — 4,25 (разброс 3,9–4,7). Для Askervein по LTL `hill_xr` ≈ 4,0.
В Онгудае пузырь в поле не разрешён ни на одном из 18 разрезов (≤ 3,5 клеток): везде x_r = 4,25H. Чувствительность к x_r = 2,8H / 5H — T4.

**(4) Линия слоя (LT-7, Q1).** `y_c(x) = q(x)·z½(x) + (1 − q(x))·y_запас(x)`, MSL.

*Центр по полю.* Столбец поля в точке: U1 = u_par на уровне гребня, U2 = u_par на 0,1H над землёй. z½ — высота, где u = U2 + ½(U1 − U2) (деление пополам 6 раз,
точность (h_c − y0)/64 = 2–6 м; все опросы — по столбцу). Поле «даёт слой» (q → 1), если одновременно (гладкие множители, произведение): (а) дефицит `(U1−U2)/U1`
≥ 0,5 (smoothstep 0,4…0,6) — тот же признак, что «начало дефицита u₁₀ < ½ притока» в LT-2 п.4; (б) профиль монотонен: падение u вверх по столбцу от бегущего максимума ≤ 0,1·U1
(гладко до 0,2·U1) — иначе струя у земли или шум, не слой; (в) z½ выше земли не менее чем на 2 вертикальные клетки (smoothstep 1…3) — иначе максимум сдвига у стенки: LT-2 п.5, на клетке 400 м
максимум ∂U/∂z у стенки в 65–100 % колонок; (г) U1 ≥ 1 м/с (smoothstep 1…2), как условие слоя. Пороги (а)–(в) — допущения `spec.json` (0,5 по LT-2; ширины переходов выбраны, не подбирались; чувствительность не считалась).
В верхней точке z½ ограничено [земля, уровень гребня].

*Запасная линия — глубина пузыря.* Где поле слоя не даёт: `y_запас = max( foot + H·(1 − min(x/x_r, 1)^m), g(x) + 0,3H·min(x/x_r, 1) )`. Верх пузыря — над подножием, как у Menke (глубина «над дном долины»):
среднее по 0 < x < x_r равно `m/(m+1)` = D = `ridge_depth_mean` / ⟨H⟩ = 157 / 163,95 = 0,958 ⇒ m = D/(1−D) = **22,6**. Центр слоя остаётся у уровня гребня до ~0,9·x_r, затем быстро спускается к полу 0,3H (пол — `ds_y_tke_max`,
уступ x/H = 6). Источники формы: **глубина — Perdigão** (LTL `ridge_depth_mean`; максимумы глубины 189–300 м > H, т. е. верх зоны местами выше гребня), **форма — холм** Rapp–Manhart (`hill_ypk`: пик σ_u на 0,91–1,06h на x/h 0,5–4, T5),
не уступ: у уступа (`ds_y_tke_max`) центр 0,4H уже на x/x_r = 0,64, запасная линия его там не воспроизводит (1,0 против 0,4, T5). Чувствительность к D: при D = 0,88 (H = 178 м) m = 7,3.
Прежняя линия LT-5 (прямая гребень → точка присоединения) оставлена режимом `yc_mode="lt5"` для сверки.
Переход поле / запас гладок по q: q — произведение гладких функций дефицита, немонотонности и высоты центра, меняется по x с полем; в `dp-air` значения кэшируются по столбцам клетки и интерполируются по x.
Угол запасной линии не задан: линия почти горизонтальна до ~0,9 x_r.

**(5) Толщина.** `δ_ω(x) = 0,30H + 0,17·λ·(min(x, x_b) + 0,57·max(x − x_b, 0))`, x_b = 0,64·x_r. 0,17 — среднее
BR74 (0,181), Delville (0,168), MW85 (0,16); 0,30H и 0,57 — из профилей уступа (δ_ω/H = 0,48 / 1,02 / 1,23 при
x/H = 1 / 4 / 6; наклоны 0,181 и 0,104). Начальная δ0 = 0,30H — линейное продолжение к x = 0; для гладкого гребня
она не проверена (холм δ_ω в LTL нет). Рост за x_r — допущение (то же замедление).

**(6) U1, U2.** U1 = u_par поля на уровне гребня в той же колонке (U_H поля). U2 — в следе: если пузырь разрешён,
поле на 0,1H над землёй (`ds_uback` измерен на y/H = 0,1), с нижним пределом −0,17·U1; иначе U2 = −0,10·U1 (середина
−0,171 … −0,035 уступа). ΔU = U1 − U2, λ ≤ 1. **Поле в Онгудае пузыря не разрешает** (≤ 3,5 клеток), поэтому U2 = −0,10·U1 — решение модели. Само поле на 0,1H над
землёй показывает след, но слабее: при x/H 2–4 u = 0…4 м/с при U1 = 6–10 м/с в окнах 50/100 м (ΔU поля 5–9 м/с) и
4–6 м/с в клетках 400 м (ΔU 3–5 м/с); модель берёт ΔU = 1,1·U1 (≈ 7–11 м/с): +20–30 % к полю на 50/100 м и ×2 на 400 м.
Чувствительность — T4 («U2 по полю»: максимумы σ_w −0…−12 %, слой в c400 слабеет).

**(7) Профиль σ.** `σ_i = f_sep·a_i·ΔU·g_x(x)·exp(−η²/2)`, η = (y − y_c)/(0,49·δ_ω); a_u,v,w = 0,166 / 0,130 / 0,153
(Delville, пики; разброс по x 0,154–0,166 / 0,096–0,130 / 0,121–0,153). 0,49 = 0,5/√(−2 ln 0,596) по `del_su_prof_half`.
Число 0,14 из guide — расхождение: измерено σ_w/ΔU = 0,153 (A), σ_v = 0,130. σ_u у слоя на уступе 0,181·U_ref даёт
a_u·ΔU при U2 = −0,1·U1 (0,166·1,1 = 0,183).
`g_x = (1 − exp(−x/(ξ·x_r)))·exp(−max(x − 0,64·x_r, 0)/(2,0·x_r))`: нарастание (σ_u уступа x/H = 1 к x/H = 4:
0,118 / 0,181 → ξ = 0,151, **при постоянном ΔU**: в отношении 0,652 уже сидит рост ΔU уступа (ds_uback −0,035 → −0,171, ΔU/U_ref
1,035 → 1,171); при ΔU по полю (пузырь разрешён) нарастание = σ/ΔU: 0,114 → 0,155, ξ = 0,120, ξ = (1−r)·0,151 + r·0,120, r — доля разрешённого пузыря), максимум около 0,64·x_r (`ds_x_tke_max`, холм 0,25–0,56) и затухание (МНК по
x/H = 6, 10: 2,0·x_r; холм затухает медленнее, 4–9·x_r).

**(8) Длина перемешивания и сложение.** В слое −u′v′ = l²(∂U/∂z)², пик ∂U/∂z = ΔU/δ_ω, −u′v′ = 0,0118·ΔU² ⇒
l ≤ 0,109·δ_ω. Механика σ ∝ u* ∝ l: `l_эфф = l(1−w) + min(l, 0,109δ_ω)·w`, w = f_sep·(1 − e^{−x/(0,15x_r)})·exp(−η²/2);
σ_мех,нов = σ_мех·l_эфф/l (в прототипе l = 1/(1/κz + 1/40 м), в игре l есть). **LT-6/LT-7, вариант B (model_obs.md), только под линией:** в области отрыва модели при неразрешённом пузыре механика от сдвига поля у стенки заменяется фоном притока (поле там течёт «прикреплённо»; в LTL
σ у стенки в рециркуляции нет — допущение; u:v:w = 2,5² : 1,9² : 1,25²): `σ_мех,B = (1 − w_B)·σ_мех + w_B·σ_фона`, `w_B = (1 − r)·f_sep·ramp(x)·Φ(−η)·(1 − smoothstep(1−a, 1+a; x/x_r))`, a = 0,25 (допущение:
плавный конец у присоединения), Φ — нормальная функция распределения, r — доля разрешённого пузыря. Выше линии (η > 0) механика поля или гребня не меняется, на линии w_B = ½·f_sep·ramp, гладко по η и x (в LT-6 B стоял на весь столбец 0 < x < x_r).
Затем max(σ_мех,B с l_эфф, σ_слоя). Слой и механика: **максимум**
(`σ = max`): l-ограниченная механика — то же производство от сдвига, сумма квадратов удвоила бы его. Корень из суммы
квадратов дал бы +4…+25 % (T4). Конвективная ветвь не трогается.
Ограничение l работает только там, где 0,109δ_ω < l: у стенки (l ≈ z ≤ 25 м при δ_ω ≥ 100 м) оно не бьёт —
**стенка остаётся главным источником у гребня** (§4).

**(9) Масштаб.** L_u = L_w = 0,48·δ_ω: шаг вихрей 3,3δ_ω (BR74, A) делится на 6,87 — отношение длины волны пика
k·S к L у спектра фон Кармана в guide. Метка C: L_u и L_w слоя в открытых источниках не найдены, одинаковость — допущение.

**(10) Перенос.** U_c = (U1 + U2)/2 — допущение BR74, измеренной нет.

**(11) Рывки вниз.** Часть σ_w слоя, нулевое среднее: амплитуда 3σ_w,слоя (пик 3σ; в коде сейчас 0,42ΔU =
3·0,14ΔU), её доля вычитается из гауссовой части, как сейчас. Растёт вместе с g_x и профилем.

**(12) Цена на точку для `dp-air`.** Поиск гребня: 41 опрос высоты земли (17 + 24); подножие (31) и h(x_r) (1) — один раз на гребень (в `n_queries` кода 72 = 41 + 31, h(x_r) отдельно)
(кэш по гребню и направлению ветра). Поле: U1 и U2 — 2 опроса столбца (нужны слою и так) **+ 6 опросов деления пополам для z½ = 8 опросов столбца**; на одну клетку вдоль ветра (dx) —
один набор (кэш по столбцу и гребню; дальше интерполяция по x между соседними столбцами), т. е. в кадре на точку 0 новых опросов при попадании в кэш, при промахе 8 (+ 41 + 32 при смене гребня); плюс опрос u на 25 м над землёй
вдоль луча при проверке пузыря (раз на гребень, до ~40). Прежний `relief_at` — 6 опросов земли. Без поля (мачты, штатная работа без поля) опросов столбца нет.

## 5. Сравнение амплитуды с уступом и холмом

Для уступа форма **подогнана** по тем же строкам (`ds_*`: δ0, ξ, 0,57, L = 2,0 — вычислены из этих чисел, не независимая проверка): σ_u/U_ref 0,118 / 0,181 / 0,144 / 0,116 против 0,120 / 0,180 / 0,156 / 0,114 (x/H 1, 4, 6, 10) —
x/H = 6 на +8 %. Холм (Rapp–Manhart, Re 10 600) — независимая проверка формы: модель **вдвое слабее по амплитуде** (0,10–0,18 против 0,32–0,20 u_b) и затухает быстрее. Причины: у холма σ нормирована на u_b, не на ΔU;
ΔU холма в LTL нет. Амплитудный множитель для холма не вводился (LT-6: на мачтах Perdigão избыток над фоном = 0,78 амплитуды уступа). Таблица LT-5 не пересчитана (слой не менялся): LT-5, T5 в истории git.

## 6. Чего модель не умеет / чувствительность

- **Нестационарность и рывки по месту**: σ даёт стационарный профиль; рывки — по существующему шуму, привязка только по амплитуде.
- **Линия слоя**: запасная (Perdigão, холм) и поле (Онгудай, T2) расходятся на 33–128 м; на мачтах Perdigão центр, судя по росту ТКЭ с высотой до 100 м, лежит не ниже 100 м над землёй, модель этого не воспроизводит
  (model_obs.md §5). Какая линия верна — вопрос поля Perdigão (LT-4).
- **Признак «поле даёт слой»** — допущения (0,5 по LT-2; допуск немонотонности 0,1U1; 2 клетки над землёй; ширины переходов). Чувствительность не считалась; q не зависит от размера клетки явно, только через профиль поля.
  На 400 м поле центр почти не даёт — работает запасная линия.
- **Askervein — граница модели**: слабый отрыв (ТКЭ в 3–4 раза выше притока), критерий s_lee = H/x_foot даёт f_sep = 0,15 и не включает слой; критерий отрыва не трогали (решение Q1).
- **Критерий присутствия** (s_lee) — допущение из конфига, не из LTL; устойчивость (Ri) не учитывается.
- **U2/ΔU**: модель, не поле (U2 = −0,1·U1 при неразрешённом пузыре); поле показывает след слабее (u на 0,1H = 0,0–0,5 u гребня при x/H 2–4 на 50/100 м, strong).
- **x_r = 4,25H** — единственное число для всех гребней; разброс 2–5.
- **Гладкий холм**: δ0, замедление роста, затухание — по уступу.
- **Закрытые источники** (Bell–Mehta, Pope §5.4, Castro–Haque): цифры только из открытых данных LTL.
- **Две вертикальные оси**: профиль берёт вертикальное расстояние до линии слоя, не нормаль (ошибка cos ≈ 4–6 % при 16–20°; запасная линия почти горизонтальна).
- **Поле Онгудая в storm**: ΔU слоя берётся по U1 грозы (2,1–2,6 м/с σ_w) — задано моделью, не проверено.
