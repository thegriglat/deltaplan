# Связь тележка—крыло: причина пп. 1, 2, 4 (TKF-1)

Инструмент, команды и допущения замера — `tools/research/trike-fix/README.md`; данные — `tools/research/trike-fix/out/` (`summary.json`, `<сценарий>.csv`); кадры «до» — `build/screenshots/trike-fix/before/TKF-1_p{1,2,4}_{side,rear,front}.png` (p1 — turn45_idle, t = 24,95 с, max bar_deg_vis; p2 — roll_pump, t = 18,6 с, max mast_normal; p4 — reversal45, t = 21,35 с, max |yaw_rel|). Код игры не менялся.

## 1. Вывод
**Причина пп. 1, 2, 4 — вид.** `TrikeRig.refresh` всегда ограничивает поворот `cart_basis` к целевой ориентации 20 °/с (`CART_TURN_DEG_S`, `_turn_toward`). Целевая ориентация (`C_phys`, из «Маятника») в виражах меняется быстрее, вид не успевает и копит отставание. Физика (`C_phys`) пределов почти не нарушает.

Ключевые числа (`summary.json`, шаг 1/120 с, штиль, старт 300 м, 80 км/ч). vis = что рисуется, phys = по «Маятнику»:

| сценарий | bar_deg vis | bar_deg phys | yaw_rel vis | yaw_rel phys | mast→нормаль max vis / phys | vis_lag max |
|---|---|---|---|---|---|---|
| trim_full | 3,8…4,5 | 3,8…4,5 | 0 | 0 | 1,7 / 1,7 | 0,06° |
| turn30_half | 3,8…4,5 | 3,8…4,5 | 0…0,7 | 0 | 4,0 / 4,0 | 0,9° |
| turn45_half | 3,8…51,9 | 3,8…4,5 | 0…46,7 | 0 | 39,6 / 5,7 | 55,6° |
| turn45_idle | 3,6…70,6 | 3,8…4,5 | 0…66,8 | 0 | 51,7 / 6,1 | 71,8° |
| reversal45 | −3,6…48,0 | 3,2…4,5 | −41,1…41,0 | 0 | 65,3 / 10,2 | 69,7° |
| roll_pump | 0,3…148,1 | 2,0…5,1 | 0…160,1 | 0 | 131,6 / 11,0 | 143,3° |
| push_full | −63,9…24,8 | 4,0…14,5 | 0 | 0 | 66,7 / 11,7 | 78,2° |
| pitch_pump | 0,9…16,4 | 0,9…12,8 | 0 | 0 | 13,6 / 10,0 | 6,6° |

Пределы штанги: −8,39° (`pull`) … +4,95° (`push`). Крен тележки к крылу (`roll_rel`) phys: ±10–12° в накачке и 45° с полным газом, ≤ 4–6° в виражах 30° и 45° на половине газа/холостых.

- **Пункт 4 (отставание в вираже).** Установившийся вираж 45° имеет угловую скорость ориентации тележки p99 34–35 °/с (turn45_half/idle), 64 °/с (turn45_full), в перекладке 62–72 °/с. Предел 20 °/с ниже — вид отстаёт на 55–72°. Вираж 30° (p99 22 °/с) почти укладывается: отставание 0,9–1,05°.
- **Скрутка по рысканию в вираже (решение пользователя 11-02).** В физике её нет: `yaw_rel_phys` = 0 по построению — тележка не имеет рыскания, `cart_axes` берёт курс из киля крыла (минус составляющая вдоль мачты). Видимая скрутка 41–67° целиком от предела 20 °/с. Модель согласуется с реальностью (§2): узел позволяет только тангаж и крен.
- **Пункт 1 (штанга за подкосом).** В виде: bar_vis до 70° (виражи) и 148° (накачка) — следствие того же отставания: штанга лежит на крыле, а тележка повёрнута на десятки градусов. В физике: штанга выходит за упор «от себя» (+4,95°) до 14,5° (push_full, 54 % времени) и 12,8° (pitch_pump, 62 %): упора подкоса о штангу в модели нет. Вход в виражи, перекладки и накачку по крену физику в пределах (≤ 5,1°). Полный газ ставит штангу в трим на 3,8…4,5°, запас до упора всего 0,4–1,2°.
- **Пункт 2 (тележка поперёк/сквозь крыло).** mast→нормаль в физике ≤ 13,6° (никогда не близко к 90°); в виде до 132° (накачка по крену), 65° (перекладка). Тоже лишь отставание вида.
- **Что проверено и не причина:** шаг 60 Гц вместо 120 (turn45_idle, reversal45, roll_pump: отличия < 1°); тяга (газ 0 / полный в виражах — те же эффекты, газ меняет лишь скорость и скорость разворота); `CART_CM_MODEL` и поворот `rm` — скачок ориентации колёса→воздух 8,5° (на земле нормаль/курс, в воздухе мачта), нужный 20 °/с лишь для этого перехода.
- **Накачка по крену** (roll ±1 каждые 2 с) — крайний режим вне нормального пилотирования, но показывает хвост: скорость ориентации до 119 °/с.

## 2. Реальный узел подвеса (по источникам)
- Крыло и тележка соединены **шарниром, допускающим свободное вращение друг относительно друга по тангажу и крену**: Gratton G.B., «Towards the tumble resistant microlight» (Brunel Univ.; https://bura.brunel.ac.uk/bitstream/2438/705/1/Fulltext.pdf, §1, рис. 1): «a hangpoint C which is a joint allowing free rotation of the wing and trike relative to each other in pitch and roll».
- Тангаж — вокруг болта подвески; крен — **подшипник крена** в кронштейне на киле (нейлоновая втулка) — AAIB Bulletin G-CEVW, P&M Quik GT450 (https://assets.publishing.service.gov.uk/media/65a8ee73ed27ca001327b1f3/Quik_GT450_G-CEVW_02-24.pdf): «The trike is connected to the hang bracket through the hang bolt, about which the wing pitches. A roll bearing … allows the wing to roll in relation to the trike».
- Рыскание относительно тележки узлом не освобождено: для тела «тележка + крыло» оно общее (поворот в рыскании — свойство крыла: устойчивость по рысканию стреловидного крыла, Gratton там же); отдельной шарнирной степени нет. То есть физическая модель (рыскание тележки = рыскание крыла, `yaw_rel = 0`) верна, а видимая скрутка — артефакт. Оценка (не источник): реальные люфты и податливость рамы дают единицы градусов, не десятки.
- Упор «от себя»: в режиме кувырка передняя стойка тележки упирается в базовую штангу, система становится жёсткой (Gratton, Brunel, §о срыве: «front strut against basebar»). Это подтверждает упор подкоса о штангу; предельный угол в источнике не дан — берём из `trike_params.json` (+4,95°, TT-К6, геометрия по модели).
- Тележка не маятник «по рысканию»; по тангажу и крену висит под точкой подвеса: на трим-скорости стабилизирующего маятникового момента почти нет (форумы/учебные материалы — слабый источник; не использовать как числа).
- **Нет в источниках (оценка/открыто):** пределы крена тележки к крылу (упоры подшипника) и демпфирование узла. Не выдумано; в модели трение узла нет, «Маятник» их не имеет. Roll_rel phys ±12° в замере — наш результат, а не проверка по реальности.

## 3. Варианты правки
**V1 (закрывает п. 4, п. 2 в виде, п. 1 в виде; обязателен).** В `scripts/flight/trike_rig.gd`, `refresh`: в воздухе `cart_basis = target` без ограничения; предел 20 °/с — только для сглаживания скачка колёса→воздух (≈ 8,5°, затухает за ≈ 0,43 с): хранить смещение `q_off = cart_basis⁻¹·target` при смене `on_wheels` и гасить `_turn_toward` до единицы. Эффект (модель при других постоянных пределах, `vis_lag_deg_max_by_limit_dps`, градусы):

| предел, °/с | turn45_half | turn45_idle | turn45_full | reversal45 | roll_pump | push_full |
|---|---|---|---|---|---|---|
| 20 (сейчас) | 55,6 | 71,8 | 54,6 | 69,7 | 143,3 | 78,2 |
| 40 | 0,1 | 0,1 | 14,2 | 9,9 | 41,3 | 45,2 |
| 60 | 0,1 | 0,1 | 2,2 | 0,8 | 19,5 | 21,6 |
| 90 | 0,1 | 0,1 | 0,1 | 0,1 | 6,2 | 1,7 |
| без предела (V1) | 0 | 0 | 0 | 0 | 0 | 0 |

Простая замена константы (60–90 °/с) тоже годится, но оставляет хвост в накачке/срыве и скачок при отрыве. TowTug использует тот же `TrikeRig` — нужны прогоны `tow`, `tow_trike`, `trike_pilot` (cart_basis в виде и звуке/камере — завязки на вид, физику не трогает); дельтапланы затронуты нулём (`TrikeRig` у них нет).

**V2 (закрывает п. 1 в физике; решение — после V1).** Упор подкоса о штангу: ограничить тангаж тележки к крылу так, чтобы `bar_deg_phys ≤ push_deg + запас`. Где: `PendulumModel` (цепь пилота, XPBD-ограничение) либо момент-пружина в `TrikeRig.ext_force` с `cart.*` из `tow_tug.json`; в «Маятнике» дельтапланов не трогать (ключ только для дельталёта). Сейчас выход за упор — 14,5° при ходе «от себя» на 10 с (срыв: скорость падает до 20 км/ч), 12,8° в накачке. Риск: меняет динамику срыва и фугоиды (`docs/research/trike-pilot/pitch-oscillation.md`, k ≤ 0,65), тесты `pendulum`, `tow`, `trike` — перенастройка; кувырок/срыв ведёт жёстче (по Gratton — реально). Если не делать V2, порог теста по штанге на тангажных сценариях — только по виду.
**V3 (не нужна).** Рыскание тележки к крылу: оставить 0. Добавлять степень свободы не надо.
**V4 (на потом).** Упоры крена тележки к крылу: нужен источник; пока ±12° — наш максимум.

## 4. Пороги для теста TKF-4 (v2 TKF-К1)
Предложение по данным; сценарии с V1, шаг 1/120 с, исключить 1 с после старта и 0,5 с после отрыва от земли:
- `yaw_rel_deg_vis` ≤ 1,0° во всех сценариях (сейчас до 160°).
- `vis_lag_deg_max` ≤ 1,0° в turn30/45 (все газы), reversal45; ≤ 3° в push_full/pitch_pump/roll_pump.
- `mast_normal_deg_max_vis` ≤ 20° во всех; ≤ 90° всегда (физика: макс. 13,6°).
- `bar_deg_vis` в [−pull, push + 0,5°] для trim_full, throttle_step, turn*, reversal45, roll_pump (после V1 = `bar_deg_phys`: 2,0…5,1°, внутри 4,95 + 0,5); для push_full и pitch_pump — только при V2.
- `|roll_rel_deg_vis|` ≤ 15° (наш максимум 12,3° + запас; источника предела нет).

## 5. Неопределённости
Предельные углы крена/демпфирование узла — в источниках не найдены; Gratton 2001 (Proc IMechE G) прочитан только по аннотации — по содержанию использованы Brunel-доклад и AAIB; геометрия штанги `wing_frame_bar` и упор +4,95° — наша оценка TT-К6; регулятор крена и период накачки подобраны, не сняты с пилота; контракт говорит «шаг 1/60 с», игра — 120 Гц (измерено на обоих, различие < 1°).
