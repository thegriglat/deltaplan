# Дома: модели вместо коробок? (RV-14)

Вопрос 18.10: переводить ли все дома на модели ради унификации. Числа — из кода и конфигов; не мерянное помечено «оценка».

## Что сейчас

`BuildingPlacer` (scripts/world_objects/building_placer.gd): запись дома = [x, z, w, l, угол, высота, крыша] по реальному контуру OSM. Стена — `BoxMesh` 1×1×1 (24 вершины, 12 треугольников), масштаб экземпляра = w × высота × l; у села — `PrismMesh` крыши (18 вершин, 8 тр.) и труба-коробка у 85 % (12 тр.). Тайл 1 км, видимость 7 км, тени включены. На тайл до трёх MultiMesh (стены, крыши, трубы). Окна по этажам, стекло, тёмный низ, профлист и цвет крыши плоских домов — в `building.gdshader` по данным в альфе `INSTANCE_COLOR`; текстур нет, VRAM ноль. Эталон: Алматы 3×3, 280 412 домов, слой 2,6…3,0 с (OL-1), высоток ≥ 45 м — 2661.

## Рекомендация

1. **Не переводить все дома** (унификация ради унификации не окупается): город, многоэтажки, промзона, дома с `height`/`levels` остаются коробками — шейдер окон уже даёт им вид, модель фиксированных пропорций тут проигрывает.
2. **Гибрид по RV-К6**: модели — только деревенские дома без высоты OSM в регионах, где «коробка с двускатной крышей» неверна (ронделавель, жесть, сваи); доля `village_model_share` в профиле, 0 по умолчанию — поведение не меняется.
3. **Ограничения**: масштаб X/Z по контуру; для вытянутого контура (l/w > ~2) и для домов дальше 1,5 км — коробка (LOD2 ≈ коробка). Замер кадра и времени слоя на Алматы/Рапа-Нуи — перед слиянием RV-10, шлюз Q1 — кадры.
4. Дым: точка трубы в модели либо без дыма.

Не проверено: доля домов под гибрид по месту; влияние на кадр.
