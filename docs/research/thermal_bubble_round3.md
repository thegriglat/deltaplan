# thermal-bubble, круг 3: шаблон по умолчанию

Решения пользователя 2026-11-09 ([план](../plan/thermal-bubble.md), «Круг 3»): довести шаблон и включить по умолчанию. Круг 2 — [thermal_bubble.md](thermal_bubble.md#круг-2-ядро-по-измерениям-и-встраивание-за-флагом) (шаблон v4, за флагом). Числа ниже — из отчётов задач, `tools/research/thermal_bubble/out/*.json` и `round3/*.md`; «оценка» — арифметика исполнителя, не замер. Контракты — [TB1 v5, TB4 v6](../contracts/thermal-bubble.md).

Итог:
- Шаблон пузыря — единственная модель подъёма термика динамических источников внутри 2000 м от фокуса; флага `bubble_template` нет. Профиль Гедеона остался лёгким слоем (ниже).
- Что изменено в модели: F0 из бюджета потока (TB-10), q(ξ) «между» и K̄ от шаблона (TB-12), радиус 2000 м оставлен (TB-13), облачный подсос выше `top` сохранён (TB-15), высота таблицы у земли по рельефу (TB-18, TB-20).
- Что не изменено: приток у земли (TB-11) — оснований править нет.
- В игре (замер `flight_r4`): подъём, покрытие, ось, ядро, разрывы и кадр проходят; приток у земли в игре слабее стенда — открытый вопрос.

## Что поменялось в модели и почему

### 1. F0 из бюджета потока (TB-10, TB1 v5)

Круг 2: голова доходит до 0,9 z_i за 1473 с, термик игры живёт ≈ 990 с. Причина — в модели: F0 в `from_strength` подбирался по пику оси (центр Хилла 2,5·U = w0), отсюда U = 0,46→0,31 w*, ниже нижней границы среднего подъёма 0,40–0,45 w* ([round3/life.md](../../tools/research/thermal_bubble/round3/life.md)). Подъём с постоянной скоростью воздуха 0,45 w* дал бы 1389 с — ориентир, прямого измеренного времени подъёма термика через слой в открытых источниках не найдено.

Согласование из физики, не подгонкой: `from_game_strength` — F0 из потока ядер (`core_flux_fraction` 13/35 = 0,371, low), w* клетки = strength/K_ALLEN:

| Вариант | t подъёма до 0,9 z_i |
|---|---|
| круг 2 (F0 по пику оси) | 1473 с |
| F0 из потока | **1089 с** (+10 % к 990 с игры) |
| w0 = 1,6 w* / 2,0 w* (проба) | 1139 / 909 с |

F0 ×2,46 (204→501) даёт U и 1/t ×1,35 = F0^⅓; центр головы 1,55 w* внутри ядер 1–2 w* LES. Разброс силы клеток сохраняется: t(w*) = 1835 / 1375 / 1089 / 876 / 729 с при w* 1,2 / 1,6 / 2,0 / 2,5 / 3,0 м/с (z_l 1400). Пик w на оси за жизнь = 1,35·strength. Жизнь клеток игры (cfg 120–240 / 300–720 / 150–300 с) не менялась — шлюз пользователю не понадобился.

Цена: ядра несут 0,56 Φ против 0,30 (K̄ ≈ 8,1·10³ м² против 4376 при w0 ≈ 3,2 м/с); Монте-Карло потока ядер = потоку поля в пределах ±20 %.

### 2. Приток у земли — не менять (TB-11)

Шаблон 0,58 w* (точка z = 10 м) в метрике LES (ячейка 50 м, узлы сетки) = **0,40 w*** (×1,12 к 0,36 LES); трение у стенки даёт 0,27–0,33. При равной силе события (w композита 2,0 w*) приток шаблона 0,57–0,65 (×1,6–1,8): композит LES — более сильный и широкий объект, подтверждения «0,36» нет. Правка (L_b 130 м даёт 0,36) портит w(z) у земли против Lenschow–Stephens — основания нет ([round3/inflow.md](../../tools/research/thermal_bubble/round3/inflow.md)). Оценки трения и подгонки силы — грубые (три z_ref, три σ).

### 3. «Между» по высоте (TB-12, TB-15)

Прежний q(ξ) расходился с средним по жизни потоком шаблона до 0,105 м/с (26 % Φ), пик 0,85 против цели L&S 0,25; q шаблона даёт сумму «пузыри + между» = w_conv без ошибки, RMS до цели L&S 0,72 → 0,34 ([round3/between.md](../../tools/research/thermal_bubble/round3/between.md)). Профиль доли площади подъёма принят постоянным (0,35), настоящий массовый поток LES не прочитан. В v5 q — 21 узел, пик ξ = 0,55; отрицательное «между» ограничено нулём.

### 4. Радиус 2000 м и судьба профиля (TB-13)

Смена профиль → таблица происходит не ближе 2108 м от фокуса (вклад пузыря ≤ 600 м), максимальное различие двух полей на шве 3,98 м/с (w0 = 4 м/с) приходится туда, где пузыря уже нет; фокус при смене не чувствует разрыва (dw = 0). Запас по сближению 141 / 84 / 53 с при 15 / 25 / 40 м/с.

| R, м | 1000 | 2000 | 3000 | 4000 | 6000 |
|---|---|---|---|---|---|
| сборка, мс на 1 с игры | 32 | 63 | 101 | 159 | 284 |
| память кеша, МБ | 32 | 85 | 153 | 235 | 452 |
| прогрев, с | 2,3 | 7,2 | 13,2 | 19,6 | 39,3 |

(1 фокус, 1 поток; 4 фокуса при R = 2000: 223 мс/с, 266 МБ, прогрев 26,6 с.) Профиль целиком убрать нельзя: нужны маска фона, σ, облачный подсос, статика, столбы < 100 м, w дыма на 2–5 км. Остался лёгким слоем: профиль Гедеона за радиусом, у статичных термиков, без таблицы, у столбов < 100 м; выше `top` — профиль с подсосом ([round3/radius.md](../../tools/research/thermal_bubble/round3/radius.md)).

### 5. Встраивание без флага (TB-15, TB4 v3–v4)

Флаг убран; `uh` без fade; центр пузыря на оси `cores` (`axis_at(zc)`); первая синхронная сборка без таблиц. Тесты со старыми числами профиля Гедеона перезаписаны: паритет с дампами GD невозможен, допуски ослаблены и добавлены проверки присутствия — это не доказательство точности новой модели (ревью TB-15 отметил, что часть растровых допусков ничего не проверяет).

### 6. Рельеф у земли (TB-14, TB-16, TB-18, TB-20, TB4 v5–v6)

Первые замеры в игре показали приток у земли ≈ 0 (77 % ядер с |u_r| < 0,01 м/с). TB-18 нашёл механизм: `sample_bubble` берёт высоту таблицы `y − y_src` (плоскость источника), на склоне точка в 10 м над землёй оказывается ниже плоскости (вклад 0) или высоко над ней. Повтор на сетке высот Алтая (соседний тайл, не Онгудай; уклон ≈ 17°): нулевых замеров 34 % против 3 % на плоскости, у 18 из 19 нулевых ядер причина — рельеф ([round3/ground_inflow.md](../../tools/research/thermal_bubble/round3/ground_inflow.md)). Величина игры (77 %) не воспроизведена, механизм — да.

Первая правка (сшивка agl 60–120 м) давала до 1,34 м/с на метр высоты (тест прятал это отбором вертикалей). TB4 v6: `high_eff(agl, h_src, zi)` — затухающая по высоте координата (Gal-Chen–Somerville 1975): high = h_src − d·(1 − smoothstep(agl/L)), d = h_src − agl, L = clamp(3|d|, 120 м, z_i). На стенде: нулевых ядер 0,022, медиана u_r 0,10 м/с; отношение dw/dz рельеф/плоскость 0,984 (648 вертикалей без отбора).

## Чего не умеет (круг 3)

1. **Приток у земли в игре слабее стенда:** медиана 0,018 м/с по 47 ядрам против 0,10 м/с на стенде TB-18/TB-20. Причина по рельефу после TB-20 заново не мерилась; порог из TB-21 убран. Для Онгудая стенда с настоящим рельефом нет (использован соседний участок Алтая).
2. **Жизнь игры и голова:** подъём до 0,9 z_i ≈ 1089 с при w* = 2,0 против 990 с; под основанием облака у верха высоких столбов голова не доходит, подъём ≈ 0, выше `top` — профиль с подсосом. Растекание под крышкой на высоких столбах заметно не будет. Время подъёма термика через слой литературой не подтверждено (нет прямых измерений).
3. **Доля ядра 0,371 — low;** от неё зависят F0 и поток (0,3 дало бы около +8 % по времени подъёма). Ядра несут 0,56 Φ против 0,30 в v4 — цена выбора F0 по потоку.
4. **Рельеф:** `L ≤ z_i`, оценка производной high верна только при |d| ≤ z_i/3; выше L поле = плоскость источника, «выше 120 м не меняется» верно, где |рельеф − плоскость| ≤ 40 м. Таблица не учитывает рельеф сама.
5. **Приток 0,58 w* (0,40 w* в метрике LES)** выше композита LES при равной силе в 1,6–1,8 раза; подтверждения нет, правки нет.
6. **Шов радиуса:** ближайшая точка различия найдена по сетке 528 точек, истинный минимум может быть чуть меньше; рывок фокуса (респаун, телепорт), свободная камера дальше 2000 м, картинка дыма не проверялись. Линейная оценка для 16 фокусов ≈ 0,9 с/с — не замер.
7. **Столб < 100 м внутри радиуса** — только профиль Гедеона, его доля в игре не измерена.
8. **Замеры шумные:** детерминизм крейта выключен (как в игре); один сид, одно место, 1200 с, probe не повторялся (47 против 48 ядер); кадры на загруженной машине (load 17–50); бот-термичник сам ставит фокус воздуха.
9. **Прежние границы круга 2** остаются: шлейф не гнётся ветром, нет обратной связи между соседними пузырями, α_plume лабораторный, один τ = 690 с в K̄.
