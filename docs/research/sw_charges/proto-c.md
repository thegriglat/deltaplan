# Прототип C: пуассоновы диполи и пары (2D, без рельефа)

Код, команды, сканы — `tools/research/sw_charges/proto_c/` (README там), числа — `out/results.json`. Спецификация — `unified-scales.md`, «Прототип C», шаги 1–3. Линия рельефа (шаг 2 спецификации) не делалась.

**Вердикт:** частично — обратные потоки есть, схема консервативна, H(ζ) = H(1−ζ) без подгонки, но σ_w пар завышена в 1,4–1,7 раза против нейтральной σ_w игры (против полной с конвекцией — в пределах ±30 % на 3 высотах из 4), L_w втрое мала, ядро диполя в 2,2–2,5 раза сильнее и уже ядра Гедеона; из 44 проверок пройдено 19 (σ_w против полной σ_w игры с конвективной поправкой — 3 высоты из 4, см. шаг 2).

## Постановка и допущения
- Вход один на все шаги: «типичный июль» из `thermals.md` — H = 250 Вт/м², z_i = 1500 м, u* = 0,4 м/с; отсюда w* = 2,17 м/с, Δθ₀ = 6,5·H_kin/w_m = 0,94 К, w₀ игры = 1,24 w* = 2,69 м/с. Ветер — гладкий U(z): логарифм (z₀ = 0,1 м) до 100 м, выше постоянный (6,9 м/с). Профиль θ: 0,5 К/км до z_i, 5 К/км выше.
- Объект — диполь Лэмба — Чаплыгина (ЛЧ) радиуса a, скорость U; поле точное (J₁ внутри, U a²/r² снаружи), у земли — зеркальное изображение, по x — периодика. Проверено: div = 1e-8, ∫w dx по линии через центр = 0, E = 2πU²a².
- Допущения 2D: «термик» — цилиндр (ролик), а не кольцо; ЛЧ — не 3D-кольцо; сдвиг ветра диполь не деформирует; взаимодействие 2D (~1/r²) сильнее 3D (~1/r³). Параметры из спецификации/литературы, не подгонялись; чувствительность — сканом (ниже).

## Шаг 1. Один термик
ОДУ: dU/dt = b/(1+k_m) − αU²/R, k_m = 1 (поэтому a = b/2, как в «Общей основе»), dR/dt = αU/2 (из dm/dt = α m w/R, m ∝ R²), θ′ разбавляется вовлечением и теряет γU в стратификации. Старт: z = R₀ = 69 м (радиус Аллена на ζ = 0,1), α = 0,15 (диапазон 0,1–0,2).

| Величина | Прототип | Игра / эталон | Итог |
|---|---|---|---|
| пик w, ζ = 0,25 / 0,5 / 0,75 | 6,7 / 5,9 / 3,7 м/с | w₀ = 2,69 | ×2,5 / ×2,2 / ×1,4: **не проходит ±30 %** |
| скорость подъёма U (центр масс) | 1,9 / 1,7 / 1,05 м/с (0,9 w*) | — | порядок w* |

Пик ЛЧ = 3,48·U (оценка из формулы поля, не подгонка). Чтобы пик равнялся 2,7 м/с, нужна U = 0,77 м/с — подъём в 2,2 раза медленнее, чем без сопротивления; сопротивление («sticky/slippery») не закладывалось. Скан: α 0,1/0,15/0,2 → потолок 1554/1331/1169 м; R₀ 30/100 м → 863/1557 м; γ в слое 0/1 К/км → 1717/923 м (потолок очень чувствителен к вовлечению и R₀).

## Шаг 2. Пары болтанки с одним S(z)
Закон: ℓ = κz, d = a = ℓ, ΔU = Sℓ = u*, Γ = ΔU·ℓ, U_п = Γ/(2πd) = u*/2π, τ = d/U_п = 2πκz/u*. Рождение λ = ε/E_пары (ε = u*³/κz — производство в лог-слое, E = 2πU_п²a²), то есть λ = c(z)S² с c = 2π/(κ z u*) из баланса энергии, а не подгонка под σ_w. Курс пары ±45° к вертикали: выброс (вверх, против ветра) или вторжение (вниз, по ветру) 50/50 — знак ⟨u′w′⟩ задан осью растяжения сдвига. Аннигиляция: пары противоположного курса ближе 0,1 среднего размера — обе исчезают. ~9·10³ живых пар (без аннигиляции 2,3·10⁴), область 800 м, 4 уровня, 40 снимков.

| z, м | σ_w пары / игра нейтральная (1,25u*(1−z/h)^¾ ≈ 0,5) | L_w пары / z | ⟨u′w′⟩ / игра | σ_крыло/σ_точка (10 м): пары / Карман |
|---|---|---|---|---|
| 10 | 1,53 | 0,31 | 1,7 | 0,57 / 0,77 |
| 25 | 1,73 | 0,39 | 2,3 | 0,84 / 0,88 |
| 60 | 1,74 | 0,38 | 2,7 | 0,97 / 0,94 |
| 120 | 1,35 | 0,34 | 1,5 | 0,99 / 0,97 |

Эталон в таблице — **нейтральный** (прототип рассчитан на лог-слой без конвекции). Но при входе прототипа (H = 250 Вт/м², u* = 0,4) L_MO = −23,6 м, и полная σ_w игры (`turbulence.md`: σ_w = 1,25 u*(1+3|z/L|)^⅓) = 0,66 / 0,81 / 1,03 / 1,27 м/с на z = 10 / 25 / 60 / 120 м. Против неё σ_w пар (0,76 / 0,86 / 0,84 / 0,64) даёт отношение **1,16 / 1,06 / 0,82 / 0,50**: проходит ±30 % на трёх высотах из четырёх, не проходит на 120 м (пары не несут конвективную часть, а выше z ≈ |L| она доминирует). Это совпадение по порядку, а не подтверждение: механика пар сравнивается с суммой механики и конвекции, и в зачёт «только механика» идёт нейтральный эталон — по нему σ_w **не проходит** ±30 % ни на одной высоте. Размах крыла 10 м: отношение «крыло/точка» совпадает с Карманом (L_w = z) в пределах 30 %, а «0,6 σ в точке» в игре относится к z ≈ 2–3 м, куда прототип не доходит (z ≥ 8 м); корреляция по размаху вычисляется прямо из поля пар, без правила.

Скан (σ_w / игра на z = 10, 25, 60, 120; живых пар): без аннигиляции 1,9–2,5 (25·10³); f_ann 0,05 → 1,7–2,0; f_ann 0,2 → 0,9–1,3 (4,5·10³); λ×0,5 → 0,8–1,3; λ×2 → 1,5–2,3; λ×3 → 1,8–2,5; φ = 30° → 1,6–2,3; φ = 60° → 1,2–1,6; ℓ = длина смешения игры (λ = 40 м) → 0,7–1,7. Видно: (1) аннигиляция убирает 60 % пар даже при критерии 0,1 размера — газ из ~40 пар на a² сильно взаимодействует, спецификация «аннигиляция при встрече» требует самосогласованной плотности; (2) σ_w² ≈ запасённой ТКЭ = ετ с τ = 2π κz/u* — в 3–5 раз дольше реального времени диссипации, отсюда завышение; σ_w «попадает» при λ ≈ ×0,3–0,5 (то есть τ ≈ 0,3–0,5 от d/U_п), но это подгонка и в зачёт не идёт; (3) L_w не меняется ни в одном скане (0,3–0,44 z) — масштаб задаёт a = κz, а определение L_w = 2·∫ρ dx до нуля даёт 0,3–0,4 z уже для 2D-диполя.

## Шаг 3. Обратные потоки: ансамбль термиков
L = 5 км периодически, рождения пуассоновы с ν = H_kin L/(A₀Δθ₀) = 0,057/с (замыкание по потоку тепла; ≈ 100 живых, спецификация ≤ 10²), среднее поле θ̄(z), Ū(z) на сетке 25 м; каждый термик отдаёт поток F = U·θ′·хорда(z) (и U·(u_t − Ū)·хорда) в клетки по своему следу, ∂θ̄/∂t = −∂F/∂z, впрыск тепла Земли — по хорде рождения. Приземный слой (< 100 м) удерживается (его держит механическая болтанка, шаг 2). Детрейнмент β = 0,5 вовлечённой массы — введён мной (в спецификации нет, без него ансамбль не работает, см. ниже). 3 ч, шаг 1 с.

| ζ | H/H_kin | 1−ζ | ⟨u′w′⟩/u*² | −(1−ζ)^1,5 |
|---|---|---|---|---|
| 0,1 | 0,91 | 0,90 | −0,22 | −0,85 |
| 0,25 | 0,74 | 0,75 | −0,21 | −0,65 |
| 0,5 | 0,49 | 0,50 | −0,11 | −0,35 |
| 0,75 | 0,24 | 0,25 | −0,18 | −0,125 |

- **Тепло.** Профиль H(ζ) совпадает с замыканием `thermals.md` в пределах 5 % без подгонки; у кромки поток вовлечения −0,2…−0,3 H (литература −0,2). Σ(θ̄−θ₀)dz/(H t) = 1,000 — это проверка консервативности численной схемы (поток в виде дивергенции), а не свидетельство о модели. ∫w dx по линиям ансамбля (2D, периодика, изображения) < 1 % от ∫|w|dx.
- **Импульс.** Термики несут вниз 0,1–0,2 u*² — поток есть и правильного знака, но в 2–4 раза меньше u*_m² игры в нижней половине слоя. Причина: ветер выше 100 м в прототипе постоянный, дефицит ветра в термике мал. При ветре, растущем до 300 м (скан) слой тормозится в 3,3 раза сильнее (−0,69 против −0,21 м/с за 3 ч), порядок зависит от профиля.
- **Торможение слоя.** Ū(100 м…z_i) за 3 ч: −0,21 м/с, что в 0,18 раза от ожидаемого стоком u*²/z_i·T = −1,15 м/с. Тормозит, но слабо; полное торможение требует и потока от пар (шаг 2).
- **Рост z_i.** По нулю H: 1270 → 1450 м (+82 м/ч против 194 м/ч срезания по начальному профилю); термики проникают до 2000–2100 м (1,4 z_i) — завышенное проскакивание.
- **Скан** (H(0,5)/H_kin; ⟨u′w′⟩(0,1)/u*²): β = 0 → 0,74; −0,21, поток H сильно шумит, θ̄ разрывается на 5–8 К (термики умирают в узком слое, строится запирающий слой); β = 1 → 0,48; z_i H=0 до 1640 м; α = 0,1/0,2 → 0,47/0,48; индуцированное поле (термики друг друга сносят) → 0,70, θ̄ расходится (−6 К у земли; в 2D взаимодействие ~1/r², в 3D ~1/r³) — в базе выключено; R₀ = 50 / 100 м → ⟨u′w′⟩ −0,75 / +0,07 (импульс очень чувствителен к R₀); L = 2,5 / 10 км — без изменений (0,49); γ слоя 0,1 / 1 К/км — 0,51 / 0,47.

## Сравнение по критерию «согласие с масштабами 2–3 в пределах ±30 % при наличии обратных потоков»
- Масштаб 2 (термик): **нет** по пику (×2,2–2,5), ширине ядра (0,62 R) и кольцу; **да** по радиусу, времени подъёма, потолку и потоку тепла ансамбля.
- Масштаб 3 (болтанка): **нет** по σ_w (×1,35–1,74), L_w (×0,3–0,4) и ⟨u′w′⟩ (×1,5–2,7); да по отношению «крыло/точка» (на z ≥ 10 м).
- Обратные потоки: есть (H, ⟨u′w′⟩ ↓, рост/запирание z_i, торможение слоя), тепло сохраняется точно.
- Сохранение и ∫w dx = 0: выполняются по построению диполя; в базовой игре кольцо Гедеона не возвращает весь поток.

## Выводы и следствия
1. Как объекты реестра с обратными потоками — диполи работают: потоки тепла и импульса из объектов дают замыкание `thermals.md` без отдельного кода, ввод в среднее поле консервативен (проверено).
2. «Согласие по σ_w ±30 %» не достигнуто без калибровки: нужна либо поправка времени жизни пар (τ ≈ 0,3–0,5 d/U_п), либо самосогласованная плотность с аннигиляцией. Калибровка λ и τ по σ и спектру из `turbulence.md` — следующий шаг, если C будет развиваться.
3. 2D-ролики вместо 3D-колец: пик в 2D ЛЧ завышен (3,48 U), взаимодействие слишком сильное; 3D-кольцо (вне задачи) нужно для оценок силы ядра.
4. Детрейнмент — обязательный закон в реестре (иначе тепло складывается слоем на уровне гибели термиков).
5. Дорого для игры: 10⁴ пар — десятки мс на шаг; использовать только вблизи пилота или заменить спектральным синтезом.

## Что не проверено
Линия рельефа и поле этапа 1; 3D; сопротивление термика; ветер выше 100 м, меняющийся по логарифму; z < 8 м; стратификация в парах; калибровка λ по натурным данным.
