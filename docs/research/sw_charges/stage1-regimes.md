# Этап 1 (а): режимы слоя по F0, M (SWC-8)

Решатель — `tools/research/sw_charges/swpy` (Рипа, MUSCL + SSP-RK2 + HLL, SW1–SW3), 1D-разрезы идеальных форм. Формат строк — SW4 v1;
сравнение с теорией `literature.md` §2 (M_c, M_s, бор 2.4), правило перевода §7 R1. Воспроизведение, время и команды —
`tools/research/sw_charges/regimes/README.md`.

## 1. Постановка

- **Масштабы** (решение 2026-11-08): мелкая вода — только a/h0 ≥ 3; dx = a/20 (проверка a/40 на 3 случаях — режим, h1, скорость бора те же); домен ±30a, губка 5a у краёв (τ = 2a/c), зонд x_up = −10a.
- **A1**: h0 = 1000 м, b0 = 0,1 м/с² (c = 10 м/с), c_d = 0, forcing none. Ridge a/h0 = 3: сетка 9 F0 × 9 M; контроль формы: ridge a/h0 = 6 и step_up (a/h0 = 3), F0 ∈ {0,5; 1,5; 2} × 9 M; сверх сетки 3 точки зоны гистерезиса (F0, M = 1,5/0,13; 2/0,5; 1,2/0,024). Старт по SW1 (η = const, u = U0). В зоне M_s ≤ M < M_c (M < 1) — второй старт `_jstart` (ветвь с прыжком на наветренном склоне, §2.2–2.3, через h_init/hu_init/b_init). Всего 151 случай.
- **A2**: хребет H = 500 м, s = 0,3 (a = 1430 м), N = 0,01 с⁻¹, h/z_i ∈ {0,3; 1; 3} → h0 = z_i = 1667; 500; 167 м, M = h/z_i; Fr_game ∈ 11 значений, U_sat = 5·Fr. R1: U10 из U_sat = U10·(z_sat/10)^α (α = 0,24, z_sat = 0,3·h, h = 0,3u*/f, f = 1,1·10⁻⁴ с⁻¹, z0 = 0,1 м — допущение, `limits.md` Б2; проверка: U_sat 12 м/с → U10 5,1, в air-phase 5,2); U0 = ⟨U⟩ по слою 0…h0; b0 = N²·h0 (N2h0) или N²·δ, δ = 1500 м (N2delta, n_layer_m); c_d = [κ/ln(0,37 h0/z0)]²; forcing balance. 66 случаев. **a/h0 = 0,86 (h/z_i = 0,3) и 2,86 (h/z_i = 1) — вне применимости мелкой воды**; в рамках масштаба только h/z_i = 3 (a/h0 = 8,6).
- **Классификатор** — контракт SW4. Уточнения (пороги в `thresholds` JSON): скачок h > 0,05 h0 на 2 клетках считается прыжком, только если охват 8 клеток ≤ 2× охвата 2 клеток (иначе плавный склон около Fr = 1 даёт ложные «прыжки»); R6 — сухие клетки в старте; Fr_crest — среднее двух клеток у x = 0; бор — h_up − 1 > 0,02 в итоговом поле, скорость — по линейной подгонке положения фронта (половина скачка) по ~60 снимкам; t_end = 3a/c + 16a/s_теор (бор проходит x_up и не доходит до губки), без бора по теории — 4 T_c (T_c = 60a/(U0+c)), потолок 15 T_c.
- **Эталон**: эксперимент и измерения, где есть; Пикар/air-phase — допуск ±10–15 % (решение 2026-11-08); подгонки под Пикар нет.

Air-phase для хребта (`air_phase_results.md` §0): обход 0,89, обратное течение 0,96, застой 1,26; допуск ±10–15 %. Переход SW у обоих вариантов лежит в 1,1–1,3 (теория M = M_c: 1,18 N2delta, 1,25 N2h0) — внутри допуска ±10–15 % около застоя 1,26 (−6 % и −1 %); до обхода (0,89) и обратного течения (0,96) переход слоя выше на 20–45 %. Сетка Fr_game (1,1 → 1,3) не позволяет различить варианты b0: их разница в пороге 6 %. Такое сравнение — **по пороговой высоте M = M_c(F0) при вне-масштабном a/h0 = 0,86**: гидравлическая критичность не зависит от a/h0 (теория §2.1), а рельеф при a/h0 < 1 решателем разрешён с dx = a/20, но гидростатика слоя тут неверна (h ≫ a), поэтому совпадение — наводка, а не подтверждение.

Для h/z_i = 1 и 3 (хребет не ниже слоя) слой всегда в R6: сухие клетки в старте, перехода к блокированию нет, тогда как у air-phase пороги по Fr есть при всех h/z_i (смещены вверх/вниз). Это не ошибка расчёта, а свойство модели: однослойный слой тоньше хребта не обтекает его сверху — воздух выше слоя в слое не представлен. Бор в R6 есть и идёт со скоростью, падающей с Fr (N2h0, h/z_i = 3: 1,3 → 0,05 м/с при Fr 0,3 → 1,1), при Fr ≥ 1,3 бор исчезает (F0 > 2,9, поток сверхкритический, уходит за хребет).

Эксперимент для A2: нет (условия игры; лаборатория — только однородный слой, см. выше). Пикар — как справка с допуском ±10–15 %.

## 4. Чего модель не умеет

- Однослойная модель: вертикальная структура ветра сведена к U0; воздух над слоем неподвижен (внутренние волны, подветренные волны, разделяющая линия тока Snyder не воспроизводятся).
- Вне мелкой воды (a/h0 < 3) гидростатика слоя неверна; h/z_i = 0,3 и 1 в A2 помечены. R6 при h/z_i = 1 — следствие M = 1,000 ровно (гребень касается верха слоя, h0 − z_b < h_min в одной клетке): это граница модели, а не измеренное блокирование; ряд при h/z_i = 1 о режиме ничего не говорит (при M = 0,99 результат был бы другим — см. R3/R5 в A1 при M = 0,8).
