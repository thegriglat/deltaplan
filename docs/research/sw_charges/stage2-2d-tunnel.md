# Этап 2 (2D), круг 2: причины недобора ΔS трубы и эталон Пикара по центрам клеток (SWC-16)

**Вердикт:** недобор ΔS панелей против трубы Lubitz & White — не ошибка формы и не сетки (форма cos² / Агнези / гаусс / cos⁴ даёт ≤ 0,06, ds_min 12,5–50 м — ≤ 0,01), а свойство схемы «потенциальный поток + фон со сглаживанием». Главные рычаги: σ сглаживания фона (у H3 при σ = 0 / 50 / 250 / 1000 м ΔS = 0,32 / 0,39 / 0,72 / 1,20, то есть от 0,3 до 1,1 измеренного 1,08 — произвольный параметр без аналога в трубе) и высота сравнения (у H3 ΔS = 0,96 / 0,72 / 0,56 / 0,42 при z = 0,02 / 0,05 / 0,1 / 0,2 H). Набор «как в трубе» (степенной профиль α трубы, без сглаживания, z — нижняя точка трубы) даёт ΔS в 0,18–0,27 измеренного, то есть хуже, чем SWC-12 (0,33–0,79); единственный набор без подгонки, ближе к трубе, — однородный фон: 0,52–0,79 измеренного (среднее 0,66), ни одна из 6 моделей не в ±15 %. Знак «ниже, а не выше» объяснён: чистый потенциальный поток (однородный фон) даёт у земли ΔS 0,29–0,72 (≈ 1,07 H/L), а труба выше него в 1,2–1,8 раза — вклад внутреннего слоя сдвига, которого в потенциальной схеме нет; профиль фона `bg_profile` занижает ещё вдвое (ΔS в 0,4–0,5 от однородного при σ = 0), а сглаживание σ = 250 м частично и произвольно это скрывает; формула Taylor–Lee (B = 2, 1,06–1,34) для тех же H/L даёт выше трубы. Эталон Пикара по центрам клеток (без степенной поправки): within_tol на нижней клетке 2/15 (pot) и 2/15 (vortex), на второй 3/15, на ~50 м 5/15 и 7/15, на ~300 м 14/15 и 14/15 (SWC-12 на 10 м: 2/15 и 3/15) — вывод «паритета у земли нет, на 300 м есть» не изменился; погрешность эталона P50 в двух нижних клетках оценена в 6–30 % от локальной скорости (≈ 1,5 × разность P100↔P50; 4–7 % U10 в слое до 100 м), на 50 м 2–9 %, на 300 м ≤ 1,5 % (медианы); это в 2–10 раз меньше расхождения панелей (медиана |err|/u_ref 0,6–1,5 в двух нижних клетках) — значит, недобор настоящий.

## Постановка и допущения
- Код: `tools/research/sw_charges/panels_exp/` (`scan_lw.py`, `scan_lw_extra.py`, `run_cc.py`, `ref_err.py`, `merge2.py`), библиотека `panels2d` (SW6 v2) не менялась; числа — `out/panels2d/tunnel/*.json`, SW7 — `out/panels2d/points.{json,csv}`, прежняя версия (SWC-12) — `out/panels2d/prev_swc12/`.
- Труба (прочитано в оригинале, PDF UC Davis): определение ΔS (ур. 1) — на той же высоте над поверхностью, подход — плоская поверхность с той же шероховатостью; сечение UC Davis — h/2 + h/2·cos(πx/2L1) = h·cos²(πx/4L1) (L1 — полуширина на половине высоты) — то есть форма SWC-12 верная; H = 38 мм, нижняя точка измерения 5 мм = 0,13 H (в SWC-12 сравнивали на 0,05 H); степенной закон трубы α = 0,19 (UC Davis), z0 = 0,16–0,20 мм; 2D-хребты H3/H5/H8 (EPA RUSHIL, Weng и др. 2000) имеют «параметрический» профиль — не cos², формул в статье нет; Gong & Ibbetson — «Cos2», определение не дано; Miller & Davenport — cos. «Поверхность» в таблице статьи для H3, UCD, H5 — нижняя измеренная точка; для EPA её высота не указана, взято 0,05 H (допущение, диапазон 0,02–0,2 H разобран ниже).
- Скан: H = 400 м, L = H/(H/L), потенциальный вариант (вихри ΔS на гребне не меняют знака, SWC-12), ds_min 25 м, апстрим x = −4000 м, всё остальное — как в SWC-12 (α 0,15, σ 250 м, cos², z по таблице, «над землёй»); меняется один фактор. Таблицы — `scan_lw.json`; ΔS по высоте для базы — там же.
- Контроль: u на x = −4000 к невозмущённому профилю 0,990–0,993 (панели добавляют ~1 % на 10 L от холма) — апстрим как опорная скорость корректен.

### Почему ниже, а не выше
1. Потенциальный поток (однородный фон) около гребня cos² даёт ΔS(z→0) = 0,72 (H3), 0,67, 0,56, 0,43, 0,34, 0,29 (H8), ≈ 1,07 H/L, то есть 0,5–0,8 трубы. Формула Taylor–Lee с B = 2 (1,34…0,50) выше трубы у крутых хребтов (H/L ≥ 0,53: 1,06–1,34 против 0,68–1,08) — она годится для H/L ≲ 0,4, поэтому «обычное завышение» относится к ней, а не к потенциальной схеме.
2. Измеренное превышает потенциальный предел в 1,2 (UCD, H8) … 1,8 раза (G&I): это внутренний слой Jackson–Hunt, в потенциальной схеме отсутствует — вклад неотделим сканом (он вне схемы, а не «параметр»).
3. Профиль фона в `bg_profile` ещё занижает: нормальный поток через панель задаётся фоном у самой земли (малым), поэтому ΔS в 0,4–0,5 от однородного (σ = 0, α 0,15: 0,32 против 0,65 у H3); сглаживание σ = 250 м частично компенсирует (поднимает фон у гребня), что и маскирует недобор в SWC-12.
4. Высота: в SWC-12 UCD сравнивали на 0,05 H (0,54), а труба дала 0,68 на 0,13 H; на 0,13 H схема SWC-12 даёт 0,39 (57 % от 0,68), то есть недобор больше, чем в SWC-12 (79 %).
5. H3/H5/H8 — «параметрическая» форма, не cos²: её нет в статье, возможная разница не оценена; на UCD (cos², α = 0,19 известны) недобор у однородного фона 28 %, у SWC-12 — 43 %.

### Погрешность эталона P50
P25 для fields не восстановлен (только dx 400…50). Метод: консервативное осреднение 2×2 дочерних клеток P50 (все четыре — воздух) без интерполяции против значения P100 той же клетки; порядок сходимости по тройке P200–P100–P50 (`ref_err.py`, `picard_err.json`).

| случай | E(P100↔P50), СКО по полю / U10 | то же, слой до 100 м | порядок p (всё поле / до 100 м) | оценка ошибки P50 в слое до 100 м (E/(2^p−1)) |
|---|---|---|---|---|
| C1 | 1,1 % | 4,1 % | 0,61 / 0,79 | 5,6 % U10 |
| C2 | 1,3 % | 4,0 % | 1,36 / 0,79 | 5,4 % U10 |
| C4 | 1,7 % | 6,7 % | 0,50 / 0,69 | 10,9 % U10 |

Точечная |P100r − P50| / max(|u|, 0,3·U10) (пол 0,3·U10 в знаменателе — для малых u в роторе и у подножия, как в `ref_err.py`), медиана по группам высот (только клетки без смешанных детей): нижняя клетка 8 % (C1), 4 % (C2), 22 % (C4); до 25 м ещё 8 / 5 / 11 %; ~50 м 1 / 4 / 6 %; ~300 м 0,4 / 0,9 / 1,0 %; максимумы 15 / 18 / 45 % у земли, до 42 % на 50 м (C2), ≤ 3,3 % на 300 м; в группе 2–5 точек. С множителем 1/(2^p−1) ≈ 1,4–1,6 это даёт **погрешность P50 7–33 % от локальной скорости в двух нижних клетках, 2–9 % на ~50 м, ≤ 1,5 % на ~300 м**. Независимая оценка по полю: E_u(P50↔P25) = 3,1–3,6 % U_ref (`cascade_2d/cases/convergence.md`, ROI). Порядок p < 1 из-за ступенчатой маски рельефа (staircase) и оценки по тройке грубых сеток; число — оценка сверху на порядок, а не точное.

Следствие: с шириной допуска 15 % + 1,5·|P100r−P50| точечно в допуск попадают 29/52 (pot) и 31/52 (vortex) сопоставимых точек (в узком допуске 24/60 и 26/60) — паритет у земли всё равно нет: медиана |err|/u_ref у панелей 0,6 / 1,1 / 0,7 в нижней клетке (C1 / C2 / C4) против 4–22 % разности P100↔P50 у эталона.

## Границы применимости
Потенциальный вариант, ds_min 25 м; ΔS-скан — без вихрей; фон трубы — степенной (α 0,19 только для UC Davis, у EPA/G&I профили неизвестны); формы H3/H5/H8 и G&I не воспроизведены; Pikar P50 — модель ±15 %, а не измерение; эталон «центр клетки» несёт ступенчатую маску (смещение эффективной стенки до ±6 м, нижние клетки — неопределённость по высоте до 100 % при z_agl 1–4 м).
