# Слой мелкой воды над рельефом: литература и связь с моделью игры (SWC-1)

Обзор постановок для этапа 1 плана [sw-charges](../../plan/sw-charges.md): что берём в решатель `swc` (контракт SW1 v1, модель Рипа), какие режимы по Fr ждём от теории и как перевести условия игры в `ref` {h0, b0, U0} и `physics.cd`. Метки надёжности: **[рец.]** — рецензируемая статья, **[кн.]** — книга, **[сверено]** — автор, год, журнал, том, страницы подтверждены поиском 2026-11-08 (содержание статей не читано, кроме аннотаций), **[не сверено]** — ссылка по памяти автора обзора: на неё не опираются ни формулы разделов 2, 4, 5, 7, ни правило R1, ни числа по умолчанию; перед цитированием в публичном тексте сверить. Формулы разделов 2, 5 (c_d), 7 выведены здесь и проверены численно, а не взяты из источников.

## 1. Постановка: одно- и двухслойная мелкая вода, reduced gravity

Слой плотной (холодной, перемешанной) жидкости толщины h под покоящимся лёгким слоем: гидростатика, давление в слое p = ρ·g′·(M − z), η = z_b + h, g′ = g·Δθ/θ0 [Gill 1982, гл. 6; Vallis 2017, гл. 3 — кн.]. Уравнения Рипа (SW1) — это мелкая вода с переменной плавучестью b в слое: сохраняются h, h·u, h·b; давление ½·b·h², донный член −h·b·∇z_b. Ripa 1993/1995 показал сохранение энергии и «термодинамику» такой модели [Ripa 1993, 1995 — рец., сверено]. Двухслойная постановка (оба слоя подвижны) нужна, когда верхний слой тоже течёт и есть внутренний гидравлический контроль [Armi 1986 — не сверено]; для v1 берём однослойную (верхний слой покоится) — этого достаточно для вопроса «блокирование/обтекание/прыжок», но не воспроизводит возмущение давления вышележащей атмосферы (внутренние волны выше инверсии уходят вверх и дают сопротивление, которого в модели нет).

Скорость длинных волн на поверхности слоя c = √(g′h); число Фруда Fr = |u|/√(g′h). Характеристики системы: u ± c (и u для b). Гидростатическое приближение требует h ≪ длины рельефа; при крутизне s ≈ 0,3 и ширине холма в несколько h допущение нарушается (нет нелинейно-негидростатических волн; по [Vosper 2004] интерфейсные волны в игре тоже не нужны, но их длина λ ≈ 2π·U/N_интерф. должна быть больше шага сетки).

## 2. Течение над рельефом: режимы по Fr, критическая высота, прыжок перед препятствием, бор, подветренный прыжок

Обозначения: F0 = U0/√(g′h0), M = hm/h0 (высота препятствия в толщинах слоя), глубины в единицах h0, скорости в √(g′h0), g′ = 1, q = h·U — расход. **Все формулы этого раздела выведены здесь** из уравнений мелкой воды (сохранение массы, импульса на разрыве, энергии на гладких участках) и проверены численно (скрипт `swc1_regimes.py`, ниже «Проверка»); литература [3–6, 8, 18] задаёт рамку и качественные режимы, но числа из неё не берутся (метки надёжности — в разделе 9). Классическая постановка — [Long 1954, 1970; Houghton & Kasahara 1968; Baines 1995, гл. 2].

**2.1 Критическая высота M_c (гладкое течение, без потерь).** Критическое сечение (Fr = 1) на гребне: h_c = q^(2/3) = F0^(2/3); Бернулли E0 = 1 + F0²/2 = M + (3/2)h_c, откуда

**M_c(F0) = 1 + F0²/2 − (3/2)·F0^(2/3)** (F0 = 1 ⇒ 0; F0 → 0 ⇒ 1).

При M < M_c гладкое течение без потерь существует: докритическое (F0 < 1) — слой над гребнем тоньше, скорость больше; сверхкритическое (F0 > 1) — слой над гребнем толще, скорость меньше. При M > M_c гладкое стационарное течение невозможно — нужна диссипация (прыжок/бор).

**2.2 Стационарный прыжок перед препятствием, кривая M_s(F0), F0 > 1.** Сверхкритический поток F0 > 1 может перейти в докритическое состояние стационарным гидравлическим прыжком (Бернулли–Бланже): сопряжённая глубина h1/h0 = (√(1 + 8F0²) − 1)/2, скорость U1 = F0/h1, энергия после прыжка E1 = h1 + U1²/2 < E0 (потеря (h1 − 1)³/(4h1)). Если прыжок стоит на плоском дне у подножия препятствия, а на гребне после него течение ровно критическое (расход тот же, q = F0), то

**M_s(F0) = E1 − (3/2)·F0^(2/3), E1 = h1 + F0²/(2h1²).**

Для M ≤ M_s после такого прыжка поток проходит гребень докритическим. Очевидно E1 < E0 ⇒ **M_s < M_c** при F0 > 1 (прыжок у подножия — наименее выгодное положение по энергии; формула M_s выведена здесь, в источниках не сверялась). Если прыжок стоит на наветренном склоне, где локальное число Фруда ниже F0, потеря энергии меньше; энергия после прыжка (с учётом высоты дна) возрастает от значения для подножия (M = M_s) до E0 (прыжок у самого гребня, M = M_c): положение прыжка на склоне параметризуется M ∈ (M_s, M_c).

**2.3 Гистерезис при F0 > 1 (M_s < M < M_c).** В этой полосе стационарны два решения: (а) гладкое сверхкритическое (R2 ниже), (б) прыжок на наветренном склоне, докритическое течение до гребня, критическое на гребне, сверхкритическое на подветренной стороне. Какое из них реализуется — зависит от предыстории: при росте M от малых значений остаётся (а) до M = M_c, при падении M с больших значений (прыжок/бор уже ушёл вверх по потоку) остаётся (б) до M = M_s. Устойчивость каждой ветви и ширину полосы в 2D-решателе с конечной диссипацией нужно **проверить опытом** (медленный подъём и спуск M, SWC-3): положение прыжка задаёт ещё условие вниз по течению (2.5); две ветви следуют из M_s < M_c, их устойчивость не доказана. Для F0 ≤ 1 гистерезиса в этой постановке нет.

**2.4 Бор вверх по потоку при M > M_c (F0 < 1) и при M > M_s (F0 > 1, нестационарно).** Если гладкое решение не существует, перед препятствием образуется бор: фронт скачка идёт вверх по потоку со скоростью s (в единицах √(g′h0)), оставляя за собой слой толщиной h1 и скорость U1. На фронте — соотношения Бланже в системе, движущейся со скоростью бора: число Фруда набегания Fb = F0 + s, h1 = (√(1 + 8Fb²) − 1)/2, т.е. Fb = √(h1(h1 + 1)/2), s = Fb − F0, U1 = Fb/h1 − s. Стационарное состояние за бором устанавливается, когда на гребне критичность: h1 + U1²/2 = M + (3/2)(h1U1)^(2/3) — это уравнение для h1 при данных (F0, M). Расход через гребень уменьшается: q1 = h1U1 < F0.

Результаты (раздел 10; тройки h1/h0, s, U1): F0 = 0,5: M = 0,216 → 1,030; 0,523; 0,470; M = 0,36 → 1,133; 0,599; 0,371; M = 0,9 → 1,39; 0,789; 0,138. F0 = 0,3, M = 0,9 → 1,227; 0,869; 0,084. F0 > 1: s = 0 ровно при M = M_s (контроль), при M = M_c: s = 0,008; 0,045; 0,147; 0,418 и h1/h0 = 1,28; 1,74; 2,58; 4,36 (F0 = 1,2; 1,5; 2; 3). Слабый бор (h1 − 1 ≈ 0,02–0,05, s ≈ 0,3–0,6 при F0 = 0,5–0,7) всё равно уходит от препятствия до границы области — отсюда требования к губке и характеристическим краям.

**2.5 Подветренная сторона: сверхкритическое течение и прыжок.** За гребнем при критичности на гребне течение переходит в сверхкритическое; глубина на плоском дне h_s решает h_s + q²/(2h_s²) = E (E — полная энергия за гребнем, = M + 1,5q^(2/3)), Fs = q/h_s^(3/2), прыжок на сопряжённую глубину h_j = h_s(√(1 + 8Fs²) − 1)/2. Примеры (h_s; Fs; h_j): F0 = 0,5, M = M_c = 0,18 → 0,422; 1,83; 0,899; M = 0,36 (бор) → 0,316; 2,37; 0,912; F0 = 0,3, M = 0,559 → 0,164; 3,41; 0,713. Положение прыжка определяет глубина вниз по течению h_d: h_d = h_j — у подножия; h_d > h_j — прыжок «затоплен» и уходит вверх по подветренному склону; h_d < h_j — сносится вниз. При h_d = h0 = 1 > h_j прыжок сидит на склоне (механизм «подветренной бури» Klemp–Lilly [11], Durran [12] — качественно, числа не оттуда). Потери в прыжке обеспечивает схема.

Критерий установления (SW3 «steady») в R3, R5 не достигается на конечной области без губки: бор уходит из области; фиксируйте бор по `h` на расстоянии X перед препятствием и по времени прихода (t = X/s), а не по steady.

Трёхмерные эффекты (круглый холм): след за холмом и срыв вихрей в однослойной мелкой воде — **[Schär & Smith 1993a, b — рец., сверено только заголовки и страницы]**: завихренность рождается на диссипативных участках (прыжок) и сносится в след; границы режимов срыва (по Fr и hm/h0) брать из Part II, этот обзор их не приводит. Это основа ожиданий для этапа 1(б), но не для 2D-случая.
**Связь с «фазами» игры** [air_phase_results.md](../air_phase_results.md): порог блокирования в игре — по Fr_game = U_sat/(N·H), по неподвижным точкам Пикара Fr_c ≈ 0,8–1,1 для хребтов и уступов. В мелкой воде критерий — M_c(Fr0) (верхняя часть таблицы выше) и поле зависит от двух чисел (Fr0, M), а не от одного; формы Fr_game и M_c(Fr0) согласуются так: при g′ = N²·z_i (см. раздел 7) Fr0 = Fr_game·M, поэтому порог M = M_c(Fr0) даёт Fr_game,c = Fr0/M: M = 0,2 → 2,4; 0,3 → 1,22; 0,5 → 0,41; 0,7 → 0,13. Порядок величины 1 при M ≈ 0,3 совпадает с играющим порогом; смысл проверки — сверить Fr_game,c(M) с таблицей AP-опытов. Это **предсказание теории, не вывод**: слоистая атмосфера с непрерывной N даёт «разделяющую линию тока» H_c = H(1 − Fr) [Sheppard 1956; Snyder и др. 1985 — не сверено], а не критическую высоту скачком.

## 3. Непрерывная стратификация против слоя: что теряем

Непрерывная N между землёй и крышкой глубины D: первая мода c1 = N·D/π; два слоя с той же полной разностью θ (g′ = N²·D) дают c = N·D, т.е. g′ = N²·z_i — верхняя оценка скорости волн, а мягкая инверсия сдвигает порог блокирования к бо́льшим Fr_game. Сравнивать с Пикаром надо режимы и положение порога, а не скорости вне слоя. Winters & Armi 2012 [рец., сверено]: для непрерывной N гидравлика сводится к редуцированной гравитации, привязанной к толщине струй, а не к N на всей глубине — это за схему (h0, b0) из «эффективной» инверсии. Vosper 2004 [рец., сверено]: ниже критического инверсионного Fr над инверсией возникает резонансная лее-волна, ещё ниже — прыжок над склоном; однослойная модель воспроизводит прыжок, но не волну выше инверсии.

## 4. Стоки и подъём: слой как гравитационное течение по склону

- **Катабатика (холодный слой, b > 0)** — уже в уравнениях Рипа: сила −h·b·∇z_b даёт ускорение вдоль уклона g′·sin α. Классические модели: Prandtl (1942, стационарный профиль «струи» — как в `AirPhase.prandtl`); интегральные модели с вовлечением [Ellison & Turner 1959; Manins & Sawford 1979 — рец., сверено]; трение и скорость стока 1–4 м/с, толщина 10–100 м [Zardi & Whiteman 2013 — не сверено; Haiden & Whiteman 2005 — не сверено]. Баланс трение/плавучесть при установлении на уклоне: u² = g′·h·sin α/(c_d + E·sin α…) — порядок величины для проверки (u ≈ √(g′·h·sin α/c_d) без вовлечения). Холодные озёра в долинах — «сухие» клетки рельефа выше слоя + выравнивание M (боковой гидравлический контроль на перегибах) — ровно то, что решает мелкая вода; в `AirPhase` долины решались D8-расходом.
- **Анабатика (подъём по прогретому склону) в рамке Рипа — вывод и проверка.** Решение координатора: SW1 v1 не меняется, b > 0 (слой перемешивания тяжелее воздуха над инверсией), нагрев уменьшает b над прогретым склоном. Проверка из самих уравнений: градиент давления в слое с переменным b равен ∇(½bh²) + h·b·∇z_b = h·b·∇η + ½h²·∇b (η = z_b + h), т.е. ускорение слоя = −b·∇η − ½h·∇b. Второй член направлен к **меньшему** b: слой течёт к прогретому месту (механизм горно-долинного ветра / бриза — Бьеркнес-циркуляция в рамке Рипа), без инвертированного слоя. Нагрев попадает в b через (g/θ0)·Q/(ρc_p) на единицу площади и *делится на h*: dθ/dt = Q/(ρ c_p h) — над гребнем слой тоньше, греется сильнее, b меньше, поток к гребню — подъём по склону возникает и при постоянном Q. Ограничения: (1) это механизм «гора — равнина» (горизонтальный градиент давления в слое), а не ламинарный/турбулентный пограничный слой Прандтля у стенки (толщина 10–100 м, скорость 1–4 м/с [Fedorovich & Shapiro 2009 — Acta Geophys. 57, 981–1010, сверено; Zardi & Whiteman 2013 — не сверено]): тот не разрешается слоем в сотни метров; (2) при Q > 0 слой нагревается, b → b_min, и дальше нужны вовлечение и рост слоя (конвективный пограничный слой пробивает инверсию) — это граница модели, считается в `b_clipped` SW3; (3) критерий возникновения турбулентной анабатики — Princevac & Fernando 2007, Phys. Fluids 19, 105102 (сверено; год по журналу 2007, не 2008). **Литература по «тепловой мелкой воде» для бризов и склоновых ветров не найдена** (поиск 2026-11-08): модель Рипа [Ripa 1993, 1995 — сверено] описана и применялась для океана (потоки тепла через поверхность; в одно-слойной версии линейные волны близки к первым двум вертикальным модам [Ripa 1995]), атмосферное применение — не подтверждено; рассуждение выше — **вывод из уравнений, проверить опытом** (квази-2D склон с Q > 0 в SWC-3: ожидаем течение к меньшему b и вверх по склону, скорость порядка √(½·h·|Δb|) на масштабе нагрева).
- **Фронт гравитационного течения:** U_f = Fr_f·√(g′h), Fr_f = √2 для глубокого окружения (энергосберегающий, идеализация) [Benjamin 1968 — рец., сверено], ≈ 1,19 в экспериментах lock-exchange [Huppert & Simpson 1980 — рец., сверено; Simpson 1997 — не сверено]. Для проверки скорости фронта холодного стока на плоской ровной дороге (тест схемы).

## 5. Трение о землю и вовлечение на верхней границе

- Квадратичное трение c_d·|u|·u (SW1): **вывод**, не цитата. Для логарифмического профиля u(z) = (u*/κ)·ln(z/z0) среднее по слою (z0, h) равно ⟨U⟩ = (u*/κ)(ln(h/z0) − 1) = (u*/κ)·ln(0,37h/z0) (e⁻¹ = 0,368), и напряжение u*² = c_d·⟨U⟩² даёт c_d = [κ/ln(0,37h/z0)]², κ = 0,4. Для z0 = 0,1 м, h = 500 м: c_d ≈ 0,0038 (проверено); z0 = 1 м — 0,0064. Диапазон 0,003–0,01 — оценка; допущение — слой нейтральный и логарифмический до h (в игре профиль степенной с насыщением, `limits.md`; поэтому c_d задаётся как параметр, не как калибровка). В `AirPhase` для стока C_D = 0,01 — оценка, не калибровка. [Gill 1982; Mahrt 1982 — не сверено, на них правило не опирается.]
- Вовлечение (в v1 нет, по контракту). Ellison & Turner 1959, J. Fluid Mech. 6, 423–448, DOI 10.1017/S0022112059000738 (сверено): скорость вовлечения w_e = U·E(Ri), Ri = g′h/U². Вид E = (0,08 − 0,1Ri)/(1 + 5Ri) (Ri < 0,8; E → 0,08 при Ri → 0, ≈ 0 при 0,8) — **по вторичному источнику, с оригиналом не сверен**; полевые данные дают вовлечение и при Ri > 0,8 (вторичный источник). Числа по умолчанию (R1) на вовлечение не опираются. Дневной рост слоя (инкапсуляция: Tennekes 1973, Stull 1988 — не сверено) в v1 тоже отсутствует; тепло входит в b (SW1, третье уравнение), h постоянно — дневное поведение сильно упрощено.
- Кориолис f·h·k×u включён в SW1; при L < 50 км и U ≈ 5 м/с число Россби U/(fL) ≫ 1 — малое.

## 6. Численные схемы и граничные условия (для Rust-решателя)

Обязательно баланс «озера в покое» (η = const, u = 0 при любом z_b), иначе рельеф порождает паразитные течения. Гидростатическая реконструкция + HLL/Rusanov [Audusse и др. 2004 — рец., сверено]; позитивность, сухие клетки [Kurganov & Petrova 2007 — сверено; Brufau и др. 2002 — не сверено]; для Рипа (переменное b) — проверка на баланс при b = const и на разрыве b [Touma & Klingenberg 2015 — рец., сверено]. Открытые границы: характеристические инварианты + губка (SW1) [Klemp & Lilly 1978 — не сверено]. CFL: Δt ≤ cfl·Δx/(|u| + √(b·h)) (в 2D 0,45–0,5 — по замеру).

## 7. Правило перевода условий игры в ref (h0, b0, U0, c_d)

Условия игры — U10, N, z_i, Δθ, нагрев (профиль и классы — [limits.md](../../guide/air-model/limits.md): U(z) = U10·(z/10)^α до z_sat, дальше постоянный; N — среднее √(g/θ0·γ) в слое z_i … z_i + n_layer_m; U_sat — амплитуда профиля притока `AirCase.u_a`). Предлагается правило **R1** (для опытов этапа 1; все числа — гипотезы, подлежат проверке опытом):

1. **h0 = z_i** (высота перемешанного слоя/инверсии; при отсутствии — 0,3·h_нейтр. слоя из `limits.md`, или высота хребта + запас, но тогда b0 ниже — отдельный случай).
2. **U0 = ⟨U⟩ по слою** от 0 до h0: U0 = [∫₀^{z_sat} U10·(z/10)^α dz + U_sat·(h0 − z_sat)]/h0 при h0 > z_sat; при h0 ≤ z_sat ⟨U⟩ = U10·10^(−α)·h0^α/(1 + α) (интеграл степенной функции). Профиль притока берётся из игры, не пересчитывается.
3. **b0 = g·Δθ/θ0**. Если Δθ задан инверсией явно — использовать его. Если известна только N в свободной атмосфере: Δθ = θ0·N²·δ/g на конечной толщине δ = n_layer_m (физичный вариант, пока δ ≪ h0) — либо «верхняя оценка» b0 = N²·h0 (c = N·h0, раздел 3). **Ожидать несовпадения**: b0 = N²·h0 завышает c, и порог блокирования уйдёт к бо́льшим Fr_game. Выбор варианта — по таблице режимов (SWC-3, сравнение с `air_phase_results.md`), а не наперёд.
4. **c_d** = [κ/ln(0,37·h0/z0)]²; z0 — по классу покрова игры (`SurfaceHeat`), со средним по области в v1.
5. **Нагрев**: q_heat (SW1) = поток тепла `SurfaceHeat` (Вт/м², + нагрев) на участке слоя; dθ/dt = Q/(ρ c_p h) — например 100 Вт/м² за 1 ч при h = 500 м и ρ c_p = 1200 Дж/(м³·К): Δθ слоя = 360 000/(1200·500) = 0,6 К. Ночью Q < 0 (Rn ≈ −30…−100 Вт/м² из `SurfaceHeat`) делает слой холоднее — b растёт ⇒ сток (катабатика); днём Q > 0 уменьшает b над склоном; течение к меньшему b даёт подъём (раздел 4), b → b_min — граница модели.
6. **Масштабная проверка**: Fr0 = U0/√(b0·h0), M = H/h0, c = √(b0·h0) (при Δθ = 5 К, θ0 = 290 К, h0 = 500 м: b0 = 0,17 м/с², c ≈ 9,2 м/с; при Δθ = 1 К: c ≈ 4,1 м/с). Эти же числа идут в `mapping` SW1 (поле `rule` = "docs/research/sw_charges/literature.md §7 R1").

**Границы применимости R1:** (а) одна инверсия, плоский профиль внутри слоя; (б) вертикальная структура профиля ветра сведена к U0, поэтому «разгон на гребне» слоя — величина средней скорости, а не скорость на 10 м (нужен коэффициент перехода к 10 м/50 м/300 м из профиля — задача сравнения с Пикаром); (в) нет вовлечения, нет роста слоя; (г) слабый ветер (U10 < 1 м/с) — Fr0 → 0, режим «полного блокирования»: результат определяется стоком и нагревом, а не U0.

## 8. Что берём, чего не берём, риски

Берём: однослойная модель Рипа (SW1), HLL + гидростатическая реконструкция, критерий M_c(Fr0) и сопряжённые толщины прыжка как *проверочные* аналитические пределы (SWC-3), стандартные c_d и R1; сравнение порога блокирования — таблицей Fr_game,c(M). Не берём: двухслойную модель (после этапа 1), вовлечение (после — по результату), нелинейно-негидростатические эффекты. Риски: (1) эквивалентность «слой ↔ N» (раздел 3) и неоднозначность Δθ — главный источник расхождения с Пикаром; (2) анабатика: по решению координатора b > 0, нагрев уменьшает b (раздел 4, вывод из уравнений, проверить опытом); (3) 3D: след/срыв вихрей зависят от трения и Кориолиса [Schär & Smith 1993b; эффект донного трения в SW — Schär & Smith, Tellus/QJ — не проверено]; (4) U0 из степенного профиля — не измерение. Проверка расчёта — раздел 10.

## 10. Проверка расчёта

Числа разделов 2 и 7 получены скриптом ниже (Python 3, stdlib; в репозитории не хранится — граница задачи; для опытов перенести в `tools/research/sw_charges/`). Контроль: F0 = 1 ⇒ M_c = M_s = 0; при M = M_s бор s = 0; при M = M_c (F0 = 0,5) q = F0, E = 1,125 — совпало. Вызовы: `Mc`, `Ms`, `bore(F, M)`, `lee(q, E)` (E = M + 1,5·q^(2/3), q = h1·U1).

```python
from math import sqrt
Mc=lambda F:1+F*F/2-1.5*F**(2/3)
def Ms(F):
    h1=(sqrt(1+8*F*F)-1)/2; return h1+F*F/(2*h1*h1)-1.5*F**(2/3),h1
def bore(F,M):  # (h1, s, U1) за бором; ищем h1, при котором гребень критичен
    st=lambda h:(sqrt(h*(h+1)/2)-F, sqrt(h*(h+1)/2)/h-(sqrt(h*(h+1)/2)-F))
    def g(h):
        s,U=st(h); return None if U<=0 else h+U*U/2-M-1.5*(h*U)**(2/3)
    prev=None
    for i in range(1,8000):
        h=1+i*0.0005; v=g(h)
        if v is None: return None
        if prev is not None and prev[1]<0<=v:
            a,b=prev[0],h
            for _ in range(80):
                m=(a+b)/2
                if g(m)<0: a=m
                else: b=m
            return (a,)+st(a)
        prev=(h,v)
def lee(q,E):  # сверхкритическая глубина за гребнем, Fs, сопряжённая глубина
    a,b=1e-6,q**(2/3)
    for _ in range(100):
        m=(a+b)/2
        if m+q*q/(2*m*m)>E: a=m
        else: b=m
    Fs=q/a**1.5; return a,Fs,a*(sqrt(1+8*Fs*Fs)-1)/2
```
