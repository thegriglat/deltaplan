# Прототип A: вихревые частицы с плавучестью, 2D (SWC-6, этап 3б)

Спецификация — `unified-scales.md`, «Прототип A», шаги 1–2 (шаг 3 с рельефом не делался). Код, команды, сырьё — `tools/research/sw_charges/proto_a/` (README там); итоговые числа — `out/results.json` (`step1`, `step2`, `criterion`, `timing`).

**Вердикт:** частично — на ранней фазе (t√(b/R) ≲ 2, для R = 100 м, Δθ = 1 К до ≈ 60–90 с) одно уравнение Dω/Dt = ∂b/∂x даёт кольцо опускания, ∫w dx = 0, скорость пятна 0,93–0,95 от 0,5·b·t и точечную пару 0,19·b·t без заданных профилей; дальше без перегруппировки частиц импульс теряется (до 0,72 B·t за 10 мин), КГ-слой растёт на 0,6–0,7 теории, а σ_w в 2D в 1,8 раза выше нынешней модели.

## Постановка
- Уравнения: ω = ∂w/∂x − ∂u/∂z, Dω/Dt = ∂b/∂x, b = g·Δθ/θ0 (θ0 = 300 К, b = 0,0327 м/с² при 1 К), Db/Dt = 0 (без перемешивания, без вовлечения, без сопротивления). Частица — (x, z, Γ = ω·A, b, A); ядро Лэмба — Озеена, σ = 1,5·h (h — шаг решётки, σ = 2,86 м); ∂b/∂x в точке — свёртка с производной гауссиана тем же σ; RK2 (Хойн), dt = 1 с.
- Скорость — прямая сумма O(N²), RawKernel CuPy, двойная точность; земля z = 0 и крышка z = 1200 м — изображения противоположного знака (k = −1…1 отражений), период по x — копии.
- Шаг 1: пятно R = 100 м, b = const внутри, центр (1500; 400) м, область 3 × 1,2 км, 9967 частиц в пятне + пояс (см. ниже), всего 11 601. Прогон 150 с.
- Шаг 2: слой tanh, u = (ΔU/2)·tanh(z/δ), ΔU = 3 м/с, δ = 10 м (толщина по завихрённости 20 м), на высоте 200 м (в расчёте z′ = z − 200), период L = 848 м = 6 самых быстрых волн (λ = 2πδ/0,4446 = 141 м), 5300 частиц (шаг 4 м, σ = 6 м), возмущение моды 6 амплитуда 0,3 м + шум 0,02 м, 300 с, dt = 0,5 с. Без земли, крышки и плавучести: чистая КГ-проверка.

**Найденная и исправленная ошибка метода (важно для любого продолжения).** Если частицы несут завихрённость только внутри пятна, половина сглаженного градиента b падает наружу, где частиц нет, и источник ω вдвое слабее: первый прогон дал v, Γ, P и KE ровно вдвое меньше ожидаемого (отношения 0,50). Лечится поясом частиц шириной 3,5σ вокруг пятна с b = 0 (завихрённость они несут). После пояса все четыре отношения → 0,95–1,0. Верно для любого метода, где baroclinic-источник считается по частицам.

- **a = b/2.** Ускорение в начале 0,477·b (v/(0,5·b·t) = 0,95–0,96 при t = 10–30 с), т. е. ≈ 4,5 % ниже присоединённой массы; заданного закона нет. Допуск ±30 % выдержан до t ≈ 100 с (при t = 90 — 0,81). Позже пятно сворачивается в шляпу/кольцо, присоединённая масса и форма меняются, v перестаёт быть 0,5·b·t (это физика без вовлечения, не сбой; с t√(b/R) ≈ 2,7 за 150 с).
- **Циркуляция и расстояние.** Γ_пол = −2bRt с точностью 3 % (t ≤ 60), расстояние между центрами вихрей 160 м против πR/2 = 157 м (+2 %). Σ Γ = 0 до 4·10⁻¹⁰.
- **Расхождение двух скоростей (замечание ревью).** Точечная пара с измеренными Γ и d: U = Γ/(2πd) = 0,193·b·t (теория 2/π² = 0,203); скорость пятна — 0,477·b·t. Ровно в 2,5 раза (0,477/0,193 = 2,47). Причина — конечное ядро: у толстого пятна завихрённость не сосредоточена в двух точках, а распределена по ободу, и скорость центра пятна определяется самоиндукцией всего распределения (и присоединённой массой), а не полем двух точек. Оба числа получаются из одного кода; противоречия нет, если сравнивать пятно с 0,5·b·t, а пару — с 0,2·b·t.
- **Сохранение, 150 с.** Γ_общая = 0 (антисимметрия); B = const по построению (b не меняется, перемешивания нет); P/(B·t) 0,998 → 0,985 (90 с) → 0,83 (150 с); энергия KE + ΔPE: KE/ΔPE = 0,99 (30 с), 0,985 (60 с), 0,90 (120 с). Энергия сохраняется до 1,5 % на t ≤ 60 с (в KE входит и кинетическая энергия самого пятна — присоединённая масса там даёт половину).
- **Длинный прогон 10 мин** (Δθ = 1/10 К, t√(b/R) = 3,4): P/(B·t) = 0,998 (100 с), 0,979 (300 с), **0,715 (600 с)**; без стенок и при N = 10⁴ / 2·10⁴: 0,722 / 0,720; при σ = 2,5·h: 0,814. Критерий «дрейф ≤ 1 % за 10 мин» **не выполнен**: потеря не от земли и крышки и не лечится числом частиц, а от слишком мелкой σ (чем больше σ, тем меньше потеря), т. е. от разрывов решётки в вытянутом пятне: без перегруппировки частиц baroclinic-источник теряет места, где градиент b есть, а частиц нет. Нужно: перераспределение частиц (remeshing) или панельная/сеточная часть. Критерий 1 % надо относить к времени до ≈ 300 с (2 %) для этой постановки.
- **Сходимость по N, σ** (t = 60 с, v/(0,5·b·t), Γ_пол/предсказание, P/(B·t)): N = 2500 (σ = 5,7 м): 0,917 / 1,00 / 0,999; N = 10⁴ (σ = 4,8 м): 0,923 / 0,99 / 0,999; N = 2·10⁴ (σ = 2,0 м): 0,923 / 0,94 / 0,993. Скорость пятна не зависит от N на 1 %; Γ_пол при малой σ слегка падает (~6 %): тоже начало потери при тонкой σ.

### Профиль w(x) и ∫w dx на высоте полёта (линия длиной 3 км, шаг 1 м)
Линия через центр пятна, t = 60 с: w_max = 0,93 м/с, w_min = −0,80 м/с (отношение −0,86), нуль на |x| = 102 м (≈ R); w < 0 на всех точках |x| > 1,3·R до края (100 % точек); ∫w dx / ∫w⁺ dx = **1,0 %** (t = 30: 1,0 %; t = 120: 1,4 %). Линии на ±150 м от центра по высоте: 2,2 % (ниже) и 3,7 % (выше) при t = 60, до 4,8 % при t = 120 (максимум из девяти линий 4,8 % < 5 %). Остаток — обрезание линии на ±1,5 км (хвост ~1/x²), не источник. Возврат опускания: |∫w⁻|/∫w⁺ = 0,99, причём **только 51 % возврата лежит в |x| < 2·x₀ (±205 м), 70 % в |x| < 3·x₀, 86 % в |x| < 5·x₀, 97 % в |x| < 10·x₀ (1 км)**: кольцо в 2D — медленный степенной хвост, а не локальное кольцо.

Тривиальность ∫w dx = 0: в 2D несжимаемая жидкость с ΣΓ = 0 даёт ноль на любой полной линии автоматически (ψ на ±∞ одинакова), так что проверка ловит ошибку кода, а не гипотезу. Содержательные части критерия — w < 0 при |x| > R, a = b/2, P = B·t и расстояние πR/2; они получены.

### Сравнение с ядром + кольцом Гедеона (`thermals.md`, `wind-field.md`: G(x) = e^(−x²)(1 − x²), G < 0 × ring_sink_factor = 1,6)
Гедеон подогнан к прототипу по пику (w_max = 0,93 м/с) и по нулю (x₀ = 102,5 м):
| | прототип (2D) | Гедеон, ring 1,0 | Гедеон, ring 1,6 |
|---|---|---|---|
| \|∫w⁻\| / ∫w⁺ на линии | 0,99 | 0,20 | 0,33 |
| w_min / w_max | −0,86 | −0,135 | −0,217 |
| СКО разницы с прототипом / w_max (\|x\| < 4·x₀) | — | 0,34 | 0,33 |
| ∫w dx / ∫w⁺ dx | 0,01 | 0,80 | 0,67 |
Прототип опускается в 3–6 раз сильнее и дальше; Гедеон возвращает через линию 20–33 % (в его модели ∫w = 0 выполняется по площади осесимметричного 3D-термика, а не по линии: ∫G·2πr dr = 0). Сравнение формы корректно (одна ширина, один пик), сравнение долей — нет: 2D-диполь и 3D-осесимметричный термик возвращают поток по-разному (в 3D поле диполя убывает как 1/r³, в 2D — 1/r²). Вывод по форме: профиль ядро + кольцо Гедеона в сечении — грубая подмена диполя; но доли опускания 2D-прототипа 3D-термику переносить нельзя (кольцо в 3D слабее и ближе — это задача 3D-прототипа).

## Шаг 2: сдвиговой слой ΔU = 3 м/с
- **Рождение вихрей.** Слой сворачивается в ядра (КГ): число максимумов завихрённости 23 (шум решётки, t = 0) → 15 (150 с) → 10 (200 с) → 9 (250 с) → 8 (300 с); ω_max 0,13 → 0,26 с⁻¹ (начальный максимум 0,15 с⁻¹ у sech²-профиля). Закладывали 6 волн; вихрей 8–10 из-за вторичной структуры/слияния (счёт грубый: максимум 9×9 точек, порог 0,5 от пика).
- **Пары.** В свободном слое ядра **одного знака** (все по знаку сдвига): «пара противоположных знаков» появляется только вместе со стенкой (пограничный слой земли — противоположная завихрённость, 200 м вниз), которой в шаге 2 нет. Утверждение «пары рождаются при КГ-неустойчивости» уточняется: рождаются *вихри* слоя; пары — со стенкой/поверхностью (этап 2) или при отрыве. Σ Γ дрейфа нет (точно), P_x = Σ z Γ: дрейф 4·10⁻¹² (машинный).
- **Скорость роста моды** (амплитуда смещения средней строки на волновом числе 6): сегментами по 30 с — 0,036 (30–60), 0,013, 0,016, 0,021, 0,025 с⁻¹ (150–180), потом насыщение. Подгонка 30–150 с: **0,0191 с⁻¹ = 0,67** теоретического максимума tanh-слоя 0,1897·(ΔU/2)/δ = 0,0285 с⁻¹ (90–180 с: 0,0203 = 0,71). Сетка 3 м (σ = 4,5 м, 9905 частиц): 0,0175 с⁻¹ (0,62) — **не приближается к теории при уточнении**, так что сглаживание σ не причина (по грубой оценке сглаживание утолщает слой лишь на ~10 % и должно было бы убывать с σ); вероятные причины: конкуренция мод/шум в начале, неточный замер по одной строке, неравновесное начало. Не доведено; степень доверия к ростовой оценке — ±30 %.
- **σ_w(z), σ_u(z), t = 300 с.** Пик σ_w = 0,75 м/с = **0,25·ΔU**, в полосе |z′| ≤ 50 м среднее 0,70 м/с = 0,23·ΔU; σ_u пик 0,98 м/с = 0,33·ΔU. Нынешняя модель (`turbulence.md`, слой смешения, Bell & Mehta 1990): σ_w = 0,14·ΔU = 0,42 м/с, σ_u = 0,18·ΔU = 0,54 м/с. Прототип выше в 1,8 раза по обоим. Сетка 3 м: пики 0,76 / 0,98 (не меняются). Объяснение: в 2D нет трёхмерного распада, и 6–8 крупных ядер когерентно вращаются, так что σ включает когерентную часть вдоль x; согласие с экспериментальными 3D-слоями по амплитуде не ожидается. Ширина слоя к 300 с ≈ ±140 м (zmin/zmax).
- **Спектр w(k)** на линиях 0, ±15, ±30 м: пик в k ≈ 0,037 рад/м (≈ 170 м, масштаб ядер); наклон −3,7 (0,05…0,3) и −3,4 (0,3…1) рад/м против −5/3 фон Кармана — спектр 2D когерентных ядер, не инерционный интервал. Для «турбулентности» из частиц 2D не годится — предупреждение спецификации («квантитативной турбулентности в 2D нет») подтверждено.

## Допущения, границы применимости
- 2D разрез, Буссинеск, без вязкости, без вовлечения и перемешивания (b несёт частица) — «верхняя оценка» подъёма; sticky/slippery (вовлечение) не закладывалось и не измерялось. Земля — идеальное изображение без пограничного слоя (скольжение), хотя на высоте 400 м (шаг 1) её влияние мало.
- Стенки не вносят baroclinic-член изображений (b у стенки — только в сумме от настоящих частиц); для термика в 300–500 м от земли поправка мала, у земли (этап 2, панели) надо считать отдельно.
- Фон U(z) = (u*/κ)·ln(z/z0) не вводился (шаг 1 в покое, шаг 2 с tanh-слоем): сдвиг фона и индуцированная завихрённость фона в шаге 1 не проверены.
- Критерий «σ_w(z) против turbulence.md» проверен для одного слоя; приземного и конвективного σ_w (w*, ξ^⅓) прототип не воспроизводит — там источник плавучесть + стенка этапа 2.
- Рост КГ — 0,6–0,7 теории, не доведён до причины. Счёт ядер грубый. Нет сравнения с эталонным решателем (на сетке/спектральным).

## Что это значит для выбора
- **Годится** как единое описание на ранней фазе подъёма: диполь, кольцо, a = b/2, P = B·t и U = 0,19·b·t из одного уравнения, без заданных профилей (критерий задания выполнен на t ≤ 60 с: кольцо w < 0 на 100 %, ∫w dx = 1,0–1,4 % ядерной линии, скорость 0,93–0,96).
- **Не годится как есть:** (1) потеря импульса при t√(b/R) > 2,5 → нужен remeshing; (2) 2D σ_w в 1,8 раза выше нынешней модели, спектр −3,5 — турбулентность из 2D-частиц нельзя ставить в игру без 3D-растяжения и масштабной привязки; (3) стоимость — 43 мс на 10⁴ частиц в FP64.
- Рекомендация: брать A как *источник организованных структур* (термик + кольцо, слои сдвига) с перегруппировкой; шумовой фон (σ_w, спектр) оставить моделью масштаба 3; решение по сравнению с прототипом B — в этапе сравнения.
