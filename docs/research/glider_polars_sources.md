## 1. Главный вывод

- **Готовой базы поляр современных дельтапланов в открытом доступе нет.** Полярой в виде чисел (три точки
  «скорость/снижение» или коэффициенты) публично снабжены единицы: обобщённые «Delta USHPA-2/3/4» и одна
  «T2C-класс» (XCSoar/LK8000), плюс двухточечные «нормативы» Wills Wing для приборов Bräuniger. Ни Moyes, ни Aeros,
  ни Icaro, ни Airborne в XCSoar/LK8000 отдельными записями нет (проверено по `PolarStore.cpp` и полному списку
  файлов `_Polars` LK8000, 157 файлов).
- **Технические характеристики (площадь, размах, удлинение, масса крыла, диапазон полётной массы, Vne, Va, скорость
  сваливания, трим) — есть, и по большинству крыльев легко.** Источник — официальные руководства и страницы моделей,
  DHV-база (публичная). Машинно разбирается HTML/PDF-текст.
- **Поляры производители не публикуют**: Wills Wing прямо пишет, что не публикует L/D («политика 20 лет») и даёт только
  «оценочные» поляры для приборов; Moyes даёт одно число «best glide 15:1 при 28 mph» (Litespeed S) и скорости.
  Настоящие поляры — только лётные измерения (GPS-логи, Idaflieg-подобных измерений для дельтапланов в открытом
  доступе не нашлось).
- **Лучший путь для игры:** брать из открытых данных паспортные поля (геометрия, массы, скорости), а поляру
  строить самим: якоря — мин. снижение/лучшее качество/скорости из руководства и оценок WW, форма — по
  модели `configs/wings/*.json` (`polar.points_kmh_ms`, `reference`). Автоматизировать можно сбор паспортов;
  поляры — ручная калибровка по нескольким репрезентативным классам с явной пометкой «оценка».

## 3. Примеры реально полученных поляр

Скорость в км/ч, снижение в м/с. «Качество» = V/3,6 / w; кривые между точками я не строил (три точки задают лишь три значения качества).

Точки: (35,5; 0,85), (47,5; 0,97), (80,0; 2,54). Качество: 11,6 / **13,6** / 8,7; мин. снижение 0,85 м/с на 35,5 км/ч. Комментарий файла: «Hi performance hang glider competition 2018 (T2C, Laminal, Combat …)» — это класс, а не конкретная модель.
2. **XCSoar, `PolarStore.cpp`, строка 105**: «Delta USHPA-3», масса 100 кг, точки (37; 0,95), (48,1; 1,15), (73; 3,6), площадь 0 (не задана). Качество 10,8 / **11,6** / 5,6. Строки 104 (USHPA-2: 30/1,10; 44,3/1,52; 58/3,6 → до 8,1) и 106 (USHPA-4: 37/0,89; 48,3/1,02; 76,5/3,3 → до 13,1) — обобщённые классы, дата в LK-копии `091217`.
3. **Wills Wing Polar Data, Falcon**: 215 fpm @ 19 mph и 530 fpm @ 34 mph, то есть 1,09 м/с @ 30,6 км/ч и 2,69 м/с @ 54,7 км/ч; качество 7,8 и 5,6. Тот же документ для U2/Fusion: 176 fpm @ 23 mph (0,89 м/с @ 37 км/ч) и 530 fpm @ 44 mph. Опорная масса — 130 % от минимальной пилотской + масса крыла; для другой массы скорости и снижения умножать на √(m2/m1).
4. **Паспорт вместо поляры, Moyes Litespeed S 4** (руководство v1.05, стр. «Specifications» и раздел Gliding): лучшая скорость 45 км/ч (28 mph), заявка «15:1» — ориентир для `reference.best_glide` в json; трим 34, сваливание 26, Vne 85 км/ч.

## 5. Что нужно игре и чего нет в открытых данных

Поля крыла из `configs/wings/*.json`, и что с ними:

| Поле игры | Есть в открытых данных? |
|---|---|
| `area_m2`, `span_m`, aspect ratio, `double_surface_pct`, угол при носе | да, из паспортов (WW, Moyes, Aeros, Icaro, DHV) |
| `wing_mass_kg`, `pilot_mass_min/max_kg`, оптимальная масса | да (hook-in ≈ `pilot_mass_*`; у WW ещё «optimum body weight» без снаряжения) |
| Vne, Va, `stall_speed_kmh`, трим, Vd/Vmax | да, но у разных производителей полностью не у всех (Aeros: без Vne; Icaro-руководство: без скоростей) |
| `reference.min_sink_ms`, `best_glide`, скорости, поляра `points_kmh_ms` | **нет** (только оценки WW на 2 точки для старых моделей, три-точечные «классы» в XCSoar/LK, заявка 15:1 у Moyes); Vms из плаката WW/Moyes даёт скорость минимального снижения, но не само снижение |
| `full_pull_speed_kmh`, `full_push_speed_kmh` | частично: Vmax/Vmin с VG 0/100 % есть в DHV-тест-отчётах (Alto L: 35/31 и 88/108 км/ч) и Vmax в паспортах Aeros; трапеция «до упора» — нет |
| `lift_slope_per_rad`, `zero_lift_alpha_deg`, `post_stall_cn` | нет; брать из теории/аэродинамики (для AR ~7–8 — из модели крыла) |
| `roll_*`, `pitch_time_constant_s`, `max_bank_deg`, `stall.*`, `launch.*` | нет; это динамика, публично измерений нет (есть только качественные описания в DHV-тест-отчётах: «лёгкий/средний» ролл, характер сваливания) |
| `visual.*` (хорда, стреловидность, цвета) | геометрию можно оценить из площади/размаха/угла носа; хорда, цвета — по фото |

## 6. Рекомендованный путь

1. **Автоматизировать сбор паспортов** (геометрия, массы, скорости) из HTML/PDF производителей (WW страницы моделей и
   плакат, Moyes спецификации, Aeros страница модели, Icaro руководство) плюс DHV-карточки для сертификационной
   массы, Vmin/Vmax при VG и класса. Формат — таблица `tools/…/glider_specs.json` со ссылкой и датой доступа на каждую
   запись. Стоимость: один скрипт на сайт, часы на 10–15 моделей; поддержка — при смене вёрстки сайтов.
2. **Поляру не «собирать», а строить**: для каждого класса (учебное, спортивное, безмачтовое) взять якоря из
   паспорта (Vms → скорость мин. снижения, трим, Vne, Vd) и оценки WW/Moyes (мин. снижение ≈ 0,85–0,95 м/с, лучшее
   качество ≈ 11–15, лучшая скорость 45–55 км/ч), калибровать одну общую параметрическую модель (профильное
   сопротивление + индуктивное при данном AR + сопротивление пилота и подвески), помечая в `_doc`: «оценка, не измерение».
3. **Числа XCSoar/LK не подсаживать напрямую как «поляру конкретной модели»**: они относятся к классам, не заданы для
   площади (кроме T2C) и без источника; годятся как независимая контрольная точка для класса «топлесс/сорев.» (T2C-класс
   ≈ 13,6 на 47,5 км/ч, 0,85 м/с на 35,5).
4. Если нужны реальные поляры конкретных моделей — единственный путь: собственные измерения по GPS-логам
   (обязательно с поправкой на воздух) или письменный запрос у производителя/WW; открытого источника нет.
