# Карта выбора старта и правила серверов тайлов (SA-2)

Решение пользователя 05.10.2026: подложку не заменять (OSM standard по умолчанию, OpenTopoMap второй). Проверено по коду ветки `steam-assets/SA-2` (= `feature/steam-assets`) и правилам на 05.10.2026.

## Источники правил
- OSM Tile Usage Policy: <https://operations.osmfoundation.org/policies/tiles/> (страница без даты правки; прочитана 05.10.2026 через пересказывающий загрузчик — цитаты ниже сверить с оригиналом перед релизом).
  - «Provide visible licence attribution»; «Show OpenStreetMap licence attribution clearly on the map (typically bottom-right). Do not hide attribution beneath UI, behind toggles, or off-screen.»
  - «Send a valid HTTP User-Agent that clearly identifies your application»; «Apps must configure a distinct, stable User-Agent naming your app and optionally a contact URL or email.» Общие `okhttp`/`curl` блокируются.
  - «Cache tiles locally according to HTTP caching headers (or at least 7 days)»; не слать `no-cache` по умолчанию.
  - «Bulk downloading» = «any pre-emptive fetching of tiles other than those a user is actively viewing»; запрещены, как и функции предзагрузки; «Offline use is not permitted on tile.openstreetmap.org».
  - «Availability is best-effort: there is no SLA»; доступ может быть закрыт без предупреждения; «Commercial services, or those that seek donations, should be especially aware that access may be withdrawn at any point.»
  - Явного лимита одновременных соединений в нынешнем тексте не найдено (старая редакция требовала ≤ 2 потоков) — у нас 4, см. строку 5.
- OpenTopoMap: <https://opentopomap.org/about>. Лицензия CC-BY-SA, коммерческое использование допустимо при явной атрибуции («Kartendaten: © OpenStreetMap-Mitwirkende, SRTM | Kartendarstellung: © OpenTopoMap (CC-BY-SA)»); использование приветствуется, «sofern unser Server z.B. durch Massendownloads nicht zu stark beansprucht wird», гарантий доступности нет (волонтёрский проект).

## Итог
Нарушений правил, ведущих к немедленной блокировке, нет: HTTPS, предзагрузки нет, атрибуция видна, кеш бессрочный. Правки по важности:
1. (строка 9) негативный кеш и пауза после 403/429/сетевых ошибок — иначе при блокировке или отсутствии сети игра сама создаёт шквал запросов; это единственное, что может привести к бану одного адреса;
2. (строка 1) User-Agent: убрать «non-commercial», добавить URL репозитория, версию брать из проекта;
3. (строка 5) для OSM-слоя 2 параллельных запроса;
4. необязательно: ссылки в атрибуции (4), отмена ушедших из вида запросов (6), срок годности кеша (7).

Граница вывода: проверено чтение кода и текст правил; сетевое поведение (реальные заголовки `Cache-Control` ответов tile.openstreetmap.org, реакция на блокировку) не измерялось. Трафик по сценарию: игрок при выборе старта открывает порядка 20–60 тайлов 256 px, кеш на диске не даёт повторов, т.е. десятки–сотни игроков = единицы тысяч тайлов в неделю с разных адресов — на порядки ниже нагрузки, ради которой ужесточают политику (оценка по сценарию, не по замеру). Правки кода — следующая задача (`scripts/terrain/raster_tile_loader.gd`, `map_picker.gd`, `configs/world.json`; при смене формата ответа/полей — версия SM-К1).
