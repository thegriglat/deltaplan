# T9 — боты xc после перехода фасада (RW-P9)

Копия `rust-wind-RW-P9` от `feature/rust-wind` (после RW-12r). Расширение: `libdp_air_release.so`, скопировано из копии `rust-wind` (в копии задачи не собрано).

## Что было

RW-12r: `xc_run.gd --synthetic --km=30` - два `SCRIPT ERROR: Invalid assignment on read-only value (Dictionary)`, затем Godot висит ~20 мин, JSON не записан.

## Причины

1. **«read-only Dictionary»** на ветке не воспроизводится. Класс ошибки RW-P4 (`AirPlaceData.fill_climate` писал в read-only словарь) закрыт коммитом `c98369743`, он в ветке. Скрипт `xc_run.gd` в этом смысле чист: все конфиги, которые он пишет (`weather`, `atmo_cfg`, `pilot_cfg`), копируются `duplicate(true)` до записи.
2. **Зависание** - настоящая причина. `xc_run.gd` строил синтетическое место с шагом 250 м; крейт принимает поле только на 25 м (так же сказано в `tests/atmosphere/air_rig.gd`). Результат: состояние места FAILED за 0.0 с, `last_error` пуст (в журнале `dp_air: FAILED за 0.0 с, поле подано, last_error=`). `_wait_ready` ждал `is_ready()` до 600 с (потом шёл полёт без воздуха). Заметно: крейт не называет причину отказа места.
3. Побочное: каталог `--out` (`build/`) не создаётся скриптом - `FileAccess.open` падает с `push_error`; создаёт вызывающий.

## Что исправлено (только `tests/atmosphere/xc/xc_run.gd`)

- Шаг места 25 м. Место - прямоугольник вокруг отрезка старт - цель с запасом `--margin` (по умолчанию и минимум 5000 м) вместо квадрата вокруг начала с запасом 8 км: узлов в разы меньше. Запас 4 км крейт не принимает (FAILED), 5 км принимает.
- `_wait_ready` возвращает причину: выходит сразу на FAILED/EMPTY (с `status().reason` либо `last_error`) или по таймауту; `simulate` возвращает `{"error": "air", "reason": …}`, `_ready` пишет `push_error` и выходит с кодом 1 (раньше - висел).

## Границы

- Цена шага воздуха (`advance_to` + набор термиков + `set_focuses`) растёт с размером места: 1041² - 34 мс на игровую секунду, 1841² - ~180 мс, 3041² - ~1.5 с. 30 км при ~8000 с полёта (термики 2.5-3 м/с, 12.8 км/ч в среднем) - порядка часов. Это вопрос крейта (вне скоупа RW-P9, `rust/` не трогаем).
- Результат места зависит от его размера: 5 км при полуразмере 5000 м - 1422 с, при 8000 - 1407 с, при квадрате 13 км - 1407 с (разница - краевые эффекты места/порывы, ≤ 1 %).
- Сравнения с прежним T9 (до перехода фасада) нет: прежних JSON под рукой не было.
