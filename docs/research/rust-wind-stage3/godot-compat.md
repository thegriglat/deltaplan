# Опора на движок: шум, генератор, хеши (RW-8a)

Ничего из ниже сказанного не запускалось (Godot не нужен по условию задачи); исходники движка в копии нет, поэтому детали реализации Godot — **вопросы к дампу**, а не утверждения. Дамп — маленький GDScript в `tools/wind_fixtures/` (headless, секунды), его пишет первая задача (RW-8b, см. `cards.md`).

## Рекомендация (вопрос 5 плана)

**Шум порывов: портировать `FastNoiseLite` (OpenSimplex2S, 3D) побитно, замена — запасной путь.** Доводы:

1. **Распределение, а не только СКО.** Рывки слоя смешения — это `clamp((n − 0,8)/1,0, 0, 1)` по шуму, нормированному на СКО 1 (`lee.burst_threshold`, `atmosphere.gd:1224`). Доля превышений порога задаётся хвостом распределения симплекс-шума (он ограничен, не гауссов). Замена на другой шум с тем же СКО меняет частоту и силу рывков за гребнем — то самое поведение, которое «настраивали с пилотами» (план, «Риски»); `FieldTurbulence._measure_burst` подгоняет только среднее и СКО под выбранный шум.
2. **Сверка.** При побитном шуме `turb`/`gust` и итог FULL (`k = 0`) сравниваются поточечно (W8: допуск как у MEAN) — около 1 300 точек-моментов `turb` и 900 `gust` в эталонах. При замене остаются σ, MEAN и T3 — эталон слабее ровно там, где физику трогать нельзя.
3. **Цена.** Порт OpenSimplex2S 3D — порядка 250–350 строк вместе с таблицей градиентов, MIT-лицензия оригинала (FastNoiseLite, Jordan Peck); Godot держит свою копию в `modules/noise`. Крейт `fastnoise-lite` в офлайн-реестре копии не найден (`~/.cargo/registry`), сеть для сборки не предполагается — порт в `dp-air` без зависимости.
4. **Шлюз.** До кода — дамп из Godot (50–100 тысяч значений `get_noise_3d` на сетке и на случайных точках, для обоих типов настройки, сидов 0, 1, 20260927 и `+7919`), сравнение с портом: расхождение ≤ 1e-6 → порт принят. **Не сошлось за день работы → замена**: шум, который дольше держит распределение (то же СКО 1, та же асимметрия и хвост P(n > 0,8), спектральная полоса одной октавы — пик k·S на 1,75 s, `gust_spectrum.gd:19`), расчёт в f64, T3 как в плане. Точность координат шума в Godot — f32 после деления на масштаб (на 3600 с при ветре 6 м/с сдвиг ~20 км, это 450 единиц решётки при масштабе 45 м: шаг f32 ~3e-5 — на значения не влияет).

Что сверять в дампе кроме значений: порядок сдвигов осей (`x, y, z` → `a.x, a.y, a.z` без поворота), вклад `frequency` (в `GustSpectrum` — 1, в `WindModel` — 1), поворот 3D (`rotation_type_3d`, в Godot по умолчанию — «improve XY planes» либо без; **не утверждается**), смещение сида (`seed + 7919` в `int32`), `FRACTAL_FBM`: `gain`, `lacunarity`, `weighted_strength` (по умолчанию Godot: 0,5, 2,0, 0) и нормировка суммы октав.

## Генератор случайных чисел и хеши

Тоже порт: PCG32 (`pcg32_random_r`, начальное состояние из сида и постоянной приращения), `randf()`, `randf_range(a, b)`. Что должен подтвердить дамп: форма `randf()` в 4.7.2 (одно слово или два/три слова с `ldexp` — менялась между 4.x), порядок вызовов (`rng.seed = s` перезапускает последовательность), целочисленные сиды (`_mix` — 31-бит, `hash()` — 32-бит без знака → сид u64). Хеш `hash(Vector3i)` / `hash(Vector2i)` — Murmur3-подобная свёртка компонент (по памяти: `hash_murmur3_one_32` по компонентам, затем `hash_fmix32`) — проверяется дампом на 1 000 троек (в том числе отрицательных координат).

**Если порт RNG не сошёлся**, замены нет: расхождение положения источников и состава термиков ломает сверку ядер (W8: «число равно; место ≤ max(25 м, 2 % radius)»). Тогда — `contract:` и W8 v2 «ядра сверяются статистически» (распределение сил и радиусов, плотность по площади), что слабее.

## Прочее воспроизводимое: числа

- GDScript `float` — f64, `Vector3` — f32 (однократная точность в обычной сборке): ожидаемое расхождение сумм ~1e-6 относительно. Дискретные решения (какой цикл клетки; `floori`; пороги `sun_min`, `best_sun`, выбор ближайшего источника водосбора) могут отличаться на границе — **ожидать единичные расхождения числа ядер** (см. «Порядок», допуск W8 «число равно»).
- Расчёт в крейте — f64 там, где в GD `float`, `f32` там, где `Packed*Array`/`Vector3`; точная копия типов не нужна, нужна копия порядка действий в дискретных местах.

## Итог RW-8c

Порт `dp_air::compat` (`noise`, `rng`, `hash`) сошёлся с дампом Godot 4.7.2 **побитно** по всем точкам: шум — 64 384 значения на вид (4 сида × 16 096 точек; сетка 16³, 8 000 точек в ±50, 4 000 в ±600), max|Δ| = 0 для NONE, FBM (2 октавы) и FBM с весом (4 октавы, gain 0,6, lacunarity 1,9, weighted 0,5, частота 0,7). Данные — `rust/dp-air/tests/data/godot_compat/` (2,5 МБ), дамп — `tools/wind_fixtures/compat_dump.sh` (`--verify` — пересъёмка и побитное сравнение).

Подтверждено по памяти (с первого раза): PCG32 (`srandom_r`: инкремент `1442695040888963407`, `randi()`), `randf_range(a, b) = randf() * (b - a) + a` в f32, FBM (`fractal_bounding`, сид октавы `seed + i`, `amp *= lerp(1, min(n + 1, 2) / 2, weighted)`), поворот 3D по умолчанию `r = (x + y + z) * 2/3; p = r - p`, `GradCoord`, таблица градиентов (в т. ч. последняя строка), простые числа `501125321 / 1136930381 / 1720413743`, `seed2 = seed + 1293373`, множитель `9,046026385208288`.

Подобрано по дампу:
- **Радиус влияния OpenSimplex2S 3D: `a = 3/4 − |d|²`, а не `2/3`** (память подвела; перебор по переборной реализации в Python, `0,6` и `2/3` не сходятся).
- **`randf()` в 4.7.2 — два слова**: `p = randi()`; если `p == 0` — 0; иначе `ldexp((f32)(randi() | 0x80000001), −32 − clz(p))`.
- **`hash(Vector2i/Vector3i)`**: murmur3 по компонентам с начальным значением **`HASH_MURMUR3_SEED = 0x7F07C65`** (не 0), затем `fmix32`.

Границы: координаты шума — f32 (после поворота и частоты — f32), проверены ±600 единиц решётки; другие `noise_type`, `rotation_type_3d`, `ping_pong` и 2D не портированы. Сид `rng.seed = s` отрицательный → `s as u64` (проверен `-1`). `randf_range` — вариант `float` (не `double`): подтверждён дампом.
