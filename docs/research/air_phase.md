# air-phase: фазовая диаграмма классов решений для ветра над рельефом

Самодостаточный документ: определения, выкладки, числа, пути к данным, команды. Литература с оценкой надёжности каждой ссылки — в `docs/research/air_phase_refs.md` (ссылки в тексте вида [Lin96]). Числа «по памяти, проверить» помечены явно.

## 1. Постановка и мотивация

Сейчас одна модель на все режимы: стационарное поле по итерациям Пикара (`tools/research/air3d/reference.md`, план `docs/plan/air_model.md`, масштаб 1) и одна сеть (U-Net P2/SY-11) на все условия. Взгляд физхимика: атмосфера над рельефом имеет **агрегатные состояния решения**, и граница между ними — не граница картин течения, а граница *типов решения*:

| тип решения | что это | аналог |
|---|---|---|
| единственное стационарное | неподвижная точка уравнений, устойчивая; Пикар сходится, сеть учится | кристалл |
| мультистабильное | несколько неподвижных точек, выбор зависит от истории (гистерезис) | полиморфизм, переохлаждение |
| только статистика | стационарного состояния нет, есть среднее по времени и распределение | кипение: пар + жидкость, положение пузырей случайно |
| плохо поставленное | решение задают малые возмущения входа | критическая точка |

Аналогии, которыми пользуемся: **ночной холодный воздух как жидкость** (сток по склонам, озёра холода в долинах, гидравлические прыжки, перелив через седловины — мелкая вода с приведённой силой тяжести g′ = gΔθ/θ); **дневная конвекция как кипение** (нагрев снизу, пузыри-термики, положение случайно, расход тепла задан); **карты режимов двухфазного течения** в трубах (Бейкер 1954, Мандхейн 1974, Тайтель–Даклер 1976, [TD76]) — для каждого режима своя модель, каждая граница задаётся своим механизмом и своей безразмерной группой, переходы — полосы, а не линии. Цель — **выделить чёткие границы структур** и под каждую структуру поставить свой решатель.

## 2. Управляющие параметры

### 2.1. Переменные и π-теорема
Размерные входы: скорость притока U (м/с), частота Брента–Вяйсяля N (1/с) свободной атмосферы, высота слоя перемешивания z_i (м), скачок θ на инверсии Δθ (К) → g′ = gΔθ/θ₀ (м/с²), высота рельефа h (м) и его горизонтальный масштаб a (м), поток тепла H (Вт/м²) → кинематический B = (g/θ₀)·H/(ρc_p) (м²/с³), шероховатость z₀, параметр Кориолиса f (1/с), шаг сетки Δx, время осреднения T. Девять величин, две размерности (м, с) → семь безразмерных групп (плюс сеточные):

| группа | смысл | где граница |
|---|---|---|
| **Fr = U/(N·h)** | кинетическая энергия ½U² против энергии подъёма ½N²h²: хватит ли перевалить | A↔C↔D |
| **s = h/a** (крутизна) | уклон подветренного склона; отрыв при s ≳ 0,3 | A↔B |
| **−z_i/L = κ·B·z_i/u*³** | плавучесть против сдвига на масштабе слоя (L — длина Обухова, u* — скорость трения) | нейтр.↔E↔F |
| **w*/U**, w* = (B·z_i)^{1/3} | то же в «скоростях»: масштаб Дирдорфа против ветра | то же |
| **h/z_i** | рельеф ниже верха слоя или пробивает его | какой Fr «правильный» |
| **Fr_i = U/√(g′·z_i)** | двухслойный Фруд: волны на инверсии, прыжок, роторы [Vos04] | C при инверсии |
| **Ro = U/(f·a)** | вращение Земли | не существенно (ниже) |
| N·a/U | гидростатичность волн (≫ 1 — гидростатика) | C: тип волн |
| U·T/a | стационарность за час осреднения | H (штиль) |
| h/Δx, a/Δx | разрешение | ограничения §4.3 |

Связь осей нагрева: u* = κU10/ln(10/z₀); при z₀ = 0,1 м u* = 0,087·U10, и −z_i/L = κ(w*/u*)³ ≈ 608·(w*/U10)³. В таблице условий w*/U считается по U_sat = U10·max_profile (≈ 2·U10 при классе D), поэтому −z_i/L ≈ 4900·(w*/U_sat)³: w*/U_sat = 0,10 ↔ −z_i/L ≈ 5; 0,17 ↔ 25; 0,30 ↔ 130. В корпусе медиана w*/U 0,077 ↔ −z_i/L ≈ 2 (прямой расчёт по H и z_i даёт медиану 3,5 — расхождение от z_i и u* конкретных случаев).

Знак H: охлаждение (H < 0) — не «малая конвекция», а другой класс (G): устойчивый слой у земли, стоки, озёра холода. В корпусе H_mean < 0 у 13,3 % случаев (вечер 17–20 ч, 40 % вечерних).

### 2.2. Что берётся за Fr в данных
В таблице условий S2 (`conditions.derive`, `tools/research/air_synth/corpus/conditions.py`): `froude = U_sat/(N·relief_m)`, где N — среднее √(g/θ₀·dθ/dz) на 1,5 км **над z_i** (свободная атмосфера, инверсия и слой перемешивания в N не входят), relief_m = max − min рельефа области 38 км, U_sat — скорость притока выше z_sat (профиль C2 v4: U10·(z/z_sat)^α до насыщения). Это **Fr всей области по N над слоем** — грубая глобальная величина. Локальные Fr (по местному перепаду до гребня) — §7. Оговорка: внутри слоя перемешивания N ≈ 0, поэтому при h < z_i «истинный» Fr нижнего слоя много больше табличного; при h > z_i (59 % случаев корпуса — рельеф выше верха слоя, медиана z_i над землёй 681 м против Δh 1259 м) табличный Fr близок к правильному для верхней части рельефа.

### 2.3. Типичные диапазоны (день полётов, корпус SY-12 hgw24, 7320 случаев)
Квантили 5 / 50 / 95 %: Fr 0,13 / 0,96 / 9,7; w*/U 0 / 0,077 / 0,74; −z_i/L 0 / 3,5 / 640; U10 1,3 / 4,5 / 10,8 м/с; H 0 / 103 / 213 Вт/м²; z_i над землёй −375 / 681 / 3792 м (отрицательное — утро, z_i ниже средней высоты рельефа); N 0,002 / 0,010 / 0,014 1/с; Δh 241 / 1259 / 2721 м; уклон p95 на 100 м 8,6 / 25 / 42°; на 400 м 0,09 / 0,31 / 0,66 (tg). По классам часа: утро — Fr 1,56, w*/U 0,035, −z_i/L 0,6; день — Fr 0,73, w*/U 0,22, **−z_i/L 41** (типичный день полётов по Дирдорфу — свободная конвекция!); вечер — Fr 0,85, w*/U 0,036, −z_i/L 0, H ≈ 11 Вт/м². Карта случаев — `docs/research/air_phase/fig_cases_hg.png`.

**Кориолис.** Ro = U/(f·a): f = 1,1·10⁻⁴ 1/с; при a = 10 км (полуширина массива) и U = 5 м/с Ro ≈ 4,5, при a = 40 км (вся область) Ro ≈ 1,1. Вращение меняет только обтекание массива целиком при слабом ветре (U < 3 м/с на 40 км) — обход «правым плечом» и асимметрию подпора ([PW85] — качественно). В решателе Кориолиса нет (f только в толщине слоя h_mech = 0,3u*/f); это граница модели, а не фаза: оставить, отметить в документации.

**Стационарность.** U·T/a при T = 1 ч: U = 5 м/с, a = 5 км → 3,6; U = 1 м/с → 0,7. При U < 1,5 м/с воздух за час осреднения не проходит один массив — «среднее за час» не определено самой постановкой, независимо от решателя (фаза H).

### 2.4. Разделимость осей
Гипотеза: диаграмма в первом приближении — произведение одномерных разбиений (A↔D по Fr, A↔B по s, нейтр.↔E↔F по −z_i/L, G по знаку H, H по U). Проверка на данных (§6.3): кривые несходимости по Fr в терцилях w*/U почти совпадают (средняя разница долей 0,05, максимум 0,20) — **Fr и нагрев разделимы**; в терцилях −z_i/L — 0,13; в терцилях крутизны и Δh — 0,15–0,18, но тут сцепление через сам Fr (малый Fr на пологом рельефе бывает только при очень слабом ветре). Связи, которые остаются: (1) нагрев снижает эффективную устойчивость нижнего слоя (N внутри слоя → 0) — граница A↔D наклонна в сечении Fr × (−z_i/L); (2) h/z_i склеивается с Fr: при h < z_i работает Fr_i двухслойный, при h > z_i — Fr по N свободной атмосферы; (3) при Fr ~ 1 подветренная волна снижает порог срыва s_crit (гипотеза, не измерено).

Предлагаемые сечения: **(1) Fr × (−z_i/L) × s при h/z_i < 1** (типичный день); **(2) Fr × (−z_i/L) × h/z_i на пологом рельефе** (утро/вечер, низкие инверсии). Схема — `docs/research/air_phase/fig_phase_schematic.png` (`tools/research/air_phase/phase_diagram.py`).

## 3. Классы решений (фазы)

Пороги — ориентиры по литературе с указанием надёжности (подробно `air_phase_refs.md`). «Тип решения»: С — стационарное единственное, М — мультистабильное, Σ — только статистика, ? — плохо поставленное.

| фаза | условия | физика и признаки | тип | переход | пороги и источники |
|---|---|---|---|---|---|
| **A** вынужденное обтекание | Fr ≳ 1,2; s < s_crit; −z_i/L ≲ 5 | перевал, разгон на гребне ΔU/U ≈ 2h/a (2D), 1,6h/a (3D), 0,8h/a (уступ) [Fin20]; линейная теория Джексона–Ханта точна при h/a ≲ 0,2 | С | плавный к B и C | без опрокидывания волн при Fr ≥ 1,12 [Lin96 — 2D, проверено]; линейные модели приемлемы при h/a < 0,2 [Fin20] |
| **B** срыв и ротор | Fr ≳ 1,2; s > s_crit | пузырь отрыва за бровкой, обратное течение у земли, слой сдвига; среднее определено, за гребнем сильные колебания (RANS не воспроизводит скачок масштаба турбулентности [Fin20]) | С по среднему; пульсации Σ | плавный, порог зависит от z₀ (шероховатость снижает s_crit) [Woo95] | s_crit ≈ 0,3 (принято в WAsP RIX [Mor06]); 15° для 2D-гребней, 20° для осесимметричных холмов [Fin20 цитирует Finnigan 1988]; максимум разгона ≈ 1,25 ограничен появлением пузыря [Fin20]; гистерезис не найден в литературе |
| **C** критическая зона | 0,5 ≲ Fr ≲ 1,2 | подветренные волны λ = 2πU/N (3–6 км при U 5–10, N 0,01), опрокидывание, нисходящая буря, гидравлический прыжок; при инверсии — волны на инверсии, роторы [Vos04] | М возможно | резкий: опрокидывание — бифуркация; переходы с гистерезисом известны для одно-/двухслойной гидравлики [HK68, Baines84 — по памяти, проверить] | опрокидывание Nh/U ≈ 0,85 для полукруга (Miles & Huppert 1969; 0,67–1,1 по форме — по памяти); Lin & Wang [Lin96]: II (опрокидывание без блокирования) 0,9 < F ≤ 1,12; III 0,6 ≤ F ≤ 0,9 — опрокидывание первым |
| **D** блокирование | Fr ≲ 0,5 | нижний слой обтекает: разделяющая линия тока H_c = h(1 − Fr) [She56, Sny85 — хорошая оценка для симметричных холмов и малого сдвига, нижняя граница при сильном сдвиге]; застой с наветренной стороны, проход через седловины, подветренные вихри (Smolarkiewicz–Rotunno 1989 — по памяти Fr < ~0,5), срыв вихрей при меньшем Fr (Schär & Durran 1997 — вторичные источники: Fr ≈ 1/3–0,4) | С при умеренном блокировании; **Σ** при срыве вихрей | резкий (появление застойной точки, [SG93]) | обход при Fr < 0,4 [HS80 — вторичный источник]; Lin & Wang IV: блокирование первым при 0,3 ≤ F ≤ 0,6 |
| **E** конвекция с ветром | 5 ≲ −z_i/L ≲ 20–25; U ≳ 5 м/с | валы вдоль ветра, расстояние 2–4 z_i; среднее определено, положения валов — статистика | С + Σ | **плавный** [Sal17] | свободная шкала при −z_i/L > 4,5 (Deardorff — по памяти); валы при −z_i/L ≲ 25 и U ≳ 5 м/с [Wec97 — по памяти]; переход валы→ячейки плавный до −z_i/L ≈ 15–20 [Sal17 — проверено] |
| **F** свободная конвекция | −z_i/L ≳ 25 | ячейки ~1–1,5 z_i, термики: доля площади восходящих ≈ 0,4 [LS80], асимметрия w 0,4–1; детерминирована только связанная с рельефом часть (анабатика, источники над прогретыми склонами) | Σ | плавный из E | w* = (B z_i)^{1/3}: H = 200 Вт/м², z_i = 1,5 км → 2,0 м/с |
| **G** устойчивое охлаждение | H < 0, U слабый | стоки Прандтля (вниз по склону 1–4 м/с, толщина 3–100 м [ZW13]), озёра холода в долинах (критическая глубина долины, отделение от потока выше [VB08]), перемежающаяся турбулентность ниже порога ветра ~5–7 м/с геострофического [VdW12] | С в среднем, но тонкие слои не разрешаются; Σ (перемежаемость) | резкий (коллапс турбулентности — «хоккейная клюшка» [Sun12]) | только вечер (часы старта ≤ 20:00); в решателе отрицательный поток кладётся в первую клетку — тоньше Δz не разрешить |
| **H** около штиля | U10 ≲ 1,5 м/с | направление не определено (меандрирование ниже 1–2 м/с [Anf05]); решение задают малые возмущения; U·T/a < 1 | ? | — | по данным §6: U10 < 1 → 79 % несходимости, 1–1,5 → 69 %, 1,5–2 → 47 %, 2–2,5 → 21 %, ≥ 3 → 2–3 % |

Карты: схема в осях (U10, H), (Fr, −z_i/L), (Fr, s), (Fr_i, h/z_i) — `fig_phase_schematic.png`. В осях (U, H) границы по нагреву — кривые H ∝ U³ (−z_i/L ∝ H·z_i/u*³), по Fr — вертикали при фиксированных N, h.

## 4. Параметры порядка

### 4.1. Определения (как считать из полей решателя)
Поля S5: `fields/m` (u, v, w; 13 уровней над землёй 25…2000 м, 96×96, клетка 400 м), `fields/h` (+θ′), `inputs/hc, heat_flux, hbl`. Приток на уровне z: U_b(z) = U10·min((z/z_sat)^α, 1), z_sat = 10·max_profile^{1/α} (α, max_profile — столбцы таблицы условий). Направление «куда» e = (−sin φ, −cos φ), φ — «откуда». Край области 5 клеток исключён (как в late_spread). Реализация — `tools/research/air_phase/phase_stats.py::field_features`.

| застой | D | доля клеток, где \|u_h\| < 0,3·U_b (25 м) |
| обход (поворот) | D | доля клеток с углом между u_h и e > 45° при \|u_h\| > 0,2·U_b (25 м) |
| обратное течение | B, D | доля клеток с u_h·e < −0,05·U_b (25 м) |
| торможение/разгон | A, D | средняя \|u_h\|/U_b; p99 \|u_h\|/U_b (50 м) |

| буря/прыжок | C | ускорение у земли на подветренном склоне / приток (не реализовано — нужен идеальный хребет) |
| улицы/ячейки | E/F | анизотропия спектра w в горизонтали на 300–600 м (в K-замыкании их нет — не реализовано) |

| конвективная добавка | E/F | СКО (u_h − u_m)/U_b на 50 м; СКО (w_h − w_m) на 300 м |
| стоки | G | течение вниз по склону у земли под устойчивым слоем (на 25 м: u_h·∇h < 0 при θ′ < 0) — не реализовано |
| неопределённость | все | разброс поздних итераций `late_spread60_p90` (p90 по области разброса снимков 500…1000 через 50 на 60 м) |

### 4.2. Поведение Пикара как параметр порядка
Статус (сошёлся / 1000 итераций), число итераций у сошедшихся (критическое замедление), разброс поздних итераций у несошедшихся (амплитуда блуждания), «почти сошёлся» (разброс < 0,05 м/с при статусе max), разные старты → разные решения (не измерено: один старт).

### 4.3. Ограничения разрешения (клетка 400 м, Δz = 105 м)
Волны 3–6 км — 8–15 клеток, разрешаются; валы 3–5 км — разрешимы, но K-замыкание их не рождает; пузырь срыва (сотни метров) — 1–2 клетки, размазан, обратное течение видно только на 25 м как слабый сигнал; склоновые ветры и стоки (3–100 м) — тоньше Δz, не разрешаются; разделяющая линия тока H_c — разрешена при Δh ≳ 300 м. Перенос 1-го порядка: численная вязкость ~UΔx/2 = 1000 м²/с при U = 5 — больше турбулентной K (десятки м²/с): эффективный Re_eff = U·a/ν_num ≈ 2a/Δx ≈ 10–50 — течение в решателе «вязкое», что сглаживает срыв вихрей и валы и помогает сходимости. Это надо помнить: **часть стационарности — свойство схемы**.

## 5. Пикар как зонд фаз

### 5.1. Теория
Итерация Пикара x_{k+1} = Φ(x_k) сходится к неподвижной точке x*, если спектральный радиус ρ(DΦ(x*)) < 1; скорость — геометрическая с множителем ρ. Для стационарного Навье–Стокса (Озеен с замороженным переносом) сжатие гарантировано при малом «числе Рейнольдса по данным» (условие малости Жиро–Равьяра [GR86]); при его росте: (а) множитель ρ → 1 — **критическое замедление**, число итераций ∝ 1/(1 − ρ) [Wissel 1984, Scheffer 2009 — для шумных рядов, аналогия]; (б) собственное значение проходит через 1 (седло-узел / вилка) — появляется второе решение, старты разводятся — **мультистабильность**, при обратном ходе параметра — **гистерезис**; (в) пара комплексных собственных значений выходит на единичную окружность (Хопф) — стационарное решение существует, но неустойчиво: итерация **ходит по циклу** (цилиндр при Re > 46 [Jac87]: стационарное решение есть, его найдёт Ньютон, но не марш по времени). Случай (в) для нас — фазы F (ячейки), D при срыве вихрей, B с нестационарным отрывом: среднее по времени есть, неподвижной точки итерация не находит, хотя она может существовать математически. **Численная** несходимость (не физика): недорелаксирование на границе устойчивости схемы, абсолютный критерий невязки (СКО < 2·10⁻⁵ м/с²) при малых скоростях, предельный цикл K(Ri) ↔ θ′ ↔ w (найден в `findings.md`). Как отличать: (1) амплитуда блуждания: разброс поздних итераций ≪ U — численная недоводка; ~ 0,1–1 U — отсутствие стационарного состояния; (2) недорелаксирование (ω 0,3–0,7 на скорость) убирает численную, но не физическую; (3) смена Δx; (4) два старта; (5) ход по параметру туда-обратно (гистерезис).

В нашем решателе (`air3d/reference.md`): итерация — импульс (Озеен, псевдошаг Δτ_u, плавучесть полунеявно), проекция SIMPLEC (1 V-цикл), тепло; K обновляется каждую итерацию с релаксацией 0,5; критерий остановки — СКО невязок импульса < 2·10⁻⁵ м/с² (абсолютный), тепла < 5·10⁻⁷ К/с, ∇·u < 10⁻⁶ 1/с; предел 1000 итераций (SY-12), цель при max — среднее снимков 500…1000 через 50.

### 5.3. Выводы раздела
1. Граница существования стационарного решения по Пикару в корпусе — **двумерная, в (U10, Fr)**: U10 ≈ 2–2,5 м/с (резкая по ветру: 0,47 → 0,21 → 0,08 на шаге 0,5 м/с) и Fr ≈ 0,3 (плавная по Fr). Старая гипотеза «Fr ~ 0,3–0,5» верна лишь при фиксированном ветре.
2. Почему слабый ветер (гипотеза N1 для проверки): K-замыкание ∝ u* ∝ U10, а численная вязкость ∝ U — обе падают с ветром, но нижний предел K = k_fa = 1 м²/с и F(Ri) → 0 при малом сдвиге (Ri = N²/|S|² велико) делают эффективное число Рейнольдса при U → 0 большим, условие сжатия Пикара нарушается. Если так — лечится нижним пределом K по физике (минимальная турбулентность слабого ветра: σ_w ~ 0,3 м/с → K_min ~ σ_w·l) или недорелаксированием; это численная граница, но наложенная на физическую (H: U·T/a < 1).
3. Критическое замедление измеримо и монотонно → по итерациям сошедшихся можно ставить «расстояние до границы» и предупреждать игру о ненадёжности поля без второго решения.

## 7. Локальность фаз

Фаза — свойство точки, не области: в одном квадрате 40 км одновременно гребень в A/B, долина под инверсией в D, прогретый склон в E/F, тенистая долина вечером в G — как зёрна фаз в шлифе сплава. Локальные параметры на клетку: **местный Fr** = U/(N·h_loc), h_loc — превышение ближайшего гребня над клеткой (максимум в окне 4,4 км минус высота клетки; при h < z_i — N эффективное слоя, при h > z_i — N свободной атмосферы); **местная крутизна** подветренного склона (∇h·e < 0); **местный нагрев** −z_i/L по потоку тепла клетки (склон на солнце против тени); **знак H**. Пример (`fig_local_phase.png`, случай 17 рельефа 35, U_sat 8,0 м/с, N 0,0118, Fr области 0,49, H 163 Вт/м²): по местному Fr область на 88 % в A, 11 % в C (подножия главного хребта), 1 % в B; тепловая карта — вся в E (−z_i/L 5–25). Доля застоя у земли в решении m по классам: A — 0,04, B — 0,06, C — 0,29 — местная классификация **предсказывает, где решатель тормозит поток**, при том что Fr области (0,49) обещал «блокирование» везде.

Сшивка: своё решение на зону (например D — послойный обход ниже H_c, A — линейное/сеть выше), на границах зон — общий приток/проекция на неразрывность (один шаг проекции ∇·u = 0 поверх сшитых полей, как в массосогласованных моделях [Ros88]); в переходных полосах — **правило рычага**: u = (1 − φ)·u_фаза1 + φ·u_фаза2, φ = сигмоида параметра порядка (например застой или местный Fr с шириной перехода по подгонке §9). Для E решения примерно складываются: среднее (A/D) + статистика валов (положение случайно, амплитуда по −z_i/L); для F — среднее + термики масштаба 2 (уже так в плане air_model: стык 1↔2).

| **C** | теория Лонга (стационарные волны при постоянных N, U — точное решение Лонга 1953/55), двухслойная гидравлика (Fr_i, h/z_i [Vos04]); при мультистабильности — **выбор ветви по истории** (утро → день) | опрокидывание при Nh/U ≈ 0,85; границы регимов Vosper — по рисунку, не перенесены | N(z), U(z), Δθ, z_i | Пикар сходится в C (5–9 %), но единственность не проверена — опыт §9 |
| **D** | разделяющая линия тока H_c = h(1 − Fr) [She56]: ниже — «срезы рельефа как стенки» (2D-обтекание контуров h = const на каждом уровне, Лаплас/FFT 96², мс на срез; идея P3 §6), выше — A на «эффективном рельефе» (срезанном на H_c); подветренные вихри — статистика (при Fr < ~0,4 положение/срыв случайны) | H_c — хорошая оценка для симметричных холмов и малого сдвига [Sny85], нижняя граница при сильном сдвиге | Fr местный, N, z_i | Пикар там, где сошёлся (Fr 0,3–0,5: 85–90 %), застой/поворот §6.1 |
| **E** | A или D для среднего + валы: расстояние 2–4 z_i, ось вдоль ветра, амплитуда σ_w ≈ 0,6w* — статистика подобия [Etling & Brown 1993 — по памяти] | валы при −z_i/L ≲ 25, U ≳ 5 [Wec97 — по памяти] | w*, z_i, U | нет эталона в проекте (K-поле валов не содержит); литература |
| **F** | **конвективная циркуляция из баланса массы и энергии**, без Пикара: подъём над прогретыми склонами Φ ∝ H·площадь, компенсация опусканием над долиной (масса), сила ядер по Аллену (уже в масштабе 2), анабатика u ∝ (B·…)^{1/3} [Schumann 1990 — формулы не извлечены]; плюс термики как статистика (w*, z_i, доля 0,4 [LS80]) | w* 1–3 м/с; доля восходящих 0,4–0,45 | H(x,y) по склонам, z_i | AM-07 калибровка (`docs/research/calibration_data.md`), прототип heat_ca (подъём над склоном 1,6–2,5 м/с) |
| **G** | стоки Прандтля по склонам (слой 3–100 м, 1–4 м/с [ZW13]) + **заполнение долин холодом как сток жидкости** (мелкая вода с g′, озёра холода по порогу глубины долины [VB08], перелив через седловины) | профили Прандтля качественно подтверждены наблюдениями; критическая глубина долины — формула не извлечена | H < 0, геометрия долин (дренаж Fastscape уже есть), U | нет эталона; литература; слова пилота (вечерняк) |

| марш по ветру (PNS) | вертикальными срезами поперёк ветра, от наветренной кромки (идея P3 §6) | применим только без обратного течения и влияния вверх по потоку [RT92] — т.е. **только в A**; в B/C/D не применим по построению | — | Пикар в A |

Сеть: учить **только в детерминированных фазах (A, B, умеренное D)**; в C — опасно (мультистабильность = двузначная цель); в E/F/H цель — среднее по запускам, не поле одного запуска (сейчас late_mean уже так, но доля таких случаев 10 %). Ошибка SY-11 (медиана 0,69 м/с на отложенных, 17 %): механический режим хуже (0,75) конвективного (0,37) — согласуется: конвективные случаи в корпусе = слабый ветер = малые абсолютные ошибки; высокие Fr 0,92 м/с (15 %) — ошибка растёт с ветром, т.е. это A/B, где сеть должна быть лучше всего → потенциал улучшения именно там (срыв, крутые места).

## 9. План опытов для чётких границ (GPU, только спроектировано)

Цель — границы как функции одного параметра при фиксированных остальных, с шириной перехода и гистерезисом (что считать и зачем; цена не оценивается).

1. **Идеальный рельеф.** Гауссов холм (h = 500 м, a = 2 км; 3D), вытянутый хребет (длина 20 км, a = 2 км; 2D-подобный) и уступ, по три крутизны s = 0,15 / 0,3 / 0,5 (a меняется при фиксированном h); область 38 км, клетка 400 м как в корпусе, плюс окно 100 м для срыва. Условия S2 с переопределением стратификации (`strat_override`, `n_bv_override_s`, `z_i_override_agl_m` уже есть в таблице): N = 0,01, z_i варьируется (h/z_i = 0,3 / 1 / 3), нагрев H = 0 / 100 / 250 Вт/м² (−z_i/L ≈ 0 / 10 / 100 при U 4 м/с).
2. **Сетка по Fr** через U: Fr = 0,1…5 логарифмически 20 точек, густо у 0,3–0,6 и 0,8–1,3 (шаг 0,05) — 30 точек на линию. Линий: 3 формы × 3 крутизны × 3 нагрева × 3 h/z_i = 81 → 2430 случаев (цена по решению автора не оценивается; порядок — как треть корпуса SY-12).
3. **Два старта** (фон; тёплый старт от соседнего Fr) и **проход вверх/вниз по Fr** через 0,3–1,3 — мультистабильность и гистерезис: расхождение полей > 0,1 U при одинаковой сходимости = две ветви.
4. **Недорелаксирование** ω = 0,5 на скорость и K на граничных случаях (Fr 0,2–0,5, U10 1,5–3) и **нижний предел K** (гипотеза N1 §5.3): если несходимость уходит и поле не меняется > 0,05 U — численная; если остаётся блуждание ~0,1 U — физическая. Критерий сходимости относительный (невязка / U²/a) вместо абсолютного — проверить на штиле.
5. **Срыв** на окне 100 м с 2-м порядком переноса: s = 0,15…0,6 шагом 0,05 при Fr = 3; измерять площадь обратного течения, длину пузыря; порог ± ширина сигмоидой; сравнить с 400 м.
6. **Критерии резкости.** Параметр порядка y(Fr): подгонка y = y₀ + Δy·σ((log Fr − log Fr_c)/w); «резкая» граница — w < 0,1 декады и/или скачок между соседними точками > 3σ шума между стартами; «плавная» — w > 0,3 декады. Гистерезис — |Fr_c↑ − Fr_c↓| > 2w.
7. Что менять в решателе/условиях: генератор идеальных рельефов (`gen_proto_reliefs.py`/`reliefs.py` уже есть), таблица условий с override, флаг ω, запись снимков каждые 50 итераций с 100-й (для автокорреляции — «шумный предвестник» [Scheffer 2009]), второй старт.

## 10. Риски и открытые вопросы; что меняет в планах

- **Риск смешения численного и физического**: граница по U10 ≈ 2,5 м/с может быть артефактом K-замыкания и абсолютного критерия (N1). Пока не проверено — не строить на ней физику.
- Перенос 1-го порядка делает решатель «вязким» (Re_eff ~ 10–50): срыв вихрей в D и валы в E он не покажет никогда — границы D(Σ) и E надо брать из литературы/опытов на мелкой сетке с 2-м порядком, не из Пикара на 400 м.
- Fr области vs местный Fr: таблица условий даёт одно число на 40 км — для карты фаз нужна местная классификация (§7), её стоит добавить в условия/признаки сети (в ann2 «безразмерные числа во FiLM» — лучше карты местного Fr и крутизны, чем скаляры).
- Мультистабильность в C не измерена (один старт); гистерезис — ни в литературе по 3D-рельефу, ни у нас.
- Для air_model (масштаб 1): (а) при U10 < 2,5 м/с не ждать неподвижной точки — цель «среднее поздних» уже стандарт, но для игры лучше F-циркуляция из баланса + статистика (§8); (б) второе решение без нагрева для w_mech оправдано: в D/A механика и нагрев разделимы (§2.4); (в) итерации сошедшихся — индикатор близости к границе (предупреждение «поле ненадёжно»). Для сети: учить в A/B/умеренном D, веса/маски по фазе; не учить на C/H; цель в F/E — среднее по запускам.
- Открыто: Fr_i (двухслойный) для C — добавить Δθ инверсии в условия; G ночью — вне часов старта, но «вечерняк» 20:00 близок к G; Кориолис на 40 км при слабом ветре.
