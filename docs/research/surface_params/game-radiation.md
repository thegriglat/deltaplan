# Для игры: радиация (K↓, L*, прямая и рассеянная)

> Часть исследования [Параметры поверхности по классам покрова](../surface_params.md).

## 9. Использование в игре (surface-heat)

Задача SH-1 (модуль surface-heat, 09.10.2026). Числа для `configs/surface_heat.json` (контракт SH1); физика — `docs/archive/plan/surface-heat.md`, §1.
Классы и их числа — разделы 1–2 (строки CSV по соответствию SH1). Здесь — то, чего в таблице П4 нет: радиация, влажность, вода, H_ref.
Каждое число — с источником или пометкой **EST** (оценка с рассуждением; не подбор под старые числа игры).

### 9.1. Коротковолновая радиация K↓ (Stull)

Stull (STU88b, ур. 2.34–2.35, 2.39–2.40): K↓ = S₀·T_r·sin ψ (только днём; ψ — высота Солнца), T_r = (0,6 + 0,2·sin ψ)·(1 − 0,4σ_H)(1 − 0,7σ_M)(1 − 0,4σ_L),
σ_H, σ_M, σ_L — доли облаков верхнего, среднего, нижнего яруса. S₀ = 1361 Вт/м² (солнечная постоянная; без поправки на расстояние до Солнца — ±3 %, вне модели).
Оговорка: формула — «параметризация для оценок» (Stull), без аэрозоля, высоты места и водяного пара; с высотой над уровнем моря ясное K↓ растёт на 5–10 % на км — не учитываем.

**Облачность игры → один ярус.** В игре одно число `sky.cover` (0 / 0,3 / 0,85 у ясно / переменная / облачно). Берём коэффициенты **среднего яруса** (EST по выбору яруса):
T_cloud = 1 − 0,7·cover. Основание: у конвективной и слоисто-кучевой облачности основание на 1–3 км; для «переменной» (cover = 0,3) даёт 0,79 — почти ровно
`sky.partly.heat = 0,8`, то есть игровая доля прогрева уже согласована с ярусом M. Для «облачно» (0,85) Stull даёт 0,405, а игра — `heat = 0,3`
(игра сильнее гасит; наблюдаемое отношение сплошной облачности к ясному небу ≈ 0,25–0,35, так что 0,405 — верхняя оценка при cover < 1).
Рекомендация: использовать **только `cover`** (множитель 1 − 0,7·cover), а `sky.heat` в H не умножать второй раз (двойной учёт облаков); если решат сохранить `heat` как есть для термиков — это отдельное решение вне П4.
Ярусы H и L (0,4 и 0,4/0,6) — для справки, в игре не нужны.

| 90 | 1089 | 0,800 | 860 | 441 |
| 63 (50° с.ш., солнцестояние) | 944 | 0,778 | 746 | 382 |

### 9.2. Длинноволновая L\*

Stull (ур. 2.39): I\* = −b·(1 − 0,1σ_H − 0,3σ_M − 0,6σ_L), b = 98,5 Вт/м² (= 0,08 К·м/с в кинематических единицах, делится на ρ·c_p).
В игре — **константа** по Stull (без T поверхности и влажности воздуха, это решение плана), облачность ярусом M: L\* = −98,5·(1 − 0,3·cover).
Ясно −98,5; cover 0,3 → −89,6; cover 0,85 → −73,4 Вт/м². Знак: потеря энергии (Rn = (1 − α)K↓ + L\*, L\* < 0). Ограничение: реально L\* зависит от T и влажности воздуха (диапазон −40…−130 Вт/м² в ясную погоду); одна константа — осознанное упрощение.

### 9.3. Прямая и рассеянная доля, наклон

Горизонтальная K↓ делится на прямую K_dir = (1 − f_d)·K↓ и рассеянную K_dif = f_d·K↓. Для склона:
K_склон = K_dir·cos θ / sin ψ + K_dif, где θ — угол между нормалью склона и направлением на Солнце, cos θ ≥ 0 (план: рассеянная — по sin ψ, т. е. не зависит от наклона; изотропная модель Лю–Джордана добавила бы множитель (1 + cos наклона)/2 и отражённую от соседних склонов — не берём).
Доля рассеянной f_d — по Эрбсу (ERB82), от индекса ясности k_T = K↓/(S₀ sin ψ) = T_r·T_cloud:
k_T ≤ 0,22: f_d = 1 − 0,09 k_T; 0,22 < k_T ≤ 0,80: f_d = 0,9511 − 0,1604 k_T + 4,388 k_T² − 16,638 k_T³ + 12,336 k_T⁴; k_T > 0,80: f_d = 0,165.
Значения для игры: ясно, ψ = 63° (k_T = 0,778): **f_d ≈ 0,17**; ψ = 40° — 0,21; ψ = 20° — 0,30; cover 0,3, ψ = 63° — 0,41; cover 0,85 — ≈ 0,93.
Для простоты в конфиге можно взять **постоянную** ясную долю 0,15–0,17 и рост до ≈ 0,9 при сплошной облачности; рекомендуем формулу Эрбса (одна строка, без таблиц). Ограничения: модель Эрбса — для горизонтальной плоскости, на равнине; в горах на высоте
рассеянной меньше (разреженная атмосфера), ошибка разложения при ясном небе — до ≈ 27 % (LAI18). Нижняя граница 0,165 уже у верхней границы вилки (ясная горная — 0,10–0,15).
