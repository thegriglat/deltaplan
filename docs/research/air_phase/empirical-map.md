# air-phase, часть 3: эмпирическая карта по готовым данным и локальность фаз

> Часть документа [air_phase.md](../air_phase.md) (вход, оглавление и вывод — там); нумерация разделов (§) сквозная по всем частям.

## 6. Эмпирическая карта по готовым данным (CPU)

### 6.1. Что уже извлечено (`fig_order_hg.png`, `tables.md` «Параметры порядка»)
Медианы по Fr (m, 25 м): застой 0,28–0,30 (Fr < 0,2) → 0,21 (0,3–0,4) → 0,13 (0,5–0,75) → 0,065 (1–1,5) → 0,014 (2,5–5) → 0,004 (> 5); поворот > 45°: 0,22 → 0,13 → 0,10 → 0,05 → 0,009 → 0,004; обратное течение: 0,10 → 0,04 → 0,03 → 0,009 → 0; средняя скорость / приток 0,7–0,8 (Fr < 0,3) → 1,2 (0,75–1) → 2,0 (2,5–5) → 2,6 (> 10); разгон p99 2,1–2,3 → 3,1–3,5; σ_w(600 м)/U_sat 0,06 (Fr < 0,1) → 0,03 (0,5–1) → 0,01 (> 5); σ_w на 800 м в м/с максимальна 0,32–0,36 при Fr 0,75–1,5 — **волновой максимум в критической зоне** есть, но слабый. Все кривые **плавные на две декады Fr**, без изломов: область 40 км — смесь локальных Fr (§7), и усреднённые параметры порядка видят «правило рычага», а не границу.

**Срыв по крутизне (Fr > 1,5, чистая механика):** доля обратного течения на 25 м — 0 при уклоне p95 (100 м) < 20°; 0,005 (20–25°); 0,018 (25–30°); 0,045 (30–35°); 0,11 (35–40°); 0,15 (> 40°), p90 до 0,28. Порог появления — около 20–25° (tg 0,36–0,47 на 100 м; на 400 м клетка сглаживает уклон ~в 2 раза, так что на сетке решателя это 0,2–0,25), согласуется с 0,3/20° литературы [Woo95, Fin20]; переход плавный по корпусу (разные места), резкость по месту проверять на идеальном хребте.

**Конвекция:** СКО (u_h − u_m)/U_b на 50 м растёт с w*/U: 0,24 (< 0,05) → 0,49 (0,3–0,5) → 0,91 (1–1,5) → 1,5 (> 1,5) — при w*/U > 0,5 нагрев меняет приземный ветер на половину и больше; СКО Δw(300 м) 0,06 → 0,15 м/с — конвективная вертикаль в среднем поле мала (K-замыкание даёт средний столб, не термики). Асимметрия w на 300 м: без нагрева 0,8–1,5 (это рельефная асимметрия: узкие подъёмы на наветренных склонах), с нагревом *ниже* (0,2–0,9 при w*/U > 1) — нагрев добавляет широкий подъём над склонами; **асимметрия w в K-поле — не индикатор термиков**, индикатор термиков здесь невозможен.

### 6.2. Распределение случаев по осям и белые пятна (`fig_cases_hg.png`)
Плотность в (Fr, Δh/z_i) двугорбая: Δh/z_i ≈ 1 (день, слой выше рельефа) и ≈ 10³ (утро, z_i у земли). Белые пятна: **G** — только вечерняя выхолаживание до 20:00 (13 %), без ночи, без разрешения стоков; **H** — 6,5 % случаев с U10 < 1,5 м/с, 70–80 % из них не сошлись — данных «решения» там почти нет; **F** — условия есть (день: −z_i/L медиана 41), но решатель в F даёт только среднее K-замыкания — ячеек/термиков в полях нет по построению; **C с инверсией** (Fr_i, h/z_i) — Fr_i не вычислен (нет Δθ инверсии в таблице; has_cap у 33 % случаев, cap_agl до 1387 м — можно добавить в условия); **B** на 400 м — срыв виден слабо.

### 6.3. Разделимость (таблицы «Разделимость»)
Несходимость по Fr в терцилях: w*/U — макс. разница 0,20, средняя 0,05 (разделимо); −z_i/L — 0,44 / 0,13 (средний терциль 0,15–19 хуже остальных при Fr 0,1–0,5 — утро с низкой z_i, т.е. ось h/z_i); уклон — 0,55 / 0,16; Δh — 0,57 / 0,18; U10 — 0,17 / 0,07 (сцеплен с Fr). Чистая разделимость только Fr × нагрев; остальное требует контролируемых опытов, в корпусе оси сцеплены через выбор условий (Fr = U/(NΔh) с Δh места).

## 7. Локальность фаз

Фаза — свойство точки, не области: в одном квадрате 40 км одновременно гребень в A/B, долина под инверсией в D, прогретый склон в E/F, тенистая долина вечером в G — как зёрна фаз в шлифе сплава. Локальные параметры на клетку: **местный Fr** = U/(N·h_loc), h_loc — превышение ближайшего гребня над клеткой (максимум в окне 4,4 км минус высота клетки; при h < z_i — N эффективное слоя, при h > z_i — N свободной атмосферы); **местная крутизна** подветренного склона (∇h·e < 0); **местный нагрев** −z_i/L по потоку тепла клетки (склон на солнце против тени); **знак H**. Пример (`fig_local_phase.png`, случай 17 рельефа 35, U_sat 8,0 м/с, N 0,0118, Fr области 0,49, H 163 Вт/м²): по местному Fr область на 88 % в A, 11 % в C (подножия главного хребта), 1 % в B; тепловая карта — вся в E (−z_i/L 5–25). Доля застоя у земли в решении m по классам: A — 0,04, B — 0,06, C — 0,29 — местная классификация **предсказывает, где решатель тормозит поток**, при том что Fr области (0,49) обещал «блокирование» везде.

Сшивка: своё решение на зону (например D — послойный обход ниже H_c, A — линейное/сеть выше), на границах зон — общий приток/проекция на неразрывность (один шаг проекции ∇·u = 0 поверх сшитых полей, как в массосогласованных моделях [Ros88]); в переходных полосах — **правило рычага**: u = (1 − φ)·u_фаза1 + φ·u_фаза2, φ = сигмоида параметра порядка (например застой или местный Fr с шириной перехода по подгонке [§9](solvers-and-experiments.md)). Для E решения примерно складываются: среднее (A/D) + статистика валов (положение случайно, амплитуда по −z_i/L); для F — среднее + термики масштаба 2 (уже так в плане air_model: стык 1↔2).
