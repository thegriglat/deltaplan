# sw-charges: итог этапов 1, 2 на 2D (три круга) и шага 3 прототипа A (рельеф)

Сводка модуля; 3D — отдельный модуль sw-charges-3d. Числа — из документов модуля (ссылки `путь#раздел`), здесь не пересчитывались. Роль 2D (решение пользователя 2026-11-08): 2D — не эталон, итог — список проблем для 3D; числа 2D паритетом или провалом не считаются, артефакты 2D не чинились. Эталон: теория (`literature.md`), эксперимент и измерения, где они есть, и Пикар как третья опора с допуском ±10–15 % (решение пользователя 2026-11-08: Пикар сам врёт на столько, под него не подгоняли).

## 1. Вопрос и решения пользователя

Вопрос плана ([plan](/docs/plan/sw-charges.md)): годится ли путь к полю ветра над рельефом без 3D-итераций Пикара — сначала слой мелкой воды (reduced gravity, g′ = g·Δθ/θ), затем заряды на поверхности (панели) и вихревые нити; результат — «годится / для чего / чего не умеет» с числами, не встраивание в игру.

Решения пользователя (журнал `docs/plan/sw-charges/decisions.jsonl`, все 2026-11-08):
- Путь без Пикара: слой мелкой воды → панели → вихревые нити; прототипы на Python; перенос в Rust/игру — отдельным решением.
- Сначала 2D (квази-2D разрезы cascade-2d); места игры и 3D — после итога 2D.
- Единое описание трёх масштабов (среднее поле, термики, болтанка): термик как диполь/кольцо, болтанка как пары; 1–2 прототипа (этап 3).
- Эталон — эксперимент и измерения (Askervein, лотки, стоки, термики, σ_w), Пикар с допуском ±10–15 %; в таблицах — колонка «эксперимент» с надёжностью.
- Шлюз Q1 (после SWC-9): слой на 400 м хуже ровного ветра; «Вариант 1» — доделать SWC-8, разрезы не трогать.
- Q2: этап 2 — на 2D-разрезах; порог успеха — паритет с Пикаром в ±10–15 %, цель — единая аналогия «заряды/вихри», а не обгон Пикара.
- Q3, Q4 (последний круг 2D) и «3D в любом случае»: 2D — не эталон, итог — список проблем (раздел 7); 3D — модуль sw-charges-3d.

## 3. Этап 1: слой против теории, air-phase, Пикара и измерений

**A1 — слой против теории (SWC-8).** 1D-разрезы, h0 = 1000 м, b0 = 0,1 м/с², a/h0 ≥ 3, без трения; сетка F0 × M ([stage1-regimes.md#2-a1-гидравлика-против-теории-2](/docs/research/sw_charges/stage1-regimes.md#2-a1-гидравлика-против-теории-2)):
- режимы: ridge 104 из 111 (a/h0 = 3: 79 из 84; a/h0 = 6: 25 из 27); расхождения у границ классификатора (слабый бор < 0,02), по существу нет;
- бор h1/h0 совпал с теорией в пределах 0,001 во всех 38 случаях; скорость бора 1–2 % при M/M_c ≥ 3, до +8 % у слабых;
- гистерезис (F0 > 1, M_s ≤ M < M_c): две ветви; F0 = 1,5, M = 0,13: прыжок −1,07a против −1,02a теории; F0 = 2, M = 0,4: прыжок дрейфует (−2,17a против −1,18a, зависит от сетки);
Эксперимент: количественных измерений для этих чисел не найдено; качественно режимы подтверждены лотками (Long 1954; Baines 1984; Lawrence 1993). Надёжность — качественная.

**A2 — условия air-phase через правило R1 (SWC-8).** Хребет H = 500 м, s = 0,3, N = 0,01 с⁻¹, 66 случаев ([stage1-regimes.md#3-a2-условия-air-phase-через-r1](/docs/research/sw_charges/stage1-regimes.md#3-a2-условия-air-phase-через-r1)): при h/z_i = 0,3 (a/h0 = 0,86, вне мелкой воды) блокирование R3 с Fr_game 1,6, переход 1,1–1,3 (теория 1,25 / 1,18); при h/z_i = 1 и 3 — R6 при всех Fr, перехода нет. Air-phase: обход 0,89, застой 1,26; при a/h0 = 0,86 гидростатика слоя неверна — наводка, не подтверждение. Эксперимента для условий игры нет.

**Слой против Пикара на разрезах (SWC-9).** Пикар dx 50, слой 400 м (основная) и 200 м; E — среднеквадратичная ошибка среднего по слою ветра / ветер притока, E0 — то же для ровного ветра ([stage1-sections.md#таблица-пикар-dx-50-основной](/docs/research/sw_charges/stage1-sections.md#таблица-пикар-dx-50-основной)):

| Случай | E слоя (400 м) | E0 | Вывод |
|---|---|---|---|
| C1, C4 (нейтраль, h0 2500) | 0,002 / 0,007 | 0,030 / 0,020 | оба в допуске, метрика почти не различает |
| C2, h0 2500 | 0,012 (N2h0), 0,035 (N2delta) | 0,031 / 0,030 | то же |
| C2, h0 1000 (F0 ≈ 1–1,2) | 0,361 (N2h0), 0,453 (N2delta) | 0,131 / 0,161 | слой хуже ровного ветра в 2,8 раза |
| C3 (слабый ветер, нагрев) | 0,151 за 1 ч, 0,237 за 3 ч | 0,053 | смещение −15 % и −24 %, подъёма к склону не видно |
| Perdigão tse13/tse09 | ū(долина)/ū(гребень) 0,85–0,98 | измерение 0,32 | тени и обратного течения нет; в измерениях рециркуляция в 49 % периодов NE |

Условие «E ≥ E0 на сильном ветре» не выполнено: из 12 вариантов E < E0 в 6, E > E0 в 6; среднее по слою ≥ 1000 м не содержит тени, ротора и разгона у земли. Эксперимент: разгон у земли ΔS₀ = 2H/L = 0,8 ± 15 % (Taylor–Lee 1984, формула; надёжность низкая); тень на 10–100 м (Perdigão, Menke 2019).

## 4. Этап 3 без рельефа: прототипы A и C (SWC-5, SWC-6, SWC-7)

Единое описание среднего поля, термиков и болтанки; оба прототипа 2D, Python.

**Прототип A — вихревые частицы с плавучестью** (Dω/Dt = ∂b/∂x; [proto-a.md#шаг-1-числа-δθ-1-к-r-100-м](/docs/research/sw_charges/proto-a.md#шаг-1-числа-δθ-1-к-r-100-м)). Получилось на ранней фазе (t√(b/R) ≲ 2; R = 100 м, Δθ = 1 К до 60–90 с): ускорение пятна 0,477·b (a = b/2 ниже на 4,5 %); Γ = −2bRt с точностью 3 %; P/(B·t) 0,998 → 0,985 (90 с); w_max 0,93, w_min −0,80 м/с, ∫w dx / ∫w⁺ dx = 1 % (тривиально для 2D). Не получилось: P/(B·t) = 0,715 за 600 с (не лечится числом частиц, только перегруппировкой); рост КГ-слоя 0,67 теории; σ_w в слое 0,25·ΔU против 0,14·ΔU игры (в 1,8 раза), спектр −3,4…−3,7 вместо −5/3; пары в свободном слое не рождаются. Цена: 43 мс на 10⁴ частиц (CuPy, FP64); для 60 Гц не годится.

**Прототип C — диполи Лэмба — Чаплыгина и пары болтанки** ([proto-c.md](/docs/research/sw_charges/proto-c.md)). Получилось: ансамбль термиков (≈ 100, ν = 0,057 с⁻¹) воспроизводит H(ζ) = 0,91/0,74/0,49/0,24 против 1−ζ = 0,90/0,75/0,50/0,25 без подгонки. Не получилось: пик w ЛЧ в 2,5 / 2,2 / 1,4 раза выше w₀ игры, ядро уже (0,62 R); σ_w пар в 1,35–1,74 раза выше нейтральной σ_w игры; L_w в 0,3–0,4; импульс термиков в 2–4 раза меньше u*² игры; из 44 проверок пройдено 19.

Рекомендация SWC-6: брать A как источник организованных структур (термик + кольцо, слои сдвига) с перегруппировкой, шумовой фон оставить моделью масштаба 3.

## 5. Этап 2 на 2D-разрезе: панели и вихри (SWC-11, SWC-12)

Метод ([stage2-2d.md#постановка](/docs/research/sw_charges/stage2-2d.md#постановка)): земля — 2D-панели постоянных источников (144–146 панелей, ds_min 25 м, рост ×1,15 до 400 м) в заданном сдвиговом фоне (степенной, σ сглаживания 250 м); «вихревой» вариант добавляет дискретные вихри Лэмба — Озеена, рождаемые за гребнем там, где подветренный уклон ≥ 0,27 (Finnigan 1988), Γ = −½u_s²dt, без диссипации. Разрезы Пикара C1, C2, C4 (P50), трубные хребты Lubitz & White 2007, линии Perdigão NE/SW. Порог успеха (решение Q2): паритет с Пикаром в ±15 %, на Perdigão — рядом с моделью игры.

Паритет по порогу Q2 выполнен на 300 м и над гребнем выше 50 м, не выполнен у земли, в долине Perdigão и против трубы; ценность — единая аналогия «источники по рельефу плюс вихри с кромки» и цена, а не точность.

### 5.5 Круги 2 и 3 (SWC-15–19): что менялось и что осталось

Круг 2 — причины недобора ΔS и погрешность эталона ([stage2-2d-tunnel.md](/docs/research/sw_charges/stage2-2d-tunnel.md)); круг 3 — пограничный слой и отрыв Хеда, SW6 v3 ([stage2-2d-bl.md](/docs/research/sw_charges/stage2-2d-bl.md)); последний круг — Jackson–Hunt и отрыв только с подветренной, SW6 v4 ([stage2-2d-jh.md](/docs/research/sw_charges/stage2-2d-jh.md#таблица-проблем)).
- SWC-16: ΔS на гребне зависит от σ сглаживания фона (0,3 → 1,2 у H3) и высоты сравнения сильнее, чем от формы, α и сетки; потенциальный предел ΔS(z→0) 0,29–0,72 (≈ 1,07 H/L) ниже измеренного в 1,2–1,8 раза — это внутренний слой, которого в схеме нет. Погрешность эталона Пикара P50 в двух нижних клетках 7–33 %, на ~50 м 2–9 %, на ~300 м ≤ 1,5 %.
- SWC-17: слой Хеда у земли 6/15 в допуске (было 2/15), на 300 м vortex_bl 10/15 (было 14/15); критерий Хеда срабатывает на любом торможении: отрыв в 6 из 11 случаев, подветренный один (C2); ложный ротор C4 исчез вместе с реальными (C2, Perdigão); ΔS трубы слой обнулил; Perdigão RMSE в 2–3,5 раза хуже игры.
- SWC-19 (v4): отрыв только за гребнем (наветренных 0), C4 — 0 м; ΔS трубы 0,52–1,22 против 0,35–1,08, недобор снят (средняя ошибка 26 %), перелёт до +49 % у MD, UCD, H8; роторы C2 и Perdigão 0 / 0 / 0; мачты NE RMSE 0,495 (3,43× игры), SW 0,273 (1,94×); на гребнях Пикара у земли 1 из 6 (SWC-17: 6 из 6 у vortex_bl).

## 8. Какие законы учтены, приближения, чего модель не умеет

**Учтено (слой Рипа, `swpy`)**: сохранение массы и импульса слоя толщины h с плавучестью b (давление Рипа, reduced gravity), сухие клетки там, где рельеф выше слоя, трение о землю c_d (по правилу R1), Кориолис, нагрев слоя, сила `balance`, губка у краёв; схема MUSCL + SSP-RK2 + HLL, well-balanced по Одюссу ([README решателя](/tools/research/sw_charges/README.md#решатель-swpy)).

**Учтено (панели и вихри `panels2d`, этап 2 и прототип A)**: несжимаемое потенциальное течение (источники на линии земли, нормальная скорость обнуляется), заданный сдвиговой фон, дискретные вихри Лэмба — Озеена с адвекцией (RK2), рождение вихрей на кромке по порогу уклона; в A — плавучесть через baroclinic-член Dω/Dt = ∂b/∂x, земля — панели.

**Приближения и границы:**
- слой: одна однородная по вертикали масса, воздух выше неподвижен; верна для a/h0 ≥ 3; хребет выше слоя (M ≥ 1) — только R6; вовлечения нет; слабые боры (< 0,02) не распознаются;
- разрезы SWC-9 — 1D по линии, блочное среднее рельефа (тень, ротор и разгон у земли не видны); нагрев слоя в farfield не компенсируется (−15 % за 1 ч);
- панели и вихри, A: 2D, идеальная жидкость, свободное скольжение на земле, без вязкости, самоиндукции и роста ядер; взаимодействие 2D (~1/r²) сильнее 3D (~1/r³); термик — цилиндр, не кольцо; индуцированное поле термиков в C выключено — θ̄ расходится;
- сравнение с экспериментом ограничено: числа слоя не сверены с лотками (полный текст недоступен), по холмам и Perdigão масштаб (10–100 м) не совпадает со слоем ≥ 1 км.

**Не умеет (по этим опытам)**: у слоя Рипа — тень и ротор за гребнем (Perdigão — обратного течения нет), разгон у земли, подъём к прогретому склону на 400 м, пороги Fr_game air-phase при h/z_i ≥ 1; у панелей — торможение у земли на наветренном склоне и подножии, паритет с Пикаром на 10–50 м, ΔS трубы, отрыв без заданного источника вихрей; у A над рельефом — отрыв термика от склона, склоновый ветер, ротор без схода вихрей; турбулентность из 2D-частиц (спектр −3,5) и σ_w конвективной части без калибровки.

## 9. Что по плану не сделано и почему

- Места игры, сильный ветер (опыт 1(б)) и слабый ветер, картинки стока/подъёма (1(в)) — не сделаны: «сначала 2D, места — после итога 2D», затем шлюз Q1; слой стока (десятки–сотни м) не проверялся.
- Эксперимент — часть: Bolund не использовался; Askervein для слоя не сравнивался (масштабы); Lubitz–White — в 5.2; стоки и σ_w слоя Рипа не измерялись.
- Время счёта: есть для A1/A2 (5330 с CPU), прототипов, панелей (5.4, 6); для разрезов SWC-9 не указано.
- 3D (панели на месте игры, 3D-поле, вихревые нити) — модуль sw-charges-3d. Прототипы B и C над рельефом, перегруппировка частиц A — не делались.
- Не считалось: C3 для панелей, стратификация C2, ансамбль, dx 25 для эталонов Пикара (SWC-3).

**Итог:** слой Рипа — гидравлика Fr: режимы теории 104 из 111, бор, гистерезис (при хребте ниже слоя и a/h0 ≥ 3); как средний ветер на 400 м над рельефом не лучше ровного (при F0 ≈ 1–1,2 хуже в 2,8 раза), в условиях игры при h/z_i ≥ 1 всегда R6. Панели — разгон на гребне выше ~50 м и паритет с Пикаром на 300 м; у земли (10–50 м), в лее и роторы — открыто. 2D после трёх кругов — не эталон, а список из 12 проблем (раздел 7): схема (остаётся в 3D) — порог и критерий отрыва, наветренный отрыв, нет внутреннего слоя, зависимость от сглаживания фона и высоты сравнения; 2D-артефакт (может уйти в 3D) — сила и незатухание ротора (~4× Menke у A), завышение σ_w (×1,35–1,8); одна причина не выяснена (мачты Perdigão). Описывается «зарядами/вихрями»: термик с кольцом и подтеканием (A), поток тепла (C), разгон на гребне (панели), ротор при заданном источнике вихрей; не описывается: приземный слой 10–50 м, отрыв по физике, склоновый ветер, турбулентность без калибровки. Проверять в 3D — модуль sw-charges-3d.
