# Контракты модуля «ui-controls»

Внутренний документ. План — `docs/plan/ui-controls.md`. Контрактный тест — `tests/game/test_ui_controls_contracts.gd`. Менять — только через координатора модуля: версия +1, что изменилось, потребители правятся в том же шаге.

## Опора: ControlInput.pitch (control-fix С1) — без изменений
`ControlInput.pitch ∈ [−1, 1]`: **+1 — трапеция от себя (нос вверх, торможение, угол атаки больше)**, −1 — на себя (нос вниз, разгон). Этот модуль смысл поля не меняет — меняет только, какие устройства ввода дают какой знак.

## У1. Раскладка тангажа по умолчанию — v2
Владелец: этот модуль (`configs/controls.json → keys`, `invert_pitch`; знак стика в `InputController._apply_gamepad`). Потребители: `InputController` (полёт; на земле на разбеге — CF-3 «как в воздухе»), экран «Управление» (`configs/ui.json → controls_help`), подсказки/локали, документация, автопилот и тесты (жмут действия по имени).

Действия (имена — смысл, не клавиша):
- `pitch_push_out` — трапеция от себя → `pitch` +.
- `pitch_pull_in` — трапеция на себя → `pitch` −.

v1 (v1.0.0, «как в самолёте» для клавиш и стика): `pitch_pull_in` = [W, Up], `pitch_push_out` = [S, Down]; стик вперёд (ось 1 < 0) → `pitch` −; мышь `bar` от себя → `pitch` +.

**v2 (решение пользователя 01.10, «как у дельтапланериста»):**
- `pitch_push_out` = [W, Up]; `pitch_pull_in` = [S, Down].
- Мышь `bar`: от себя (курсор вверх, `relative.y < 0`) → `pitch` + (как в v1).
- Стик: вперёд (ось `gamepad.pitch_axis` < 0) → `pitch` +.
- `invert_pitch` (по умолчанию `false`): `true` меняет знак для клавиш, мыши и стика разом («как в самолёте»).
- На земле стоя/шагом (до CF-3): W/S — `walk_forward`/`walk_back`, ↑/↓ — `nose_up`/`nose_down` (↑ — нос вверх), без изменений. После CF-3: на разбеге «как в воздухе» — значит через `pitch_push_out`/`pitch_pull_in` с этим знаком; CF-3 знак повторно не переставляет.
- Экран «Управление»: строки «идти/шаг назад» привязаны к `walk_forward`/`walk_back`, а не к действиям тангажа.
- Инвариант (тест): в полёте по умолчанию W, ↑, мышь от себя, стик вперёд дают `pitch` > 0 и рост угла атаки; S, ↓, мышь на себя, стик назад — `pitch` < 0.

## У2. Обзор с клавиш при трапеции мышью — v1 (этап 2, 02.10)
Владелец: этот модуль (UC-3). Потребители: `InputController`, `CameraRig`, `Game` (связка), экран «Управление» и тексты (UC-4), автопилот (не затронут — жмёт действия по имени).

Действия (`configs/controls.json → keys`): `look_up` = [W], `look_down` = [S], `look_left` = [A], `look_right` = [D].

Условие — `InputController.keys_look() -> bool`:
`true` ⇔ `enabled` и не `hands_off` и `mouse.mode == "bar"` и `mouse_captured` и (в полёте `not on_ground` **или** на разбеге — зажат `run` и разбег не заблокирован).
Стоя и шагом на земле, в режиме мыши `look`, с отпущенной мышью — `false` (всё как в У1 v2 / С2 v2).

Когда `keys_look()`:
- **Трапеция**: физическая клавиша, назначенная на любое из `look_*` (W/S/A/D), в `ControlInput.pitch`/`roll` **не вносит ничего** (вклад 0, а не «держит»). Другие клавиши тех же действий (стрелки) — как в У1 v2. Нажатие действия без физической клавиши (`Input.action_press` — автопилот, тесты) — считается.
- **Камера кабины** (`CameraRig.mode == "cockpit"`): удержание `look_left`/`look_right` меняет рыскание головы (+ влево), `look_up`/`look_down` — тангаж (+ вверх) со скоростью `camera.json → cockpit.head.key_rate_deg_s` (°/с, > 0), в пределах `cockpit.head` (yaw_limit_deg, pitch_up_limit_deg, pitch_down_limit_deg); отпустил — голова остаётся; V/средняя — плавно вперёд (как было). `set_look` (скриншоты) — клавиши голову не двигают.
- Камера `chase` — клавиши обзора ничего не делают; `free` — без изменений (WASD двигают её, крыло без рук).

Связка: `CameraRig.keys_look_fn: Callable` () -> bool; не задана — `false` (клавиши голову не двигают). `Game` ставит `camera.keys_look_fn = input_controller.keys_look`.
Наблюдаемое для тестов: `CameraRig.head_look_deg() -> Vector2` — текущий поворот головы (x — рыскание + влево, y — тангаж + вверх), °, без взгляда на прибор и без `look_down_deg`.

Инварианты (тест `test_u2_*`): bar + захват, полёт: W/S/A/D 0,5 с → `pitch` = 0 и `roll` = 0 (|·| < 1e-6); ↑ → `pitch` > 0; `action_press("pitch_push_out")` → `pitch` > 0; bar без захвата — W → `pitch` > 0; разбег (на земле, Shift) bar + захват — W → `pitch` = 0; режим `look` — У1 без изменений. Камера кабины с `keys_look_fn` = true: A 0,5 с → рыскание ≈ +45° (при 90°/с), W 0,5 с → тангаж > 0; с `false` — 0.
