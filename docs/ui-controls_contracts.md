# Контракты модуля «ui-controls»

Внутренний документ. План — `docs/plan/ui-controls.md`. Контрактный тест — `tests/game/test_ui_controls_contracts.gd`. Менять — только через координатора модуля: версия +1, что изменилось, потребители правятся в том же шаге.

## Опора: ControlInput.pitch (control-fix С1) — без изменений
`ControlInput.pitch ∈ [−1, 1]`: **+1 — трапеция от себя (нос вверх, торможение, угол атаки больше)**, −1 — на себя (нос вниз, разгон). Этот модуль смысл поля не меняет — меняет только, какие устройства ввода дают какой знак.

## У1. Раскладка тангажа по умолчанию — v2
Владелец: этот модуль (`configs/controls.json → keys`, `invert_pitch`; знак стика в `InputController._apply_gamepad`). Потребители: `InputController` (полёт; на земле на разбеге — CF-3 «как в воздухе»), экран «Управление» (`configs/ui.json → controls_help`), подсказки/локали, документация, автопилот и тесты (жмут действия по имени).

Действия (имена — смысл, не клавиша):
- `pitch_push_out` — трапеция от себя → `pitch` +.
- `pitch_pull_in` — трапеция на себя → `pitch` −.

v1 (v1.0.0, «как в самолёте» для клавиш и стика): `pitch_pull_in` = [W, Up], `pitch_push_out` = [S, Down]; стик вперёд (ось 1 < 0) → `pitch` −; мышь `bar` от себя → `pitch` +.

**v2 (решение пользователя 01.10, «как у дельтапланериста»):**
- `pitch_push_out` = [W, Up]; `pitch_pull_in` = [S, Down].
- Мышь `bar`: от себя (курсор вверх, `relative.y < 0`) → `pitch` + (как в v1).
- Стик: вперёд (ось `gamepad.pitch_axis` < 0) → `pitch` +.
- `invert_pitch` (по умолчанию `false`): `true` меняет знак для клавиш, мыши и стика разом («как в самолёте»).
- На земле стоя/шагом (до CF-3): W/S — `walk_forward`/`walk_back`, ↑/↓ — `nose_up`/`nose_down` (↑ — нос вверх), без изменений. После CF-3: на разбеге «как в воздухе» — значит через `pitch_push_out`/`pitch_pull_in` с этим знаком; CF-3 знак повторно не переставляет.
- Экран «Управление»: строки «идти/шаг назад» привязаны к `walk_forward`/`walk_back`, а не к действиям тангажа.
- Инвариант (тест): в полёте по умолчанию W, ↑, мышь от себя, стик вперёд дают `pitch` > 0 и рост угла атаки; S, ↓, мышь на себя, стик назад — `pitch` < 0.
