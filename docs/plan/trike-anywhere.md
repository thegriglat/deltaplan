# План trike-anywhere (код задач TA)

## Цель
Дельталёт игрока и буксировка дельтаплана — на любом месте одиночной игры, не только на Wilotree Park. Решения
пользователя 2026-10-23 — `.dpcli/dpcli inbox trike-anywhere` (`decisions.jsonl`).

## Решения пользователя (2026-10-23)
- По «Лететь» — одно окно: «Дельтаплан» / «Дельталёт»; для дельтаплана — буксировка (нет / виды места). В сети окна нет.
- Выбор буксировки и пункт «Дельталёт» с вкладки «Место» экрана старта убрать.
- Дельталёт — на колёсах в точке старта места, курс места, на любом склоне. Буксировка — на любом месте: линия от
  точки старта по курсу, длины — блок `tow` места или общие (`configs/tow.json`), рельеф не проверяется.
- Лётных проверок нет (склоны, полёты, кадры): только тесты окна и появления дельталёта на колёсах в точке старта.

## Задачи
- **TA-1** (`dp-engineer`) — окно выбора старта (TA-К1): `StartMenu` «Лететь», «Лететь отсюда»; строка буксировки
  с вкладки «Место» убрана; тесты меню и буксировки обновлены.
- **TA-2** (`dp-engineer`) — `Game` (TA-К2): дельталёт и буксировка в любом месте без проверки рельефа; контрактный тест.
- **TA-3** (`dp-writer`, после слияния TA-1 и TA-2) — руководство (`docs/guide/flight/trike-pilot.md` «Как стартовать»,
  разделы о выборе буксировки в `docs/guide/`), `CHANGELOG.md` «В работе».

Волна 1 — TA-1 и TA-2 параллельно (стык — поля `FlightSettings.vehicle`, `tow_kind`, уже есть). Волна 2 — TA-3.

## Приёмка
Тесты задач по фильтрам карточек; полный прогон — главная сессия. Визуал — тестовая сборка у главной.

## Условия остановки
Нужна правка физики колёс/буксировки или новые лётные проверки — шлюз к главной.
