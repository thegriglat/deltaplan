# Вид пилота и управление (отзыв тестировщика 08.10)

Ветка `feature/pilot-view`, копия `~/deltaplan-pilot-view`, координатор — dp-coordinator. Контракты — `docs/contracts/pilot-view.md` (PV1–PV3) и A3 в `docs/contracts/aframe-geometry.md`. Журнал — `docs/plan/pilot-view/` (`dp`).

## Цель
Отзыв пилота-тестировщика (англ., 08.10), пункты, выбранные пользователем:
1. Пилот висит слишком высоко: нужно 2–3 дюйма (5–7 см) над базовой штангой.
2. Трапеция слишком далеко позади камеры (или камера слишком высоко и впереди), FOV узкий; из кабины должны быть видны хотя бы центр штанги и носовые тросы.
3. Базовая штанга изогнута вперёд в центре — у всех крыльев, кроме учебных вроде Alpha (у Falcon изогнутая).
4. X — возвращает «мышь» (положение управления) в центр, а не только держит крыло ровно, пока зажата.
5. Опция: крен мышью как трапецией (мышь вправо = штанга вправо = вес влево).

## Решения пользователя (не обсуждаются)
- Чиним пункты 1–5 отзыва (08.10). Высота подвеса — 5–7 см над штангой (заменяет 0,37 м из A3.5 v5).
- Геометрия (подвес, глаза, трапеция) — из реальных размеров и источников, не на глаз; визуальные мелочи — не больше 2 попыток; без поясняющих подсказок в игре.
- Значение по умолчанию для крена мышью — решает координатор по физике/коду, с обоснованием в журнале.

## Физика и границы модели
- Высота подвеса меняет длину подвески (`configs/pilot.json → hang_length_m`, `body_below_hang_m`) — это положение центра масс пилота под карабином, т. е. физика маятника. Меняем честно (реальный пилот висит низко), изменения откликов по крену/тангажу и скоростей трима — в отчёт; провал тестов поляры/крыльев — шлюз.
- Положение базовой штанги относительно подвески задаётся геометрией крыла (A1: подвеска, наклон и длина стоек). Положение плеч и глаз относительно подвески — из модели пилота (подвеска = центр масс пилота). Если реальная геометрия расходится с A3.1 («база под плечами») — A3.1 пересматривается по источникам (PV-1), а не подгоняется наклоном стоек.
- Изгиб штанги — геометрия визуала и хвата; аэродинамика штанги в модели не учитывается.

## Шлюзы (условия остановки)
- Реальная геометрия (PV-1) требует менять подвеску/наклон стоек крыльев (A1) — физика трима меняется → шлюз.
- Провал тестов поляры/трима после смены длины подвески → шлюз.
- Центр штанги и носовые тросы не попадают в кадр ни при каком разумном FOV (≤ 100° по вертикали) при реальной геометрии → шлюз с вариантами.
