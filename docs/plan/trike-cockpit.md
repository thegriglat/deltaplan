# Приборы дельталёта из кабины (модуль `trike-cockpit`, код задач TC)

## 1. Цель
Пользователь в тестовой сборке Linux (`main` 1e803596b, 2026-10-23): у дельталёта от первого лица (`camera.mode == "cockpit"`) приборы ничего не показывают. Найти причину и исправить, чтобы пилот дельталёта из кабины видел показания.

## 2. Решения пользователя (не обсуждаются)
- Отзыв выше — исходная постановка (2026-10-23).
- После исправления — тестовая сборка Linux у главной сессии; кадры кабины (если нужны для приёмки) — `/home/greg/deltaplan/build/screenshots/trike-cockpit/`.
- Лимит на число исполнителей не действует; файлы во временном каталоге (scratchpad) — только с префиксом ID задачи.
- **От третьего лица приборы дельталёта (HUD тахометр/топливо) работают нормально — проблема только в кабине** (2026-10-23)
- **В кабине дельталёта — только тахометр и топливо; полётные приборы (вариометр, высота, скорость) не добавлять. Задача — чтобы эти два прибора показывали из кабины** (2026-10-23)

## 3. Что известно (главная сессия, по коду — проверить, не доверять)
- `scripts/game/game.gd`: у дельталёта монтируются только `TrikeGauges3D` (тахометр, топливо; `_mount_trike_gauges`, маркер `InstrumentPanel` тележки), приборы крыла из `game.json → mounted_instruments` (вариометр/высотомер и т. п.) **не монтируются** («маркеров крыла дельтаплана у дельталёта нет»). Показания — `_update_trike_gauges()` → `update_readout`.
- HUD `TrikeGaugesHud` по контракту TP-К4 скрыт в кабине (виден только в `chase`).
- Возможные причины (гипотезы): стрелки/шкалы 3D-приборов не видны или не двигаются (слой, освещение, масштаб, ориентация, `update_readout` не доходит); полётных приборов (вариометр, высота, скорость) в кабине дельталёта нет вовсе; приборы закрыты/вне поля зрения кабинной камеры.

## 4. Границы
- Физику дельталёта и дельтаплана не трогать; вид кабины дельтаплана (`vehicle "glider"`) — без изменений (тесты `pilot_hud`, `cockpit` зелёные).
- Если исправление требует решения по составу приборов (какие полётные приборы ставить дельталёту и куда) — шлюз пользователю с вариантами.

## 5. Условия остановки (шлюз)
- Нужно выбрать состав или размещение приборов в кабине.
- Причина вне модуля (модель тележки, `tools/blender`) и требует пересборки модели.
