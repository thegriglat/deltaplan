# План: мультиплеер — «зона полёта»

Статус: оценка (28.09.2026), в работу не взято. Цель — летать вместе с живыми пилотами (семья, друзья) в одном небе; для взрослых: без портов, аккаунтов и сложных экранов.

## Что уже есть
- Термики детерминированы: генерация по клеткам сетки, зерно = общий сид × клетка × время (`scripts/atmosphere/thermal_field.gd`); фокус пилота только выбирает, какие клетки считать. Одинаковые место, дата, время, погода и сид → одинаковые термики и облака у всех. Атмосферу по сети не передаём.
- Боты = почти готовые «чужие пилоты»: крыло с расцветкой, пилот, имя над головой (`bot_names`), очередь на старте, взлёт по одному.
- Трафик: ~100 байт на пилота × 10 Гц.

## Решения (предложение)
1. **Лобби** — не нужно. Два экрана: «Создать зону полёта» (место, дата, время, погода — как «Полёт…») → код вида `ОНГУДАЙ-47`; «Присоединиться» — ввод кода (+ список открытых зон). Кто в зоне — на экране загрузки и в паузе.
2. **Соединение** — маленький сервер-посредник на VPS (~5 €/мес): все подключаются к нему сами, роутеры и порты не мешают; зона живёт на сервере (часы зоны там же), уход создателя её не закрывает. Альтернативы: прямое подключение к хозяину (порт/UPnP — у части не заработает), Steam (только если игра будет в Steam).
3. **В сетевом полёте**: время только ×1, пауза не останавливает мир, ускорения нет; в зону — только с той же версией игры. Позднее подключение: настройки зоны + текущее время → загрузка рельефа → появление в лагере у старта. Столкновений между пилотами нет.
4. **Очередь на старт** — варианты: (1) свободно, сквозь друг друга; (2) живая очередь как у ботов, простой ~60 с → уступает (рекомендую); (3) несколько стартовых мест на широких стартах; (4) «стекло» — пока не первый, полупрозрачный. Начать с (2), при заминках — (4). После посадки «Ещё раз» → в конец очереди.
5. **Боты** в сетевом полёте — выключены в первой версии (позже — ведёт сервер).

## Добавлено пользователем
- **Своё имя пилота.** Поле «Имя» в настройках (сохраняется в профиле), по умолчанию «Пилот»; уходит в зону при подключении, другие видят его над крылом — тем же выводом, что имена ботов.
- **«Быстро догнать».** Кнопка (в паузе / по клавише) — выбрать пилота из зоны и мгновенно оказаться рядом: в воздухе в ~50 м позади-сбоку на той же высоте, тем же курсом и скоростью; с земли — старт сразу в воздухе рядом с ним. «По-читерски», чтобы быстро собраться и лететь вместе; только в сетевом полёте.

Минимальная версия (зона по коду + чужие пилоты с именами + свободный старт + «догнать») — ~8–9 дней.

## Риски
- Одинаковость термиков Windows/Linux (дробные вычисления) — проверить тестом первым делом.
- Точки с карты: разный кеш OSM → чуть разные дома/ЛЭП (на полёт почти не влияет).
- Сервер надо держать и следить за ним.
- Разные версии игры — только одинаковые.
