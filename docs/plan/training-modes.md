# training-modes — тренировки и загрузка заданий (код задач TM)

TODO.md T-59 (FR-36) и T-56 (FR-35). Только одиночная игра; физику и модель воздуха не трогаем; подсказок про безопасность нет; тексты ru+en.

## Решения (2026-10-17)
- **T-59 — через существующее.** Окно «Тренировка» уже содержит карточки `ridge` (склон), `thermals` (центровка), `landing` (посадка) с предустановленными целями `duration` / `height` / `landing` (`configs/training.json`, GL-К1). Это и есть подключение режимов по KISS: отдельного меню «Режим», `TrainingMode` и экрана итога тренировки не делаем — итог даёт «выполнено n из m». Старые классы `scripts/tasks/training_{mode,ridge_soaring,thermal_centering,spot_landing}.gd` в игру не идут и удаляются; `configs/tasks/training_spot_landing.json → targets` нужен целям (мишень посадки) и остаётся.
- **T-56 — по образцу треков.** В `GoalsTab` рядом со списком заданий кнопка «Загрузить задание…» (`.xctsk`, `XctskImporter`): файл проверяется (читается, пункты в детальной зоне места), годный копируется в `user://tasks/` и выбирается в списке; негодный — сообщение под кнопкой. Редактора заданий нет.

## Границы
- Карточка «Склон» считает время в воздухе (цель `duration`), а не время у склона; «Центровка» — набор высоты над взлётом. Тонкие критерии старых классов (полоса высот, доля времени в подъёме, кольца мишени) не переносятся — цели их не требуют.
- Файлы live-menu (главное меню) и takeoff-wind (физика старта) не трогаем.
