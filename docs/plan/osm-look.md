# osm-look — внешний вид объектов OSM

Сейчас (OT-11, `build/screenshots/OT-11/almaty_air.png`): одноцветные коробки, у плоской крыши цвет стен, сверху
«кубики»; ЛЭП, мачты, ветряки — конусы и цилиндры. Цель — читаемый сверху город и село, узнаваемые объекты,
без заметной просадки кадра на слабой машине (RX 5600 XT) и без пересборки тайлов.
Контракты — `docs/contracts/osm-look.md` (L1–L6), O9 поднят до v2.

## Решения пользователя (не обсуждаются)
- Дома: стиль «город / село / промзона» на клиенте (тип O3, площадь, плотность на клетку ~200 м); крыша всегда
  другого цвета; город — плоская серая/битумная крыша, окна по этажам, светлые стены; село — скатные крыши,
  1–2 этажа, мало окон; промзона — профлист без окон; затемнение у земли; шейдером без роста геометрии; тени как есть.
- Поправка этажности мегаполиса (Алматы выглядит маленьким): только дома с высотой из эвристики; множитель от
  плотности центра (~0,5–1 км) и масштаба города (~8–10 км), центр миллионника ×1,5–2,5; в ядре — «стекляшки»
  15–30 этажей; параметры в `osm_tiles.json → height_rule`; минимум — только плотность + стекляшки.
- Дым из труб у 20–30 % домиков «не города», детерминированно; готовый дым костра; ограниченная дальность, пул.
- Модели вместо конусов: опора ЛЭП, столб, решётчатая мачта, телебашня, труба, ветряк (лопасти по ветру), кабинка
  канатки; лоупольный меш + хорошая текстура/альфа; Blender-скрипт, CC0/процедурные текстуры, `ASSETS.md`.
- Пасхалки к OSM не привязывать. Тайлы и упаковщик не трогать (идёт ночная сборка мира).
- Кадры каждой модели и вида — сразу по готовности в `/home/greg/deltaplan/build/screenshots/osm-look/<задача>/`,
  одобрения не ждать. Не больше 2 попыток на визуальную мелочь.
- Единственный шлюз — тестовая сборка `build/osm_test` + кадры Алматы, отчёт главной сессии.

## Задачи
### OL-1 Дома: стиль, этажность мегаполиса, трубы и дым, провод ветра
`dp-engineer`. L1–L4. `OsmData` (поля 8–9), `BuildingStyle` (classify/adjust), `BuildingPlacer`/`OsmBuildings`
(INSTANCE_CUSTOM, шейдер `building.gdshader`, трубы), дым (пул эмиттеров дыма костра), `OsmLayer.update_wind` +
вызов из `WorldObjects`; конфиги `world_objects.json → buildings.style/chimney/smoke`, `osm_wind`,
`osm_tiles.json → height_rule.metro`. Приёмка: `test_osm_look_contracts` зелёный, тесты `world_objects`,
`osm_tiles`; время слоя домов Алматы 3×3 ≤ +15 %; кадры (город сверху, центр с высотками, частный сектор с дымом,
промзона). Оценка — большая.

### OL-2 Модели ЛЭП, мачт, телебашни, трубы
`dp-engineer`. L5. `tools/blender/build_osm_objects.py` → `assets/models/osm/*.glb`, `OsmPilot._power/_verticals`
на моделях (MultiMesh), `verticals.skip`, `ASSETS.md`. Приёмка: `test_osm_look_models_l5`, `world_objects`,
кадры каждой модели. Оценка — средняя.

### OL-3 Ветряки и кабинки канатки
`dp-engineer`. L6 (+ L4 как потребитель). `tools/blender/build_osm_wind_cable.py`, `osm_wind_turbines.gd`,
`osm_cable_cars.gd`, части в `OsmLayer`, `ASSETS.md`. Приёмка: `test_osm_look_models_l6`, `world_objects`,
кадры (ветряк, кабинки Шымбулака). Оценка — средняя. Ветер в игре — после слияния OL-1.

### OL-4 Тестовая сборка, кадры Алматы, замер кадра до/после
`dp-mechanic` (Sonnet). После OL-1..OL-3. Сборка Linux в `build/osm_test` (как OT-12), кадры Алматы (город,
частный сектор, ЛЭП, Шымбулак с канаткой, ветряки — где есть), `frame_profile` main против `feature/osm-look`.
Это шлюз: отчёт главной сессии.

## Волны
1. OL-1, OL-2, OL-3 параллельно (разные файлы; общие — `osm_layer.gd` (OL-1 провод, OL-3 части), `world_objects.json`
   (разные разделы), `ASSETS.md` (OL-2/OL-3 — свои подразделы)). Порядок слияния: OL-1 → OL-2 → OL-3.
2. OL-4.

## Риски
- Шейдер домов на 280 тыс. экземпляров: INSTANCE_CUSTOM и ветвления в фрагментном — замер кадра обязателен.
- Поправка этажности: соседи 3×3 тайла по краю видят меньше застройки (масштаб города занижен у края) — граница модели.
- Ветер на ветряках/дыме: вызовы `air_velocity_at` — бюджет L4 (≤ 64 за 0,5 с).
