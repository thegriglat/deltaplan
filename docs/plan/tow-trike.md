# tow-trike — буксировщик-дельталёт (код задач TT)

## 1. Цель
Аэробуксировку тянет дельталёт, а не Ан-2: тележка `trike.glb` + крыло по паспорту (iXess 15), летит по физике
«Маятника» (тележка — точечная масса на подвеске, тяга винта по данным двигателя и винта), управляет автопилот
(разбег, отрыв, набор, круг, уход). Винт крутится от газа, пилот сидит. Ан-2 остаётся только пасхалкой.

## 2. Решения пользователя (не обсуждаются)
- 2026-10-22: буксировщик — дельталёт вместо Ан-2. (1) Тележка `trike.glb` (модуль trike-model) + крыло по числам
  `tools/research/trike-model/wings.json` (основа — самый полный набор, iXess 15; чего нет — оценка с обоснованием) тем же
  путём, что крылья игры (`build_gliders.py` / `glider_params.json`). (2) Физика «Маятник», на подвеске вместо пилота —
  тележка (масса, ЦТ под подвеской), тяга винта по данным (двигатель, винт, обороты). (3) Автопилот: разбег, отрыв,
  набор, круг, скорость буксировки 55–65 км/ч; после отцепа уходит. (4) Винт — `prop_spin`, `speed_scale` от газа;
  пилот в позе `sit`. (5) Ан-2 из буксировки убрать, `EggAn2` — пасхалка. (6) Параметры из источников, допущения — в
  документации; шлюз, если буксировщик с дельтапланом на тросе не держит скорость/набор по числам BHPA.
  Почему: Ан-2 так медленно не летает; дельталёт — штатный буксировщик дельтапланов.

## 3. Решения координатора
- Крыло буксировщика — `configs/wings/trike_ixess15.json` в группе `tug` с `player: false` (не видно игроку и ботам) —
  чтобы пройти весь путь крыльев игры и их тесты (TT-К2).
- Двигатель и винт — тележки `trike.glb` (Rotax 582, редуктор C 3,47, винт 1,8 м, 2 лопасти; TK-К1); крыло — iXess 15.
  Расхождение с аппаратом iXess (912ULS) — в документе TT-1 с оценкой, как это меняет набор.
- Тяга и трос на буксировщик — явные силы через `set_external_force` (TW-К4); дельтаплан на тросе — неявное звено, как
  было (TW-К5): якорь — `tug.pos/vel`. Сила троса на буксировщик берётся с прошлого шага (масса буксировщика ≈ 3× массы
  дельтаплана с пилотом, натяжение 20–35 даН — допущение в документации).
- Колёса — 1 степень свободы вдоль курса (как тележка TW-К10), отрыв по `N ≤ 0`; руления, тормоза и посадки на колёса
  нет — буксировщик после отцепа уходит и исчезает.
- Связка проверяется тестом `tests/game/test_tow_trike_climb.gd` (TT-К4); пороги — BHPA §2.7.5 B (2,54 м/с) и решение
  пользователя (55–65 км/ч), полоса — `runway_length_m`.
