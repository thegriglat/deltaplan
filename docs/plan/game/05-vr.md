# 05. VR

Идея пользователя (05.10.2026): режим VR. Управление — один джойстик (ручка трапеции), голова вертится шлемом. Статус: записать в планы, не в работу.

## Оценка (главная сессия, 05.10.2026)
**Что облегчает**
- OpenXR встроен в Godot 4 (SteamVR, Quest через Link, WMR); Forward+ умеет рисовать картинку для двух глаз.
- Голова = XRCamera3D вместо `CameraRig`; ручка — джойстик/контроллер; трекинг рук не нужен.
- Приборы уже 3D (штанга, стойка) — работают сами.
- Укачивание при полёте умеренное: движение плавное, горизонт широкий.

**Что потребует работы**
1. **Производительность — главный риск.** 2 глаза × ~2K × 90 кадров/с ≈ в 3–4 раза тяжелее монитора. Объёмные облака, дымка, трава, GPU-расчёты на RX 5600 XT не потянут → пресет «VR» (облака проще, дальность, масштаб рендера, FSR).
2. **Экранные эффекты**: 3 шейдера читают экран/глубину, 2 `CompositorEffect` — научить рисовать для двух глаз (multiview).
3. **Интерфейс**: 17 экранов/панелей 2D в шлеме не видны → панели в 3D (SubViewport на плоскости) + указатель-луч. Упрощение: меню на мониторе, шлем — только в полёте.
4. **Разбег и посадка**: тело движется, голова сидит → проверить укачивание, ослабить покачивание камеры.

**Объём**: минимальный VR (полёт + приборы, меню на мониторе) — 1 координатор, 4–6 задач; меню в шлеме — ещё 3–4.

## Первый шаг (когда возьмёмся)
Дешёвый замер: включить OpenXR, камеру в шлем, замерить кадры текущей графики (без шлема — только запуск и нагрузка; ощущения — нужен шлем у кого-то из пилотов).
