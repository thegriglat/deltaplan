# haze-humidity — влажность места, дымка и свет облаков (код задач HH)

Что сейчас (2026-10-21, `main` e376388b):
- **Точка росы** — одна таблица по месяцам для всех мест, подогнана под Алтай (`configs/weather_model.json → dew_point_c`,
  `scripts/atmosphere/weather_model.gd:85`), плюс `td_follow_heat` и `td ≤ t`. Альпы, Крым, любая точка карты получают
  алтайскую влажность. От Td зависит кромка: `z_lcl = h_v + lcl_m_per_k·(T − Td)` (`weather_model.gd:93`).
- **Дымка** — густота `haze_k` = ход дня (после пика прогрева к закату линейно до ×1,6, `evening_haze_k`) × облачность
  (`overcast` ×1,3); видимость мутного слоя 60 км постоянна (`configs/world.json → haze`), верх — у кромки.
  От влажности не зависит.
- **Цвет солнца** — ручная таблица по высоте солнца (`configs/world.json → time.light`, узлы 2/8/18/35°), один на всю
  сцену; ниже 2° не меняется (`min_light_elevation_deg`). Облака берут его целиком (`cloud_layer.gd:_update_light`);
  низ облаков — постоянный `ambient_bottom` × `base_darkness` (`cloud_common.gdshaderinc:cloud_light`). Розового низа на
  закате и «облака ещё в солнце, земля уже в тени» нет. Рэлей есть только в дымке (фаза `1 + cos²θ` ×0,5, `haze.gdshader`).
- Влажность рельефа `TerrainRelief.moisture` — геометрия стока, статична и почти одинакова по местам (медиана 0,47) —
  для дымки не годится (обсуждение 2026-10-21).

## Задачи

### Волна 1 — исследования (параллельно)
1. **Климат точки росы** (researcher). Источник: ERA5 (2m dewpoint, месячные средние) против NASA POWER (T2MDEW
   климатология) — покрытие, лицензия на распространение в игре (атрибуция), разрешение. Разброс по дням: σ суточной Td
   вокруг месячной средней по ячейке и месяцу (из того же источника). Поправка на высоту: средняя высота ячейки против
   высоты долины места (градиент Td по высоте — из литературы/данных, не выдумывать). Сверка: Алтай (Синюха) против
   нынешней таблицы `dew_point_c`, 3–4 места игры, сухое и влажное место. Скрипт запекания, файл сетки (формат — п. 5),
   размер (ориентир ≤ 1 МБ), команда воспроизведения — в `tools/research/haze_humidity/`.
2. **Дымка от влажности** (researcher). Гигроскопический рост аэрозоля: ослабление ∝ (1 − RH)^−γ (Хенель и др.), γ для
   континентального аэрозоля — из литературы с источником. Предложение: `haze_k(RH)` вместо или вместе с ходом дня
   (`evening_haze_k`) и `overcast` — что из них остаётся физикой, что дублирует. Таблица видимости по часам 6–21 для
   сухого и влажного места при нынешней и предлагаемой модели.
3. **Проверка основания облаков** (researcher). Плотность, `base_darkness`, `ambient_bottom`, затенение небом по толщине
   (`sky_occlusion_m`), основание Cb: яркость основания относительно неба и вершины против наблюдений/литературы
   (оптическая толща кучевых, альбедо снизу). Числами по кадрам из `tools/shots/` (без замка GPU). Итог: корректно / что
   не так с числами. Правку — не делать, только по шлюзу.
