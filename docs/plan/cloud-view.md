# cloud-view — вид у облаков и над ними (код задач CVW)

## 1. Цель
Два дефекта вида, замеченные пользователем в полёте:
1. Выше некоторой высоты весь экран белёсый, хотя подъём шёл в ясном участке (не в облаке).
2. На границе облака (вход/выход, у кромки) другие облака по цвету будто инвертируются.

Найти причину каждого (воспроизвести, указать код и механизм), исправить. Физика света и дымки прежде «нравится»:
белёсость, которая следует из модели (дымка, рассеяние над слоем), — показать доказательство, не прятать.

## 2. Решения пользователя
- 2026-11-05: подпроект `world` (как cloud-field, cloud-base, cloud-look).
- 2026-11-05: только одиночная игра.
- 2026-11-05: не больше 10 одновременных агентов на координатора.

## 3. Что известно
- «Белая мгла» в облаке: `scripts/game/cloud_whiteout.gd` (`CloudWhiteout.amount` по плотности облака у камеры,
  сгущает туман Environment), `configs/game.json → cloud_whiteout` — кандидат на п. 1 (срабатывает вне облака?).
- Облака: `scripts/atmosphere/cloud_layer.gd`, `cloud_common.gdshaderinc`, `cloud_raymarch_cs.gdshaderinc`,
  `cloud_temporal_cs.gdshaderinc`, `cloud_compositor_effect.gd`; дымка — haze (модуль haze-humidity).
- Похожие известные дефекты: T-91 (белые точки в облаках на закате, луч с alpha ≈ 0), T-31 (обрыв слоя ровной линией).
- cloud-look отменён (2026-10-24); его ветки `cloud-look/CLK-2/6/7` не трогать.
- Визуал проверяется тестовой сборкой Linux (собирает главная сессия); кадры для пользователя —
  /home/greg/deltaplan/build/screenshots/cloud-view/.

## 4. Задачи
Карточки заводит координатор. Ориентир:
- воспроизведение обоих дефектов кадрами (место, время, высота, погода с облаками; подъём в ясном участке,
  проход у кромки облака) и замер величин (amount мглы, параметры тумана/дымки, выход луча облаков);
- разбор причины по каждому; правка; тест или кадр до/после;
- CHANGELOG.

## 5. Волны
Определяет координатор.

## 6. Условия остановки (шлюз)
- Причина — в модели света/дымки (белёсость физична) — шлюз с доказательством и вариантами.
- Правка заметно меняет вид облаков вне этих случаев или цену кадра — шлюз.
