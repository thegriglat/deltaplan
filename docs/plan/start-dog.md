# start-dog — собака на старте (код задач DOG)

## Проблема
Сцена, знакомая каждому пилоту: собака бежит за взлетающим дельтапланом и лает. Лагерь у старта (модуль
start-camp) живой — люди, палатки, вещи, — а собаки нет.

## Решения пользователя (2026-10-17, не обсуждаются)
- Собака «живёт» у стартового лагеря на части стартов: часто, не каждый раз, детерминированно по месту и дню;
  лежит, бродит у лагеря и вещей, нюхает. Мир не вокруг пилота.
- Пилот начинает разбег → собака срывается, догоняет, бежит рядом и лает; крыло оторвалось → останавливается у
  бровки (с обрыва не прыгает), лает вслед, трусит обратно. Пилот долго стоит — собака занята своим.
- Модель — **только готовая CC0** (или иная лицензия с коммерческим использованием), даже низкополигональная и
  стилизованная — «будет забавно». Своих моделей (генерация, «палки → мясо») не делать: подходящей нет — шлюз.
  Недостающие клипы (лай, лежит, сидит) — ключами в Blender на скелете готовой модели.
- Анимации: галоп (разбег 5–8 м/с), трусца, стоит-лает, лежит/сидит, нюхает (по возможности). Лапы не скользят,
  по рельефу, не сквозь палатки/вещи/камни по возможности.
- Лай: CC0 (Freesound с проверкой лицензии) или сгенерировать; 3D-звук, из кабины на разбеге слышно.
- Модель лёгкая: треугольники/LOD, текстура по экранному размеру, сжатие + мипмапы. Цену GPU не мерить.
- Пасхалку не упоминать на сайте, в devlog, на страницах версий и в `CHANGELOG.md`.
- Исполнители: Opus — модель/анимации/поведение, Sonnet — простое. Визуальные мелочи — не больше 2 заходов.
  Тестовые сборки не делать. Кадры для пользователя — `/home/greg/deltaplan/build/screenshots/start-dog/<задача>/`.

## Решения координатора (2026-10-17)
- Встраивание — каркас пасхалок (К1–К7), id `start_dog`, `per_flight`, постоянная; доля мест-дней — свой бросок в
  `can_appear` по месту старта лагеря и дате (DOG-K4), а не `chance` (тот зависит от ключа мира с погодой).
- Погоня — за любым бегущим со старта лагеря (игрок и боты, DOG-K1): мир не вокруг игрока.
- Бровка — пробой рельефа вперёд (уклон/провал) + жёсткий предел вдоль курса старта.
- Характер — как у «бешеного уазика»: заметно и весело (громкий лай, азартный галоп), без подсказок и текстов.

## Задачи

#### DOG-1. Готовая модель собаки, клипы, лай, кадры в игре
Тип `dp-researcher`, opus. Контракты DOG-K2, DOG-K3. Найти готовую модель собаки с анимациями под коммерческое
использование (сначала Quaternius «Ultimate Animated Animal Pack» / «Animated Animals» — проверить фактический
состав и лицензию; затем Poly Pizza, Kenney, OpenGameArt, Sketchfab CC0/CC-BY); выбрать одну, перевести в
`dog.glb` по DOG-K2 (имена клипов, −Z вперёд, бюджет, импорт со сжатием и мипмапами), дописать недостающие клипы
ключами в Blender на её скелете, измерить `speed_ms`/`cycle_s`. Лай — 2–4 гавка CC0. `ASSETS.md`. Минимальный
`start_dog.gd` + блок конфига (стоит у лагеря и проигрывает клипы по очереди — для кадров), кадры каждого клипа в
игре на старте → `/home/greg/deltaplan/build/screenshots/start-dog/DOG-1/`. Подходящей модели нет — `blocked`,
таблица кандидатов с причинами.
→ **Шлюз Q1** главной: кадры модели и клипов до поведения.

#### DOG-2. Поведение собаки
Тип `dp-engineer`, opus. После Q1. Контракты DOG-K1, DOG-K4 (+ DOG-K2/K3 как потребитель). Поля контекста
(`runners`, `camp_start`, `obstacles_near`), полный `start_dog.gd` (состояния, аллюры без скольжения, рельеф,
обход, бровка, звук), конфиг, тест `tests/world_objects/test_start_dog.gd` (синтетический рельеф с бровкой и
сценарный бегущий). Раздел о собаке в `docs/guide/world-objects/easter-eggs.md` (внутренний документ).

#### DOG-3. Кадры разбега с собакой
Тип `dp-engineer`, sonnet. После DOG-2. Скрипт кадров `tools/shots/start_dog_*` (ничего в игре не меняет):
последовательность кадров разбега с автопилотом — из кабины и сбоку (≈ 6–10 кадров: собака лежит → срывается →
бежит рядом → крыло оторвалось → лает у бровки → трусит назад) → `/home/greg/deltaplan/build/screenshots/start-dog/DOG-3/`.
Визуальная доработка по кадрам — не больше 2 заходов (через DOG-2a при необходимости).
→ **Шлюз Q2** главной: финальные кадры, ветка `feature/start-dog` готова к слиянию.

## Условия остановки (шлюз)
- Нет готовой модели с подходящей лицензией и хотя бы галопом/бегом — отчёт главной (своих моделей не делать).
- Тест К7 (физика побитно) краснеет из-за собаки и не чинится в пределах пасхалки.
- Кадры после 2 заходов всё ещё плохи (скольжение, сквозь камни, прыжок с обрыва) — показать как есть.
