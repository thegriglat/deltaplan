# План sw-charges-3d (код задач SWD)

## Цель
Продолжение модуля sw-charges в 3D (отдельный модуль — по решению пользователя, чтобы не рос контекст координатора).
Проверить «электрическую» аналогию поля ветра над рельефом в 3D: фон + заряды на поверхности рельефа (панели) +
вихревые нити с гребней, по возможности — термики и болтанка вихревыми частицами/диполями (прототипы A/C sw-charges).
Цель модуля — **единая аналогия трёх масштабов**; порог успеха — паритет с Пикаром в его ±10–15 %, обгон не обязателен.

## Решения пользователя
См. `.dpcli/dpcli inbox sw-charges-3d`; предыстория и решения 2D — `docs/plan/sw-charges.md` (раздел «Решения пользователя»,
«Идеи на будущее») и журнал `docs/plan/sw-charges/decisions.jsonl` (база влита из `feature/sw-charges`).
- **3D sw-charges — отдельным модулем с новым координатором (чтобы не рос контекст); делать в любом случае, 2D — подготовка (список проблем «схема / 2D-артефакт»), не эталон; порог успеха — паритет с Пикаром ±10–15 %; прототипы на Python/CuPy.** (2026-11-08)
- **Параллельно с 3D-прототипами: в Rust (dp-air) вынести расчёт среднего поля ветра за общий интерфейс, чтобы Godot переключал тип расчёта ключом/настройкой, не зная деталей. Сейчас одна реализация — Пикар (поведение побитно прежнее); интерфейс проектировать так, чтобы туда встала будущая схема «панели + вихри» (поле без сетки: запрос в точке и/или выдача на сетки окон). Сама схема панелей в Rust — позже, отдельным решением.** (2026-11-08) — чтобы игра могла переключать тип расчёта ветра
- **Отмена задачи 5 (общий интерфейс поля в Rust): 3D-прототипы на Python, интерфейс в игре не нужен до решения о переносе.** (2026-11-08) — 3D тоже на Python
- **Добавить вариант без эволюции во времени: установившийся вихревой слой (лист тока) вдоль линии отрыва и границы зоны рециркуляции, сила — из критерия отрыва; цена порядка панелей. Нестационарные нити, если остаются дорогими (O(n²), рост узлов), для игры не годятся — не вкладываться в их доводку сверх уже начатого по Q1; ограничитель роста (B) — только если дёшев.** (2026-11-08) — если нити дорогие, они потом всё равно не подойдут
- **Первым проверить простейший вариант установившегося вихревого слоя: одна прямая нить вдоль подветренного склона (ось ротора вдоль хребта), концы уходят в землю подковой (∇·ω=0), отражение в земле — панелями; положение и сила — из условия равновесия вихря (аналог вихрей Фёппля за цилиндром) с точкой отрыва на гребне, без подгонки. Без эволюции во времени; болтанка — масштаб 3, не здесь. Сравнить ротор с Menke 2019 и Askervein.** (2026-11-08) — дёшево (десятки отрезков), стационарно; нити с эволюцией дороги
- **Критерии оценки вариантов (панели, нити, вихревой слой, нить ротора) — не только совпадение потока с измерениями/Пикаром: равный вес у скорости расчёта (панели быстрее Пикара — довод за) и стройности модели (одна аналогия зарядов/токов на все масштабы). В итоге — таблица варианта по трём осям: поток, время, стройность.** (2026-11-08) — поток — один из аргументов
- **Уточнение к критериям оценки: первая ось — ротор (есть/нет, длина против Menke 2019), а не поток вообще. Ротор — один из аргументов наравне со скоростью расчёта и стройностью модели; отсутствие ротора не обнуляет вариант, если он быстр и укладывается в аналогию.** (2026-11-08) — пользователь: «не поток, а ротор я имел в виду»
- **Вариант B (нить ротора) — геометрическое замыкание вместо равновесия Фёппля: ось нити вдоль хребта над подветренным склоном, по нормали к склону от середины между гребнем и точкой присоединения; неизвестные R (высота по нормали) и Γ — из двух условий: точка остановки потока у поверхности на гребне (отрыв) и в точке присоединения (подножие склона или середина долины до следующего гребня — что ближе; правило одно на все места). Нить ставить только выше порога (подветренный уклон или критерий отрыва Хеда), контроль — нет ложного ротора на C4-подобных буграх. Концы — в землю подковой, отражение — панели. Без подгонки по месту. Сравнить с вихревым слоем (A), Menke 2019 и Askervein; оценка по трём осям (ротор, время, стройность).** (2026-11-08) — вихрь в потенциальном потоке не держится сам (Фёппль); держат вязкость и турбулентность, которых в панелях нет — положение задаётся правилом геометрии; ветер в склон не входит, линия тока вокруг нити замкнута
- **Отменить SWD-5c (урезанный счёт Perdigão нестационарными нитями без ограничителя): нестационарные нити для игры отвергнуты (дороги), ротор ищем стационарно (SWD-10 слой, SWD-11 геометрическая нить); эталон ротора — Menke 2019 и Пикар. В итог — уже имеющееся: 120 с без ротора, рост узлов O(n²). Ограничитель роста (B из Q1) тоже не делать. Освободившийся GPU — задаче 4 (термики/болтанка 3D).** (2026-11-08) — счёт ~3,5 ч GPU на tau ради схемы, которая не пойдёт в игру
- **Q3 — третий вариант (C') параллельно с A и B: ротор как цепочка «лежачих смерчей» — звенья нити вдоль хребта, каждое = вихрь (ток, Γ) + линейный сток (заряд, Q), т. е. комплексная сила (Q − iΓ)·log z; течение спиральное. Притяжение к склону — от отражения стока в земле (в жидкости одноимённые притягиваются, Бьеркнес) — это и есть «подсасывание» пониженного давления, которого нет у чистого вихря. Баланс масс: воздух из стока уходит вдоль оси звена к концам/стыкам (в землю/долину) и/или источник в точке присоединения — без утечки массы. Неизвестные Γ, Q, положение — из равновесия вдоль и по нормали к склону; Q — из литературы о вовлечении слоем сдвига (доли U), Γ — из потока завихренности со склона = градиент давления вдоль склона на панелях за гребнем (Lighthill/Morton), а не из отдельного критерия отрыва. Без подгонки по месту. Литература: суброторы (Doyle & Durran 2007, T-REX) — ротор распадается на короткие вихри; субвихри — связь с болтанкой (масштаб 3). Оценка по трём осям (ротор, время, стройность).** (2026-11-08) — в реальности ротор держит пониженное давление (подсос к склону); ротор — положенный набор смерчей; модель стройнее — ротор из тех же зарядов
- **Дополнение к варианту «лежачих смерчей» (Q3, C'): (1) концы ротора прибиты к рельефу (Гельмгольц: вихревая линия не обрывается в воздухе) — длина ротора = участок хребта с подветренным уклоном выше порога, концы — где он кончается (седловина, конец хребта, распадок); геометрия, без подгонки. (2) Устойчивость — по отношению закрутки к осевому оттоку (число закрутки, Γ/Q — фаза комплексной силы): осевой отток (сток) растягивает и держит вихрь (аналог вихря Бюргерса) — ротор стационарен; закрутка выше порога распада вихря (vortex breakdown, порог из литературы) — ротор рвётся, среднего ротора нет, есть срыв вихрей (масштаб 3, болтанка); около порога — «дышит». Чистая нить (Q = 0) — предельный случай распада, согласуется с неудачами SWD-9/11. (3) Выход для игры — состояние: ротор есть / нет / дышит; проверка по присутствию, не по числам.** (2026-11-08) — ротор — смерч с двумя концами, прибитыми к рельефу: либо держится и стабилен, либо рвётся и ротора по сути нет
- **Вариант «лежачих смерчей» (C': звенья «сток + вихрь», концы на рельефе, устойчивость по Γ/Q и распаду вихря) — основной для роторов: приоритет ему (люди/GPU), A и B — вспомогательные/сравнение, не расширять. Проверить: ротор Perdigão есть во всём разумном диапазоне Q из литературы (разброс 2–3×); применимость порога распада к лежачему вихрю у склона — проверить, не брать на веру. Стратификация/инверсия — задел на потом, сейчас нейтральный случай.** (2026-11-08) — идея перспективная, интуитивно понятная, критерии распада чёткие
- **Смысл варианта «лежачих смерчей» в электрической аналогии (описывать результат в этих терминах): ротор — один объект, заряженный провод вдоль хребта, по которому текут его же заряды (осевой отток воздуха из стока к концам) — движущиеся заряды = ток = вихрь ротора (магнетизм как движущееся электричество). Ориентация: ток вдоль хребта (заряды вдоль оси, не по кругу в разрезе — виток дал бы течение вдоль оси). Склон — зеркало: провод + отражение с обратным током держат ротор вдоль склона, притяжение заряда к своему отражению прижимает к склону. Γ/Q — «скорость носителей»: 0 — чистый сток, ротора нет; растёт — ротор крутится; выше порога — распад вихря. Гипотеза (не проверено): порог распада как предельная скорость носителей — возможная связь с черенковскими подветренными волнами из «Идей на будущее» sw-charges. Единый язык: рельеф — заряды на поверхности, ротор — движущиеся заряды, болтанка — пары вихрей.** (2026-11-08) — держать ротор в поле общей модели

## Задачи (уточняет координатор)
1. **Панели 3D** (Python/CuPy): рельеф по растру места (GLO-30, 25 м; кроны/крыши DSM — сгладить или убрать, лес —
   шероховатость), панели 25–30 м у точек сравнения и крупнее вдали; плотность источников, скорость в точке; внутренний слой
   у земли (Jackson–Hunt, итог последнего круга 2D); время и память (плотная матрица 10–20 тыс. панелей / блоки).
2. **Вихревые нити 3D**: сход с гребня по физическому критерию отрыва (итог 2D), только подветренная сторона; линии
   **замкнуты** — уходят в землю по бокам хребта или петлёй (∇·ω = 0, «нет монополей»); растяжение, перезамыкание, затухание.
3. **Сравнение**: Askervein (мачты, `tools/research/data/askervein/`), Perdigão (мачты ISFS, лидары DTU, Menke 2019 —
   `tools/research/data/perdigao/`, постановка `tools/research/cases/`), Пикар ±10–15 % (крейт / `rust/dp-stand`); Bolund
   не использовать. Колонка «эксперимент» с надёжностью.
4. **Прототипы A/C в 3D** (термики-кольца, пары вихрей болтанки) над рельефом — если дёшево; уточнения из «Идей на будущее»
   sw-charges (порог рождения по Ri, экранировка).

Приёмка: тесты rust_wind/W8 зелёные, переключение `picard`/`off` проверено тестом, без Godot-стендов для замеров.

## Ожидаемые новые для 3D проблемы

и вихрей (возможны мультиполи/БПФ).
