# План модуля «ui-controls» — раскладка тангажа «как у дельтапланериста»

Внутренний документ. Журнал — `docs/plan/ui-controls_progress.md`, контракты — `docs/ui-controls_contracts.md`. Ветка `feature/ui-controls`, копия `~/deltaplan-ui-controls` (от `main` 938d1ea).

## Цель
По умолчанию в полёте вперёд/вверх = трапеция **от себя** (нос вверх, торможение): W, ↑, мышь от себя (в режиме `bar`), стик вперёд. Назад/вниз = **на себя** (нос вниз, разгон). Это раскладка дельтапланериста, не самолёта.

## Решения пользователя (не обсуждаются)
- 01.10 — по умолчанию в полёте **W = трапеция от себя**, **S = на себя**; то же для ↑/↓ и для стика/мыши по умолчанию («вперёд/вверх = от себя», мышь вперёд = от себя), без инверсии «как в самолёте» по умолчанию. Настройка инверсии остаётся, но по умолчанию — дельтапланерная.

## Что было на v1.0.0 (938d1ea)
- `configs/controls.json → keys`: `pitch_pull_in` = [W, Up] (на себя), `pitch_push_out` = [S, Down] (от себя). `InputController._update_air`: `pitch_dir = −(pull_in − push_out)·inv` → W даёт `ControlInput.pitch` −1.
- Мышь (`bar`): `pitch = −offset.y` — мышь от себя (курсор вверх) = от себя. **Уже дельтапланерно.**
- Стик (`_apply_gamepad`): `pitch = gy·inv`, ось 1 вперёд < 0 → стик вперёд = на себя. **Как в самолёте — менять.**
- На земле: W/S — шаг (`walk_forward`/`walk_back`), ↑/↓ — нос вверх/вниз (`nose_up`/`nose_down`). Не меняется.
- `configs/ui.json → controls_help`: раздел «На земле» показывает клавиши шага через действия `pitch_pull_in`/`pitch_push_out` — после перестановки показал бы S/↓ для «идти». Привязать к `walk_forward`/`walk_back`.
- Подсказка инверсии `settings_invert_pitch_hint` («W — от себя, S — на себя») описывала инверсию; теперь инверсия = «как в самолёте».

# Этап 2 — камера с клавиш при тангаже мышью

## Запрос пользователя (02.10, дословно)
«если управление тангажем через мышь то WASD должны от 1го лица двигать камеру».

## Разбор кода (ветка модуля от main ce5ea58)
- Мышь в режиме `bar` (`controls.json → mouse.mode`, **по умолчанию**; пункт настроек «Мышь: Обзор / Трапеция») ведёт трапецию по **обеим осям** (тангаж и крен), пока мышь захвачена (`InputController.mouse_captured`, клавиша M; захват при старте — `mouse.capture_on_start`). Клавиши при этом суммируются с мышью (`_update_bar`: `_key_pitch + m_pitch`) — WASD и стрелки дублируют мышь.
- Обзор головой в кабине — `CameraRig._head` (рыскание/тангаж, пределы `camera.json → cockpit.head`: ±120°, вверх 60°, вниз 70°); в `bar` — только с зажатой правой кнопкой; отпустил — голова остаётся; V/средняя — плавно вперёд (`recenter_time_s` 0,25 с); Q — держать взгляд на прибор. Смещения точки глаз с клавиш в коде нет (точка глаз = маркер PilotHead + доля смещения тела).
- Камера сзади (`chase`) — без обзора/орбиты. Свободная (`free`) — WASD/E/Q двигают её, крыло без рук (`hands_off`), при автопилоте клавиши ей не отдаются.
- Земля (С2 v2 control-fix, CF-3): стоя/шагом W/S — шаг, A/D — поворот; Shift (разбег) — WASD, стрелки, мышь — нос и крен крыла «как в полёте».
- Автопилот жмёт действия по имени (`Input.action_press`, без физических клавиш) — исключение физических клавиш (как `_bar_strength(only_bar)` на земле) его не задевает.
- Контрактный тест У1 водит клавиши в режиме мыши `look` — остаётся верным.

## Развилки (шлюз 02.10, до кода)
1. Разбег (Shift) в режиме «мышь — трапеция»: WASD — обзор (как в полёте, скачка трапеции на отрыве нет) или как сейчас — трапеция (тогда на отрыве при зажатой W вклад клавиш стечёт к триму за ~0,75–1 с).
2. Камера сзади в этом режиме: WASD ничего не делают (трапеция — мышь и стрелки) или по-прежнему трапеция.
3. Мелочи с дефолтом (решаю сам, если не скажут иначе): правило действует, только пока мышь захвачена (M отпустил мышь — WASD снова трапеция); голова с клавиш — со скоростью `cockpit.head.key_rate_deg_s` = 90°/с в тех же пределах, отпустил — остаётся (как обзор мышью), V/средняя — вперёд; стрелки — трапеция всегда; X, Q, свободная камера, режим мыши `look`, геймпад, автопилот — без изменений.
