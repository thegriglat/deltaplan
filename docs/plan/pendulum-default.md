# «Маятник» по умолчанию (модуль `pendulum-default`, код задач PMD)

## 1. Цель
Режим управления «Маятник» (`controls.roll_control_mode = "pendulum"`, модель `PendulumModel`) становится основным способом управления в игре; сайт и документация приводятся в соответствие.

## 2. Решения пользователя (не обсуждаются)
- «Маятник» — умолчание везде: конфиг и запасные значения в коде (15.10).
- Пометку «экспериментальный» убрать в UI, переводах, CHANGELOG, гайде, на сайте (15.10).
- «Маятник» первым в списке режимов; «Смещение веса» и «Как раньше» (простое) остаются выбираемыми, не удаляются (15.10).
- Подпись вкладки «Аппарат» — настройки основного режима; если другие режимы их не используют — так и сказать коротко (15.10).
- Тесты, зависящие от умолчания, править по смыслу, не подгонкой (15.10).
- Файлы физики маятника (`scripts/flight/pendulum*`, `configs/pendulum.json`) не трогать: их меняет параллельный модуль `pendulum-body-vg`; текст сайта — по текущему `main`; сверка чисел «Границ модели» на сайте — отдельной задачей после слияния `pendulum-body-vg` (15.10).

## 3. Задачи
### PMD-1 Умолчание, список, подписи, тесты
Исполнитель: `dp-engineer` (sonnet). Контракт PMD-К1.
- `configs/controls.json` → `roll_control_mode: "pendulum"` (и `_doc` к нему); запасные значения: `scripts/flight/glider.gd` (≈ стр. 77) и `scripts/game/input_controller.gd` (≈ стр. 58) и все прочие места, где читается `roll_control_mode` с запасным значением, → `"pendulum"`.
- `scripts/ui/settings_panel.gd`: `ROLL_MODES` → `["pendulum", "weight_shift", "rate"]` (индекс пункта ↔ значение через массив, не через числа).
- `locale/ui.csv`: `settings_roll_pendulum` без «(экспериментальный)»/«(experimental)»; `setup_app_pendulum_only` — новая подпись (PMD-К1).
- Тесты, где умолчание режима подразумевалось `weight_shift`/`rate`: задать режим явно там, где тест проверяет старый режим; где тест про умолчание — ждать `pendulum`.
- Контрактный тест `tests/contracts/test_pendulum_default_contracts.gd`.
Приёмка: тесты `pendulum`, `tests/game/`, `tests/net/`, `tests/ui/`, `roll`, `pendulum_default` — без новых падений.

### PMD-2 Где код молча предполагает FlightModel
Исполнитель: `dp-engineer` (sonnet). Параллельно с PMD-1, в своей копии; режим в тестах задаёт явно (`pendulum`).
Проверить с «Маятником»: боты (у них по PD-К1 — `FlightModel`, это так и остаётся), сеть (поза и PD-К4–К5, `controlMode`/`pilotRel`), камера «из глаз», посадка (`landing_flare`, разбор посадки), разбег/старт (`ground_run`, `pilot_legs`), догон-буксир (`catch_up_tow`, `set_kinematic`), автопилот, телеметрия/приборы, статистика полёта, motion rig, задания (`scripts/tasks`), обучение/сценарии — если есть. Искать: обращения к членам `FlightModel`, которых нет в поверхности PD-К1; `model is FlightModel`/типизация; ветки `roll_control_mode == "weight_shift"`, где «иначе» молча значит FlightModel; чтение `weight_shift`-полей ввода.
Приёмка: список найденных мест в отчёте (файл, что предполагалось, что сделано); найденные ошибки починены с тестом на «Маятник»; тесты как у PMD-1 — без новых падений.

### PMD-3 Сайт
Исполнитель: `dp-writer` (sonnet). Источник фактов — `docs/guide/flight/pendulum.md`, код `main`, PMD-К1.
- `site/content/mechanics/flight.{ru,en}.md` — переписать: основной режим — «Маятник» (как считается, ввод, земля, срыв и штопор, ленточки, границы модели — честно, где врёт); старые режимы — коротким разделом.
- `site/content/mechanics/instruments.{ru,en}.md` — фраза про ленточку по новому умолчанию.
- Главная (`site/content/_index.{ru,en}.md`), «Подходы» (`site/content/approaches.{ru,en}.md`, раздел «Что в игре сейчас») — по факту; все «экспериментальный» про маятник (кроме страниц версий `site/content/releases/` — история не переписывается).
Правила: сайт — только текущее состояние, без планов; о родителях — только «родители автора — пилоты»; пасхалки не упоминать; без продающего тона.
Приёмка: `hugo` в `site/` без ошибок; на сайте (кроме `releases/`) нет «экспериментальн»/«experimental» рядом с маятником.

### PMD-4 Документация и CHANGELOG
Исполнитель: `dp-writer` (sonnet). После приёмки PMD-1 и PMD-2 (CHANGELOG — по их отчётам).
- `docs/guide/flight/pendulum.md` — что режим основной (вступление/статус); раздел «Границы модели» не трогать (его меняет `pendulum-body-vg`).
- `docs/guide/flight.md` — «Маятник» основной, старые режимы — запасные.
- `CHANGELOG.md` → «В работе»: функционально, по-русски.
Приёмка: `.dpcli/dpcli docs check` без ошибок.

## 4. Волны
1. PMD-1, PMD-2, PMD-3 — параллельно.
2. PMD-4 — после PMD-1 и PMD-2.
3. После слияния `pendulum-body-vg` — задача сверки чисел «Границ модели» на сайте (по просьбе главной).

## 5. Условия остановки
- Ошибка «Маятника» в боте/сети/посадке, которую не починить без правки файлов физики маятника, — шлюз.
- Тесты падают из-за самой физики маятника (не из-за умолчания) — шлюз, не подгонять.
