# 02. «Как летать», анкета после полёта, актуальный TODO

**Цель:** два текстовых файла в сборке для мамы-пилота и TODO/ARCHITECTURE, совпадающие с тем, что реально есть в игре.

**Контекст (прочитать):** docs/game.md («Управление», «Разбег», «Кабина»), docs/instruments.md («Экран — планшет»), docs/flight.md («Модель», посадка), questions.md (⏳-вопросы маме), REQUIREMENTS.md §2.4–2.6.
**Папки-владения:** `dist/` (новая: исходники txt), `tools/build.sh` (только копирование `dist/*.txt` в архив), `TODO.md`, `docs/ARCHITECTURE.md` (таблица модулей).
**Зависимости:** нет (можно сейчас). После окончания integration — сверить таблицу клавиш ещё раз (5 мин).
**Модель:** sonnet. **Размер:** S. **Закрывает:** NFR-5, NFR-4 (тексты на русском), подготовка показа.

## Шаги
1. `dist/Как летать.txt` (≤ 2 страниц, простым языком, без жаргона программиста, UTF-8 с BOM + CRLF для Блокнота Windows):
   запуск; меню «Лететь»/«Полёт…»; разбег (W+Shift, нос сам, ↑/↓); полёт (W/S трапеция, A/D крен, мышь — голова, Q — взгляд на прибор);
   страницы прибора 1–5 (что на каждой); камеры C; пауза Esc, R — заново; как узнать термик (писк варио, крыло кренит); посадка (выравнивание S у земли);
   где лежат `configs/` и что можно править; «если не запускается».
2. `dist/Вопросы после полёта.txt` — анкета 15–25 вопросов, ответы прямо в файле. Блоки: разбег и отрыв; крыло в воздухе (скорость, инерция крена, «тяжесть» на тяжёлом пилоте — вопрос flight.3); термики (сила, болтанка — atmosphere.5, края, +8 «валить»); облака и подсос; посадка во встречный ветер (questions «Посадка» 1); звук (вариометр, поток, парус — sounds.6); что видно из кабины; прибор читается?; места (старты Онгудай/Биягода/Аушкуль — необязательные); что больше всего не похоже на жизнь; что хочется в первую очередь. Шкалы «1–5» + свободный ответ.
3. `tools/build.sh`: копировать `dist/*.txt` в корень папки сборки перед zip.
4. `TODO.md`: отметить `[x]` сделанное по коду/докам (VR-4 общая карта, дымка-инверсия, ЛЭП, посадочные площадки, ветроуказатели, деревья, задания/тренировки/рекорды — логика без меню), снять «в работе» с законченного; добавить ссылку на docs/plan/README.md.
5. `docs/ARCHITECTURE.md`: добавить в таблицу модулей `scripts/world_objects/`, `scripts/tasks/`, `scripts/ui/`, `scripts/vegetation/`, `assets/shaders/sail/`.

## Критерий приёмки
- `tools/build.sh linux` → в `build/deltaplan-linux.zip` есть оба txt; `file` показывает UTF-8 with BOM, CRLF.
- Каждая клавиша в «Как летать» есть в `configs/controls.json` (проверить grep’ом по списку; расхождений 0).
- Анкета ≤ 25 вопросов, покрывает все ⏳ «папа/мама» из questions.md про ощущения (список соответствия в конце карточки-отчёта).
- `tools/lint.sh` не затронут; TODO.md не содержит `[ ]` для того, что сделано (ревью координатора).
