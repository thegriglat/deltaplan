# 06. Синхронизация TODO.md с кодом

**Цель:** TODO.md отражает реальное состояние: ничего «в работе»/не отмеченного, что уже сделано в коде, и наоборот.

**Контекст:** TODO.md, docs/plan/README.md (столбец «Сейчас в работе»), docs/ARCHITECTURE.md, REQUIREMENTS.md.
**Папки-владения:** TODO.md, docs/ARCHITECTURE.md (таблица модулей). Код не трогает — только сверяет и правит пометки.

## Шаги
1. Пройти TODO.md построчно; для каждой строки без `[x]` проверить в коде/тестах, не сделана ли она фактически (особенно пункты instruments.md «в работе» без агента — см. README группа 8).
2. Снять «— *в работе*» с пунктов, чьи агенты (integration, terrain2, atmosphere, vegetation, sounds) уже закончили — сверить с README «Сейчас в работе».
3. Отметить `[x]` реально готовое; для частично готового — уточнить формулировку (что осталось).
4. docs/ARCHITECTURE.md: добавить в таблицу модулей отсутствующие папки (`scripts/world_objects/`, `scripts/tasks/`, `scripts/ui/`, `scripts/vegetation/`, `assets/shaders/sail/` и др., если их там нет).

## Критерий приёмки
- Ревью координатора: 0 строк TODO.md вида «сделано в коде, но не отмечено `[x]`» (выборочная проверка 10 случайных строк).
- 0 пометок «в работе» на агентов, которые по README уже закончили.
- Таблица модулей docs/ARCHITECTURE.md содержит все папки верхнего уровня `scripts/*`.

**Зависимости:** делать последней в группе — после карточек 01–05 (даёт актуальную картину «что сделано»). **Модель:** sonnet. **Размер:** S.
