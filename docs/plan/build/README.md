# Группа 13. Сборка, проверка и выпуск (Linux)

Объём: только Linux, без CI, без Windows, без оптимизации под слабое железо (NFR-1 сейчас — 60 FPS на
дискретной видеокарте). Веха «показа маме» снята с плана — карточки 01/02 старых черновиков удалены/переписаны.

## Порядок

1. **01-sborka-linux-proverka** — `tools/check.sh` зелёный (линт, тесты, сборка Linux, smoke). Базовая проверка,
   с неё начинать.
2. **02-stabilnost-matrica** — матрица крылья × локации × погода, автопилот без ошибок в логе. После 01.
3. **03-zamery-fps-zagruzka** — FPS (NFR-1) и время загрузки (NFR-2) на пресете medium. Можно параллельно с 02.
4. **04-konfigi-doc-edinicy** — все числа в `configs/*.json` с `_doc` и единицами (NFR-7). Независима, вести сейчас.
5. **05-assets-md-sverka** — ASSETS.md соответствует файлам в `assets/` и `data/`. Независима, вести сейчас
   (лучше — после того как sounds закончит).
6. **06-todo-sync** — TODO.md и docs/ARCHITECTURE.md синхронизированы с кодом. Последняя — даёт актуальную
   картину после 01–05.

Карточки 04 и 05 можно делать параллельно с 01–03 в любой момент. 02 и 03 требуют, чтобы integration, terrain2,
atmosphere, vegetation, sounds закончили (иначе цифры/ошибки неактуальны).
