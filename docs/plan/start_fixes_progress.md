- 30.09 — координатор: задача «пилот на земле» разделена на SF-3 (рука пилота, крен, дуга, переход) и SF-4 (причина касания крылом), параллельно; стык в `ground_run.gd` — по разным функциям.
- 30.09 — решение пользователя: SF-4 передаётся исполнителю SF-3 (один исполнитель на связанные задачи); SF-4 коммитит находки в `start/sf4` и останавливается, SF-3 вливает `start/sf4` и сдаёт обе по общим условиям приёмки; копия sf4 — удалить после слияния. Вписано в план (решение 4).
- 30.09 — решение пользователя: пустырь = только убрать деревья; траву, кусты и прочее не убирать. Новая поляна — FOREST → GRASS, SHRUB не трогается; приёмка — нет деревьев в R, трава на месте, проверка координатором по скриншоту. Отправлено исполнителю SF-1. В плане — решение 5.
- 30.09 — координатор по находкам SF-4: (д) рельеф не трогаем, не шлюз, если на всех стартах локаций при крене 0 (стоит/шагом/разбег, трапеция нейтрально) зазор по видимой земле ≥ 0; иначе — шлюз. Тело пилота стоя вертикально — визуально в `GliderVisual._ground_pose`, К4 остаётся v1. `reset_on_ground` — начальный тангаж = установившийся стоя. Всё передано SF-3.
- 30.09 — `test_takeoff::test_headwind_launch` (atlas, nose_high) падает уже на базе 6f34786 (= main 113878d + документы) — не регрессия модуля; сообщить главной сессии.
- 30.09 — SF-3 промежуточно: порог бокового ветра стоя (sport, встречный 4, нос нейтрально) 1,90 м/с; при встречном 6 м/с — 0,6–1,0 м/с (нос на 10° ниже — ≈2 м/с): ноги разгружены, рука слабеет. Физика, не шлюз — находка для пользователя.
