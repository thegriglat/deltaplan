# sail-texture — своя текстура паруса (код задач SLT)

## 1. Цель
Просьба пилота: загрузить свою картинку и видеть её на парусе своего крыла. Игрок выбирает файл (PNG/JPG) в игре,
видит предпросмотр, выбор сохраняется в профиле (`user://`) и применяется к крылу игрока на всех 48 моделях.
Сброс — родная текстура.

## 2. Решения пользователя
- 2026-11-05: подпроект `game`.
- 2026-11-05: только у себя — по сети текстура не передаётся; чужие пилоты и боты — как сейчас
  (`bots.json → visual.sail_schemes`, родная текстура).
- 2026-11-05: куда ложится картинка (верх/низ паруса отдельно или одна на весь парус) — решает координатор
  по развёртке UV крыльев; решение — в журнал (`decide`).
- **Наложение своей картинки (SLT-К2): одна картинка на обе обшивки, читаемая снаружи — верх (s,q) при взгляде сверху, низ (1−s,q) при взгляде снизу; верх картинки — к носу. Координаты по UV1 (s=u, q — доля местной хорды по SLT-1), пропорции — вписать по центру: аспект обшивки = размах / корневая хорда этой обшивки (считается из меша), вне картинки и при alpha<1 — родная текстура; карман киля — родная. Без пересборки моделей.** (2026-11-05) — SLT-1: у всех 49 моделей одна схема UV1; по UV картинка не теряется на треугольном плане (в отличие от плоской проекции), у корня пропорции верны; обе обшивки — видят и камера сзади (верх), и пилот из кабины и с земли (низ).
- **Перевёрнутое UV2 в шейдере паруса (побочная находка SLT-1, Q1) чинить сразу в этом модуле, для всех крыльев (в т.ч. ботов) — отменяет ночное решение по Q1** (2026-11-05)

## 3. Что известно
- Вид чужих и ботов: `GliderVisual`, расцветки — `configs/bots.json → visual.sail_schemes`, Color или родная текстура
  (`scripts/game/remote_pilots.gd`).
- Модели крыльев — glb, геометрия по паспортам (docs/guide/models/wings.md).

## 4. Задачи
Карточки заводит координатор. Ориентир:
- исследование развёртки UV паруса у моделей крыльев (одна ли схема у всех 48, верх/низ, двойная обшивка);
- загрузка и хранение картинки (выбор файла, проверка формата и размера, копия в `user://`), предпросмотр, сброс;
- применение к крылу игрока (материал паруса), тест;
- guide и CHANGELOG.

## 5. Волны
Определяет координатор.

## 6. Условия остановки (шлюз)
- UV крыльев не позволяет положить картинку без пересборки моделей — шлюз с вариантами.
- Нужна передача по сети или изменение вида ботов — шлюз (решение 2026-11-05: только у себя).
