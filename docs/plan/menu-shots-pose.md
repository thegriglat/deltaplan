# menu-shots-pose — поза планера на кадрах фона меню (код задач MSP)

## 1. Цель
На кадрах `tools/shots/menu_art.py` (4K-набор `build/shots-menu4k`, 16 номеров из `index_3840x2160.md`) дельтаплан местами
в крутом крене/пикировании (пример — 06: крыло почти вертикально). Найти причину и исправить скрипт съёмки так, чтобы на
всех кадрах планер был в правдоподобном установившемся полёте; переснять и показать пользователю.

## 2. Решения пользователя
- 2026-10-23: снимать кадр с намертво зафиксированным планером (без физики и ветра в момент съёмки) — основной вариант.
  Уточнено пользователем 2026-10-23: крен 0, тангаж 0, курс — по кадру (как у полёта к `sim_time_s`); пилот и подвеска
  в равновесии (MSP-К1 v2). Сейчас сим уже стоит на паузе во время прогрева, так что
  поза на кадре — поза в момент `sim_time_s`; фиксация заменяет её заданной.
- Кадры смотреть уменьшенными (960 px), не 4K целиком. Для пользователя — `/home/greg/deltaplan/build/screenshots/menu-shots-pose/`.
- **Кадр снимается с зафиксированным планером без физики и ветра в момент съёмки: крен 0, тангаж 0, курс — по кадру (как у полёта к sim_time_s)** (2026-10-23) — ветер и физика раскачивают позу к моменту снимка

## 3. Задачи
- **MSP-1** (dp-engineer) — причина (поза в момент `sim_time_s` по всем 16 номерам: крен, тангаж, угловые скорости,

## 5. Условия остановки (шлюз)

пересъёмка не укладывается в набор из 16 номеров.
