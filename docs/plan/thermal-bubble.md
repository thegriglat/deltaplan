# План thermal-bubble (код задач TB)

## Цель
Сделать термик физичнее по сути, **без сложных схем**. Сейчас термик — наклонённый ветром столб от источника до
верха, который даёт только вертикальную скорость w. Профиль по радиусу — Гедеон (1 − x²)e^(−x²) с кольцом
опускания, радиус — по Аллену (`rust/dp-air/src/terms/thermal/profile.rs`, `life.rs`). Горизонтальной
скорости нет, поэтому воздух поднимается «ниоткуда»: масса не сохраняется, у земли нет притока к термику, у
верха нет растекания.

Идея: термик — всплывающий тёплый пузырь, то есть вихревое кольцо (Scorer 1957, Turner 1957), а с шлейфом —
стартовый факел (Turner 1962). В системе пузыря течение почти стационарно и подобно само себе. Поэтому:
- один безразмерный шаблон считается заранее (аналитика или предрасчёт);
- в игре шаблон масштабируется по радиусу и силе;
- пузырь сдвигается по траектории: всплывает и сносится ветром поля;
- шаблон складывается с полем.

Оба поля бездивергентны, значит и сумма бездивергентна.

Итог — пользователю: даёт ли шаблон физичнее поле (приток, кольцо, растекание), не ломая того, что уже сверено
с литературой, и сколько стоит опрос. Встраивать ли в игру — решение пользователя после итога.

## Решения пользователя
См. `.dpcli/dpcli inbox thermal-bubble`.
- **Проверить идею «термик — пузырь в своей системе координат, сложенный с полем со сдвигом во времени».
  Цель — физичнее по сути, без сложных идей; предрасчитанный шаблон (Пикар или аналитическое решение для всех
  термиков) — основной путь.** (2026-11-09)
- **Если шаблон концептуально лучше моделирует термик — дорабатывать и встраивать в игру (оценка главной сессии: да — масса сохраняется, есть приток, кольцо и растекание).** (2026-11-09)
- **Встраивать без флага — шаблон пузыря по умолчанию, это просто улучшение игры; флаг /thermal/bubble_template и старый профиль можно убрать.** (2026-11-09)

## Задачи (уточняет координатор)
1. **Шаблон.** Начать с аналитики: сферический вихрь Хилла (голова) + вовлечение Тёрнера/Скорера (рост
   радиуса, замедление подъёма) + шлейф стартового факела там, где термик — столб. Отражённое кольцо под
   плоскостью земли — метод изображений, пока пузырь у земли. Предрасчёт (Пикар/LES в системе пузыря) — только
   если аналитика окажется явно беднее литературы; Пикар стационарный, пузырь стационарен лишь приближённо.
   Числа (α вовлечения, C подъёма, скорости притока у земли) — из литературы со ссылкой и надёжностью, не
   подбирать.
2. **Прототип и сверка.** Поле одного термика и нескольких рядом:
   - дивергенция суммы с полем;
   - профиль w в ядре против нынешнего (Гедеон/Аллен) и Lenschow–Stephens;
   - приток у земли, растекание у верха, кольцо опускания — против литературы;
   - разрезы картинками для пользователя в `/home/greg/deltaplan/build/screenshots/thermal-bubble/`.
3. **Цена опроса.** Время на точку (сумма ближайших пузырей: поворот, масштаб, таблица) против нынешнего
   `sample`; память шаблона.
4. **Вывод.** Что меняется для пилота (приток, подсос, срыв на краю), что ломается из сверенного, что встраивать.

**Круг 3 — доработка и встраивание по умолчанию** (решения пользователя 2026-11-09; разбиение — координатор):
5. Исследования (параллельно, без правок `bubble.py` и `dp-air/src`; числа — из литературы, не подбирать):
   - TB-10 — жизнь термика игры (~990 с) против подъёма головы (~1480 с до 0,9 z_i): причина в модели,
     литература о времени подъёма термиков через слой; согласование из модели, не подгонкой.
   - TB-11 — приток 0,58 w* против 0,36 w* LES: сравнение «как у эталона»; правка — только с физическим основанием.
   - TB-12 — профиль «между» q(ξ) по высоте под шаблон (сумма «пузыри + между» = w_conv по высоте).
   - TB-13 — радиус 2000 м: шов, кто опрашивает ветер дальше, можно ли убрать старый профиль целиком.
6. TB-14 — полётный замер в игре: присутствие термиков, приток у земли, подъём в ядре, нет разрывов; время кадра
   нового против старого (на коде круга 2 — флаг вкл против выкл).
7. TB-15 — встраивание: шаблон v5 по выводам TB-10…13, без флага, облачный подсос сохранён, тесты перезаписаны.

- Прототип — Python (NumPy) в `tools/research/thermal_bubble/`. Круги 1–2 — Rust за флагом. Круг 3 (решение
  пользователя 2026-11-09): шаблон в игре по умолчанию, флаг `/thermal/bubble_template` и старый профиль можно убрать,
  побитность со старым не нужна; тесты с числами старой модели — перезаписать с обоснованием.

- Эталон — литература и измерения; не подгонять под нынешнюю модель, но расхождения с ней объяснить.
- Выводы — `docs/research/thermal_bubble.md`.
