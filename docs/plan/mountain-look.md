# Горы похожи на горы (модуль `mountain-look`, код задач MLK)

Цель пользователя: высокие горы (Гималаи, Эверест, Эльбрус, Альпы, Кавказ) выглядят как суровые высокие горы —
острые гребни, рваные скалы, — а не как высокие мягкие холмы. Холмы — спокойные, горы — суровые; различие читается
с первого взгляда. Контракты — `docs/contracts/mountain-look.md` (MLK-К1…К3).

## 1. Решения пользователя (не обсуждаются)
- Сглаживание Copernicus при сборке (σ 0,8 клетки, против ступенек леса в DSM) — **только там, где лес или застройка**
  (маска леса 10 м, классы WorldCover); на скалах, снегу, голом камне, лугах — высоты как в данных; переход плавный, без шва.
  Это меняет `height_at` (физика, поле воздуха) — так и надо; совместимость не нужна: версия формата места +1, места пересобираются.
- Детали скал — в нормалях и раскраске; смещение вершин — только вдали, с затуханием у камеры: у камеры картинка = `height_at`,
  без швов по LOD и между слоями.
- Дальнее заострение (`relief_*`) усилить для высоких гор (крутизна, перепад высот, высота над морем — решает координатор/исполнитель,
  физично-правдоподобно).
- Детальный слой увеличивать — только если замеры покажут, что иначе никак, и с оценкой памяти и видеопамяти (бережно к VRAM).
- Снег WorldCover: рваные кромки, снег по крутизне и кривизне (на крутом не держится, в ложбинах держится) — только в шейдере.
- Физика прежде «нравится», без шлифовки (визуальная мелочь — не больше двух попыток, берётся лучшая).
- Проверка визуала — числами и тестовой сборкой Linux для пользователя, без скриншотов агентами.
- Тяжёлые прогоны — `systemd-run --user --scope -p MemoryMax=12G`, не больше 4 тестов Godot параллельно, Godot только с временным `XDG_DATA_HOME`.
- В main не сливать без одобрения пользователя.

## 2. Что известно (проверить числами)
1. Слои: детальный 40 км / 25 м (Copernicus GLO-30), фон 160 км / 100 м (Terrarium). Вершины дальше ~20 км — на 100-метровой сетке;
   у фона LOD 12/25/45 км (шаг вершин 200–800 м). Подозрение: на кадре Эвереста видны пики фонового слоя.
2. Сглаживание σ 0,8 везде: выше границы леса гребни теряют ~40 % кривизны и ~5 м высоты (`cliff_look_probe --shape=1`).
   Сглаживание идёт в `DemStage` до `SurfaceStage` — классов и маски леса в этот момент ещё нет (порядок стадий меняется в MLK-2).
3. Дальнее заострение `relief_*` (≤ 8 м, гаснет у камеры в `relief_near_m` 200–350 м) — по 4 соседям узла слоя, не зависит от LOD,
   но вершины LOD стоят через 2–8 узлов: пик между вершинами теряется.
4. Снег класса 8 WorldCover — доля классов с шумом `surface_edge_noise`, без `ragged_edge`; рваные кромки 7–25 м — только у снега в кулуарах.

## 3. Задачи
### MLK-1 Замер: слои, сглаживание, силуэт гор (до)
`dp-researcher` (Sonnet). Поставляет MLK-К3 (зонд). Скрипт-зонд `tools/bench/mountain_look_probe.gd` (+ `.tscn`; можно на основе
`cliff_look_probe.gd`), места: Эверест (старт у Намче/Гокио, Эверест ~25–30 км), Эльбрус (Чегет, ~10–13 км), Монблан (Шамони, Планпра),
Кавказ/Альпы ещё одно место по выбору, и холмы (встроенный `ongudai`) как контраст. Числа по пунктам 1–2 раздела 2:
- для каждого места — главные вершины в поле зрения: расстояние, слой, высота сырая (Copernicus 30 м без сглаживания) / в данных игры /
  в отрисовке (LOD-шаг вершин + текущее `relief_*`), недобор м;
- гребни по зонам (слой × полоса дальности × выше/ниже границы леса): кривизна игра/сырое, просадка гребней, м;
- горизонт с точки старта (+300 м над землёй): профиль угла горизонта по азимуту (шаг ≤ 0,1°) — сырой эталон против отрисовки;
  «шероховатость» силуэта (СКО высокочастотной части угла) и недобор высоты пиков в градусах, доля горизонта от фонового слоя;
- сглаживание: выше границы леса и в лесу отдельно — кривизна и просадка гребней σ 0,8 против сырого;
- оценка памяти/VRAM, если увеличивать детальный слой (60/80 км при 25 м, маска 10 м) — таблица, без реализации.
Итог: `tools/research/mountain_look/README.md` (frontmatter research, команды воспроизведения, таблица) + JSON по контракту К3.
Ответ на вопросы: подтверждено ли (1) «пики Эвереста — фоновый слой», что теряется больше — сетка 100 м или шаг LOD; (2) потеря от σ 0,8 выше леса.
Приёмка: зонд отрабатывает на всех местах (`MLOOK … OK`), JSON по К3, README с числами. Оценка — средняя.

### MLK-2 Сглаживание DSM только в лесу и застройке
`dp-engineer` (Sonnet). Поставляет MLK-К1 v1. Сборка места: маска веса w (лес — маска 10 м, застройка — класс WorldCover 7 / built10),
мягкая; h = сырое + w·(G_σ(сырое) − сырое); порядок стадий — так, чтобы маска была до финальных высот (реки на сырых высотах допустимы);
фон после — `_patch_from_finer` по новым высотам. `Locations.FORMAT_VERSION` 3→4, фикстуры тестов пересобрать (или тест паритета
переписать на новое правило). Контрактный тест `tests/contracts/test_mountain_look_contracts.gd` (К1). `cliff_look_probe --shape=1`
на Шымбулаке/Эльбрусе: выше леса кривизна игра/сырое ≥ 0,95, просадка гребней ≤ 0,5 м; в лесу — как было. Документ:
`docs/guide/terrain.md` (абзац про сглаживание), `docs/guide/location-data.md`. Оценка — средняя.

### MLK-3 Заострение дальних вершин высоких гор
`dp-engineer` (`model: opus`: шейдер вершин, силуэт, LOD). Поставляет MLK-К2 v2. Зависит от MLK-1 (числа «до»).
Варианты по числам MLK-1: (а) сила `relief_*` от крутизны, перепада высот в окрестности (масштаб 0,5–2 км) и высоты над морем
(высокие голые горы — сильнее, холмы — как сейчас); (б) силуэт без потери пиков между вершинами LOD — высота по пирамиде максимумов
(или иная схема), функция мира и дальности, не шага LOD. Правило К2: у камеры (`relief_near_m`) dh = 0, без швов по LOD и между слоями.
CPU-зеркало dh для зонда (К2). Приёмка: зонд К3 — шероховатость силуэта отрисовки / сырой ≥ 0,7 у высоких гор (было — по MLK-1),
недобор пиков ≤ 1/2 прежнего; у холмов (`ongudai`) изменение силуэта ≤ 10 %; время кадра рельефа не хуже +5 % (`tools/bench/probe.gd`
или GPU-тест); контрактный тест К2. Увеличение детального слоя — только через шлюз с оценкой памяти. Оценка — большая.

### MLK-4 Снег WorldCover: рваные кромки, по крутизне и кривизне
`dp-engineer` (Sonnet). Только шейдер и `world.json → terrain_look.snow_*`; классы и `surface_at` не меняются.
Кромка снега класса 8 — `ragged_edge` (шум 7–25 м, как у снега в кулуарах); доля снега гаснет на крутом (≈ 45–60°, порода видна),
держится в ложбинах (вогнутость `gully`/`v_convex`), сдувается с выпуклых гребней; без новых текстур; цикл без `break`.
Приёмка: тесты рельефа (`--filter=terrain`) зелёные, `cliff_look_probe` на Эльбрусе — доля снега по полосам уклона (CPU-зеркало формулы
снега в зонде: на > 55° снег ≤ 0,2, на < 30° без изменений ± 0,05). Оценка — малая.

### MLK-5 Замер «после» и тестовая сборка Linux
`dp-mechanic`. Зонд К3 на тех же местах после MLK-2/3/4 → таблица до/после в README MLK-1; `tools/build.sh linux` из копии модуля.
Оценка — малая.

## 4. Волны
1. MLK-1, MLK-2, MLK-4 параллельно (разные файлы: зонд / сборка места / фрагментный шейдер снега).
2. MLK-3 после MLK-1 (и после влития MLK-2 — числа на новых высотах).
3. MLK-5.

## 5. Шлюзы
- MLK-1 покажет, что без увеличения детального слоя силуэт не спасти, — вернуться с оценкой памяти/VRAM и вариантами.
- Сглаживание по маске даёт видимые ступеньки DSM на опушках в физике (удар о «стену» крон) — вернуться.

## 6. Риски
- Сборка Эвереста/Эльбруса требует сети (Copernicus, Terrarium, WorldCover) — зонд кеширует в своём `XDG_DATA_HOME`/кеше задачи.
- `test_parity_with_builtin_askarovo` и фикстуры мест ломаются от смены высот — пересобрать фикстуры в MLK-2.
- MLK-3 и MLK-4 правят один шейдер (`terrain.gdshader`) и `world.json → terrain_look` — вершинная и фрагментная части; слияние по очереди.
