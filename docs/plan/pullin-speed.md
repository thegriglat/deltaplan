# pullin-speed — скорость полного «на себя» в «Маятнике» (код задач VM)

TODO T-86. Ветка `feature/pullin-speed` от `main`, копия `~/deltaplan-pullin-speed`.

Полный «на себя» в «Маятнике» даёт 44,6 / 56,6 / 59,9 км/ч (учебное / мачтовое / безмачтовое,
`docs/research/pendulum_pitch.md`, «После правки рук»), а «Смещение веса» по поляре паспорта —
63–103 км/ч (Vmax спортивных — DHV VG 0, то есть без VG). Разница не из-за VG: он дал бы ~+20 %.

## Решения пользователя
- VG и упругость кромок не делаем (решение 11.10, модуль pendulum). Петли и пилотаж — не цель;
  цель — честная скорость крыльев для перелётов (2026-10-19).
- Сначала разбор готовых данных в docs и tools/research; новые прогоны — только чего не хватит (2026-10-19).
- Физика прежде «нравится»: если ограничение физическое (ход рук реального пилота) — так и оставить,
  описать в «Границах»; если артефакт модели — чинить модель для всех крыльев, не подгонять числа.
- **VG и пилотаж не делаем; цель — честная Vmax для перелётов; сначала разбор готовых данных, новые прогоны — чего не хватит; проверить и точку подвески** (2026-10-19) — отзыв с Reddit про петлю; T-86

## Задачи

### Волна 1
- **VM-1** (dp-researcher, Sonnet) — разбор: откуда паспортная Vmax (что это за режим у DHV: полный
  «на себя» без VG, какой ход трапеции и поза пилота), какой ход рук и угол крыла к стропе нужны
  в модели для паспортной Vmax, сколько даёт ход 0,45 м (`scripts/flight/pendulum/pilot_arms.gd:
  shift_x_pull`) и откуда это число; **точка подвески** (догадка пользователя 19.10): где она
  у нас по крыльям против паспортов и «ЦМ + 2–3 см» пилота, сколько км/ч даёт на полном «на себя»
  (на триме 0,4–0,9 км/ч на см, ползунок ±4 см — docs/guide/flight/pendulum.md; при «ЦМ + 2–3 см»
  безмачтовые теряли устойчивость по тангажу, Kn ≤ 0 у 10 из 15); вклад центровки/Cm0 паруса, CL_α полос (4,5 без взаимной
  индукции), сопротивления пилота. Данные — docs/research/pendulum_pitch.md, docs/research/pendulum/
  prototype.md (таблица крыльев), docs/guide/flight/polar-table.md, docs/guide/models/wings.md,
  configs/wings/*.json, прототип tools/research/pendulum/. Итог — research-документ: причина
  с числами, к какому из классов «физика / граница модели / ошибка модели» относится, варианты
  правки с ожидаемым эффектом. Код игры не править.
- **Шлюз Q1** — итог VM-1 пользователю: причина и варианты.

## Границы и остановка
- VG, пилотаж, петли — вне модуля. Режимы `weight_shift`/`rate` (`FlightModel`) не трогать.
- Если причина в аэродинамике полос и нужна новая модель (взаимная индукция и т. п.) — шлюз,
  а не правка в модуле.
- Версию не выпускаем.
