# План sw-ground (код задач SWG)

## Цель
Продолжение sw-charges-3d (сдан в main 7aeeea098). Довести схему «заряды на поверхности + вихри» до места, где летает
дельтаплан: у земли в лее и долине. Если получится — у схемы реальный шанс заменить Пикар (линейное решение без итераций,
нет проблемы сходимости в слабый ветер); если нет — она остаётся аналогией для верхних слоёв.
Оценка вариантов — по трём осям с равным весом: ротор, время, стройность (одна аналогия зарядов/токов).

## Решения пользователя
См. `.dpcli/dpcli inbox sw-ground`.
- **Продолжать после итога sw-charges-3d: (1) слой у земли в лее и долине, (2) геометрическая нить ротора на реальном рельефе, (3) время на всём поле.** (2026-11-08)
- **Приоритет — довести саму модель (слой у земли, ротор); замеры времени и сравнение скорости с Пикаром — потом, только если модель окажется состоятельной. SWG-6 (рычаги опроса) не продолжать: идущий счёт можно доснять и записать как есть, новых задач по времени не заводить. В итоге: время Python/CuPy-прототипа — не вердикт для схемы (Пикар — оптимизированный Rust на CPU, панели линейны: дерево Барнса–Хата/FMM, многосеточный метод, отбрасывание дальнего рельефа дальше 10–15 км как фона — оценки, не задачи).** (2026-11-09) — сначала состоятельность модели, скорость — после

## Что известно (не переделывать)
Итог — `docs/research/sw_charges_3d.md` (разделы «Итог одним экраном», «Варианты × ротор / время / стройность», «Открытые вопросы»), решения 3D — `docs/plan/sw-charges-3d.md`, идеи — `docs/plan/sw-charges.md` «Идеи на будущее».
- Панели + JH (`potential_jh`) выше 50 м на Perdigão в ±15 % Пикара у 0,64–0,72 точек; Askervein 0,12; в лее и долине у земли +63…+209 % к Пикару (замедление не воспроизводится). Чувствительность к z0 (медиана 1,80 м против 0,645 по ln z0) и σ не сканировалась.
- Ротор: ни один из 7 вариантов; Пикар тоже почти нет (NE 0/430/170, SW 0 против Menke 420–680 м) — по ротору ничья.
- Нестационарные нити, слой Рошко, нить Фёппля — отвергнуты (не повторять).
- Геометрическая нить (rotor3d v2: ноль скорости в присоединении, R = 0,25(x_r − x_c), порог уклона 0,27): Agnesi |u_min|/U 0,54, C2 L = 680 м (Пикар ~800), C4 — нити нет (запас 0,7 %); на Askervein/Perdigão не прогонялась.
- «Лежачие смерчи» (C'): state «нет» при литературных E; порог распада у стены не подтверждён — открытый вопрос, не цель модуля.
- Код: `tools/research/sw_charges_3d/` (panels3d, rotor3d, chain3d, compare…), интерпретатор `tools/research/cascade_2d/py`.

## Задачи (уточняет координатор)
1. **Слой у земли в лее и долине (главное).** Найти причину завышения у земли (+63…+209 %): внутренний слой JH (линейная теория для пологих холмов — в лее/долине за пределами применимости), z0, σ сглаживания, фон, отсутствие торможения отрывом. Сначала диагностика (что даёт завышение — по разложению вклада), потом исправление — по возможности на языке аналогии (например, отрыв/мёртвая зона как заряды/токи), без подгонки по месту. Приёмка: доля точек в ±15 % Пикара у земли (10, 50 м) в лее и долине Perdigão и на Askervein — до/после; мачты — RMSE.
2. **Геометрическая нить ротора на реальном рельефе.** rotor3d v2 на Perdigão (NE, SW) и Askervein: L и |u_min| против Menke 2019 и Пикара; ложные роторы на пологих буграх — нет. Одно правило на все места; не подгонять.
3. **Время на всём поле.** Панели (+нить) на сетках окон игры (64×64 на 100 и 50 м, все уровни) против Пикара на той же машине; холодный старт и пересчёт при смене ветра.

## Условия
- Прототипы — Python (NumPy, CuPy); Rust/игра — только после решения пользователя. Пикар — через крейт/`dp-stand`, без Godot.
- Пикар — не истина (±10–15 %); эталон — измерения (Askervein, Perdigão, Menke 2019); колонка «эксперимент» с надёжностью.
- Масштабы: предел GLO-30 (30 м), мельче 25–30 м не считать. Не шлифовать.
- Данные и команды — `tools/research/sw_ground/`; выводы — `docs/research/sw_ground.md`.

## Приёмка
- Таблицы до/после по задаче 1 (лее, долина, гребень, наветренный; 10/50/300 м; Perdigão NE/SW, Askervein).
- Ротор Perdigão по задаче 2: есть/нет, L против Menke и Пикара.
- Время поля на сетках окон против Пикара.
- Вывод: годится ли схема на замену Пикару у земли; что осталось вне аналогии.
