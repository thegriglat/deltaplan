Решения координатора:
- Шаблон модели уже есть (`build_gliders.py` + `glider_params.json`); «шаблон» волны 1 = машиночитаемая спецификация из ТЗ + применяющий скрипт (W3-02).
- Поляра новых крыльев — подобием от базы класса по нагрузке на крыло (К4): L/D не придумываем, DHV Vmin — проверка, не подгонка. Выносится на шлюз 1.
- `sport.lower_cover` 0,70 → ≈0,9: общее правило ТЗ (`lower_cover` = доля двойной/100 ± 0,1) при паспортных 92 % (в разделе E3 не было отдельной строкой).
- К3 → v2 по предложениям W3-02 (`manual`, размах/площадь только в `config`, `dhv` только из DHV, `wings3d_overrides/`).
- Группа меню — по конструкции (смысл групп: «Мачтовые двухобшивочные» / «Безмачтовые»), а не по `tz_curated`: N19 `seed_spyder` (безмачтовое по цитате, база sport) → `topless`; N28 `moyes_litesport` (мачтовое по цитате, база laminar) → `kingpost`. Правится в `tz_curated.py` задачей волны.
- N15 Icaro MastR — по цитате небольшой кингпост: `kingpost: true`, группа `kingpost`, `kingpost_m` — оценка (≈ половина базы, помечено в `_doc`), остальная форма от combat; инвариант К1 соблюдается.
