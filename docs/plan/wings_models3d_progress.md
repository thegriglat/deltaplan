- Шаблон модели уже есть (`build_gliders.py` + `glider_params.json`); «шаблон» волны 1 = машиночитаемая спецификация из ТЗ + применяющий скрипт (W3-02).

- `sport.lower_cover` 0,70 → ≈0,9: общее правило ТЗ (`lower_cover` = доля двойной/100 ± 0,1) при паспортных 92 % (в разделе E3 не было отдельной строкой).
