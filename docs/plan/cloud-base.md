# Основания облаков (модуль `cloud-base`, код задач CBS)

## 1. Цель
Сейчас основания всех кучевых лежат в одной плоскости — срез одной линией через весь кадр (кадры меню 06, 09, 17, `build/shots-menu4k/`). Сделать основания по кромке инверсии (уровень, на котором поле/термики ставят основание облака) с разбросом между облаками 50–150 м. Больше ничего в облаках не менять.

## 2. Решения пользователя (не обсуждаются)
- 2026-10-24: модуль `cloud-look` отменён вместе с правками (в `main` не идёт). Вместо него — только основания облаков по кромке инверсии с разбросом 50–150 м; лёгкий исполнитель, без координатора.
- Свет, форма верха, дальнее поле, перистые, экспозиция — не трогать.
- Замеры времени кадра не делать.
- Проверка — кадры меню до/после: `tools/shots/menu_art.py --only=06,09,17 --size=1920x1080`, «до» — с `main`, пары «до | после» — `/home/greg/deltaplan/build/screenshots/cloud-base/`.

## 3. Задачи
### CBS-1 Основания по кромке инверсии с разбросом
Исполнитель: `dp-engineer` (sonnet). Найти, откуда берётся высота основания у отрисовки (`CloudField.base_msl`, `z_lcl_msl_m`, кромка `env.cb` у термиков) и что в коде называется кромкой инверсии; основание каждого облака = кромка + сдвиг, разброс сдвигов между облаками 50–150 м (параметр в `configs/atmosphere.json`). Если кромка инверсии и уровень основания в коде — разные величины, в отчёте указать, какую взял и почему.

## 4. Условия остановки (шлюз)
- Разброс требует менять модель поля облаков или термиков (физику подъёма), а не только высоту основания.
