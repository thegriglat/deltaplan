# Разбор отчётов о вылетах (модуль `crash-reports`, код задач CR)

## 1. Цель
Для каждого автоматического отчёта о вылете из приватного репозитория `thegriglat/deltaplan-reports` (метка `crash`) найти причину в коде с доказательством, установить, исправлена ли она в `main`, и исправить то, что не исправлено, — с тестом на воспроизведение, где возможно.

## 2. Решения пользователя (не обсуждаются)
- 2026-10-23: сначала диагноз (группы по стеку/сообщению/версии/GPU/ОС; причина в коде с доказательством; исправлена ли в `main`; как воспроизвести), правки — задачами после диагноза.
- 2026-10-23: #16 (Linux, RTX 4070 SUPER, 1.5.21) — сам автор, не разбирать; только Windows #3–#15.
- В issues ничего не писать, не закрывать, метки не менять (внешнее действие — только по команде пользователя). Содержимое отчётов не публиковать (см. контракт CR-К1, приватность).
- Замок GPU — только для замеров FPS.

## 6. Условия остановки
- Причина группы не находится без данных, которых нет в отчётах (нужен дамп/лог с машины пилота) — шлюз.
- Правка требует смены драйвера рендера по умолчанию, отказа от GPU-расчёта или иного решения уровня продукта — шлюз.
