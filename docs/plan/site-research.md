# site-research — исследования на сайте (код задач SRS)

Повод (2026-10-21): страница сайта «Облака и тени» описывала старую схему «одно облако на термик», хотя в игре —
поле облачности (CLF-1/9/10, `docs/research/cloud_field.md`, статус `active`), графиков исследований на ней нет.
Вероятно, так не только с облаками.

## Решения пользователя
- Посмотреть, каких исследований нет на сайте, и обновить доки, если требуется (2026-10-21).
- Тексты — понятно игроку и пилоту, «нормально в общем»; исполнители — sonnet (2026-10-21).

## Задачи

### Волна 1 — аудит
1. **Сверка** (writer или researcher): все исследования со статусом `active` (вывод применён в игре) и `closed`
   с выводами в `docs/registry/findings.md` / `docs/registry/research.md` против страниц `site/content/` (ru и en) и
   против `docs/guide/` (описывает ли руководство то, что есть в `main`). Итог — таблица: исследование → где должно
   быть на сайте → есть / нет / устарело (что именно) → есть ли готовые графики (`tools/research/<тема>/`,
   `build/screenshots/<модуль>/`) → оценка объёма правки. Только аудит, без правок.
2. **Новые функции игры** (тот же аудит): всё, что игрок видит, из CHANGELOG.md за последние версии и docs/guide/game/ — против сайта. Пользователь (2026-10-21): скорее всего нет страниц про тренировки, учебные острова, файлы задач и треков (IGC/GPX/xctsk) и прочее недавнее; треки частично есть в site/content/docs/goals.*. Нет страницы — в таблицу как новая страница.

### Волна 2 — правки по таблице
2. Страницы сайта (ru + en) и, где расходится с `main`, `docs/guide/`: группами по странице, одна страница — одна
   задача; 3–5 наглядных графиков из исследований, подписи под ними; устаревшее исправить.

## Не трогать
- `site/content/mechanics/clouds*` — модуль `site-cloud-field` (SCF-1) пишет сейчас.
- Точка росы, дымка, цвет солнца и облаков — модуль `haze-humidity` их меняет; в текстах — нейтрально, правки — после него.

## Правила текстов
- Понятно игроку и пилоту, без жаргона кода (имена файлов — только в «Подробнее»), честно о границах модели, без
  продающего тона; родители — только «пилот»; пасхалки не упоминать.
- Не выдумывать: числа — из исследований и находок, со ссылкой на источник в docs.
- Сайт собирается: `hugo --source site --quiet -d <tmp>` — exit 0.

## Условия остановки
- Итог волны 1 — таблица пробелов в журнал; волна 2 — без шлюза, по таблице (решение пользователя «обновить, если требуется»).
- Расхождение руководства (`docs/guide/`) с кодом `main`, которое требует проверки поведения игры, а не текста, — шлюз.
