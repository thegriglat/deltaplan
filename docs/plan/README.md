# План: группы задач

Верхний уровень плана. Работа делится на **группы** (области кода). Для каждой группы отдельный
планировщик пишет карточки задач в `docs/plan/<папка группы>/NN-кратко.md` (цель, контекст, владения,
шаги, критерий приёмки, модель, размер S/M/L, закрываемые требования).

**Объём плана — доделать основу:** все открытые пункты TODO.md и требования REQUIREMENTS.md, **кроме**
разделов TODO «Идеи», «Позже», «Места» (новые места), требований «Позже»/«на будущее»/«далёкое будущее»
(VR-23…VR-30, FR-14c, сменные вариометры FR-25a, английский NFR-4) и явно отложенного пользователем
(слабое железо/Compatibility, CI, поломка крыла, настоящая аэродинамика, аэробуксировка). Вех «показа» нет:
после выполнения пользователь сам всё посмотрит и попробует (только Linux; Windows-сборка — позже).
Разделы «Вопросы пилотам» — открытые вопросы из questions.md: ответы поправят конфиги, но работу не блокируют.

Правила для планировщиков групп:
- карточка трогает только папки своей группы; изменения чужого API — отдельной карточкой в группе-владельце;
- стык двух групп (например, «ветер → трава») делает группа-**потребитель** через уже опубликованный API;
  если API нет, сначала идёт карточка у владельца;
- отложено пользователем, не планировать: оптимизация под слабое железо / Compatibility, CI, поломка крыла
  (FR-14c), настоящая аэродинамика, аэробуксировка, новые места из раздела «Места» TODO.md;
- **сейчас работают агенты** (их задачи не планировать заново, учитывать как незавершённые):
  integration, terrain2, atmosphere, vegetation, sounds — см. отметки «в работе» ниже.

Размер группы — объём оставшейся работы: **S** ≈ 1–2 карточки, **M** ≈ 3–5, **L** ≈ 6+.

**Рекомендации для GrassField (от агента vegetation, не реализовано):**
1. Прореживание вдали: пучкам в куске — случайный rank 0..1; виден, если rank < плотность(расстояние); дальние пучки шире (far_width_k). Вершин вдали в 5–8 раз меньше.
2. Волны порывов: смещение копить на CPU (offset += dir·speed·dt) → uniform; порывистость = |air_velocity_at − mean_wind_at|, сглаженная экспонентой — иначе рисунок скачет при смене ветра.
3. Приминание гасить по высоте ног над землёй: полное до ~0,4 м, ноль выше ~1,2 м; нормаль травинки явно, без переворота (иначе обратные стороны темнеют при cull_disabled).
4. Посадки — прямоугольником (axis_deg, length_m, width_m из WorldObjects.get_landing_sites), не кругом; сухость травинок по локации поверх палитры (Онгудай +0,35, Аскарово +0,25).

## Зависимости между группами

```
4 Рельеф ──surface_at, height, солнце──▶ 2 Атмосфера ──air_velocity_at, облака, cloudbase──▶ 3 Облака
   │  TerrainWind ◀── mean_wind/thermals (2)        │
   ├──▶ 5 Растительность (ветер, просеки, палитра)   ├──▶ 6 Объекты (ветер для колдунов, дыма)
   ├──▶ 6 Объекты (height_at, latlon)  ── OSM реки ──▶ 4
7 Модели ──маркеры, анимации, SailMaterial──▶ 1 Полёт (glider_visual) и 12 Сцена (PilotAnimator)
1 Полёт ──Telemetry──▶ 8 Приборы, 9 Звук, 10 Задания
10 Задания ──API──▶ 11 Интерфейс + 12 Сцена (подключение)
12 Сцена собирает всё; 11 — экраны сцены 12
13 Сборка — последняя: проверяет всё сразу
```

Ключевые цепочки:
- **VR-5 время суток:** 4 (солнце по дате/времени) → 2 (суточный цикл термиков) → 11/12 (выбор времени, часы).
- **FR-14d тучи с дождём:** 2 (физика) → 3 (дождевые полосы) → 9 (звук дождя) → 12 (подключение, если нужен новый API).
- **VR-3 смог:** 4 (дымка/смог по классу «застройка») — сам; 6 (дым VR-15) может брать высоту инверсии у 4.
- **Тень крыла / колыхание паруса:** 7 → 9 (синхронный звук хлопания).
- **Задания в игре:** 10 готово → 12 (трекер в `tick`) → 11 (меню режима, итог и рекорды).
- **Ответы пилотов** (когда придут) → правки конфигов в 1, 2, 4, 9; работу не блокируют.
