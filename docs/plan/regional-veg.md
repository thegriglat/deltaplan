## Решения пользователя
Вариант B (минимальный) из исследования, 2026-10-18:
- регион места: дерево решений 128–256 листьев на Кёппене–Гейгере (Beck 2018, CC BY 4.0 — в ASSETS.md), запечённое в `configs/` (3–6 КБ JSON), + ручные исключения-прямоугольники (Рапа-Нуи, Ницца, Покхара…) + существующие высотные пояса (SL-5);
- 3 новые породы своим генератором `tools/blender/build_trees.py` (стиль как у 5 существующих, LOD + импостер, 4 варианта): дуб/бук, пальма, тропическая вечнозелёная лиственная; каменная сосна — параметром `pine`, если дёшево;
- список пород места вместо константы на 5; в памяти только породы места (≤ 6) — VRAM не растёт;
- дома: профиль региона в конфиге (палитры, уклон, этажность) + 2 процедурные формы без текстур: плоская крыша с парапетом, низкая вальмовая;
- сезон SL-6: вечнозелёные тропические породы не желтеют.
- Проверка — кадры без замеров GPU: Бразилия (−27,72; −48,78), Альпы, Алтай (Онгудай — заметно не меняется), Средиземноморье, Рапа-Нуи (`volcano_island`; рельеф не трогаем). Шлюзы пользователю: кадры моделей пород до массовой интеграции; итоговые кадры мест.

## Решения координатора (2026-10-18)
- **Профили, не классы Кёппена.** Дерево даёт один из 8 наборов исследования (`arid, tropical_wet, savanna, mediterranean, subtropical, temperate, boreal, alpine_ice`); исключения могут назначать и доп. профили `island` (малые тропические/субтропические острова: пальма + тропическая). Профиль = секции `trees`, `terrain_look`, `scene_look`, `buildings`, сливаются `world ← профиль ← место` (RV-К1).
- **Алтай и Урал не меняются:** исключение-прямоугольник «Сибирь/Урал» (49…75° с. ш., 55…180° в. д.) → `boreal`; профиль `boreal` = текущие 5 пород в текущем порядке, без правок домов и полога. Дуба к востоку от Урала нет и в природе.
- **Атлас импостеров — один общий 4×2** (ячейки 0…4 — старые породы, 5 дуб, 6 пальма, 7 тропическая): 8 из 8, размер и VRAM прежние; порода места берёт свою ячейку из `trees.atlas_cell`. Сетки и текстуры моделей грузятся только для пород места.
- **Каменная сосна — не делаем:** отдельная форма кроны = отдельные glb и ячейка атласа, а атлас заполнен (8/8) — «дёшево» не выходит. Средиземноморье — сосна, дуб, пальма у моря.
- Атлас собирают не задачи моделей (бинарный конфликт), а интеграция RV-9 флагом `--atlas-only`.
- Городские деревья (`city_trees`, берёза) и кустарник (`shrub_scatter`) — вне модуля.

## Задачи

### Волна 1 (параллельно)
- **RV-1** (dp-engineer) — запекание `configs/biomes.json` (RV-К1): скрипт `tools/world/bake_biomes.py` (Кёппен 1 км → 8 наборов → дерево 128 листьев по lat/lon, взвешенное cos(lat); при неуспехе эталонов — 256), исключения, профили-заготовки; `scripts/world/biome.gd` (`Biome.at`, `Biome.profile`); тест 12 эталонных точек; атрибуция в ASSETS.md. Исходник Кёппена — вне репозитория (`~/.cache/deltaplan/koppen/`).
- **RV-2** (dp-engineer) — список пород места (RV-К2): `TreePlacer.SPECIES` → набор из `trees.set`; реестр `atlas_cell`/`season_kind`/`conifer` в `configs/world.json → trees`; шейдеры крестов и импостеров — массивы на 6 и `sp_count`, ячейка атласа из `sp_cell`; модели грузятся только для набора; тест «Алтай не изменился» (тот же набор деревьев, пород, позиций, что до правки).
- **RV-3** (dp-engineer) — генератор под новые породы (RV-К3): `ORDER` + `oak, palm, tropical`, число вариантов на породу, `--atlas-only`, заготовки параметров, новые типы кроны/листвы как точки расширения; старые 5 пород не пересобираются.
- **RV-6** (dp-engineer) — дома по профилю (RV-К4): формы H1 (плоская с парапетом), H2 (низкая вальмовая), выбор формы по стилю, потолок этажности для домов по правилу, без `metro`; палитры — существующие ключи. Подключение профиля к месту — RV-9.

### Волна 2 (после RV-3; модели — по агенту на породу)
- **RV-4** дуб/бук, **RV-5** пальма, **RV-7** тропическая вечнозелёная (dp-engineer, Blender) — `tree_<sp>.glb` (RV-К3), текстуры, импостеры, превью в `/home/greg/deltaplan/build/screenshots/regional-veg/models/<sp>/`. Визуальные мелочи — ≤ 2 попыток.
- **RV-8** (dp-engineer) — вечнозелёный полог в сезоне (RV-К5): `scene_look.evergreen` гасит осень/листопад доли лиственных в пологе рельефа; CPU-зеркало `SeasonLook`.
- **Шлюз Q1** — кадры моделей пород пользователю до интеграции.

### Волна 3
- **RV-9** (dp-engineer) — интеграция: атлас `--atlas-only`; реестр моделей; профиль места из `Biome` в `terrain.gd` (деревья, `terrain_look`, `scene_look`) и в конфиг домов; наборы пород, пояса, веса, палитры, тон полога по профилям; docs guide; кадры 5 мест в `/home/greg/deltaplan/build/screenshots/regional-veg/places/`.

## Границы
- Физику, модель воздуха, рельеф (`volcano_island` в том числе) — не трогаем; версию не выпускаем; GPU не мерим.
- Модуль takeoff-wind (физика старта) идёт параллельно — его файлы (`scripts/flight/`, старт) не трогаем.
- VRAM: новые текстуры по экранному размеру (листва 512², кора 256×512, импостер 256×512), сжатие + мипмапы (импорт как у существующих).
- Модели только свои (генератор) — лицензия своя.
