## Порядок и параллельность
1. **Волна 1 (параллельно):** 01, 04, 06 — разные файлы (01 — `tests/atmosphere/xc/`; 04 — `cloud_physics.gd`,
   `thermal_field.gd`; 06 — `wave_field.gd`). 04 и 06 обе правят `configs/atmosphere.json` — разные секции.
2. **Волна 2 (параллельно):** 02 и 05 после 01 (05 добавляет режим в `xc_pilot.gd` — 02 этот файл не правит).
3. **Волна 3:** 03 — последней: крутит числа пресетов по отчёту 02, когда физика 04 уже устоялась.

Стык с группой 3 (облака): все общие файлы `scripts/atmosphere/` — по списку владений в docs/plan/README.md;
при конфликте группа 2 идёт раньше. Веса источников термиков по поверхности — группа 4 (отдельной карточкой там).
