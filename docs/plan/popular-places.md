# popular-places — популярные места (старты дельтаплана из OSM)

## Цель
В меню «Полёт» рядом с «Выбрать на карте» — кнопка «Популярные места». Окно: страны (с числом мест) → места страны
(название, высота, при каком ветре работает старт, если известно); поиск по названию (в стране и по всем странам).
Выбор места = выбор точки старта по его координатам — тот же путь, что точка с карты (квадрат с центром в старте).

## Что есть (05.10.2026)
- `scripts/ui/flight_setup_screen.gd`: ряд `pick_row` — кнопка `setup_pick_on_map` (`_open_map`) и подпись точки
  `_pick_label`; выбор точки — `settings.pick_lat/pick_lon` (+ `_pick_elev_m = NAN`, `_update_pick_label()` сам
  запросит высоту Terrarium), так же делает «Недавние места» (`_select_recent`). Оверлей карты — `PanelContainer`
  на весь экран с полями 40 px.
- Загрузка: `settings.has_pick()` → `terrain.load_location_latlon(lat, lon, picked_location_size_km)`,
  старт — `StartPlacement.find_launch` возле точки (`scripts/game/game.gd`). Менять не нужно.
- На «Готово» точка попадает в «Недавние места» (`RecentPlaces.add`, имя — обратный геокодер OSM).
- Экспорт: `data/**` в сборке, `tests/*` — нет (тестовый файл мест кладём в `tests/`).

## Границы
- Координаты и названия — как в OSM (полнота разметки неравномерна, имена на местных языках, бывают пустые).
- Ориентация старта — только подпись; на ветер и выбор склона в этом модуле не влияет (идея на будущее —
  ветер по умолчанию «в старт» по ориентации).
- Высота в списке — `ele` из OSM (м над уровнем моря); подпись точки после выбора — Terrarium, как у карты.
