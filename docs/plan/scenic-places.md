# scenic-places — красивые места (код задач SCP)

## 1. Цель
Витрина: по каким местам игрок сразу видит, что игра может показать. Наборы известных природных пейзажей —
5–10 мест на страну для ~20–30 крупнейших стран. Не обязательно места полётов. Отдельная кнопка рядом
с «Популярными местами» в окне выбора места; игрок попадает сразу в воздух над видом.

## 2. Решения пользователя
- 2026-11-05: подпроект `game`.
- 2026-11-05: ~20–30 крупнейших стран, по 5–10 мест на страну; страны выбирает координатор (где есть что показать).
- 2026-11-05: старт — в воздухе над видом (крыло уже летит, высота и курс на лучший вид).
- 2026-11-05: только природные пейзажи — горы, каньоны, озёра, побережья, вулканы, ледники, долины;
  без культовых зданий и городов-достопримечательностей: здания по образцу мы не рендерим.

## 3. Что известно
- «Популярные места»: каталог стартов `data/places/hg_takeoffs.json` (`configs/ui.json → popular_places_path`),
  `scripts/ui/popular_places.gd`, `popular_places_window.gd`, `place_pick_row.gd`, `flight_setup_screen.gd`;
  контракт — docs/contracts/popular-places.md.
- Места строятся по координатам из открытых данных рельефа (docs/guide/terrain/relief.md); что игра рисует
  хорошо (рельеф, вода, лес, снег, облака) и что нет (здания по образцу) — guide.

## 4. Задачи
Карточки заводит координатор. Ориентир:
- список мест: координаты точки и курса вида, высота, страна, название RU/EN, почему красиво; проверка, что место
  природное и рельеф даёт вид (данные есть, не за краем карты);
- каталог (формат по образцу PP-К1) и окно/кнопка рядом с «Популярными местами»;
- старт в воздухе с заданной высоты и курса (переиспользовать, что уже есть в игре для старта в воздухе, если есть);
- проверка кадрами нескольких мест сборкой; guide, CHANGELOG.

## 5. Волны
Определяет координатор.

## 6. Условия остановки (шлюз)
- Список мест — показать пользователю до каталога в игре.
- Старта в воздухе в игре нет и его нужно делать с нуля — шлюз с вариантами.
