# Вопросы

Формат: вопрос → варианты → **что выбрано сейчас (recommended)**. Ответь прямо под вопросом — поменяю, если нужно.
Вопросы без выбора помечены **⏳ ЖДЁТ ОТВЕТА**.

## Проект
1. **Язык: GDScript или C#?** GDScript проще, горячая перезагрузка, без .NET-сборки. C# быстрее на тяжёлой математике.
   → **Выбрано: GDScript.** Если физика/рельеф упрутся в скорость — отдельные горячие места вынесем.
2. **Рендер: Forward+ / Mobile / Compatibility?** Для ноутбука без видеокарты Forward+ может быть тяжеловат.
   → **Выбрано: Forward+**, замерим FPS на встроенной графике; при проблемах — Mobile.

## Приборы и звук вариометра (instruments)
1. **Кривые звука вариометра (частота/темп/скважность).** Варианты: таблица тонов XC Tracer по умолчанию (400→1800 Гц, 1,7→6,7 писка/с на 0,1→10 м/с); более «быстрый» Flytec-подобный писк (темп растёт круче); свой профиль папы.
   → **Выбрано: таблица XC Tracer** (`configs/audio.json → climb_tones`, формат как в конфиге XC Tracer — папа может вписать свой профиль из прибора).
2. **Звук снижения.** Варианты: непрерывное гудение; прерывистый длинный тон (как у части Flytec); выключен.
   → **Выбрано: непрерывное гудение ниже −2,5 м/с, 400 → 220 Гц** к −10 м/с (`sink_tones`, скважность 100 %).
3. **Инерция датчика и окно среднего.** Варианты: τ 0,5 / 0,7 / 1 с; среднее 20 / 25 / 30 с.
   → **Выбрано: τ = 0,7 с, среднее за 25 с** (интегратор). Звук берёт то же отфильтрованное значение, что и цифры.
4. **Ориентация карты на приборе.** Варианты: север вверху; по курсу (track-up).
   → **Выбрано: север вверху** — при кружении в термике карта не крутится. Переключается `map.orientation`.
5. **«Расстояние» на приборе (FR-25).** Варианты: от точки взлёта по прямой; пройденный путь; до следующего пункта.
   → **Выбрано: от взлёта по прямой** (как «Dist Takeoff» у Flytec). До пункта добавим с маршрутным режимом (FR-35).
6. **Подписи на приборе.** Варианты: русские сокращения (ВАРИО, ВЫСОТА, НАД ЗЕМЛ, ВОЗД, ПУТЕВ, КАЧ); английские как на реальных приборах (Vario, Alt, AGL, Speed, L/D).
   → **Выбрано: русские** (NFR-4), через `tr()` — английский добавится переводом.

## Рельеф (terrain)
1. **Район тестовой локации «Алтай».** Варианты: Манжерок / Малая Синюха + Горно-Алтайск; Чемал; Курайский хребет (Чуйский тракт, выше и суровее, но далеко от туристических стартов).
   → **Выбрано: Манжерок — Горно-Алтайск** (центр 51.87° N, 85.87° E, 40×40 км + фон 160 км). Здесь реально летают (старт на Малой Синюхе у курорта), высоты 250–1380 м. Если папа летает в другом месте — скажи координаты, локация пересобирается одной командой.
2. **Стартовые площадки.** Точных координат стартов в открытых источниках не нашёл, поставил по рельефу:
   Малая Синюха — западный старт (51.8212, 85.8536, курс 276°), вершина Синюхи — восточный склон (51.8322, 85.8747, 115°), Тугая над Горно-Алтайском — южный склон (51.9710, 85.9421, 150°; как старт — допущение).
   → **Выбрано: эти три.** ⏳ Хорошо бы, чтобы папа подтвердил/поправил реальные точки и курсы (`configs/locations/altai.json → start_sites`).
3. **Источник высот.** Варианты: Copernicus GLO-30 (лучше, но GeoTIFF — только офлайн-подготовка); Terrarium (хуже, но грузится в игре).
   → **Выбрано: Copernicus для встроенной локации, Terrarium для выбора точки на карте в игре.**
4. **Лес в данных.** Copernicus и SRTM — модели поверхности: в лесу «земля» = верх крон (+15…25 м). Варианты: оставить (AGL над лесом = до крон — для пилота это и есть опасная высота); вычитать высоту леса по карте лесистости (нет открытой подходящей).
   → **Выбрано: оставить + лёгкое сглаживание**, 3D-деревья утоплены в поверхность.
5. **Карта для выбора места.** Варианты: OSM tile.openstreetmap.org (жёсткая политика, риск блокировки); OpenTopoMap (волонтёрский сервер); отмывка рельефа из тех же тайлов высот; свой векторный сервер (martin).
   → **Выбрано: отмывка из Terrarium сейчас** (`MapPicker`), векторная карта через martin — позже.
6. **Направление солнца.** Сейчас статично из `configs/world.json → sun` (азимут 200°, высота 52°, ~14 ч летом). Варианты: статично; считать по дате/времени/широте и двигать днём.
   → **Выбрано: статично** для MVP. Если атмосфере нужно время суток (жизненный цикл термиков) — добавим расчёт солнца по времени.

## Звуки (sounds)
1. **Откуда брать файлы freesound: HQ-превью или оригиналы?** Оригиналы (wav/flac) требуют логина или API-ключа (OAuth2). HQ-превью (Ogg ~140–190 кбит/с) доступны без логина, лицензия у них та же. Варианты: превью; оригиналы через ключ API; оставить превью и заменить позже.
   → **Выбрано: превью.** Для игры качества хватает: всё равно сжимаем в Ogg. Если дашь ключ freesound API, `fetch_candidates.py` можно доработать и перекачать оригиналы — обработка повторится одной командой.
2. **Поток воздуха: записи или синтез?** Варианты: только записи ветра (pitch/громкость); только процедурный синтез; гибрид.
   → **Выбрано: гибрид, основа — процедурные периодические лупы** (шум обтекания ∝ V по Струхалю, бафтинг, эоловы тоны тросов) с `pitch_scale`/громкостью от воздушной скорости, плюс две записи для «живости» на малой и большой скорости. Алгоритм и ключи для `configs/audio.json` — в `docs/research/sounds.md` §3.
3. **Генеративные модели (Stable Audio Open, AudioLDM 2).** AudioLDM 2 — CC-BY-NC-SA, не подходит. Stable Audio Open — Community License (бесплатно при доходе < 1 млн $), но модель на HF закрыта (нужны логин и токен).
   → **Выбрано: не использовать.** CC0-записей и синтеза хватило, шумовые текстуры лучше синтезировать.
4. **Sonniss GDC bundles** (royalty-free, но «сырые» файлы нельзя распространять, бандлы по 7+ ГБ). Если репозиторий будет открытым, исходные файлы из бандлов в него класть нельзя.
   → **Выбрано: не использовать**, пока есть CC0-альтернативы.
5. **Атрибуция CC-BY.** Два файла под CC-BY 4.0 (мягкая посадка — J.Zazvurek, удар трубы — spoonbender): их нужно упомянуть в титрах или «Об игре». Варианты: сделать экран «Об игре» с атрибуцией; заменить эти два файла на CC0 (например, 342535 Medium Thud, Kenney impactMetal).
   → **Выбрано: оставить и указать в «Об игре»** (текст готов в `assets/sounds/LICENSES.md`). Экран делает интегратор.
6. **Проверка на слух.** Кандидатов я отбирал по спектрограммам, огибающей, статистике клиппинга и описаниям авторов. Послушать не мог.
   → ⏳ **ЖДЁТ ОТВЕТА:** послушай `tools/sounds/preview/airflow_sweep_demo.ogg` (поток 20→90→20 км/ч) и `assets/sounds/*`. Если что-то звучит фальшиво (особенно свист тросов и синтетическое трепетание), скажи — поправлю параметры в `synth_wind.py` или выберу другой файл из кандидатов в `docs/research/sounds.md`.
