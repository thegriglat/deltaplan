# AP-11. Переносятся ли границы фаз с идеальных форм на рельеф с эрозией

## Вывод

Перенос частичный (`transfer = partly`). Доля порогов на эрозии, попавших в объединённый ДИ идеальных форм (H = 0,
h/z_i = 1, 9 линий), — 0,60 по 8 параметрам, у которых есть ≥ 3 идеальных порога и ≥ 4 засчитанных рельефа из 6.
Хорошо переносятся порог подъёма у склона (`sl_area_km2`: 5 из 6 в ДИ, сдвиг −0,07 декады) и средняя скорость
(`f_speed50`: 6 из 6, −0,09). Плохо переносятся ротор и обратное течение (`f_rev25`, `lee_rev_area25_km2`: 0 из 2 и
1 из 4, сдвиг −0,2…−0,33 декады, ротор появляется при меньшем Fr), застой (`f_stag25`: 0 из 3, +0,15 декады, выше)
и «слой смешения» (`lee_du_rel`: 0 из 3). Главное отличие: на идеальных формах переходы резкие (w ≈ 0,003–0,02 декады
у сходимости, застоя, поворота, обратного течения), на эрозии они размытые (w ≈ 0,05–0,12 декады): рельеф
из многих гребней с разной высотой переходит фазу не в одной точке Fr, а по очереди. Для классификатора: границы
скорости и подъёма можно брать с идеальных форм (с запасом ≈ ±0,1 декады), границы ротора/застоя — только с шириной
перехода и сдвигом (ниже по Fr для ротора), не как острый порог.

«Fr всей области» (по перепаду рельефа, как в таблице) упорядочивает не хуже местного Fr: медианный разброс lg Fr_c
между рельефами 0,114 декады при Fr всей области против 0,107–0,146 при местном Fr (перепад до гребня в окне
R = 1,5/3/6 км, медиана/p90 по гребням). Выигрыш лучшего варианта (R = 3 км, медиана) несущественен
(4 из 6 параметров лучше, на 0,01 декады), остальные варианты хуже. Местный Fr не оправдывает усложнения.

## Оговорки

- Всего 6 рельефов, на каждый порог — 2–6 засчитанных, ДИ идеальных объединяется по 1–9 линиям: «попал в ДИ» — слабый
  критерий для параметров с одним идеальным порогом (`lee_du_rel`, `drift_rel`, `wstd600_rel`) и широкий у `f_speed50`/`sl_w_max`
  (ДИ 0,1–5): попадание почти гарантировано. Порог 0,7/0,3 для yes/no — условность.
- Ширины на эрозии без шума стартов (второго старта на ERODED нет): класс резкая/плавная по w, не по скачку. Ширина
  включает разброс между гребнями одного рельефа и вносится не гладким переходом одной фазы.
- «Идеальные» — только линии H = 0, h/z_i = 1 (уступ, хребет, холм × 3 уклона), а крутизна идеальных (s = 0,15–0,5) выше p95 эрозии
  (6–15°, tg 0,11–0,27); сдвиг может быть эффектом разной крутизны, не эрозии как таковой — отделить нельзя.
- Местный перепад определён по сетке решателя 400 м; окно 1,5 км — 8 клеток; метрики гребней чувствительны к порогу
  (гребень — локальный максимум окна с перепадом > 0,25 максимального). Это одна из возможных оценок, не единственная.
- Параметр порядка «подгонка только сошедшихся» оставляет у больших рельефов (Fr 0,4–0,5 и выше) лишь 18–23 точки; пороги ≤ 0,45 — штиль (U10 < 1 м/с) и считаются отдельно.
- Термики на ERODED не считаются (H = 0). Перенос порогов термиков не проверяется.
- Идеальные пороги взяты из `analysis/AP-8/summary.json` текущей версии (после слияния).
