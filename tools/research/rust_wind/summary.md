# RW-6a — вывод

- В `picard_rs` нет сборщика случая (`AirCase.prepare` + `K_SETUP`), грубого старта, заморозки колонн, фаз, окон, `WindField`, оркестровки; `adv2` в игре нет.
- Фазы и заморозка определяют поле при слабом ветре: отложить без расхождения T1 нельзя; порядок — Пикар без фаз, потом фазы.
- Погода для поля — подмножество (~600 строк GD) в RW-6; RW-12 раньше не поднимать. Пробел W5: режим притока `start|inflow`.
- Окна: 0,56× и 0,99× области; сдвиг 50 м — 2,7–4,7 с (8 потоков), 8–14 с (2); рекомендация — перенести последним хвостом, отключаемым.
- Загрузка на CPU ≈ 20–30 с (8 потоков), 70–100 с (2) без запечённого поля.
