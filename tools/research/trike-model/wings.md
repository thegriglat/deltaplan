# TK-13: крылья дельталётов — параметры с источниками

Данные: `tools/research/trike-model/wings.json` (version 1; каждое число `{value, src}`; нет данных — `"н/д"` с указанием, где искали;
расчёт — `src` начинается с «вывод»). Крыло не строилось. Единицы: м, м², град, кг, км/ч, Н. Узлы/мили/fpm переведены (1 kt = 1,852 км/ч;
1 mph = 1,609344 км/ч; 1 fpm = 0,00508 м/с).

## Что выведено и как (границы применимости)
- **Хорды** (root/tip): в источниках нет. `R + T = 2S/b` (трапеция), `T/R = 0,25` — типичное отношение для топлесс/кингпостных крыльев игры
  (`glider_params.json`: 0,23–0,26 при носе 120–130°). Погрешность хорд ≈ ±10 %; использовать только для генерации формы, по площади/размаху подгонять
  как `build_gliders.py` (area справочно). Реальный планформ с изогнутой задней кромкой даёт другие хорды; при появлении руководства — заменить.
- **Статическая тяга iXess** ≈ 2070 Н (диапазон 1790–2330 Н при FM 0,55–0,75): идеальный диск `T = (2ρA)^(1/3)(FM·P)^(2/3)`, D = 1,70 м,
  P = 61,7 кВт (момент 128 Нм по Rotax, принят постоянным до 4600 об/мин), FM = 0,65 — допущение. Измеренной тяги нет; для проверки по
  тесту `docs/plan/trike.md` (≈15 %) нужен паспорт (например, BMAA AAN или руководство Air Creation).
- **Трим iXess**: 74 км/ч — только прокси (пример ASI-плакарда HADS: glide 40 kt); реальная трим-скорость и диапазон не указаны.
- Vne у Aeros: страница Profi TL — 140, страница Aeros-2 — 130 км/ч (ограничение аппарата); Vs P&M «38 mph (48 km/h)» на сайте и в Wikipedia — ошибка
  перевода, правильно 61,2 км/ч (TADS).
- Расхождения: масса крыла iXess 53 кг только из Wikipedia (WDLA), паспорта нет; Wikipedia Tanarg — 9,85 м, 15,1 м², AR 6,4; процент двойной обшивки iXess
  (90 %) — по пересказу Wikipedia, не перепроверен по первоисточнику.
- Модель-«маятник»: при MTOW 450 кг на крыло 13–15 м² нагрузка 30–35 кг/м²; HADS разрешает экипаж 55–120 кг на место.

## Не найдено
Углы носа GT450; крутка, латты, профиль, высота кингпоста — ни у одного (в открытых руководствах нет); координаты ЦМ тележки относительно точки подвески
(TADS: «не критично», датум — ось носового колеса); измеренная тяга/тяга от скорости; диаметр винта и тяга Aeros-2; расход iXess. Искали: BMAA HADS/TADS
(Quik, QuikR, Airborne Edge XT — два последних PDF нечитаемы после извлечения текста), Wikipedia, сайты P&M/Aeros, DULV (Kennblatt Aeros-2/Profi TL не найден).
Не охвачены (нет доступных данных): Airborne Streak/Wizard, North Wing, «Фрегат», Aeros Stranger — читаемых паспортов не найдено.

Оговорки. (1) «Трим» у Air Création — «cruising speed» при нейтральной штанге (по сноске страницы Tanarg neo), это допущение. (2) Страницы AC указывают редуктор
«2,43:2»/«2,43:3» — опечатки, принят 2,43:1 (HADS Tanarg). (3) У Samson две цифры в ячейках (пустой вес, Vne) — по двум двигателям, но метки склеены; выбрана первая;
Thor 303 — двигатель-кандидат, мощность относится к двигателю Polini, не к паспорту Samson. «Motor thrust» в таблице LM — склеенные метки, не тяга. Samson —
лёгкая пешая тележка (1 место, MTOW 270 кг), для модели трайка по массе/мощности не сопоставим с остальными. (4) Тяга QuikR — перенос оценки iXess (тот же двигатель и D),
не измерение. (5) ЦТ относительно точки подвески не публикуется ни у одного; Air Création и P&M даже не называют положение подвески. Старые «н/д» (винт Aeros-2,
расход iXess, ЦТ) новыми источниками не закрыты.
