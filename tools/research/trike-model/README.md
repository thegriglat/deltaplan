Результат: `tools/blender/trike_params.json` (контракт TK-K1 v1). Оси JSON — Blender (+X вправо, +Y вперёд, +Z вверх), начало — точка подвески `HangPoint`.

- Замер глаз: `cp tools/research/trike-model/measure_eye.gd tests/game/test_tk1_eye.gd` (временно, не коммитить),

## Замер глаз (eye_measured)
Камера «Сидячей позы» (eye_mode back_hidden: PilotHead + back_offset_m 0.3 м назад) минус `HangPoint`, в базисе визуала пилота, автопилот, 16 отсчётов по 1 с в установившемся полёте. Средние (Blender, м):
- training: (-0.061, 0.352, -1.144)
- apogee: (-0.087, 0.390, -1.122)
- в осях горизонта (без тангажа крыла) значения плавают на +-0.3-0.5 м по y и z из-за фугоиды автопилота; поэтому берутся оси планера. x плавает +-0.2 м от крена и в JSON принят 0 по симметрии (среднее -0.06...-0.09 — след крена, не смещение).
- Голова без смещения камеры (PilotHead): training (-0.06, 0.65, -1.14), т.е. камера на 0.30 м позади глаз модели; по контракту `seat.eye` = камера.

## Посадка (seat)
Спинка 15 град назад; туловище от таза до C7 0.53 м (рост сидя по NCSU) и голова вертикально (C7→глаза 0.20 вверх, 0.08 вперёд) дают бедро `hip` (0, 0.409, -1.856). Подушка на 0.10 м ниже бедра (seat_pan, 0.45 x 0.42), бедро на 8 град вверх к колену (0.43 м), голень 0.45 м под 50 град вниз вперёд (сгиб колена 58 град >= 20), голеностоп 0.09 м над подошвой; подошвы (+-0.15, 1.174, -2.231) над землёй на 0.27 м; педаль под правой стопой; кисти на бёдрах (y 0.70) — расстояние от плеча 0.54 м при длине руки 0.63 (локоть чуть согнут). Подушка на 0.544 м над землёй — в диапазоне типичных 0.5-0.6 м.

## Расхождение с реальной посадкой
Реальный сидящий 1.78 м: глаза = подушка (0.55-0.60 м) + 0.79 м (0.80-0.82 над жёстким сиденьем, минус сжатие подушки) = 1.34-1.39 м над землёй, т.е. -1.16...-1.11 м от подвески (hang_height 2.50). Замер в игре -1.144: Δz по оси z не более 0.04 м. Вперёд от подвески у реального трайка голова переднего пилота примерно +0.3...+0.6 м (оценка по схеме "пилот перед мачтой", источника с числом нет): Δy -0.25...+0.05 м. Δx = 0. Все Δ < 0.3 м; seat строится по замеру. Оговорка: в игре пилот висит на крыле в позе "prone" (подвесная модель), поэтому совпадение по высоте — следствие подбора hang_height/seat_height, а не независимая проверка.

## TK-6: кадры с пилотом и проверка посадки (модель v2)
Воспроизведение (Blender 4.3.2, Cycles на GPU через CUDA, ~1 мин; первый запуск ~7 мин — JIT-компиляция ядер CUDA в кэш):
- кадры: `blender --background --python tools/blender/render_trike.py` — 4 кадра без пилота (`trike_front34/side/rear34/top`), 5 с пилотом (`pilot_front34/side/rear34/front/top`) и крупно посадка (`seat_closeup_side/front/feet`) в `/home/greg/deltaplan/build/screenshots/trike-model` (PNG 1600x1000, 256 выборок, без шумодава: в сборке нет OIDN, OPTIX-устройство не найдено; ключи `--out`, `--only trike|pilot|closeup`, `--pilot`). Видео не делается (решение пользователя 2026-10-22), старый `prop_spin.mp4` не тронут. Кадры в репозиторий не коммитятся (локально).
- посадка: `blender --background --python tools/research/trike-model/fit_check.py` -> `fit.json` (см).
Метод `fit_check.py`: вершины `PilotBody` и `Helmet` после depsgraph (поза sit; вершины, привязанные к костям кокона/фала `Pod*`/`Strap` с весом > 0.5, схлопнуты контрактом TK-K3 и не учитываются) против островов связности `Trike_LOD0` и `Engine_LOD0` (вершины слиты на 1e-5; замкнутыми считаются острова, где каждое ребро принадлежит двум граням: 107 из 118). Вершина внутри — по чётности пересечений луча (3 направления, большинство); глубина — расстояние до ближайшей поверхности. Подошвы и седалище тонкими пластинами (подножка 1 см) не ловятся чётностью, поэтому дополнительно: заглубление = (верх опоры) − (низ подошвы/седалища) по лучу вниз в пределах контура опоры. `max_penetration_cm` = максимум из двух. Зазор спинки — расстояние вершин туловища до передней плоскости острова спинки по её нормали (15 град). Глаза: узел `Head` против `seat.eye`.
Результат (см, по модулю; со знаком — `*_signed_cm`, < 0 — внутри):
| величина | значение | порог |
|---|---|---|
| max_penetration_cm | 2.63 (внутри замкнутых деталей 1.00; подошва L в подножку 2.63, R 2.08, седалище в подушку 0.89) | <= 2 — НЕ проходит |
| seat_gap_cm | 0.89 (седалище на 0.89 см ниже верха подушки) | <= 3 |
| back_gap_cm | 0.06 | <= 3 |
| foot_gap_l/r_cm | 2.63 / 2.08 (подошвы глубже верха подножки/педали) | <= 3 |
| eye_err_cm | 0.05 | <= 2 (K3) |
| hip_err_cm | 1.31 | <= 3 (K3) |
Допущения: проверяются вершины, не рёбра; слабое место — подошва: низ подошвы -2.202 м против верха подножки -2.16 м (подножка толщиной 1 см), т.е. подножка частично внутри ботинка. Модели не подгонялись (чужой scope TK-2/TK-8).
