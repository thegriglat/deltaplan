# trike-model / TK-7: данные v2 (винт, двигатель, тандем, бак, трубы)

Результат — `tools/blender/trike_params.json` (TK-K1 v2). Тест: `godot --headless --path . res://tests/run_tests.tscn -- --filter=trike_model_k1`.
Образцы: `ref/bizorg_trike_1.jpeg` (тандем), `ref/fregat_big.jpg` (https://motodeltaplan.narod.ru/images/podveska/fregat_big.jpg — рядный 2-тактный 582-подобный двигатель, двухлопастный узкий винт, заднее сиденье выше, канистра под ним).

## Двигатель и винт (согласованы)
Выбран Rotax 582 UL DCDI: 64.4 л.с. при 6500 об/мин, два цилиндра в ряд, ЖО, бор 76 мм (https://en.wikipedia.org/wiki/Rotax_582); редуктор C 3.47:1 — именно такая связка на трайке в DULV 105/91-8.7 (https://www.dulv.de/kennblatt/Trike/10591-871.pdf). Типоразмеры редукторов B/C/E (https://motive.aero/engine-details/rotax-582ul/317; масса и вылет — IM 582 UL, 72-00-00, https://www.rotax-owner.com/pdf/IM_582ULSeries_Ed1_R0.pdf).

Двухлопастный винт на 582 в листах DULV не найден; число лопастей 2 — по фото Fregat и решению пользователя (контракт допускает 3). Вывод для модели: D = 1.80 м (длиннее прежних 1.727 м), хорда наибольшая 0.14 м, у законцовки 0.11 м (суммарная ширина 2×0.14 < 3×0.12 — лопасть уже), ступица/кок 0.17 м. Обороты: крейсер двигателя ≈ 5500 → винт 5500/3.47 ≈ 1590 об/мин; скорость конца лопасти π·1.8·1590/60 ≈ 150 м/с (ниже M 0.45) — правдоподобно для композитного винта. Обороты винта по Rotax OM 582 UL Ed3 (https://www.rotax-owner.com/pdf/OM_582_UL_Series_Ed3_R0.pdf): холостой 2000 → `prop_rpm_idle` 576; взлётный 6800 (до 5 мин) → `prop_rpm_max` 1960 (конец лопасти ≈ 185 м/с); продолжительный максимум 6500 → 1873. `prop_spin_period_s` = 1.0 (клип prop_spin). Максимум в стоянке на листе C 3.5:1 — 1750 об/мин.

Габариты двигателя (0.50×0.50×0.45) — оценка: открытых габаритных чертежей 582 не найдено (в Wikipedia и на motive.aero размеров нет); цилиндр 0.13 м = 76 мм бор + оребрение; выхлоп 0.10 м — оценка.

## Тандем и бак
- Заднее сиденье выше переднего на 0.20 м (по фото Fregat, масштаб по переднему колесу 14" = 0.356 м: 0.15-0.25 м); позади переднего, спинка 15° касается мачты (мачта на z = −1.2 — y ≈ −0.39, верх спинки там же). Подножки заднего — по бокам переднего сиденья (x ±0.30, выше на подъём; смещение стопы от подушки — как у переднего).
- Бак: Airborne XT912 — 70 л (https://www.airborne.com.au/pages/ml_xt912_specs.php). Габарит 0.32×0.45×0.46 м = 66 л (скруглённые рёбра отнимают ≈ 5%); высота 1.44 ширины (≥ 0.6). Под подушкой заднего (верх бака на 0.10 м ниже), просвет до земли ≈ 0.19 м; горловина сбоку сверху.
- Диаметры труб (киль 0.050, мачта 0.050, подкос 0.045, рама 0.040 м) — по фото Fregat (масштаб по переднему колесу), ±30%.

## Допущения и границы
Прототип — композит (габариты Airborne/Tanarg, двигатель и винт — трайк с 582 по Fregat); модель — внешний вид, не расчёт. Все числа с пометкой «вывод: оценка» — без прямого источника. Высота оси винта 1.30 м выбрана так, чтобы верх диска оставался на 0.30 м ниже подвески. Заднее сиденье рассчитано от текущего `seat` (TK-2 может сдвинуть переднее — пересчёт на координаторе).
Лицензии: числа — факты из открытых страниц (DULV, Rotax IM, Wikipedia CC BY-SA, Airborne, motive.aero); файлы и фото не копировались.
