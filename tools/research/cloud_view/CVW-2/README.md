# CVW-2: «инверсия» цвета облаков на кромке облака

## Вывод
Причина — **мгла `CloudWhiteout` включает туман окружения Godot, и от него зависят две вещи**:
1. **Небо** (`scripts/game/cloud_whiteout.gd::apply`): `fog_density` становится > 0 уже при `amount ≈ 0,005` (density 0,013). Экспоненциальный туман Godot для неба
   (бесконечная дальность) насыщается при любой плотности > 0 и красит небо на долю `fog_sky_affect` (0,1, в `configs/world.json → fog`) цветом тумана
   `fog_light_color` (0,55; 0,67; 0,86; аэроперспектива 0,5). Скачок: небо (G) 0,133 → 0,273 за 12 м высоты (час 13), 0,185 → 0,278 (час 18) — ступенька, не плавный рост.
2. **Другие облака** (`scripts/atmosphere/cloud_layer.gd::_update_light`, строки ≈ 530–538): если `env.fog_enabled`, дымка облаков (`fog_color`, `fog_density`
   шейдера `cloud_raymarch_cs.gdshaderinc`, ≈ строка 388: `fog = 1 − exp(−dist·fog_density)`; `col = col·(1−fog) + fog_color·alpha·fog`) берётся из **окружения**
   (`fog_density` мглы до 0,06 1/м — это «50 м видимости», для облаков за километры = полная заливка цветом тумана), иначе — из `atmosphere.json → fog_density_fallback`
   (4e-05) и `fog_color_fallback`. Игра включила туман мглой → дымка облаков переключается со слабой (4e-05, (0,66; 0,74; 0,86)) на сильную цвета тумана:
   белые облака (0,40; 0,45; 0,52) уходят в синий (0,30; 0,42; 0,575) и к цвету неба — контраст облако/небо падает с (0,34 по R) до (0,10), цвета «меняются местами» по
   каналу R: облака темнеют по R и синеют, небо светлеет. Обновление `_update_light` идёт раз в 1 с (`_light_acc > 1.0`), поэтому дымка облаков меняется ступенями,
   с запаздыванием до секунды относительно неба.
Мгла нужна по смыслу внутри облака; здесь её запускает **грубое поле** `cloud_density_at` (cover × параболический профиль слоя, `rust/dp-air/.../field.rs::density_at`):
оно ненулевое по всей глубине слоя (cover 0,23–0,45 → density 0,2–0,6), без шума и без привязки к видимой форме облаков, поэтому «внутри облака» срабатывает уже при пересечении основания слоя
(y = base_msl) задолго до видимого клуба — кромки по горизонтали у поля нет (фон `bg_cover`), есть только вертикальные границы слоя.

Доказательство разделением (час 13, вертикальный проход через основание, камера смотрит вбок):
| режим | небо x_bg (G) на кромке | облака x_other (R,G,B) на кромке |
|---|---|---|
| `nowhiteout` (мгла не вызывается) | плавно 0,133 → 0,136 | (0,402; 0,451; 0,521) без изменений |
| `game` (как в игре) | **0,133 → 0,273 (−26 м), 0,312 (−14 м)** | **(0,402; 0,451; 0,521) → (0,353; 0,441; 0,564) → (0,300; 0,419; 0,575)** |
| `fogon` (fog_enabled=true, параметры исходные, плотность 0) | без скачка (0,131 → 0,135) | без изменений |
| `cloudfogfix` (как game, но дымка облаков остаётся «по умолчанию») | **скачок остаётся: 0,133 → 0,269** | **без изменений (0,405; 0,455; 0,528)** |
Итог: скачок неба — от `fog_density > 0` (не от самого `fog_enabled`); смена цвета облаков — от переключения дымки облаков на туман окружения. Оба убираются, если мгла
не трогает эти параметры у неба/облаков. Кандидаты (в), (г) — экспозиция, темпоральное накопление — в нашем режиме без изменений: `nowhiteout` показывает плавный ход.

## Что измерено
Стенд `tools/shots/cloud_view_edge_shot.gd` (+.tscn, +.uid): ongudai, час 13 и 18 (вечерний), атмосфера прокручена на 600 с и заморожена; камера идёт по прямой
со скоростью 60 м/с (dt кадра 1/60 с), мгла обновляется каждый кадр как в `game.gd::_process` (`_whiteout.update`/`apply` на `sky.world_env.environment`),
`density_cam` = `air.cloud_density_at(cam)`. Проходы: `h` — горизонтальный на высоте середины слоя (все 2400 м внутри слоя: у грубого поля нет горизонтальной кромки,
`x_edge_dist_m` ≈ 10⁴), `v` — **вертикальный через основание слоя** (base_msl 2774 м, вход при density > 0,05), камера смотрит вбок (yaw 45°, pitch 2°) на другие облака.
Режимы: `game`, `nowhiteout`, `fixedfog` (запланирован, не снят), `fogon`, `cloudfogfix`.

Колонки CVW-К1 + доп. (`x_`): `x_mode` (режим_путь), `x_s_m` — путь вдоль линии, м; `x_edge_dist_m` — расстояние до границы плотности 0,05 по линии
(− снаружи, + внутри); `x_in_density` (0/1); `x_own_frac` — не определено (пусто); `x_mask_frac` — доля кадра (сетка 192×108), где кадр с облаками отличается от кадра без облаков
более чем на 0,01 (линейные значения); `x_other_*` — средний линейный цвет этих пикселей (облака; при камере внутри слоя пиксели «облако» и «ближняя дымка» не различимы,
отдельного «чужого облака» не выделено); `x_other_noclouds_luma` — яркость тех же пикселей в кадре без облаков; `x_bg_*` — средний цвет остальных (небо/рельеф);
`x_fog_height_density`, `x_nc_luma_mean` — средняя яркость кадра без облаков. PNG — вне репозитория: `/home/greg/deltaplan/build/screenshots/cloud-view/CVW-2/` (`*_nc.png` — кадр без облаков).
`cloud_top_msl` = base_msl + depth столбца растра (`depth` принят за мощность, м); `cover_cam` — cover столбца растра (ближайший столбец), не билинейный `CloudField.sample`.

## Варианты правки (код игры не менялся)
1. **Не включать Godot-туман у неба и не подмешивать его к дымке облаков**: `cloud_layer._update_light` брать `fog_*` не из `env`, а оставлять `*_fallback` (или отдельный параметр
   «дымка облаков»), а мглу в облаке рисовать отдельным слоем/шейдером (экран) вместо `Environment.fog_*`. Эффект: пропадают оба скачка; риск — мгла перестаёт скрывать рельеф и небо
   так же, как раньше, придётся её воспроизвести (прибор на трапеции, FR-21).
2. **`fog_sky_affect` во время мглы вести плавно от 0 к 1** (сейчас base 0,1 даёт ступеньку на любой плотности > 0) и ввести порог: `apply` не включать туман, пока `amount` < ~0,05.
   Эффект: ступенька неба меньше (~+0,01 вместо +0,14), смена цвета облаков откладывается; риск — слабая мгла на кромке слоя без изменений неба.
3. **Мгла по реальной форме облака**: подавать в `CloudWhiteout.update` плотность из того же поля, что рисует шейдер (с шумом), а не грубое `cover × профиль`; тогда мгла включается
   у видимого клуба, а не на основании слоя. Эффект: изменение появляется только в самом облаке; риск — стоимость выборки плотности (Rust, горячий путь) и расхождения с видом для края поля.

## Допущения и ограничения
- Поле плотности для мглы гладкое (`field.rs::density_at`); «кромка облака» в этом смысле — граница слоя по высоте и пороговое значение 0,05 вдоль линии; видимые клубья (шейдер) шире/уже.
- Цвета — линейные, из PNG (sRGB → linear), по сетке 192×108; «маска облаков» — разность с кадром без облаков (второй SubViewport без компоситора), порог 0,01.
- Освещение/экспозиция/тональная кривая камеры в `nowhiteout` плавные — как причина не подтверждены. Темпоральное накопление не исследовалось отдельно (серия идёт кадрами подряд, без телепортов).
- Часть ранних серий `m13.csv`/`m18.csv` (горизонтальный проход `*_h`) и первый заход `mv*` сняты до замены `libdp_air_tune.so` (09:05, дополнение координатора); повтор вертикального
  прохода `game` (`mv13/mv18`) и `nowhiteout`/`cloudfogfix` (`mw*`) — уже на новой библиотеке: числа `game`/`nowhiteout` в `mv13` и `mw13` совпадают до 3-го знака. Горизонтальные `*_h` — только как справка.
- Режим `fixedfog` в стенде есть, но не прогонялся; `cloudfogfix` на час 18 — 5 кадров (прогон оборван по таймауту), на час 13 — 25.
- FPS/время кадра не измерялись. Первые 90 кадров каждого режима — прогрев (мгла наращивается до начала записи).
