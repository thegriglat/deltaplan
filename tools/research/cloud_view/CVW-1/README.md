# CVW-1: белёсый экран выше некой высоты в ясном воздухе

## Воспроизведение
Стенд `tools/shots/cloud_view_climb_shot.gd` (по образцу cloud_cut_shot/haze_shot; код игры не менялся).
Камера ставится в ясный столбец поля облаков, поднимается по 16 высотам AGL, кадры 960×540.
```
XDG_DATA_HOME=~/.cache/dp-xdg/cloud-view-CVW-1 .dpcli/dpcli lock cpu CVW-1 -- godot --path . \
  --audio-driver Dummy --resolution 1920x1080 res://tools/shots/cloud_view_climb_shot.tscn -- \
  --out=/home/greg/deltaplan/build/screenshots/cloud-view/CVW-1/main --csv=measures.csv \
  --hours=13,18 --pitches=-3,-30 --temp=20 --wind=1.7 --air_s=5400 --variants=main,nowo,nohaze,noclouds,bare
python3 analyze.py measures.csv summary.json > tables.md
```
Первый запуск в копии: `godot --headless --path . --import`; нужен кэш рельефа (`terrain_cache` скопирован из ~/.local/share/Deltaplan) и `addons/dp_air/bin/*.so`.
`measures.csv` собран из двух запусков (main+nowo; nohaze+noclouds+bare, на пересобранном libdp_air_tune.so): на пересечении (5 кадров nohaze в обоих) luma и whiteout совпадают до 4 знаков — замена библиотеки результат не меняет.
Кадры (вне репозитория): `/home/greg/deltaplan/build/screenshots/cloud-view/CVW-1/main/` (не открывались, проверка числами).

## Условия
ongudai, старт 13 ч (кадры 13 и 18 ч), +20 °C, ветер 1,7 м/с, время атмосферы 5400 с. При +31 °C/5 м/с поле покрывает всё: cover > 0,05 в 9216 из 9216 ячеек, ясного столбца нет — выбран слабый вариант погоды. Даже тут cover мин. 0,034, ср. 0,30: чисто ясных столбцов нет вообще.
Столбец (2200, 4200), земля 868 м, cover_cam 0,097, основание 1924 м MSL, верх соседних облаков 3741, макс. cover в 6 км 0,67; верх дымки 2024 м MSL.
Допущения: cover_cam/основание/верх — билинейно по растру `cloud_raster()` (как CloudField.sample внутри сетки); density_cam — `Atmosphere.cloud_density_at`; мгла — как game.gd (`CloudWhiteout.update` + `apply`, 40×0,1 с до установившегося значения). В кадре нет игрока и интерфейса. Одна погода, одно место, один столбец.

- (а) CloudWhiteout: в слое отключение мглы возвращает кадр (0,323 → 0,236, std 0,056 → 0,120). Единственное сильное «побеление».
- (б) дымка Environment/haze.gdshader: вклад +0,01…0,04 luma, равномерно по высоте; пелены не даёт; небо (верх кадра) остаётся синим 0,09/0,25/0,53 на всех высотах над слоем.
- (в) проход облаков: в слое вклад ~0 (0,323 vs 0,324), выше — до +0,03 (видимые облака вдали, ожидаемо).
- Медленный рост luma с высотой (0,25 → 0,31) есть и в bare (0,208 → 0,266): геометрия кадра (больше неба/дали при pitch −3), а не пелена.

## Причина
`scripts/game/game.gd::_process` берёт `air.cloud_density_at(camera)` → `rust/dp-air/src/terms/clouds/field.rs::density_at`: «грубая плотность 0..1 без шума» = cover × 6ζ(1−ζ) по растру поля (cover — доля площади ячейки 400 м под облаком). `scripts/game/cloud_whiteout.gd::update/apply` умножает на density_gain 1,5 и смешивает fog_density → 0,06, цвет → белый, fog_sky_affect → 1, fog_height_density → 0. Камера в просвете между облаками (в ячейке cover 0,1 90 % площади чисто) получает ту же мглу, что внутри облака с средней плотностью: плотность — среднее по ячейке, а не значение в точке. Фон вне сетки (bg_cover ≈ 0,3) даёт пелену и там. «Некая высота» = основание слоя (здесь 1056 м AGL); выше верха столбца density = 0.
В более облачный день (cover 0,5–1) тот же механизм даёт amount до 1 по всей толще слоя (в этом прогоне не снимался — uncertain).

## Физична ли белёсость
Нет. В просвете воздух прозрачен (видимость десятки км, модель дымки: 35 км); мгла даёт fog_density 0,0087 1/м (~450 м) и белый цвет. Белая мгла физична только внутри облака (капли, видимость десятки м). Над слоем и в стороне модель света/дымки пелены не даёт (подтверждено: nowo = main выше слоя).

## Варианты правки (код не менялся)
1. Порог: want = clamp((density − d0)/(1 − d0)) при d0 ≈ 0,4–0,5 вместо density×gain — слабое среднее не даёт мглы (cloud_whiteout.gd, configs/game.json). Ожидание: просвет с cover < 0,4 — amount 0. Минус: граница облака «ступенька» по cover.
2. Реальная плотность в точке: считать density у камеры тем же шумовым профилем, что рисует raymarch (cloud_raymarch_cs), а не cover×профиль — мгла только в видимом облаке; точнее, дороже (CPU-копия шума или обратное чтение).
3. Гибрид: грубая плотность только как маска (cover > 0,3) × плавный вход по глубине в облако от видимого края (расстояние до ближайшего нарисованного облака). Сложнее, нужна геометрия облаков.

## Неопределённости
- Мгла по cover 0,1 в этом прогоне небольшая (0,145); как выглядит жалоба пользователя при cover ≈ 0,5–1 — не снято.
- Видимость облака в камере не проверена прямо (альфа центра кадра не записана); «ясно» — по cover, по близости к кадру noclouds ≈ main в слое.
- Кадры не просматривались глазами.
- FPS не мерялся (решение пользователя).
