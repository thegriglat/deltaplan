# CVW-3: мгла не протекает в небо ступенькой и в дымку облаков

## Что изменено
- `scripts/game/cloud_whiteout.gd::apply`: при `amount = 0` — исходные параметры побитно, метаданных нет. При `amount > 0`: `fog_sky_affect = lerp(s0, 1, v)`,
  `s0` = исходный, если исходный туман включён, иначе 0; `v = amount` (линейно: непрерывна, `v(0)=0`, `v(1)=1`; гладкая нелинейность не нужна — `amount` уже сглажен экспонентой `rise_time_s`);
  цвет тумана — lerp к цвету мглы по `amount`; метаданные окружения `fog_base` и `whiteout_veil` (CVW-К2 v2).
- **Плотность тумана — геометрическая** (`fog_density ≈ b·(0,06/b)^amount`, `b = max(исходная, fog_density_floor = 1e-6)`), а не линейная. Причина (найдена при замере): линейная даёт при
  `amount = 0,007` плотность 4e-4 1/м, т.е. `1 − exp(−4e-4·5000 м) ≈ 0,86` для рельефа в 5 км — даль заливается цветом тумана на кромке слоя (x_bg G 0,133 → 0,269 даже при `fog_sky_affect` 0,007).
  Геометрическая (с весом a^8 к плотности мглы, чтобы при amount ≥ 0,95 было ≥ 0,05): при `amount = 1` ровно `fog_density` мглы (видимость как в v1), при малых `amount` — километры видимости.
- `cloud_layer.gd`: дымка облаков в `_update_light` — из `fog_base` (если есть); вуаль `_update_veil` каждый кадр → `veil_color`, `veil_v` в UBO компоновщика.
- `cloud_raymarch_cs.gdshaderinc`: `col = col·(1−v) + veil_color·alpha·v` после дымки. `cloud_compositor_effect.gd`: пара `veil_color/veil_v` в `VEC_PARAMS`.

## Границы модели
- Не-GPU запасной шейдер `cloud_volume.gdshader` вуали не получил (вне скоупа): без компоновщика облака мглу не получают, дымка — из `fog_base`.
- В середине диапазона `amount` мгла слабее, чем в v1 (видимость при `amount = 0,5` ≈ 4 км вместо 33 м, зато облака и небо закрыты вуалью `v`): цена отсутствия ступеньки;
  полная мгла (`amount ≥ ~0,95`) та же. Ощущение «густоты» при плотности облака 0,3–0,6 — на глаз пилота.
- Замеры сняты до добавления веса a^8 (он меняет плотность только при amount > ~0,5, вне окна ±50 м от основания: там amount < 0,1, вес < 1e-8).
- Данные первого прохода (линейная плотность) не сохранены: перезаписаны.
