# CVW-5: плотность облаков-записей

## Сделано
- `cloud_layer.gd`: `_towers()`/`_towers_at()` заменены на `_towers_shape()` - максимум по 8 башням считается прямо в цикле, без `Array[Vector4]` (замечание ревью CVW-4). Результат тот же (тесты CVW-К3).
- Стенд `cloud_view_climb_shot.gd`: вариант `recs` - перебор времён атмосферы, пока слой не рисует запись с плотностью >= 0,5; проход -1000...+1000 м через её центр и 6 кадров в просвете (`recsgap`). `after.json`: `rec_*`.
- Тест: Cb-запись (kind 3), вне бокса 0, `_towers_shape` детерминирована и убывает от башни.

## Замер
Запуск: `--temp=31 --wind=5 --hours=13 --pitches=-3 --air_s=1800,2400,3000 --variants=recs`, ongudai; на t=3000 с слой рисует 2 записи (Cb, kind 3, vis 1,0), центр (11378, 3653, 11153).
| | значение |
|---|---|
| кадров с записью (x_cloud_recs>0, плотность>0) | 22 |
| мгла в теле записи (max) | 1,000 |
| мгла в просвете (камера вне всех рисуемых облаков), 5 кадров | 0,000 |
Просвет найден в 3750 м от центра; одна точка рядом (+100 м) попала в другое облако (плотность 0,22, мгла 0,34) - это не просвет, в счёт не входит.
Яркость кадра в просвете 0,44...0,57 (в теле 0,568): в кадре просвета есть другие облака/небо, чистого сравнения яркости с плотностью нет (кадры цифрами, глазами не смотрелись).

## Граница записи и шейдер (quality 1)
Шейдер сдвигает uv башен на до ±0,15 (w1, w2) и высоту на до ±0,06; в первой версии CPU брал неискажённые башни (оценка смещения до 0,15·rx ~ 960 м). Теперь `_rec_density` повторяет искажение: `wp = p/(top_period_m·ns)+seed`, w1 = канал R, w2 = канал R по `wp.zxy+(0,37; 0,11; 0,73)`, мип 0 (`_nz`), `hh`, пересчёт `spread_k` (как в шейдере, без повторной добавки анвила) и ранний выход при башнях < -0,7. Тесты CVW-К3 проходят.

Замер границы по кадрам (стенд `recs`, слой поля выключен - только запись, мгла выключена, взгляд от облака вдоль пути, шаг 10 м, ±150 м вокруг CPU-кромки visible_density = 0,5; Cb kind 3, t=3600 с, высота 30 % слоя, центр (20866, 5323, 4515)): **надёжно не меряется**.
- Яркость кадра на обеих кромках плоская: выход 0,297-0,298, вход 0,390 по всем 31 кадру, хотя visible_density по CPU падает с 1,0 до 0,17 на 4400-4700 м (спад ~300 м). Камера смотрит от тела наружу; видимой границы скачком яркости нет.
- Обзор той же записи снаружи (`recs_view_12000.png`, `recs_view_5000.png`) показывает рыхлое облако с провалами (клубы), а не сплошное тело: кромка у шейдера разорвана на клочья масштаба десятков-сотен метров, одним числом смещения не описывается.
- Первая версия замера (до отключения слоя поля) дала 20-30 м, но там в кадре было облако слоя поля, а не запись - не использовать.
Что известно: перенос w1/w2 с quality 1 на CPU сделан (тесты CVW-К3 проходят); числом "расхождение кромки <= 10 м" не подтверждено; ширина размытия CPU-кромки ~300 м (спад плотности 1,0 -> 0,17), клочья шейдера - того же порядка. Мгла по CPU-плотности плавная, поэтому ступеньки на кромке нет.

## Границы
Кучевые (kind 0) и линзы на сцене не встретились (объекты считаются фоном, при `--air_s` разные запуски дают разный набор); они проверены только синтетикой. Результат стенда недетерминирован по набору объектов.
