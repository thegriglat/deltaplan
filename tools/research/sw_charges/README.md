# sw-charges: опыты

Форматы — `docs/contracts/sw-charges.md` (SW1 случай, SW2 поле, SW3 прогон). Проверка файлов:
`python3 tools/research/sw_charges/contract/check_contract.py <каталог>` (самопроверка — `--selftest`).

Разделы дописывают задачи модуля (SWC-n): крейт, воспроизведение, таблицы, где лежат крупные данные.

## Решатель swpy

Пакет `swpy/` — явный конечнообъёмный решатель модели Рипа (SW1) на NumPy: `case.py` (генератор SW1), `solver.py`
(схема, `run(case, out_dir) → (поле, запись)`), `io.py` (SW1–SW3), `cli.py` (`swc`). Внутри float64, в файлах float32.

Окружение: `tools/research/sw_charges/py` (обёртка, uv-venv в `${SWC_VENV:-$HOME/.cache/sw_charges/venv}`, `requirements.txt`: numpy, pytest).

Команды:
```
tools/research/sw_charges/py -m swpy case ideal --name N --shape ridge --H 50 --s 0.2 --dim 1 --nx 400 --dx 50 \
    --h0 500 --b0 0.1 --U0 2.1 --sponge-width 5000 --out DIR      # → DIR/N.json+.bin (SW1)
tools/research/sw_charges/py -m swpy run DIR/N.json --out OUT     # → OUT/N.field.json+.bin (SW2), OUT/N.run.json (SW3)
```
Код выхода `run`: 0 — steady/averaged/max_time, 3 — diverged. Проверка файлов: `contract/check_contract.py OUT`.
Дымовой прогон: `bash tools/research/sw_charges/swpy/smoke.sh`. Тесты: `tools/research/sw_charges/py -m pytest -q tools/research/sw_charges/swpy/tests`
(T1–T11 карточки SWC-4: покой, Риттер, Бернулли дозв./сверхзв., критичный гребень, переключение режима M_c, масса,
1D = 2D, трение+сила, нагрев, статусы SW3).

Схема: MUSCL (minmod по η, u, v, b) + SSP-RK2, HLL, well-balanced реконструкция Одюсса второго порядка; в клетках у
мокро/сухо, при h на грани ≤ 0 и в крайних клетках области — первый порядок. Трение неявно, сила `balance`, Кориолис —
поворот, нагрев и губка — расщеплением после переноса. dt = cfl/max(λx, λy) (+ страховка по сумме осей в 2D).
Границы модели: давление Рипа с переменным b не имеет точного покоя (покой точен только при b = const); вовлечения нет;
HLL размазывает контактный разрыв (v, b переносятся против потока массы — резкие); на фронте сухого дна схема первого порядка.

Замеры (CPU, NumPy, 1 поток, машина под нагрузкой других задач): T5 (1D, nx 800, dx 50, ridge a = 1000 м, M = 0,5, F0 = 0,5) — стационар
за ~13 400 с модельного времени, ≈ 8 100 шагов, ≈ 25 с; шаг 1D nx 800 ≈ 3 мс; шаг 2D 512×512 ≈ 0,5 с (SSP-RK2, две стадии).
Наблюдения: порог `steady_tol` (по умолчанию 5e-4 в генераторе и CLI) — 1e-4 у схемы второго порядка достижим не всегда (шум ограничителя на масштабе 2Δx, пол
невязки ≈ 1e-4 дозвук., ≈ 3e-4 сверхзвук.) — поэтому по умолчанию 5e-4 (как в тестах Бернулли/M_c). При M > M_c прыжок за гребнем стоит у ~1,8a
(сопряжённая глубина), а не дальше 2a; значения «на гребне» — среднее двух клеток по обе стороны x = 0.

## Панели panels2d

Пакет `panels2d/` (SW6, SWC-11): 2D-панели постоянных источников по линии рельефа (Hess & Smith) + дискретные вихри Лэмба — Озеена, только NumPy.
- `Terrain(x, z, smooth_m=0, far_m=20000)`, `build_panels(terrain, x_focus, ds_min, ds_max, growth)` → `Panels` (концы, середины, нормали в воздух, ds).
- Фон: `bg_uniform(U)`, `bg_profile(U10, alpha, z_sat, terrain, smooth_m=250)`; вихри: `Vortices(x, z, gamma, core)`.
- `solve(panels, bg, vortices=None)` → σ (прямое N×N, невязка `residual` ≈ 1e-13); `velocity(panels, sigma, bg, x, z, vortices)` → (u, w), под землёй NaN.
- `step(state, dt)` — МДВ, RK2; `state` = {panels, bg, vortices, t, shed}; ведёт `state['born']`, `state['lost']` (сумма Γ рождённых/ушедших).
Тесты (18, из них 8 — v3): `tools/research/sw_charges/py -m pytest -q tools/research/sw_charges/panels2d/tests` (в `conftest.py` BLAS в 1 поток — на загруженной машине многопоточный в десятки раз медленнее на малых матрицах).
Замеры (CPU, 1 поток, машина под нагрузкой): solve N=500 ≈ 60 мс, N=2000 ≈ 0,85 с; velocity на N=500 ≈ 70 мкс/точку (10⁴ точек); step с 1000 вихрей при N≈500 ≈ 0,34 с (две сборки+решения, 2 × 10⁶ пар вихрь–вихрь).
Границы: открытая линия источников и угол 90° у основания полукруга — ошибка первого порядка по ds у основания; сетка без панелей-обрезков (каждая ≥ 0,5·ds_min); вихри без самоиндукции и без роста ядра; σ пересчитывается каждый шаг. Ошибка |V|/(2U·sinθ) − 1 в точках коллокации полукруга R=200 (x_focus=None):

| R/10 | +279 % | −50 % | −8,7 % | −3,6 % | −1,2 % | −0,9 % |
| R/20 | −48 % | −23 % | −4,7 % | −2,4 % | −0,7 % | −0,6 % |

### v3: пограничный слой, отрыв, скорость у стенки (SWC-15)

`panels2d/bl.py`: `surface_flow`, `boundary_layer`, `separation`, `velocity_bl` (интерфейс — SW6 v3, `docs/contracts/sw-charges.md`).
- `surface_flow`: `u_s` — касательная скорость в точках коллокации (фон + вихри + касательная часть панелей; собственная панель вклада не даёт), `cp = 1 − (u_s/U_ref)²`. Дополнительно (не из контракта): `u_e` — скорость на кромке слоя = `u_s` + (фон на 50 м над стенкой − фон на стенке): при однородном фоне `u_e = u_s`; при профиле (где фон у стенки обрезан z0) `u_e` даёт скорость слоя, а не нуля; `du_e` = du_e/ds, центральные разности (`np.gradient`) и среднее по 3 панелям. Слой и Стратфорд считаются по `u_e`.
- `boundary_layer` (Хед 1958, ARC R&M 3152; в виде White, «Viscous Fluid Flow», гл. 6): dθ/ds = cf/2 − (H+2)(θ/u)du/ds; (1/u)d(uθH1)/ds = F(H1) = 0,0306(H1 − 3)^−0,6169; H1(H) = 0,8234(H − 1,1)^−1,287 + 3,3 при H ≤ 1,6, иначе 1,5501(H − 0,6778)^−3,064 + 3,3 (константы взяты из карточки задачи, по первоисточнику не сверялись); cf/2 = (κ/ln(δ/z0))², κ = 0,4, δ = θ(H1 + H). RK2 (средняя точка) по s с подшагами ≤ 15·θ0 (релаксация жёсткая, на крупных панелях вдали без подшагов расходилась); ограничения: H1 ≥ 3,3 + 10⁻³, θ ≥ 10⁻³θ0.
- Старт — слой ровной земли: δ0 = 500·z0 (50 м при z0 = 0,1; приземный слой, он же высота фона для `u_e`). Условие стационарности формы dH1/ds = 0 при du/ds = 0 даёт H1·cf/2 = F(H1); для δ0/z0 = 500 корень H0 = 1,66, θ0 = 7,59 м (H0 = 1,3–1,4 из карточки получилось бы только при δ/z0 ≈ 10⁴, т.е. δ ≈ 1 км — вся АПС). **Рост θ на ровной земле dθ/ds = cf/2 > 0 стационарного решения не имеет**; слой держится (θ0, H0) до первого возмущения давления: пока |u_e/u_e(0) − 1| ≤ 1 % (GATE), далее — по Хеду без поправок. То есть рост ровного слоя уравновешен крупномасштабным градиентом давления АПС (вне модели). После рельефа слой остаётся «свободным» (толстым, сотни метров; обратной релаксации к АПС нет). Эта граница — главное допущение: попытки «силы» (вычесть cf0/F0 или градиент a0) либо гасили отрыв (H ≤ 1,8 даже при H/L = 0,7), либо были неустойчивы.
- Отрыв Хеда: первая точка, где H ≥ 2,4 при du/ds < 0, либо u_e ≤ 0 (обратное течение у стенки; cf шероховатой стенки в формуле всегда > 0, критерий cf ≤ 0 не срабатывает отдельно). Слой за ней — NaN (повторного присоединения нет); `bl["i_sep"]` — индекс (−1 нет). В `value` — H в первой панели за порогом (может быть большим: один шаг пересекает порог).
- Стратфорд (1959, J. Fluid Mech. 5:1–16), турбулентный: Cp·(x dCp/dx)^½·(10⁻⁶Re)^−0,1 = 0,39 (формула и константа 0,39 — из карточки, по статье не сверялись). Cp = 1 − (u_e/u_max)², x — дуга от точки минимума давления (максимума u_e), Re = u_max·L/ν, ν = 1,5·10⁻⁵, L — длина разгона (от последней точки до максимума, где u_e ≤ минимум + 1 % — ровная ступень до холма). Участок торможения заканчивается там, где du/ds снова ≥ 0. Вариант для резкого скачка давления не реализован.
- `velocity_bl`: z_agl − вертикально над линией панелей, панель — ближайшая по x; при z_agl < δ касательная составляющая = u_edge·ln(z_agl/z0)/ln(δ/z0) (u_edge — касательная потенциальная скорость на z_agl = δ; сшивка непрерывна и совпадает с u_*/κ·ln(z/z0), u_* = κ·u_edge/ln(δ/z0) из `bl`), нормальная — потенциальная; z_agl ≤ z0 → 0.
- `step(..., shed="auto")`: точки схода — `separation(..., "head")` каждого шага (z0 из `state["z0"]`, по умолчанию 0,1), точка выше земли на ds_min/2 по нормали панели.

Инварианты v3 (тесты): ровная земля + `bg_profile` (U10 = 8, α = 0,2) — `velocity_bl` / фон в пределах 3 % на 10–300 м (худшее — 2,4 % на 10–20 м: степенной закон против логарифмического внутри δ0 = 50 м); θ постоянна, H = 1,66, отрыва нет; полуцилиндр R = 200: u_s = 2U·sinθ в пределах 2,0 % (θ 30–150°, ds = R/20); Agnesi H/L ≤ 0,3 — отрыва нет ни одним методом; Agnesi H/L = 0,7 — отрыв Хеда на подветренном склоне; `step` с `auto` — Γ сохраняется.

Границы: (1) **Стратфорд на Agnesi отрыва не даёт даже при H/L = 3** (левая часть ≤ 0,23 при пороге 0,39): потенциальное торможение за гладким холмом пологое; метод срабатывает на резком торможении (полуцилиндр: θ ≈ 54°, значение 0,39). (2) Отрыв Хеда зависит от фона и допущения о слое ровной земли (H/L = 0,5: есть при профиле, нет при однородном). (3) Полуцилиндр: Хед даёт отрыв перед ним (x = −522 м, торможение к «углу» 90° у основания) — граница модели панелей. (4) Отрыв не влияет на потенциальное решение (нет обратной связи; она — через вихри `step`). (5) Присоединения нет; `bl` после отрыва — NaN.
