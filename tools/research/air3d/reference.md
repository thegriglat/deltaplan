# Эталон масштаба 1 (AM-01): 3D-Пикар — спецификация для переноса на GPU

Документ в работе (AM-01, `docs/plan/air_model.md`). Первым зафиксировано решение по сетке — от него
зависит V-цикл давления в AM-02. Остальные разделы (точная дискретизация, порядок шагов, приёмка) —
ниже по мере готовности.

## Решение: σ-сетка или маска

**Решение: декартова сетка MAC с маской «клетка под землёй» (как в прикидке), не σ-сетка.**
Вертикальный шаг — постоянный на уровне клипмапа, Δz = Δx/2 в окнах (100 м → 50 м, 50 м → 25 м),
~100 м по области.

Числа, на которых решение стоит (Онгудай, рельеф — блочное среднее 25-м слоя по клетке):

| Сетка | уклон p50 / p95 / p99 / макс. | доля клеток «воздух» | уровней по z (маска) |
|---|---|---|---|
| область 400 м | 0,22 / 0,39 / 0,50 / 0,69 | 0,82 | 48 (Δz 105 м) |
| область 200 м | 0,27 / 0,50 / 0,61 / 0,97 | 0,82 | 48 |
| окно 100 м у Каянчи | 0,31 / 0,60 / 0,68 / 0,80 (39°) | 0,82 | 62 (Δz 50 м) |
| окно 50 м | 0,36 / 0,68 / 0,76 / 0,85 (40°) | 0,82 | 112 (Δz 25 м) |

Почему маска:
1. **Уклоны большие.** На клетках 100/50 м, где пилот летает, 5 % склонов круче 0,6 (31°), максимум
   ~40°. В σ-координатах перекрёстные метрические члены (x–σ, y–σ) — порядка уклона, т. е. того же
   порядка, что главные. Отсюда: (а) точный оператор давления A = DᵀWD на σ-сетке — 19-точечный (старый
   план WF-01), его не решить «V-циклом с прогонками по столбцам» так же дёшево, как 7-точечный; (б)
   7-точечное «сосредоточенное» приближение (перекрёстные члены отброшены в проекции) при уклоне 0,6
   — плохой предобуславливатель, дивергенция уходит только внешними итерациями; (в) диффузия θ′ и u
   вдоль наклонных σ-поверхностей даёт ложные потоки у крутых склонов (известная беда σ-моделей, в
   WRF — сглаживанием рельефа до ~30–45°). Маска не имеет предела по уклону: обрыв — просто столбец.
2. **Точность проекции.** С маской оператор давления — точный 7-точечный, симметричный, с
   неотрицательными проводимостями граней; один V-цикл на итерацию Пикара уже в прикидке довёл
   ∇·u до СКО ≤ 6·10⁻⁸ 1/с на всех 217 решениях. Требование ∇·u ≤ 1e-6 выполняется «по построению».
3. **Точность у земли.** Здесь σ-сетка лучше: первый слой ~10 м против Δz/2 = 12,5–25 м у маски, и
   нет «лесенки». Но: (а) решение пользователя — «мельче 25 м не нужна, меньшее — масштаб 3»; в окне
   50 м маска как раз даёт 25 м по вертикали; (б) слой перемешивания днём замыкается турбулентной
   вязкостью K(z) до сотен м²/с — тонкий склоновый слой (10–50 м) среднее поле всё равно размазывает;
   (в) в прикидке ключевые числа (подъём у старта, разгон на 50 м, седловина) между окнами 100 и 50 м
   меняются на 0–10 % — лесенка не ломает сходимость по клетке; синтетика AM-01 (Аньези, сопка,
   седловина) проверит это прямо сходимостью по клетке и против потенциального обтекания/Askervein.
   Выборка для игры у земли — по реальной высоте над рельефом: ниже центра первой воздушной клетки —
   логарифмический профиль к нулю на z0 (как трение в решателе).
4. **Сложность на GPU.** Маска — один байт на клетку, все шаблоны 7-точечные с постоянными
   Δx, Δz, коэффициенты собираются на лету из соседей; всё это уже работает в 3D. σ-сетка требует
   метрики на клетку (высоты граней, наклоны), ядер перекрёстных членов (явная поправка) и либо
   19-точечного давления, либо смирения с медленной дивергенцией; итераций Пикара у σ-сетки с
   анизотропией 10 м × 100 м и перекосом 0,6 заведомо не меньше.
5. **Цена маски.** «Пустых» клеток под землёй — 18 %; уровней больше, чем у σ (62 и 112 против
   ~32–40 в окнах 100/50 м) — это ×1,5–3 по памяти и времени итерации в окнах. Если окна 50 м не уложатся
   во время (AM-04), дешёвая мера без смены схемы — растянуть Δz выше максимума рельефа окна (сейчас
   равномерно до «макс. + 2000 м»), шаблоны это выдерживают (Δz по уровню); это не делалось.

**Что это значит для AM-02 (V-цикл давления):** неизвестная φ в центрах клеток (nz, ny, nx);
оператор — 7-точечный с переменными проводимостями граней c = K_грани/h² (0 — грань закрыта землёй
или границей области → условие Неймана); неактивные клетки (земля) — строка «1·φ = 0»; все грани
области при «жёстких» границах закрыты → оператор вырожден, правую часть и решение центрировать по
активным клеткам. Огрубление только по x, y (×2, z не огрубляется), активность грубой клетки — «хотя
бы одна из 2×2 активна», сглаживание — зебра-прогонки по вертикальным линиям (Томас), на самом грубом
уровне — прогонки по z, x, y. Точные формулы огрубления проводимостей, ограничения/продолжения и числа
сглаживаний — в разделе «Дискретизация» (будет ниже); эталонные промежуточные результаты V-цикла —
`tests/atmosphere/fixtures/air_model/`.

## Дискретизация (спецификация для GPU)

Код-исполнение — `air.py` (класс `Air`, ядра CUDA в строке `_SRC`); при расхождении с текстом
прав этот раздел. Эталонные промежуточные массивы одной итерации — `tests/atmosphere/fixtures/air_model/ref/`
(раздел «Эталоны для тестов GPU»).

### Уравнения (что решаем)
Установившийся Буссинеск, приближение «среднее поле на час при перемешанном воздухе»:

    (u·∇)u = −∇p + ∇·(K ∇u) − [у земли] C_d |u_h| u_h / Δz + ẑ g θ′/θ0 − s(x)(u − U_b)
    ∇·u = 0
    ∇·(u θ′) + w dθ̄/dz = ∇·(K_h ∇θ′) + [у земли] H/(ρc_p Δz) − θ′/τ − s_θ(x) θ′

g = 9,81, θ0 = 300 К, ρc_p = 1206 Дж/(м³·К), K_h = K (Pr_t = 1), τ = 7200 с.

### Сетка и маска
- Массивы (NZ, NY, NX) = (nz+2, ny+2, nx+2) с ореолом в 1 клетку, индекс `(k·NY + j)·NX + i`;
  i — восток (x), j — север (y), k — вверх. Центры клеток: x_i = x0 + (i − ½)Δx, z_k = z_bot + (k − ½)Δz.
  Δz постоянен (окна Δz = Δx/2, область 400/200 м — Δz = 105 м).
- Рельеф h(i, j) — блочное среднее 25-м слоя по клетке; в ореоле — копия крайней клетки.
- Тип клетки `cell`: 0 — земля (z_k < h, и весь слой k = 0), 1 — воздух внутри, 2 — ореол
  (значение задано: боковые клетки i, j ∈ {0, N−1} и верхний слой k = NZ−1, если не земля).
- Грани MAC: `u[k,j,i]` — грань x между клетками (i−1, i); `v[k,j,i]` — между (j−1, j);
  `w[k,j,i]` — между (k−1, k). Тип грани по двум клеткам (c0, c1): 0 — хотя бы одна земля (значение 0);
  1 — обе воздух (неизвестная); 2 — воздух–ореол (граница области, задаётся); 3 — ореол–ореол.
  Грани с индексом 0 по своей оси — тип 3 (u, v) и 0 (w, дно).

### Турбулентная вязкость K (м²/с), клетки
Фоновая часть K_b (считается один раз на решение, CPU) — Троен–Март (1986) / Холтслаг–Бовилль (1993):
- u* = κ U10 / ln(10/z0), κ = 0,4, z0 = 0,1 м; U10 — прогноз на 10 м;
- H_s — поток тепла (К·м/с) после гаусса σ = 1500 м; h_s — рельеф после того же гаусса;
- h_mech = 0,3 u*/f, f = 1,13·10⁻⁴ 1/с (51° с. ш.);
- неустойчиво (H_s > 10⁻⁶): h = max(z_i − h_s, 300 м, h_mech); w* = (g/θ0 · H_s · h)^(1/3);
  устойчиво (H_s < −10⁻⁶): L = −u*³θ0/(κ g H_s), h = min(h_mech, 0,4 √(u* L/f)); иначе h = h_mech;
- z = z_k − h(i, j) (над реальным рельефом клетки, ≥ 0); z_s = min(z, 0,1 h);
  w_m = (u*³ + 7 κ (z_s/h) w*³)^(1/3) (неустойчиво), u*/(1 + 5 z/L) (устойчиво), u* (нейтрально);
- K_b = max(k_fa, κ w_m z (1 − z/h)²) при z < h, иначе k_fa = 1 м²/с (свободная атмосфера).
Местная часть (ядро `kloc`, **каждую итерацию** перед импульсом, по текущему полю) — длина
перемешивания Прандтля–Блэкадара с поправкой на устойчивость, плюс горизонтальная подсеточная
диффузия Смагоринского:

    |S|² = 2 S_ij S_ij,  S_ij = ½(∂_j c_i + ∂_i c_j),  c — скорость в центре клетки (среднее двух граней);
    ∂_a c_a = (f_{a,+} − f_{a,−})/h_a (точно по граням); ∂_d c_a (a ≠ d) — центральная разность центров
      соседних клеток; сосед-земля → односторонняя разность; оба — земля → 0;
    N² = g/θ0 · (dθ̄/dz(k) + ∂θ′/∂z) (та же разность); Ri = N²/max(|S|², 10⁻¹²);
    F = 1/(1 + 5 Ri)² (Ri > 0), √(1 − 16 Ri) (Ri ≤ 0);
    1/l = 1/(κ z) + 1/λ, z = max(z_k − h(i,j), Δz/2), λ(i,j) = max(40 м, 0,1·h(i,j))  (масштаб вихрей ~ 0,1 слоя);
    K* = max(K_b, l² |S| F);  K ← K + 0,5 (K* − K)                         — вертикальная (и по z-граням)
    |D_h|² = (∂_x c_x − ∂_y c_y)² + (∂_y c_x + ∂_x c_y)²;
    K_h* = max(K*, (c_s Δx)² |D_h|), c_s = 0,25;  K_h ← K_h + 0,5 (K_h* − K_h)  — по x, y-граням
Обновляются только клетки cell = 1; в ореоле K = K_b. Pr_t = 1 (тепло — те же K и K_h).
В шаблонах: для соседа по оси z берётся K, по осям x, y — K_h.

Зачем местная часть: без неё в следе за крутым гребнем нет производства турбулентности → отрыв
«дышит», установившегося решения нет (Аньези H = L = 300 м: 3000 итераций без сходимости; с ней —
711). Смагоринский по горизонтали — стандарт мезомасштабных моделей (WRF km_opt = 4, c_s = 0,25):
подсеточное горизонтальное перемешивание на клетке Δx; на сходимость почти не влияет, картину
сглаживает слабо.

### Нагрев: нелокальный перенос по слою перемешивания
Положительный поток H > 0 кладётся **не в первую клетку, а равномерно по толщине слоя
перемешивания столба** (клетки воздуха с 0 < z_k − h(i,j) < h, h — из K_b): Q = H/(ρc_p · n·Δz),
n — число таких клеток. Это профиль потока Холтслага–Бовилля H(z) = H0(1 − z/h) без вовлечения:
тепло в слое перемешивания разносят термики (масштаб 2), а не местная диффузия. Отрицательный поток
(выхолаживание, вечер) — в первую клетку (устойчивый слой местный). Зачем: при нейтральном θ̄ в слое
перемешивания (так в погоде игры и в жизни) нагрев первой клетки делает среднее поле
конвективно-неустойчивым — на клетке 400 м «сеточные термики» раскачиваются без неподвижной точки
(штиль 12:00: 3000 итераций, w на 200 м гуляет на 0,16 м/с СКО, до 0,7); с нелокальным нагревом —
111 итераций. (Прикидка сходилась иначе: θ̄ с 3 К/км в слое перемешивания — это нефизично устойчивый
слой, подъём у старта в штиль 0,18 против 0,49 м/с здесь.)

### Фоновый ветер и губки
- Направление «куда дует» e = (−sin φ, −cos φ), φ — «откуда» (метео). Ветер на высоте U_a = 1,8·U10.
- Профиль на грани: U_b = U_a·e·min((max(z − h_f, z0)/z_sat)^α, 1), α = 0,14, z_sat = 10·1,8^(1/α) = 664 м
  (профиль игры `WindModel.profile`, нормированный на ветер на высоте); h_f — средняя высота двух
  столбцов грани. U_b = 0 на гранях типа 0. w_b = 0.
- Губки (1/с): s = r·max(ramp(до потолка, 1000 м), ramp(до боковой грани, 2000 м)), ramp(d, L) =
  clip(1 − d/L, 0, 1)², r = 1/300. Для θ′: s_θ — потолок и только **приточные** боковые грани.
  Для w — то же по высоте грани w. Окна клипмапа — без губок.

### Импульс (ядро `build_mom`, грань типа 1 компоненты c ∈ {u, v, w})
Замороженная переносящая скорость a на грани: a_c = f(idx), a_d (d ≠ c) — среднее 4 граней
d вокруг: ¼(g[c0] + g[c0 + s_d] + g[c1] + g[c1 + s_d]), c0 = idx − s_c, c1 = idx (клетки по сторонам).
Уравнение строки (Σ C·x = b):

    diag = 1/Δτ_u + s;  b = f/Δτ_u + s·U_b − (p[c1] − p[c0])/h_c − corr2
    для каждой оси d и стороны ±, сосед q = idx ± s_d:
      𝒦 = K при d = z, K_h при d ∈ {x, y};
      K_face = 𝒦[c1] (d = c, +), 𝒦[c0] (d = c, −), иначе ¼(𝒦[c0] + 𝒦[c1] + 𝒦[c0 ± s_d] + 𝒦[c1 ± s_d]);
      vis = K_face/h_d²; up = (− и a_d > 0) или (+ и a_d < 0)
      тип(q) = 0: d = c → diag += vis (+ |a_d|/h_d если up) — нормальная компонента у стенки = 0;
                  d ≠ c → ничего (касательная у стенки: вязкого потока нет, перенос — нулевой градиент)
      иначе:     diag += vis; C_q = −vis (− |a_d|/h_d если up; diag += |a_d|/h_d)
    u, v: если грань ниже (idx − s_z) типа 0 → diag += C_d·√(a_x² + a_y²)/Δz,  C_d = (κ/ln(Δz/2/z0))²
    w:    b += g/θ0·½(θ′[c0] + θ′[c1]);  diag += cpl_k;  b += cpl_k·w (полунеявная плавучесть),
          cpl_k = g/θ0 · max(γ_w,k, 0) · Δτ_θ/(1 + Δτ_θ/τ), γ_w,k = ½(γ_k + γ_{k−1})
Не-неизвестные грани: строка C = (1, 0…), b = текущее значение. **Δτ_u = 0,3 с/м · Δx** (400 м → 120 с,
100 м → 30 с, 50 м → 15 с; прикидка — 600 с на всех клетках). Неподвижная точка от Δτ не зависит;
итераций до критерия — почти ∝ Δτ (псевдошаг работает как нижняя релаксация Пикара): окно 50 м
3 м/с — 1621 итерация при 600 с, 411 при 150, 51 при 15 с (замер ref_study, «Окна» ниже). Эталоны
`ref/` посчитаны с Δτ_u = 600 с (записано в их JSON) — для сверки блоков брать значение из JSON.

### Перенос
Против потока 1-го порядка, неявно (в шаблоне). **2-й порядок не включён**: отложенная поправка
(MUSCL: линейная, ван Лир, ван Альбада — ядра `adv2_mom`, `adv2_heat`, опция `adv2`) на крутом рельефе
лишает Пикар неподвижной точки (Аньези H = L: невязка стоит на 1–4·10⁻⁴ при любом ограничителе, с
местным K тоже), т. е. без численной вязкости 1-го порядка на этих клетках установившегося среднего
поля нет. Насколько 1-й порядок сглаживает — замер на пологих случаях, где сходятся оба (таблица
«Перенос 2-го порядка» ниже).

### Тепло (ядро `build_heat`, клетка типа 1)

    diag = 1/Δτ_θ + 1/τ + s_θ;  b = θ′/Δτ_θ + Q − γ_k · ½(w[k] + w[k+1]) − corr2
    по 6 граням: v_out — скорость наружу; v_out > 0 → diag += v_out/h, иначе C_q += v_out/h (поток
    вносит сосед); если сосед не земля — dif = ½(𝒦[idx] + 𝒦[q])/h² (𝒦 = K по z, K_h по x, y), diag += dif, C_q −= dif
Q — см. «Нагрев: нелокальный перенос». Δτ_θ = 1200 с; θ_b — цель губки (0; в окне — родитель):
b += s_θ·θ_b. Поток тепла H (Вт/м² на
горизонтальную площадь) — `weather.py`: H0·sky·[max(0, cos угла солнца к склону) + 0,1 sin h] −
40·(1 − 0,7·облачность); H0 = 330; вода — 0; у краёв области гасится sin²(π/2·d/2000 м).

### Прогонки (ядро `line_thomas`)
Зебра по линиям: направление d ∈ (z, x, y) по порядку; для каждого — чётность 0, затем 1 (чётность =
сумма двух других индексов по модулю 2). Внутри линии — Томас по всей длине массива (включая ореол и
неизвестные строки-тождества), внелинейные соседи — из текущего x. Шаг импульса: 2 раза × (u: z, x, y;
v: z, x, y; w: z, x, y) с шаблонами, собранными один раз. Шаг тепла: 4 раза × (z, x, y).

### Проекция (SIMPLEC, один V-цикл)
1. div = (u_{i+1} − u_i)/Δx + (v_{j+1} − v_j)/Δx + (w_{k+1} − w_k)/Δz в клетках воздуха (без ореола);
2. rhs = div − mean(div по воздуху) (оператор вырожден: все границы — Нейман);
3. φ = 0; один V-цикл `MG.vcycle` для A φ = rhs, где A — 7-точечный: C_{±x} = Kx_face/Δx² и т. д.,
   C_0 = −ΣC; Kx_face = ½(K_c[i−1] + K_c[i]) · [тип грани = 1], K_c = 1/(1/Δτ_u + s),
   Kz_face = 1/(1/Δτ_u + s_w + cpl_k) · [тип = 1]; неактивные клетки — строка «1·φ = 0»;
4. φ −= mean(φ по воздуху); u −= Kx_face·Δφ/Δx (то же v, w); p += φ.
V-цикл (`MG`): уровни по x, y делятся на 2, пока nx, ny чётны и ≥ 6 (z не огрубляется);
проводимость грубой грани x = (c_x[2j] + c_x[2j+1])/8 (у, z — аналогично; z: сумма 4 / 4), затем
обнуляется, если одна из клеток грани неактивна; грубая клетка активна, если активна хоть одна из 2×2;
на уровне: 2 × зебра-прогонка по z → невязка → ограничение (среднее 2×2) × активность → рекурсия с нуля →
продолжение (копия в 2×2) × активность → 2 × прогонка по z; на самом грубом — 20 × (z, x, y).

### Граничные условия области («жёсткие» с губками)
Грани типа 2: при ветре приток (s·U_b < 0, s — внешняя нормаль) = U_b; выход = U_b × c, c =
(Σ притока)/(Σ выхода) по граням (баланс площадей с рельефом); касательные на границе — 0 по нормали
(берутся из U_b в ореоле, тип 3). Штиль — стенки (0). Потолок — крышка w = 0 под губкой 1 км. θ′ в
ореоле = 0. Окна клипмапа: все грани типов 2/3 и θ′ ореола — трилинейно из родителя (центры родителя),
затем поправка потока Σ = 0 (равномерно по площади граничных граней); **зона релаксации** (Дэвис
1976): губки s у боковых граней на 4 клетки и у потолка на 1000 м тянут u, v, w, θ′ к полю родителя,
интерполированному во все грани/клетки окна (U_b, w_b, θ_b окна = родитель). Без неё окно 100 м при
6–8 м/с не сходится: невязка у потолка окна (родитель 400 м × свободная атмосфера с малым K).

### Итерация Пикара (порядок, `Air.outer_step`)
1. граничные условия (`apply_bc`);
2. местное K (`kloc`);
3. [поправка 2-го порядка импульса — выключена];
4. шаблоны импульса u, v, w от текущего состояния (`build_mom`);
5. шаг импульса (прогонки);
6. проекция (один V-цикл), p += φ;
7. [поправка 2-го порядка тепла — выключена]; шаблон тепла по новой скорости; шаг тепла.
Старт: область — фон U_b на гранях типа 1, 30 V-циклов проекции, p = 0; окно — трилинейно из
родителя, 30 V-циклов, p = 0. Тёплый старт — сохранённые u, v, w, θ′, p + 4 V-цикла без изменения p.

### Критерий остановки
Раз в 10 итераций: невязка установившихся уравнений = b − C·x шаблонов, собранных от текущего
состояния (псевдочлены сокращаются): СКО по неизвестным импульса < 2·10⁻⁵ м/с², тепла < 5·10⁻⁷ К/с,
СКО ∇·u < 10⁻⁶ 1/с. После остановки — `finalize`: 10 V-циклов проекции без изменения p (поле для игры,
∇·u до округления). Расхождение: не конечна или max|невязки импульса| > 50 м/с² → «diverged»;
предел итераций (3000) → «max».
