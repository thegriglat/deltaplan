# Задание: извлечь характеристики дельтапланов (Haiku)

Входные файлы — список путей (дан в задании агенту). Правила и список полей — в parse.py, строки 15–35 (PROMPT и SCHEMA): прочитай только их и следуй дословно.

- Запись на каждую модель И типоразмер; в каждой записи: manufacturer, model, size, cert_class, cert_standard, facts, geometry.
- facts: список {field, value, unit, quote}; число только явно из текста, как написано (без пересчёта единиц), unit как в тексте, quote — точный короткий фрагмент (до 120 символов). Ничего не выдумывай и не вычисляй.
- geometry (для 3D-модели): список {name, value, unit, quote} для явных размеров/форм: длины киля/передних кромок/поперечины, высота и ширина контрольной рамы, высота кингпоста, угол носа, закрутка/washout/рефлекс/двугранный угол, вырез паруса, форма законцовок, место подвески пилота, размеры труб, упоминания чертежей/рисунков с размерами.
- Для карточек DHV (service.dhv.de): модель и размер — из заголовка; Vmin/Vmax при VG 0 % и VG 100 % → vmin_vg0/vmin_vg100/vmax_vg0/vmax_vg100; стартовая масса (Startgewicht) → takeoff_mass_min/max; площадь, размах, класс (cert_class), год/номер испытания (cert_standard). Добавь в запись ключ "src" — имя файла-источника. Если карточка не про дельтаплан (а про параплан и т. п.) — пропусти её.
- Нет данных — {"wings": []}.
- Результат — один JSON {"src_files": [...], "wings": [...]} в файл, указанный в задании. Ничего другого не читай и не меняй, не коммить.
- Ответ одной строкой: сколько записей, фактов, geometry.
