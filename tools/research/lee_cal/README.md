# Калибровка притока у старта в тени (fix/lee-start-calibration)

Ошибка: `AirRuntime` подбирает множитель притока k так, чтобы U на 10 м над стартом равнялась ветру меню.
Старт в подветренной тени даёт при k = 1 малую U₁, k упирался в предел 3, и по всей области ветер выходил
2–6 × меню. Ветер меню — ветер открытой местности (его даёт профиль притока при k = 1), поэтому верхний
предел k теперь 1: подгонка только снимает избыток разгона обтекания над наветренным стартом (k < 1), а
старт в тени честно слабее меню; второго прохода тогда нет (k не меняется, поле то же).

## Файлы
- `air_scan.gd/.tscn` — сетка ±2,4 км шагом 100 м вокруг старта, `mean_wind_at` на 30/100/200 м над землёй.
- `run.sh <метка> [имя…]` — прогоны (6 м/с, 12:00, 15 июля; Рапа-Нуи — точки `--latlon` с ветром со 110°;
  Онгудай, Аскарово — старты с ветром в старт и с тыла) → `out/<метка>/` (json не в git — пересчитать).
- `summary.py before after` — таблица ниже.

## Воспроизведение
    git checkout <коммит до правки> -- scripts/atmosphere/air_model/air_runtime.gd
    .dpcli/dpcli job --lock gpu start lc-before 7200 tools/research/lee_cal/run.sh before
    git checkout HEAD -- scripts/atmosphere/air_model/air_runtime.gd
    .dpcli/dpcli job --lock gpu start lc-after 7200 tools/research/lee_cal/run.sh after
    python3 tools/research/lee_cal/summary.py before after
