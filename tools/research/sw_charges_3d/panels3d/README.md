# panels3d — панели-источники в 3D (SWD2)

Интерфейс — `docs/contracts/sw-charges-3d.md`, раздел SWD2 (проверка имён: `./py contract/check_contract.py api panels3d`).
Тесты: `./py -m pytest -q panels3d/tests` (18 тестов; 5 тяжёлых — только с CuPy/GPU, ~40 с на RTX 4070 SUPER). Замеры: `./py panels3d/bench.py hemi|scale`.

| Файл | Что |
|---|---|
| `terrain.py` | `Terrain3D`, фоны `bg_uniform` / `bg_profile` / `bg_zero` (у функции — `.wind_to`) |
| `mesh.py` | `build_panels`: дерево квадрантов → согласованная триангуляция, `Panels` (`locate`, `height`) |
| `influence.py` | точная формула треугольника, `assemble`, LU / GMRES, `velocity`, касательная скорость (NumPy / CuPy) |
| `jh.py` | `hill_length`, `velocity_jh` |
| `sep.py` | `separation3d`, слой Кармана — Хеда вдоль линий тока |

## Устройство
- **Ядро.** Плоский треугольник, σ = const: V = [Ω·n + Σ m_e·ln((r₁+r₂+L)/(r₁+r₂−L))]/4π (Ω — телесный угол по Ван Оостерому —
  Стратаски, m_e — внешняя в плоскости нормаль ребра). Формула точна всюду (в т. ч. вдали — ограничений по ошибке нет, мультиполя
  нет), без потери точности у линии ребра (r₁+r₂−L = 2(r₁r₂+d₁·d₂)/(r₁+r₂+L)); у самого ребра регуляризовано
  ε = 10⁻³·ds. Проверено квадратурой (3·10⁻³ отн.). Собственный вклад — σ/2; тангенциальная часть собственной панели — точная.
- **Сетка.** Квадрат со стороной `ds_min·2^k ≥ 2·far_m` (чуть больше ±`far_m`: листья у фокуса точно `ds_min`), центр — центр
  растра. Лист делится, пока сторона > h(d); баланс 2:1; лист без висячих узлов — 2 треугольника (диагональ по чётности),
  с висячими — веер из центра. Узлы — на `terrain.height`. «Размер клетки» = сторона листа; `ds` панели = √площади
  (у `ds_min`-листа 17,7 м при 25 м).
- **Решение.** `dense` — LU (f64, кеш в `Influence`), `gmres` — перезапускаемый GMRES(80) на матрице (`rtol` 1e-9); обе на
  выбранном backend. Память: A (8N² байт) + LU после первого `dense` (ещё 8N²); N = 16 700 → 4,5 ГБ, сборка 4 с, LU 14 с (GPU).
  Для 12 ГБ потолок ≈ N 25 000 (A + LU).
- **JH.** Как panels2d v4 (см. SWD2); σ_bg получается решением с той же `infl`; решение для однородного U_ref
  кешируется в `infl._cache`. Выше h_m сшивка — как в panels2d (линейная по ln z на [h_m, 2h_m]).
- **Отрыв.** Линии тока трассируются по узловому (area-взвешенному) полю `ut`, барицентрическая интерполяция, RK2,
  шаг ds/2; слой считается на равномерном ряду по длине дуги с шагом `ds_min`; u_e = |ut| + (фон на 50 м вдоль
  касательной − фон у стенки), du_e сглаживается по 3 точкам; слой Хеда — копия констант и формул panels2d.bl v3.
  `lee_only`: гребни профиля земли вдоль самой линии тока (правило panels2d.crests), окно — до следующего минимума.

## v3 (SWD-4): `couple`, `restart`
- `velocity_jh(couple=True)` — ΔS из полной внешней скорости (потенциал + extra + панели от σ_extra), см. `sim3d/README.md`; тест на
  ровной земле: u = u0·(1 + A·extra/U_ref), `couple=False` — u0 + extra; ΔS < −1 даёт обратный поток; выше 2·h_m — как `velocity`.
- `separation3d(restart=True, streamlines_from="bg")` — линии тока по σ_bg (кеш в `Influence`, `panels._infl_obj`), u_s со знаком, присоединение
  и повторный отрыв; `points["k"]`, `points["reattach"]`; `lines` — по уровню `k`. Правило присоединения — `sep._reattach_index`
  (README `sim3d`). Двойной хребет (a = 250 м, 3a между гребнями, ds_min 25 м): отрыв за обоими гребнями (x ≈ 240 и 996 м на средней линии),
  без `restart` — только за первым; присоединение первого — на 410 м.
- `velocity_jh`: `hill_length` по колонкам — один профиль на поперечную линию (долг ревью SWD-2).

## Инварианты (тесты) и числа
- Ровная земля, `bg_uniform`: |σ| ≤ 1e-6·U, u = U ± 0,5 % (2–300 м).
- Полусфера R = 100 м, ds_min = R/20: вершина 1,5U ± 2 % (по панелям и по скорости над вершиной); 1,5U·sinθ ± 5 % при θ ∈ [30°, 150°]
  (на деле ≤ 2,3 %); у основания (вертикальная стенка) — граница сетки, ошибка первого порядка.
- Агнези-хребет (a = 250 м, H/L = 0,5, длина по y ≥ 20 полуширин): u на гребне на 10, 50, 300 м = panels2d (потенциал) ± 3 %.
- Полусфера R = 100 м, ошибка |speed/(1,5U·sinθ) − 1| по θ и ds_min (`bench.py hemi`; панели вдоль плоскости симметрии, z > 0,2 м):

| R/10 | 3456 | 66 % | 34 % | 3,7 % | 34 % | 66 % |
| R/15 | 5544 | 79 % | 4,2 % | 2,9 % | 4,2 % | 79 % |

  ошибка 55–80 % и с измельчением почти не падает — плоские треугольники с постоянным σ не передают поверхность, касательную к потоку
  вдоль стенки, это граница метода (на гладком рельефе уклоны < 45° не затрагивается).

  panels2d.separation 203,0 м (разница 0,9·ds_min при допуске 2·ds_min); на концах хребта срабатывает `lee_only` (в `rejected`).

## Границы модели
- **ΔS Тейлора — Ли: B_eff 1,13, а не 1,6.** Гаусс H/L = 0,1 (L = 603 м): потенциальное ΔS на l = 33 м над вершиной 0,065
  (на поверхности 0,075 = 0,76·H/L), усиление A(l) = (ln(h_m/z0)/ln(l/z0))² = 1,72 → ΔS(l) = 0,113 = 1,13·H/L, а контракт ждёт
  B·H/L = 0,159 ± 25 %: получено −29 %. Контракт v2: B_eff ∈ [0,9; 1,4] (факт 1,13); расхождение с 1,6 — граница модели. Подбор не делался.
- Квазидвумерность слоя вдоль линий тока: растекание линий тока (сходимость/расхождение) в u_e не учтено; поперечный перенос
  количества движения и форм-фактора между линиями нет.
- `hill_length` (v2) — ближайший гребень по профилю в обе стороны; на наветренном склоне L — того же холма, скачка масштаба нет.
- Фокус (`focus_r` = 10·ds_min по умолчанию) — единственный способ получить мелкие панели; `focus=None` на крупном растре
  даёт N порядка 10⁵ (плотная матрица не поместится).
- Рельеф вне растра — продолжение края с затуханием к `z_far`; панели вне растра плоские (приближение дальнего поля).
- Перепад гребня < 2·ds_min в `hill_length` не считается холмом (правило SW6 v4): для холма H = 35 м нужен ds_min ≤ 17 м.
- `velocity_jh` с `couple`: нить у стены гасится изображением в панелях, влияние на внутренний слой мало (`sim3d/README.md`).
- `separation3d`: только `method="head"`; отрыв только по линиям тока, начатым на наветренном краю растра; тангенциальная
  скорость кусочно-линейная по узлам (шум ~ ds_min).
