# SWD-12: прототипы A и C в 3D — вывод

Числа — `tables.md`, `summary.json`; воспроизведение и границы — `proto3d/README.md`. Рельеф: плоскость, холм Гаусса (H = 200 м, s = 250 м, уклон до 0,48), Perdigão NE (GLO-30).

## A: термик-кольцо
- **Ядро.** Вихревые частицы с баро-клинной генерацией: импульс P_z/(∫b dV·t) = 0,99; ускорение центра плавучести/b сходится при σ/R → 0: 0,38 / 0,46 / 0,52 / 0,56 (σ = 32 / 23 / 16 / 12 м), экстраполяция 0,66 против 2/3 (шар, присоединённая масса ½).
- **Кольцо.** В плоскости центра ∫w⁻/∫w⁺ = 0,96 (60 с) / 0,95 (90 с); w_min/w_max = −0,20 против Гедеона в игре −0,135 (в 2D было −0,31) — кольцо глубже, чем у Гедеона в 1,5 раза.
- **Подтекание у земли** (10 м, ρ = R): 0,25 / 0,38 м/с при 30 / 60 с, как в 2D над плоской землёй (0,24 / 0,42); на склонах 0,22–0,55.
- **Отрыв от склона (№10): осталась.** Шар: Δd_n(60 с) относительно плоского контроля −2,7 / −0,9 / −0,3 м (середина склона, подножие, Perdigão, штиль); с ветром 3 м/с термик прижат (−43 м на наветренном склоне, −30 м Perdigão). Положительное +38 м на подветренном склоне — геометрия (склон уходит вниз), не отрыв.
  Нагрев склона потоком 250 Вт/м² (штиль): вдоль склона течёт (0,2 м/с на 10 м к 150 с; на ровной земле 0), слой отрывается через ≈ 250–300 с и на склоне, и на ровной земле (d_n 60 против 66 м при 300 с), склон отрыв не ускоряет (Δd_n −6…−14 м). Анабатика растёт, но это короткий опыт; w центра к 400 с 4 м/с завышена (нет вовлечения).
- Эксперимента для термика у склона нет; надёжность — только согласие с теорией шара и с 2D.

## C: кольца-пары болтанки
- **Нейтральный слой (№6: ушла, с оговоркой).** σ_w/(1,25u*) = 1,09 / 1,09 / 1,06 / 1,05 на 10 / 25 / 60 / 120 м (2D: 1,53 / 1,73 / 1,74 / 1,35); −⟨u'w'⟩/u*² = 1,06–1,18 (c_K ≈ 1: κ_eff = 0,39 против 0,40); L_w/z = 0,24–0,29 (мало, как в 2D); σ_u/σ_w ≈ 1 против 1,9 игры (кольца изотропны).
  Оговорка: диаметр кольца d = ℓ — аналогия с парой, не данные; при R_r = ℓ σ_w в 2,1 раза выше игры; c/R 0,25–0,5: 1,03–1,14; курс 30°/60°: 1,17/0,90; окно и коробка: 1,04–1,14. Параметры не подгонялись.
- **Порог по Ri.** Над z_c = u*/(2κN) рождения нет: z_c = 30 м: σ_w/(1,25u*) = 1,02 (10 м, Ri = 0,03) → 0,73 (20 м, Ri = 0,11) → 0,04 (40 м, Ri = 0,44) → 0 (160 м); z_c = 60 м сдвигает так же. Без порога (F ≡ 1) — ≈ 1,06 везде.
- **Экранировка (замыкание на среднем поле).** c_K(Ri) = 0,93 / 0,87 / 0,70 / 0,45 / 0,20 / 0,055 при Ri = 0…0,24; стационарный баланс напряжения u*²(1−z/H) даёт S_eq/S_лог = 1,02 (10 м) … 0,80 (120 м, нейтрально) и Ri_eq → 0,23–0,25 на верху стратифицированной колонки (N² = 10⁻⁴, 4·10⁻⁴), σ_w,eq в 0,8–1,3 игры. Ожидание «завышение σ_w уходит само»: в 3D завышения почти нет (c_K ≈ 1), экранировка меняет S на единицы процентов; это алгебраическое равновесие, не динамика (устойчивость не проверена).
- **Над рельефом** (40 м над землёй, холм Гаусса): σ_w 0,53 (ровно) / 0,60 (наветренный склон) / 0,36 (гребень) / 0,64 (подветренный) м/с; σ_w/(ℓS) ≈ 1,28–1,38 везде — рельеф входит только через сдвиг S потенциального поля (S от ровной: 1,12 / 0,65 / 1,12). Кольца не повёрнуты к склону, отрыв потока и лес в S не входят.

## Цена
A: 0,6–1,4 с на шаг RK2 (6·10³ частиц, 3,4·10³ панелей, ядро без атомарного разбиения; после — в 40 раз быстрее на кольцах), нагрев потоком 0,4 с/шаг (4,8·10³ частиц). C: 7–9 с на высоту (2·10⁴ колец, 2·10⁵ звеньев, ×18 изображений/сдвигов, 3 снимка); GPU RTX 4070 SUPER, f64.

## Что не сделано / границы
- Нет вовлечения и трения; невязкое; ядра фиксированы; фон не растягивает вихри. Нет эксперимента для термика у склона.
- Кольца C не взаимодействуют (нет аннигиляции/перезамыкания/каскада), единый масштаб кольца для ℓ, изотропия по u.
- Экранировка — равновесие среднего поля, а не эволюция шкалы; стратификацию кольца не меняют (N² не смешивается).
- Над рельефом C — локальный ансамбль у трёх точек одного холма, не поле по всему рельефу.
