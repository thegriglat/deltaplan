# rotor3d — нить ротора с геометрическим замыканием (SWD7 v1)

Запуск тестов: `tools/research/sw_charges_3d/py -m pytest -q tools/research/sw_charges_3d/rotor3d/tests -s` (9 тестов,
≈ 7 мин на CPU, если GPU занят: `tests/conftest.py` прячет CuPy, когда свободно < 3 ГиБ; на GPU — минуты). Проверка имён:
`contract/check_contract.py api rotor3d`. Только вызывает `panels3d`, `filaments3d`, `sheet3d.foppl` (сбор хребтов, ось,
замкнутая подкова, порог Хеда — импортом; `sheet3d` не менялся); из `panels3d.influence` — `panel_velocity(..., self_idx)`.

## Что считается
- `rotor_vortex(panels, bg, z0, infl=None, params=None)` → `(fil, sigma, info)`; `velocity_rotor(...)` = `velocity_jh(couple=True)`
  с `extra = induced(fil)` (без нити — побитно `velocity_jh`).
- **Правило геометрии** (`profile_rule`, один на все места): профиль земли вдоль ветра через середину оси хребта,
  сглаживание σ = 2·ds_min (как `hill_length`). x_c — гребень; x_r — ближайшая по ветру из (подножие: первый минимум
  сглаженного профиля за гребнем | середина пути до следующего гребня «valley_mid»); если минимума нет (Agnesi, C2: спад
  монотонный до края) — подножие там, где остаётся `tail_frac` = 10 % высоты над основанием профиля (допущение: в контракте
  случая «минимума нет» нет); x_m = x_c + `m_frac`·(x_r − x_c), `m_frac` = 0,5 (контракт); нить — прямая вдоль оси хребта
  через x_m + R·n, n — нормаль к сглаженному склону в x_m; длина — протяжённость гребня; концы — замкнутая подкова (`sheet3d`).
- **Два условия** — касательная скорость по ветру (МНК-плоскость по панелям в радиусе 1,5·ds_min, как в `sheet3d`) = 0 в x_c
  и в x_r. Панели линейны по `extra`, поэтому u_t(x_i) = a_i + Γ·b_i(R): a_i — от фона (одно решение), b_i — одно решение
  панелей с единичной нитью при фоне 0 на каждое R. Γ = −a₁/b₁ из первого условия, R — корень g(R) = (a₂ + Γ·b₂)/U
  (три R/H на геометрической сетке от 2,5·core/H до 3, затем обратная квадратичная интерполяция/ложное положение). σ итога —
  σ_bg + Γ·σ_ед без нового решения (проверено тестом против прямого решения). Корень принимается при |g| < 1e-3, Γ > 0.
- **Пороги**: `gate="head"` (по умолчанию) — отрыв Хеда за хребтом (`_gate_by_separation`); `"slope"` — макс. подветренный уклон
  сглаженного профиля между x_c и x_r > `slope_min` (0,27); `"none"`. `info["candidates"]` — для каждого хребта оба
  флага и уклон независимо от выбранного порога.
- `info`: `ridges` (`x_c, x_r, x_m, rule_r, R, Gamma, s, h, gate, placed, converged, residual, nsolve, ut_bg, grid`), `candidates`,
  `n_ridges`, `n_rejected`, `n_unconverged`, `nsolve` (решений панелей), `t_s`.

## Результат: корня нет
`ut_bg` — касательная скорость фона (бг + панели) в x_c и x_r; `g(R)` на сетке R/H.

| Случай (N панелей) | x_r, м (правило) | u_t фона x_c / x_r, м/с | g(R) на сетке (контракт, m_frac 0,5) | с m_frac 0,3 |
|---|---|---|---|---|
| Agnesi H/L 0,5 (a = 250 м, H = 125 м, ds 50, N 4250) | 725 (подножие, хвост 10 %) | 17,2 / 3,7 | −0,82; −0,82; −0,77 | R = 65 м, Γ = 3,8·10⁴ м²/с = 20·U·H |
| C2 (H 250, L 300, ds 60, N 7308) | 925 (хвост 10 %) | 15,6 / 4,3 | −1,15; −1,09; −0,80 | R = 146 м, Γ = 3,4·10⁴ м²/с |
| C4 (H 203, ds 60, N 8794) | 955 (хвост 10 %) | 8,5 / 2,7 | −0,94; −0,95; −0,94; −0,89; −0,78 (gate none) | — |

- **Почему.** g(R) < 0: если Γ гасит u_t на гребне, у подножия перелёт (−0,8…−1,1·U). Потенциальная скорость на гребне в 4–6 раз
  выше, чем у подножия; индуцированная нитью на земле (с изображением) убывает как Γ·h/(π(d²+h²)) и в симметричном расположении
  почти одинакова в обеих точках (b₂/b₁ ≈ 0,7–1), а нужно b₂/b₁ = a₂/a₁ ≈ 0,2–0,3 — нить в 2–3 раза ближе к гребню. Пока
  геометрия делит x_c…x_r пополам (контракт), корня нет ни при каком R (проверено до R = 3·H; при R → ∞ g → (a₂ − a₁)/U).
- **Сдвиг x_m (диагностика, не контракт).** `m_frac` 0,3 даёт корень, но Γ ≈ 20·U·H (в 2D-пределе Фёппля 1–12·U·R), под
  нитью u∥ у земли до −167 м/с (Agnesi) и −75 м/с (C2): условие u_t = 0 на гребне, где потенциальная скорость 17 м/с, нить
  может выполнить только нефизичной силой. Зона u∥ < −0,5 м/с на 15 м над землёй за гребнем C2: 840 м (у Пикара L ≈ 800 м) —
  совпадение за счёт нефизичной Γ, не подтверждение. Положение m_frac не подбиралось (взяты 0,3 и 0,15 для показа
  чувствительности: при 0,15 корень R = 299 м, Γ = 1,5·10⁴; при 0,08 корня нет).
- **Пороги на C2/C4.** C2: Хед да, уклон 0,40 да. C4: Хед **да** (ложный ротор по порогу, x_c = 85 м, H 203 м), уклон 0,249 < 0,27
  — нет. Нить на C4 не ставится из-за отсутствия корня, а не из-за порога; порог по уклону отделяет C2 от C4, порог Хеда — нет.

## Цена
N 4250 (CPU, 1 ядро): `rotor_vortex` с корнем — 4 решения панелей (≤ 5), без корня — 3; время ≈ 15 с (решение — 0,03 с, остальное —
BS нити по N центроидам и окна `panel_velocity`; на GPU — меньше). N 7308 (C2, m_frac 0,3): 7 решений (в контракт ≤ 5 не
укладывается: сетка 3 + 4 уточнения).

## Границы модели
Нить прямая, одна на хребет, по линии тока через середину оси (вдоль-хребтовой изменчивости рельефа нет); вихрь в потенциальном
потоке не равновесен (положение задано правилом, не динамикой); поле в слое Jackson–Hunt с `couple=True` раздувает обратный поток
(как в `sheet3d`); «подножие» при монотонном спаде — допущение 10 %.
