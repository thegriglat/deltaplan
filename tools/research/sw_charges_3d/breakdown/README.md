## 1. Какое S и какой порог применимы

Число закрутки определено по-разному, и пороги несравнимы между определениями:
- струя (Gupta, Lilley, Syred 1984): S = G_phi/(R G_x), поток момента импульса / поток осевого импульса; порог распада в
  струях ~0.6, но в литературе 0.45–0.95 (зависит от конфигурации).
- изолированный вихрь (Batchelor): q = Gamma/(2 pi a W) или swirl ratio v_theta,max/W; порог Squire/Benjamin ~1.0–1.5.
- Re-Omega карта (Escudier 1988): порог растёт при малых Re, при большом Re — плато; в турбулентной атмосфере (Re ~ 1e8) — плато.

Применимость к лежачему вихрю у склона: пороги получены для (а) струи/трубы с заданным осевым потоком, (б) свободного
вихря в бесконечной среде. Лежачий ротор отличается: земля рядом (изображения, асимметрия), осевой поток не задан, а
создаётся стоком (Бюргерс: W = a_s z, растяжение), нет стенок трубы, турбулентность. Поэтому порог применим как
ОЦЕНКА порядка, а не как точная граница. Для SWD9 v2 разумное определение: S = v_theta,max / W, где W — осевой отток
из ядра звена: W = |q| l / (pi a^2) (q — сток на ед. длины, l — длина звена, a — радиус ядра). Диапазон порога
для этого S: **S_c in [1.0, 1.5]**: ниже 1.0 — "есть", 1.0–1.5 — "дышит", выше 1.5 — "нет". Если брать
определение струи (S_jet) — [0.45, 0.95]; пересчёт между S_jet и v_theta/W зависит от профиля (грубо S_jet ~ 0.5–0.7 v_theta/W
для Ламба–Озина) — НЕ проверено, в контракт лучше брать одно определение.
Q = 0 даёт S -> бесконечность: распад ("нет"), согласуется с предельным случаем SWD9.

## 3. Оценка S и диапазона E (s_vs_E.py)

Допущения: l = 2H (по SWD9), a = H/2, Gamma = 0.5 u_t^2 tau, q = E u_t L_s (формулы SWD9), u_t(x_c) = 0.5 U,
v_theta,max = 0.64 Gamma/(2 pi a). Результат аналитически не зависит от H, U, L_s:
S = v_theta,max/W ~ 0.02/E (при u_t/U=0.5, l/a=4); 45 комбинаций H in {100,200,400}, U in {8,12}, L_s/H in {3,4,5}.

| E | S (по v_theta/W) | state по [1.0, 1.5] |
|---|---|---|
| 0.01 | 2.0 | нет |
| 0.02 | 1.0 | дышит (граница) |
| 0.05 | 0.40 | есть |
| 0.10 | 0.20 | есть |
| 0.20 | 0.10 | есть |

Порог E: E_c(S=1.5) = 0.013, E_c(S=1.0) = 0.020 (дышит при E из [0.013, 0.020]). Итог: при E из диапазона
литературы 0.02–0.10 ротор есть/дышит; "нет" только при E < ~0.013 (почти нет вовлечения).

## 4. Рекомендация и границы

- E: одно значение по умолчанию 0.05, проверка присутствия при E in {0.02, 0.05, 0.10}; ротор должен быть во всём
  диапазоне — по этой оценке так и есть (S <= 1.0).
- Тест "Q = 0 -> нет" корректен (S -> inf); "дышит" на E ~ 0.013–0.02 — граница для инварианта.
- Границы: оценка однопараметрическая (S ~ 1/E), зависит от допущений u_t/U, l/a, a=H/2; пороги получены для струй
  и изолированных вихрей, не для вихря у стены. Прямых измерений осевого оттока ротора не найдено (Perdigão-статьи
  дают рециркуляцию и TI, не W вдоль оси); E из слоя смешения — перенос по аналогии. Без подгонки по месту.
