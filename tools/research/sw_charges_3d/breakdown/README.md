## 1. Какое S и какой порог применимы

Число закрутки определено по-разному, и пороги несравнимы между определениями:
- струя (Gupta, Lilley, Syred 1984): S = G_phi/(R G_x), поток момента импульса / поток осевого импульса; порог распада в
  струях ~0.6, но в литературе 0.45–0.95 (зависит от конфигурации).
- изолированный вихрь (Batchelor): q = Gamma/(2 pi a W) или swirl ratio v_theta,max/W; порог Squire/Benjamin 1.0–1.2 (см. 1а).
- Re-Omega карта (Escudier 1988): порог растёт при малых Re, при большом Re — плато; в турбулентной атмосфере (Re ~ 1e8) — плато.

Применимость к лежачему вихрю у склона: пороги получены для (а) струи/трубы с заданным осевым потоком, (б) свободного
вихря в бесконечной среде. Лежачий ротор отличается: земля рядом (изображения, асимметрия), осевой поток не задан, а
создаётся стоком (Бюргерс: W = a_s z, растяжение), нет стенок трубы, турбулентность. Поэтому порог применим как
ОЦЕНКА порядка, а не как точная граница. Для SWD9 v2 разумное определение: S = v_theta,max / W, где W — осевой отток
из ядра звена: W = |q| l / (pi a^2) (q — сток на ед. длины, l — длина звена, a — радиус ядра). Диапазон порога
для этого S: **S_c in [0.9, 1.2]** (уточнено по первоисточнику, п. 1а): ниже 0.9 — "есть", 0.9–1.2 — "дышит", выше 1.2 — "нет". Если брать
определение струи (S_jet) — [0.45, 0.95]; пересчёт между S_jet и v_theta/W зависит от профиля (грубо S_jet ~ 0.5–0.7 v_theta/W
для Ламба–Озина) — НЕ проверено, в контракт лучше брать одно определение.
Q = 0 даёт S -> бесконечность: распад ("нет"), согласуется с предельным случаем SWD9.

### 1а. Открытый первоисточник (NASA NTRS, текстовый слой PDF прочитан)

Spall, Gatski & Grosch 1987, Phys. Fluids 30, 3434 = ICASE Report 87-3 / NASA CR-178232,
https://ntrs.nasa.gov/citations/19870008595 (PDF https://ntrs.nasa.gov/api/citations/19870008595/downloads/19870008595.pdf).
Цитаты чисел из текста: критерий Squire (стоячая волна возможна при) k = V_max/W >= 1.20 (вихрь Рэнкина, W=const) и
k >= 1.00 (второй случай, V_max = 0.638 V_0); Benjamin даёт то же условие; Ro = W/(r* Omega), k — обратная величина
для составного вихря; критическое Ro ~ 0.64–0.65 для симметричного распада концевого вихря при Re > 50 (при меньших Re
ниже); опыт Garg & Leibovich: пузырь при локальном Ro 0.63–0.67, спираль при Ro ~ 0.7 (спираль — при меньшей закрутке);
Uchida & Nakamura: пузырь при Ro = 0.64; вихри передней кромки крыла — Ro около 1 (k ~ 0.6–0.7, "по опыту", без анализа).
Вывод: в определении v_theta,max/W порог k_c ~ 1.0–1.2 (концевые вихри, пузырь), спираль и вихри передней кромки — ниже
(до ~0.65). Диапазон для SWD9: [0.9, 1.2] (0.9 ~ Ro 0.7 спираль). Верхняя граница 1.5 из первой версии (q=1.5 Batchelor) —
граница УСТОЙЧИВОСТИ по инерционной неустойчивости, не порог распада, и убрана.
Определение Ro/k тут для вихря в трубе/свободного; для вихря у земли не проверено. Squire 1960, Benjamin 1962, Garg &
Leibovich 1979 прочитаны только через Spall (вторично). Второй независимый первоисточник открыть не удалось
(ODU/ResearchGate/CORE — HTTP 403; arXiv 1809.07603 даёт только ссылки на Leibovich 1978 и Escudier 1984/1988 без чисел).

## 3. Оценка S и диапазона E (s_vs_E.py)

Допущения: l = 2H (по SWD9), a = H/2, Gamma = 0.5 u_t^2 tau, q = E u_t L_s (формулы SWD9), u_t(x_c) = 0.5 U,
v_theta,max = 0.64 Gamma/(2 pi a). Результат аналитически не зависит от H, U, L_s:
S = v_theta,max/W ~ 0.02/E (при u_t/U=0.5, l/a=4); 45 комбинаций H in {100,200,400}, U in {8,12}, L_s/H in {3,4,5}.

| E | S (по v_theta/W) | state по [0.9, 1.2] |
|---|---|---|
| 0.01 | 2.0 | нет |
| 0.02 | 1.0 | дышит |
| 0.05 | 0.40 | есть |
| 0.10 | 0.20 | есть |
| 0.20 | 0.10 | есть |

Порог E: E_c(S=1.2) = 0.017, E_c(S=0.9) = 0.022 (дышит при E из [0.017, 0.022]). Итог: при E из диапазона
литературы 0.02–0.10 ротор есть/дышит; "нет" только при E < ~0.017 (почти нет вовлечения).

## 4. Рекомендация и границы

- E: одно значение по умолчанию 0.05, проверка присутствия при E in {0.02, 0.05, 0.10}; ротор должен быть во всём
  диапазоне — по этой оценке так и есть (S <= 1.0; при E=0.02 — "дышит").
- Тест "Q = 0 -> нет" корректен (S -> inf); "дышит" на E ~ 0.017–0.022 — граница для инварианта.
- Границы: оценка однопараметрическая (S ~ 1/E), зависит от допущений u_t/U, l/a, a=H/2; пороги получены для струй
  и изолированных вихрей, не для вихря у стены. Прямых измерений осевого оттока ротора не найдено (Perdigão-статьи
  дают рециркуляцию и TI, не W вдоль оси); E из слоя смешения — перенос по аналогии. Без подгонки по месту.

## 5. SWD-16b: сверка с обзором Lucca-Negro & O'Doherty 2001, градиент давления и Re ядра

Источник (дан пользователем): O. Lucca-Negro, T. O'Doherty, «Vortex Breakdown: A Review», Prog. Energy Combust. Sci. 27 (2001) 431–481
(выходные данные — по карточке задачи; PDF `Vortex.pdf` лежит в корне main, в репозиторий не копируется, лицензия — издательская, текст не цитируется

### 5.1 Сверка S_c ∈ [0,9; 1,2]

Обзор (Lucca-Negro & O'Doherty 2001, раздел «Theoretical», критерий Squire/Benjamin): параметр k = v_θ,max/W (отношение максимальной
азимутальной скорости к осевой); критическое k лежит между 1 (экспоненциальный профиль закрутки) и 1,2 (вихрь Рэнкина, W = const);
Benjamin для составного вихря приходит к k ≈ 1,2 (со ссылкой на Spall+ 1987). Это ровно та же пара, что в п. 1а (Spall+ 1987 из NTRS);
обзор — независимое подтверждение, которого не было (пометка «открыть второй источник» из п. 1а снята для Squire/Benjamin).
Критерий Spall+ 1987 в обзоре: Ro = U/(Ω r_core) < Ro_c ≈ 0,65 при Re_core > 100; ниже по Re_core Ro_c меньше. Определение S = v_θ,max/W
в SWD9 v5 совпадает с k Squire (не со струйным S_jet), так что диапазон [0,9; 1,2] применим «как есть» **для изолированного осесимметричного
вихря**. Нижняя граница 0,9 (спираль, Ro ≈ 0,7) в обзоре прямо не названа — она из Spall+ 1987/Garg–Leibovich по п. 1а; обзор лишь
подтверждает, что спираль возникает при меньшей закрутке, чем пузырь («spiral always occurs before axisymmetric breakdown»).
Оговорка обзора, важная для нас: порог зависит от профиля закрутки и осевого профиля (Hallett & Toews 1987: большое ядро твёрдого вращения и
осевой максимум на оси — порог выше; Farokhi+ 1989: интегральное число закрутки недостаточно, нужны размер ядра и профиль), а «критическое»
у Squire/Benjamin — условие существования стоячих волн, а не сам срыв.

### 5.2 Неблагоприятный градиент давления (обзор, раздел «Adverse Pressure Gradient»)

Качественно (обзор): положительный осевой градиент давления смещает срыв вверх по потоку и переводит спираль в пузырь (Sarpkaya 1971a,
Narain 1977, Spall & Gatski 1990/91, Breuer & Hänel 1989); дозвуковое торможение к выходу трубы инициирует срыв (Sarpkaya). Количественно в
обзоре одна ссылка: по Lambourne 1967 при наложенном градиенте критическое k оказывается ниже 1.2 «и даже ниже 1»; Sarpkaya 1974 — срыв при
v_θ,max < W в неблагоприятном градиенте. Числа k_c(dp/dx) в обзоре нет. Также (Hall 1967, Escudier 1988): на оси градиент давления усиливается
закруткой — для Рэнкина dp/dx|₀ = dp/dx|∞ + 2ρ v_max² a'/a (мой вывод: p∞ − p₀ = ρ v_max²), то есть растущее ядро (a' > 0) даёт неблагоприятный
градиент на оси даже при нулевом внешнем (Krause 1985: растущее ядро -> срыв неизбежен). Для ротора за хребтом ядро растёт при присоединении —
вклад работает в ту же сторону.

Собственная оценка порядка (Бернулли по оси, п. 5.3): внешний подъём давления dp = c·ρW²/2 даёт W_eff = W√(1−c), порог k_c(c) = k_c0·√(1−c).
Это согласуется с обзором по направлению и по «ниже 1», но коэффициента из эксперимента нет.

### 5.3 Числа (adverse_re.json)

| c = dp/(ρW²/2) | k_c (нижняя / верхняя граница) |
|---|---|
| 0 | 0,90 / 1,20 |
| 0,2 | 0,81 / 1,07 |
| 0,5 | 0,64 / 0,85 |
| 0,9 | 0,29 / 0,38 |

c, нужное, чтобы chain_jh на Perdigão (S = 1,7–4,0 по SWD-17) перешёл из «нет» в «дышит/есть»: S = 1,7: c = 0,50–0,72; S = 4,0: c = 0,91–0,95.
Реальное c для хребта: dp = Cp·ρU²/2, а W при E = 0,02/0,05/0,10 равен 0,10/0,26/0,51 U (из s_vs_E: W/U ≈ 5,1 E при L_s/H = 4, u_t/U = 0,5),
поэтому c = Cp·(U/W)². При Cp = 0,1 (подъём давления в области присоединения за хребтом порядка 10 % скоростного напора, допущение, не из обзора):
c = 9,7 / 1,5 / 0,39. То есть при E ≤ 0,05 внешний градиент по порядку не меньше, а больше «напора» стока: ось тормозится до остановки и без
всякой закрутки, а при E = 0,10 (W ~ U/2) и Cp ≈ 0,1 порог снижается всего на 10–20 %. Вывод: определять S через W стока с константным порогом нельзя
применять там, где есть внешний подъём давления: «нет» при S = 1,7–4 в chain3d может быть следствием выбора W (напор стока мал), а не отсутствия
срыва.

### 5.4 Re ядра

Обзор: зависимость от Re — эффект завихренности, а не вязкости (Re_tube); критическое Ro ≈ 0,65 при Re_core > 100 (Spall+ 1987), ниже —
меньше (то есть нужна БОЛЬШАЯ закрутка, k_c растёт; цифр для Re_core < 100 в тексте обзора нет, только график). Критерий Escudier–Zehnder
Re_B ≈ −3R⁻¹ (трубный, малые R) к нашему случаю не применим. Re_core = Γ/(2πν_eff) при Γ = 300–1000 м²/с (SWD9): молекулярная вязкость —
3·10⁶–10⁷ (плато, k_c не меняется); ν_eff = 0,1 м²/с — 480–1600; ν_eff = 1 — 48–160; ν_eff = 10 — 5–16 (ниже 100). Турбулентная вязкость
ядра ротора в ПС атмосферы неизвестна (в нейтральном ПС ν_t ~ κu*z ~ 20 м²/с на 100 м, но вращение подавляет турбулентность в ядре); если ν_eff
выше ~0,3–1 м²/с, порог по Re надо повышать, противоположно эффекту градиента. Обзор отмечает и турбулентный срыв (Spall & Gatski 1995):
завихренность за пузырём втрое ниже, чем в ламинарном — повторные пузыри менее вероятны; сам порог для турбулентного ядра в обзоре не дан.

### 5.5 Рекомендация и границы

- Диапазон S_c [0,9; 1,2] для изолированного вихря **подтверждён**, не менять. Для лежачего ротора за хребтом ввести отдельно (без подгонки)
  поправку на внешний градиент: либо k_c(c) = k_c0·√(1−c) с c = Cp·(U/W)² из давления Пикара/потенциального поля в области присоединения,
  либо определять W не по стоку, а по осевой скорости на оси с учётом давления. Для SWD-17 вопрос «пересматривать S_c или E/R_rule/Γ» —
  не S_c глобально, а определение W/давление; проверка: посчитать c по полю давления на реальных хребтах Perdigão.
- Re-поправку оставить на потом: нужен ν_eff ядра, данных нет.
- Границы: обзор не содержит числа k_c(градиент) и данных для горизонтального вихря у земли; обзор подчёркивает, что срыв зависит от всего поля
  давления и скорости, а не от нескольких параметров (Hall 1972) — наша оценка (Бернулли по оси, Cp = 0,05–0,3, одна сила на ось) верна по
  порядку и направлению, не как количественный закон. Проверять против эксперимента, а не по «нравится».
