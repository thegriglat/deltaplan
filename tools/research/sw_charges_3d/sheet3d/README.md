# sheet3d — установившаяся нить ротора Фёппля (SWD6 v2)

Запуск тестов: `tools/research/sw_charges_3d/py -m pytest -q tools/research/sw_charges_3d/sheet3d/tests -s` (7 тестов, ≈ 1,5 мин
на RTX 4070 SUPER; 5 тяжёлых — только с CuPy). Проверка имён: `contract/check_contract.py api sheet3d`.
Только вызывает `panels3d` (`build_panels`, `assemble`/`solve` с `infl`, `velocity`, `velocity_jh(couple=True)`,
`separation3d`, `hill_length`) и `filaments3d` (`Filaments`, `induced`, `imbalance`); из `panels3d.influence` берётся
`panel_velocity(..., self_idx)` (скорость в центроидах с собственным членом) — в публичный API её нет, замечание в отчёте.

## Что считается
- `foppl_vortex(panels, bg, z0, infl=None, params=None)` → `(fil, sigma, info)`; `velocity_foppl(...)` = `velocity_jh(couple=True)`
  с `extra = induced(fil)` (без нитей — `extra=None`, поле побитно равно `velocity_jh`).
- **Хребты.** Гребни `hill_length` на линиях поперёк ветра (шаг 2·ds_min), гребни соседних линий в пределах 2·ds_min — один
  хребет (≥ 2 линий); ось — МНК/SVD по точкам гребня, `n_a` — поперёк оси по ветру, Γ > 0 вдоль оси `a = ẑ × ŵ`
  (в слое сдвига ω_y = ∂u/∂z − ∂w/∂x > 0). Хребет принимается, если `separation3d` (Хед, σ_bg, `lee_only`) даёт отрыв за ним
  в полосе хребта (`gate="head"`; `"none"` — не проверять).
- **Нить.** Прямая на высоте z = ground(середина) + h, смещена на s по `n_a`, длина — протяжённость гребня по линиям.
  Ножки — вертикальные, до поверхности панелей (якорные узлы).
- **Три неизвестных (s/H, h/H, Γ/(U·H))**, три уравнения (`scipy.optimize.root`, hybr, старт (1, ½, 1)): скорость в середине
  нити (фон + панели + все нити, самоиндукция прямого участка ровно 0 — точка на оси) вдоль `n_a` и по `z` равна нулю
  (равновесие, Föppl 1913); касательная скорость вдоль `n_a` в точке отрыва (МНК-плоскость по панелям в радиусе
  1,5·ds_min) равна нулю. Точка отрыва: `sep="crest"` — гребень на середине нити (решение пользователя), `"separation3d"` —
  точка Хеда ближайшей линии, `params["sep_point"]=(x, y)` — произвольная (для 2D-предела; не в контракте).
- Корень принят, если |r|/U < `tol` (1e-3), 0 < s ≤ 6H, 2·core ≤ h ≤ 3H (иначе — корни на бесконечности и в ядре у земли);
  при отказе — до 8 запасных стартов на сетке (s, h) с Γ из МНК по двум линейным по Γ уравнениям равновесия. Нет корня —
  `converged=False`, нить не ставится, счётчик `n_unconverged`.
- Несколько хребтов — по очереди (Гаусс — Зейдель, `sweeps=2`), прочие нити входят в `extra` как заданные.
- `info`: `ridges` (`x_c, y_c, axis, L_axis, H, s, h, Gamma, converged, residual, iters, starts, p_sep`), `n_ridges`,
  `n_rejected`, `n_unconverged`, `nfev` (вычислений невязки), `t_s`.

## Важное: подкову нужно замыкать под землёй
Открытая подкова (две ножки, оканчивающиеся на панелях) как `extra` панелей даёт неверное отражение: Био — Савар открытой
линии не соленоидален — на концах «фантомные заряды»; поток через панели закрывает их неверно. Замер (плоская земля,
линия 2 км на h = 100 м, Γ = 1000, панели `ds` 20–40 м, `far_m` 800–10 000 м): скорость у нити от панелей 0,647 против 0,794
по методу изображений (−19 %), от разрешения не зависит. Замкнутая петля (ножки продолжены под землю, возврат под землёй
на глубине h + core) даёт 0,808 против 0,810 (±0,2 %; от глубины возврата не зависит) — в воздухе завихренности по-прежнему
только подкова, возврат лежит в теле. Поэтому `fil` — замкнутая петля из подковы и подземного возврата (узлы на поверхности —
якорные). Метод изображений на рельефе недоступен — замыкание универсально.

## Числа
**2D-предел** (полуцилиндр R = 100 м, длина 20R, `bg_uniform(10)`, отрыв при θ = 60° от оси по ветру, `sep_point`).
Эталон — вихрь Γ над стенкой, цилиндр |z| = R, изображения в стенке (−Γ в z̄₀) и в окружности (−Γ в R²/z̄₀, +Γ в R²/z₀),
u = v = 0 в z₀ без собственного члена и нулевая касательная скорость в R·e^{iθ}: s = 2,166R, h = 0,978R, |Γ| = 11,90·U·R.
| ds_min | N | s, R | h, R | Γ, U·R | отклонение s / h / Γ |
|---|---|---|---|---|---|
| R/5 (20 м) | 8376 | 1,986 | 0,891 | 10,58 | −8 / −9 / −11 % |
| R/6,7 (15 м) | 10952 | 2,105 | 0,951 | 11,32 | −2,8 / −2,7 / −4,9 % |
Длина 30R вместо 20R меняет s, h, Γ на 0,2–0,6 % (ошибка — дискретизация цилиндра, не длина). θ = 70°, ds 20 м: s, h, Γ на
−8 / −8 / −11 %. Обратный u∥ на 10 м над землёй на 40 и 80 м за подножием склона: с нитью −17,8 и −29,1 м/с (U = 10), без нити +1,9 и +3,6;
скорость в слое Jackson–Hunt с ΔS < −1 и усилением A > 1 (формула `velocity_jh`) сильно раздувает обратный поток — граница.

**Цена.** N = 10 952: нить 10,9 с (152 вычисления невязки, каждое — решение LU с кешем + скорость в центроидах), холодное решение
панелей (сборка + LU + решение) 7,0 с: отношение 1,6 (≤ 20). Один вызов невязки ≈ 0,07 с, это не «20 решений»: если считать
решением только `solve` с готовым LU (0,03 с), то нить ≈ 150 таких решений.

## Что НЕ получилось (модель)
- **Отрыв в вершине (контракт, `sep="crest"`) корня не имеет.** 2D: вдоль кривой равновесия Фёппля касательная скорость в вершине
  полуцилиндра остаётся положительной (0,42U на y₀ = 2R, 0,18U на 3,2R) и стремится к нулю только при уходе вихря в
  бесконечность (тест `test_2d_reference_crest_has_no_finite_root`). Нулевая касательная скорость достигается лишь ниже по
  склону (θ ≈ 30–65° от оси по ветру на ветви y₀ ≤ 1,2R). 3D-полуцилиндр с отрывом в вершине — тоже `converged=False`.
- **Agnesi H/L 0,5 (a = 250 м, H = 125 м, длина 1500 м, N = 8662) + bg_profile(10 м/с, α 0,2):** гребень найден, отрыв по Хеду
  на 192 м за гребнем есть, но ни для `crest`, ни для `separation3d` корня с s > 0 нет: единственные корни — s ≈ 0 (вихрь над
  гребнем, h ≈ 0,64H) или s < 0 (отброшены). Скан при w = 0 (первая версия, с открытой подковой — только как ориентир): u⊥ в точке вихря
  +0,1…0,8·U (фон + потенциал сносят вихрь вниз по ветру), нулевая касательная скорость требует Γ ~ 4–6·U·H, при которой u⊥ > 0,5U.
  В итоговой версии (замкнутая петля) — 9 стартов (до 30 вычислений каждый), 288 вычислений, корня с s > 0 нет. s/H, h/H, Γ/(U·H) и
  обратный u∥ на 10 м за гребнем — **нет** (нить не ставится, поле = `velocity_jh`). Причина — не разрешение (H/ds 5, ядро
  ds/2) и не длина, а само замыкание «равновесие + Kutta в заданной точке» в потенциальной постановке.
- У вихря в `core` у земли (h < 2·core) разрешения нет: H/ds ≥ 5 обязательно.
- Фоновый сдвиг ветра (`bg_profile`) входит в уравнения равновесия только через скорость в точке вихря; самоиндукции изгиба нет.
