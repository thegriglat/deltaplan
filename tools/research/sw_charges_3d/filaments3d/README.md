# filaments3d — вихревые нити 3D (SWD3)

Запуск тестов: `tools/research/sw_charges_3d/py -m pytest -q tools/research/sw_charges_3d/filaments3d/tests` (≈ 3 с).
Интерфейс — `docs/contracts/sw-charges-3d.md`, раздел SWD3; проверка имён — `contract/check_contract.py api filaments3d`.

## Модель
- `Filaments`: узлы `x`, отрезки `seg` (a→b), `gamma`, `core`, `anchored`, `fid`, `stats` (счётчики `split`, `merge`,
  `reconnect`, `lifted`, `removed`). `fid` — связные компоненты графа (пересчитывается в `step`/`shed`).
- Био — Савар отрезка с регуляризацией Розенхеда — Мура — **точная замкнутая форма**, без квадратуры:
  `u = Γ/(4π)·(t × r₀)·[(s−s₀)/(A·√((s−s₀)²+A))]₀ᴸ`, `A = |t × r₀|² + δ²`. Ошибка — округление (≈1e-16 отн.). Самоиндукция —
  сумма по всем отрезкам тем же ядром, без локального члена (смежные отрезки на узле дают 0 при коллинеарности).
- GPU (CuPy) — при N·K ≥ 1e6, иначе NumPy; `backend="numpy"|"cupy"|"auto"`. Тест на равенство CPU/GPU.
- `step`: RK2 (средняя точка) по `flow + induced`; Γ отрезка постоянна, растяжение — от движения узлов. Якорные узлы:
  касательная к `ground` составляющая скорости, затем z = ground(x, y) (нормаль — центральные разности, h = 0,5 м).
  Порядок: движение → дробление (вставка средней точки, повтор ≤ 10 раз) → слияние → перезамыкание → ядро
  (`core² += 4·nu_t·dt`) → затухание (`Γ·exp(−dt/tau_s)`) → земля и удаление.
- Слияние: отрезок короче `l_min` стягивается в узел (якорный остаётся; оба якорных — не сливаются); не сжимает нить
  до ≤ 4 отрезков; сумма потоков в узле сохраняется точно.
- Перезамыкание (Schwarz 1985; de Waele & Aarts 1994): пары отрезков с расстоянием середин < `r_rec` (по умолчанию
  среднее ядро пары), `cos` направлений < −0,5, без общих узлов: `a1→b1, a2→b2` ⇒ `a1→b2, a2→b1`. При неравных Γ
  сильный отрезок делится на два параллельных (общие узлы): остаток `Γ₁−Γ₂` и часть `Γ₂`, обменивается только `Γ₂`.
  Каждый отрезок — не больше одного обмена за шаг. Γ и баланс в узлах сохраняются точно (до округления).
- Земля: неякорный узел ниже `ground` → `ground + core/2` (`stats["lifted"]`); нить целиком удаляется, если > 50 % узлов
  под землёй (до подъёма), если max |Γ| < `gamma_min`, если все узлы за `bounds` (`stats["removed"]`).
- `shed`: `u_s` — **векторы** скорости слоя (M,3); Γ = ½·ū²·dt, ū — среднее модулей на концах отрезка; знак Γ — по
  `(n × û_t)·(b−a)`. Если Γ соседних отрезков различается (скорость вдоль линии меняется), разность уходит ножкой
  длиной `core` по −n в якорный узел (иначе ∇·ω ≠ 0). Для линии на земле (нормаль и узлы на поверхности) ножка
  привязывается к земле на следующем `step`.

## Отклонение от SWD3: константа скорости кольца
SWD3 даёт `Γ/(4πR)·(ln(8R/δ) − ½)`. Для ядра Розенхеда — Мура `(r²+δ²)^(−3/2)` численно (n = 128, 256, 512, R = 100,
Γ = 50, δ = 5: 0,1558; 0,1605; 0,1617 → предел ≈ 0,1621) получается `ln(8R/δ) − 1` = 0,1621; с −½ — 0,1820 (+12 %).
Константа −½ относится к другому профилю ядра (ср. Saffman 1992, §11: −¼ для равномерной завихренности, −1 для полого
ядра; RM ближе к полому). Тест 1 сверяет с `−1` (±3 %) и отдельно фиксирует, что −½ не подходит. Нужна правка SWD3.

## Границы модели
- Ядро нити не деформируется (растяжение не уменьшает `core`, нет сохранения объёма ядра); только диффузия `nu_t`.
- Перезамыкание — эвристика по близости середин отрезков, не по минимальному расстоянию между отрезками.
- Среди параллельных остатков после неравных обменов накапливаются малые отрезки; чистит `gamma_min` только целиком.
- Стенка — только через `flow` и `ground`, изображения нитей нет.
- Пары N·K — прямая сумма O(N·K), без дерева/FMM.
