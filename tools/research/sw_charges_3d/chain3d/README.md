# chain3d — ротор как цепочка «сток + вихрь» (SWD9 v5)

Тесты: `tools/research/sw_charges_3d/py -m pytest -q tools/research/sw_charges_3d/chain3d/tests -s` (19 тестов, ≈ 30 с).
Только вызывает `panels3d`, `filaments3d`, `sheet3d` (сборка хребтов, замкнутая петля), `rotor3d.profile_rule`.

## Электрическая аналогия
Ротор — **заряженный провод вдоль хребта, по которому текут его же заряды**. Заряды — линейный сток q (м²/с на единицу
длины, расход на единицу длины): они уходят вдоль оси к концам (осевой отток стока). **Движущиеся заряды — ток, а ток —
вихрь ротора** (Γ, ток вдоль оси провода; замыкается ножками в землю и под землёй, ∇·ω = 0 — «нет монополей»). **Склон —
зеркало**: провод и его отражение в земле (панели; в итерациях — изображение в касательной плоскости) держат ротор у
склона (притяжение Бьеркнеса). Отношение тока к заряду Γ/q — «скорость носителей»: 0 — чистый сток, ротора нет; выше
порога вихрь распадается. Связь порога с черенковскими подветренными волнами — **гипотеза, не проверена**.
Комплексная сила звена (Q − iΓ)·log z — спиральное течение.

## Что считается
- **Роторы**: по оси каждого хребта (`find_ridges`); правило уклона (`lee_slope`, одно для всех мест и для SWD7):
  максимум подветренного уклона профиля вдоль ветра между x_c и x_r при сглаживании 1·ds_min; участок оси с уклоном
  > `slope_min` (0,27, не подгоняется) — ротор. Agnesi H/L 0,5: 0,296. Концы — на краях участка (седловина → два ротора).
- **Звенья**: K = ceil(длина / l_link), l_link = 2·H. Γ_k = ½(u_t(x_c)² − u_t(x_r)²)·(x_r − x_c)/U_ref (Lighthill 1963;
  Morton 1984), q_k = −E·u_t(x_c)·(x_r − x_c), E = 0,05 по умолчанию (диапазон 0,02–0,10, SWD-16); источник −q_k на линии
  x_r (масса). Формулы Γ, q не менялись.
- **Ядро по геометрии**: r_c = R_rule·(x_r − x_c), R_rule = 0,25 (то же, что SWD7 v2), δ Розенхеда — Мура у нитей,
  стоков и источников = r_c; равновесие ищется при n ≥ r_c (n = r_c + H·y²); корень на границе — `on_ground`.
- **Положение звена (v5, `position="geometry"`, по умолчанию; ответ пользователя на Q4)**: без условия равновесия.
  s = (x_r − x_c)/2 от гребня вдоль ветра, n = r_c по нормали к сглаженному склону; звено держит его отражение (провод +
  зеркало, панели). Одно решение панелей со всеми звеньями-кандидатами (даёт `residual` — модуль скорости поперёк оси в
  середине звена, диагностика, и `u_min_over_U`), второе — только если часть роторов в state «нет» и поле остальных нужно
  без них: **n_solves ≤ 2** сверх фона. `converged` = True всегда (не критерий). `info["rotors"][].u_min_over_U` — минимум
  u∥/U на 10 м над землёй в 24 точках между x_c и x_r **с полем ротора, даже если state «нет»** (для отчёта; < 0 —
  обратное течение). State — по S честно; E, Γ, S_c, R_rule не подгонялись. Расход источника на линии присоединения
  пересчитывается на длину стока (сток идёт по рельефу, источник — по горизонтали): Σ расходов = 0 до 1e-9 и на реальном рельефе.
- **Равновесие v4 (`position="equilibrium"`) и цена**: итерации — без пересчёта панелей: фон + панели фона + цепочка + её зеркальное изображение в
  касательной плоскости земли у оси (вихрь −Γ, стоки тот же знак). Затем `n_corr` = 2 раза: решение панелей с цепочкой,
  смещение (точное − модельное) в серединах звеньев, новое равновесие. Итого **3 решения панелей** сверх фона (было 44).
- **Число закрутки (v4)**: S_k = v_θ,max/W, v_θ,max = |Γ_k|/(2π r_c), W = |q_k|·l_link/(π r_c²); S_c ∈ [0,9; 1,2]
  (Spall, Gatski & Grosch 1987): state по наибольшему S звеньев: < 0,9 «есть», до 1,2 «дышит», выше «нет» (поле не
  добавляется; `apply_state=False` — диагностика). Порог — для свободного вихря/трубы; к лежачему вихрю у склона **не
  подтверждён**. `info["rotors"]` — также `Gamma_over_q` = |Γ|/|q| (определение v3).

## Числа (v5, position="geometry")
Agnesi H/L 0,5, 7 звеньев, ds_min 50 м; C2/C4 — разрезы cascade-2d, вытянутые вдоль оси (тесты `test_cases.py`).

| Проверка | Результат |
|---|---|
| s, n звена | = (x_r − x_c)/2 и r_c ± 1 м у каждого звена (тест) |
| цена | Agnesi 1 решение панелей (state «нет» — диагностика), Perdigão 2 (часть роторов применена); ≤ 2 |
| Agnesi | S = 4,44 → state «нет»; \|u\|_min/U на 10 м = +0,06 (скорость вдоль ветра у склона не меняет знак), невязка в середине звена 0,93·U |
| C2 | ротор 6480 м, S = 3,51 → «нет», u_min/U на 10 м = −0,35 (при принудительном поле; L против ~800 м Пикара в тесте `test_c2…`) |
| C4 | роторов нет (уклон) |
| баланс масс | Σ расходов ≤ 1e-9·Σ\|q\| на хребте с переменной высотой (тест) |

### Чувствительность к E (Agnesi, apply_state=False)
| E | Γ/q | S | state | u_min/U на 10 м |
|---|---|---|---|---|
| ×½ (0,025) | 20,8 | 8,88 | нет | +0,07 |
| ×1 (0,05) | 10,4 | 4,44 | нет | +0,06 |
| ×2 (0,10) | 5,2 | 2,22 | нет | +0,04 |

Ротор не получен ни при какой E в разумном диапазоне 0,02–0,10: S > 1,2 везде (S ∝ 1/E, при E ×2 всё ещё 2,2). Для S ≤ 1,2
нужна E ≈ 0,18 — вне диапазона SWD-16 (**не подгонялось**).

## Границы модели
- Положение по геометрии (s = полпути от гребня до присоединения, n = r_c) — допущение пользователя (Q4), не решение уравнения;
  `residual` ≈ 0,9·U показывает, что скорость в середине звена с самим же полем далека от нуля: линия не «плавает».
- Порог S_c — для свободного вихря/трубы, для лежачего вихря у склона не подтверждён; связь с черенковскими волнами — гипотеза.
- Образ в итерациях v4 — приближение (плоскость в касательной у оси); в v5 итераций нет, зеркало даёт панельная часть.
- Уклон — по линиям вдоль ветра, не по линиям тока; звено — прямое отрезок, ядро r_c = 0,25·(x_r − x_c) велико (181 м у Agnesi)
  и ослабляет индуцированную скорость вихря до ~Γ/(4π r_c).
- v4 (для сравнения, `position="equilibrium"`): равновесия на Agnesi нет (невязка 0,9·U, 4 из 7 на границе n = r_c), обратного течения нет.
