# chain3d — ротор как цепочка «сток + вихрь» (SWD9 v4)

Тесты: `tools/research/sw_charges_3d/py -m pytest -q tools/research/sw_charges_3d/chain3d/tests -s` (16 тестов, ≈ 40 с).
Только вызывает `panels3d`, `filaments3d`, `sheet3d` (сборка хребтов, замкнутая петля), `rotor3d.profile_rule`.

## Электрическая аналогия
Ротор — **заряженный провод вдоль хребта, по которому текут его же заряды**. Заряды — линейный сток q (м²/с на единицу
длины, расход на единицу длины): они уходят вдоль оси к концам (осевой отток стока). **Движущиеся заряды — ток, а ток —
вихрь ротора** (Γ, ток вдоль оси провода; замыкается ножками в землю и под землёй, ∇·ω = 0 — «нет монополей»). **Склон —
зеркало**: провод и его отражение в земле (панели; в итерациях — изображение в касательной плоскости) держат ротор у
склона (притяжение Бьеркнеса). Отношение тока к заряду Γ/q — «скорость носителей»: 0 — чистый сток, ротора нет; выше
порога вихрь распадается. Связь порога с черенковскими подветренными волнами — **гипотеза, не проверена**.
Комплексная сила звена (Q − iΓ)·log z — спиральное течение.

## Что считается
- **Роторы**: по оси каждого хребта (`find_ridges`); правило уклона (`lee_slope`, одно для всех мест и для SWD7):
  максимум подветренного уклона профиля вдоль ветра между x_c и x_r при сглаживании 1·ds_min; участок оси с уклоном
  > `slope_min` (0,27, не подгоняется) — ротор. Agnesi H/L 0,5: 0,296. Концы — на краях участка (седловина → два ротора).
- **Звенья**: K = ceil(длина / l_link), l_link = 2·H. Γ_k = ½(u_t(x_c)² − u_t(x_r)²)·(x_r − x_c)/U_ref (Lighthill 1963;
  Morton 1984), q_k = −E·u_t(x_c)·(x_r − x_c), E = 0,05 по умолчанию (диапазон 0,02–0,10, SWD-16); источник −q_k на линии
  x_r (масса). Формулы Γ, q не менялись.
- **Ядро по геометрии**: r_c = R_rule·(x_r − x_c), R_rule = 0,25 (то же, что SWD7 v2), δ Розенхеда — Мура у нитей,
  стоков и источников = r_c; равновесие ищется при n ≥ r_c (n = r_c + H·y²); корень на границе — `on_ground`.
- **Равновесие и цена**: итерации — без пересчёта панелей: фон + панели фона + цепочка + её зеркальное изображение в
  касательной плоскости земли у оси (вихрь −Γ, стоки тот же знак). Затем `n_corr` = 2 раза: решение панелей с цепочкой,
  смещение (точное − модельное) в серединах звеньев, новое равновесие. Итого **3 решения панелей** сверх фона (было 44).
- **Число закрутки (v4)**: S_k = v_θ,max/W, v_θ,max = |Γ_k|/(2π r_c), W = |q_k|·l_link/(π r_c²); S_c ∈ [0,9; 1,2]
  (Spall, Gatski & Grosch 1987): state по наибольшему S звеньев: < 0,9 «есть», до 1,2 «дышит», выше «нет» (поле не
  добавляется; `apply_state=False` — диагностика). Порог — для свободного вихря/трубы; к лежачему вихрю у склона **не
  подтверждён**. `info["rotors"]` — также `Gamma_over_q` = |Γ|/|q| (определение v3).

всём диапазоне E, а при отключённом state поле слишком слабо.

## Границы модели
- Причина: при r_c = 181 м индуцированная скорость вихря у стены не превышает ~Γ/(4π r_c) ≈ 3 м/с (Γ ≈ 6500 м²/с),
  а скорость фона + панелей у линии на высоте ≥ r_c ≈ 17 м/с; корень не существует ни на границе, ни выше. Нужно
  пересмотреть Γ (в 5 раз больше) или R_rule / вид регуляризации (контракт); не подгонялось.
- Образец изображения в итерациях — приближение (плоскость в касательной у оси, изображение только центрального отрезка,
  без ножек); поправка — смещением в середине звена.
- Связь порога S_c с лежачим вихрем у склона, с черенковскими волнами — гипотеза.
- Уклон — по линиям вдоль ветра, не по линиям тока; звено — прямое горизонтальное.
