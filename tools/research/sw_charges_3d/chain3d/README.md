# chain3d — ротор как цепочка «сток + вихрь» (SWD9 v2)

Тесты: `tools/research/sw_charges_3d/py -m pytest -q tools/research/sw_charges_3d/chain3d/tests -s` (13 тестов, ≈ 20 с).
Только вызывает `panels3d`, `filaments3d`, `sheet3d` (сборка хребтов, замкнутая петля), `rotor3d.profile_rule`.

## Что считается
- **Роторы**: по оси каждого хребта (`find_ridges`) для линий тока вдоль ветра считается подветренный уклон между x_c и x_r
  профиля, сглаженного на `ds_min` (`slope_smooth`=1; при 2·ds_min Agnesi H/L 0,5 даёт 0,244 < 0,27 — порог отсекал бы
  его, при 1·ds_min 0,296). Непрерывный участок оси с уклоном > `slope_min` (0,27) — ротор; концы — на краях участка
  (седловина, конец хребта) ± шаг оси. На хребте несколько роторов — по числу участков.
- **Звенья**: K = ceil(длина ротора / l_link), l_link = 2·H (суброторы, Doyle & Durran 2007 — допущение об масштабе).
  Звено — прямой отрезок оси: вихрь (замкнутая петля с возвратом под землёй, ножки на концах, ∇·ω = 0 точно) и линейный
  сток на той же линии. Γ_k = ½(u_t(x_c)² − u_t(x_r)²)·(x_r − x_c)/U_ref (Lighthill 1963; Morton 1984), q_k =
  −E·u_t(x_c)·(x_r − x_c), E = 0,09 = ½·dδ_ω/dx при dδ_ω/dx = 0,181 (Brown & Roshko 1974, U2 = 0; одно значение, оценка
  расхода слоя). Источник −q_k на линии x_r на высоте 2·core (масса: Σ q·L = 0 до 1e-16).
- **Положение** (s по ветру от гребня, n по нормали к сглаженному склону): скорость в середине звена (фон + панели +
  поле цепочки) = 0 поперёк оси, 2 уравнения на звено, `scipy.optimize.root(hybr)` совместно; старт s=(x_r−x_c)/2,
  n=H/2. Самоиндукция прямого отрезка в его середине равна нулю по симметрии. Принимается: невязка < 2e-3·U,
  0 < s ≤ 6H, 1,5·core ≤ h, n ≤ 3H; иначе звено снимается.
- **Состояние**: S = |Γ̄|/|q̄| (по звеньям, взвешено длиной; тангенс угла спирали (Q − iΓ)·log z), диапазон распада
  S_c = 1,0–1,3 (Leibovich 1978; Escudier 1988 — порядок величины для вихря с осевым потоком, перенос на лежачий смерч —
  допущение): S < 1,0 «есть», до 1,3 «дышит», выше «нет» (поле не добавляется; `apply_state=False` — для диагностики).
- `info["rotors"]` — {axis_from, axis_to, length_m, S, S_c_range, state, n_links}; `info["links"]` — {s, n, Gamma, q,
  converged, residual, x_c, x_r, h}.

## Границы модели
- Контракт требует ≤ 10 решений панелей: не выполнено (Якобиан по 2K неизвестным; блочно-диагональный и Бройден — не
  сошлись за 80 вычислений, связь соседних звеньев сильная).
- Γ из потока завихренности — слишком велика: обратный u∥ в разы больше U; равновесие лежит на 1 панель над землёй
  (разрешение 50 м) — результат зависит от сетки. Это следствие формул контракта без подгонки, не отлажено.
- Порог по уклону зависит от сглаживания (0,244 при 2·ds, 0,296 при 1·ds на Agnesi).
- Уклон по линиям тока вдоль ветра, не по реальным линиям тока. Звено — прямое, горизонтальное; рельеф вдоль оси учтён только ножками.
- E и S_c — литературные порядки величины для плоского слоя смешения и вихря с осевым потоком.
