# sim3d — связка панелей и нитей (SWD4 v2)

Интерфейс — `docs/contracts/sw-charges-3d.md`, раздел SWD4 (проверка имён: `./py contract/check_contract.py api panels3d sim3d filaments3d`).
Тесты: `./py -m pytest -q sim3d/tests` (8 тестов, ~90 с на RTX 4070 SUPER). Замеры: `./py sim3d/bench.py`.

| Файл | Что |
|---|---|
| `core.py` | `Setup`, `run`, `velocity_mean` |
| `bench.py` | время шага на N ≈ 5700 панелей |

## Шаг
1. `solve(bg + extra)`, `extra` = `filaments3d.induced` (значения в центроидах — один раз за шаг; `infl` собран в `Setup`).
2. Каждые `sep_every` шагов (`params["sep_every"]`; по умолчанию правило |u|·dt·n ≈ 2·core, n = round(2·core/(U_ref·dt)), не менее 1 —
   срывающийся слой дискретизируется нитями с шагом ~2 ядра вдоль потока, решение координатора): `separation3d(restart, streamlines_from="bg")` → `shed` по каждой из `lines` с Γ = ½·u_s²·Δt, Δt — время
   с прошлого схода, **накопленная** Γ = Σ ½|u_s|²·dt за период: u_s умножается на √(период-среднее |u|² на линиях прошлого схода / |u|² на них в конце периода)
   (на каждом шаге периода |u|² считается по `tangent_velocity`); u_s — вектор `ut` полного решения (с нитями) в точках линии, нормали — `panels.n`.
3. `filaments3d.step`: flow = bg + панели (σ этого шага), ground = `panels.height`; подшаги dt_f ≤ `cfl`·min(core)/max|u в узлах|
   (u = flow + `self_velocity`, считается в начале шага); σ на подшагах — от начала шага.
4. За t ≥ `t_avg` (по умолчанию t_end/2) — среднее и СКО (Welford) в `probes` для "potential" (σ_bg, без нитей),
   "potential_jh" (`velocity_jh`, `couple=False`), "vortex_jh" (`velocity_jh` с нитями, `couple` из `Setup`).
5. `stats[i]`: t, n_fil, n_nodes, n_seg, gamma_abs (Σ|Γ|), imbalance, max_u, substeps, t_step, residual, n_sep, n_reattach, n_lines и
   счётчики `f_split`, `f_merge`, `f_reconnect`, `f_lifted`, `f_removed`.

`velocity_mean(result, x, y, z, variant)` — из `probes_mean`, если точки совпали с `probes`, иначе по `snapshots` (в снимке — нити и σ
до схода этого шага; нужен `record_every`).

## Значения `fil` по умолчанию (обоснование)
- `r_rec` = 0 (перезамыкание выключено): иначе лавина (см. «Границы»).
- `tau_s` = None, `gamma_min` = 0, `nu_t` = 0: обоснованной оценки нет (оборот вихря холма 2a/U ≈ 25 с — оценка порядка, не измерение), поэтому
  затухания по умолчанию нет и рост числа узлов показан честно.
- `bounds` — по растру (x, y) и z ≤ max(z) + 2000 м; `l_max`, `l_min` — умолчания `filaments3d` (2·core, 0,5·core).
- Точки линии отрыва вне сетки панелей (`locate` → −1) в сход не попадают; счёт — `stats[i]["n_skipped"]`.

| t, с | узлов | отрезков | подшагов | шаг, с |
|---|---|---|---|---|
| 1 | 29 | 28 | 4 | 0,5 |
| 21 | 688 | 674 | 4 | 0,7 |
| 41 | 2499 | 2471 | 5 | 0,9 |

Рост не ограничен (≈ ×2,6 за 20 с и дальше; на t ≈ 90 с — ~19 000 отрезков, шаги по десяткам секунд), инвариант «рост < ×10 за последние 100 шагов» на
умолчаниях не выполнен. Тест 200 шагов (`test_ridge_filaments_lee_closed_bounded`) идёт на явно заданных ограничителях (`tau_s`, `gamma_min`, `bounds`, ядро 25 м, сход раз в 20).

## Что добавлено в panels3d (SWD2 v3)
- `velocity_jh(couple=True)`: ΔS из полной внешней u∥ (потенциал + extra·U_ref/|bg(100 м)| + панели от σ_extra) на max(z_agl, l);
  может быть < −1; ниже h_m extra не прибавляется отдельно; w ниже h_m — потенциальная, выше — полная (сшивка по t).
- `separation3d(restart=True, streamlines_from="bg")`: линии тока по σ_bg (σ_bg кешируется в `Influence`, который `Setup` кладёт в
  `panels._infl_obj`), u_s — проекция полного `ut` на касательную линии (со знаком); после отрыва слой не считается до присоединения;
  `points["k"]` — номер отрыва на линии, `points["reattach"]` — {x, y, z} или None.
- Правило присоединения (`panels3d.sep._reattach_index`, в контракте только «u_s > 0 снова на ≥ 2·ds_min»): если после отрыва u_s
  уходило ≤ 0 — первая точка, где u_s > 0 на ≥ 2·ds_min подряд; если u_s всё время > 0 (торможение без обращения) — первая точка, где
  u_s растёт на ≥ 2·ds_min подряд. Второе — моё решение, в контракте его нет.
- `velocity_jh`: масштаб холма по колонкам считается один раз на поперечную линию (долг ревью SWD-2).

## Инварианты (тесты) и числа
- Ровная земля, `bg_profile`: отрыва и нитей нет, поле = фон (≤ 1 %), СКО средних 0.
- Замкнутая нить у ровной земли (кольцо R = 300 м, h = 50 м, Γ = 100): скорость изображения через панели = скорость зеркального кольца ±3 %
  (замер 0,7 %); предел R ≫ h — Γ/(4πh). **Отклонение от контракта:** длинная прямая нить с ножками на концах панелями даёт Γ/(4πh) лишь
  с ошибкой ~2h/L (L = 600 м: −16 %; 3000 м: −4 %; 6000 м: −2,5 %; не зависит от ds_min 12,5–25), потому что ножки лежат в плоскости
  панелей и дают нулевой поток через стену — вихрь, протыкающий стену, панелями не воспроизводится. Тест на замкнутой нити.
- Хребет Agnesi H/L 0,5 (a = 250 м, N = 2826, ds_min 25): нити рождаются за гребнем (якорные узлы x > 0), `imbalance` ≤ 1e-12, 200 шагов без NaN,
  число отрезков за последние 100 шагов растёт < ×10. Тест идёт со сходом раз в 20 шагов, ядром 25 м, затуханием τ = 25 с,
  `gamma_min` = 1, `bounds` — иначе нитей слишком много (см. «Границы»).
- Двойной хребет (через 3a = 750 м): с `restart` якорные узлы нитей и за вторым гребнем, без — только за первым.
- `couple`: **контракт ждёт > 10 % разницы u∥ на 10 м за гребнем — получено ~4,5 %**; > 10 % — на 5 м (сход каждый шаг, ядро 12,5 м,
  24 шага). Причина: нить у стены гасится изображением в панелях, на 33 м (l) её вклад в ΔS мал. Тест проверяет 10 % на 5 м и 3 % на 10 м.

## Границы модели
- **Лавина перезамыканий.** `filaments3d.step` с `r_rec` = core (умолчание) при непрерывном сходе у стены даёт тысячи обменов за десятки
  шагов (3900 за 19 шагов; r_rec = 0,08·core — то же через ~300 подшагов): остатки неравных Γ плодят отрезки. `Setup` ставит `r_rec` = 0
  (перезамыкание выключено); для включения — `params["fil"]["r_rec"]`. Фильтра малых Γ в `step` нет (`gamma_min` — только целая нить).
- **Рост числа узлов.** Без затухания и `gamma_min` число узлов растёт экспоненциально (удвоение за ~12 с при сходе каждый шаг):
  нити у стены растягиваются сдвигом, дробление `l_max` = 2·core размножает отрезки. Для долгих счётов нужны `tau_s`, `gamma_min`,
  `bounds`, больший `core` или `l_max`. Физически обоснованного `tau_s` нет (в тесте — оборот вихря холма 2a/U ≈ 25 с).
- Вихрь на стене гасится изображением в панелях: влияние нитей на внутренний слой мало (см. `couple`).
- σ на подшагах — от начала шага (нити, сошедшие в этом шаге, на σ не влияют до следующего шага).
- Ровная земля/хребты малого размера: `separation3d` чувствителен к ds_min (ds 35–50 м на хребте H = 125 м — отрыв пропадает; двойной хребет
  — перепад между хребтами 60 м < 2·ds_min при ds_min ≥ 30 м, гребень не распознаётся).
- `velocity_mean` по снимкам берёт σ и нити до схода своего шага.
