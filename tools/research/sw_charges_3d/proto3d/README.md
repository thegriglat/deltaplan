# proto3d: прототипы A и C в 3D (SWD-12)

Вывод и числа — `out/proto3d/summary.md`, `tables.md`, `summary.json` (SWD8 v1). Интерпретатор — `../py` (CuPy, f64). Данных извне нет, кроме рельефа
`out/refs/PERD_NE.h5` (Copernicus GLO-30 DSM, лицензия — `tools/research/data/perdigao/README`); остальное синтетика. Графики — `fig_a.png`, `fig_c.png`.

## Файлы
- `vp.py` — RawKernel: скорость и градиент от векторных источников (Био — Савар, ядро 1−exp(−(r/σ)³)), ∇b для баро-клинной генерации; прямая сумма, нити по (цель, кусок источников), atomicAdd (порядок суммирования не детерминирован, ~1e-15).
- `rings.py` — круговые кольца из звеньев. `ground.py` — рельеф → `panels3d` (панели, LU один раз). 
- `pa3d.py` — A: вихревые частицы (x, α = ωV, b, V, σ), Dω/Dt = (ω·∇)u + ∇b×ẑ, земля — панели, RK2; `Heated` — нагрев поверхности потоком.
- `a_cases.py`, `run_a.py` — постановки (плоско, холм Гаусса H = 200 м s = 250 м, Perdigão NE у tse06) и опыты; `pc3d.py`, `run_c.py` — C; `screen.py` — равновесие экранировки; `analyze.py` → сводка; `figures.py`.
- `tests/test_vp.py` — градиент против конечных разностей, ∇·u = 0, скорость кольца в центре.

## Воспроизведение (GPU, без замка; всего ≈ 40 мин)
```
cd tools/research/sw_charges_3d
./py -m pytest -q proto3d/tests
./py -m proto3d.run_a conv ; ./py -m proto3d.run_a blob ; ./py -m proto3d.run_a flux      # ≈ 2 + 12 + 8 мин
for w in neutral closure thresh sens terrain; do ./py -m proto3d.run_c $w; done            # ≈ 10 мин
./py -m proto3d.analyze ; ./py -m proto3d.figures
./py contract/check_contract.py files out/proto3d
```
(`flat` + нагрев потоком при T = 400 с без шума запускался отдельно: `run_flux("flat", T=400, dt=4, noise=0)`; запись в `a_flux.json`.)

## Модель A
Частицы несут вектор α = ω·V и плавучесть b; завихрённость рождается баро-клинно (∂_y b, −∂_x b, 0)·V, растягивается (ω·∇)u от самих частиц; ядра фиксированы, σ = 1,3 h.
Скорость = фон + частицы + панели (σ панелей решается каждый вычисляемый шаг RK2 с учётом частиц). Невязкая жидкость, Буссинеск, N² = 0, **нет вовлечения**, нет трения о землю; частицы под землёй зеркалятся по вертикали.
Несущие частицы с b = 0 в слое 2,5σ вокруг шара обязательны: без них импульс шара терялся на 70 % (проверка P_z/(B t)).
Нагрев потоком: слой частиц (агл < h) в пятне R = 100 м получает db/dt = F_b/(h cosθ), F_b = g/θ₀·H/(ρc_p) (H = 250 Вт/м²); решётка несущих частиц над пятном вдоль рельефа, пустые места у земли досеваются каждые 5 с. Шум ±30 % по колонкам — необязательный.

## Модель C
Кольцо вместо пары: ℓ = κz, d = 2R_r = ℓ, ΔU = Sℓ, Γ = ΔUℓ, ядро c = 0,35 R_r, U_r — Сэффман, τ = d/U_r, λ = ε F(Ri)/E на м³/с, ε = ℓ²S³, F = clip(1−4Ri, 0, 1); курс ±45° в плоскости ветра, 50/50; зеркало земли, периодика 3×3.
Статистика на высоте z — из ансамбля в коробке 12ℓ(z) и окне высот [z/4, 4z] (самоподобие, иначе мелких колец слишком много); кольца не взаимодействуют (нет аннигиляции, перезамыкания).
Экранировка — замыкание на среднем поле: напряжение колец c_K(Ri)ℓ²S² = u*²(1−z/H), c_K, c_σ измерены на локально-однородном ансамбле (`closure`), решение алгебраическое (стационарное), не эволюция.
Над рельефом: коробка 12ℓ вокруг точки, S(агл) из потенциального решения панелей (`bg_profile`, α = 0,14), кольца размещены по высоте над землёй, земля для них — панели ds_min = 10 м (скорость колец + панели от σ колец). Ориентация колец не повёрнута к склону.
