# SWG-1: вывод

- **Причина завышения у земли в лее.** Ниже ≈ 100 м `potential_jh` = лог-профиль × `(1 + A·dS)`, `dS` — ускорение потенциального потока; в лее `(1 + A·dS)` = 0,94–1,05, Пикару нужно 0,52–0,60 (Perdigão 10 и 50 м), 0,57 (Askervein 10 м). Дефицит следа в схеме не возникает. Измерения подтверждают лее: мачты `potential_jh` +0,80 (NE, n = 6), +0,52 (SW, n = 3), +0,51 (Askervein, n = 6). Завышение +109…+220 % к Пикару в долине мачтами не подтверждено (+0,25, −0,19, n = 5).
- **До:** доля в ±15 % Пикара — Perdigão lee 10/50 м 0,15/0,08 (NE), 0,08/0,13 (SW); valley 10/50 м 0,12/0,15, 0,29/0,27; Askervein lee 0,03/0,55, valley 0,17/0,29 (медиана rel +0,7…+1,5 в лее Perdigão, не только среднее). RMSE s мачт 0,218/0,184/0,126 (Askervein/NE/SW).
- **Не причины:** z0 (Picard-согласованный 0,645 м и локальный ухудшают), σ 0…160 м (монотонно хуже при большем), фон (для JH-варианта влияние ≤ 0,01), JH сам по себе (в лее снижает ошибку на 0,24–0,37).
- **Отрыв Хеда:** на потенциальных скоростях покрывает 0–5 % точек лее и 24 % долины Perdigão, Askervein — 0 отрывов; SWD5b-нити сдвигают s на ≤ 0,03·s_ref — механизма торможения нет.
- **Находка:** клип лог-фона в `potential` на 10 м (92 % точек Askervein valley, 34–58 % Perdigão) — `potential` без JH на 10 м ненадёжен.
- **Идеи:** (1) заряды вытеснения следа `q = d(U_e·δ*)/ds` из слоя Хеда + `velocity_jh(couple=True)`; (2) вихревой лист слоя сдвига до присоединения; условие — триггер отрыва на 80–100 % точек лее. Подгонки z0/σ/фона рычага не имеют.
