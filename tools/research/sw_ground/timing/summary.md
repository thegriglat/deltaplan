# SWG-3 — вывод

Онгудай, окна 64×64×62 (100 м, 253 952 точек) и 64×64×112 (50 м, 458 752), RTX 4070 SUPER и Xeon E5-2666 v3.
Панели (ds_min = dx, N ≈ 17–18 тыс., плотная LU на GPU): холодный 122 / 193 с, смена ветра 94 / 191 с; с нитью ротора 198 / 491 и 214 / 382 с.
Пикар крейта (8 потоков, tol 5): 3,1 / 6,2 с и 3,4 / 13,8 с; tol 1: 4,4 / 11,0 и 5,3 / 22,5; 2 потока tol 5: 7,8 / 16,7 и 9,1 / 36,1.
Панели медленнее в 14–40 раз (8 потоков, tol 5), 5–16 раз (2 потока). Узкое место — опрос поля (89–93 % времени), не сборка/LU/решение
(≈ 12 с один раз, повторное решение 0,2 с). Сетка SWD5 (ds_min 25 м) на окне не помещается в 12 ГБ GPU (N 55–195 тыс.).
Холодное окно Пикара совпало с RW-6 (3,1 + 6,2 = 9,3 с против 9,9 с). Подробности, допущения, границы — `README.md`.
