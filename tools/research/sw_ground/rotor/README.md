# SWG-2 — нить ротора на реальном рельефе (SWG3 v1)

## Воспроизведение
```
tools/research/sw_ground/py tools/research/sw_ground/rotor/run_rotor.py [CASE ...]   # часть случаев -> out/swg-2/rotor_<CASES>.json
tools/research/sw_ground/py tools/research/sw_ground/rotor/merge_rotor.py            # склейка -> out/swg-2/rotor.json
tools/research/sw_ground/py tools/research/sw_ground/contract/check_contract.py tools/research/sw_ground/out/swg-2/rotor.json
tools/research/sw_ground/py -m pytest -q tools/research/sw_ground/rotor
```
Параметры одни на все случаи (SWD7 v2): closure reattach, R_rule 0,25, gate slope, slope_min 0,27; панели — σ 40 м,
ds_min 25 м, лог-фон, z0 — медиана растра (основной набор SWD5). Не подбирались. Критерий ротора — u∥ < −0,5 м/с на 15 м,
отрезок > 50 м (rotor_scan SWD5), u∥ масштабирована к U данных в опорной точке. Эталоны — SWD1 (Menke 2019, ACP 19, 2713;
Пикар nom/adv1). Данные — только из репозитория (лицензии как в sw_charges_3d/ASSETS.md).

## Вывод
Ложных роторов «нет» не выполнено: одно правило с порогом 0,27 ставит нить на Askervein (где ротора нет) и на 8 хребтах
Perdigão без подтверждения Пикара nom. Длина ротора на NE совпадает с Menke, но порог по уклону не отделяет пологие
бугры от роторных хребтов. Ограничения: Пикар nom сам занижает ротор (на SW его нет, а Menke наблюдал), поэтому
«ложный» по Пикару — оценка сверху; окно хребта ограничено областью Пикара ±3 км; хребты у края области (SW ridge 0)
подозрительны.
