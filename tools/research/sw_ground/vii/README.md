# vii: панели + интегральный пограничный слой, связь по образцу XFOIL (SWG-10)

Круг 3 задачи 1 (решение пользователя 2026-11-09): вместо JH — интегральный турбулентный слой (импульс Кармана +
вовлечение), связанный с панелями зарядами вытеснения `σ_d = d(U_e·δ*)/ds`; прямая связь на присоединённом слое,
полуобратная (Carter) в отрыве; скорость у земли — из профиля слоя. **Итог: схема работает на гладком синтетическом
хребте и на Askervein (сходится), но на Perdigão полуобратная связь Carter не сходится** (60 итераций, 31–38 % узлов
профилей меняются > 1e-3 за итерацию); в таблице Perdigão — последняя итерация стабилизированного расчёта, у которой
смещение против настоящей неподвижной точки, оценённое на Аньези, — до 0,19·U_∞ на 10–100 м. Вывод — раздел «Вывод и следующая идея».

## Воспроизведение
```bash
cd tools/research/sw_ground
../../../.dpcli/dpcli lock cpu swg10 -- env CUDA_VISIBLE_DEVICES= ./py -m vii.run layer PERD_NE   # и PERD_SW, ASK_TU03B (по 3–6 мин на ядро)
./py -m vii.run points            # группы фокуса ds_min 25 м на GPU (CuPy, ~1,5–3 мин на случай; при нехватке памяти — CPU)
./py -m vii.run assemble          # out/swg-10/ground.json (SWG2) + tables.md
./py contract/check_contract.py out/swg-10/ground.json
./py -m vii.scan_agnesi           # диагностика δ0 на Аньези → out/swg-10/agnesi_scan.json (~10 мин CPU)
./py -m pytest -q vii             # 6 тестов (~3 мин CPU); пишет out/swg-10/agnesi.json
```
Файлы: `bl.py` (семейство профилей, уравнения, прямой/обратный ход, векторно по профилям), `core.py` (профили вдоль
ветра `Strips`, связь `VII`, заряды `sigma_d`, поле `vii_parts`), `run.py`, `assemble.py`, `scan_agnesi.py`,
`test_vii.py`. Импорт без изменений: `ground.model` (GRun, jh_parts; его патчи panels3d учитываются),
`ground.evaluate`, `ground.tables`, `wake.core` (`wake_panels`, `solve_rhs`), `wake.synth` (Аньези), `panels3d`.
Образец слоя — `panels3d/sep.py` (`march_layer`, Хед); копия с новыми именами и изменениями — `vii/bl.py`.
Сырьё `out/swg-10/raw/*.npz` (поля слоя на профилях, 28 МБ) — локально, не в git; `raw/*.json` — в git.

## Схема, уравнения, замыкания
- **Невязкое.** Панели 3D (SWD2 v5: σ 40 м, z0 — медиана растра) с **однородным** набегающим потоком
  `U_∞ = bg_log(Z_SAT = 500 м)` (вся завихренность фона — в слое). Вдув: `A σ_d = q`, `q = cos β·d(U_e δ*)/ds_h` на
  панелях внутри растра (`wake.core.wake_panels`, `solve_rhs` — та же матрица и LU; Lighthill 1958). Вне растра
  `U_e δ*` продолжена постоянной вдоль профиля — краевых источников нет.
- **Слой** квазидвумерно на профилях вдоль ветра (шаг 12,5 м, поперёк 25 м, как WakeGrid SWG-4), s — длина дуги по
  поверхности (рельеф σ 40 м); начало — край растра, равновесный слой. `U_e` — модуль касательной скорости невязкого
  решения в центрах панелей (матрица касательных скоростей float32, одна на сетку), интерполяция на узлы, сглаживание
  σ 25 м вдоль профиля (шум центров панелей).
- **Уравнения** (`bl.py`): `dθ/ds = C_f/2 − (H + 2)(θ/U)dU/ds − S_m/U²` (Карман); `d[U(δ − δ*)]/ds = U·F(H1) − S_e`,
  `F = 0,0306 (H1 − 3)^−0,6169` (Head 1958, ARC R&M 3152; формулы как `panels3d/sep.py`).
- **Профиль и C_f** — семейство Coles (1956) для шероховатой стенки со свободным знаком u_τ:
  `u/U_e = a(1 + ln η/λ) + (1 − a) sin²(πη/2)`, `η = z/δ`, `λ = ln(δ/z0)`, `a = (u_τ/U_e)λ/κ`, `C_f/2 = sign(a)(aκ/λ)²`.
  δ*, θ, H, H1 — аналитические интегралы (`∫ ln η·sin²(πη/2) dη = −0,20526`). `a = 1` — чистый лог (равновесие фона,
  `H = λ/(λ − 2)`), `a = 0` — `C_f = 0`, `a < 0` — обратный ток у стенки. Состояние — `(a, λ)`, θ и δ* — явные функции
  (обращать семейство не нужно). Обоснование `C_f`: закон стенки шероховатой стенки + след Coles на краю δ (вместо
  `(κ/ln(δ/z0))²` из sep.py, где нет зависимости от H).
- **Равновесие ровной земли** (допущение): атмосферный слой не растёт (трение уравновешено крупномасштабным
  градиентом давления, рост сверху держит задерживающий слой) → постоянные стоки `S_m = (C_f0/2)U_∞²`,
  `S_e = U_∞ F(H1_0)` равновесного слоя `δ0 = Z_SAT = 500 м`, `a = 1` (толщина — из фона bg_log, не подбор).
  Perdigão: θ0 = 57,3 м, δ*0 = 88,9 м, H0 = 1,55, C_f0/2 = 0,0051; Askervein: 40,9 / 51,4 / 1,26 / 0,0017.
- **Связь.** Прямой ход при `H ≤ 2,5`; шаг, давший `H > 2,5` (XFOIL 6.99, `xbl.f` MRCHUE: `HTMAX = 2.5`), — обратным
  ходом: задан наклон `dδ*/ds` предыдущей итерации, решение — `U_e,visc` (система 3×3 по a′, λ′, U′); при первом входе —
  `H = const` (как MRCHUE). Обновление: в обратной зоне `δ*_{k+1} = δ*_k[1 + ω(U_visc/U_inv − 1)]` (Carter; форма
  проверена по Howlett 1989, NASA ntrs 19890009878), на прямом участке `δ*_{k+1} = δ*_k + ω(δ*_слоя − δ*_k)`.
  Зона обратного хода растёт (узел, где хоть раз `H > 2,5`, остаётся в ней). Критерий — `max|Δδ*|/δ* < 1e-3`.
  Защиты (счётчиками): `H ≤ 10` в обратном ходе по δ* (иначе `H = const`), `δ ≤ 4δ0`, `U_e/U_∞ ∈ [0,05; 3]`,
  поправка `U_visc/U_inv` за итерацию в `[0,5; 1,5]`.
- **Скорость у земли:** `u(z) = |U_o(x, y, z)|·f(z)`, `U_o` — невязкое поле (U_∞ + панели + вдув) на высоте точки, f —
  профиль слоя по `(a, λ)` в точке (билинейно с профилей); выше δ `f = 1`; s — модуль, знак f — знак u∥.
  На ровной земле `f = ln(z/z0)/ln(500/z0)` и `u = bg_log` в точности.
- **Сетки.** Слой и связь — сетка случая ds_min 100 м с фокусом во всех точках SWG1 (N 6,9–9,4 тыс.); поле в точках —
  группы ≤ 40 точек, ds_min 25 м (как SWG-1), σ_d на них — из `U_e δ*` слоя. `potential`, `potential_jh` пересчитаны
  там же и совпадают с `out/swg-1` побитно (`base_check` = 0).
- **Варианты** (`ground.json` variants): `vii` — основной; `vii_nc` — тот же слой без связи (одна прогонка по невязкому
  U_e без вдува, в отрыве `H = const`) — показывает, что делает именно взаимодействие. `vii_rotor` (нить SWG-2) **не
  считался**: основной вариант не сошёлся на Perdigão, складывать не с чем. С листом SWG-7 не сочеталось.

| ω = 0,5, сглаживание только поправки ΔD (50 м) | не сошлась за 60 (max Δ 5e-3) | разнос (max Δ до 4e2) |
| ω = 0,2, без сглаживания | расходится медленно (H → 4,6) | — |
| ω = 0,1, сглаживание δ* 50 м | — | не сошлась за 50 (62 тыс. узлов > tol) |
| **ω = 0,2, сглаживание δ* 50 м (рабочий, один на все места)** | не сошлась за 60 (max Δ 0,31), **смещение u(z) против ω = 0,5 — до 0,19·U_∞** | не сошлась (ниже) |

Рабочий набор выбран как единственный, при котором итерации на Perdigão не разносятся; это стабилизатор, а не
решение: сглаживание δ* после каждой поправки меняет саму неподвижную точку.

## Проверки (pytest, 6)
- Ровная земля: слой равновесный (θ, a постоянны до 1e-9), `H0 = λ/(λ − 2)`; на ровной сетке панелей `vii` = `potential_jh`
  на 10/50/300 м в пределах 1 % (требование карточки), при `σ_d = 0` и выключенном слое поле = `potential` побитно.
- `U ∝ (x0 + s)^m` (пластина, без стоков, z0 = 0,1 м): H растёт; предел прямого хода (H ≥ 2,5) при **m = −0,238**;
  литература — `m_sep ≈ −0,216 − 0,4·Re_p^−1/3` для автомодельных турбулентных слоёв (Vigdorovich 2014, JETP 119,
  doi:10.1134/S1063776114110193, по аннотации; гладкая стенка). Обратный ход с δ* прямого восстанавливает U_e (< 2 %).
- Аньези H = 125 м, a = 250 м (H/L = 0,5), z0 = 0,1: при ω = 0,5 связь **сходится за 20 итераций, отрыва нет**
  (H_max 1,37, C_f min 0,0036). u/U_∞ на 10 м за гребнем (x = 150/300/450/600/900 м): **vii 0,62/0,50/0,48/0,47/0,48**,
  potential_jh 0,64/0,48/0,47/0,48/0,51, слой без связи 0,56/0,34/0,31/0,33/0,37. На 100 м — 0,93/0,79/0,74/0,73/0,73
  (vii) против 0,91/0,81/0,78/0,78/0,79 (potential_jh). Профили 10–100 м — `out/swg-10/agnesi.json`.

## Почему так (механизм, с числами)
1. **Слой толщиной с холм.** δ0 = 500 м (из фона) при H/L ~ 0,5 и L ~ 250–500 м — интегральный метод вне своей
   области (тонкий слой, давление поперёк постоянно, δ ≪ L). Поверхностный U_e действует на весь 500-метровый слой:
   без связи на Аньези θ 18 → 94 м за 300 м лее, δ* 24 → 157 м, наклон тела вытеснения ≈ наклон склона.
2. **Сильное взаимодействие.** Вдув `q` до 1,6·U_∞ (Perdigão, первая итерация): тело вытеснения «заливает» подветренный
   склон, внешнее течение тормозится меньше, слой — тоже. На Аньези связь убирает дефицит слоя без связи
   (0,31–0,34 → 0,47–0,48 U_∞ на 10 м) и даёт почти potential_jh. Отрыва нет при δ0 = 500 м (и 200, 100 м); он
   появляется только при тонком слое (δ0 = 25 м, без сходимости; таблица δ0 выше), т. е. отрыв — свойство тонкого внутреннего слоя, а не всего АПС.
3. **Полуобратная связь Carter не сходится на Perdigão**: обратная зона — 21–28 тыс. узлов (до 58 % точек лее/долины),
   из них почти все меняются > 1e-3 за итерацию; при ω = 0,5 — разнос. Известное ограничение явной поправки Carter при
   сильном взаимодействии и шаге ≪ δ* (поэтому XFOIL решает слой и невязкое одновременно, глобальным Ньютоном,
   Drela & Giles 1987 — не открывалась). Изменение s в точках между двумя последними итерациями — в среднем
   ≤ 0,031·s_ref (`conv_mean` в decomp), т. е. итерации «топчутся», но не у неподвижной точки (смещение — п. «Параметры»).
4. **Откуда «улучшение» в лее Perdigão.** Не от отрыва (C_f ≤ 0 у 1–4 % точек), а от того, что слой над всей сложной
   областью утолщается (θ +20 % уже upstream): `layer` −1,0…−1,8 перекрывает `outer_eq` +1,8…+3,0 (однородный поток
   над глубокими долинами разгоняется у земли сильнее, чем лог-фон потенциала). На 300 м vii хуже базы (доли 1,00 →
   0,61–0,84) — слой глубиной 500 м меняет и 300 м. Askervein (пологий): слой почти равновесный, сходится за 18
   итераций, изменений против базы нет, кроме гребня (доля 0,88 → 0,59, мачты гребня 0,252 → 0,346).

## Что вне аналогии и допущения
- Слой — квазидвумерный вдоль ветра (поперечная дивергенция `U_e δ*` отброшена, как SWG-4); U_e — поверхностная
  (тонкий слой), хотя δ ~ H холма; стоки равновесия АПС — постоянные (без Кориолиса и поворота ветра).
- Замыкание вовлечения Хеда — гладкостенная эмпирика, применена к H1 семейства Coles шероховатой стенки; семейство
  Coles с отрицательным u_τ для обратного тока — допущение (Swafford 1983 не открывался, не использован).
- Стабилизатор (ω = 0,2, сглаживание δ* 50 м) — численный, без литературного обоснования; меняет ответ.
- Отрыв и рециркуляция у земли — свойство тонкого слоя: с δ0 = 500 м схема их не даёт.

## Вывод и следующая идея
VII по образцу XFOIL с δ0 = 500 м (толщина фона) **не даёт отрыва и мёртвой зоны в лее**: на Аньези H/L 0,5 сошедшаяся
связь ≈ potential_jh (взаимодействие гасит дефицит слоя), на Perdigão полуобратная связь Carter не сходится, а
таблица (лее 10 м NE +1,48 → +0,90, SW +2,00 → +1,08; доли в ±15 % 0,14–0,29; 300 м хуже) — от последней итерации
стабилизированного расчёта со смещением до 0,19·U_∞. **Не встраивать.** Зацепки: (1) отрыв на Аньези появляется только
при тонком слое (δ0 = 25 м ≈ 0,2 H холма; при 50 м C_f → 0) — слоем для VII должен быть внутренний слой (масштаб JH l), а не весь АПС
(вне него — невязкий сдвиговый поток); (2) для сильного взаимодействия нужна одновременная (Ньютон, как XFOIL ISES)
связь, явная поправка Carter не годится.
