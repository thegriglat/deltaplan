# sky_k(el): яркость рассеянного света ясного неба по высоте солнца (HH-15)

Контракт HH4 v3 (`docs/contracts/haze-humidity.md`): `sky_k(el)` — рассеянная освещённость безоблачного неба относительно 35°
(`DHI(el) / DHI(35°)`, горизонтальная площадка), по опубликованной модели ясного неба с аэрозолем; одно значение на энергию
неба, окружение, свет дымки и окружение облаков. Замена прежней таблицы `clouds.sky_light` (0,07 при 2° — «по памяти») и
ручной `time.light.sky_energy`.

## Метод

1. **Основная — однократное рассеяние в атмосфере игры** (`single_scatter.py`; разрешено контрактом: «по той же SunTransmission-атмосфере»).
   Сферическая Земля R = 6 371 км; Рэлей β_R(550) = 1,16·10⁻⁵ 1/м, шкала 8 км (Bucholtz 1995), фаза `3/(16π)(1 + cos²γ)`;
   аэрозоль — слой постоянной плотности до верха дымки (2 км), ослабление 3,912 / 60 км = 6,5·10⁻⁵ 1/м на 550 нм,
   альбедо однократного рассеяния 0,9, фаза Хеньи–Гринстейна g = 0,7 (как `haze_g`). Радианс неба
   `L(ω) = ∫ [β_R p_R + β_a ω₀ p_a] · E_sun · T_солнце(точка) · T_глаз(точка) ds`, пропускание к солнцу — тот же алгоритм,
   что `SunTransmission` (хорда в сфере верха дымки + численный интеграл Рэлея, луч в Землю — 0). `DHI = ∫ L cosθ dω` по верхней
   полусфере (48 × 36 направлений, 64 отсчёта по лучу). Результат — отношение к 35°.
2. **Сверка — ESRA** (`sky_light.py`): Rigollier, Bauer, Wald 2000, *Solar Energy* 68(1) (European Solar Radiation Atlas):
   `Dh = I₀·Trd(TL)·Fd(sin h)`, `Trd = −1,5843·10⁻² + 3,0543·10⁻² TL + 3,797·10⁻⁴ TL²`, `Fd = A₀ + A₁ sin h + A₂ sin² h`
   (A₀, A₁, A₂ — полиномы TL; при A₀·Trd < 2·10⁻³ — A₀ = 2·10⁻³/Trd), TL = 3 (мутность Линке; τ_аэрозоля ≈ 0,12 — сопоставимо с
   дымкой игры). Коэффициенты — по памяти статьи, не проверены по тексту: сверена форма и значения (`DHI(35°)` = 96 Вт/м², отношение к прямой
   горизонтальной 0,20 — типично для ясного дня).
3. **Bird–Hulstrom 1981** (SERI/TR-642-761; `sky_light.py: bird_diffuse`): при ≥ 8° совпадает с ESRA в пределах 8 %; ниже 5° вне области
   применимости (воздушная масса > 10) — даёт 0,05 при 2°; в таблицу не берётся.

## Погрешность и границы

- С ESRA (TL = 3) таблица сходится в пределах ±3 % при 6–35°; при 0–4° ESRA выше на 9–49 %: вероятные причины (не разбирались): у ESRA при низком солнце вклад
  «плато» (A₀) и более прозрачный воздух (при TL = 3 путь солнца у горизонта в воздухе короче, чем в слое игры: 60 км видимости на 2 км
  при 2° — это ≈ 57 км пути в слое), в однократном рассеянии нет многократного (в сумерках оно заметнее). Оценка погрешности: **±30 % при ≤ 2°,
  ±10 % при 3–5°, ±3 % выше 6°.**
- Зависимость от дымки (одно значение на день не пересчитывается): ослабление ×0,46 (3·10⁻⁵) — sky_k(2°) = 0,257; ×2 (1,3·10⁻⁴) — 0,086
  (таблица для 6,5·10⁻⁵ — 0,156); при 8°: 0,557 / 0,281 (0,422); при 18°: 0,803 / 0,610 (0,719).
- Литературные ориентиры по порядку величины (Kittler/CIE, из прежнего `sky_light`): ≈ 12 клк при 35°, ≈ 0,8 клк при 2°, ≈ 0,4 клк на горизонте
  дают 0,07 и 0,03 — ниже таблицы в 2–3 раза при ≤ 2°; источник не проверен (по памяти), расхождение внутри заявленной
  погрешности модели с дымкой 60 км не объясняется; в `uncertain` отчёта.
- Яркость неба в направлении (радианс) — не освещённость: зенит и небо над горизонтом — `zenith.py` (относительно зенита при 35°):
  зенит при 2° — 0,18 (DHI: 0,16), небо на 5° над горизонтом в 90° от солнца — 0,30, в противосолнечной стороне — 0,46;
  использовать для неба одно число `sky_k` — приближение (контракт).

## Экспозиция заката E(el) (`exposure.py`)

`L(el) = light_energy·max(sin el, 0)·ρ + sky_k`, `light_energy = sun.energy·T_G(el)/T_G(35°)`, ρ = 0,2 (трава, почва, камень 0,15–0,25);
`E = clamp((L(35°)/L(el))^a, 1, E_max)`, a = 0,8, E_max = 10. Падение яркости сцены к 2° — 2,9 ступени (L = 0,14); при a = 0,8 экспозиция
возвращает 2,3 ступени (E = 4,9). Фото закатов: экспозиция дня и заката отличается на 3–5 ступеней (оценка автора, не измерение), зрение
адаптируется частично — полная компенсация (a = 1) сделала бы закат днём; сцена на закате темнее дня, но не чёрная.
