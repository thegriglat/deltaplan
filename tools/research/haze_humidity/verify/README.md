# Сверка климата Td и T700 с прогнозами и станциями (HH-9)

Проверка, не подгонка: сетки (`data/climate/dew_point_1deg.bin` HH1 v1, `upper_air_1deg.bin` HH2 v2) и их чтение (HH7:
билинейно по 4 ячейкам, месяц — на 15-е, между серединами линейно) не менялись.

## Итог (числа — `summary.json`, `places.csv`, `places_summer.csv`, `stations.csv`)
| проверка | Td | T700 |
|---|---|---|
| Прогноз Open-Meteo, 22.10–06.11.2026 (16 дней, 38 мест): сдвиг (прогноз − климат) | **+0,72 К**, ДИ95 [0,04; 1,44] = +0,24σ | **+0,54 К**, ДИ95 [−0,01; 1,10] (35 мест) |

Критерий задания (сдвиг > 0,5σ или доля вне 55–80 %): в целом сдвиг 0,24σ и 0,19σ, доли 67 % и 56 % — в норме (лето —
у нижней границы). Разбор отклонений ниже.

## Метод
- **Климат модели на день** — как в игре: Td = билинейно HH1 `TD` в день (между серединами месяцев) + `g_td·(z − Z_ячейки)/1000`,
  z — `elevation` из ответа Open-Meteo, g — HH7 (30–60°: DJF −4,5, MAM −3,9, JJA −3,3, SON −4,2; |φ|≤20° −4,6; прочее −4,0;
  сезон местный, на юге сдвиг 6 мес.). σ = `SD`, тоже интерполирована по дню. T700 — HH2 `T` без поправки.
- **Прогноз дня** = среднее почасовых `dew_point_2m` (`temperature_700hPa`) в 00 и 12 UTC (так построены сетки). Дни без
  обоих сроков пропускаются.
- **Корреляция дней.** Для каждого места: доля, сдвиг, std(Δ); lag-1 автокорреляция Δ в среднем 0,51 (Td), 0,64 (T700) →
  эффективный объём ≈ 5,6 независимых дней из 16 на место (T700: 3,7). Поэтому итог — среднее по местам, ДИ — бутстрэп по
  местам (10 000 повторов, кластер = место). Пул по дням без кластеров дал бы те же 67,2 %, но обманчиво узкий ДИ — не используется.
- **T700 исключён** для мест выше 2500 м (La Paz, Lhasa, Quito): 700 гПа там у поверхности или под рельефом, значения —
  экстраполяция модели.
- Прогноз — модель по умолчанию Open-Meteo (`best_match`); чувствительность — `gfs_seamless`, `icon_seamless`.

## Места (38)
7 мест игры: Алтай (Чемал), Онгудай, Аскарово, Аушкуль, Крым, Дараб, Кэрнс. 31 точка суши: пустыни (Таманрассет, Эр-Рияд,
Алис-Спрингс, Финикс, Каир), муссоны/тропики (Дели, Мумбаи, Бангкок, Манаус, Лагос, Найроби), субтропики Ю. полушария
(Йоханнесбург, Буэнос-Айрес, Сантьяго, Сидней, Перт), умеренные (Лондон, Берлин, Москва, Чикаго, Сиэтл, Токио, Мадрид),
континентальные/субарктика (Якутск, Фэрбенкс, Улан-Батор), высокогорье (Денвер 1600 м, Кито, Ла-Пас, Лхаса, Алма-Ата).
Координаты — `common.py`. Выбор — охват поясов, климатов и высот; не случайная выборка (поэтому доля «в σ» — по этим местам,
не по площади суши).

## Разбор отклонений
- **Места игры** (7): сдвиг +0,04 К, доля 83 % осенью; в июле −0,33 К, 57 %. Отдельно: Онгудай −4,0 К осенью — OM даёт
  высоту 1364 м (горная ячейка модели), долина игры ниже; поправка к высоте сделана на 1364 м, хвост остаётся.
- **Тропики и σ мала**: Манаус, Лагос, Кито, Мумбаи (σ Td 0,5–0,8 К) — сдвиг 1–1,6σ при сдвиге ≈ 0,7–1,1 К; доля 0–6 %. Это
  малая σ, не большая ошибка в К; для игры значим сам размер в К.
- **Единичные большие сдвиги осенью**: Алис-Спрингс +7,5 К, Фэрбенкс +6,5 К, Сантьяго +3,3 К, Финикс +3,1 К, Таманрассет
  +3,4 К — при σ 4–7 К это аномалии периода (16 дней, один сезон), а не системный сдвиг (n_eff ≈ 5).
- **Зависимость от высоты**: регрессия сдвига на (z_OM − Z_ячейки): наклон −1,0 К/км (осень), −0,9 К/км (лето) при корреляции
  −0,13 (разброс Δz между местами 0,29 км) — остаточный эффект поправки g (−4 К/км) в пределах шума; поправка работает.
- **Горизонт**: доля в σ растёт с заблаговременностью — 62 % (дни 0–3), 64 % (4–9), 74 % (10–15); std(Δ) 1,8 → 2,3 К.
  На длинных сроках прогноз стягивается к климату (дисперсия меньше климатической), на коротких — реальная погода и
  аномалия периода; 68 % — между. Значит оценка по 16 дням консервативна по доле.
- **Чувствительность к модели прогноза** (сдвиг Td, К): осень `best_match` +0,72, GFS −0,13, ICON +0,89; лето `best_match` −0,10,
  GFS −1,17. Разброс между прогнозными моделями (≈ 1 К) сравним с самим сдвигом и больше его → сдвиг +0,7 К осенью не
  отличим от различий в моделях прогноза; смысл имеет, что он < 0,5σ.
- **Сезон**: +0,7 К осенью 2026 против −0,1 К в июле 2025. Гипотеза (не проверена): тренд — сетка Td усреднена за 1991–2020
  (середина 2005), 2026 тёплый/влажный в сравнении; пока HH-1c не перепекла Td на 2011–2020.
- **Станции вне ERA5**: Новосибирск (Толмачёво), Оренбург, Мидленд — годовой сдвиг сетки Td −0,01/+0,19/+0,09 К, макс. по месяцам 0,9–1,2 К;
  T700 радиозондов (IGRA) +0,01/−0,25/−0,51 К, макс. 0,4–0,7 К. Это подтверждает обработку (осреднение 0,25°→1°, билинейное
  чтение, средняя за месяц, поправка по высоте станции) на трёх независимых точках.
- **Иран (Шираз, Тегеран)**: Td сетки выше наблюдений на 2,4–2,5 К в среднем (4,2–4,4 К в июне–августе), при σ ≈ 3–5 К.
  Ячейка Шираза 1794 м против станции 1500 м (поправка +1,2 К уже учтена); Тегеран ячейка не выводилась. Вероятная причина
  (гипотеза, не проверена здесь) — известное «влажное» смещение Td ERA5 в засушливых районах плюс репрезентативность
  метеостанции (аэропорт в пустынной котловине против ячейки 1° с горами и зоной Персидского залива); ошибка обработки
  маловероятна, т.к. тот же код даёт ±0,2 К в трёх других местах. Дараб (игра, 28,75°N 54,55°E, в 220 км от Шираза): прогноз
  отличается от сетки на +1,25 К осенью и −1,5 К в июле — т.е. по прогнозным моделям «влажности» сетка не завышена
  систематически. Расхождение — вопрос о достоверности Td ERA5 в Иране; для игры (Дараб) — в пределах 0,3σ.
  Станционных данных по Дарабу нет; решение координатору/пользователю.

## Допущения и границы
- Сравнение с прогнозом проверяет климат в смысле «погода дня ~ N(климат, σ)». Прогнозные модели не независимы друг от друга и
  от ERA5 полностью (все используют реанализ/ассимиляцию, ICON/GFS/IFS); независимы лишь станции.
- Одна осень (2026) и один июль (2025) — год аномалий в выборке остаётся; ДИ по местам не учитывает межгодовую
  изменчивость одного сезона (для этого нужно несколько лет архива).
- Historical Forecast = склейка первых часов оперативных прогнозов (малая заблаговременность), то есть июльская проверка
  не про горизонт; лето 2025 вне периода климата Td (1991–2020) и T700 (2011–2020).
- Td OM на высоте `elevation`: считаем, что Open-Meteo уже приводит точку к своей высоте; если у модели Td не
  пересчитывается к DEM, остаточный наклон был бы ≈ −4 К/км, а он ≈ −1 — значит сверка с поправкой корректна.
- σ T700: `t700_sd.npz` в HH-1g пока NaN, поэтому доля в σ T700 не считалась. При появлении σ достаточно `python analyze.py`
  (читает файл заново; заменить `RAW/t700_sd.npz`). Ориентир σ T700: std(Δ) = 2,7 К (осень), 2,0 К (июль) — включает
  ошибку прогноза и межгодовую изменчивость.
- Станции: Td — ISD-Lite, 00 и 12 UTC, день = среднее двух сроков при наличии обоих, 2011–2020, ≈300 дней на месяц; сетка Td —
  1991–2020 (30 лет), сравнение с 10 годами. T700 — IGRA v2 monthly means (00 и 12 UTC, ±2 ч), среднее по годам, где есть оба срока.
  Шираз IGRA 2011–2020 — нет данных (с 2022); T700 по нему не считался.

## Воспроизведение
```
cd tools/research/haze_humidity/verify
PY=~/data/haze_humidity/venv/bin/python        # numpy brotli
git show haze-humidity/HH-1g:data/climate/upper_air_1deg.bin > ~/data/haze_humidity/verify/upper_air_1deg.bin   # коммит bca9b3df
git show haze-humidity/HH-1g:tools/research/haze_humidity/upper_air/t700_sd.npz > ~/data/haze_humidity/verify/t700_sd.npz
$PY fetch.py forecast; $PY fetch.py forecast gfs_seamless; $PY fetch.py forecast icon_seamless
$PY fetch.py summer;   $PY fetch.py summer gfs_seamless
# станции: ISD-Lite (s3://noaa-isd-pds/isd-lite/data/<год>/<usaf>-<wban>-<год>.gz, 2011–2020) -> ~/data/haze_humidity/verify/isd/;
# IGRA: https://www.ncei.noaa.gov/pub/data/igra/monthly/monthly-por/temp_{00,12}z-mly.txt.zip -> ~/data/haze_humidity/verify/igra/
$PY stations.py && $PY analyze.py
```
Сырые ответы API (≈ 5 МБ) — `~/data/haze_humidity/verify/raw/` (вне репозитория). Прогноз привязан к дате запроса (22.10.2026);
для повторения через время — другой интервал, `fetch.py` не перезаписывает существующее.
Сетка Td — `data/climate/dew_point_1deg.bin` из этой копии (feature/haze-humidity).

## Источники и лицензии данных
- **Open-Meteo** (open-meteo.com): Forecast API (`api.open-meteo.com/v1/forecast`) и Historical Forecast API
  (`historical-forecast-api.open-meteo.com`); бесплатно без ключа для некоммерческого использования, лицензия данных
  CC-BY-4.0 с атрибуцией («Weather data by Open-Meteo.com»); пауза между запросами 0,4 с, всего ≈ 190 запросов. В игру и в
  репозиторий сырые ответы не входят — только сводные таблицы (производные); при публикации — ссылка на Open-Meteo.
- **NOAA NCEI ISD-Lite** (синоптические наблюдения) и **IGRA v2** (радиозонды; Durre et al. 2006, J. Climate 19:53–68): данные
  NOAA США — общественное достояние, атрибуция NOAA/NCEI. Станции: Толмачёво 296340-99999, Оренбург 351210-99999 / RSM00035121,
  Мидленд 722650-23023 / USM00072265, Шираз 408480-99999, Тегеран-Мехрабад 407540-99999 / IRM00040754.
- Климатические сетки — ERA5 (Copernicus, CC-BY-4.0), см. README dew_point и upper_air.
