# HH-12: цвет облаков на закате (диагноз света HH-7)

Только диагноз; правок в scripts/, configs/ нет. Числа: `result.json` (главные), `analysis.json`, `low_sun.json`, `fixes.json`, `ablation_stats.json`, `frame_stats.json`.

## Вывод
1. **Таблица пропускания HH4 верна.** Против независимого спектрального интеграла (Планк 5778 К, CIE 1931 по аналитическому фиту Wyman-Sloan-Shirley 2013, Рэлей λ^-4.08) T/T_ref совпадает в пределах 3-5 % при 5,7-35 градусов; R завышен на 10-15 % при 2 и 0,8 градуса (три длины волны вместо полосы). Chapman: воздушная масса на горизонте 35,39 против 35,37; зенитная толща 0,0928 против 0,0928.
2. **sun_l на боках облаков тёплый:** G/R, B/R = 0,76/0,38 (5,7 градуса), 0,54/0,12 (2), 0,41/0,04 (0,8) для облака над дымкой (бока 3200 м, верх дымки 2800 м, haze_k 1,4). Контрольные числа контракта v2 (1;0,47;0,13 при 5 градусах) - для точки у моря с аэрозолем по всему лучу; облако выше дымки тёплее, это физика.
3. **Тепло теряется после sun_l.** Яркость: sun_l новой модели в 1,9/3,7/5,2 раза (RGB, 5,7 градуса) выше прежнего (T/T_ref >1 для облака над дымкой), фаза вперёд с silver 1,4 даёт ×4,7 (cos 0,9) - ×9,6 (cos 0,99); HDR облака 2,5-7, а AgX (exposure 1,1, white 6) при яркости R=2 даёт G/R 0,85 и B/R 0,63, при R>=4 - белый (проба настоящим Godot, `tonemap_probe.gd`). В реальных кадрах яркий 1 % облаков при 2 и 0,8 градуса во всех ракурсах (к солнцу, сбоку, от солнца): G/R 0,94-0,95, B/R 0,87-0,89 (прежний свет: 0,83-0,88 / 0,75-0,83; физика: 0,54/0,12 и 0,41/0,04). Второй, меньший вклад: ambient и fog_color_fallback облаков - дневные константы, не идут за sky_energy/horizon_tint (<=0,05 по G/R в ярких пикселях, заметнее в средних тонах). Затемнение солнца (sun_x0.3, x0.1) оттенок не возвращает - пиксели сине-серые (фон и ambient).
4. **Предложения (не окончательные до HH-13):** F1 - ambient/fog облаков × horizon_tint и sky_energy; F2 - hue-preserving потолок максимального канала радиации облака (~1,5-2) перед композитом; проверить кадром. Подробнее и числа - `result.json → fix`.
5. **HH4 v2 (sun_color = sun_tint):** облака берут toa из конфига (белый × T/T_ref), не из `DirectionalLight3D.light_color`, поэтому v2 цвет облаков не меняет. Если HH-13 подаст sun_tint в облака вместе с T/T_ref - двойной учёт (при 2 градусах G/R ~0,54 × 0,24).

## Допущения и границы
- Сценарий (haze_k 1,4; долина 600 м; верх дымки 2800 м; бока 3200 м) - не измерение: параметры в кадре не логировались. Озон в модели не учтён (грубое приближение Chappuis - только в `spectral.py`).
- HDR облака в движке не измерялся (без правки scripts/ буфер недоступен); цепочка sun_l × фаза (HG 0,6 / -0,2, silver 1,4) × Бир (0,25-1,25) × powder 0,8 + ambient + fog -> проба тонмаппера; согласуется с кадрами для прежнего света.
- Маска облаков = |кадр - кадр без облаков| > 25; края смешаны с фоном; яркий 1 % смещён отбором к белому.
- Кадры 2 и 0,8 градуса: время по NOAA (как скрипт HH-10), не по SunClock; ракурсы: к солнцу, сбоку (+75 градусов), от солнца (+180), тангаж 8 градусов (к солнцу - высота солнца).
- Абляции делались конфигами профиля (`user://configs`, глубокое слияние): sun_x0.3/x0.1 меняют `world.sun.energy` (и свет рельефа).

## Воспроизведение
```
cd <корень копии>; export XDG_DATA_HOME=~/.cache/dp-xdg/<имя копии>; godot --headless --path . --import   # один раз
cd tools/research/haze_humidity/sunset_color
python3 analyze.py; python3 low_sun.py; python3 fixes.py        # аналитика + проба тонмаппера (GPU-замок, DISPLAY=:0)
python3 ablation_frames.py [вариант ...]                          # кадры 5,7 градуса
python3 ablation_frames.py scen el2_sun,el2_side,el2_back,el08_sun,el08_side,el08_back base,no_clouds,old_light,F1_F3
python3 ablation_stats.py; python3 frame_stats.py
```
Окно иногда открывается вполовину ширины (958 вместо 1918) - раннер повторяет; кадры других размеров статистика пропускает. `frames/` (~90 МБ PNG) не в git.
