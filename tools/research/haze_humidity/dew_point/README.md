# Климат точки росы: сетка 1° для haze-humidity (HH-1)

## Источник и лицензия
- **ERA5** (ECMWF), `2m_dewpoint_temperature`, часы 00 и 12 UTC каждого дня (среднее двух сроков гасит суточную гармонику),
  **1991–2020 (30 лет, 10 957 дней)**, исходное разрешение 0.25°, усреднено по площади в ячейки 1° (вес ∝ перекрытие·cos φ).
  Доступ без ключа: ARCO-ERA5, публичный Zarr `gs://gcp-public-data-arco-era5/ar/full_37-1h-0p25deg-chunk-1.zarr-v3`.
- **Лицензия: CC-BY-4.0** (ECMWF: «committed to providing open data under the Creative Commons Attribution (CC-BY-4.0) licence»;
  страница набора CDS — «CC-BY licence», DOI 10.24381/cds.adbb2d47). Распространение производных данных (в т.ч. в
  коммерческой игре) разрешено при атрибуции с указанием изменений. Версию «4.0» ECMWF называет явно; в CDS-странице
  набора номер версии не указан — см. uncertain.
- **Текст атрибуции (для ASSETS.md / титров):**
  «Contains modified ECMWF Reanalysis data (ERA5): Hersbach, H. et al. (2020), ERA5 global reanalysis, Q. J. R. Meteorol.
  Soc. 146, 1999–2049, doi:10.1002/qj.3803. © European Centre for Medium-Range Weather Forecasts (ECMWF), retrieved via the
  Copernicus Climate Data Store, DOI 10.24381/cds.adbb2d47. Licensed under CC-BY-4.0. Data were averaged to 1° cells,
  aggregated to monthly climatology and quantised.» Логотип ECMWF не использовать.
- Ссылки: https://confluence.ecmwf.int/x/2hAiK (атрибуция ECMWF), https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels
- **NASA POWER (T2MDEW, MERRA-2) — не выбран:** сетка 0.5°×0.625° (грубее вдвое-втрое), нет высоты орографии под рукой для
  подсеточной регрессии, суточные ряды берутся только по запросам API на точку (массовая выгрузка σ по сетке — тысячи
  запросов). Данные NASA открыты (без ограничений на повторное использование), покрытие глобальное с 1981. Эти сведения о
  POWER — из общих знаний, не проверены по первоисточнику (не влияют на результат).

## Файл
`data/climate/dew_point_1deg.bin`, формат HH1 v1 (`docs/contracts/haze-humidity.md`): 360×180×12, int16, brotli q11.
**Размер 1 496 591 байт** (контрактный ориентир ≤ 1 МБ превышен на 0,5 МБ; шлюз приёмки ≤ 2 МБ; raw 3 240 000 байт).
td_scale 0.01 °C, sd_scale 0.01 К, z_scale 0.5 м. Диапазоны: Td −66.6…27.9 °C, σ 0.26…12.6 К, Z −35…5383 м
(клиппинга нет, пропусков нет). Контрактный тест Godot: 3 тестов, 0 упало.
Чтобы уменьшить до ~1 МБ — понизить точность (td_scale 0.05, sd_scale 0.05) — не делал, смысла для 1.5 МБ нет.

## σ по дням
σ среднесуточной Td (1° ячейка, среднее 00+12 UTC) вокруг средней своего месяца по всем дням всех 30 лет — включает
межгодовую изменчивость. Суша: среднее 4.6 К (5–95%: 0.9…8.1 К); внутри одного месяца-года (без межгодовой части) 4.2 К.
Алтай (долина): январь 7.4 К, июль 2.6 К; Askarovo/Aushkul: зима ~7.0 К, лето 3.2 К; Крым: зима 3.6, лето 2.5; Ладакх/Иран (Darab) ~4.6–4.8 К круглый год; тропики (Cairns) 1.2–2.5 К.
Среднее двух сроков занижает суточную σ на малую долю (разброс внутри суток не учтён), оценка — для суточной модели.
Пропуск в источнике: 2018-05-16 пуст в ARCO — день исключён (и месяц 2018-05 из 0.25° для регрессии).

## Поправка на высоту
Td сетки отнесена к средней высоте ячейки ERA5 (Z). Для долины места: `Td = Td_cell + G·(z_valley − Z_cell)/1000`, G — К/км (<0).
- **Из данных (регрессия по подклеткам 0.25° внутри 1°, суша, перепад ≥ 300 м, пул Σcov/Σvar; `gradient.json`):**
  30–60°N: зима −4.5, весна −3.9, лето −3.3, осень −4.2; год −4.0 К/км. Тропики 20°S–20°N: −4.5…−4.7, год −4.6.
  Алтай-регион: год −4.15 (лето −4.0); Ю.Урал: год −3.0 (лето −2.4); Загрос: год −4.15; Квинсленд: год −2.8.
  Глобально суша −4.8 (медиана ячейка-месяц −4.4; p10..p90 в gradient.json).
- **Теория (`theory.py`):** хорошо перемешанный слой, постоянное отношение смеси: −1.6…−1.8 К/км. Ниже наблюдаемого
  в данных: на уровне 2 м Td падает быстрее из-за убывания влаги с высотой над источником (приземный слой более влажный
  в долинах, масштаб ~2–3 км) и горизонтальной корреляции с температурой; регрессия по ERA5 0.25° — оценка модели,
  не измерений.
- **Рекомендация для HH-4:** `dew_point_gradient_k_per_km = −4.0` (единое значение; при желании сезонно для 30–60°N:
  −4.5/−3.9/−3.3/−4.2 для ДЯФ/МАМ/ИИА/СОН). Поправка для места Алтай (долина 304 м, Z_cell 762 м): +1.8 К.
  Литературные значения для сверки (по памяти, не проверены): давление пара в горах убывает экспоненциально
  с масштабом ~2–3 км (Kunkel 1989; Rolland 2003; Liston & Elder 2006, MicroMet) — порядок согласуется.

## Сверка с таблицей (`sites.csv`, 8 мест × 12 мес.)
Высота долины — 10-й перцентиль рельефа в радиусе 10 км (AWS Terrain Tiles z10, https://registry.opendata.aws/terrain-tiles/,
как `valley_percentile 0.1` игры; Алтай 303.7 м против 304 в configs — совпало); для морских мест — 0 м.

Алтай по месяцам (с поправкой, ян…дек): −17.6, −15.5, −9.3, −1.3, 4.9, 11.7, 14.3, 11.8, 5.9, −0.8, −8.9, −14.7
против таблицы −19, −18, −11, −3, 2, 7, 9, 8, 3, −2, −9, −16: среднее отклонение +2.5 К, июль **+5.3 К**.
Таблица единая для мира и не годится для других мест: Крым/Кэрнс/остров отличаются на 10–25 К.

**Что даёт кромке:** при `lcl_m_per_k = 122` м/К Δ(Td) июля Алтая +5.3 К уменьшает T−Td и опускает основание/кромку
на ≈ 122·5.3 ≈ **−640 м** (а для сухого Darab: Td 5.5 против 9 → +3.5 К разности → +430 м кромка выше).

## uncertain
- Td = среднее 00+12 UTC, не истинное суточное среднее; σ по ячейке 1° (сглажена по сравнению с точкой).
- Градиент из регрессии ERA5 0.25° (модельный, с подсеточной орографией ~28 км) — не измерения; литература приведена по
  памяти, без проверки по первоисточникам.
- Таблица `dew_point_c` Алтая «подогнана под эталоны прогноза» — разница с климатологией может быть оправдана подгонкой
  других параметров (upper_air); HH-4 должна пересчитать эталоны.
- CC-BY «4.0» в CDS-странице не указан явно (указан в ECMWF-документе); перед релизом сверить текст лицензии CDS.
- Высоты долин — 10-й перцентиль по DEM, а не `configs/locations/*.json`.
