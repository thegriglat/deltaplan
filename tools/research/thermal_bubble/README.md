# thermal-bubble — шаблон пузыря (TB-1)

`bubble.py` (только numpy) — поле одного термика: голова — сферический вихрь Хилла, шлейф стартового факела
(Тёрнер 1962, Мортон–Тейлор–Тёрнер 1956), отражения от земли и крышки. Интерфейс — TB1 в `docs/contracts/thermal-bubble.md`.

## Формулы
Всё поле — осесимметричная функция тока Стокса ψ(ρ, s): u_ρ = −(1/ρ)∂ψ/∂s, u_s = (1/ρ)∂ψ/∂ρ, поэтому ∇·v = 0 тождественно
(скорости — аналитические производные ψ). Сумма вкладов и образов тоже бездивергентна.

- **Голова** (вертикальная ось через центр, система земли). r < R: ψ = (3U/4)ρ²(1 − r²/R²) + (U/2)ρ²;
  r ≥ R: ψ = (U/2)ρ²R³/r³. В центре w = 2,5 U, на r = R скорость непрерывна (тест).
- **Шлейф** (ось от (xs, ys, 0) к центру головы, наклон сносом). Плоский профиль MTT:
  b = (6/5)α_p s, w_p = (5/(6α_p))(0,9 α_p F0/π)^{1/3} s^{−1/3}, Q = πb²w_p ∝ s^{5/3}
  (деление на π: у MTT F — поток на π, здесь F0 = g′Q — полный). Внутри ρ < b: ψ = Q(s)ρ²/(2πb²) (w = w_p).
  Снаружи — потенциальный приток вовлечения: линия стоков плотности −dQ/ds на оси (Гаусс–Лежандр, панели растут ×1,25),
  ψ точечного источника −(m/4π)s/r. Сшивка ψ = χψ_in + (1−χ)ψ_out, χ — гладкая (квинтика) на ρ/b ∈ [1; 1,5];
  за концами шлейфа радиус сшивки сходит к нулю (иначе стирается чужое поле).
  Верхний конец: поток Q сходится к нулю плавно на длине R внутри головы (там плотность −dQ/ds > 0 — расходящийся
  поток уходит радиально в голову); отдельного точечного источника в центре нет — его особенности не нужно.
  Q(0) = 0 (Q ∝ s²·(s²+s₀²)^(−1/6), s₀ = 3 м — только чтобы не было сингулярности у земли).
- **Отражения.** Земля z = 0: образ v_img(x, y, z) = M·v(x, y, −z), M = diag(1, 1, −1); крышка z = z_i — так же;
  при обеих плоскостях — ряд образов n = −2…2 (w на плоскостях ≤ 3·10⁻⁵ max|w|).
- **Траектория** (`state`). Пока источник включён (t0…t0+τ): фронт z_f^{4/3} = (4/3)·φ·k_p·t, k_p = w_p z^{1/3}
  (Turner 1962: z_f ∝ F^{1/4}t^{3/4}, скорость фронта = φ скорости шлейфа); центр z_c = z_f/(1+α_h), R = α_h z_c.
  После отрыва: R = α_th(z − z_v), U = C·√(g′R) ⇒ (z − z_v)² = d₀² + 2K(t − τ), U (z − z_v) = K = const (Scorer 1957).
  C = [2(1+k)α_th]^(−1/2) из импульса (1+k)·d(VU)/dt = B, k = 1/2 (присоединённая масса шара).
  **K взят из непрерывности U при отрыве**, а не из B = F0·τ: при B = F0·τ скорость скачет в 2,7 раза (1,44 → 3,92 м/с),
  потому что голова несёт лишь часть плавучести (в этом случае 13 % F0·τ, `thermal_B`), остальное — в шлейфе и следе.
  Низ шлейфа z_b растёт со скоростью шлейфа w_p(z_b) ⇒ z_b = ((4/3)k_p(t−τ−t0))^{3/4} (тот же закон, что у фронта);
  когда z_b дошёл до начала вливания в голову — Q = F0 = 0, z_b = z_c (шлейфа нет). Слой нейтральный (B сохраняется).
- **Крышка.** Когда z_c + R = z_i, голова останавливается (U = 0, R замораживается), растекание даёт отражение крышки;
  `state` → None через R/U_до_касания после касания. Снос: голова целиком, низ шлейфа — нет.
- **from_game.** F0 = w*³z_l/8,5 (Дирдорф 1970: (g/θ0)H_kin = w*³/z_l; Аллен 2006: n_A = 8,5/z_l²).
  τ — из баланса потока плавучести: поток на площадь w*³/z_l = n_A·B/T с B = F0·τ и T = τ (термик за τ пересекает слой) ⇒
  τ = время, за которое фронт с этим F0 доходит до z_l: τ = (3/4)z_l^{4/3}/(φ k_p). Для w* 2,5 и z_l 1400: F0 = 2574 м⁴/с³,
  τ = 633 с (жизнь термика игры из `ThermalCfg`: рост 120–240 + зрелость 300–720 + распад 150–300 с — тот же порядок).

## Числа (`PARAMS`)
| ключ | значение | диапазон в литературе | источник | надёжность |
|---|---|---|---|---|
| alpha_thermal | 0,25 | 0,25–0,34 | Scorer 1957; Morton–Taylor–Turner 1956; Turner 1969 | medium |
| added_mass_k | 0,5 | — (точно для шара) | Lamb §92; Batchelor 1967 §6.4; Turner 1964 | high |
| C_thermal | 1,155 | из k, α | вывод (не подогнан) | medium |
| alpha_plume | 0,12 (плоский профиль) | 0,10–0,16 (гауссов в 1/√2 меньше) | MTT 1956; Turner 1973 | medium |
| front_fraction | 0,6 | — | Turner 1962, J. Fluid Mech. 13, 356 | medium |
| alpha_head | 0,15 | «чуть больше половины угла термика» | Turner 1962 (оценка по фразе, оригинал не сверен) | low |

Литература (веб-поиск, оригиналы не открывались — числа сверены по цитатам): Turner 1962, JFM 13, 356 (скорость фронта 0,6);
Scorer 1957; Turner 1957, 1964, 1969; Morton–Taylor–Turner 1956; обзор термиков arXiv:astro-ph/0008099 (α 0,25–0,34);
McKim et al. arXiv:1906.07224 (спор о природе вовлечения). Лицензии данных: данных нет, только числа из публикаций.

## Допущения и границы
- Буссинеск, несжимаемость; слой нейтральный; сдвиг ветра по высоте не учтён (ветер постоянный, наклон — по сносу); рельеф — только плоскость.
- Закон подъёма — осреднённая теория подобия; турбулентности, расщепления и колебаний головы нет.
- Шлейф — точечный источник F0 (виртуальный источник площадного ядра ~270 м не учтён): у земли скорость шлейфа завышена
  (w_p(100 м) ≈ 7 м/с против ~1 м/с свободной конвекции у Аллена); выше 0,3 z_l — разумна (w_p(700) = 3,5 м/с при w* 2,5).
- Траектория при отрыве: непрерывность U, не B = F0·τ (см. выше). Скорость низа шлейфа = скорости шлейфа — оценка (low).
- Приток к шлейфу — потенциальный (вихрей вне головы нет); вовлечение головы в Хилла-поле не рассчитано, только рост R.
- Тесты `contract/check_contract.py tb1` — пройден; свои проверки: центр Хилла 2,5U, непрерывность на r = R, приток к оси, Q ∝ s^{5/3},
  подобие R ∝ z − z_v, U (z − z_v) = const, непрерывность U, дивергенция двух пузырей.
