# thermal-bubble — шаблон пузыря (TB-1, v2: TB-1b)

`bubble.py` (только numpy) — поле одного термика: голова — сферический вихрь Хилла, шлейф стартового факела
(Тёрнер 1962, Мортон–Тейлор–Тёрнер 1956) от виртуального источника, отражения от земли и крышки. Интерфейс — TB1 v2 в
`docs/contracts/thermal-bubble.md`. Вся структура (голова + шлейф + приток) осесимметрична вокруг **вертикальной** оси
через (xc, yc) и сносится ветром целиком (система воздуха): xs = xc, ys = yc.

## Формулы
Всё поле — осесимметричная функция тока Стокса ψ(ρ, s): u_ρ = −(1/ρ)∂ψ/∂s, u_s = (1/ρ)∂ψ/∂ρ, поэтому ∇·v = 0 тождественно
(скорости — аналитические производные ψ). Сумма вкладов и образов тоже бездивергентна.

- **Голова** (вертикальная ось через центр). r < R: ψ = (3U_h/4)ρ²(1 − r²/R²) + (U_h/2)ρ²;
  r ≥ R: ψ = (U_h/2)ρ²R³/r³. В центре w = 2,5 U_h, на r = R скорость непрерывна (тест). U_h — сила вихря
  (`State.Uh`); пока голова поднимается, U_h = U (скорость центра), у крышки U → 0, а вихрь гаснет отдельно (ниже).
- **Шлейф** (вертикальная ось, начало s — виртуальный источник на глубине z_v, s = z + z_v). Плоский профиль MTT:
  b = (6/5)α_p s, w_p = (5/(6α_p))(0,9 α_p F0/π)^{1/3} s^{−1/3}, Q = πb²w_p ∝ s^{5/3}
  (F0 = g′Q — полный поток плавучести). Q(s) умножен на плавные «подъёмы» (квинтика): снизу на длине L_b
  (у земли L_b = b0 — слой притока; у оторванного низа L_b = max(b0, z_b/2)), сверху на длине R (вливание в голову,
  трубка кончается в центре головы).
  Снаружи — потенциальный приток вовлечения: линия стоков плотности −dQ/ds на оси (Гаусс–Лежандр, панель ≤ 0,6 b),
  ψ точечного источника −(m/4π)s/r. Сшивка ψ = χψ_in + (1−χ)ψ_out, χ — квинтика на ρ/b ∈ [1; 1,5].
  **Внутри трубы ψ_in = G(s)ρ² с G = ψ_out(b(s), s)/b²** — поток трубы берётся из самого внешнего решения на её границе:
  при ψ_in = Q ρ²/(2πb²) на концах, где Q меняется на масштабе b, ψ_in и ψ_out не совпадали, и сшивка давала ложные
  10 м/с у основания (найдено при проверке непрерывности). Цена: w на оси на 4–15 % ниже MTT (внешнее решение щелевое,
  b/s = 0,14); это меньше разброса α_p (0,10–0,16 ⇒ w_p ±20 %).
- **Виртуальный источник** (ревью TB-1, minor). Точечный MTT давал 11 м/с на 20 м. Начало шлейфа — под землёй:
  z_v = 5b0/(6α_p) (MTT для площадного источника радиуса b0: b(z = 0) = b0). b0 = r₂(ζ = 0,1) = 0,102·0,1^{1/3}(1 − 0,025)·z_l
  = 0,0461 z_l = 64,6 м при z_l = 1400 — радиус ядра Аллена (Allen 2006) у нижней границы его области применимости,
  ближайший к земле, где формула ещё осмысленна. Тогда z_v = 449 м, w_p(z = 0) = 4,0 м/с = 1,6 w*. Ниже b0 над землёй
  поток растёт от нуля на длине b0 (горизонтальный приток в основание шлейфа), w(z = 0) = 0 (образ под землёй).
  Q(s) при этом ∝ (z + z_v)^{5/3}.
- **Отражения.** Земля z = 0: образ v_img(x, y, z) = M·v(x, y, −z), M = diag(1, 1, −1); крышка z = z_i — так же;
  при обеих плоскостях — ряд образов n = −2…2 (w на плоскостях ≤ 3·10⁻⁵ max|w|).
- **Траектория и жизнь** (`state`; всё гладко, без ступенек).
  1. Пока источник включён (0…τ): фронт стартового факела от виртуального источника
     s_f^{4/3} = s_0^{4/3} + (4/3)·φ·k_p·t (Turner 1962: скорость фронта = φ скорости шлейфа), s_0 — голова радиуса
     R = α_h s_c, посаженная на землю; центр s_c = s_f/(1+α_h), R = α_h s_c (конус от виртуального источника, при z = 0
     R ≈ b0). Начало: z_f = 158 м, голова касается земли. Сила поля выходит на полную за R₀/U₀ = 42 с (`_onset`).
  2. После τ: свободный термик R = α_th(z − z_v′), U = C√(g′R) ⇒ (z − z_v′)² = d₀² + 2K(t − τ), U (z − z_v′) = K (Scorer 1957).
     C = [2(1+k)α_th]^(−1/2) из импульса (1+k)·d(VU)/dt = B, k = 1/2.
     **K взят из непрерывности U при отрыве**, а не из B = F0·τ: голова несёт лишь долю плавучести (17 % F0·τ, `thermal_B`),
     остальное — в шлейфе и следе; при B = F0·τ U скакала бы.
  3. **Крышка.** Время головы t_e идёт со скоростью dt_e/dt = s_f = ss((z_i − z_c − R)/R) (квинтика): на подходе (в пределах
     ~R под крышкой) подъём плавно останавливается, верх головы стремится к z_i снизу и не пересекает (c ~ t^(−1/2)); R
     замораживается; растекание даёт образ крышки. Вихрь головы U_h гаснет как exp(−θ), dθ/dt = (1 − s_f)/t_decay
     (только у остановившейся головы). t_decay = z_l/w* = 560 с — конвективное время (Lenschow–Stephens 1980: жизнь
     термика порядка z_i/w*); надёжность low (подбор масштаба по порядку величины, прямого измерения нет).
  4. **Конец источника.** Низ шлейфа поднимается со скоростью шлейфа: dz_b/dt = w_p(z_b + z_v), разгон по квинтике
     за 3b0/w_p(z_v) ≈ 48 с (иначе поле у земли меняется рывком); шлейф гаснет по f = ss((z_c − R − z_b)/min(2R, 0.4(z_c − R))),
     Q ∝ f, F0_eff = F0 f³ — до того, как низ догнал голову, поэтому скачка при «догнал» нет.
  5. Конец (`state` → None): оценка амплитуды max(2,5 U_h, f·w_p у низа) < 2 % её пика (контракт: < 5 % по полю).
     При w* 2,5, z_l 1400, ветер 3: ≈ 2700 с.
- **from_game.** F0 = w*³z_l/8,5 (Дирдорф 1970: (g/θ0)H_kin = w*³/z_l; Аллен 2006: n_A = 8,5/z_l²).
  **τ — отдельное допущение (время работы источника), не вывод из баланса потока и не время хода фронта:**
  τ = рост + зрелость термика игры (`ThermalCfg::default`: grow_s 120–240, mature_s 300–720; середины 180 + 510) = 690 с.
  Литературного числа времени работы источника у земли не найдено (надёжность low). Для w* 2,5, z_l 1400: F0 = 2574 м⁴/с³.
  При этом голова к τ доходит до ~0,9 z_i и подходит к крышке, пока шлейф ещё питает (или чуть после отрыва).

## Числа (`PARAMS`)
| ключ | значение | диапазон в литературе | источник | надёжность |
|---|---|---|---|---|
| alpha_thermal | 0,25 | 0,25–0,34 | Scorer 1957; Morton–Taylor–Turner 1956; Turner 1969 | medium |
| added_mass_k | 0,5 | — (точно для шара) | Lamb §92; Batchelor 1967 §6.4; Turner 1964 | high |
| C_thermal | 1,155 | из k, α | вывод (не подогнан) | medium |
| alpha_plume | 0,12 (плоский профиль) | 0,10–0,16 (гауссов в 1/√2 меньше) | MTT 1956; Turner 1973 | medium |
| front_fraction | 0,6 | — | Turner 1962, J. Fluid Mech. 13, 356 | medium |
| alpha_head | 0,15 | «чуть больше половины угла термика» | Turner 1962 (оценка по фразе, оригинал не сверен) | low |

Литература (веб-поиск, оригиналы не открывались — числа сверены по цитатам): Turner 1962, JFM 13, 356 (скорость фронта 0,6);
Scorer 1957; Turner 1957, 1964, 1969; Morton–Taylor–Turner 1956; обзор термиков arXiv:astro-ph/0008099 (α 0,25–0,34);
McKim et al. arXiv:1906.07224 (спор о природе вовлечения). Лицензии данных: данных нет, только числа из публикаций.

## Допущения и границы
- Буссинеск, несжимаемость; слой нейтральный; сдвиг ветра по высоте не учтён (ветер постоянный); рельеф — только плоскость.
- **Ось вертикальна, шлейф не гнётся.** Структура сносится ветром целиком; низ шлейфа уходит от точки источника по ветру
  (граница модели: в жизни шлейф от неподвижного источника гнётся ветром; при ветре термики чаще отрываются пузырями).
- Закон подъёма — осреднённая теория подобия; турбулентности, расщепления и колебаний головы нет.
- τ — допущение (см. from_game); t_decay, b0, время разгона низа шлейфа — оценки порядка величины (low).
- Приток к шлейфу — потенциальный (вихрей вне головы нет); вовлечение головы в Хилла-поле не рассчитано, только рост R.
- w на оси шлейфа на 4–15 % ниже MTT (см. выше); у земли шлейф быстрее Аллена (w_p(0) = 4,0 м/с против ~1 w*): виртуальный
  источник с b0 = 0,046 z_l убирает 11 м/с точечного, но не доводит до w*; max|v| у земли (z ≤ 140 м) = 4,7 м/с ≤ 2w* (приёмка).
- Скорость низа шлейфа = скорости шлейфа — оценка (low).
- Тесты: `contract/check_contract.py tb1` (v2: непрерывность 2 с ≤ 0,25 пика — 0,09; перед концом ≤ 0,05 — пройден);
  свои: центр Хилла 2,5U, непрерывность на r = R, приток к оси, Q ∝ s^{5/3}, w на оси против MTT, ось вертикальна,
  виртуальный источник (w конечна, w(0) = 0), непрерывность во времени у переходов, подобие, U при отрыве, дивергенция.
