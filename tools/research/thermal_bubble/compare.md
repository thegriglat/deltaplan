# TB-5 — сверка шаблона пузыря v3 и баланс Φ

Скрипт `compare.py` считает поле `bubble.py` (TB1 v3) на типичном случае и сводит семь величин TB3 с литературой
(`literature.md`) и нынешним профилем (`current.py`, порт `profile.rs`). Числа — `out/compare.json`
(`format: tb-compare`), разрезы — `/home/greg/deltaplan/build/screenshots/thermal-bubble/tb5_*.png` (5 файлов; круг 1 `tb2b_*` не тронут).
Что изменилось в шаблоне — `README.md`, «Что изменилось в v3».

**Случай.** Медианы `docs/research/calibration_data/thermals.md`: w* = 2,56 м/с, z_i = z_l = 1400 м; ветер поля 3 м/с;
источник `from_game` (v3: F0 = 0,371·w*³z_l/8,5 = 1026 м⁴/с³, τ = 690 с, b0 = 64,6 м); жизнь пузыря 2915 с. Нынешняя модель:
`allen_core` (R верха 107,1 м, w0 = 1,24 w* = 3,17 м/с, n_A = 8,5/z_l² = 4,34·10⁻⁶ м⁻²), top = z_l.
Горизонтальные величины — в системе воздуха; сдвиг на ветер даёт разность поля 0.

**Оговорки.**
- Определение радиуса одно (смена знака w ≈ граница области подъёма условной выборки), но эталон — полуширина d/2 по влажности/температуре самолётом, а не
  по знаку w: прямого совпадения определений нет. Аллен (r₂) в 1,27 раза больше L&S; при его α (0,033) радиус был бы 0,076 z_i — тоже в диапазоне.
- Строка w_core_max: среднее по диску w>0 в момент пика 0,44 w* (L&S ŵ = 0,45 w*; v2: 0,84), при 0,75 w* на двух уровнях — там первый нуль
  радиуса даёт широкое кольцо (см. ниже).
- **Профиль w(ρ) не монотонен за краем головы.** На ζ = 0,5 w(75 м) = 0,72, w(100) = 0,32, w(150) = **+0,50**, w(200) = −0,07 м/с: положительное кольцо до
  ~180 м вокруг головы радиусом 84 м. Источник — шлейф: плоский MTT с лабораторным α_p = 0,12 даёт трубу b = 165 м при R головы 84 м (измеренное α головы в 10 раз меньше
  лабораторного, α_p не менялся). Радиус ядра по первой смене знака от кольца не зависит, но «ширина подъёма» шаблона у головы больше радиуса ядра. См. `uncertain`.

## 7. Баланс Φ (v3)

Типичный случай: w* = 2,56, z_i = z_l = 1400, n_A = 8,5/z_l² живых ядер. Сила по правилу игры (thermals.md, «Плотность источников»): w0 = min(2,5 w*, Φ/(n_A K̄)),
несомый ядрами поток = n_A K̄ w0, «между» = Φ − несомое. **Φ типичный = 0,35 × 0,45 w* = 0,1575 w* = 0,40 м/с** — доля площади подъёма × средний подъём
(L&S 1980, Stull 1988): потока поля игры (F̄ + W̄) в прототипе нет, это допущение (чувствительность ниже).

| величина | шаблон v3 | нынешняя | измерения |
|---|---|---|---|
| K̄, м² (по контрактному определению: жизнь, столб 0…z_l, на 1 м/с) | **1462** (w0 = 1 м/с) | **7413** (численно, огибающая без паузы gap); 6182 по формуле `columns.rs` | — |
| сила ядра по правилу (кап 2,5 w*) | 6,4 м/с | 6,4 м/с | — |
| доля Φ, несомая ядрами | **0,10** (через K̄·w0); **0,88** (прямой поток при w0 = 6,4: 8,2·10⁴ м³/с) | **0,51** (численный K̄); 0,43 (формула) | 0,37 (вывод 0,13/0,35); игра сейчас: 0,37–0,45 днём |
| «между», в w* | 0,142 (K̄·w0); 0,018 (прямой) | 0,077 | 0,099 |

Расхождение численного K̄ нынешней и формулы `columns.rs` — только в доле жизни: форма (площадь) совпадает до 0,2 % (9520 против 9500 м²), множитель жизни 0,779 (численно: рост+зрелость+спад
без паузы) против 0,651 (формула: с паузой gap = 180 с и duty = 1) — ×1,197. Формула считает среднее по циклу с паузой, наше определение — по жизни пузыря.

**Вывод.** Для шаблона K̄ по контракту неустойчив: поток пузыря растёт с силой быстрее линейного (проверено: K̄ при w0 = 1 — 1462 м², поток/w0 при 3,17 м/с — 4396, при 6,4 — 12823 м²; фронт шлейфа идёт со скоростью ∝ F0^⅓, и время подъёма/жизнь при слабом пузыре другие),
поэтому K̄ при w0 = 1 м/с (медленный пузырь живёт до предела 4τ + 3000 с, хвост долгий) занижает поток сильного пузыря в 8,7 раза (1462·6,4 = 9,4·10³ против 8,2·10⁴ м³/с). Прямое число (0,88)
говорит: одно ядро шаблона на пределе 2,5 w* несёт почти весь Φ типичного случая, а нынешнее — половину; «между» от этого меняется с 0,077 (нынешняя) до 0,018 w* (шаблон, прямое) —
почти нет широкого подъёма сверх ядер. Если оставить измеренную долю ядер 0,37, остаток «между» = 0,099 w*; шаблон в игре должен задаваться не капом 2,5 w*, а `core_flux_fraction`
(иначе ядра слишком мощные: пик 6,4 м/с против 1–2 w* = 2,6–5,1 м/с). Кап 2,5 w* — правило нынешней модели.

Чувствительность к Φ (0,10 / 0,1575 / 0,25 w*): доля нынешней 0,80 / 0,51 / 0,32, доля шаблона по контрактному K̄ 0,16 / 0,10 / 0,06; «между» нынешней 0,020 / 0,077 / 0,170 w*, шаблона по K̄ 0,084 / 0,142 / 0,234.

**Что изменится в «между» при встраивании.** Поток вверх, несомый ядром шаблона (прямой), больше, чем у нынешнего ядра, в 1,7 раза при одинаковой силе ⇒ «между» (остаток организованного подъёма) шире не станет;
уменьшится на 0,06 w* (0,077 → 0,018). Это следует из числа n_A·K̄ и капа, а не из измерения: решение о доле ядер (0,37) и о капе — за человеком.

## Допущения и границы

- Ветер проверен на бездивергентность; шаблон ветер не гнёт, сдвиг не наклоняет шлейф.
- Приток/растекание/кольцо — потенциальные следствия формы поля; прямых измерений нет (null), LES не читали.
- «Ядро» литературы — условная выборка; сравнение на уровне порядка величины (определения радиуса не идентичны, см. §2).
- Φ в балансе — допущение (L&S × площадь), не поле игры. n_A «живых» ядер Аллена и «живых» пузырей шаблона (жизнь 2915 с против 915 с игры) — не одно и то же.
- Периодическая ячейка (3×3 образа) — идеализация; возрасты (i+0,5)/6 — равномерно.
- Скан по времени 15 с (30 с в чувствительности).
