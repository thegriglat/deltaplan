# TB-2b — сверка шаблона пузыря: один и несколько термиков

Скрипт `compare.py` считает поле `bubble.py` (TB1 v2) на типичном случае и сводит семь величин TB3 с литературой
(`literature.md`) и нынешним профилем (`current.py`, порт `profile.rs`). Числа — `out/compare.json`
(`format: tb-compare`), разрезы — `/home/greg/deltaplan/build/screenshots/thermal-bubble/tb2b_*.png` (5 файлов).

**Случай.** Медианы `docs/research/calibration_data/thermals.md`: w* = 2,56 м/с, z_i = z_l = 1400 м; ветер поля 3 м/с;
источник `from_game` (F0 = 2763 м⁴/с³, τ = 690 с, b0 = 64,6 м); жизнь пузыря до исчезновения 2645 с. Нынешняя модель:
`allen_core` (R верха 107,1 м, w0 = 1,24 w* = 3,17 м/с, n_A = 8,5/z_l² = 4,34·10⁻⁶ м⁻²), top = z_l.
Горизонтальные величины считались в системе воздуха (поле пузыря сносится ветром целиком; проверено: сдвиг на ветер даёт
разность поля 0, осевая симметрия до 4·10⁻¹⁶).

## 1. Дивергенция суммы с ветром

| случай | p99 \|∇·v\|·R/U | flux_rel |
|---|---|---|
| один термик, 7 моментов (60…2400 с), ветер постоянный | ≤ 7,5·10⁻⁷ (t = 690 с) | ≤ 3,5·10⁻⁹ |
| то же, ветер u(z) = U ln(1+z/z0)/ln(1+1400/z0), z0 = 0,1 м | те же числа | те же |
| шесть термиков, «все живы» (обе формы ветра) | 2,1·10⁻⁷ | 3,8·10⁻⁹ |

Порог приёмки 10⁻³ — запас 3 порядка. Ветер сокращается точно (u зависит только от z, ∂u/∂x = 0). flux_rel нормирован на
∮|v_возм·n| (строже, чем на полное поле: с ветром 2·10⁻¹¹). R/U: R головы, U — сила вихря (U_h при остановке у крышки).
Линейность суммы шести: `velocity(all) − Σ velocity(i)` = 2·10⁻¹⁶ отн. Это по построению: шаблон — линейная суперпозиция
потенциальных полей, обратной связи между соседями нет.

## 2. Семь величин TB3

| quantity | шаблон | нынешняя | литература | вывод |
|---|---|---|---|---|
| w_core_max_over_wstar | **1,83** (1,72…1,95 по ζ) | 1,24 | пик ядра 1–2 (low); ŵ среднее 0,45 | пик в диапазоне; среднее по диску w>0 **0,84 w\*** против 0,45 L&S и 0,46 у нынешней |
| core_radius_over_zi (ζ = 0,5) | **0,120** (R головы 172 м) | 0,0707 | 0,0555 (L&S), 0,071 (Allen), 0,08–0,09 (Ansmann) | шаблон шире в 1,3–2,2 раза |
| rise_speed_over_wstar | **0,59** (U = 1,51 м/с при zc = 0,5 z_i; средняя 0,61; старт 0,75) | — (нет головы) | нет числа | — |
| inflow_ground_over_wstar | **0,81** (2,1 м/с, z = 10 м; максимум по ρ на z = 30 м при r ≈ 85 м) | 0 (нет горизонтальной скорости) | нет числа | новое для пилота |
| outflow_top_over_wstar | **0,45** (1,15 м/с, ζ 0,85–0,95) | 0 | нет числа | новое |
| ring_sink_min_over_wstar | **−0,88** (ζ = 0,3, t = 435 с) | −0,27 | нет числа (Ansmann: нисходящие слабее по среднему w) | шаблон ×3,3 кольца нынешней |
| updraft_area_fraction | **0,136** (w>0), 0,088 при w>0,1 w* | 0,129 | 0,3–0,4 (0,13 — ядра Аллена) | оба ниже воздуха подъёма вдвое-втрое |

Определения (одинаково для обеих моделей). *w_core_max* — max по ρ, по жизни, на 7 уровнях ζ = 0,23…0,5, среднее по уровням;
момент пика у ζ = 0,23 — t = 150 с, у ζ = 0,5 — t = 405 с (по мере подъёма головы), то есть это пик в голове/шлейфе при прохождении.
*core_radius* — первая смена знака w (+ → −) вдоль луча в момент, когда центр головы на уровне (ζ = 0,25: 0,083 / 0,060;
ζ = 0,75: 0,157 / 0,075 z_i — шаблон/нынешняя; радиус головы растёт по Скореру 0,25·(z−z_v′), а ядро Аллена почти постоянно).
*inflow/outflow* — max радиальной скорости по ρ и по жизни. *ring* — min w по ρ, ζ = 0,3…0,8, по жизни; по уровням (шаблон/нынешняя):
0,3: −0,88/−0,27; 0,5: −0,82/−0,27; 0,7: −0,46/−0,27; 0,8: −0,22/−0,27. *updraft* — доля w > 0 при раскладке по п. 5.

Четыре величины без литературного числа (rise, inflow, outflow, ring) — `literature: null` с причиной (literature.md, доработки 1–2:
AMS закрыт 403). Сверка по ним — только с нынешней моделью и качественно.

**Что можно считать результатом, а что нет.**
- Пик ядра (1,83 w*) в литературном диапазоне 1–2 w* (но диапазон — из пересказа, low). Среднее по ядру 0,84 w* почти вдвое выше
  среднего подъёма L&S 0,45 w* (high), причём нынешний профиль совпадает с 0,45 по построению. Радиус ядра шаблона 0,12 z_i —
  больше всех литературных значений. Вывод: **головы шаблона слишком крупные и сильные**, если LES/самолётное ядро считать эталоном;
  причина — α_th = 0,25 и R ≈ 0,25 (z − z_v′) без ограничения от окружения; подгонять не стали.
- Приток 0,8 w* и растекание 0,45 w*, кольцо −0,88 w* — предсказания шаблона без литературной проверки.

## 3. Профиль w(ρ) в ядре, м/с (шаблон / нынешняя)

Момент: центр головы шаблона на данном ζ (ζ = 0,25: t = 149 с; 0,5: 369 с; 0,75: 622 с).

| ρ, м | ζ = 0,25 | ζ = 0,5 | ζ = 0,75 |
|---|---|---|---|
| 0 | 4,85 / 3,17 | 4,33 / 3,17 | 3,85 / 3,17 |
| 50 | 3,96 / 1,45 | 3,95 / 1,84 | 3,65 / 1,96 |
| 100 | 1,30 / −0,51 | 2,81 / −0,03 | 3,05 / 0,13 |
| 150 | −0,78 / −0,46 | 0,91 / −0,66 | 2,05 / −0,69 |
| 200 | −0,22 / −0,08 | −0,44 / −0,27 | 0,65 / −0,36 |
| 300 | −0,09 / 0 | −0,16 / 0 | −0,56 / 0 |
| 450 | −0,03 / 0 | −0,07 / 0 | −0,12 / 0 |
| 900 | −0,004 / 0 | −0,014 / 0 | −0,023 / 0 |

Форма. Шаблон — плоскодонное ядро (Хилл: w(0) = 2,5 U_h, к r = R почти линейный спад) с мягким хвостом возвратного
течения ~ρ⁻³ (−0,16 м/с на 300 м); нынешняя — колокол Гедеона с кольцом −0,69 м/с (3,17·0,217) и жёстким нулём за 2,5 радиуса
(0 за 300 м). Шаблон спадает с +2,8 до −0,4 м/с на 100 м (ζ = 0,5), то есть градиент на краю ≈ 0,03 с⁻¹.
У нынешней +3,2 → −0,66 м/с на 150 м (0,026 с⁻¹), но ядро уже в 1,7 раза.

## 4. Поток массы через уровень ζ (один термик)

| ζ | вверх, м³/с шаблон | вниз, м³/с шаблон | вверх нынешняя | вниз нынешняя | чистый нынешняя |
|---|---|---|---|---|---|
| 0,25 (t = 149 с) | 1,04·10⁵ | −1,04·10⁵ | 2,6·10⁴ | −4,0·10⁴ | **−1,4·10⁴** |
| 0,50 (t = 369 с) | 1,93·10⁵ | −1,93·10⁵ | 3,6·10⁴ | −5,6·10⁴ | **−2,0·10⁴** |
| 0,75 (t = 622 с) | 2,91·10⁵ | −2,91·10⁵ | 4,1·10⁴ | −6,3·10⁴ | **−2,2·10⁴** |

Шаблон замкнут: интеграл по кругу r ≤ 30 км вверх и вниз совпадают до 0,02 % (небаланс — обрезание хвоста). Возвратный
поток на ζ = 0,5: 50 % в r ≤ 450 м, 90 % в r ≤ 1,3 км (при r_up99 = 160 м) — **возврат лежит в зоне соседей** (шаг решётки
516 м), поэтому у шаблона он совместно используется ближайшими термиками. Интеграл по жизни через ζ = 0,5: вверх 1,77·10⁸ м³
(в среднем 6,7·10⁴ м³/с за 2645 с).

Нынешний профиль не замыкает массу вообще, и не в ту сторону, которую можно было ждать: кольцо ×1,6 больше подъёма (Гедеон
интегрируется в 0, ×1,6 ⇒ чистый поток отрицательный), на каждом уровне чистый поток ≈ −0,55 от вверх — воздух уходит вниз
без источника. Поток вверх — 3,6·10⁴ м³/с против 1,9·10⁵ у шаблона (в 5,4 раза слабее).

Оценка баланса при n_A одновременно живых термиков на м²: шаблон 4,34·10⁻⁶·6,7·10⁴ = 0,29 м/с = 0,11 w*; нынешняя
4,34·10⁻⁶·3,6·10⁴ = 0,16 м/с = 0,06 w*. Ориентир: доля 0,3–0,4 · ŵ 0,45 w* = 0,13–0,18 w* средним подъёмом по
площади (оценка, перемножение двух чисел L&S). Шаблон ближе (0,11), чем нынешняя (0,06), но n_A «живых» ядер Аллена и
«живых» пузырей — не одно и то же (оценка грубая).

## 5. Несколько термиков

Раскладка: 6 источников на шестиугольной решётке с плотностью n_A (шаг ближайших 516 м; сторона квадрата 1/√n_A = 480 м),
возрасты (i+0,5)/6 · 2645 с (225…2425 с), перестановка по узлам seed 0, момент «все живы» T = 2645 с.
Старшие термики к T уже у крышки (голова 1130–1145 м, U ≈ 0, шлейф погас): в поле остаётся вихрь U_h 0,06–0,6 м/с.

**Линейность и взаимодействие.** Сумма линейна по построению (2·10⁻¹⁶), обратной связи нет: сосед не меняет траекторию,
подпитку и вовлечение другого. Что получается из суперпозиции потенциальных полей:

- Приток у земли (z = 30 м, пара на 516 м, возраст 300 с): к оси первого со стороны соседа 1,71 м/с, с противоположной стороны
  1,85 м/с, изолированный 1,81 м/с — сосед меняет приток на −5 / +2 %. Приток локален (радиус максимума ≈ 85 м, спад быстрый).
- Середина между соседями на 30 м: горизонтальная скорость 0 (единичный даёт 0,24 м/с, они гасятся) — критическая точка;
  w = −0,037 против −0,019 одиночного (ровно 2×, линейно).
- Нисходящий поток между: на ζ = 0,5 в середине пары −0,10 м/с (одиночный −0,05); минимум по линии между двумя −0,17 (одиночный −0,12);
  на уровне головы пары (t = 369 с) в середине −0,46 (одиночный −0,23), минимум по линии −0,84 против −0,68.
- На всей ячейке z = 30 м (6 термиков, периодическая ячейка 3d × 2h): max |(u, v)| = 1,85 м/с (одиночный 1,79),
  медиана 0,13 м/с; **67 % площади — тихая зона \|(u, v)\| < 0,2 м/с**. Приток у земли в шаблоне — только вокруг шлейфа
  (зона радиуса порядка 100 м), между термиками его нет.
- Площадь w > 0 на ζ = 0,5 (периодическая ячейка, 120 перестановок возрастов): **0,136 [p5…p95: 0,124…0,151]**; порог w>0,02 w*: 0,118,
  0,05: 0,101, 0,1: 0,088. Нынешняя на тех же узлах: 0,129 (0,111 при пороге 0,1 w*). Метрика w>0 некорректна без порога: на
  непериодическом куске из тех же шести 0,30, большая часть — хвосты старших термиков порядка 10⁻³ м/с разных знаков.
  Средний w по ячейке ζ = 0,5: +0,009 w* (шаблон), −0,034 w* (нынешняя). Минимум w в ячейке −0,84 w* и −0,27 w*.

Доля 0,13–0,14 ниже литературной 0,3–0,4 вдвое-втрое: ядра по n_A занимают лишь часть площади подъёма; в литературе в «подъём» входит
всё w>0 термика с окружением (шаблон такого окружения не содержит).

## 7. Что это значит для TB-4 (вывод — за TB-4)

- Дивергенция и замкнутость массы — шаблон выполняет, нынешний профиль нет (чистый поток по уровню отрицателен).
- Новое для пилота относительно нынешней модели: приток к шлейфу у земли до 2 м/с на радиусе порядка 85 м, растекание у верха до 1,2 м/с, возвратное
  опускание до −2,2 м/с (0,88 w*) на краю головы (у нынешней −0,69 м/с), широкий спад возвратного течения на сотни метров.
- Против литературы шаблон «крупный и сильный» (радиус ядра ×1,3–2,2, среднее w ×1,8); нынешняя подогнана под L&S по среднему и радиусу Аллена.
  Рекомендовать подгонку α_th/b0 к L&S — нельзя без решения человека (Пикар не истина, ядро шаблона — Скорер с α 0,25, нижняя граница диапазона 0,25–0,34).

## Допущения и границы

- Все горизонтальные величины — в системе воздуха; ветер поля 3 м/с и сдвиг проверены только на бездивергентность (шаблон ветер не гнёт и не
  ослабляет; сдвиг не наклоняет шлейф).
- Приток/растекание/кольцо — потенциальные следствия формы поля; прямых измерений нет (null), LES не читали.
- «Ядро» литературы (L&S, Allen) — условная выборка по самолёту/модели; w>0 — в пределах ядра. Сравнение на уровне порядка величины.
- Радиус ядра = первая смена знака w: для шаблона это почти радиус головы R (Хилл положителен до r ≈ R); для литературы — радиус по L&S/Allen. Определения не идентичны физически.
- Периодическая ячейка (3×3 образа) — идеализация; куски шести без периодичности дают другую площадь (0,30 против 0,14 по w>0).
- Возрасты (i+0,5)/6 жизни — равномерно на длительности; в игре возраст распределён иначе (рождения с пуассоновским потоком).
- Скан по времени 15 с (30 с в чувствительности); max по сетке ρ с шагом 2,5 м у оси.
