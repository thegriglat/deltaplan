# TB-10: жизнь термика игры и подъём головы

Воспроизвести: `tools/research/thermal_bubble/py tools/research/thermal_bubble/round3/life.py` (≈ 1,5 мин; `--check` — опорное число),
результат `out/round3_life.json`, рисунок `round3/life_rise.png`. `bubble.py` не правился (варианты Аллена — подмена констант на время расчёта).
Условия: z_i = 1400 м, w0 = 2,5 м/с (w* = 2,016 м/с, t* = z_i/w* = 694 с), τ = 690 с. Подъём считается по **верху головы** z_c + R = 0,9 z_i.

## Что задаёт подъём в модели
Цепочка: F0 → шлейф w_p ∝ F0^⅓ → фронт 0,6 w_p (Turner 1962) → U головы при отрыве (непрерывность) → далее Скорер: U(z+z_h) = K.
1. **F0 в `from_strength` берётся из условия max w на оси = w0.** Максимум оси приходится на центр головы в начале (t ≈ 130 с, z ≈ 170 м: 2,50 м/с), а у Хилла w в центре = 2,5·U_h. Поэтому U ≈ w0/2,5 = 1 м/с в начале: **0,46 w***, F0 = 204 (из потока было бы 501).
2. Свободный подъём после отрыва почти не тормозит: d = z_c + z_h ≈ 2,7 км (z_h = 1,81 z_i, α = 0,0256), U падает 0,93 → 0,74 (при τ) → 0,63 м/с (1169 м): **0,46 → 0,31 w***.
3. Нечувствительны: τ = 420 / 690 / 960 с → 1473 / 1473 / 1469 с (голова по фронту шлейфа, τ только переключает режим); α Аллена (0,033) → 1433 с (−3 %).

## Литература о подъёме термиков через слой
| источник | число | что значит здесь |
|---|---|---|
| Lenschow & Stephens 1980, BLM 19:509 | средний подъём ŵ ≤ 0,45 w*; ядра 1–2 w* (по пересказу, low) | скорость воздуха в термике; термик как целое — не быстрее воздуха внутри |
| Ansmann, Fruntke & Engelmann 2010, ACP 10:7845 | средний подъём в апдрафтах 0,40–0,45 w* (аннотация) | то же, независимое подтверждение |
| Schmidt & Schumann 1989, JFM 200:511 | композит сильных событий: пик 2,0 w*; пузыри внутри апдрафта быстрее среднего | верхняя рамка скорости |
| Stull 1988, гл. 4 | t* = z_i/w* — масштаб оборота вихря (из памяти, не перечитывалось) | единица времени |
| Scorer 1957; Turner 1962 | U(z+z_h) = K; фронт 0,6 w_p | закон самой модели |
Прямого измеренного **времени подъёма термика через слой** найти не удалось (скорость вершины не нормирована в w*, см. `literature.md`; Young 1988 — AMS 403). Поэтому ориентир — время при заданной скорости воздуха (z_i = 1400, w* = 2,016):

| скорость | время до 0,9 z_i |
|---|---|
| 0,45 w* (среднее) | 1389 с |
| 0,63 w* (то, что надо для 990 с) | 992 с |
| 1,0 w* | 625 с |
| ŵ_LS(z) до 0,5 z_i / 0,8 z_i | 885 / 1836 с (ŵ → 0 при 0,91 z_i) |

Вывод: подъём 1473 с — это скорость ≈ 0,43 w* (среднее по пути), **нижняя граница среднего подъёма**, а не ошибка; жизнь игры 990 с соответствует 0,63 w* — между средним и ядром. Расхождение — выбор скорости головы, не число из литературы.

## Почему поток
**F0 брать из бюджета плавучести (`from_game`), а не из пика w0.** Это не подгонка под 990 с: поток 0,371·Φ — вывод из литературы (Deardorff 1970; Allen 2006; доля ядер, README v3), и он сам даёт 1089 с (+10 % к жизни игры; остаток внутри разброса, F0^⅓ ⇒ 0,371 → 0,3 даст ещё ≈ +8 % по времени). Центр головы при этом 2,5U = 3,1 м/с = 1,55 w* — внутри ядер 1–2 w*, т.е. сам пик w0 = 1,24 w* игры оказывается слабее измеренного ядра.

## Рекомендация
1. В TB-15: F0 из `from_game` (или w0 = 1,5–1,6 w*), не `from_strength(w0 = 1,24 w*)`; пик на оси игры вырастает на 25 % (3,1 против 2,5 м/с) — проверить против w_conv и K̄ (TB-12/15), доля ядра 0,371 — low.
2. Оборвать пузырь на жизни клетки игры (огибающая уже это делает) — растекание под крышкой на высоких столбах остаётся вне игры; при 1089 с и 990 с голова на 0,84 z_i, т.е. почти у верха.
3. Менять жизнь клеток игры (удлинять до 1480 с) не нужно и не рекомендуется (сверенные циклы клеток и облаков).

## Допущения и границы
- Время подъёма по верху головы; ориентиры литературы — подъём с постоянной/ŵ скоростью воздуха, не измеренное время подъёма термика (его нет).
- 990 с — по docs §5.1 (огибающая игры); середины ThermalCfg grow+mature+decay дают 915 с.
- Литературная надёжность: числа L&S, Ansmann, S&S — из аннотаций и пересказов (оригиналы AMS закрыты); Stull — из памяти.
- Один тип сцены (z_i 1400, ветер 0, w0 2,5); Скорер вне лабораторного α — как в v3.

Источники: Lenschow & Stephens 1980; Ansmann 2010; Schmidt & Schumann 1989; Scorer 1957; Turner 1962; Stull 1988; Allen 2006; Deardorff 1970 (подробнее — `literature.md`). Данных нет, только числа из публикаций.
