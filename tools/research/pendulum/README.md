# Оценки для модуля pendulum

Воспроизведение: `python3 tools/research/pendulum/estimates.py` → `estimates.json` и таблица в stdout. Входы — `configs/wings/sport.json`, `configs/pilot.json`, `configs/flight.json`.

Что считается:
1. Полюса разомкнутой модели Hiway Demon (Abouheaf, Gueaieb, Lewis, arXiv:2108.02393, табл. 1–2; модель Cook & Spottiswoode 2006; dt 0,01 с) → непрерывные ωn, ζ, периоды.
2. Маятник пилота: точечная масса на 1,137/1,211 м, физический маятник, связанная система с лёгким свободным крылом.
3. Инерция крыла «спорт» по трубам (`flight.json → ground_bank.span_mass_fraction`) и присоединённой массе воздуха.
4. `Cm_alpha` по двум точкам балансировки (трим, полный добор), момент веса пилота при полном ходе трапеции, статическая сила на штанге.
5. Короткий период (крыло отдельно / пилот жёстко), фугоида Ланчестера.
6. ω·dt для 60/120/240 Гц: маятник, руки-пружина, стропа как пружина.
7. Крен: момент веса при полном смещении, L_p при Cl_p = −0,45, постоянная времени крена.

Источники — таблица «Литература и числа» в `docs/plan/pendulum.md`. PDF статей не хранятся. Лицензии: статьи ICAS — открытый доступ архива ICAS (цитирование); NASA TM-81269 — public domain; arXiv:2108.02393 — лицензия arXiv (цитирование чисел).
