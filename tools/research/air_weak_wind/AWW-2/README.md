# AWW-2. Механизм F: перенос теплосодержания θ′·h

## Что сделано
- Правка 1 из `tools/research/air_weak_wind/AWW-1/README.md` («Предложение правок») — патч `AWW-1/proto_theta_h.patch`
  применён как есть: в марше θ′ слоя перемешивания (`K_THETA`, `AirPhaseCpu.theta`) на входе клетки
  θ′_in = E_up / max(h, h_up), E_up — билинейная интерполяция θ′·h вверх по ветру, h_up — интерполяция h. Новых параметров нет.
  Физика — slab-модель слоя перемешивания (Stull 1988 §11.3; Garratt 1992 §6.1): растущий слой разбавляет тепло, тонеющий
  сохраняет θ′ (избыток — остаточный слой, не моделируется), при постоянном h — прежняя формула.
- Тест `test_air_phase.gd::test_f_heat_content` (из `AWW-1/tw/tw3_code.diff`): море h 50 м, поток −0,05 К·м/с → суша h 1500 м:
  θ′ моря −0,717 К, Δθ′ суши у берега 0,0233 К = θ′_моря·h_моря/h_суши·e^{−Δt/τ} (без правки было бы ≈ −0,7 К); суша → море —
  θ′ не раздувается; однородная поверхность — прежняя формула до 1e-6. Сверка GPU = CPU — `test_air_phase_gpu.gd`
  (`tools/gpu_tests.sh --filter=test_air_phase`: 11 тестов, 0 упало).

Ожидание по AWW-1 подтверждено: «Термики» 0,44 → 1,27 с 101° → 187°, landing_hill +6 %, прочие ≤ 0,003 м/с.
Неожиданно сдвинулось — ничего. Вне островов (горы без моря) h_bl меняется вдоль ветра по рельефу, поэтому θ′ слабого дня
сдвигается на тысячные кельвина — физично, ветер почти не меняется. В Онгудае точечный w на 10 м меняется на −0,13 м/с:
старт на краю термика (ось в 196 м, радиус 143 м), снос на 0,7° иной — сэмпл попадает в другую часть края; прогон
детерминирован (повтор дважды — те же числа, `out/rep`).

## Границы
- Остаток «Термики» 1,27 против 2 м/с меню — торможение у земли на середине наветренного склона (AWW-1 «Диагноз 1»),
  в `docs/guide/air-model/limits.md`. Заморозка области «сильным D» по N над z_i не тронута (правка 2 не применялась).
- Пробник поднимает предел времени расчёта `air_model.timeout_s` 60 → 1200 с: GPU общий с соседними пачками, при 60 с
  расчёт падал в аналитику. На результат расчёта не влияет.
- Запечённые поля `data/locations/*/air` не перепечены — `model_hash` меняется, перепечка отдельной задачей.
