# LT-5: вывод

Модель слоя смешения за гребнем (36 констант, все с id LTL, выводом или явным допущением) + прототип на 18 разрезах Онгудая.

1. Слой: δ_ω = 0,30H + 0,17λx (после 0,64·x_r вдвое медленнее), σ_u,v,w = 0,166/0,130/0,153·ΔU, гаусс σ_y = 0,49δ_ω вокруг прямой гребень — присоединение, нарастание и затухание по x_r, l ≤ 0,109δ_ω, L = 0,48δ_ω.
2. Онгудай (strong, 6 гребней): провал σ_w за гребнем исчезает (30 м над землёй, x/H 4: ×1,7…×3,4), максимум избытка над притоком — x/H 2–2,3 на 30–50 м (c400 — там, где прежняя модель следа не видела). Абсолютный максимум у гребня (25–60 м над землёй, 1,5–3,3 м/с) — стенка, слой её не трогает.
3. Не подгонялось, но: форма холма — вдвое слабее эксперимента; поле даёт U1 и слабый след; критерий присутствия и x_r = 3,5H — допущения; сверки с натурой (LTO) нет.
