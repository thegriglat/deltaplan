# 2б. Симметричный хребет, оба склона прогреты, штиль (проверка симметрии)

Сетка 128×64 клеток по 50 м (воздушных 7952), давление: mg × 2 на шаг, устройство gpu, float32.

## Числа (установившееся состояние)

| Величина | Значение |
|---|---|
| Максимальный подъём | 2.08 м/с на x = 3.23 км, 525 м над землёй (1025 м над подножием) |
| Приток у подножия крутого (левого) склона, нижние ~100 м | +0.48 м/с (+ — к склону) |
| Приток у подножия пологого (правого) склона | +0.48 м/с (+ — к склону) |
| Ветер вверх по склону (середина, нижняя клетка) лев./прав. | +0.65 / +0.65 м/с |
| Опускание в долине слева (200 м над землёй … 2 км): мин / среднее | -0.19 / -0.079 м/с |
| Над пологим склоном и за ним: мин / среднее | -0.53 / -0.077 м/с |
| Высота подъёма (w > 20 % макс.) | 1600 м над подножием |
| Верх прогретого воздуха (θ′ > 0,1 К) | 1550 м над подножием |
| Наклон столба подъёма dx/dz | -0.31 |
| Установление | 6302 шагов, dt = 2.19 с, 230 мин модельного времени |
| Время счёта до установления | 3.40 с (всего 3.55 с, 0.539 мс/шаг) |
| Память GPU (пул) | 5.6 МБ |
| Невязка массы / тепла | 1.6e-11 / -2.0e-05; макс. |m−1| 1.8e-08 |

## Условия приёмки

- **1. сохранение массы/тепла ≤ 0,1 %** — да: невязка массы 1.6e-11 от массы области, тепла -2.0e-05 от нагрева; макс. |m−1| в клетке 1.8e-08
- **3. симметричный хребет → симметричная картина, подъём над гребнем** — да: макс. |w(x) − w(зеркально)| = 6.0e-06 м/с при макс. подъёме 2.08 м/с на x=3.225 км (гребень 3,200); приток у подножий +0.48 / +0.48 м/с
- **6. устойчивость, установление** — да: установилось за 6302 шагов (dt=2.19 с, 230 мин модельного времени) за 3.4 с счёта
