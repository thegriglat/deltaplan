# 3. Оба склона прогреты, фоновый ветер 3 м/с слева направо

Сетка 192×64 клеток по 50 м (воздушных 11888), давление: mg × 2 на шаг, устройство gpu, float32.

## Числа (установившееся состояние)

| Величина | Значение |
|---|---|
| Максимальный подъём | 1.40 м/с на x = 2.27 км, 75 м над землёй (375 м над подножием) |
| Приток у подножия крутого (левого) склона, нижние ~100 м | +1.41 м/с (+ — к склону) |
| Приток у подножия пологого (правого) склона | -1.63 м/с (+ — к склону) |
| Ветер вверх по склону (середина, нижняя клетка) лев./прав. | +1.53 / -2.09 м/с |
| Опускание в долине слева (200 м над землёй … 2 км): мин / среднее | -0.10 / +0.233 м/с |
| Над пологим склоном и за ним: мин / среднее | -1.10 / -0.039 м/с |
| Высота подъёма (w > 20 % макс.) | 2650 м над подножием |
| Верх прогретого воздуха (θ′ > 0,1 К) | 2700 м над подножием |
| Наклон столба подъёма dx/dz | +0.46 |
| Установление | 5480 шагов, dt = 2.19 с, 200 мин модельного времени |
| Время счёта до установления | 3.07 с (всего 3.38 с, 0.560 мс/шаг) |
| Память GPU (пул) | 9.3 МБ |
| Невязка массы / тепла | 3.8e-12 / -2.8e-05; макс. |m−1| 1.3e-07 |

## Условия приёмки

- **1. сохранение массы/тепла ≤ 0,1 %** — да: невязка массы 3.8e-12 от массы области, тепла -2.8e-05 от нагрева; макс. |m−1| в клетке 1.3e-07
- **5. подъём наклонён по ветру, картина не разваливается** — да: тепловая часть (с нагревом − без): наклон столба подъёма dx/dz = +0.46 (>0 — по ветру), макс. добавка подъёма 0.35 м/с на x=2.12 км, 125 м над землёй; полное поле: макс. w 1.40 м/с, поле гладкое, без пилы
- **6. устойчивость, установление** — да: установилось за 5480 шагов (dt=2.19 с, 200 мин модельного времени) за 3.1 с счёта
