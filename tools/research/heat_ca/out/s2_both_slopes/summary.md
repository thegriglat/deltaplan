# 2. Оба склона прогреты одинаково, штиль

Сетка 128×64 клеток по 50 м (воздушных 7792), давление: mg × 2 на шаг, устройство gpu, float32.

## Числа (установившееся состояние)

| Величина | Значение |
|---|---|
| Максимальный подъём | 2.47 м/с на x = 3.33 км, 725 м над землёй (1175 м над подножием) |
| Приток у подножия крутого (левого) склона, нижние ~100 м | +0.48 м/с (+ — к склону) |
| Приток у подножия пологого (правого) склона | +0.44 м/с (+ — к склону) |
| Ветер вверх по склону (середина, нижняя клетка) лев./прав. | +0.65 / +0.81 м/с |
| Опускание в долине слева (200 м над землёй … 2 км): мин / среднее | -0.20 / -0.102 м/с |
| Над пологим склоном и за ним: мин / среднее | -0.75 / -0.126 м/с |
| Высота подъёма (w > 20 % макс.) | 1800 м над подножием |
| Верх прогретого воздуха (θ′ > 0,1 К) | 1700 м над подножием |
| Наклон столба подъёма dx/dz | +1.03 |
| Установление | 6302 шагов, dt = 2.19 с, 230 мин модельного времени |
| Время счёта до установления | 3.40 с (всего 3.55 с, 0.540 мс/шаг) |
| Память GPU (пул) | 4.0 МБ |
| Невязка массы / тепла | -1.3e-11 / -1.1e-05; макс. |m−1| 2.3e-08 |

## Условия приёмки

- **1. сохранение массы/тепла ≤ 0,1 %** — да: невязка массы -1.3e-11 от массы области, тепла -1.1e-05 от нагрева; макс. |m−1| в клетке 2.3e-08
- **3. схождение и подъём над гребнем** — да: макс. подъём 2.47 м/с на x=3.33 км (гребень 2,80); приток у подножий слева +0.48, справа +0.44 м/с; вверх по склонам +0.65 / +0.81 м/с
- **6. устойчивость, установление** — да: установилось за 6302 шагов (dt=2.19 с, 230 мин модельного времени) за 3.4 с счёта
