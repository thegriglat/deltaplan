# 1. Солнце на крутой склон, второй в тени, штиль

Сетка 128×64 клеток по 50 м (воздушных 7792), давление: mg × 2 на шаг, устройство gpu, float32.

## Числа (установившееся состояние)

| Величина | Значение |
|---|---|
| Максимальный подъём | 1.65 м/с на x = 2.48 км, 475 м над землёй (875 м над подножием) |
| Приток у подножия крутого (левого) склона, нижние ~100 м | +0.49 м/с (+ — к склону) |
| Приток у подножия пологого (правого) склона | +0.37 м/с (+ — к склону) |
| Ветер вверх по склону (середина, нижняя клетка) лев./прав. | +0.53 / +0.18 м/с |
| Опускание в долине слева (200 м над землёй … 2 км): мин / среднее | -0.23 / -0.075 м/с |
| Над пологим склоном и за ним: мин / среднее | -0.17 / -0.024 м/с |
| Высота подъёма (w > 20 % макс.) | 1400 м над подножием |
| Верх прогретого воздуха (θ′ > 0,1 К) | 1400 м над подножием |
| Наклон столба подъёма dx/dz | +0.20 |
| Установление | 5754 шагов, dt = 2.19 с, 210 мин модельного времени |
| Время счёта до установления | 3.11 с (всего 3.41 с, 0.541 мс/шаг) |
| Память GPU (пул) | 2.3 МБ |
| Невязка массы / тепла | 5.5e-12 / -1.5e-05; макс. |m−1| 1.9e-08 |

## Условия приёмки

- **1. сохранение массы/тепла ≤ 0,1 %** — да: невязка массы 5.5e-12 от массы области, тепла -1.5e-05 от нагрева; макс. |m−1| в клетке 1.9e-08
- **2. подъём над прогретым склоном, приток у подножия, опускание в долине/над тенью** — да: макс. подъём 1.65 м/с на x=2.48 км; приток у подножия +0.49 м/с (к склону +), вверх по склону +0.53 м/с; средняя w в долине -0.075, над тенью -0.024 м/с
- **6. устойчивость, установление** — да: установилось за 5754 шагов (dt=2.19 с, 210 мин модельного времени) за 3.1 с счёта
