# Опыт 2: установившееся без шагов (Пикар + прогонки/многосеточный)

Команды — `README.md`. Таблицы — `out/tables.md`, `out/results.json`; поля — `out/runs/*.npz`, `out/truth/*.npz`.

## Схема

Итерация Пикара — один CUDA Graph:
1. Импульс Озеена: полулагранжев оператор автомата как 9-точечный шаблон при замороженном ветре, вязкость, плавучесть, губка, псевдошаг 120 с, «зебра»-прогонки. Плавучесть полунеявная (0,3·dθ̄/dz).
2. Проекция SIMPLEC: ∇·(K∇φ) = ∇·u*, 1 V-цикл, сглаживание прогонками. Анизотропия в инверсии до ×20, поточечный Гаусс–Зейдель на ней расходился.
3. Тепло: псевдошаг 1200 с, 8 пар прогонок.

Детали:
- прогонка — циклическая редукция блоком на линию;
- параметры одни на все 16 случаев, подгонки нет;
- остановка — невязка, измеренная шагом самого автомата: < 3,3·10⁻⁶ м/с² и 5·10⁻⁶ К/с.

## Точность

Автомат, запущенный из решения Пикара, за 2 ч уходит не больше чем на 10⁻⁴. От 8 ч шагами решение отличается на 0,02–0,5 % по u, w и ~1,2 % по θ′ (недосчёт самих 8 ч).

| 100 м | 0,081 / 1,31 | 0,085 / 1,52 | 0,23 / 0,88 | 0,10 / 1,19 |
| 50 м | 0,107 / 3,01 | 0,163 / 4,49 | 0,33 / 2,96 | 0,10 / 2,73 |
| 25 м | 0,279 / 9,94 | 0,357 / 13,0 | 1,09 / 10,0 | 0,30 / 4,14 |

- Выигрыш в штиль ×5…×36, с ветром ×2…×9.
- До 1 % по w: ×10…×57 в штиль, ×4…×13 с ветром.
- Итерация стоит 0,6–1,2 мс ≈ 1,5–2 шага автомата.

Ключевые числа на 50 м совпадают с эталоном и с прогоном 8 ч:
- s1: подъём 1,67 / 1,65 / 1,67 м/с, приток 0,49, высота 1450 / 1400 / 1450 м;
- s4: выше инверсии |w| = 0,027 м/с у всех трёх.

## Физика

- масса ∇·u = 0 точно, нелокальное давление;
- импульс полный: перенос, вязкость, прилипание, плавучесть, давление;
- тепло консервативно;
- нет влаги, сжимаемости, излучения, вращения Земли, суточного хода, разрешённой турбулентности.

Граница применимости — сама установившаяся постановка: средняя циркуляция при перемешанном воздухе, без пузырей и облаков со скрытым теплом. При малой вязкости стационарности нет.

Как единая модель «воздуха»:
- ветер у рельефа, источники термиков, инверсия — да;
- база облаков — после добавления влаги (ещё один скаляр);
- грозы — только диагностика.

Что не вышло: чистый Пикар с явной плавучестью раскачивается; θ̄·∇·u давал ложный нагрев; поточечный Гаусс–Зейдель расходился на анизотропии. Замыкание Дарси из предварительного захода отброшено.

## Вердикт

«Поле на час» считать Пикаром, шаги по времени — только для переходов между часами, стартуя из решения Пикара.
