# Опыт 2: установившееся без шагов по времени — итерации Пикара + прогонки/многосеточный

Прототип клеточного автомата тепла и массы (`../README.md`) доходит до установившейся картины
шагами по времени: ~3–7 ч модели, 1–26 тыс. шагов. Здесь то же установившееся состояние ищется
**напрямую**: заморозили ветер → решили линейные уравнения импульса+давления и тепла → обновили
ветер → повторили (итерации Пикара). Итог и числа — `summary.md` (текст отчёта опыта) и `out/tables.md`.

База (`../model.py` и др.) не тронута; нужные файлы скопированы сюда (`model.py`, `plots.py` —
копии без изменений).

## Файлы

- `picard.py` — решатель (класс `Picard`): стационарные уравнения автомата в ТОЙ ЖЕ дискретизации,
  внешние итерации Пикара с псевдошагом, прогонки циклической редукцией (CUDA RawKernel),
  многосеточный Пуассон со сглаживанием прогонками, вся итерация — один CUDA Graph;
- `study.py` — опыт: Пикар против шагов по времени, 4 сценария × 200/100/50/25 м → `out/results.json`,
  `out/runs/*.npz`;
- `report.py` — картинки и таблицы → `out/fig_*.png`, `out/tables.md`;
- `truth.py` — автомат, досчитанный с критерием в 10 раз строже (до 12 ч) → `out/truth/*.npz`
  (использовался при отладке, чтобы отделить «ошибку схемы» от недосчитанности эталона).

## Как воспроизвести

```bash
cd tools/research/heat_ca/exp2_picard
# «строгий» автомат (≈ 3 мин GPU):
../.venv/bin/python truth.py                       # → out/truth/*.npz, out/truth.log
# основной опыт (замеры времени — под общим замком GPU, ≈ 5–10 мин):
flock /tmp/heat_ca_gpu.lock ../.venv/bin/python study.py run          # → out/results.json, out/runs/
#   только часть: study.py run s1_sun_one_slope s4_inversion --cells 50,25
../.venv/bin/python report.py                      # → out/fig_*.png, out/tables.md
```

Картинки (все строит `report.py` из `out/results.json` и `out/runs/*.npz`):
- `out/fig_convergence.png` — ошибка w (отн. L2 от точной неподвижной точки) против времени GPU:
  Пикар (сплошные) и шаги по времени (штрих), 4 сценария × 4 клетки;
- `out/fig_outer.png` — сходимость внешних итераций (невязка = насколько один шаг автомата сдвигает решение);
- `out/fig_compare_<сценарий>.png` — 50 м: эталон | Пикар | разность для w, u, θ′;
- `out/fig_flow_picard_<сценарий>.png` — стрелки ветра по решению Пикара (как `flow.png` базы).

Параметры решателя (одинаковы для всех сценариев и клеток, `Picard.__init__`): псевдошаг импульса
Δτ_u = 120 с, тепла Δτ_θ = 1200 с, за итерацию — 8 пар прогонок тепла (строки+столбцы), 2 пары
для u и w, 1 V-цикл давления; полунеявная плавучесть с множителем 0,3; остановка — когда шаг
автомата сдвигает решение медленнее 3,3·10⁻⁶ м/с² и 5·10⁻⁶ К/с (в 10 раз строже критерия эталона
0,02 м/с и 0,03 К за 10 мин), проверка раз в 10 итераций.

Только GPU (CuPy, CUDA). В игре это были бы вычислительные шейдеры Vulkan: всё, что здесь есть —
поэлементные ядра, прогонки по линиям (блок на линию, разделяемая память) и V-цикл, — переносимо.
