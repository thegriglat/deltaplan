# Опыты 1, 3, 6: линейность, ядра, «ядро струи»

Команды для каждой картинки — `README.md`. Выходы — в `out/`, сырые поля — в `out/cache/*.npz`.

Прогоны автомата здесь идут 8 ч без досрочной остановки. Эталоны `out/refs` отличаются от 8 ч на 4–5 % по u и w и на 9–15 % по θ′; s4 на 25 м — до 27 %.

## Опыт 1. Линейность

s1, 50 м; A — нижняя половина солнечного склона, B — верхняя.

| Нагрев, Вт/м² | Подъём A+B, м/с | Ошибка суперпозиции w | u | θ′ |
|---|---|---|---|---|
| 15 | 0,04 | 4,7 % | 3,3 % | 1,7 % |
| 60 | 0,16 | 18,6 % | 11,4 % | 4,1 % |
| 250 | 1,12 | 69,4 % | 40,3 % | 12,4 % |
| 600 | 2,48 | 87,2 % | 76,1 % | 20,7 % |

- Линеен только режим «сантиметров в секунду».
- A и B сливаются в один столб.
- θ′ почти линеен: количество тепла задаёт закон сохранения.
- Картинки: `exp1_linearity_map.png`, `exp1_linearity_vs_strength.png`.

## Опыт 3. Ядра

Один столбец 250 Вт/м², 50 м, 8 ч.

| Источник | Пик w, см/с | w < 5 % дальше | w < 1 % дальше |
|---|---|---|---|
| равнина | 10,2 | 1,95 км | 3,85 км |
| середина склона | 11,0 | 2,20 км | 2,45 км |
| у гребня | 10,8 | 1,20 км | 3,70 км |

- θ′ спадает ниже 1 % только за 3,75–5,7 км, то есть ядро θ′ практически глобальное.
- Ядро зависит от места.

Сборка s1 из ядер (100 м, 64 столбца):
- сумма точных ядер: ошибка u / w / θ′ = 0,77 / 0,86 / 0,25, подъём 0,48 м/с против 1,45;
- три ядра: 0,79 / 0,87 / 0,31, подъём 0,41 м/с;
- цена 0,033 мс.
- Картинки: `exp3_kernels.png`, `exp3_kernel_decay.png`, `exp3_kernel_reconstruction*.png`.

## Опыт 6. «Ядро струи»

`jet.py`. Цепочка проходов:
1. Размытие карты нагрева даёт основание струи (L = 700 м, a = 250 м).
2. Тёплый бассейн по закону сохранения ∬θ′ = τ∫q; форма — частично перемешанный слой с β = 0,45.
3. Струя — уравнения плавучей струи. Ширина σ² = σ0² + 2Kt без подгонки совпала с эталоном (~390 м). Выше бассейна адиабата, снос по ветру U/w.
4. Склоновый ветер — решение Прандтля.
5. Горная волна — линейная, через Фурье.
6. Неразрывность — многосеточная проекция (масса точно).

## Физика

- Суперпозиция и ядра — линеаризованный Буссинеск (функция Грина); годятся только при подъёме меньше ~5 см/с.
- Ядро струи:
  - масса — точно;
  - тепло — глобально;
  - импульс — только вдоль оси струи;
  - давление — только проекция, без торможения давлением.
- Годится для места и силы термиков и потолка по инверсии. Ветер у рельефа — грубо. Облака — после влаги. Грозы — только CAPE.

## Вердикт

- Одной линейной свёрткой автомат не заменить.
- «Ядро струи» — быстрая диагностика и начальное приближение для решателя.
