# TKF-1: вывод

Причина пп. 1, 2, 4 — **вид**, а не физика: `TrikeRig.refresh` ограничивает поворот `cart_basis` до 20 °/с (`CART_TURN_DEG_S`) всегда, а не только при переходе колёса↔воздух. Реальная ориентация тележки по «Маятнику» в виражах и перекладках меняется быстрее (p99 34–62 °/с, пик до 119 °/с при накачке), вид отстаёт на 55–72° (`vis_lag_deg_max`), отсюда скрутка по рысканию (до 41–67°), «тележка сквозь крыло» (mast_normal до 132°) и штанга вне дуги.
Физика (C_phys): рыскание тележки к крылу = 0 по построению (в модели нет степени свободы; реальный узел — шарнир по тангажу и крену, Gratton), мачта к нормали крыла ≤ 13,6°, штанга в пределах дуги во всех виражах и перекладках; выходит за упор «от себя» (до 14,5° против 4,95°) только при ходе штанги «от себя» и накачке по тангажу — упора подкоса в физике нет.
Правка: V1 — в воздухе без ограничения скорости, 20 °/с оставить только для сглаживания скачка колёса→воздух (8,5°). Подробно — `docs/research/trike-fix/coupling.md`.
