# VI-7: источник термика не над водой

Решение пользователя Q2 (б), 17.10: источник термика над морской/водной клеткой не ставится, общий закон для всех мест, без особых
случаев. Находка VI-5: на вулканическом острове (15 января, 12 ч, ясно, 28 °C, пассат 2 м/с с 110°) около половины термиков — с
источником над морем.

## Причина

Источники поля (`AirThermals`, уровень 400 м) отбирались по потоку Φ столбца, точка источника — лучшая по силе источника
`GroundField.sun` из нескольких точек столбца (`pick_in_column`); «вода» отсеивалась только при силе 0 у всех точек. Над морем сила не 0:

- тёплое море (вода теплее воздуха, `Terrain.set_water_heat`) — поток тепла ~23 Вт/м², сила 0,068 > 0 — класс WATER;
- открытый океан без файлов WorldCover — класс NONE, у которого поток как у суши (~245 Вт/м², сила 0,68), высота 0 м.

Кроме того, поток столбцов над водой (Φ, H) шёл в водосборы береговых источников и в нормировку плотности источников.
Термики-клетки (аналитика вне поля) выбирали точку так же — 18 над морем NONE.

## Правка (общая, без особых случаев)

- Вода в точке — `GroundField.is_water`: класс WATER (карта поверхности и маски воды места) или море по правилу `Terrain.is_sea` —
  класс NONE и высота ≤ 0,5 м. Класс — `surface_fn` атмосферы, иначе `surface_at` объекта рельефа (`height_fn` — `Terrain.height_at`);
  класса нет совсем (тестовый рельеф без карты) — воды не знаем, суша.
- Точка источника поля (`pick_in_column`) и термика-клетки (`ThermalField._spawn`) — только не на воде (вода — сила 0).
- Поток столбца источникам — только с его суши: Φ, W̄⁺ (организованная доля), H и площадь водосбора × доля суши L столбца
  (`AirThermals.land_fraction`: углы и центр столбца, у берега — 4×4 точки); столбец целиком на воде — ничей, его w_conv остаётся пилоту
  широким средним полем. Решатель поля (поток тепла H в модели воздуха, w_conv, θ) не меняется; формат состояния — тоже.
- Доля суши считается раз на сетку места (~0,5 с в рабочем потоке, кеш `GroundField.land_cache`).

Сырые прогоны — `out/` (не в git), сводка — `summary.json`.

Оговорки:
- учебный остров «до» — с запечённым полем, «после» — поле пересчитано (правка меняет `model_hash`, перепекание — VI-9), отсюда 594 → 633
  при тех же 0 над водой и той же силе;
- на вулканическом острове источников над сушей стало меньше (213 → 142): нормировка плотности (средний Φ кандидатов Φ̂) теперь только по
  суше — раньше слабые кандидаты над морем занижали Φ̂ и уплотняли источники на суше; сила термиков та же;
- вода или суша мельче клетки 400 м, не задевшая ни угла, ни центра столбца, в доле суши не видна (точку источника на ней всё равно
  отсеивает проверка точки);
- на точке в июле при 28 °C источников над водой нет и до правки (вода холоднее воздуха — H ≤ 0), поэтому взят январь.
