# FBW-1: термики вечером — сценарий пилота

Отзыв пилота (1.5.11): «поставил 7 м/c фоновый, облачно, 20:00 … термики адовые — +4 почти у самой земли».

`probe.tscn` через сцену игры (`main.tscn → _fly`): 15.10 20:00 поясного, облачно (`overcast`), ветер 7 м/с
«в старт», температура — обычный максимум месяца; контроль 15.07 13:00 ясно. Места: Онгудай (Каянча),
Аушкуль (Аушҭау восток), Алтай (Синюха запад) и два рантайм-места — кеш точки `user://locations/pt_fb1013_*`
с рельефом Онгудая, центр перенесён на 43,3° / 42,5° и 58,0° / 60,0°, пояс по долготе.

Запуск (из корня копии):
- `bash tools/research/fb1013_evening/run.sh` — headless: путь термиков «аналитика»; вход поля (H, z_i, w*)
  считается на CPU (`AirPlace.domain_case`, как `AirRuntime`). Печатает строку `ИТОГ: …` (приёмка FBW-1).
- `bash tools/research/fb1013_evening/run_gpu.sh` — окно 320×240, поле на GPU: путь, который пилот видит
  по умолчанию (`air_model.enabled = auto`).

Колонки (`probe.gd → COLS`): ψ, закат, прогрев и доля рождений погоды, H у старта (2 км, среднее/макс.),
H чистых классов (суша/застройка/вода), w*, рождений за 10 мин и живых у старта, термическая w на
20–300 м в 2 км (всё, только пузыри, «между» поля), w у земли перед стартом (0–200 м, 5–30 м) по
составляющим (среднее/склон, термики, фон, болтанка), |ветер на 6 м над стартом|/7, «город» (клетка
400 м с наибольшей долей застройки в 15 км): доля, H, w.

Данные: `out/before_*.csv` — код до починки, `out/after_*.csv` — после (`headless` / `gpu`),
`out/headless.csv` — последний прогон `run.sh`. Итоги — отчёт FBW-1 (`dp log FBW-1`).
