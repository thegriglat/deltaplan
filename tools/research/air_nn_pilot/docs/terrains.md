## Рельефы П-2 (NN-P4, NN-16, NN-P8; контракт П6 v3, `terrain_cut.py`)
~300 реальных горных квадратов 38,4 км по всей суше + отложенные горные системы (Кавказ, Пиренеи, Аппалачи — решение
пользователя 02.10; **Южные Альпы Новой Зеландии — v2, решение 03.10, Q1**: на v1 отложенные системы положе пула) **тем же путём рельефа, что у игры**: тайлы Terrarium (`configs/world.json → runtime_terrain`,
слой `detail`: z = `layer_zoom` — 12, ниже при шаге < 18 м), высота R·256 + G + B/256 − 32768, узлы — центры пикселей
web-mercator с метрическим шагом на широте центра (`_plan_layer`), без сглаживания, билинейно как `HeightLayer.sample`
на сетку 25 м 1601² → `hc400` = блочное среднее 16 × 16 (как `air3d/terrain.block_mean`). Конфиг —
`configs/terrain.yaml` (зёрна, пороги, боксы систем).

```bash
.venv/bin/python terrain_cut.py run          # все стадии (этап n из 5), продолжение — та же команда
.venv/bin/python terrain_cut.py status [--json]
.venv/bin/python tests/test_contract_terrain.py [--max N]   # контракт П6 v2 (системы и число мест — из конфига)
.venv/bin/python tests/test_terrain_cut.py                  # побитный повтор + kill -9 в fetch и cut
```

**Проверка пути рельефа.** Вырезка Онгудая и Алтая этим путём (Terrarium) против встроенных мест (Copernicus GLO-30):
`hc400` расходится на 0,7 ± 6,8 м (max 37 м) и −2,0 ± 4,0 м (max 22 м); уклон p50 0,217 против 0,219 и 0,117 против
0,117, размах 1964 против 1963 м — геопривязка и оси верны. Оценка уклона по z8 против точной 400 м на 4 местах пробы —
0,96…1,00 (`slope_est_scale` = 1); размах z8 выше hc400 на ~2 % (медиана по 345 местам 0,98), поэтому предел оценки
3100 м, точный фильтр — 3000 м по hc400 (не прошло ни одно место по размаху, 11 — по морю). Слой выбора по z8 совпал со
слоем по точному уклону у 269 из 300 мест пула; метка `stratum` в индексе — по точному уклону.

**Итог (02.10)**: 345 мест — пул 300, отложено 45 (по 15). Уклон p50 пула: p5/p50/p95 = 0,017/0,213/0,446, max 0,497;
≥ 0,4 — 44 места (в т. ч. 1 отложенное), ≥ 0,22 в пуле — 147; размах ≥ 2000 м — 135, max 2984 м. Онгудай: 0,219 / 1963 м,
процедурные: медиана 0,016 / 719 м. Крутых мест (p50 ≥ 0,4) при размахе ≤ 3000 м на суше мало (72 кандидата сетки):
их слой — в основном Береговые горы Британской Колумбии (18), Кордильеры, Новая Зеландия, Альпы, Патагония.
Сырьё 1,9 ГБ (`pilot/raw/terrarium`), вырезки 2,8 ГБ (`pilot/tiles/v1`), рабочее 0,4 ГБ (`pilot/tmp/terrain_v1`).
Копия картинок, `index.csv`, `manifest.json`, `times.json` — `figures/p2_terrain/`.

**Для загрузчика `t_*` (NN-P6):** `h` — float32; для побитного `hc400` = `T.block_mean(h, …)` (и `R.grid_domain`)
приводить `h` к float64 в `places.location` (`hc400` посчитан из `h.astype(float64)` тем же reshape-mean — совпадение
точное, 0 м). Сетка: x0 = y0 = −20 000, шаг 25, оси [j — север, i — восток]. Вырезки читать только при
`manifest.json → complete = true`; соответствие `t_*` → кандидат сетки — `tiles/v1/sources.json`.

**Границы.** Terrarium — смесь источников (SRTM 30–90 м, GMTED, ETOPO1 над морем; на z12 ≈ 20–38 м — передискретизация),
как в игре. Квадраты метрические в проекции на широте центра (как игра; искажение масштаба на 40 км < 1 %). Вода —
только порог `sea_frac` (узлы ≤ 0,5 м, вкл. впадины ниже уровня моря); озёра в горах — как суша. Высоты мест до 5,5 км
над морем (Тибет, h_mean p95 4,4 км) — применимость решателя на такой высоте (плотность, профиль притока) — вопрос
координатору. Боксы систем грубые (для доли и отложенных частей), не границы хребтов. Тест прерывания берёт тайлы через
`file://` из основного сырья (без сети); сетевой путь проверен самим прогоном (повторы, продолжение).
Данные: AWS Terrain Tiles, атрибуция — https://github.com/tilezen/joerd/blob/master/docs/attribution.md (`ASSETS.md`).
