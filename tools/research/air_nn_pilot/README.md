# Пилот air-nn (этап П): может ли малая сеть заменить решатель поля ветра

План — `docs/archive/rejected/air-nn.md` (§8.2, шлюз ШП; правила §3.2–3.4, §4.4–4.6, §5), контракты — `docs/archive/rejected/air-nn-contracts.md`
(П1 — образец набора, П2 — вход/выход сети, П3 — отчёт). Вопрос пилота: по карте рельефа и числам погоды малая сеть
(U-Net + FiLM, область 96 × 96 по 400 м) выдаёт поле эталонного решателя AM-01 «как игра» с полезной точностью — в том
числе на незнакомом рельефе?

Сеть удалена из игры в AP-21 и заменена фазовой сборкой ветра (`tools/research/air_phase/`); исследование сохранено как материал для статьи. Вывод — `docs/registry/findings.md`, раздел «air-nn».

## Границы
Эталон — решатель AM-01 «как игра» (400 м, 1-й порядок, июль, широта Онгудая), не измерения: пилот меряет, как сеть
сжимает решатель. U10 набора 0–8 м/с; другие сезоны/широты, вода и покров — не проверялись. Точки оценки — центры окон
плана, не только официальные старты. Данные в git — только свои числа (`ref/`, `tests/out/`); рельеф мест — Copernicus
DEM GLO-30 (атрибуция — `ASSETS.md`), в репозиторий из пилота не копируется.
