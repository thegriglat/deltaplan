# P3E8: обучение только на уверенно сошедшихся

**Гипотеза.** Цель для несошедшихся решений (среднее поздних состояний) шумная и мешает сети; без неё сеть лучше.

**Признаки сходимости в метаданных случая (П1).** `runs.d400_h/d400_m.status` (`ok` — критерий решателя выполнен, цель —
конечное состояние; `max` — предел итераций: у terrain цель — среднее снимков с 500-й итерации, у main — последнее
состояние), `iters` (предел 1000 у terrain, 3000 у main), у `max` terrain — `late_spread60_p90` (p90 разброса ветра на 60 м
между поздними снимками: медиана 0,42, p75 0,67, p90 1,08 м/с при ветре порядка 0,3–2 м/с — цель действительно шумная).
Невязки и истории в метаданных нет: критерий внутри решателя; «без колебаний в конце» проверить нечем.

**Правило «уверенно».** Оба решения (с нагревом и без) имеют статус `ok` и `iters ≤ 0,3 · max_outer` (terrain ≤ 300, main
≤ 900) — `pilotnn.data.confident`. Порог по распределению iters у `ok` (`out/p3e8/conv_stats.md`): медиана 61–121,
p95 171–376, p99 521–1208; 30 % предела отрезает хвост у предела (у terrain ≈ 5–10 % «ok»-решений, у main 2–7 %),
которые мало отличимы от `max`. Порог мягкий: различия между 0,2…1,0 предела — 8 п.п. случаев (77…85 %), основное
сокращение даёт сам статус `ok`.

**Сколько остаётся.** Обучение 2083 → 1686 (81 %), проверка 317 → 263 (83 %), отложенные системы 720 → 540 (75 %).
Рельефов в обучении 143 → 143 (все остаются; доля уверенных на рельеф: p10 0,55, медиана 0,82, минимум 0,17), в проверке 119 → 106.
По ветру U10: <1 м/с — 169/362 (47 %), 1–2 — 145/298 (49 %), 2–3 — 236/303 (78 %), 3–5 — 97 %, 5–8 — 98 %. Слабый ветер
не выпадает целиком, но остаётся около половины; по часам доля ровная (79–86 %).

**Опыт.** Задача — копия задачи P3E0 (v0_ctrl): архитектура, гиперпараметры, зерно 2, 100 рельефов, статистики нормировки по
обучению; списки обучения и проверки отфильтрованы тем же правилом. Эпох 150 (предел; у P3E0 остановка на 143) — лучшая
проверка на 120-й. Оценка: в `evaluate` добавлена группа `conf` (уверенно сошедшиеся — случай целиком); P3E0 и P3E1 пересчитаны
своими весами новым кодом (числа на сошедшихся совпали с прежними 0,683/1,966).

**Вывод.** На уверенно сошедшихся отложенных системах P3E8 равен P3E0 (0,707 против 0,703 м/с, p90 1,99 против 2,01 — в пределах
разброса от зерна 0,013), а на несошедших хуже (0,59 против 0,48; на обучающих несошедших 0,52 против 0,30): сеть, не видевшая
слабый ветер с шумной целью, на нём ошибается больше; гипотеза «шумные цели мешают» не подтвердилась.

**Границы.** Одно зерно; правило «уверенно» — по статусу и числу итераций (невязок нет); «уверенные» — не независимая
истина: решатель на них тоже может иметь погрешность (ρ-таблица учитывает u_ref). Отложенный набор несбалансирован по ветру
(слабый ветер среди несошедших). Проверка при обучении у P3E8 на другом (облегчённом) наборе, значения 0,213 и 0,269 не сравнимы.
