# Изгиб базовой штанги: 48 крыльев

Задача PV-2, контракт PV3 v1 (`docs/contracts/pilot-view.md`). Повод: отзыв пилота-тестировщика 08.10 — у всех крыльев, кроме учебных вроде Wills Wing Alpha, штанга изогнута вперёд в центре (у Falcon — тоже).

## Вывод
- Изогнутых 37, прямых 11. Диапазон `bow_m`: 0,07…0,11 м у изогнутых; умолчание `control_frame.basebar_default` — 0,08.
- **Форма** (прямая/изогнутая) — по руководствам и страницам производителей. В терминах производителей изогнутая штанга — «speedbar» (basetube с отгибами; в руководствах Aeros: «offset of the speedbar is directed forward»). Wills Wing: Falcon 3 — SpeedBar стандарт, Straight опция; Alpha — straight стандарт, speedbar опция; алюминиевая обтекаемая штанга Slipstream/Litestream — «deeper bend».
- **Величину выноса** ни один открытый источник не даёт (ни в руководствах WW, Aeros, ни в паспортах DHV): чертежей speedbar с размером нет. Поэтому `bow_src = "class_estimate"` у всех изогнутых. Оценка — по классу: круглый speedbar 0,07; обтекаемый алюминиевый 0,09 («deeper bend»); карбоновый «deep offset profile» и безмачтовые 0,11; неопределённость ±0,03. Это согласуется с шириной штанги 1,36–1,5 м (вынос ≈ 5–8 % ширины) и пределом контракта 0,03…0,25.  Фото с размерами не использовались (не найдены) — это главное допущение; проверить по фото/замеру реальной штанги при случае.
- Форма: прямой центр, прямые участки у углов `straight_len_m` 0,10–0,15 м, между ними отгибы (дуга по всей длине не подтверждена; «straight_len_m» — оценка). Подробнее форма у безмачтовых: уже есть провис вниз `speedbar_dip_m` 0,05 — вынос вперёд отдельный параметр.
- Не найдено/не прочитано: Moyes (сайт и руководство Litespeed RX не открылись), Icaro, Bautek, Seedwings, Flight Design — по ним образец класса. Обобщённые `training`/`sport` — по образцу Alpha / T2C.

## Как получены оценки
1. Руководства (`pdftotext` локально, PDF не хранятся): Aeros Target, Combat-C, Combat-09 (§ сборка: offset speedbar вперёд); Wills Wing T2C, Falcon 3/4, Falcon 2, Discus — про форму ничего, кроме bend упоминаний.
2. Страницы запчастей/продуктов WW: falcon-basetubes (Straight/SpeedBar), alpha, control-bars, slipstream FAQ, carbon speedbar.
3. Проектные паспорта: `tools/research/data/wing_passports/out/construction/batch_{a,b,c}.json` (цитаты про speedbar: Eagle, Sting 3, F2, Spectrum, Alto, Kite, SHE1, Target).
4. Крылья без данных — по классу (однообшивочные учебные и крылья 1980-х — прямые; остальные — изогнутые), `ref` указывает образец.
5. Запросы к сайтам — единичные, вежливо.

Воспроизведение: `python3 tools/research/basebar_curve/apply_basebar.py` (из корня; пишет `glider_params.json` и `basebar_data.json`). Лицензии: цитаты короткие, страницы производителей/руководства не хранятся.
