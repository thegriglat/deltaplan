## Диагноз: 200 м, 3 м/с с нагревом (эталон `picard/`, статус max)
`out/diag200_*.json`, таблица — `python3 diag_table.py`. Невязка θ′ и θ′_d убывает до ~200-й итерации
(th_rms 7,6e-7), затем предельный цикл с периодом ~30 итераций: 5,4e-7…1,0e-6 при порогe 5e-7, mom_rms
на плато 1,0–1,3e-5 (тоже не убывает). float64 повторяет float32 до 3 знаков — не округление. 94 % Σr²
(по карте max по z) — в трёх крайних столбцах западной **выходной** границы (i ≤ 3), на 2,7–3,2 км над
морем (верх слоя перемешивания, z_i = 3,36 км; над остальным полем невязка ≤ 1e-7).

| Вариант | Итог |
|---|---|
| base32 / base64 | max, цикл 5,4e-7…1,0e-6 |
| prt1 (Pr_t = 1) | ok на 211-й — но то же плато (5–7e-7), случайный провал под порог |
| oldsth (прежний s_th в cplz) | max, то же |
| dtau600 (Δτ_θ = 600 с) | max, 8e-7…1,2e-6 |
| nocpl (couple = 0) | расходится в цикл 1e-3 (полунеявная плавучесть нужна, как и раньше) |
| sweeps8 (heat_sweeps = 8) | ok на 221-й, невязка убывает монотонно |
| **nolocal (local_k = False)** | **ok на 191-й, монотонно; thd_rms 2e-8** |
| **krelax25 (k_relax 0,5 → 0,25)** | **ok на 171-й, монотонно (1,0e-6 → 8,0e-7 → 6,6e-7 → 5,5e-7 → 4,4e-7)** |
| air.py до А1 (контроль) | ok на 151-й (максимум невязки — там же, у выходной границы, но убывает) |

Вывод: цикл — обратная связь местного K(Ri) (`kloc`: N² от dθ′/dz, релаксация 0,5) ↔ θ′ ↔ w у выходной
границы в верхней части слоя перемешивания; до А1 её гасил искусственный сток −θ′/τ полного θ′. Это не
дефект реализации А1 (порядок θ′_d в источнике, знаки, критерий — проверены: обе невязки на одном плато,
θ′_d с диагональю 1/τ тоже в цикле, потому что качаются u и K), а жёсткость связки K(Ri)–θ′ без
искусственного демпфирования — задача сходимости А2.
