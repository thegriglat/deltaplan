# Метрики M1 (CSD-2)

Контракты: F0/F1/M1 — `docs/contracts/cascade-2d.md`; определения — `docs/plan/cascade-2d.md`, «Метрики».
Запуск через обёртку: `tools/research/cascade_2d/py`.

- `metrics.py --case C1 [--ref F1] [--fields каталог|F1 ...] [--baselines 400,200,100,50] [--out dir]` —
  пишет `out/metrics/<C>.json` и `.csv` (атомарно, проходит `contract/check_contract.py`).
  По умолчанию эталон `$CASCADE2D_DATA/fields/<C>/picard_none_d25.json` (нет — `d50`, отмечено в `notes`),
  поля — все F1 случая. Строки грубого Пикара представлены базовыми линиями B_k (строятся в памяти из
  `picard_none_d<k>.json`), сами picard-файлы строками не идут.
- `plots.py --case C1 --field F1 [--vs B400]` — `out/fig/<C>/<имя>_fields.png` и `_profiles.png`, ≤ 300 КБ.
- `test_metrics.py` — синтетика: поле против себя, константный сдвиг, точность интерполяции B_k на
  линейном поле, L_rec, бездивергентность функции тока, сквозной прогон с контрактной проверкой.

## Решения по неоднозначностям (в рамках контракта)
- Приведение на сетку эталона: линейно по x и z, вне сетки — линейная экстраполяция, затем 0 на гранях
  стенок эталона (`tu/tw = 0`). Метрики — по клеткам воздуха эталона. Интерполяция через стенку размазывает
  скачок; это граница модели B_k.
- U_ref и знаменатель S(z): |u| клеток, линейно по z_agl внутри колонны (клетки воздуха) и по x между
  центрами двух колонн; x = −4800 м попадает на грань, берётся среднее двух колонн.
- ΔS(z) = |S_поле − S_эталон| на 25/50/100 м, `mean` — среднее трёх.
- L_rec — самый длинный участок подряд колонн в LEE (x_c < x ≤ x_c+6L), где u нижнего воздушного ряда
  (при z_agl ≤ 25 м) < 0, число колонн · dx. `L_rec_ref` — то же у эталона.
- Термик (только C3): w_max — максимум w клеток в ROI (z_agl ≤ 300 м), F_up = Σ max(w,0)·dx на z = 750 м
  по |x − x_c| ≤ 3L (w линейно между гранями).
- `max_rel_div`, `max_speed` — на собственной сетке поля (у B_k — грубого Пикара), а не после интерполяции.
- σ_u, σ_w (V3h, ≥ 2 seed одной пары dx/parent_dx): на каждой z_agl = 25…300 через 25 — СКО отклонения
  от среднего по seed (ddof = 1), среднее по колоннам ROI; профили 12 чисел, одинаковы у всех seed группы.
- E_ref: метрики B50 против P25 (пусто, если эталон не P25 или нет `picard_none_d50`).
- В json добавлены `notes`, `x_c`, `L` (контракт допускает лишние ключи).
- Эталон P25 в `$CASCADE2D_DATA` на момент сдачи проверен только на синтетике.
