# Промо-видео: пробная автоматическая съёмка

Прототип (07.10.2026, приостановлен): полёт над Онгудаем, камера от третьего лица облетает дельтаплан, звук — то, что слышит пилот. Запись — Godot Movie Maker (кадры с фиксированной частотой, независимо от скорости машины).

```bash
tools/shots/promo/promo.sh build/promo/run1 20            # 20 с, 1920×1080, флаги по умолчанию
tools/shots/promo/promo.sh build/promo/run2 15 1280 720 -- --autostart --camera=chase --location=ongudai ...
```

- `promo.gd` — драйвер съёмки: прячет прибор, отключает CameraRig и ведёт камеру по ключам `[t_с, угол_° (0 — сзади, + вправо, 180 — спереди), радиус_м, высота_м, fov_°]` (Catmull-Rom); курс сглажен в мировых осях, взгляд чуть впереди планера, камера не ниже 3 м над землёй.
- `promo.sh` — временная копия проекта с нужным разрешением, `dp lock gpu` + xvfb + Movie Maker (PNG + WAV), сборка ffmpeg в mp4 (libx264 crf 15, aac 192k).

Что выяснилось:
- нужен дисплей (xvfb с Vulkan), `--headless` не пишет;
- `--resolution` Movie Maker игнорирует — размер из `project.godot` (`viewport_width/height`), отсюда копия проекта;
- `--no-overlay` работает только со `--screenshot` — прибор прячет скрипт;
- PNG 1080p — около 0,9 с на кадр (16 с видео ≈ 8–9 мин); MJPEG быстрее, но качество хуже;
- звук Movie Maker пишет WAV рядом с PNG.

Не сделано: плавные разгоны и торможения облёта, маршрутный автопилот по точкам (боты маршрут не держат; план — расширить `scripts/game/autopilot.gd`), сценарий в JSON вместо констант в `promo.gd`. Ключи облёта целиком не проверены глазами.
