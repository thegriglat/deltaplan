# Вулканический остров — данные места (VI-1)

Место только для «Тренировки» (контракт VI-К1, `docs/contracts/volcano-island.md`): реальный остров ~24 × 18 км, суша ~165 км², пассат с 110°.
Данные лежат в игре (`res://data/locations/volcano_island/`, ~3 МБ), конфиг — `configs/locations/volcano_island.json`
(`bundled`, `training_only`, `utc_offset_h` −6). Сети при запуске игры нет; сеть нужна только `build.sh`.
Рельеф не правится. Координаты и рабочие пометки — только здесь (в игре, `ASSETS.md` и на сайте остров безымянный).

## Сборка и воспроизведение

```bash
tools/terrain/volcano/setup_env.sh                       # .venv (numpy, Pillow), не коммитить
tools/terrain/volcano/build.sh                           # сеть: обычный сборщик в временном профиле → data/locations/volcano_island/
tools/terrain/volcano/build.sh --from ПРОФИЛЬ            # без сети: взять готовое место из профиля (XDG_DATA_HOME)
tools/terrain/volcano/rebuild_check.sh                   # повтор сборки из сети + сравнение высот и классов с папкой (numpy)
tools/terrain/volcano/make_config.py                     # configs/locations/volcano_island.json из таблицы стартов и посадок
tools/terrain/volcano/.venv/bin/python tools/terrain/volcano/check_sites.py     # правила стартов и посадок, exit 1 — нарушено
.dpcli/dpcli lock gpu <имя> -- tools/terrain/volcano/.venv/bin/python tools/terrain/volcano/air_quick.py   # воздух, GPU, окно DISPLAY=:0
python3 tools/terrain/volcano/air_quick.py --show        # главные числа из out/air_quick.json
.dpcli/dpcli lock gpu <имя> -- tools/terrain/volcano/shots.sh                   # кадры → build/screenshots/volcano-island/VI-1/
```

`build.sh` — `godot --headless -s res://tools/terrain/build_location.gd -- --lat -27.10 --lon -109.35` в временном `XDG_DATA_HOME`
(параметры слоёв — умолчания сборщика: detail 40 км / 25 м Copernicus GLO-30, far 160 км / 100 м Terrarium, WorldCover 10 м, реки, сглаживание
под лесом и крышами, тайлы OSM) и `pack.py`: копия `meta.json`, `*.webp`, `built_patches.json`, `surface.json`, `osm_tiles.json`, `build.json`
(без `location.json`, `*.import`, `*.remap`, `detail_raw.webp`), поля `meta.location` и `build.key` = `volcano_island`, тайлы OSM со статусом
`ok` → `osm/<j>/<i>.dpt`. Статус `missing` в bundled-месте запрещён.

Воспроизводимость (17.10): повтор сборки из сети (61 с, 93 запроса) совпал с папкой — высоты detail и far 0,000 м разницы, классы и вода
detail/far 0 % отличающихся ячеек (`rebuild_check.sh`; байты WebP не сравниваются).

Как подбирались (`scan_sites.py`, перебор узлов 25 м; кандидаты исследования ушли с уклоном 6–9° на сетке 100 м — сдвиг по склону к бровке):

- `east_cliffs`: исходный ориентир (−27,1049; −109,2384, 199 м) имел уклон 6,7° на 25 м — сдвинут на 0,6 км вверх по склону, к верху наветренного склона плато
  (профиль по курсу 101°: 228 → 208 → 194 → 185 м через 100 м и далее 6° до обрыва к морю в 950 м: 137 → 54 → 0 м).
- `east_cliffs` (VI-5, решение Q1): перенесён с плато (228 м, подъёма у старта нет, w ≈ −0,1 м/с; обрыв в 950 м — с плато при встречном
  ветре 6 м/с до него не долететь) на кромку морского обрыва восточного плато: 141 м, 8,9° на 25 м, по курсу 110° через 75 м — 83 м, через
  150 м — 14 м (море). Перебор `check_sites`-правил по кромке (x 10800–12200, z −600…2400, шаг 10 м, курсы 80–140°) дал пояс кандидатов
  125–145 м; взят с курсом точно по пассату и наибольшим перепадом за кромкой.
- `landing_cliffs` (VI-5): **посадки в пределах k ≈ 6 у кромки нет** — плато за стартом поднимается вглубь острова, внизу море без пляжа.
  Наименьшее k до точки с уклоном < 10° по всей кромке — 6,7 (уклон 9,7°, голый грунт в 50 м от обрыва), до ровного поля 120×60 м
  (наибольший уклон ≤ 7,5°) — 9,7…11. Взято поле на кромке в 491 м к северо-востоку, на 45 м ниже (k = 10,9; уклон 6,3°, по полю 6–7,5°);
  восточнее в 50 м — обрыв, поэтому размер 120×60 м (`configs/world_objects.json`). Долёт — вдоль кромки в динамике (w +1…2 м/с),
  без подъёма не достаётся; отклонение от VI-К1 «k ≈ 6» вынесено в отчёт VI-5.
- `crater_ridge`: ориентиры (−27,1805; −109,4131) и гребень (−27,170; −109,4136) отвергнуты: первый — лес в точке старта (класс 1), второй — плоское дно (уклон 0,3°); **кроме того, быстрая проверка воздуха показала на пологом наветренном склоне у ориентира w < 0 (среднее −0,29 м/с)** — старт перенесён
  на кромку юго-западного обрыва (226 м, обрыв к морю в ~400 м по курсу).
- `plateau_landing`: ориентир cand5 как есть (13,1° на 25 м); мишень `landing_target` — первая пологая (3,9°) площадка по курсу.
- Ровных мест на острове мало (лавовые склоны 5–9° повсюду), поэтому посадки — пологие луговые уступы с уклоном 4–8°, не ровные поля. Размеры в
  `configs/world_objects.json → landing.sites.volcano_island` (200×100, 180×90, 220×110 м, ось 110°).
- Имена: `loc_volcano_island`, `site_volcano_island_{east_cliffs,crater_ridge,plateau_landing}` — «Вулканический остров/Volcanic Island», «Восточные обрывы/East Cliffs»,
  «Гребень кратера/Crater Ridge», «Посадка на плато/Plateau Landing»; без топонимов (контракт VI-К1).
- `thermal_slope` — не заведён (см. «Термики»).

## Быстрая проверка воздуха (VI-1, для шлюза; старый east_cliffs на плато, k притока до fix/lee-start-calibration — см. «Проверка воздуха (VI-5)»)

`air_quick.py` + `air_probe.tscn`: поле GPU игры (`AirRuntime.load_field`, область + окна у старта), выборка `air_velocity_at` в точках; 15 января,
12 ч, облачность partly, без турбулентности и пузырей термиков. Ветер — «на старте» (u10 над стартом калибруется приточным множителем k).
Условие остановки задания (k = 3,0 или ветер у старта > 15 м/с) не сработало нигде.

Склон — 6 м/с с 110°. Бровка: у `east_cliffs` — верх обрыва к морю (самая наветренная точка линии по ветру с h ≥ 100 м, ~950 м от старта), у
`crater_ridge` — верх обрыва (~350 м от старта); линии по ветру через 9 точек вдоль фронта (±1 км, шаг 250 м). w — вертикальная скорость воздуха, м/с.

|---|---|---|
| k притока / ветер на 10 м над стартом | 1,025 / 6,03 м/с | 1,546 / 6,09 м/с |
| w, среднее по 81 точке (50–150 м над бровкой, 100–300 м с наветра) | **+0,67** | **+0,88** |

| 100 м с наветра, 50 / 100 / 150 м над бровкой | 1,11 / 1,04 / 0,89 | 1,18 / 1,27 / 1,29 |
| 200 м с наветра, 50 / 100 / 150 м | 0,63 / 0,67 / 0,64 | 0,79 / 0,89 / 0,94 |
| 300 м с наветра, 50 / 100 / 150 м | 0,30 / 0,36 / 0,38 | 0,40 / 0,52 / 0,60 |

| ротор: доля точек с обратным ветром / минимум составляющей по потоку | 0 % / +5,3 м/с | 5 % / −1,4 м/с |

Вывод по воздуху: у обоих стартов подъём у обрыва есть, максимум у верха обрыва (≈ +1,1…1,3 м/с на 50–150 м над ним), на 300 м от кромки — +0,3…0,6 м/с.
Ротор слабый: у `east_cliffs` за кромкой плато нет (плато простирается вглубь острова), только слабый спуск; у `crater_ridge` небольшая зона
обратного ветра до −1,4 м/с и сход до −1,9 м/с за обрывом.
Первый вариант `crater_ridge` (старт на пологом наветренном склоне гребня с h 190 м, −5596; 7284) дал w = −0,29 м/с и k = 0,73: пологие
5–10° склоны острова при 6 м/с подъёма практически не дают — подъём даёт обрыв к морю. Это же касается `east_cliffs`: на плато у старта подъёма нет
(w ≈ −0,1 м/с на 100–300 м от кромки плато), лифт начинается в ~900 м впереди над обрывом: стартовать с плато и лететь к обрыву.

Сырые выборки — `tools/terrain/volcano/out/` (probe_*.json, air_quick.json; не коммитятся, воспроизводятся командой выше за ≈ 5 мин).

## Термики

15 января (южное лето), 12 ч, ясно, t_max 27 °C, 2 м/с с 110° (k = 0,756); w_conv поля на 150 и 300 м над землёй по сетке 250 м по всему острову
(2640 узлов суши, 6705 — моря; фокус поля — старт `plateau_landing`, поле покрывает остров на 100 %).

| | суша | море |
|---|---|---|
| w_conv на 150 м: среднее / p90 | 0,025 / **0,142** м/с | 0,000 / 0,023 м/с |
| w_conv на 300 м: среднее / p90 | 0,026 / 0,150 м/с | 0,002 / 0,037 м/с |
| по классам на 150 м (среднее / p90) | луг 0,028 / 0,146; лес 0,020 / 0,123; грунт −0,011 / 0,129; кустарник 0,047 / 0,201 | вода −0,086 / 0,011 |
| сила источника (среднее) | лес 0,82; застройка 0,75; грунт 0,64; пашня 0,60; кустарник 0,56; луг 0,55 | вода 0 |

p90 ядра над сушей 0,14 м/с — **меньше порога 1 м/с**, старт `thermal_slope` не заведён. Причина по модели: остров мал и окружён морем, контраст нагрева суши и
воздуха при t_max 27 °C слаб; сильных источников нет (луг 0,55). Для сравнения, на учебном острове p90 над полями было 0,25 м/с (тот же поле-решатель), т. е.
шкала w_conv в этой модели при слабом ветре малая. Другие t_max (жарче) не прогонялись.

## Погода стартов (VI-5)

Наборы TI-К2 v2 (`start_sites[].weather`, пишет `make_config.py`; запечены — VI-К3, `bash tools/terrain/bake_all.sh --id volcano_island`):

| старт | откуда | ветер | `wind_ref` | час | дата | небо | t_max |
|---|---|---|---|---|---|---|---|
| `east_cliffs` | 110° | 6 м/с | start (k притока 0,98) | 12 | 15 января | partly | 27 °C |
| `crater_ridge` | 110° | 6 м/с | inflow (k = 1) | 12 | 15 января | partly | 27 °C |
| `plateau_landing` | 110° | 2 м/с | start (k 0,81) | 9 | 15 января | clear | 27 °C |

Обоснование (числа — из источников ниже, поясное время места UTC−6, солнечный полдень ≈ 13:17):

- **Январь** — южное лето: субтропический антициклон юго-восточной части Тихого океана стоит южнее острова, пассат с востока–юго-востока
  устойчив, фронты западного переноса (зима, июнь–август, основные дожди) не доходят. Наблюдения аэропорта острова (METAR): преобладает ветер
  с востока (44 %) и юго-востока (21 %), средний ≈ 8,8 уз (4,5 м/с); среднемесячный ветер 4–5 м/с круглый год. 110° — между ними.
- **6 м/с** на склонах — обычный пассат чуть выше среднего, в коридоре 5–8 м/с карточки; ветер у старта ≤ 10 м/с при всех трёх скоростях
  (максимум 8,0 м/с у `east_cliffs` при 8 м/с). У `crater_ridge` старт лежит в ослабленном потоке: подгонка притока «под ветер у старта»
  упирается в предел k = 1 (после fix/lee-start-calibration) — при наборе 6 м/с у старта было бы 4,6 м/с вместо обещанных 6. Поэтому набор
  задан как набегающий поток (`wind_ref: inflow`, k = 1 — то же поле, честная подпись): пассат 6 м/с, у старта 4,6 м/с.
- **t_max 27 °C** — средний максимум января 26,9 °C (норма 1991–2020; февраль 27,5 °C, рекорд января 32,0 °C).
- **12 ч** у склонов — середина дня, `partly` (январь — 270 солнечных часов, но кучёвка пассата обычна); посадка — **9 ч**, ясно, 2 м/с:
  спокойное утро до развития конвекции (у мишени 1,4 м/с на 10 м).

Источники (нормы климата аэропорта острова, Dirección Meteorológica de Chile 1991–2020; ветер по METAR; средний ветер по месяцам) — ссылки
в шапке `make_config.py` (в тексте README место не называется). Данные только для обоснования, в игру не попадают (лицензии не нужны).

## Проверка воздуха (VI-5)

`air_check.py` + `air_check_run.tscn` (копия `tools/terrain/island/air_check_run.gd` + режим точек): главная сцена с `--autostart` на старте с
его набором погоды из конфига, поле GPU игры (k притока ≤ 1 после fix/lee-start-calibration), пауза, `Atmosphere.air_velocity_at` без болтанки,
среднее 5 снимков через 60 с. Наборы 5 и 8 м/с и погода термиков — подмена набора только в памяти процесса.

```bash
.dpcli/dpcli lock gpu air -- tools/terrain/volcano/.venv/bin/python tools/terrain/volcano/air_check.py   # ≈ 40 мин, окно DISPLAY=:0
python3 tools/terrain/volcano/air_check.py --show                 # главные числа из out/air_check.json
python3 tools/terrain/volcano/air_check.py --summarize            # итог из сырых out/check_*.json (не коммитятся)
```

Первый запуск в копии с холодным кешем шейдеров даёт «таймаут расчёта (60 с)» и аналитику — скрипт останавливается, повторить.
