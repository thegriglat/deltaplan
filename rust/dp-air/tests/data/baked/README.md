# Дамп запечённых полей (RW-6p)

Эталон GDScript (`AirBakedField.load_file`, настоящий `AirRuntime.baked_lookup`) для `rust/dp-air/tests/baked.rs`. Снимает и проверяет `tools/research/rust_wind/dump_baked.sh` (`--verify` — пересъёмка и побитное сравнение); Godot — под замком `.dpcli/dpcli lock cpu`.

Файлы: `baked.json` (карта массивов `arrays: имя → [смещение, длина]` в f32, файлы и уровни, сценарии выбора с причиной отказа) и `baked.bin` (f32 LE подряд, ≈ 1,3 МБ).

Источник — все `data/locations/*/air/*.json` (8 стартов двух островов, по 3 уровня): 700 точек на уровень (скорость, θ′, `w_conv`, «внутри»), срезы сырых массивов каждая 997-я клетка, 16 сценариев `baked_lookup` на старт (условия в допуске и вне, дата, нет файла, нет набора погоды, центр и старт `key`, чужой хеш модели). Дамп зависит от самих запечённых файлов и хеша модели воздуха: перепечь полей или правка `scripts/atmosphere/air_model/` — пересъёмка дампа.
