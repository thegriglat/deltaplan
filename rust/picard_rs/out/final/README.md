# PR-12 — итоговые замеры picard_rs (Онгудай 400 м)

Итоговый код ветки `picard-rs` (коммит `b0b128bc2`, после пачки 2 PR-9), Xeon E5-2666 v3 (Haswell, 10 ядер / 20 потоков), ветка `x86_64+avx2+fma`,
все прогоны под замком `cpu` (18 слотов), по одному разу, процесс — `picard solve`. Время — `time.total_s` R2 (подготовка + итерации + проверки, без чтения `.bin`).
`tol_scale 5` — принятый порог (холодный и тёплый старт); `tol_scale 1` — критерий эталона, база для сравнения. Сходимость в штиль (u0_heat) не разбирается — только время.

## Воспроизведение

```
cargo build --release --manifest-path tools/research/air_cascade/picard_rs/Cargo.toml
.dpcli/dpcli job start pr12 7200 bash tools/research/air_cascade/picard_rs/out/final/run.sh   # ~25 мин, из корня копии
python3 tools/research/air_cascade/picard_rs/residual/summarize_final.py --out tools/research/air_cascade/picard_rs/out/final/summary.json
python3 tools/research/air_cascade/picard_rs/residual/md_final.py     # таблицы ниже
python3 tools/research/air_cascade/picard_rs/contract/check_contract.py --results tools/research/air_cascade/picard_rs/out/final/cold_tol5/
```

Данные: случаи `~/data/air_cascade/ongudai/ongudai_d400_*.{json,bin}` (AC-R2/PR-3/PR-10, вне git, расчётные, лицензия — проект). Состояния R4 (десятки МБ) —
`~/data/air_cascade/picard_rs/final/` (`S1200_X` — холодный h1200; `W1215_X`, `W1230_X` — цепочка тёплых; `C1215_X`, `C1230_X` — холодные). База «до» — `out/base/` (PR-1, R2 v2).

Каталоги: `cold_tol1/`, `cold_tol5/` — холодные 4 случая × 2/3/6/8; `coldh_tol*/` — холодные h1200 (только 8 потоков, даёт `S1200`), h1215, h1230;
`warm_tol*/` — тёплые h1215 (`--init S1200_X`) и h1230 (`--init W1215_X`, то есть из тёплого). Цепочка для каждого tol своя: h1200 холодный → h1215 тёплый → h1230 тёплый.
Состояния для `--init` взяты из прогонов на 8 потоках; путь решения от потоков не зависит (проверено `compare_r2.py`: 2 против 6 потоков — идентичны на u3_heat tol 5, u6_heat tol 1, тёплом h1230 tol 5).

## Срок пересчёта в реальных секундах

`configs/atmosphere.json:321` — `recompute_game_min = 15` игровых минут. Игровые часы идут со скоростью `time.speed` (`configs/world.json:44`, по умолчанию 1; варианты
`speed_options` `:46` — ×1, ×10, ×60, 0; `scripts/world/sun_clock.gd:80`: `hour += dt·speed/3600`), по сети — всегда 1 (`scripts/game/game.gd:1419`). Срок: 900 с при ×1, 90 с при ×10, 15 с при ×60.
Значения ×10/×60 взяты из `speed_options` по умолчанию в `settings_panel.gd:209`; реальные варианты в `world.json` не пересчитывались.

## Выводы и границы

- Холодная загрузка (tol 5, 8 потоков): 6,2 с (u3_heat, u3_mech), 4,6 с (u6_heat), 3,5 с (u0_heat); на 2 потоках 15–19 с (u0_heat 10,5 с). До оптимизации (tol 1) 15–22 с на 8 потоках —
  оптимизация даёт ×2,0–2,1 при том же числе итераций и полях, tol 5 — ещё ×1,6–1,7 (u3), ×3,1 (u0_heat), ×1,6 (u6_heat).
- Тёплый пересчёт (tol 5, 8 потоков): h1215 — 10 итераций, 0,75 с; h1230 (тёплый из тёплого) — 20 итераций, 1,29 с; холодный — 9,3 и 8,6 с (×7–12 быстрее по времени). При tol 1 h1230 тёплый требует 90 итераций (5,1 с против 14,6 с, ×2,9).
- Доля срока: при ×1 и ×10 пересчёт (tol 5, 2–8 потоков) укладывается в 0,1–4 % срока; при ×60 (срок 15 с) — 9 % на 8 и 24 % на 2 потоках; тёплый tol 1 h1230 на 2 потоках при ×60 (15,6 с) срок не укладывает.
- Цепочка: отклонение конца цепочки (тёплый h1230 tol 5 против холодного h1230 tol 1) — у старта Δw 0,009, Δ(u,v) 0,036 м/с; склоны Δw 0,026 (Δwt 0,058); термики Δw 0,015 — все в пределах порога PR-8 (0,05 / 0,2 / 0,1). Ошибка не копится:
  Для сравнения, одно звено (h1215): старт Δw 0,025, Δ(u,v) 0,102 м/с — больше, чем у конца цепочки; ошибка по цепочке не копится (на этой паре). Тёплый tol 5 останавливается
  на первой проверке критерия (раз в 10 итераций), поэтому его отклонение зависит от того, на какой итерации попала проверка.
  Склон Δwt 0,058 из 0,1 — худший запас (×1,7).
- Границы: одна точка поля (Онгудай, u3_heat, 3 момента h1200/1215/1230, 15 июля); mech и другие пары не проверены; замер по одному прогону на точку (разброс ~2 % по PR-9), не серия; база PR-1 снята на том же железе, но в другой день и при другом коде; на машине с Godot/фоном цифры хуже.
- Тёплый tol 1: h1230 — 90 итераций против 20 у h1215: поле h1230 дальше от h1215, чем h1215 от h1200, или медленная мода; причину не разбирали.
