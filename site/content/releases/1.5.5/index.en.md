# Deltaplan 1.5.5 — take-off run in Pendulum mode

11.10.2026 · [Download on itch.io](https://thegriglat.itch.io/deltaplan)

## What's new
**Pendulum mode (experimental): take-off run and launch**
- The run on a slope is shorter: a training wing lifts off after 10-12 m in no wind and 5-6 m into a headwind.
- Fixed legs that slowed the run on a slope; the hands now hold the wing nose up during the run.
- At launch in a crosswind the wing turns its nose into the wind.
- Where the simulation lies: landing in Pendulum mode is still hard even with correct technique. The default mode is still "Weight shift".
