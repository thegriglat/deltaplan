# Deltaplan 1.5.13 — half the disk space

14.10.2026 · [Download on itch.io](https://thegriglat.itch.io/deltaplan)

## What's new
- The game takes almost half the disk space: glider textures are stored compressed (Basis Universal), and identical seam maps shared by gliders of one layout are kept as one file. Game data shrank from 212 to 86 MB, the whole Linux build from about 285 to 155 MB. The sails look the same.
