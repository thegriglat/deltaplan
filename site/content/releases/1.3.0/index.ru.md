# Deltaplan 1.3.0 — ветер по режимам

07.10.2026 · [Скачать на itch.io](https://thegriglat.itch.io/deltaplan)

## Что вошло
**Ветер над рельефом**
- Ветер над рельефом считается по режимам: обтекание склона, срыв за гребнем, волны, штиль, вечерний сток по склонам и долинам, свободная конвекция. Для обтекания, срыва и волн поле досчитывает решатель на видеокарте; в штиль, при сильной устойчивости, в вечернем стоке и при свободной конвекции поле даёт готовая модель режима. Загрузка места стала короче.
- Меню «Ветер над рельефом»: «Расчёт» (режимы + решатель на видеокарте) и «Эвристика» (профиль ветра без рельефа). Без видеокарты — эвристика.
- При слабом ветре, когда решатель не сходится, поле усредняется по последним итерациям, а там, где ведёт модель режима, берётся её значение.
- Зона за гребнем приведена к измерениям: опасность — ротор (обратный поток у склона, болтанка, рывки сверху), а не сильный провал.
- Нейросеть ветра удалена: ONNX Runtime и Visual C++ Redistributable больше не нужны.

**Пилот**
- Разбег: ноги бегут в плоскости бега, стопы под корпусом; корпус плавно наклоняется вперёд на разбеге и выпрямляется в полёте.

**Интерфейс**
- Язык по умолчанию — английский. Русский — переключателем в главном меню или в настройках, выбор запоминается.

**Отладка**
- Стрелки ветра (F5) рисуются своим кодом; расширение Debug Draw 3D удалено.
- Слой карты режимов ветра (F4 в отладке ветра).
