# Deltaplan 1.3.4 — a straight launch run in a crosswind

08.10.2026 · [Download on itch.io](https://thegriglat.itch.io/deltaplan)

## What's included
**Launch**
- The launch run in a crosswind no longer veers off course: while the feet still reach the ground, the little hops at liftoff no longer swing the pilot's nose into the wind (before, each hop turned it by 5–10°, up to 40° over the run). Once the pilot is in the harness, the nose lines up with the airflow smoothly, within half a second.

**Debug**
- F3 wind arrows now use the same colours as F5: red — rising air, blue — sinking air (F3 had them the other way round).
