# Deltaplan 1.5.15 — crash reports

14.10.2026 · [Download on itch.io](https://thegriglat.itch.io/deltaplan)

## What's new
- If the game closes unexpectedly, on the next start it sends the developer a short report by itself: version, graphics card and driver, settings of the last flight (graphics quality, wind mode, number of bots, place) and the end of the game log. Paths with your user name are removed from the log. Nothing to do on your side — the menu shows "Crash report sent".
