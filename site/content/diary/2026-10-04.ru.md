Итог дня по нейросети ветра: все пробы P3 и новая архитектура «2,5D-оператор» (ann2) упираются в одну и ту же относительную ошибку ≈ 22 % скорости ветра, лучше P2 лишь на 6–10 %. Направление отложено, в игре остаётся сеть P2 — она вышла в [1.0.5](/releases/1.0.5/) вместе с режимом «Осмотр карты».

<!--more-->

## P3: закрыт без выигрыша

Ночью досчитались последние варианты третьего пилота (отложенные горные системы, ветер на 60 м, медиана м/с; контроль P3E0 — 0,683):
- P3E6 — фоновая стратификация θ̄(z) во FiLM: 0,689, не помогает ({{< commit 03a8790 >}});
- P3E7 — U-FNO (спектральные свёртки neuraloperator, для ONNX — двойник на матрицах ДПФ): 0,732, на 7 % хуже ({{< commit 9283dd4 >}});
- P3E8 — обучение только на «уверенно сошедшихся» случаях: 0,692, а несошедшиеся стали хуже (0,59 против 0,48) ({{< commit 9c5dffa >}}).

Лучшей осталась P2 (300 мест, 0,62 / 1,84 м/с): тройной объём данных дал больше любых правок кодировки. Решение пользователя: P3 закрыть, в игру — P2 ({{< commit c705c6c >}}). Итоговая таблица — [docs/archive/plan/air-nn-p3.md](/docs/archive/plan/air-nn-p3.md).

Между делом пользователь записал «держим в уме» три идеи другой постановки: марш по ветру вертикальными срезами, нити по ветру с «поршнем в трубке» и Монте-Карло, сетка по линиям тока, где ячейки — трубки тока.

## WindNinja как второй эталон

Проверили, может ли WindNinja (массосогласованная модель USDA Forest Service, общественное достояние) служить независимым эталоном или запасным вариантом ветра ({{< commit 607e591 >}}). Собрали 3.13 и 4.0.0 только на процессоре и сравнили с решателем на 60 м:
- на гребнях разгон совпадает (1,19 против 1,13 от притока), направление — медиана расхождения 10°;
- в долинах и на подветренных склонах решатель держит 0,3 от притока, WindNinja — 0,84–0,97: торможения горным массивом у диагностической модели без уравнений импульса нет.

Решение пользователя: торможение массивом — реальное явление, решатель остаётся эталоном, массосогласованные эвристики его не заменяют. Подробно — [tools/research/windninja/README.md](/tools/research/windninja/README.md).

## ann2: архитектура заново

Пользователь решил начать сеть ветра заново — модуль ann2, план [docs/plan/ann2.md](/docs/plan/ann2.md). Заодно сменили критерий: не «ρ по допуску», а **ошибка ветра ≤ 10–15 % скорости** (10 % — цель, 15 % — допустимо); P2 сейчас — 17–30 %.

- **AN-1, предел данных** ({{< commit 96abd5c >}}): может, сеть упирается в шум цели? Нет: дрейф цели у сошедшихся — 0,003 м/с при ошибке P2 0,59, у несошедшихся среднее 11 снимков отличается от среднего 51 на 0,009 при ошибке 0,355. Чинить цель незачем — [docs/research/ann2_data_limit.md](/docs/research/ann2_data_limit.md).
- **AN-2/AN-3, «2,5D-оператор»** ({{< commit a26c333 >}}, {{< commit f5271b1 >}}): свёрточный энкодер ConvNeXt + энкодер профиля атмосферы + внимание + голова по непрерывной высоте с оценкой σ, 3,0 М параметров, 40 000 шагов. Лучше P2 на 7–9 % (0,567 против 0,624 на сошедшихся), на слабом ветре и несошедшихся — как P2; переобучение после ~26 000 шагов. Голова оказалась в 12 раз медленнее P2.
- **AN-4** ({{< commit 7ff8800 >}}): проверка данных на 140 случаях — расхождений нет; число Фруда случая — в пределах разброса от зерна; исключать конвективные случаи (w*/U > 0,5) из обучения хуже на ~4 %; разложенная голова в духе DeepONet — 34 мс на процессоре вместо 167 мс без потери точности.

Вывод: относительная ошибка ≈ 0,22 у всех сетей (P2, P3, AN-3, AN-4) — архитектура не узкое место, дело в постановке или объёме данных. После AN-3 обсуждали, что дальше: тест на заучивание 5–10 рельефов, другая функция потерь, разделение задач; для слабого ветра — отдельная модель (склоновые ветры и конвергенция как источники термиков, переключение по w*/U, без LES) ({{< commit c3a45d5 >}}). Решение пользователя: направление **отложить**, итоги и таблицы оставить в плане и реестре выводов, данные прогонов удалить — воспроизводятся командами из README ({{< commit 59368a8 >}}).

## Выпуск 1.0.5

[1.0.5](/releases/1.0.5/) ({{< commit 870ed5a >}}):
- ветер над рельефом нейросетью P2 (экспериментально) — на процессоре, видеокарта для ветра не нужна;
- пункт меню «Осмотр карты»: место, время и ветер как для полёта, но без пилота — сразу свободная камера со стрелками ветра; стрелки теперь строятся вокруг камеры, радиус 1800 м ({{< commit cdc8e86 >}}).
